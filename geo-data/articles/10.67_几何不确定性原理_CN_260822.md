## 摘　要

离散随机家族（10.58–10.66、0.9、0.10、0.11、0.12）已定理化"随机性从哪来"：折叠均匀化定理（10.60 定理 10.60.2.01）证明确定性映射产生均匀随机，Born 法则从投影测度涌现（10.60 命题 10.60.3.01），塌缩即截面投影（主库 #48）。但经典量子力学最著名的结构——不确定性原理的**乘积下界**——此前在家族内缺席：不存在"两个不相容观测量"的对易子结构。

本文用 3.12 已建立的几何演化方程（命题 3.12.4.01）与 Wick 旋转对应（命题 3.12.10.02）提供的正则结构，构造谱间隙方向 η 上的几何位置算符 η̂ 与几何动量算符 p̂，证明：

$$\boxed{\sigma_\eta \cdot \sigma_p \geq \frac{\hbar_{\text{geom}}}{2} = \frac{1}{4\lambda_1^{\text{eff}}} = \frac{5}{7821} \approx 0.0006393\ \mathrm{rad}^2}$$

并证明扩散核高斯波包精确饱和该不等式。饱和态宽度 σ_η(Δτ=1) = 1/√λ₁^eff ≈ 0.0505689 rad 与 3.12 §4.3 线性近似邻域边界 |η| ≤ 1/√λ₁^eff 重合——该重合是定义性结果（σ_η(Δτ=1) = √(2ħ_geom) = √(1/λ₁^eff) 由 ħ_geom := 1/(2λ₁^eff) 恒等给出，边界即同一 λ₁^eff 的倒数），反映量子力学适用域与最小不确定态宽度在框架内自洽，不构成独立发现。

## 第1章　动机与位置

### §1.1　缺口：不确定性原理的乘积下界

经典量子力学的核心结构清单中，唯一在离散随机家族内完全缺席的是 Robertson 不等式：

$$\sigma_A \sigma_B \geq \frac{|\langle [\hat{A},\hat{B}]\rangle|}{2}.$$

此前的判断（10.67 前身审核）是"家族内没有乘积不等式结构"——Λ_H（0.9 定义 0.9.4.01）是单矩阵谱比，零方差定律（0.9 定理 0.9.4.10）是单族统计，都不构成"两个量同时测不准"的下界。不确定性原理需要的是**两个不相容观测量的正则对**。

### §1.2　武器：3.12 已提供的正则结构

3.12 的几何演化方程（命题 3.12.4.01）已经给出了所需的一切：

1. **谱间隙方向坐标 η**（§4.1）：因果时间 τ = √λ₁^eff·η，η > 0 远离 Birkhoff 不动点 σ*；
2. **二阶导数算子**：Ĥ_geom = −(1/2λ₁^eff)∂_η² + V(η)，自伴生成元（命题 3.12.4.01）；
3. **虚数单位来源**：辛算子 J，J² = −id（§6.4，命题 3.12.6.02，来自 Cl(7) 复结构）；
4. **有效作用量量子**：ħ_geom = 1/(2λ₁^eff)，量纲 [rad²]（命题 3.12.10.02，Wick 旋转读出）；
5. **数值锚定**：λ₁^eff = 391.05 rad⁻²（命题 3.12.4.02，§4.3）。

本文的贡献不是引入新公理，而是**读出**上述结构中隐含的正则对易子 [η̂, p̂] = iħ_geom——几何论此前"没有不确定性原理"，是因为没有读出 η 与 ∂_η 的共轭关系。

### §1.3　与经典理论的关系

经典不确定性原理是量子力学的铁律；本文的不等式在几何框架内同样严格，但**数值定标不同**：ħ_geom 不是普朗克常数，而是谱间隙本征值的倒数。二者的连接通过 3.12 §2.2 的 Born 法则（定理 3.12.2.01，偏差 −2.23×10⁻⁸%）在映射层建立。

## 第2章　几何正则结构

### §2.1　几何位置算符

**定义 10.67.1.01（几何位置算符）**。在希尔伯特空间 L²(ℝ, dη)（谱间隙方向坐标 η 上的平方可积函数空间）上，定义

$$\hat{\eta}:\ \Psi(\eta) \mapsto \eta\,\Psi(\eta).$$

η̂ 是稠密定义的自伴乘法算符（标准论证：η 为实值可测函数，其乘法算符在 L²(ℝ,dη) 上自伴）。物理对应：η 是编码轨道沿谱间隙方向离开 σ* 的角位移（3.12 §4.1），故 η̂ 编码"系统在谱间隙方向上的位置"。

### §2.2　几何动量算符

**定义 10.67.1.02（几何动量算符）**。在 Schwartz 空间 𝒮(ℝ) 上定义

$$\hat{p} = -i\hbar_{\text{geom}}\,\partial_\eta,\qquad \hbar_{\text{geom}} = \frac{1}{2\lambda_1^{\text{eff}}} = \frac{10}{7821} \approx 0.00127861\ \mathrm{rad}^2.$$

p̂ 在 𝒮(ℝ) 上本质自伴（标准论证：−i∂_η 是动量算符的标准自伴实现，乘以正实常数 ħ_geom 保持自伴性）。量纲检查：ħ_geom 量纲 [rad²]（3.12 §10.2 明确标注），∂_η 量纲 [rad⁻¹]，故 p̂ 量纲 [rad]；对易子 [η̂,p̂] 量纲 [rad²] = ħ_geom 量纲，一致。

**物理对应**：p̂ 编码沿谱间隙方向的"谱流"——波函数相位在 η 方向的变化率。在 3.12 的图景中，Ψ = √ρ·e^{iφ_I}（命题 3.12.4.01），相位 φ_I 的 η 梯度正是谱流。

### §2.3　正则对易子

**引理 10.67.2.01（几何正则对易子）**。在 𝒮(ℝ) 上，

$$\boxed{[\hat{\eta}, \hat{p}] = i\hbar_{\text{geom}}}.$$

*证明*。对任意 Ψ ∈ 𝒮(ℝ)：

$$[\hat{\eta},\hat{p}]\Psi = \hat{\eta}(-i\hbar_{\text{geom}}\partial_\eta\Psi) - (-i\hbar_{\text{geom}}\partial_\eta)(\eta\Psi) = -i\hbar_{\text{geom}}\left[\eta\,\partial_\eta\Psi - \partial_\eta(\eta\Psi)\right] = -i\hbar_{\text{geom}}\left[\eta\,\partial_\eta\Psi - \Psi - \eta\,\partial_\eta\Psi\right] = i\hbar_{\text{geom}}\Psi.$$

∎

**说明**：这是纯算子代数恒等式（A0 类，可独立提交主库）。iħ_geom 的引入不需要任何新假设——ħ_geom 由 λ₁^eff 定义（3.12 命题 3.12.10.02），i 由辛算子 J 提供（3.12 §6.4），η 与 ∂_η 的共轭是 L² 理论的标准事实。

## 第3章　几何 Robertson 不等式

**定理 10.67.3.01（几何不确定性原理）**。对任意归一化态 Ψ ∈ L²(ℝ, dη)（满足 ⟨η̂⟩, ⟨p̂⟩ 有限），定义方差 σ_η² = ⟨(η̂−⟨η̂⟩)²⟩，σ_p² = ⟨(p̂−⟨p̂⟩)²⟩。则

$$\boxed{\sigma_\eta \cdot \sigma_p \geq \frac{\hbar_{\text{geom}}}{2} = \frac{1}{4\lambda_1^{\text{eff}}} = \frac{5}{7821} \approx 0.000639304436773\ \mathrm{rad}^2.}$$

*证明*。标准 Robertson 推导（纯算子代数）：

**(1)** 对任意两个自伴算符 A, B 与归一化态 Ψ，令 f = (A − ⟨A⟩)Ψ，g = (B − ⟨B⟩)Ψ，则 σ_A²σ_B² = ⟨f|f⟩⟨g|g⟩ ≥ |⟨f|g⟩|²（Cauchy-Schwarz）。

**(2)** ⟨f|g⟩ = ⟨(A−⟨A⟩)Ψ|(B−⟨B⟩)Ψ⟩ = ⟨Ψ|AB|Ψ⟩ − ⟨A⟩⟨B⟩。

**(3)** 取 A = η̂，B = p̂。由引理 10.67.2.01，[η̂,p̂] = iħ_geom，故

$$\langle\Psi|[\hat{\eta},\hat{p}]|\Psi\rangle = i\hbar_{\text{geom}}.$$

**(4)** Im⟨f|g⟩ = ⟨Ψ|[η̂,p̂]|Ψ⟩/(2i) = ħ_geom/2。故 |⟨f|g⟩| ≥ ħ_geom/2，代入 (1) 开方得 σ_ησ_p ≥ ħ_geom/2。∎

**数值代入**（λ₁^eff = 391.05 rad⁻²，命题 3.12.4.02 锚定）：

$$\frac{\hbar_{\text{geom}}}{2} = \frac{1}{4 \times 391.05} = \frac{5}{7821} \approx 0.000639304436773\ \mathrm{rad}^2.$$

**推论 10.67.3.02（谱间隙定标）**。λ₁^eff 越大，不确定性下界越小：σ_ησ_p ≥ 1/(4λ₁^eff)。谱间隙本征值 λ₁^eff = 391.05 rad⁻² 是 Birkhoff 混合矩阵的第一本征值（3.12 §4.3），它同时控制：扩散系数 D = ħ_geom（§4.1）、因果时间标度 τ = √λ₁^eff·η、以及本不等式。**谱间隙是"确定性的来源"**——这一结论与 0.9 的谱刚性立场（Λ_H ≫ 1 = 结构信号）同向：谱间隙越宽，不确定性下界越紧，系统越"确定"。

## 第4章　饱和态与几何传播子

### §4.1　高斯饱和波包

**定理 10.67.4.01（饱和态）**。对任意 Δτ > 0，高斯波包

$$\Psi_{\Delta\tau}(\eta) = (2\pi\sigma_\eta^2)^{-1/4}\exp\left(-\frac{\eta^2}{4\sigma_\eta^2}\right),\qquad \sigma_\eta^2 = 2\hbar_{\text{geom}}\Delta\tau = \frac{\Delta\tau}{\lambda_1^{\text{eff}}}$$

精确饱和几何 Robertson 不等式：σ_η·σ_p = ħ_geom/2。

*证明*。

**(1)** Ψ_Δτ 是归一化高斯（标准积分）。其位置方差 σ_η² = 2ħ_geomΔτ（高斯 exp(−η²/4σ_η²) 的 |Ψ|² 方差为 σ_η²）。

**(2)** 高斯波包的动量方差（标准结果，Fourier 变换下高斯保持高斯）：σ_p² = ħ_geom²/(4σ_η²) = ħ_geom²/(8ħ_geomΔτ) = ħ_geom/(8Δτ)。

**(3)** 乘积：

$$\sigma_\eta \cdot \sigma_p = \sqrt{2\hbar_{\text{geom}}\Delta\tau \cdot \frac{\hbar_{\text{geom}}}{8\Delta\tau}} = \sqrt{\frac{\hbar_{\text{geom}}^2}{4}} = \frac{\hbar_{\text{geom}}}{2}.$$

∎

**数值**（Δτ = 1，工具计算）：

$$\sigma_\eta = \sqrt{2\hbar_{\text{geom}}} = 0.0505689405376\ \mathrm{rad},\qquad \sigma_p = \sqrt{\frac{\hbar_{\text{geom}}}{8}} = 0.0126422351344\ \mathrm{rad},\qquad \sigma_\eta\sigma_p = 0.000639304436773\ \mathrm{rad}^2 = \frac{\hbar_{\text{geom}}}{2}.$$

### §4.2　饱和态即几何传播子

**命题 10.67.4.02（饱和态与扩散核同一）**。Wick 旋转前的扩散核（3.12 定义36，d=1 维）：

$$P(\eta_f, \Delta\tau | \eta_i, 0) = \frac{1}{\sqrt{4\pi D\Delta\tau}}\exp\left(-\frac{|\eta_f-\eta_i|^2}{4D\Delta\tau}\right),\qquad D = \frac{1}{2\lambda_1^{\text{eff}}} = \hbar_{\text{geom}}$$

在初态 η_i = 0 处给出 P(η_f) ∝ |Ψ_{Δτ}(η_f)|²（取 σ_η² = 2DΔτ = 2ħ_geomΔτ）。即：**饱和态 Ψ_Δτ 的模方恰是扩散核的转移概率密度**——最小不确定态就是几何演化方程的基本解。

### §4.3　邻域边界重合（自洽性注记）

**推论 10.67.4.03（线性近似域 = 最小不确定宽度）**。饱和态在 Δτ = 1 处的宽度

$$\sigma_\eta(\Delta\tau=1) = \sqrt{2\hbar_{\text{geom}}} = \sqrt{\frac{1}{\lambda_1^{\text{eff}}}} = 0.0505689405376\ \mathrm{rad}$$

**精确等于** 3.12 §4.3 线性近似邻域边界 |η| ≤ 1/√λ₁^eff ≈ 0.0505 rad（命题 3.12.4.02 中薛定谔方程涌现的有效域）。

*几何意义*。薛定谔方程（命题 3.12.4.01）在 σ* 邻域 |η| ≤ 1/√λ₁^eff 内成立；而一个最小不确定波包的宽度恰好就是这个边界。换言之：**量子力学描述（薛定谔方程 + 不确定性）在谱间隙方向上自洽到饱和态宽度为止**——超出该宽度，线性近似失效，需回到完整的扩散方程（3.12 §4.1）。注：该重合是定义性恒等式——σ_η(Δτ=1) = √(2ħ_geom) = √(1/λ₁^eff) 由 ħ_geom := 1/(2λ₁^eff) 直接给出，边界 |η| ≤ 1/√λ₁^eff 是 3.12 §4.3 规定的线性近似有效域尺度，两边共享同一参数 λ₁^eff，无独立自由度，故不构成独立发现；其意义在于自洽性——饱和宽度恰落在线性近似有效域内，超出则需回到完整的扩散方程（3.12 §4.1）。

## 第5章　几何意义

### §5.1　谱间隙作为确定性来源

**命题 10.67.5.01（确定性定标）**。几何不确定性下界随谱间隙单调递减：

$$\sigma_\eta\sigma_p \geq \frac{1}{4\lambda_1^{\text{eff}}}.$$

λ₁^eff = 391.05 rad⁻² 是 Birkhoff 混合矩阵的第一本征值（3.12 §4.3）。谱间隙越宽：
- 扩散系数 D = 1/(2λ₁^eff) 越小 → 信息丢失越慢（3.12 §4.1）；
- 因果时间标度 τ = √λ₁^eff·η 越陡 → 演化越快离开 σ*；
- 不确定性下界 1/(4λ₁^eff) 越紧 → 谱流越"确定"。

这与谱刚性立场（Λ_H = λ₂/λ₁ → 1 无结构，≫ 1 结构信号）同向：**谱结构（间隙/刚性）是确定性的度量，随机性是无结构极限**。几何不确定性原理把这一立场从"族统计"推进到"单态不等式"。

### §5.2　与塌缩-测量的衔接

主库 #48（命题 3.12.8.04，塌缩即截面投影）确立"维度骤降 → 信息丢失 → 随机性"；本定理确立另一个方向：**即便在无测量时，谱流也存在最小不确定度**。二者互补：
- 测量侧（#48，#46）：信息丢失产生随机性（折叠的统计面）；
- 动力学侧（本定理）：谱流的内禀不确定性（正则对的下界）。

不确定性原理在几何框架内的完整图景 = 折叠统计面（测量）+ 正则下界（动力学）。

### §5.3　与 0.12 交替循环的衔接

0.12（交替循环的结构定理）中，均匀化算子 U（折叠/商）产生随机表象，结构化算子 S 产生确定表象。本定理给出 S 相位的**最小不确定度**：结构化算子的每次作用（沿 η 的谱流）至少携带 σ_ησ_p ≥ ħ_geom/2 的"模糊"，这为 0.12 定理 C 的"确定相位"补充了量子级的精度下限——确定不是无限精确，而是确定到 ħ_geom/2 为止。

"随机不是公理"的立场（0.9 §3.1）被本定理加强：随机性的两个来源（测量的折叠、动力学的谱流模糊）都追溯到确定性几何（投影结构、谱间隙），无一需要概率公设。

## 第8章　诚实边界与开放问题

### §8.1　边界

1. **η̂ 的合法性依赖中间层**：η 作为"谱间隙方向坐标"来自 3.12 的几何演化方程（命题 3.12.4.01/4.02），属于中间层（物理量推导锚定实验输入 λ₁^eff = 391.05 rad⁻²）。引理 10.67.2.01 与定理 10.67.3.01 本身是纯算子代数（A0 类，可提交主库），但"η̂ 是合法可观测量"这一前提依赖 3.12。
2. **ħ_geom → 物理 ħ 的映射**：3.12 §2.2（定理 3.12.2.01）通过 Born 法则将 ħ_geom 映射到物理 ħ（偏差 −2.23×10⁻⁸%），但该映射属于映射层，本定理的 [rad²] 量纲在映射层才获得 [能量×时间]。
3. **一维限制**：本定理在谱间隙方向 η 上构造（L²(ℝ,dη)）；完整的扇区参数空间是二维（3.12 §4.1），完整的构造需要 η 与横向方向的正则对——这是 3.12 尚未提供的结构。

### §8.2　开放问题

1. **能量-时间不确定性**：ΔE_geom·Δτ ≥ ħ_geom/2 的几何版本需要 V(η) 的完整谱或演化算子的生成元分析（ΔE 的严格定义）。当前未构造。
2. **完整二维正则结构**：扇区参数空间（η, ξ）上的两个正则对是否存在？若存在，将给出"谱间隙方向 vs 横向方向"的互补关系，可能对应物理上的某种角-动量型不确定性。
