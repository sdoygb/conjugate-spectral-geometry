## §2　代数基础：编码轨道与费米子代数

### §2.1　编码轨道的生成元结构（0.2 §3 复述）

编码轨道是 δ 作用于对象的 8 步轨道：

Cl(0) → Cl(1) → ⋯ → Cl(7) → Cl(8)，

每步添加一个生成元 e_j（j = 1,…,8），满足：

e_j² = −1,   e_j e_k = −e_k e_j (j ≠ k)。

结构：3（物质）+ 2（因果）+ 2（信息）+ 1（闭合）= 8；结构常数 Λ=3、ΔΘ=5、k₀=2 在分段处凝结（0.2 §3、0.5）。

### §2.2　Majorana 同构

**定义 10.89.2.01（Majorana 化）**。对编码轨道生成元 e_j（e_j²=−1），定义

γ_j := i·e_j,   j = 1,…,m。

则 γ_j² = −e_j² = +1，且 γ_j γ_k = −γ_k γ_j (j≠k)——即 {γ_j, γ_k} = 2δ_jk。{γ_j}_{j=1}^m 生成实 Clifford 代数 Cl(m) 的 Majorana 表示。

**命题 10.89.2.02（编码轨道生成元 = 费米子代数生成元，精确）**。设 n 对编码轨道生成元 {(e_{2p−1}, e_{2p})}_{p=1}^n，经 Majorana 化得 {γ_{2p−1}, γ_{2p}}。定义

a_p = (γ_{2p−1} + i γ_{2p})/2,   a_p† = (γ_{2p−1} − i γ_{2p})/2,

则 {a_p, a_q} = 0、{a_p†, a_q†} = 0、{a_p†, a_q} = δ_pq——即 {a_p†} 是 n 个**费米子轨道的产生算符**。占据数

n̂_p = a_p† a_p = (1 − i γ_{2p−1} γ_{2p})/2 = (1 + e_{2p−1} e_{2p})/2

是投影算子（n̂_p² = n̂_p）。∎

**证明**：直接验证反对易关系；γ_j 的 Majorana 性质保证 a_p 满足费米子代数；n̂_p 的幂等性由 (e_{2p−1}e_{2p})² = −1 推出（e 反交换、平方 −1 → 乘积平方 = −e_{2p−1}e_{2p}e_{2p−1}e_{2p} = +e_{2p−1}²e_{2p}² = +1，故 (1+e_{2p−1}e_{2p})²/4 = (1+2e_{2p−1}e_{2p}+1)/4 = (1+e_{2p−1}e_{2p})/2）。∎

### §2.3　Cl(8) 的化学内容（编码轨道闭合步）

**定理 10.89.2.03（Cl(8) = 4 费米子轨道的占据代数，精确）**。编码轨道第 8 步（闭合步，Bott 回归，Berry 相位 2π，0.2 §3.1 步 8）给出

Cl(8) ≅ Mat(16, ℝ) ≅ End(Fock₄),   Fock₄ = ∧(ℂ⁴),   dim = 2⁴ = 16。

即：**编码轨道的 8 个生成元实现 4 个复费米子轨道（8 个 Majorana）的完整占据代数**；其 Fock 空间（4 个自旋轨道的全部 16 个占据模式）恰为 Cl(8) 的自然表示空间。

**化学对应（本文构造）**：4 个自旋轨道 = 2 个空间轨道（1s 或一个 σ 键的 σ/σ* 对，H₂/STO-3G 的 FCI 扇区 dim = C(2,1)² = 4 ⊂ 16 = 全 Fock）；sp³ 四面体（4 个空间轨道）则需要第二个编码轨道周期。此对应为构造，待 §6 验证平台检验。

### §2.4　轨道 = 编码轨道占据位的定义

**定义 10.89.2.04（轨道占据位）**。第 p 个轨道位 = 编码轨道生成元对 (e_{2p−1}, e_{2p}) 的占据数本征空间：n̂_p = (1 + e_{2p−1}e_{2p})/2 的本征值 0（未占据）/ 1（占据）。N 电子态 = 满足 Σ n̂_p = N 的占据模式，即 Fock 空间的 N 粒子扇区 ∧^N(ℂ^n)。

**命题 10.89.2.05（泡利原理的代数实现，精确）**。两个电子不能占据同一轨道位：n̂_p² = n̂_p 且 n̂_p 只能取 0/1。这与 3.12 §9.3 的旋量丛推导（交换两费米子得 −1 因子 → 同点占据矛盾）一致——代数层面（编码轨道生成元的反交换）与几何层面（S³ 旋量丛平行移动）给出同一结论。∎

### §4.4　编码轨道面积竞争定理（候选形态，2026-09-01 推导）

**问题**：Z_eff = Z − Σσ_j（10.9/Slater 式线性屏蔽）对 K 层/轻原子可用（He 电离能 1.4%），但对高层多电子失效（Ne 2p 线性模型给 Z_eff≈6.2，实验类氢值≈2.5，高估 2.5 倍）。"编码轨道面积竞争"的完整形式必须包含两种极限。

**候选定理（面积竞争的三种机制）**：

1. **分层线性竞争（轻原子/内层极限）**：Z_eff = Z − Σ_j σ_j，其中
   σ_inner = sinθ_M⁰ = 0.84740（次内层），σ_same = sinθ_M⁰/√8 = 0.29960（同层）。
   检验：He K 层 Z_eff = 1.7004（I₁ = 24.245 eV，实验 24.587，**1.4%**）；Li 2s（Z−2σ_inner = 1.305，实验类氢 1.26，3.6%）。**适用范围：同层电子少的壳层**。

2. **满壳层幂律竞争（惰性气体极限）**：壳层闭合时，最外层电子有效核电荷与第一电离能满足
   Z_eff ≈ Z^{k₀/ΔΘ} = **Z^{2/5}**，  I₁ ≈ 13.6·Z^{2k₀/ΔΘ}/n² = **13.6·Z^{4/5}/n²**，
   其中 2/5 = k₀/ΔΘ（互锁常数之比，0.5 §2）。
   检验（I₁ 预测 vs 实验）：**Ne 21.45 vs 21.565（0.5%）**、He 23.68 vs 24.587（3.7%）、Ar 15.26 vs 15.760（3.2%）、Kr 14.94 vs 13.999（6.7%）、Xe 13.23 vs 12.130（9.1%）、Rn 13.33 vs 10.749（24%）。
   **中等 Z（≤36）成立（0.5-7%），高 Z 失效（指数从 0.40 向 0.39 漂移）**。
   对比：10.9 的线性框架给 Ne L 层 Z_eff = 3.76，与实验类氢值 2.52 差 33%——**幂律候选（2.51）远优**。

3. **中间区（同层填充过程）**：两极限的非线性插值——**未完成**。根因：Z_eff 的物理本质是径向屏蔽（同层电子的屏蔽效率取决于轨道径向分布），而几何论目前没有径向/穿透结构（轨道 = 编码轨道占据位，无波函数形状）。这是面积竞争定理完整化的关键缺失。

**结构关系（精确部分，独立于上两机制）**：σ_inner/σ_same = √8（Bott 周期 8 的平方根）——10.9 拟合值内部关系（0.8500/0.30 = 2.833，偏差 0.2%）的几何候选精确化（0.84740/0.29960 = 2.829，偏差 0.03%）。**"屏蔽由 Bott 周期结构决定"由此获得支持**。

### §4.5　穿透结构：s/p 穿透比与中间区机制（2026-09-01 推导）

**问题**：Ne 2p 的强屏蔽（类氢 Z_eff = 2.52，要求总屏蔽 7.48）无法由任何常数屏蔽模型给出（常数模型给 4-6）——**径向/穿透结构是必须的**：s 轨道在核附近概率密度非零（穿透强），p 轨道 ∝ r² 在核附近为零（穿透弱）。

**发现（s/p 穿透比 √2，实验 XPS 检验）**：最外层 ns/np 结合能比（实验，NIST XPS）：

| 原子 | E_ns/E_np | vs 2（=√2²） | 类氢 Z_eff 比 |
|---|---|---|---|
| Ne | 48.5/21.6 = 2.245 | 12% | 1.50 |
| Ar | 29.2/15.8 = 1.848 | 7.6% | 1.36 |

2. **Ne/Ar 的 s/p 比偏差**（12%/7.6%）未解释——候选：轻原子相对论效应小、2s/2p 径向分离不足（√2 是"径向完全分离"极限）；

### §4.6　几何 Fock 方程：面积竞争的自洽不动点（2026-09-01 第一版）

**问题**：10.9 的电子结构 = "能级公式 + 拟合屏蔽"，不是自洽理论——轨道能量不依赖占据（无平均场结构），屏蔽是输入常数。量子化学的 Fock 方程（SCF 自洽场）在几何论中缺位（断点 1：轨道定义没有导出可计算的轨道方程）。

**定义 10.89.4.02（几何 Fock 方程，第一版）**。设 N 电子体系、轨道位 p = (n_p, ℓ_p)。几何 Fock 方程 = 面积竞争关系的**自洽闭合**（不动点）：

1. **轨道能量**：ε_p = −13.6·Z_eff(p)²/n_p²（10.9 能级公式，谱展开/Born法则）；
2. **有效核电荷（面积竞争）**：Z_eff(p) = Z − Σ_{r∈occ} σ_{r→p}；
3. **屏蔽结构（穿透）**：内层（n_r < n_p）σ_inner = sinθ_M⁰；同层（n_r = n_p）σ_same(n_p, ℓ_p)（ℓ 依赖——穿透弱则屏蔽强）；
4. **占据**：aufbau（能量最低的 N 个轨道位）；
5. **自洽**：Z_eff 依赖占据集 {occ}，占据依赖 ε_p——迭代到不动点。**不动点 = 谱互锁定理（定理 1.3.4.01）在轨道层面的实现**（几何论"自洽"概念 = 扇区参数互锁）。

**第一版机器验证（Z = 2-10 实验第一电离能反推，类氢 Z_eff = n√(I₁/13.6)）**：

| 屏蔽参数 | 实验反推 | 几何候选 | 偏差 |
|---|---|---|---|
| σ_same(1s) | 0.2959（He） | sinθ_M⁰/√8 = 0.2996 | 0.6% |
| **σ_same(2s)** | **0.6030（Be）** | **sinθ_M⁰/√2 = 0.5992** | **0.6%** |
| σ(1s→2s) | 0.8705（Li） | sinθ_M⁰ = 0.8474 | 2.7% |
| σ_same(2p) | F/Ne 稳定 ≈ 0.75 | 待定（依赖 2s→2p 假设） | — |

**关键发现（√2 家族第三次确认）**：σ_same(2s) ≈ sinθ_M⁰/√2——与 σ_inner/σ_same(1s) = √8（§4.4）、s/p 穿透比 √2（§4.5）同族；**同层屏蔽随壳层外移增强**（1s 0.30 → 2s 0.60 → 2p ~0.75）：外层轨道穿透弱 → 被同层屏蔽狠——σ_same 的 (n, ℓ) 依赖从自洽涌现（不再需要常数拟合），这是与 10.9 的判别性区别。

- **缺口 B（结构性，2026-09-01 第一版处理）**：**N/O 电离能锯齿 = 配对惩罚 + 半满交换稳定，两者都落在几何论常数家族上**：

  - **诚实边界**：配对惩罚标度由两个周期（2 个锯齿点）验证，需第四周期（As→Se）与过渡金属（d 配对）检验；类氢 Z_eff 反推在开壳层有弛豫污染——"几何 Fock 方程"从屏蔽模型到完整原子理论的方向已出，检验待续。

### §7.5　深聚集的几何论机制：编码轨道接触断裂（10.10 联合截面）

深聚集（多参考）的几何论表达不是 FCI 的"能级成簇"，而是 **10.10 的编码轨道接触断裂**：

1. 分子 = 多个原子的编码轨道接触（10.10 联合截面）——每个化学键 = 一个编码轨道接触界面；
2. **深聚集 = 接触界面的断裂**：键断裂 → 联合截面破坏 → 基态从单参考（1 个接触闭合构型）变为多参考（多个断裂构型竞争）——即 10.87 的波包分裂（σ²/σ*² 家族）；
3. **每层一个接触结构**：原子（第 2 层）无接触界面 → 无深聚集通道（⟨r⟩_2 恒在泊松带）；小分子（第 3 层）1-2 个接触 → 断裂产生深聚集；大分子（第 4 层）多接触 → 全部同时断裂接近深聚集极限 0.127；
4. **接触数由 Nₙ 标定**：Nₙ/Nₙ₋₁ 是层间接触结构的尺度比（第 4 层 N₄/N₃ = 6.32）——"断裂界面数"的几何论量是编码容量比，不是化学键数。

1. **接触断裂能量**：全部接触断裂 E_break(n) = M_n·E_bind。锚点：H₂O 2 键断裂 E_break ≈ 2×4.5 = 9.0 eV vs 实验解离能 ≈ 9.5 eV（5%）；H₂O 键数 2 vs 有效通道 √(N₃/N₂) = 2.36（15%）——**"接触数 = 化学键数"在第 3 层近似成立**，"有效通道"略多（含非键自由度）；
2. **深聚集度-断裂通道数**：δ_n = 1 − ⟨r⟩_n(min)/0.386 随断裂通道数增长——锚点：1 通道 δ ≈ 0.44（N₂ 0.218/O₂ 0.232/C₂H₂ 0.2495）、2 通道 δ ≈ 0.54（H₂O 0.179）——**每增 1 通道 δ 增 ~0.10**；
3. **接触数由 Nₙ 标定（候选）**：有效断裂通道 M_n ~ √(N_n/N_{n−1})（层级-尺度映射 = 有效通道比）——M₃ ~ 2.36（H₂O 2 键，15%）、M₄ ~ 3.16（第 4 层有效通道；苯 12 化学键但"独立断裂通道" ~3——候选，待验）；"接触数由 Nₙ 标定"的具体形式 = M_n ∝ √(N_n/N_{n−1})；
4. **深聚集极限（层级递归，§7.4）的机制解释**：⟨r⟩_n(min) = ⟨r⟩_{n−1}(eq)/√(N_n/N_{n−1}) = **M_n 个有效通道全部断裂**的谱聚集极限——深聚集的深度由全部接触断裂产生的近简并构型数决定，构型数按层级-尺度映射标定；
5. **诚实标注**：M_n 的精确形式（√(N_n/N_{n−1}) vs 化学键数 vs 其他）**未定**——锚点只有 2 档（1 键/2 键断裂），需更多断裂档位（3、4 键全断的分子）区分；κ_joint 逐接触不同（10.10 逐接触计算）；δ ∝ 通道数的斜率（0.10/通道）由 2 点定出，统计功效低。

**判别实验（2026-09-01，CH₄ 4 键全断——证伪两个候选）**：

| 系统 | 断裂界面 | 深聚集 ⟨r⟩ | δ = 1−⟨r⟩/0.386 |
|---|---|---|---|
| N₂ | 1 键 | 0.218 | 0.435 |
| C₂H₂ | C≡C | 0.2495 | 0.354 |
| H₂O | 2 键 | 0.179 | 0.536 |
| **CH₄** | **4 键全断** | **0.345** | **0.106** |

（CH₄ STO-3G 对称拉伸（Td→C2v 分块），dim 15876；R=1.09→3.0：⟨r⟩ 0.389→0.345，RHF −39.73→−37.66。）

**结论（证伪 + 修正）**：

1. **"深聚集 ∝ 化学键数"被证伪**：CH₄ 4 键全断（0.345）比 H₂O 2 键（0.179）**浅**——若按"每键加深 0.04-0.05"（检验三），4 键应 ≈ 0.10-0.14，实际 0.345；
2. **"层级常数（同层深聚集相同）"被证伪**：CH₄（0.345）≠ H₂O（0.179）——同在第 3 层（小分子）但深聚集差 2 倍；
3. **检验三（深聚集 ∝ 断裂界面数）被 CH₄ 证伪**——那是 2 个数据点（1 键 vs 2 键）的过度解读（H₂O 恰好比 N₂ 深，可能源于 O 的孤对/开壳层结构而非键数）；
4. **修正（新认知）**：深聚集由**断裂键的多参考生成强度**决定（非键数、非层级常数）——H₂O 深（0.179，O 中心：断裂后 O 的 2p⁴ 开壳层 + 孤对参与 σ²/σ*² 竞争强）、CH₄ 浅（0.345，C 中心：C-H 极性键 + C 的 2p² 开壳层弱）——候选机制：**中心原子的价电子结构（孤对数/开壳层强度）决定断裂片段的 σ²/σ*² 竞争强度**（原子锚点：O ⟨r⟩=0.3776 比 C ⟨r⟩=0.3862 深，方向一致）；
5. **定理 10.89.7.02 需修正**：M_n 不是"接触数"而是"多参考生成通道数"（同核 σ 键权重大、极性键权重小、中心原子孤对增强）——具体加权形式未定，需系统数据（不同中心原子/键型的断裂实验）。
