## §1 引言：从并列探针到探针复形

10.77 交付了 21 枚探针的并列全景。但探针之间不是无关的：⑯（两态 Markov）是⑰（风险排名）的前提，⑲（结构诊断）与⑳（饱和期）是同一全局状态的两个精度层次，㉔（传播序列）与㉕（长周期监测）共享 λ₂/BR 双指标框架，⑭（语言距离）是⑨（语言家族）的成对化。这些关系在 10.77 中散见于"→探针"注记与 §23 的对应表，**没有作为一个结构被陈述**。

本文回答元层问题：探针家族能否组织成一个可计算、可推导的几何结构？答案是肯定的——把探针作为单纯形的顶点、探针间关系作为边、互锁环作为面，探针网成为**单纯复形**，其谱与同调给出全网的结构不变量：

- **谱间隙** = 探针网的刚性（10.75 的刚性概念从数据层提升到预言层）；
- **Betti 数** = 预言一致性的约束结构（环 = 一致性约束，空洞 = 理论盲区）；
- **覆盖度** = 定理-探针二部结构，暴露预言层的冗余不足。

边集不是事后拼凑的：全部 28 条语义边都能从 10.77 §22/§23/§24 与 10.75 §6 的既有推导中逐条定位（§4 给出每条边的出处）。这是"理论的价值在于预言"在元层的贯彻——探针之间的关系本身是可推导的，而非人工连线。

## §2 三维地址：探针的规范坐标

**定义 10.81.2.01（探针三维地址）**：每枚探针 p 有一个规范坐标 (s, t, o)：

| 轴 | 取值 | 含义 |
|---|---|---|
| 尺度 s | μ（微观：个体随机点）/ m（中观：集体量）/ M（宏观：全局图） | 数据粒度，对应 10.75 三尺度 |
| 状态 t | R（刚性检验，中性）/ B（破缺侧）/ G（补缺侧）/ BG（双侧） | 两态模型中的位置 |
| 对偶 o | S（结构侧：谱/刚性/纤维化）/ W（实现侧：事件/统计） | 10.80 谱-波型共轭的投影侧 |

坐标的判定规则（非人工标注）：
- s 由"随机点是谁"判定：受访者/国家个体 = μ；国家/区域均值 = m；全球图/76 年序列 = M；
- t 由探针的判别对象判定：检验锁是否存在 = R；预言破缺 = B；预言补缺/修复 = G；两者同判 = BG；
- o 由探针的观测通道判定：谱量（λ₂、BR、std 标度律、η² 的谱读法）= S；事件/统计量（冲突、满意度均值、贸易份额）= W。

**命题 10.81.2.02（坐标唯一性）**：21 枚实探针在三维格点上无重合（§3 表逐行可查）。编号空洞 ①②⑫⑬ 的坐标空缺位置见 §8.2。

**注**：⑲ 同时落在 B 与 G（破缺热点诊断 + 补缺窗口诊断），⑳ 同时落在 B 与 G（破缺过峰 + 补缺弱化）——这不是分类歧义，而是**互锁的签名**：同一结构预言的两个面（§4.2 边型 I 的定义依据）。

## §4 四类边：依赖 / 互锁 / 对偶 / 数据共享

**定义 10.81.4.01（四类边）**：探针 p, q 之间四类可推导关系：

- **依赖边 D**（有向，无向化进图）：p 的判别规则/机制前提引用 q 的结论。判据：10.77/10.75 正文存在"→探针"或"←探针"的显式机制迁移注记。
- **互锁边 I**（无向）：p 与 q 是同一结构预言的两个面，互相构成判别条件。判据：10.77 中两枚探针共享同一预言对象且互为检验（如 10.77.15.03 明示"与探针⑰…互补：同一区域既是最可能的破缺点，也是最可能的补缺点"）。
- **对偶边 C**（无向）：p 与 q 是同一理论结构的谱侧/实现侧投影。判据：10.80 谱-波型共轭在探针层的一一对应，且不与 I 边重复（I 已覆盖的双面关系不再计入 C）。
- **数据共享边 S**（无向）：p 与 q 使用同一数据源。判据：§3 盘点表的数据源列相同。

**命题 10.81.4.02（边集与出处）**：D=23 条、I=7 条、C=5 条、S=40 条，语义唯一边（D∪I∪C 去重）=28 条。逐条出处：

## §8 三个结构发现

### 8.1 发现一：互锁刚性成立——时序一致性前提满足

## §10 元层定理猜想：探针网刚性

**猜想 10.81.10.01（探针网刚性，候选主库验证，A0 类）**：设互锁复形 I（顶点=预言探针，边=I 边，面=互锁三角形）。若 I 连通（β₀(I 子图)=1）且 β₁(I 复形)=0，则互锁预言集存在**全局一致的时序指派**（可判定）；且互锁谱间隙 Δ_I=λ₁−λ₂ 度量互锁约束的集中度——Δ_I 越大，核心互锁节点（当前为 ㉔）对全网时序的约束越强，时序指派越唯一。

**论证**：
1. 时序指派 = 区间约束满足问题（interval CSP）：每枚预言探针给窗口 [t₁, t₂]（如 ⑰⑲ 关闭 2031-08-23、⑳ 压力最大 2029–2035、㉔ 传播 2034–2038）；I 边 = "同结构两面的窗口必须交叠或衔接"约束；
2. β₁(I)=0 ⟺ 互锁约束图上无未解环：区间 CSP 在约束图无环时多项式可解且解存在当且仅当逐边相容（经典结果，弧一致性的树传播）；
3. β₁(I)>0（存在未填平互锁环）⟹ 环上窗口约束可能矛盾（反例：A 窗口 [2026,2031] 与 B 窗口 [2034,2038] 若以"必须交叠"互锁则不可同时满足）；
4. β₀(I)>1 ⟹ 存在互锁孤岛：跨岛预言无约束关联，全网一致性不可由 I 边保证；
5. 当前实例：β₀(I)=1（7 节点连通）、β₁(I)=0（唯一环 {⑲⑳㉔} 被面填平）、Δ_I=1.3602——前提成立，时序链 ⑰⑲（2031 关）→⑳（2029–2035）→㉔（2034–2038）→㉕（BR 回落监测）逐边相容，**全网预言时序一致可判定**。

**边界**：本猜想是纯图论/谱论命题（A0，局部代数）；"全局一致的时序指派"指框架内所有已记录预言窗口的逻辑相容性，不包含对窗口内事件是否发生的判断（破缺无记忆，探针⑯）。

1. **边集判据的严格性**：边只取"正文显式机制注记"（定义 4.01）；⑨→⑭、⑮→⑯、⑳→㉕ 三条边在本文写作中曾因"机制链（§3 表）与边清单（§4）"的口径差产生分歧，最终以 10.77 正文注记核实后定案（D=23）并同步脚本。判据若放宽（如"主题沿袭"也算依赖），全部不变量需重算；
2. **圈号双轨**：10.75 §6 内部"第五/第六探针"与 10.77 圈号 ⑤⑥ 并存，本文以圈号为准；10.75 内部编号仅作历史注记；
3. **S 边入谱不入同调**（命题 4.03）：数据冗余的谱效应已计入（全图 λ_max=9.3932），但同调结构纯语义；
4. **数值可复现性**：全部数值由 `gpu_spectra/probe_complex_network.py` 输出（numpy eigvalsh + GF(2) 边界矩阵）；未来若正文新增"→探针"注记导致边集变化，脚本重跑即可更新全部不变量。

### 开放问题

1. **边判据敏感性**：若 D 边按"机制链"宽松判据（§3 表口径）扩展，D 可能超过 23 条，β₀/β₁ 随之变化——需要一次判据的正式裁定（写入本文即裁定：以正文显式注记为准）；
2. **⑫ 的独立编号**：贸易成对通道（ρ=−0.171 迄今最强连续耦合）以"⑩′"扩展存在而无圈号——是否升格为独立探针⑫、补全成对耦合三通道（⑩地理/⑭语言/⑫贸易）；
3. **猜想 10.81.10.01 的主库验证**：A0 类（图论/谱论），可提交主库独立重推；
4. **动态复形**：预言兑现/失效后节点状态变化（2031-08-23 关闭 ⑰⑲ 检验后，探针复形需要时间演化版本——"探针复形的动力学"未定义，是下一层开放问题；§9 的实测更新即首次动态读数，后续需形式化"状态-时间"演化规则）；
5. **空洞②的实现**：群尺度-大范围交叉探针（negacyclic d→∞）若实现，其 std 零方差结果将把 ③ 的刚性断言升级为"任意尺度"，可能改变刚性簇的内部结构。
