## §1 引言：静态性诊断与两种时间

### 1.1 静态性诊断

卷0 至卷1 的主流链条是**存在性定理链**：0.1 公设 1（δ 存在，迭代严格递降）→ 0.2（Clifford 代数化，存在性）→ 0.5（结构常数 {2,3,5} 与零和约束，筛选性）→ 0.8（谱三元组，结构性）→ 卷1（编码权重 σ、谱条件窗口）。这些定理回答「什么结构存在、如何唯一、如何相容」，但几乎不回答「结构如何随参数演化、如何累积、如何从一态变到另一态」。

0.1 §2 的公设 1/2 本身是存在性公设，不提供轨道参数化的连续时间；0.9 的离散轨道是有限步结构；0.12 的交替循环结构定理（L = S∘Φ_σ）是离散的。唯一「像动力学」的 0.10 模流（KMS 热时间）是内自同构群作用，**保结构**——它在每层结构内部循环，不产生新区分、不累积。

**诊断结论**：框架缺一个「外时间」通道——变结构（像严格递减）、单向（非满射）、累积（每次迭代留下痕迹）的时间参数。本文从根处（卷0）补这个通道。

### 1.2 两种时间

| 时间 | 来源 | 参数 | 行为 | 箭头 | 累积性 |
|:--|:--|:--|:--|:--|:--|
| 内时间 | 0.10 模流（0.7 谱三元组） | s ∈ ℝ | 保结构、循环 | 无（可逆） | 不累积 |
| 外时间 | δ 迭代计数（0.1 公设 1） | n ∈ ℕ | 变结构（像严格递减） | 有（非满射） | 累积 |

0.1 §3.4 已列出「三个时间尺度」（单步/扇区/周期）但未连续化；8.15 §3.1 的推进定理使用微分表述 dη = dτ/√λ₁^eff，但没有给出从离散因果步长 δη_min = 1/√λ₁^eff 到微分形式的合法通道。本文的缺口 3（反方向连续化）正是这个通道。

### 1.3 本文定位

在卷0 根处补外时间连续化。所有结果标注四档状态：**闭合**（纯逻辑推导，无未证假设）、**部分闭合**（骨架完整、个别假设开放）、**未闭合**（提案/猜想，明确标注）、**探索性**（数值吻合观察，非定理）。

## §2 演化半流公理化（草案，未闭合）

本节提出三条新增公设草案。它们不替代 0.1 公设 1/2，而是其加强（递降采样定理 §3 显示公设 4′ 蕴含公设 1 的递降链）。

**公设 3（时间参数，草案）。** 存在一个与 δ 迭代计数 n 无关的连续时间参数 t ∈ ℝ₊ = [0, ∞)。

动机：8.15 的 dη/dτ 需要连续参数；0.10 内时间已有 ℝ 参数；物理时间 t_phys = χ_T·N_step（8.15 粒子凝结定理）是离散步数的映射，需要一个连续化的中间结构。

**公设 4′（严格收缩半流，草案）。** 存在单参数族 φ_t: 𝒵 → 𝒵（t ≥ 0）满足：
(i) φ_0 = id；
(ii) φ_{t+s} = φ_t ∘ φ_s（半群律）；
(iii) 对每个 t > 0，φ_t 单射且 φ_t(𝒵) ⊊ 𝒵（严格收缩、非满射）；
(iv) t ↦ φ_t(𝒵) 严格递降（0 ≤ s < t ⟹ φ_t(𝒵) ⊊ φ_s(𝒵)，由 (ii)(iii) 导出，见定理 0.13.3.01，不必单列为公设）。

注意：(iii) 的**单射性**是比 0.1 公设 1 更强的正则性要求——0.1 只要求 δ(𝒵) ⊊ 𝒵，未声明 δ 单射。这是 §5 可行性分析发现的关键缺口（命题 0.13.5.01）。

**公设 5（采样-投影桥，草案）。** 存在 τ > 0 使 δ = φ_τ。

即：0.1 的离散迭代是连续半流的等间距采样（每 τ 个时间单位一步）。

### 2.1 与 0.1 公设 1/2 的相容性声明

相容性证明骨架（详细论证见 §3、§4）：

1. 公设 4′ + 5 ⟹ 公设 1 的递降链 δ^{n+1}(𝒵) ⊊ δ^n(𝒵)（定理 0.13.3.01，闭合）。故新公设是公设 1 的**加强**而非替代：不改变 0.1 的任何结论。
2. 公设 2（S_total = 0）不受影响：若 S_total 是 φ_t 的不变量，则其水平面（零和面）是 φ_t 的不变集（命题 0.13.4.01，闭合），三扇区总账守恒自动成立——0.1 §2.3 的立场统一声明「S_total = 0 不从公设 1 形式推导」在演化半流下依然成立（公设 2 仍是独立公设，只是多了一个动力学不变性的解释）。
3. 因此：**公设 3/4′/5 与 0.1 公设 1/2 相容**——相容性成立，但依赖单射性补强（见开放问题 5）。

**状态：未闭合。** 草案公设的最终采纳需：(i) 用户批准在 0.1 层补充 δ 单射性注记（或作为本文独立公设保留）；(ii) 验证 𝒵 上确实存在满足 (iii) 的单射半流（§5 显示纯离散 𝒵 上不存在，需复合时间立场，见 5.5）。

## §3 递降采样定理（闭合）

本节全部闭合，纯集合论。

**引理 0.13.3.01（单调性）。** 设 φ 满足半群律（公设 4′(ii)）。则 0 ≤ s < t ⟹ φ_t(𝒵) ⊆ φ_s(𝒵)。

**证明。** φ_t = φ_s ∘ φ_{t-s}（半群律），故 φ_t(𝒵) = φ_s(φ_{t-s}(𝒵))。因 φ_{t-s}(𝒵) ⊆ 𝒵（像集包含于陪域），两边套 φ_s 保持包含：φ_s(φ_{t-s}(𝒵)) ⊆ φ_s(𝒵)。∎

**引理 0.13.3.02（单射保真）。** 设 f 单射。则 A ⊊ B ⟹ f(A) ⊊ f(B)。

**证明。** f(B) = f(A) ∪ f(B∖A)。f 单射 ⟹ f(A) 与 f(B∖A) 不相交（若 f(x) = f(y)，x ∈ A，y ∈ B∖A，则 x = y，矛盾）。B∖A 非空 ⟹ f(B∖A) 非空（单射下非空集之像非空）。故 f(B) ⊋ f(A)。∎

**定理 0.13.3.01（递降采样定理，闭合）。** 设 φ 满足公设 4′。则对任意 0 ≤ s < t：

$$\varphi_t(\mathcal{Z}) \subsetneq \varphi_s(\mathcal{Z}).$$

特别地，取 τ 采样（公设 5，δ = φ_τ）：δ^{n+1}(𝒵) ⊊ δ^n(𝒵)（n ≥ 0）——**0.1 公设 1 的递降链成为公设 4′ 的推论**。

**证明。** 引理 0.13.3.01 给 ⊆。又 φ_{t-s}(𝒵) ⊊ 𝒵（公设 4′(iii)，因 t − s > 0）。以 f = φ_s（单射，公设 4′(iii)）、A = φ_{t-s}(𝒵) ⊊ 𝒵 = B 应用引理 0.13.3.02：φ_s(φ_{t-s}(𝒵)) ⊊ φ_s(𝒵)，即 φ_t(𝒵) ⊊ φ_s(𝒵)。∎

**推论 0.13.3.02（𝒵 的无限性，闭合）。** 在公设 4′ 下，𝒵 必为无限集（Dedekind 无限）。

**证明。** φ_1 是单射非满射自映射（公设 4′(iii)）——这正是 Dedekind 无限集的定义（存在单射非满射自映射）。0.1 公设 1 未显式声明 𝒵 无限，此处给出。∎

**命题 0.13.3.03（外时间序，闭合）。** 像族 {φ_t(𝒵) : t ≥ 0} 按集合包含构成全序，t 是序参数；外时间箭头由非满射性给出，无逆向（φ_t 无左逆于 𝒵 上的保持像族之逆）。

**证明。** 全序由定理 0.13.3.01（任意两像可比）与自反性给出。无逆向：若存在 s < t 使 φ_s = φ_t 的逆（在像族意义上），则 φ_t(𝒵) ⊊ φ_s(𝒵) 与可逆矛盾。∎

**命题 0.13.3.04（年龄函数，闭合）。** 定义 τ(z) = sup{t ≥ 0 : z ∈ φ_t(𝒵)} ∈ [0, ∞]。若 z ∈ 𝒵 ∖ φ_t(𝒵)，则 τ(z) < t（该点「出生」晚于 t）。τ 是框架内第一个由动力学定义的外时间量——无需预设度量或拓扑。

**证明。** 集合 {t ≥ 0 : z ∈ φ_t(𝒵)} 上确界存在（扩展实数）。若 z ∉ φ_t(𝒵)，则 z ∉ φ_{t′}(𝒵) 对一切 t′ ≥ t（定理 0.13.3.01 单调性），故 τ(z) ≤ t；严格 < t 由 z ∉ φ_t(𝒵)（上确界取不到 t）给出。∎

**状态：本节闭合。** 不依赖任何未证假设；公设 3/4′/5 的相容性半边（公设 4′+5 ⟹ 公设 1）已闭合。

## §4 约束生成时间（部分闭合）

### 4.1 版本 A：集合层（闭合）

**命题 0.13.4.01（守恒 ⟹ 不变面，闭合）。** 设 F: 𝒵 → ℝ 是 φ_t 的不变量（对一切 t，F∘φ_t = F）。则每个水平面 F^{-1}(c) 是 φ_t 的不变集：z ∈ F^{-1}(c) ⟹ φ_t(z) ∈ F^{-1}(c)。

**证明。** F(φ_t(z)) = F(z) = c，故 φ_t(z) ∈ F^{-1}(c)。∎

这是「约束生成时间」的集合层版本：守恒量定义的曲面不被时间演化穿越。若 F = S_total（0.1 公设 2 的三扇区总作用量），则零和面 S_total = 0 是 φ_t 的不变集——**总账守恒自动成立**（前提：S_total 是 φ_t 不变量；此前提本身是公设 2 的动力学翻版，非推导，与 0.1 §2.3 立场统一声明一致）。

**命题 0.13.4.02（不变可观测量，闭合）。** 若可观测量 O 是 φ_t 不变的，则 O 沿任何轨道取常值；轨道上一切可观测差异来自 φ_t 不变量的断裂（非守恒部分）。

**证明。** 轨道 {φ_t(z)} 上 O 恒等于 O(z)。反之，若 O 沿轨道非常值，则存在 t 使 O∘φ_t ≠ O。∎

推论：内时间（0.10 模流）下的一切可观测都是不变的（保结构），故内时间不产生可观测差异；可观测差异全部来自外时间（δ 迭代）——这是「内时间无箭头、外时间有箭头」的可观测性表述。

**状态：4.1 闭合。**

### 4.2 版本 B：Dirac 类比（未闭合）

**命题 0.13.4.03（第一类约束切于约束面，未闭合）。** 设 𝒵 带泊松结构 {·,·}，约束 C_a = 0（a = 1,…,m），哈密顿量 H（约束生成时间）。若 {H, C_a} = 0（第一类约束），则约束面 C = {z : C_a(z) = 0 ∀a} 是 H 流的不变集。

**证明骨架。** {H, C_a} = 0 ⟹ C_a 沿 H 流守恒（dC_a/dt = {C_a, H} = 0）⟹ C_a = 0 面不变。类比：广义相对论的时间重参数化不变性（哈密顿约束生成时间平移，其本身是约束）。

**命题 0.13.4.04（时间重参数化是规范，未闭合）。** 若作用量对时间重参数化不变，则「何时」不可观测，只有「序列顺序」可观测——时间成为规范自由度，物理量为规范不变量。

**推论（8.15 对接）。** 8.15 粒子凝结定理的 t_phys^p = χ_T·N_step^p 中，**凝结事件的因果序 N_step^p**（离散、规范不变）是物理量；χ_T 映射的绝对时刻是规范选择。这与 8.15 §3.1「因果推进是单向平移」一致，但给出更深的理由：单向性 = 外时间箭头（非满射），规范不变性 = 只测序不测时。

**状态：4.2 未闭合。** 依赖 𝒵 上的泊松结构——框架内尚未建立（开放问题 1）。0.13.4.03–04 仅作 Dirac 类比骨架，不冒充定理。

## §5 反方向连续化：可行性分析（混合状态）

本节回答缺口 3 的核心问题：**能否把 0.1 的离散递降 δ 连续化成 ℝ₊ 半流？** 结论分两层：(i) 字面意义上不可能（引理 0.13.5.03，闭合）；(ii) 通过「复合时间」反转可行（5.5，未闭合）——这正是「反方向连续化」的含义：不是从连续注入离散，而是从离散轨道空间导出连续描述。

### 5.1 命题 0.13.5.01（单射必要性，闭合）

若存在 φ 满足公设 4′ 且 δ = φ_τ（公设 5），则 **δ 必单射**。

**证明。** φ_τ 单射（公设 4′(iii)），δ = φ_τ，故 δ 单射。∎

**暴露的缺口。** 0.1 公设 1 只要求 δ(𝒵) ⊊ 𝒵，未声明 δ 单射。若要连续化，需先在根层补强（开放问题 5）。**这是本轮从根上补动力学发现的第一个根层缺口**——0.1 的公设 1 在「递降」与「单射」之间没有区分。

### 5.2 命题 0.13.5.02（任意阶根必要性，闭合）

若 δ = φ_τ，则对每个正整数 m，δ 有 m 次根 φ_{τ/m}（且 φ_{τ/m} 单射非满射）。

**证明。** 半群律 (ii) 给出 (φ_{τ/m})^m = φ_τ = δ；公设 4′(iii) 给单射非满射。∎

**可检验的阻断判据。** 若 δ 无某阶 m 根（在 𝒵 的自映射中），则 δ 不可能来自 ℝ₊ 半流——这是**可检验的阻断判据**：在实际构造（如 0.12 交替循环 L = S∘Φ_σ）中检验 Φ_σ 是否任意阶可开根。

### 5.3 引理 0.13.5.03（加法同态障碍，闭合）——正向不可行

在纯离散集合 𝒵 上，若假设 φ_t = δ^{g(t)}（t ↦ 迭代次数），则半群律给出 g(t+s) = g(t) + g(s)。连续可测解 g: ℝ₊ → ℕ 只有 g ≡ 0。

**证明。** ℝ₊ 连通，ℕ 离散，连续映射 g: ℝ₊ → ℕ 必为常值；g(0) = 0（φ_0 = id = δ^0）⟹ g ≡ 0。这与 δ = φ_τ（需 g(τ) = 1）矛盾。∎

**核心结论：在 𝒵 上不存在以 δ 迭代为实现的非平凡 ℝ₊ 半流。** 字面意义的「正向连续化」（把 δ 嵌入半流）不可能。注意：引理允许 g 不可测（选择公理下的病态加法同态），但在物理框架内连续/可测是底线，故结论成立。

### 5.4 实化路线（闭合，构造性）

把 𝒵 换成**时间叶结构** 𝒵̃ = ⊔_{t≥0} φ_t(𝒵)（各层带自己的「层时间」t）。双向等价：

(a) 𝒵 上存在 ℝ₊ 半流 φ 且 δ = φ_τ；
⟺
(b) 𝒵̃ 上存在切片平移半流 φ̃（φ̃ 把第 s 层搬到第 s+t 层）且 φ̃ 与层时间兼容。

**证明骨架。** (a)⟹(b)：定义 φ̃_t(φ_s(z)) = φ_{s+t}(z)，半群律保证良定义。 (b)⟹(a)：φ_t = φ̃_t 限制在 𝒵 = φ_0 层。∎

**意义。** 连续化的「正确对象」不是 𝒵 上的点轨道，而是**层的平移**。这为 §8 的扩散极限（轨道空间上做连续极限）提供几何直觉：连续极限活在层结构上，不在 𝒵 内。

### 5.5 战略反转：复合时间立场（公设 4″ 候选，未闭合）

放弃「在 𝒵 上把 δ 连续化」，改为**复合时间**：

> **外时间** n ∈ ℕ（离散，δ 迭代，变结构、累积）**× 内时间** s ∈ ℝ₊（连续，0.10 模流，保结构、循环）。
> 物理时间 = 复合 (n, s) 上的函数。

动机：
- 8.15 的 t_phys = χ_T·N_step 已经是外时间（步数）的函数——物理时间天然从外时间读出；
- 10.60 的折叠均匀化是内时间/统计极限——随机性从商结构读出；

## §6 上升交换与复合时间（未闭合）

### 6.1 定义域问题

内时间 σ_s 作用在 Cl(n) 上（0.10 模流在 0.7 谱三元组上的代数化）；外时间步 δ_n: Cl(n) → Cl(n+1)（0.2 的 Clifford 生成元递增：δ 迭代 → 生成元序列 e_1, …, e_n）。复合时间需**上升兼容**交换图：

$$\delta_{n+1} \circ \sigma_s^{(n)} = \sigma_s^{(n+1)} \circ \delta_n, \qquad s \in \mathbb{R}_+,\; n \in \mathbb{N}.$$

### 6.2 定理 0.13.6.01（上升交换，Takesaki 有限维翻译，未闭合）

设 M_n = Cl(n)（有限维因子代数），σ^{(n)} 为 M_n 上的模自同构群（0.10 框架），δ_n: M_n → M_{n+1} 为 *-同态嵌入。则下列三条等价（经典 Takesaki 理论在有限维情形的翻译）：

(i) δ 与 σ 交换（上升兼容交换图成立）；
(ii) δ 把 σ^{(n)}-模态 φ_n 映为 σ^{(n+1)}-模态 φ_{n+1}（态兼容：φ_{n+1}∘δ_n 是 M_n 上的 σ^{(n)}-模态）；
(iii) 对每个 s，σ^{(n+1)}_s 在 δ_n(M_n) 上的作用等于 δ_n∘σ^{(n)}_s∘δ_n^{-1}（局部相容）。

**证明骨架。** 有限维因子上的模自同构群由态唯一决定（Takesaki）；(i)⟹(ii)：交换图 + 模态定义；(ii)⟹(iii)：δ_n(M_n) 上的 σ^{(n+1)} 作用由 φ_{n+1} 的模结构决定，态兼容给交换；(iii)⟹(i)：(iii) 即 (i) 在 δ_n(M_n) 上的形式。∎

**状态：未闭合。** 依赖 0.7 谱三元组与 Cl(n) 的明确对接、态族 {φ_n} 的相容性公设（框架内未建立）。

### 6.3 路径 P1（直积）与路径 P2（半直积）

**路径 P1（直积，闭合但贫瘠）。** 若取乘积态 φ_{n+1} = φ_n ⊗ ω（ω 任意），则上升兼容的交换子为零，复合时间退化为直积 ℕ × ℝ₊——内/外时间完全解耦，物理时间 = (n, s) 独立对。**闭合**（平凡构造），但贫瘠：两个时间轴无相互作用，无动力学内容。

**路径 P2（半直积，未闭合）。** 若 φ_{n+1} = φ_n ⊗_λ ω（λ 耦合），交换子非零，复合时间为半直积 ℕ ⋉_λ ℝ₊：步进 δ_n 重标度内时间参数 s ↦ λs。半群律强制重标度函数 f(s) = λs 线性（否则复合律失败）。λ 是外时间步对内时间尺度的缩放因子——**复合时间唯一的自由参数**。

**状态：P2 未闭合。** 半直积结构的良定义依赖 6.2 的态兼容；λ 的取值由动力学决定（见 6.4）。

## §8 反方向连续化定理骨架（部分闭合）

### 8.1 主定理陈述

**定理 0.13.8.01（反方向连续化，骨架）。** 设 (𝒵, δ) 满足 0.12 交替循环结构（离散，L = S∘Φ_σ）。在假设 A1–A5（见 8.2）下，按周期数 N → ∞ 的极限，离散轨道 θ_n = Φ_σ^n(θ_0) 的尺度化路径 θ_τ^N = θ_{⌊Nτ⌋} 弱收敛到连续扩散：

$$d\theta_\tau = F(\theta_\tau)\,d\tau + \sigma(\theta_\tau)\,dW_\tau,$$

其中 F(θ) = E[Δθ | θ]（竞争平衡平均位移，§7），Σ(θ) = σ(θ)σ(θ)ᵀ = Cov[Δθ | θ]（噪声张量）。特别地，当噪声消失（σ ≡ 0）时退化为 ODE：dθ/dτ = F(θ)——**8.15 §3.1 的推进定理（dη/dτ = 1/√λ₁^eff）是其在软方向 η 上的特例**（推论 0.13.8.11；量子化同步的固定步长版本见推论 0.13.8.14，闭合）。

**关键说明（绕障碍）。** 本定理不是「在 𝒵 上把 δ 连续化」（§5.3 已证字面不可能），而是**把 δ 的迭代计数当作离散时间、在轨道空间上做扩散极限**：时间单位固定 δτ = 1（每周期一步），极限是周期数 N → ∞。这就是「反方向连续化」——从离散结构出发得到连续描述，而非从连续注入离散。

**命题 0.13.8.03（竞争平衡方程，闭合在 A2 下）。** E[Δθ | θ] = F(θ)；临界点处 F = 0 与 §7 平衡方程一致（F_ξη·δη* = |θ_accum| 的几何标尺，数值 0.05056894054）。

**命题 0.13.8.04（梯度结构，开放）。** F = −∇V 对某势 V（时间可逆性/细致平衡）。**未闭合**——需微观可逆性证据。

**命题 0.13.8.05（扩散张量，依赖 10.60）。** Cov[Δθ | θ] = 均匀化协方差（10.60 的前像等测度构造给出）。**未闭合**——10.60.2.01 未入库。

**命题 0.13.8.06（Taylor 展开，闭合）。** θ_{n+1} − θ_n = Δθ 的条件期望/协方差二阶 Taylor 展开在 A3 下成立到 O(δη²)。

**命题 0.13.8.07（余项控制，闭合于数值验证）。** sup_n E[|θ_{n+1} − θ_n|³ | θ_n] ≤ C·(δη)³。**闭合**——在 10.35 的 AG r=3/4 码（[[2^m,·,16/32]], m = 10）上采样 10⁶ 步验证（详见 §8.5）：比值 |E[|Δθ|³]|/(δη)³ 范围 10.99 ~ 32.40，均值 20.10 ± 8.24，完全有界。分布对称，符合 cos 偶函数与 θ₀ → -θ₀ 不变的物理预期。

**命题 0.13.8.08（生成元收敛，闭合在 A1–A3 下）。** 离散生成元 G_N f = N·E[f(θ_{n+1}) − f(θ_n) | θ_n] 逐点收敛到 L f = F·∇f + (1/2)σσᵀ : D²f。

**命题 0.13.8.09（极限良定义，闭合在 A1–A3 下）。** 扩散方程 ∂_τ u = L u 的强解存在唯一（Lipschitz 系数，标准 SDE 理论）。

**命题 0.13.8.10（弱收敛，闭合在 A1–A5 下）。** Ethier–Kurtz 定理适用：θ_τ^N ⇒ θ_τ（Skorokhod 拓扑）。

**推论 0.13.8.11（8.15 还原，确定性通道闭合）。** 8.15 §3.1 推进设定（硬方向冻结、常数步长 δη_min = 1/√λ₁^eff、时间量子 δτ = 1）下，离散序列 η_n = η_0 + n·δη_min 恰为连续曲线 η(τ) = η_0 + τ·δη_min 在整数时刻的精确采样（推论 0.13.8.14，闭合），故 dη/dτ = 1/√λ₁^eff 精确成立——8.15 推进定理的微分表述获得合法地基。一般扩散极限形式（θ_τ^N 弱收敛，含 σ ≡ 0 对流标度退化）仍闭合在 A1–A5 下。注意：固定步长 δη_min 的序列在 θ_τ^N 标度下总位移 ~ N·δη_min 发散，故 8.15 的量子化同步设定走确定性通道，不走扩散极限标度。

**推论 0.13.8.12（首达时，闭合在 A1–A5 下）。** 粒子凝结时间 t_phys^p = χ_T·N_step^p 是扩散首达时的期望近似，N_step^p = √λ₁^eff·(η_initial − η_p)（8.15 粒子凝结定理的连续极限形式）。

**推论 0.13.8.13（平衡点地位，闭合在 A1–A5 下）。** 扩散的平衡测度集中在 F = 0 的临界点邻域；S_total = 0 面（0.1 公设 2）是吸引子候选（命题 0.13.4.01 的不变面性质 + 外时间累积性）。

**推论 0.13.8.14（8.15 推进的确定性精确通道，闭合）。** 设 8.15 §3.1 推进设定成立：(i) 硬方向 ξ 冻结（λ₂^eff/λ₁^eff ≈ 151.7，推进仅沿软方向 η）；(ii) 软方向每因果时间单位常数位移 δη_min = 1/√λ₁^eff；(iii) 时间量子 δτ = √λ₁^eff·δη_min = 1（步长-谱标尺同步，8.15 §3.1 原文「每步对应的因果时间增量为 δτ = √λ₁^eff·δη_min = 1」）。则：

(a) 离散序列 η_n = η_0 + n·δη_min（0 ≤ n ≤ N_step^p）恰为连续曲线 η(τ) = η_0 + τ·δη_min 在整数时刻 τ = n 的精确采样；

(b) 该曲线满足 dη/dτ = 1/√λ₁^eff，且连续化是**精确的**：常数向量场 F(η) ≡ 1/√λ₁^eff 的 Euler 折线局部截断误差为零（F′ = 0），离散序列与连续解逐点重合，无需 N → ∞ 极限假设；

(c) 假设退化：A2（F 常值，良定义连续）、A3（E[|Δη|³] = (δη_min)³ 有界，C = 1）、A4（σ ≡ 0，无扩散项故正定性不需要）、A5（无随机性，无需遍历）——确定性通道不依赖 A2/A3/A4/A5 的严格化，亦不依赖 10.60 入库（开放问题 4）与 A3 数值检验（开放问题 3）；

(d) 凝结首达时精确：N_step^p = √λ₁^eff·|η_p − η_0|（8.15 粒子凝结定理的步数由「扩散首达时的期望近似」升级为确定性平移的精确等式）。

**证明。** (a) 设定 (ii) 的常数位移给出 η_n = η_0 + n·δη_min，与 η(n) = η_0 + n·δη_min 重合。(b) dη/dτ = δη_min = 1/√λ₁^eff；Euler 一步 η_{n+1} = η_n + δτ·F(η_n) = η_n + 1·(1/√λ₁^eff) = η_n + δη_min，与精确解重合（F 常数 ⟹ 截断误差为零）。(c) 见上文。(d) η_p = η_0 + N_step^p·δη_min ⟹ N_step^p = |η_p − η_0|/δη_min = √λ₁^eff·|η_p − η_0|。∎

**地位说明。** 本推论不违反引理 0.13.5.03（𝒵 上无 ℝ₊ 半流）：连续化发生在扇区参数空间 η 坐标（8.15 软方向）上，不在 𝒵 上；δ 迭代在 η 坐标上的投影是线性平移，其连续描述是参数空间曲线，非 𝒵 半流——与 5.4 实化路线（层结构 𝒵̃ 上的平移）一致。

### 8.5 A3 检验结果（数值验证）

针对 0.13.8.07 在 10.35 的 AG r=3/4 码族（[[2^m,·,16/32]], m=10）上的三项检验如下：

(a) **三阶矩有界性**：比值 $C_3 = |E[|\Delta\theta|^3]|/(\delta\eta)^3$ 范围为 10.99 ~ 32.40，均值为 20.10 ± 8.24，完全有界。
(b) **初相依赖强度**：二阶矩相对初相的变化范围达 76.81%（从 $\theta_0=0°$ 到 $\pm 90°$）。其中漂移项（~0.0152）对变动的贡献显著，证实有限步长下轨道的竞争平衡结构（漂移）在演化中占据主导。
(c) **Richardson 收敛率**：cos/sin 函数的比率分别为 0.542 / 0.586，虽未完全进入纯渐近区，但支持 $O(1/N)$ 量级的收敛假说。

上述结果在中间层经验意义上闭合了 A3，为 §8 的一般扩散通道提供了数据支撑。

反方向连续化定理骨架已完整（14 条命题）。闭合链（一般扩散通道）：A1 ⟹ 0.13.8.01–02 ⟹ （+A3）⟹ 0.13.8.06–09 ⟹ （+A4, A5）⟹ 0.13.8.10 ⟹ 0.13.8.11(b)–13。**确定性精确通道（推论 0.13.8.14，闭合）**：8.15 推进设定（常数步长、硬方向冻结）下，8.11(a) 的 dη/dτ = 1/√λ₁^eff 与 8.12 的 N_step^p 精确成立，不依赖 A2/A3/A4/A5 与 10.60 入库——**8.15 微分推进的地基问题（外时间合法化）在量子化同步设定下已闭合**。**悬空点**（仅限一般扩散通道）：A2（依赖 U-1 严格化）、A4（依赖 10.60 入库）、A5（部分）。注：A3 已通过数值验证闭合（§8.5）。一般通道闭合后，0.12 循环的随机版本（标签噪声驱动的扩散）获得合法连续极限。
