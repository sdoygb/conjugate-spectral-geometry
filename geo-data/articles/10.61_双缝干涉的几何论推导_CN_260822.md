# 10.61 双缝干涉的几何论推导：Born 法则与投影叠加

**编号**：10.61 | **日期**：260822 | **系列**：应用（量子测量 → 光学干涉） | **语言**：CN | **性质**：定理化

## 摘要

本文把双缝干涉的条纹分布纳入几何论定理链：从 Born 法则涌现定理（10.60.4.01）出发，推导屏上强度分布的形状（cos²），并明确标注间距标度（λD/d）依赖的实验锚定。主要结果：

1. **命题 10.61.2.01（双路径扇区结构）**：双缝 = 两个同时激活的路径通道；屏上观测 = 商映射 + 截面（#48、10.59 定理 10.59.2.02）；两通道联合投影满足算子线性 P(L₁+L₂)P = (c₁+c₂)J（#3）——**振幅叠加是投影的线性，不是额外公设**。
2. **命题 10.61.2.02（等权重归一化）**：等宽等距双缝 → 两通道投影强度相等；#257 归一化 → σ₁ = σ₂ = 1/2。
3. **定理 10.61.3.01（双缝干涉强度定理）**：Born 法则（10.60.4.01）+ 投影线性 + 等权重 ⟹ I(x) = I₀cos²(πd·x/(λD))（等幅理想化；完整形式含包络，定理 10.61.3.04）。**条纹形状（cos²）是几何论定理的直接推论**；相位差 Δφ = 2πd·x/(λD) 是实验锚定（标准几何光学光程差，远场近似）。
4. **定理 10.61.3.04（单缝包络定理）**：缝 = 缝内位置连续纤维族（命题 10.61.2.03）⟹ 单通道振幅带 sinc 角分布（矩形窗傅里叶变换，相位锚定同定理 10.61.3.01 (iv)）⟹ 完整强度 I(x) = I₀sinc²(πax/λD)·cos²(πdx/λD)；包络第一零点 x₀ = λD/a（a = 0.1 mm 时 6.328 mm ≈ 5Δx，中央包络内 9 条亮纹）。
5. **推论 10.61.3.02（条纹间距）**：Δx = λD/d。
6. **推论 10.61.3.03（对比度）**：等幅 V = 1；非等幅（σ₁ ≠ σ₂）V = 2√(σ₁σ₂)/(σ₁+σ₂)。
7. **数值锚定（中间层，§4）**：λ = 632.8 nm（He-Ne）、d = 0.5 mm、D = 1 m ⟹ Δx = 1.2656×10⁻³ m = **1.2656 mm**，与标准光学公式逐项一致（calculate_math 验证：632.8×10⁻⁹ × 1 / 0.5×10⁻³ = 1.2656×10⁻³）。

**关键依赖**：10.60.4.01（Born 法则涌现定理）、10.60.3.01（投影的测度变换）、10.60.2.01（折叠均匀化：前像等测度）；#3（投影强度）、#257（扇区权重归一化）、#259（Born 法则代数形式）、#48/#46（测量结构）；10.59.2.02（商映射分解）、10.59.2.04（纤维结构）；10.52（双光子双缝相位检验）、10.53（时间纠缠干涉相位预言）为实验语境。

**分层标注**：§2–§3 为纯几何/代数命题（真理层候选，可提交主库验证）；§4 为数值锚定（中间层，参数 λ、d、D 为标准光学实验配置）；§5 为推导边界声明与开放问题。

## §1 问题的坐标

### 1.1 问题

双缝干涉是量子力学最古老的检验：1801 年杨氏实验确立波动性；1989 年 Tonomura 实验显示电子逐点到达、累积成干涉条纹。标准光学给出的屏上强度为

$$I(x) = I_0 \cos^2\!\Big(\frac{\pi d x}{\lambda D}\Big), \qquad \Delta x = \frac{\lambda D}{d},$$

其中 d 为缝间距、D 为屏距、λ 为波长。

几何论已从商结构涌现 Born 法则（10.60.4.01：pᵢ = σᵢ = cᵢ² 不是独立假设）。本文回答：**条纹分布是否是 Born 法则 + 投影叠加的直接推论？** 答案是分层的——条纹的形状（cos²）是几何推论；条纹的间距（λD/d）依赖相位差的实验锚定。

### 1.2 已有真理的坐标

主库真理层与已入库文章的测量结构：

- **10.60.4.01（Born 法则涌现定理）**：观测 = 商映射 + 截面（#48、10.59.2.02）；随机性 = 折叠均匀化（10.60.2.01）；概率数值 = 投影强度 σᵢ = cᵢ²（#3、#257）；振幅–概率关系 Δλᵢ = K√σᵢ（#259）；长时间测量频率 = σᵢ（#47）。
- **10.60.3.01（投影的测度变换）**：长度（振幅）按 |cos θ| 变换，测度（概率）按 cos²θ 变换——概率是振幅的平方是测度论事实。

## §2 双缝的几何结构（真理层）

本节为纯几何/代数命题（A0 类：局部代数命题，Berry 相位 = 0），可提交主库验证。

**命题 10.61.2.01（双路径扇区结构）。** 双缝实验（缝 1、缝 2 等宽等距，缝间距 d，屏距 D）的测量结构为：两条路径通道 L₁、L₂ 同时激活，屏上点 x 是两通道的共同像点（商映射 + 截面，#48；10.59 定理 10.59.2.02：折叠 = φ∘π_q）。两通道在观测截面 V 上的联合投影满足算子线性：

$$P(L_1 + L_2)P = (c_1 + c_2)J,$$

其中 cᵢ 为单通道投影强度（#3）。**振幅叠加是投影算子线性性的直接结果，不是额外公设。**

*证明*。由 #48，观测 = 信息密度在扇区参数空间上的投影约束——商映射 + 截面；由 10.59 定理 10.59.2.02，商映射分解为折叠 = φ∘π_q，屏上同一点 x 对应纤维上的两个前像（两通道的光程配置，10.59 命题 10.59.2.04：纤维为等测度陪集族）。两通道同时激活时，观测截面 V 上的联合投影作用于叠加方向 L₁ + L₂：P(L₁ + L₂)P = PL₁P + PL₂P（P 线性）= c₁J + c₂J = (c₁ + c₂)J（#3 逐项）。∎

> **注 1（"同时激活"的几何含义）**。单缝实验只有一条通道：P(L₁)P = c₁J，屏上强度均匀（无振荡）——与单缝无条纹的观测一致。双缝的关键是**两通道共存于同一观测截面**：联合投影的强度不是 c₁² + c₂²，而是 (c₁ + c₂)²——交叉项的出现是算子线性的必然（见 §3 定理）。

> **注 2（与折叠纤维结构的关系）**。屏点 x 是两前像的共同像，这正是 10.59 离散纤维化的图像：商映射把两条路径"折叠"到同一像点；像点的测度由纤维上的相干叠加决定（§3）。

**命题 10.61.2.02（等权重归一化）。** 等宽等距双缝的两通道投影强度相等：c₁ = c₂；由 #257 归一化（双通道情形 ∑σᵢ = 1）得

$$\sigma_1 = \sigma_2 = \tfrac{1}{2}, \qquad c_1 = c_2 = \tfrac{1}{\sqrt{2}}.$$

*证明*。缝等宽等距 ⟹ 两通道的单缝衍射角分布相同 ⟹ 在任意观测截面 V 上的投影幅度相同（#3 的 cᵢ 由方向与截面的夹角决定，θ₁ = θ₂）⟹ c₁ = c₂。双通道归一化：σ₁ + σ₂ = 1（#257 在双通道情形的直接应用，∑σᵢ = 1 对任意扇区分解成立），故 σᵢ = 1/2、cᵢ = 1/√2。∎

> **注（等权重是实验对称性，不是几何推导）**。c₁ = c₂ 来自缝的等宽等距（实验配置的对称性）；#257 给出归一化。若缝宽不等或透过率不同，则 σ₁ ≠ σ₂——对比度公式见推论 10.61.3.03。

**命题 10.61.2.03（缝的连续纤维族结构）。** 有限缝宽 a 的缝通道 = 缝内位置 ξ ∈ [−a/2, a/2] 的连续纤维族 {L(ξ)}（10.59 命题 10.59.2.04 等测度平移族的连续化——10.59 §5.2 连续轨/离散轨对偶的几何载体）；均匀缝的缝内权重密度为常数 ρ(ξ) = ρ₀（等测度，10.60 定理 10.60.2.01：前像等测度 → 均匀基础）。屏上点 x 处单通道的投影振幅为纤维上的相干叠加：

$$c_1(x) = c_1 \rho_0 \int_{-a/2}^{a/2} e^{i\varphi(x,\xi)}\,d\xi, \qquad \varphi(x,\xi) = \frac{2\pi\xi x}{\lambda D},$$

其中 φ(x,ξ) 为缝内位置 ξ 相对缝中心的光程差相位（锚定：定理 10.61.3.01 (iv) 的同一远场几何光学公式）。

*证明*。10.59 定理 10.59.2.02 的离散纤维化（纤维 = 陪集族）在缝内位置连续化：缝 = 一维连续参数族 {L(ξ)}，屏上同一点 x 接收纤维上全部成员的贡献（§2 注 2：像点的测度由纤维上的相干叠加决定）。等测度权重：均匀缝 ρ(ξ) = ρ₀（10.59 命题 10.59.2.04 前像为等测度平移族；10.60 定理 10.60.2.01 前像等测度 → 均匀基础）。相位差由远场几何光学光程差给出（锚定，与定理 10.61.3.01 (iv) 同一公式，参考点由缝中心推广到缝内位置 ξ）。投影线性（#3）作用于纤维积分：P(∫ρ(ξ)L(ξ)dξ)P = (∫ρ(ξ)c(ξ)dξ)J；c(ξ) = c₁（缝内各位置到屏上同一点 x 的路径方向相同——远场，#3 的 cᵢ 由方向与截面的夹角决定）——振幅层面为 c₁ρ₀∫e^{iφ(x,ξ)}dξ。∎

## §3 干涉强度定理（真理层）

本节组装 §2 与 10.60 的 Born 法则链。相位差部分为实验锚定（注 1 明确标注）。

**定理 10.61.3.01（双缝干涉强度定理）。** 设双缝等宽等距（缝间距 d、屏距 D），入射光波长 λ（锚定输入）。屏上点 x（|x| ≪ D）处的强度为

$$I(x) = I_0 \cos^2\!\Big(\frac{\pi d x}{\lambda D}\Big).$$

*证明*。四步：

(i) **振幅叠加**（命题 10.61.2.01）：屏上点 x 的复振幅为两通道贡献之和

$$\Psi(x) = a_1 e^{i\varphi_1(x)} + a_2 e^{i\varphi_2(x)},$$

其中 aᵢ = K√σᵢ 为通道振幅（10.60.4.01 (iii)，#259：Δλᵢ = K√σᵢ），φᵢ(x) 为通道相位。

(ii) **Born 法则**（10.60.4.01 + 10.60.3.01）：屏上强度 ∝ 概率 = |振幅|²（测度按 cos²θ 变换，迹结构）：

$$I(x) = \big|a_1 e^{i\varphi_1} + a_2 e^{i\varphi_2}\big|^2 = a_1^2 + a_2^2 + 2a_1 a_2 \cos(\varphi_1 - \varphi_2)$$

（恒等式：|a₁e^{iφ₁} + a₂e^{iφ₂}|² = a₁² + a₂² + 2a₁a₂cos(φ₁−φ₂)，calculate_math 符号验证）。**交叉项 2a₁a₂cosΔφ 是干涉项**——它存在是因为概率是振幅的平方（10.60.3.01）；若概率 = |振幅|（线性测度），交叉项不存在，无干涉条纹。

(iii) **等权重**（命题 10.61.2.02）：a₁ = a₂ = a，代入得

$$I(x) = 2a^2\big(1 + \cos\Delta\varphi\big) = 4a^2 \cos^2\!\frac{\Delta\varphi}{2},$$

归一化 I₀ = 4a²（Δφ = 0 处峰值）⟹ I(x) = I₀cos²(Δφ/2)。

(iv) **相位差锚定**：远场近似（|x| ≪ D）下两通道光程差 ΔL = L₂ − L₁ = d·x/D（标准几何光学），相位差

$$\Delta\varphi(x) = \frac{2\pi}{\lambda}\cdot\frac{d x}{D}.$$

代入 (iii)：I(x) = I₀cos²(πd·x/(λD))。∎

> **注 1（锚定声明——推导边界）**。步骤 (i)–(iii) 是几何推导：振幅叠加（命题 10.61.2.01）、概率 = |振幅|²（10.60.3.01）、等权重（命题 10.61.2.02）全部来自主库真理与 10.60 定理链。步骤 (iv) 的相位差 Δφ = 2πd·x/(λD) 是**实验锚定**（标准几何光学光程差公式，远场近似），不是几何论推导——10.52 双缝实验方案、10.53 干涉相位预言均在此锚定语境下工作。

> **注 2（干涉项的几何本质）**。干涉项来自 Born 法则的平方结构：|c₁e^{iφ₁} + c₂e^{iφ₂}|² 的交叉项 = 2c₁c₂cosΔφ。在 #3 的代数中，这对应联合投影强度 (c₁+c₂)² 的展开——干涉是"两通道共存于同一截面"的测度后果，不需要波函数公设之外的任何结构。

> **注 3（峰谷位置——如何对照实验图）**。峰（I = I₀）：x_k = kλD/d（k ∈ ℤ）；谷（I = 0）：x = (k + ½)λD/d。相邻峰间距 = λD/d（推论 10.61.3.02）。标准强度图中条纹的等间距峰谷序列即此公式（§4.2 对照说明）。

**推论 10.61.3.02（条纹间距）。** 双缝干涉条纹的相邻峰间距

$$\Delta x = \frac{\lambda D}{d}.$$

*证明*。cos²(πd·x/(λD)) 是 x 的周期函数，周期 = λD/d（cos² 的周期为 π：πd·Δx/(λD) = π ⟹ Δx = λD/d）。峰与峰、谷与谷的间距均为此值。∎

**推论 10.61.3.03（对比度公式）。** 双缝条纹的对比度 V = (I_max − I_min)/(I_max + I_min)：

(i) **等幅**（命题 10.61.2.02）：V = 1（I_max = I₀、I_min = 0，完全相消）。

(ii) **非等幅**（σ₁ ≠ σ₂，缝宽不等或透过率不同）：V = 2√(σ₁σ₂)/(σ₁ + σ₂)。

*证明*。I_max = (a₁ + a₂)²（Δφ = 2πk 处），I_min = (a₁ − a₂)²（Δφ = (2k+1)π 处）。代入 V：

$$V = \frac{(a_1+a_2)^2 - (a_1-a_2)^2}{(a_1+a_2)^2 + (a_1-a_2)^2} = \frac{4a_1 a_2}{2(a_1^2 + a_2^2)} = \frac{2a_1 a_2}{a_1^2 + a_2^2} = \frac{2\sqrt{\sigma_1 \sigma_2}}{\sigma_1 + \sigma_2}$$

（aᵢ = K√σᵢ，#259；K 因子相消）。等幅 σ₁ = σ₂ 时 V = 1。∎

> **注（对比度与归一化的互锁）**。V = 2√(σ₁σ₂)/(σ₁+σ₂) 满足 0 ≤ V ≤ 1（几何平均 ≤ 算术平均），且只依赖权重比 σ₁/σ₂——与 #257 归一化的绝对尺度无关，与 #259 的 K 因子无关。

**定理 10.61.3.04（单缝包络定理——缝宽进入投影强度）。** 设双缝等宽（缝宽 a）、等距（缝间距 d），屏距 D，入射光波长 λ（锚定输入）。屏上点 x（|x| ≪ D）处的强度为

$$I(x) = I_0\,\mathrm{sinc}^2\!\Big(\frac{\pi a x}{\lambda D}\Big) \cos^2\!\Big(\frac{\pi d x}{\lambda D}\Big), \qquad \mathrm{sinc}(u) = \frac{\sin u}{u}.$$

*证明*。四步：

(i) **连续纤维族**（命题 10.61.2.03）：单通道投影振幅为缝内位置的相干叠加

$$a_1(x) = a_1 \rho_0 \int_{-a/2}^{a/2} e^{i\varphi(x,\xi)} d\xi, \qquad \varphi(x,\xi) = \frac{2\pi\xi x}{\lambda D} \ (\text{锚定}).$$

(ii) **矩形窗的傅里叶变换**（纯数学，calculate_math 符号验证）：

$$\int_{-a/2}^{a/2} e^{i 2\pi \xi x/(\lambda D)} d\xi = \frac{\lambda D}{\pi x} \sin\frac{\pi a x}{\lambda D} = a\,\mathrm{sinc}\Big(\frac{\pi a x}{\lambda D}\Big), \qquad \lim_{x\to 0} \frac{\lambda D}{\pi x}\sin\frac{\pi a x}{\lambda D} = a$$

——均匀缝（矩形权重）的傅里叶变换是 sinc；单通道振幅 a₁(x) = a₁ρ₀a·sinc(πax/(λD))——**缝宽进入振幅**（ρ₀a = 纤维族总测度 = 跨度，10.59.2.04 等测度结构）。

(iii) **等宽等距**（命题 10.61.2.02）：两缝 sinc 因子相同；双缝组装（定理 10.61.3.01 步骤 (i)–(iii) 逐项成立，振幅 a → a₁(x)）：

$$I(x) = 4|a_1(x)|^2 \cos^2\frac{\Delta\varphi(x)}{2} = I_0\,\mathrm{sinc}^2\!\Big(\frac{\pi a x}{\lambda D}\Big) \cos^2\!\Big(\frac{\pi d x}{\lambda D}\Big), \qquad I_0 = 4a_1^2\rho_0^2 a^2,$$

（Δφ(x) = 2πd·x/(λD)，定理 10.61.3.01 (iv) 锚定）。∎

> **注 1（两类零点的区分）**。谷点 x = (k + ½)λD/d 是干涉相消（两通道反相，cos² = 0）；包络零点 x = kλD/a（k ≠ 0）是单通道自身的纤维叠加零点（sinc = 0）——屏上整条条纹消失（干涉项与直流项同时为零）。后者与 O4 的谷点信息零点（§5）不同层面。

> **注 2（与 10.59 混叠窗口定理的结构类比）**。紧支撑窗口（缝宽跨度 a）在共轭变量（屏上角频率 k = 2πx/(λD)）上的可分辨尺度 = 1/a（包络第一零点 x₀ = λD/a）——与 10.59 定理 10.59.3.01 的混叠阈值（信号跨度 σR 超折叠半周期 q/2 ⟹ 方向信息丢失）同构：**窗口跨度决定共轭变量上的可分辨尺度**（傅里叶对偶，10.59 §5.2 连续轨/离散轨对偶表的延伸）。单通道投影强度 σ₁(x) = σ₁sinc²(πax/λD)（Born 平方，10.60.3.01）即"投影强度变为 x（θ）的函数"的显式形式——缝宽 = 纤维族跨度，包络 = 其傅里叶变换的平方。

**推论 10.61.3.05（包络零点与中央亮纹数）。** 包络第一零点 x₀ = λD/a；中央包络内（|x| < x₀）的完整亮纹数 = 2⌈d/a⌉ − 1（亮纹 x_k = kλD/d 满足 |k| < d/a）。缝宽 a = 0.1 mm、d = 0.5 mm 时：x₀ = 6.328 mm = 5Δx，完整亮纹 9 条（k = 0, ±1, …, ±4）。

*证明*。sinc 的零点在 πax/(λD) = kπ（k ∈ ℤ ∖ {0}），即 x = kλD/a——第一零点 x₀ = λD/a。亮纹在 x_k = kλD/d（推论 10.61.3.02）；|x_k| < x₀ ⟺ |k| < d/a——k 的个数 = 2⌈d/a⌉ − 1（含 k = 0）。d/a = 5 时 9 条。∎

## §4 数值锚定与实验对照（中间层）

本节为实验锚定：参数 λ、d、D 为标准光学实验配置（He-Ne 激光双缝）。

### 4.1 数值互锁

**结构命题 10.61.4.01（数值互锁：条纹间距与标准光学一致）。** 标准配置 λ = 632.8 nm（He-Ne）、d = 0.5 mm、D = 1 m 下，定理 10.61.3.01 给出：

| 量 | 几何论计算 | 标准光学 | 一致？ |
|:---|:---|:---|:---:|
| 条纹间距 Δx = λD/d | 1.2656×10⁻³ m = **1.2656 mm** | λD/d = 1.2656 mm | ✅ 完全一致 |
| 强度分布形式 | I₀cos²(πdx/λD) | I₀cos²(πdx/λD) | ✅ 完全一致 |
| 对比度 V | 1（等幅理想） | 1（等幅理想） | ✅ |
| I(Δx/8)/I₀ | cos²(π/8) = (2+√2)/4 ≈ 0.8536 | 同左 | ✅ |
| 完整强度（缝宽 a） | I₀sinc²(πax/λD)·cos²(πdx/λD) | 同左 | ✅ |
| 包络第一零点 x₀ = λD/a | 6.328 mm（a = 0.1 mm）≈ 5Δx | 同左 | ✅ |
| 中央包络内亮纹数 | 9（k = 0, ±1, …, ±4；d/a = 5） | 同左 | ✅ |

数值验证（2026-08-22，calculate_math）：Δx = 632.8×10⁻⁹ × 1 / 0.5×10⁻³ = 1.2656×10⁻³ m（精确）；cos²(π/8) = 1/2 + √2/4 ≈ 0.8536；∫_{-a/2}^{a/2}e^{i2πξx/(λD)}dξ = a·sinc(πax/λD)（符号验证）；x₀ = 632.8×10⁻⁹ × 1 / 0.1×10⁻³ = 6.328×10⁻³ m，x₀/Δx = 5（精确）；sinc²(π/40) ≈ 0.9979，sinc²(π/40)·cos²(π/8) ≈ 0.8518；∫sinc²(u)du = π。

### 4.2 如何对照标准强度图（Wikimedia 双缝强度分布图）

标准强度图（图 ②，Wikimedia Commons public domain，仅作对照）画的是强度随屏幕位置（或 sinθ）的分布。与本文章公式的对应：

- **横轴**：屏上位置 x（或等价 sinθ ≈ x/D）；**纵轴**：I(x)/I₀。
- **峰**：x_k = kλD/d = k × 1.2656 mm（k = 0, ±1, ±2, …），图中为等间距亮纹中心。
- **谷**：x = (k + ½) × 1.2656 mm，图中为暗纹（强度为零，完全相消）。
- **包络**：标准强度图的 sinc² 包络（缝宽 a 决定包络宽度，条纹幅度随 |x| 增大按 sinc² 衰减）已由定理 10.61.3.04 几何推导——缝 = 连续纤维族（命题 10.61.2.03），单通道振幅带 sinc 角分布；与标准图的包络一致。等幅理想化（a → 0 极限，命题 10.61.2.02）是定理 10.61.3.01 的特例。

### 4.3 与 Tonomura 电子双缝实验的对照

Tonomura 实验（电子逐点到达、长时间累积成条纹）对应 Born 法则的遍历闭合端（10.60.4.01 (iv)：长时间测量频率 = σᵢ；#47）：单次测量是二值符号（#46：m_k = sgn(Re P_kΨ)——电子落到屏上某点），长期统计收敛到投影强度分布——即本文的 I(x)/I₀ = cos²(πdx/λD)。定性一致：单电子无预知落点（随机性来自折叠均匀化，10.60.2.01），累积分布即条纹。

## §5 推导边界与开放问题

**结构命题 10.61.5.01（推导边界）。** 本文推导的分层声明：

- **几何推导（定理链）**：条纹形状 cos²——振幅叠加（命题 10.61.2.01，投影线性 #3）、概率 = |振幅|²（10.60.3.01 + 10.60.4.01）、等权重归一化（命题 10.61.2.02，#257）、干涉项来自平方结构的交叉项（定理 10.61.3.01 注 2）。
- **几何推导（定理链，续）**：包络 sinc²——缝 = 连续纤维族（命题 10.61.2.03，10.59.2.04 等测度纤维的连续化）、纤维相干叠加（§2 注 2）、矩形窗傅里叶变换 = sinc（定理 10.61.3.04 步骤 (ii)，纯数学）、Born 平方（10.60.3.01）给出 sinc²。
- **实验锚定（输入）**：① 相位差 Δφ = 2πd·x/(λD)（标准几何光学光程差，远场近似）；② 参数 λ、d、D、a（实验配置）；③ 等幅假设（等宽等距缝的对称性）。
- **不包含**：非理想缝（透过率差异）、多色光（非单色）。
