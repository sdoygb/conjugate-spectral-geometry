# 摘　要

本文闭合 10.65 遗留的两个缺口。（A）π/4 对应的度规层面判别：9.1 表格 lnΩ₀(7,2) = 0.8543 与有效度规版（λ₁^eff/λ₂^eff = 391.05/59324.3）吻合 0.04%，与裸度规版（392.21/58760.77）差 0.32%——**9.1 的 lnΩ₀ 用有效度规**。由此 π/4 对应的 0.0052% 吻合是"红外有效层面"的结构（裸度规下破裂至 0.17%），非裸层面巧合。残余 δ = 9.53065×10⁻⁵ 的候选：2λ₁/(λ₂S_e)（0.94%）、(2λ₁/(λ₂S_e))(1−√2λ₁/λ₂)（0.0012%，不自然组合）、λ₁ 精确化吸收（λ₁' = 391.199）。（B）热极限饱和值收敛：由 9.1 §8.2 的角色论证（lnΩ₀ = 简并基态 Boltzmann 重分配因子，非密度权重），热域对应为每粒子熵 S(Tc)/Nk_B = (5/2)ζ(5/2)/ζ(3/2) = 1.283781；连续性（二级相变）给出 N_sat = 2.963，与能隙交叉 N* = 3.131 相容（过渡带 5.4%）；排除候选 ζ(3/2)^{2/3}（不连续 34%）与 ζ(3/2)−π/4（零温单通道值）。**结论：热极限 lnΩ₀ 饱和值 = 1.283781，七螺旋 Tc 修正 = 25.12 meV = 291.5 K**。

## §1　引言：两个待闭合缺口

10.65 的缺口清单中，A（π/4 对应）与 B（饱和常数判别）处于"部分闭合"状态。本文的闭合依赖两个此前未核实的事实：

1. **9.1 内部的度规使用**：lnΩ₀ 公式（定理 9.1.6.01）中的 λ₁/λ₂ 用裸度规（392.21/58760.77）还是有效度规（391.05/59324.3）？这直接决定 π/4 吻合的数值。
2. **lnΩ₀ 的物理角色**：9.1 §8.2 的原始推导确认其机制，这是热极限饱和值判别的核心依据。

## §2　缺口 A 闭合：π/4 对应的度规层面判别

### 2.1 度规判别

9.1 定理 9.1.6.03 的 ε_pair 数值用裸度规（392.21/58760.77）；但定理 9.1.8.01 表格的 lnΩ₀ 值验证：

| 度规 | λ₁/λ₂ | lnΩ₀(7,2) | vs 表格 0.8543 |
|:---:|:---:|:---:|:---:|
| 裸度规 | 392.21/58760.77 | 0.857053 | 差 0.32% |
| **有效度规** | 391.05/59324.3 | **0.853927** | **差 0.04%** |

**结论：9.1 的 lnΩ₀ 用有效度规（红外有效量），ε_pair 用裸度规（裸量）**——同一篇文章中两种度规各有其位。

### 2.2 π/4 对应的层面归属

有效度规下（S_e = 137.035999084）：

$$\ln\Omega_0(1,2) = \frac{1}{4}\ln(\lambda_1^{\text{eff}}/\lambda_2^{\text{eff}}) + \ln(S_e/2\pi) = 1.826881885$$

$$\zeta(3/2) - \pi/4 = 2.612375349 - 0.785398163 = 1.826977185$$

$$\delta = 1.826977185 - 1.826881885 = 9.53065\times10^{-5} \quad (0.0052\%)$$

裸度规下：lnΩ₀(1,2) = 1.830008511，δ = +3.031×10⁻³（0.17%）——**吻合破裂 30 倍**。因此 π/4 对应是"红外有效层面"的结构：lnΩ₀（有效度规）与 ζ(3/2)−π/4（临界统计量）在有效层面吻合，裸层面不吻合。这排除了"π/4 对应 = 裸代数巧合"的解读，指向红外动力学结构。

### 2.3 δ 的结构候选与判别

δ = 9.53065×10⁻⁵ 的候选（r = λ₁^eff/λ₂^eff = 0.006591738）：

| 候选 | 数值 | 偏差 |
|:---|:---:|:---:|
| 2λ₁/(λ₂S_e) | 9.62044×10⁻⁵ | 0.94% |
| (2λ₁/(λ₂S_e))(1−√2·λ₁/λ₂) | 9.53076×10⁻⁵ | 0.0012%（组合不自然） |
| 1/(8π²S_e) | 9.24220×10⁻⁵ | 3.0% |
| λ₁ 精确化吸收：λ₁' = 391.05·e^{4δ} | **391.1991** | — |

判别途径：若 λ₁^eff 的独立精确计算给出 391.199（而非 391.05），δ 全部归因于 λ 精度（10⁻⁴ 相对级）；否则 δ 需要独立结构。**当前判定：π/4 对应确认为红外有效结构（0.0052%），δ 限定在 λ₁ 精度级，其归属待 λ₁ 精确化或独立数据点。**

## §3　缺口 B 闭合：热极限饱和值收敛

### 3.1 角色论证（9.1 §8.2 原文）

9.1 §8.2 明确：lnΩ₀ 在分母来自 Boltzmann 因子 exp(−ΔE/k_BT) 在 Ω₀ 个简并基态上的重新分配——"当存在 Ω₀ 个简并基态时，有效激发温度降低因子 lnΩ₀。这不是 BCS 类比，而是统计力学在简并基态系统上的直接推论。"（定理 9.1.8.01 的推导依据。）

**由此：lnΩ₀ 的角色 = 简并基态的 Boltzmann 重分配因子，不是密度权重**。这直接排除候选 ζ(3/2)^{2/3}（其角色是临界密度 nλ³ = ζ(3/2) 的温度权重，机制不同）。

### 3.2 热域对应：每粒子熵

热统计域（T > Δε，N > N* = 3.131，10.65 §2）中基态简并被热占据取代。lnΩ₀ 的热对应 = 每粒子有效热态数对数。BEC 临界点（理想玻色气体标准结果）：

$$\ln\Omega_0^{\text{th}} = \frac{S(T_c)}{N k_B} = \frac{5}{2}\frac{\zeta(5/2)}{\zeta(3/2)} = 1.283781$$

### 3.3 连续性：N_sat = 2.963

二级相变（无潜热）要求零温 lnΩ₀ 与热饱和值连续衔接。解 lnΩ₀(N) = S(T_c)/Nk_B：

$$N_{\text{sat}} = \exp\!\Big(2\big[\ln\Omega_0(1,2) - 1.283781\big]\Big) = \exp(2\times0.543101) = 2.962998$$

过渡带检验：在 N_sat 处，k_BT_c = 4.61283×2.9627/1.28383 = 10.645 meV < Δε = 36/2.9627 = 12.150 meV（余量 12%，仍零温域边缘）；能隙交叉 N* = 3.131 处 lnΩ₀ = 1.2562（低于饱和值 2.2%）。**两判据相容于过渡带 N ∈ [2.96, 3.13]**——5.4% 的差来自判据定义（熵饱和 vs 能隙闭合）与 E_topo 精度。

### 3.4 排除候选与收敛

- **候选2（ζ(3/2)^{2/3} = 1.896810）排除**：与 lnΩ₀(N*) = 1.2562 差 34%（不连续）；角色不符（密度权重 vs Boltzmann 重分配）；其与饱和值 1.2838 的 1.5% 接近为 ζ 函数数值巧合（(3/2)·S(Tc)/Nk_B = 1.9257 vs 1.8968）。
- **候选3（ζ(3/2)−π/4 = 1.826977）排除**：零温单通道值（N=1 基准，§2 的红外结构），非热饱和值。零温域 lnΩ₀(N) 从 1.8269（N=1）下降至 1.2562（N*），热域升至 1.2838——**几何简并度（零温）与热熵（热域）在过渡带交汇**。

**收敛结论**：热极限 lnΩ₀ 饱和值 = S(T_c)/Nk_B = **1.283781**。七螺旋 Tc 修正（10.65 §6 方案 I：仅替换 lnΩ₀，δ₀² 保持零温 0.2093）：

$$k_B T_c'(7) = 37.77 \times \frac{0.853927}{1.283781} = 25.123\ \text{meV} = 291.5\ \text{K}$$

（原预言 438.3 K，下调 33.5%；δ₀² 热标度方案 II 给出更低边界 123.5 K，依赖材料参数，标注开放。）

## §4　附带发现：9.1 内部的度规使用

同一篇文章中：ε_pair（定理 9.1.6.03 数值）用裸度规（392.21/58760.77），lnΩ₀（定理 9.1.8.01 表格）用有效度规（391.05/59324.3）。若为有意设定：配对能是"裸"量（Hamilton 层），简并度是"红外有效"量（观测层）——与 8.18 的裸/有效度规区分一致（λ₁ = 392.21 裸 / 391.05 有效）。若为不一致：需 9.1 澄清。当前按有意设定处理（两处数值各自自洽）。

## §5　汇总与剩余开放

**闭合状态**：
- 缺口 A：π/4 对应确认为红外有效结构（有效度规 0.0052%，裸度规破裂）——从"单点数值吻合"升级为"带层面归属的结构对应"；δ = 9.53×10⁻⁵ 归属待定（λ₁ 精确化 391.199 可吸收）
- 缺口 B：饱和值收敛为 S(T_c)/Nk_B = 1.283781（角色 + 连续性 + 排除法），Tc(7,2) = 291.5 K——从"三候选"收敛为单值

**剩余开放**：
1. δ 的最终归属：λ₁ 精确化（391.05 → 391.199？）或独立结构（当前无 0.01% 级自然候选）
2. δ₀² 的热标度（方案 II 边界 123.5 K）——材料依赖
3. 9.1 裸/有效度规并用的文档澄清
4. 实验判别：Bi₂Se₃ 七螺旋 Tc ∈ {291.5 K（本文）, 438.3 K（9.1 原预言）}——判别力 33%
