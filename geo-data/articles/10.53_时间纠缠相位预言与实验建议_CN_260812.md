# 时间纠缠的干涉相位预言与双光子双缝检验

**编号**：10.53 | **日期**：260812 | **系列**：应用（时间纠缠→量子光学实验接口） | **语言**：CN | **性质**：理论预言与实验建议

**摘要**：时间纠缠理论预言：双光子干涉（二阶关联）条纹相对几何预期存在附加相位偏移 δ_φ，其值介于 0 与 ½log2（≈0.347 rad）之间，来源于两个探测时刻之间由谱条件约束的时间纠缠熵；标准量子光学理论（包括 arXiv:2403.04432 的完整时间-能量纠缠形式）预言该偏移恒为零。本文给出该预言的实验建议——双光子双缝干涉（双光子杨氏干涉）：405 nm 激光二极管泵浦 BBO 晶体产生 810 nm 简并纠缠对，通过教学双缝后由两路 SiPM 符合计数；同步扫描探测器位置，对符合计数做 Fourier 分解，同时提取单光子频率项与双光子频率项条纹相位。判别判据：双光子频率条纹相对几何预期整组平移（上限 0.347 rad ≈ 0.22 mm）、单光子频率分量反向偏移、差条纹零偏移（对称性对照）、平移量与装置几何无关。装置全部由市售组件构成（约 4000 元），测量约 1–2 小时；此前所有双光子杨氏实验均未标定条纹绝对相位，本检验为文献空白。

## §1 引言

二阶关联（g⁽²⁾）干涉——双光子干涉——是量子光学的基础实验：自发参量下转换（SPDC）纠缠对经分束器或双缝后的符合计数条纹由路径不可区分性决定，条纹相位为路径差的线性函数 2πΔL/λ（Ghosh–Mandel 1987 [1]；Hong–Noh 1998 [2]；Peeters et al. 2009 [3]）。2024 年 arXiv:2403.04432 [4] 给出了时间-能量纠缠的完整理论形式，其双光子态的相位自由度在标准框架下已穷尽——标准理论中，符合条纹相对几何预期的相位偏移恒为零。

本文所依据的理论框架（共扼谱几何：时间熵与时间纠缠 [5]）预言：两个探测时刻之间的信息关联（时间纠缠熵）对干涉条纹贡献一个附加几何相位

$$\delta_\varphi(\Delta\eta, \Delta\xi) = \frac{1}{2}\log\left(1 + \frac{1}{\lambda_1(\Delta\eta)^2 + \lambda_2(\Delta\xi)^2}\right),$$

其中 Δη、Δξ 为两探测时刻间隔与横向弧长差的约化量，λ₁、λ₂ 为框架参数（λ₁ ≈ 5.9×10⁴ rad⁻²、λ₂ ≈ 3.9×10² rad⁻²，文献 [5]）。当两探测时刻间隔趋于零（Δη → 0），偏移达到上限 ½log2 ≈ 0.347 rad；当间隔增大，偏移迅速衰减（Δη ~ 1 时已低于 10⁻³ rad）。标准量子光学预言该偏移恒为零。

**为什么选择双缝**：① 二阶关联在双缝中由 SPDC 对的能量-时间纠缠自动产生，无需额外参考通道；② 双缝几何将光程差沿屏面自然展开，无需亚微米延迟线或压电扫描元件；③ 绝对相位（相对几何预期）从未被任何已有双光子实验标定——这是本检验的空白点；④ 装置可完全由市售组件搭建，成本约 4000 元。

## §2 理论预言

### 2.1 双光子双缝的条纹结构

双光子杨氏实验（[1] 型）：SPDC 简并对（信号 s、闲频 i）同时产生，各自经过缝 A 或缝 B 后到达探测器 D₁(x₁)、D₂(x₂)。符合计数 R_c(x₁,x₂) 含四个路径组合——AA（s、i 同过 A）、BB（同过 B）、AB（s 过 A、i 过 B）、BA（s 过 B、i 过 A）——产生两类二阶条纹（近轴近似，d 为缝间距，D 为缝屏距，k = 2π/λ）：

- **和条纹**（AA↔BB 干涉）：相位 Φ_sum(x₁,x₂) = −kd(x₁+x₂)/D
- **差条纹**（AB↔BA 干涉）：相位 Φ_diff(x₁,x₂) = kd(x₂−x₁)/D
- **单光子频率项**（AA↔AB 等交叉项）：相位 ∝ kdx₁/D 或 kdx₂/D——频率为和/差条纹之半

预言：每条条纹携带附加相位偏移 δ_φ，其值由该路径组合对应的两光子时刻间隔决定。

### 2.2 同步扫描的可检验形式

**同步扫描 x₁ = x₂ = x** 下，和条纹相关组合（AA、BB）的两光子时刻间隔**恒为零**（几何对称性）——偏移取上限，且与装置几何标度、时间-几何映射的数值均无关。由此得到四个数据签名：

**签名 1（主判据）：和条纹整组平移。** 和条纹相对几何预期 −2kdx/D 的相位偏移 δ₀ ∈ (0, ½log2]，上限 0.347 rad（对应 Δξ 取理论最小可分辨值 1/√λ₂）。数据表现：双光子频率条纹（周期 λD/(2d) = 4.05 mm）所有峰位一致平移 Δx₀ = 0.347/(2π)×4.05 mm ≈ **0.224 mm**（约 5.5% 条纹周期），不随 x 变化（常数截距）。**非零即证实时间纠缠相位通道存在**；标准预言平移恒为零。

**签名 2（次级判据）：单光子频率分量反向偏移。** 单光子频率项（交叉项）的偏移 = δ(Δη_AB) − δ₀，其中 Δη_AB = dx/(D·cχ_T√λ₁^eff)（χ_T 为理论时间标度，文献 [5]）随 x 增大，偏移从 0 快速下降至 ≈ −0.35 rad——与签名 1 **方向相反**：同一数据集的 Fourier 分量中，双光子频率条纹与单光子频率条纹反向偏移（标准预言两者都对齐）。偏移在 x < 0.5 mm 内完成大部分下降（形状由 δ(Δη) 的 log 形式决定）。

**签名 3（对照）：差条纹零偏移。** AB、BA 组合的时刻间隔相等（对称性）→ 偏移在干涉项中抵消 → 差条纹偏移恒为零（框架与标准预言在此一致）——验证装置对称性与 Fourier 分离正确性；若差条纹偏移 ≠ 0，前两条判据作废（装置问题）。

**签名 4（稳健性）：几何无关性。** 签名 1 的相位偏移与缝间距 d、缝屏距 D、泵浦功率无关（和条纹相关组合的 Δη ≡ 0 是几何事实）——更换 d（50/100/200 μm）重测，相位偏移不变（空间平移量随条纹周期缩放，相位量不变）——排除装置几何系统误差。

### 2.3 数值与判定分层

- 预言区间：δ₀ ∈ (0, 0.347] rad——上限 ½log2 依赖 Δξ = 1/√λ₂ 假设；**判别不依赖精确上限**（非零即证实；若实测 0 < δ₀ < 0.347，按 δ₀ = ½log(1+1/(λ₂Δξ²)) 反推 Δξ 实验值）
- 签名 1 不依赖时间-几何映射数值（Δη ≡ 0 配置）——检验的稳健核心
- 签名 2 依赖逐组合 δ 分配（框架映射的自然应用）——独立验证通道，不构成判别前提

**关键参数**：d = 100 μm、D = 1 m、λ = 810 nm——和条纹周期 λD/(2d) = 4.05 mm，单光子频率项周期 λD/d = 8.1 mm；x 扫描范围 [0, 8] mm 覆盖和条纹约 2 个周期。

### 3.2 测量协议

1. **标定**：强光（LED 白光）直照双缝，相机拍摄双缝条纹，独立标定 d、D（精度 ~0.5%）；随后转入单光子模式（泵浦 ~1–10 mW，符合率 ~kHz）
2. **同步扫描**：x₁ = x₂ = x，x ∈ [0, 8] mm，步长 0.2 mm（和条纹每周期约 20 点）
3. **采集**：每点 ≥ 2×10⁵ 符合计数（kHz 符合率下约 3 分钟）；FPGA 同时记录单计数（强度归一化与装置监测）
4. **Fourier 分离**：R_c(x) 分解为 0 频（直接项，归一化基准）、kdx/D 频（单光子频率项）、2kdx/D 频（和条纹）——频率 1:2 干净分离；差条纹（同步扫描相位恒定）为慢调制基线
5. **相位提取**：和条纹分量相位线性拟合——斜率标定几何预期 −2kdx/D，**截距 = 偏移 δ₀**（斜率/截距分离，几何标度误差不影响偏移提取）；单光子频率项独立拟合（签名 2 的形状）；差条纹基线拟合（签名 3）
6. **稳健性复核**：更换 d = 50/200 μm 或改变泵浦功率重测——签名 1 相位偏移应不变（签名 4）

### 3.3 统计与精度

- 和条纹可见度 V ~ 0.7（保守估计；[1] 型实验理论可见度 100%）
- 相位拟合精度 δφ ≈ 1/(V√N)：分辨 0.347 rad 偏移达 10σ（相位精度 0.035 rad）需 N ≈ 1.7×10⁵ 符合计数/点
- 40 个扫描点总测量约 2 小时；上限检验区（x ∈ [0, 2] mm）数据可先行分析（约 30 分钟出初步结果）
- 系统误差：偶然符合（5 ns 窗 + TEC 暗计数 ~10 kHz → ~1 Hz，远小于 ~kHz 真符合率）；SiPM 面积平滑（0.3 mm 狭缝 → 可见度损失 ~2%）；强度漂移（0 频分量逐点归一化消除）

## §4 判定与分层

| 观测结果 | 判定 |
|---|---|
| 和条纹偏移 ≈ 0.347 rad + 单光子频率项反向偏移 ≈ −0.35 rad，差条纹偏移 = 0 | **强证实**（时间纠缠相位通道 + 逐组合分配模型）|
| 和条纹偏移非零（0 < δ₀ ≤ 0.347），差条纹偏移 = 0 | **证实**（时间纠缠相位通道存在；按 δ₀ 反推 Δξ）|
| 两频率分量均对齐（±0.02 mm，相位 ±0.03 rad）| **排除**（时间纠缠相位通道）|
| 差条纹偏移 ≠ 0 | 装置对称性破坏——先排查，暂不谈判定 |
| 偏移随 d/D 变化 | 几何标定错误——非理论问题 |

## §5 结论

本文给出时间纠缠理论的可检验预言及其实验建议，要点如下：

1. **预言可判别**：双光子双缝和条纹相对几何预期的相位偏移 δ₀ ∈ (0, 0.347] rad，标准量子光学预言 0——判别信号 0.347 rad，超出相位精度一个量级（10σ）
2. **装置可达**：全部市售组件（约 4000 元），双光子杨氏干涉有三十余年实验先例（[1][2][3]）验证可行性；无压电、无亚微米延迟线、无低温要求
3. **文献空白**：所有已有双光子杨氏实验均未标定条纹绝对相位（相对几何预期）——本检验是首次将此量作为测量对象，任何结果均有价值
4. **判定稳健**：主判据（签名 1）不依赖时间-几何映射数值与 Δξ 精确假设；次级签名（签名 2）与对照（签名 3）、稳健性（签名 4）构成完整判别结构

理论框架细节（时间熵的推导、参数 λ₁、λ₂ 与 χ_T 的确定）见文献 [5]。期待独立实验组的验证。
