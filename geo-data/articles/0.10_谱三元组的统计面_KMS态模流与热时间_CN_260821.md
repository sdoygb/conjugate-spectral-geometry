## 摘要

0.7 从 Cl(8) 构造谱三元组 $(A, \mathcal{H}, D)$ 并展开其**几何面**（度量、谱维数、谱作用量）；本文展开同一框架的**统计面**：Tomita-Takesaki 模理论（模算子 $\Delta_\omega$、模共轭 $J$、模流 $\sigma_t^\omega$）、KMS 条件（平衡态公理化）、Connes-Rovelli 热时间假设（物理时间 = 态的模流）。主要结果：(i) KMS 态是谱三元组框架内的合法统计对象，与 0.7 构造相容（$A = \mathrm{Cl}^0(8)$ 是有限维矩阵代数，模理论适用且为内自同构）；(ii) 热时间假设给出时间从态涌现的机制——几何论首次获得动力学（模流 = 时间流），此前的谱、格、$S_{\text{total}} = 0$ 均为静态结构；(iii) 模流与谱作用量的关系（$S_{\text{total}} = 0$ 与平衡态的关系）标注为开放问题；(iv) 与 0.9 离散轨的对接：KMS 态 = 模型族上的平衡态选择原理（MaxEnt 的代数版本），自由费米子（Clifford 生成元）热态 = 自由概率对象——通往 0.11 的桥。分层标注：Tomita-Takesaki 模理论与 KMS 条件是纯数学（可提交主库，A0 类）；热时间假设是框架内的结构命题（中间层）；与 $S_{\text{total}} = 0$ 的统一是开放问题。

## §1 从几何面到统计面

### 1.1 0.7 的展开：谱三元组的两面

0.7 定理 0.7.1.01 从 Cl(8) 构造谱三元组：

$$
A = \mathrm{Cl}^0(8), \quad \mathcal{H} = \Delta_8 \oplus \bar{\Delta}_8, \quad D = \delta|_{\mathrm{Cl}(8)}
$$

并展开其几何面：$D$ 的谱给出度量（谱维数 8）、谱作用量 $S(D) = \operatorname{Tr}(f(D^2/\Lambda^2))$（0.8）给出三扇区耦合的变分表述。**但谱三元组的数学框架本身是双面的**：Connes 的非交换几何建立在算子代数的表示论之上，而表示论的统计侧（态、模、KMS 条件）与几何侧（谱、度量、维数）在 Tomita-Takesaki 模理论中是同源的。0.7 与 0.8 只取了几何面；统计面——模算子、模流、热时间——未展开。本文兑现这一半。

**与 0.5/0.9 的平行结构**：0.5 使用 E₈ 偶幺模格的代数面（根系统 → 结构常数），0.9 展开同一对象的离散面（格族、谱统计、λ₁/GH）。同理，0.7 使用谱三元组的几何面，本文展开统计面。**两次补入都是"展开已有工具的另一半"，而非引入外来对象**——这是卷0扩展的固定形态。

### 1.2 统计面的入口：态与 GNS 构造

统计面需要一个入口概念：**态**（state）。算子代数 $A$ 上的态 $\omega$ 是正归一化线性泛函（$\omega(1) = 1$，$\omega(x^*x) \geq 0$）。GNS 构造将态转化为表示：

**定义 0.10.1.01（GNS 构造）**：设 $\omega$ 是 $C^*$ 代数 $A$ 上的态。GNS 三元组 $(\pi_\omega, \mathcal{H}_\omega, \Omega_\omega)$ 由以下方式构成：$\mathcal{H}_\omega$ 是 $A$ 关于半范数 $\|x\|_\omega = \omega(x^*x)^{1/2}$ 的完备化（模去零空间），$\pi_\omega$ 是左乘表示，$\Omega_\omega$ 是单位元的像。$\Omega_\omega$ 是循环向量（$\pi_\omega(A)\Omega_\omega$ 稠密）。

> **注（地位声明）**。态是模型内选择（与 0.9 §3 的立场一致）：统计不是新公理，而是"在模型族上选择分布"的代数版本。δ 公理与 $S_{\text{total}} = 0$ 公理（0.1）不变。

**在谱三元组中的候选态**：$A = \mathrm{Cl}^0(8) \cong \mathrm{Mat}(8,\mathbb{R}) \oplus \mathrm{Mat}(8,\mathbb{R})$ 是有限维实矩阵代数。其上的态由正定密度矩阵给出（有限维情形，迹态与 Gibbs 态均为合法选择）。三扇区 $\mathcal{M}/\mathcal{C}/\mathcal{I}$（0.8）的编码态是统计面的自然候选——见 §4.2。

## §2 Tomita-Takesaki 模理论（纯数学）

本节内容是算子代数的标准结果（Tomita 1967；Takesaki 1970），不依赖 CSG 的任何假设，可直接提交主库验证（A0 类：局部代数命题）。

### 2.1 模算子与模共轭

设 $M \subseteq B(\mathcal{H})$ 是 von Neumann 代数，$\Omega \in \mathcal{H}$ 是循环分离向量（$\Omega$ 对 $M$ 循环且分离）。定义反线性算子：

$$
S_\Omega: \; x\Omega \mapsto x^*\Omega \quad (x \in M)
$$

$S_\Omega$ 是闭稠定算子。极分解：

$$
S_\Omega = J \Delta_\Omega^{1/2}
$$

**定义 0.10.2.01（模算子与模共轭）**：$\Delta_\Omega = S_\Omega^* S_\Omega$ 是自伴正算子，称为**模算子**；$J$ 是反线性等距（$J^2 = 1$），称为**模共轭**。

**定义 0.10.2.02（模流）**：由模算子生成的单参数自同构群

$$
\sigma_t^\omega(x) = \Delta_\Omega^{it} \, x \, \Delta_\Omega^{-it}, \quad t \in \mathbb{R}
$$

称为态 $\omega$（对应向量 $\Omega$）的**模流**。$\sigma_t^\omega$ 是 $M$ 的自同构（Tomita-Takesaki 定理）。

**命题 0.10.2.03（模流的不动性）**：态 $\omega$ 在模流下不变：$\omega \circ \sigma_t^\omega = \omega$ 对所有 $t$。

### 2.2 KMS 条件与平衡态

**定义 0.10.2.04（KMS 条件）**：设 $\sigma_t$ 是 $M$ 的单参数自同构群，$\beta > 0$。态 $\omega$ 对 $(\sigma_t, \beta)$ 满足 KMS 条件，若对任意 $x, y \in M$（$y$ 属于 $\sigma$ 的全解析元素），存在带域 $0 < \operatorname{Im} z < \beta$ 上的解析函数 $F_{x,y}(z)$，在边界上连续，且

$$
F_{x,y}(t) = \omega(x \, \sigma_t(y)), \quad F_{x,y}(t + i\beta) = \omega(\sigma_t(y) \, x)
$$

等价地：$\omega(x \, \sigma_{i\beta}(y)) = \omega(yx)$。

KMS 条件是量子统计力学中**平衡态**的公理化定义：Gibbs 态是 KMS 态，且（无相变时）KMS 态在给定 $\beta$ 下唯一。

**命题 0.10.2.05（Gibbs 态满足 KMS）**：设 $M = B(\mathcal{H})$，$\rho = e^{-\beta H}/\operatorname{Tr}(e^{-\beta H})$（$\beta$ 逆温度，$H$ 哈密顿量）。态 $\omega_\rho(x) = \operatorname{Tr}(\rho x)$ 对 $\sigma_t(x) = e^{itH} x e^{-itH}$ 满足 KMS 条件，且其模流为

$$
\sigma_t^{\omega_\rho}(x) = e^{it\beta H} x e^{-it\beta H}
$$

即模流 = 时间演化（参数重标度 $t \mapsto \beta t$）。**模流与物理时间演化的等同在此例中精确成立**——这是热时间假设的直观基础。

**命题 0.10.2.06（KMS 与模流的对应）**：态 $\omega$ 对 $(\sigma_t^\omega, \beta)$ 满足 KMS 条件当且仅当 $\sigma_t^\omega$ 是其模流（对 $\beta = 1$ 归一化）。KMS 态是模流的平衡态：模流 = 该态的热时间演化。

> **注（分层标注）**。定义 0.10.2.01–0.10.2.04 与命题 0.10.2.03/2.05/2.06 是纯数学（算子代数标准定理），不依赖 CSG 假设——可提交主库（A0 类）验证。其证明在文献中完备（Takesaki 1970；Bratteli–Robinson 1997），本文不再重复。

## §3 热时间假设

### 3.1 Connes–Rovelli 的表述

Connes–Rovelli（1994）热时间假设：**物理时间演化不是先验的，而是由统计态涌现的**——对任意忠实正规态 $\omega$，其模流 $\sigma_t^\omega$ 就是"该态的热时间"；物理动力学 = 某（优选）态的模流。

$$
\text{时间} = \text{态的模流}：\quad \text{物理演化} = \sigma_t^{\omega_*}
$$

其中 $\omega_*$ 是优选态（见 §4.2 的开放问题）。温度不再是独立参数：$\tau = \beta t$ 的重标度表明**温度 = 时间单位的选择**——同一个模流，重新标度参数即改变"温度"。

### 3.2 时间从态涌现

在 CSG 框架中，热时间假设的地位是**结构命题**（中间层）：它不修改公理，而是给出"动力学从何而来"的机制。此前几何论的所有核心对象均为静态：谱（0.7/0.8）、格与谱统计（0.9）、$S_{\text{total}} = 0$（0.8 约束）。热时间假设首次给出**时间流**：给定态即给定演化。

**结构命题 0.10.3.01（热时间机制）**：在谱三元组框架内，任意忠实正规态 $\omega$ 定义时间演化 $\sigma_t^\omega$；物理时间 = 优选态的模流（若优选态存在）。

### 3.3 温度作为时间单位

KMS 条件中的 $\beta$ 与模流的参数 $t$ 通过 $\tau = \beta t$ 联系：模流的"单位"由态决定，温度是时间单位的重标度。这给出一个几何论此前没有的量：**温度**（模参数）与**时间**（模流参数）的同源性。谱作用量（0.8）的截断 $\Lambda$ 与 KMS 的 $\beta$ 的关系——两者都是"标度参数"——见 §4.2 开放问题。

## §4 统计面在 CSG 框架内的地位

### 4.1 与谱三元组构造的相容性

$A = \mathrm{Cl}^0(8) \cong \mathrm{Mat}(8,\mathbb{R}) \oplus \mathrm{Mat}(8,\mathbb{R})$ 是有限维实矩阵代数（0.7 定理 0.7.1.01）。有限维 von Neumann 代数的模理论是**内自同构**的：

**命题 0.10.4.01（有限维模流）**：设 $M = \bigoplus_i \mathrm{Mat}(n_i, \mathbb{C})$，态 $\omega$ 由密度矩阵 $\rho = \bigoplus_i \rho_i$ 给出（$\rho_i > 0$）。则模算子 $\Delta_\omega = \rho \otimes \rho^{-1}$（作用在 $\mathcal{H} \otimes \bar{\mathcal{H}}$ 上），模流为内自同构

$$
\sigma_t^\omega(x) = \rho^{it} x \rho^{-it}
$$

对 $\rho = e^{-\beta H}/Z$，恢复命题 0.10.2.05 的时间演化。**相容性结论**：0.7 构造的谱三元组（有限维）上，KMS 态、模流与热时间全部良定义——统计面与几何面在同一框架内相容，不需要扩展公理。

### 4.2 与 $S_{\text{total}} = 0$ 的关系（开放）

0.8 的谱作用量原理给出**变分极值**（$S_{\text{total}} = 0$：三扇区贡献之和为零）；KMS 条件给出**平衡态**（模流不变）。两个极端原理并存：

- 作用量极值（Lagrangian 传统）：选择使作用量极值的构型
- KMS 平衡（统计传统）：选择在模流下不变的态

**统一猜想（开放）**：$S_{\text{total}} = 0$ 确定优选态 $\omega_*$（三扇区编码态），物理时间 = $\sigma_t^{\omega_*}$。若成立，则"作用量为零"与"平衡"是同一选择原理的两个表述：**优选态既是作用量零点又是模流不动点**。此猜想目前无证明，标注为开放问题——不假装连接。

### 4.3 与 0.9 离散轨的对接

0.9 §3 确立"随机不是公理，是模型族的均匀采样"；KMS 条件给出同一立场的代数版本：**模型族上的平衡态 = KMS 态**。对应关系：

| 0.9 离散轨 | 0.10 统计面 |
|:--|:--|
| 模型族 $\{\Lambda_q(A)\}$（均匀采样） | 态 $\omega$（正归一化泛函） |
| 谱统计量（Λ_H、λ₁/GH） | 模流的谱（$\Delta_\omega$ 的特征值 = 温度/时间参数） |
| 零方差定律（经验，N=20） | KMS 平衡（命题 0.10.2.06） |
| 随机性定位（§3.1：结构选择） | 态的选择（§1.2：模型内选择） |

**选择原理的统一表述**：0.9 的"为什么选均匀分布"与统计面的"为什么选平衡态"是同一个问题——约束下的唯一选择（MaxEnt 原理 / KMS 条件）。这是 0.9 与 0.10 的对接点。

### 4.4 模流的离散类比（开放）

0.9 的格轨（q-ary 格、模结构）上是否存在模流的离散类比（量子格 / 有限群的模理论）？有限维情形的模流是内自同构（命题 0.10.4.01），在格/有限结构上的离散对应（如有限群上的 KMS 型条件）未建立——标注开放。

### 5.2 通往 0.11 的桥：自由概率与自由费米子

0.2 的 Clifford 代数生成元（$\gamma^\mu$）是**自由费米子**的代数；自由费米子的 Gibbs 态（热态）的关联函数是**自由概率**（Voiculescu）的自然对象——自由卷积 $\boxplus$ 对应随机矩阵谱的加法组合。因此：

- 随机 Clifford 代数（自由费米子 + 随机耦合）= 自由概率的谱理论
- 0.2（Clifford，连续轨）与 0.9（随机格，离散轨）在"随机 Clifford 代数"处交汇
- 自由概率是 0.10（统计面）与 0.11（信息几何：Fisher 度量、模型族上的统计流形）之间的桥梁

此桥在本文仅作预告（§5.2 为连接点标注，非证明）。

## §6 结论与开放问题

**结论**：

1. 谱三元组框架是双面的：几何面（0.7/0.8）与统计面（本文）同源。统计面由态、模算子、模流、KMS 条件构成——全部在 0.7 构造的有限维谱三元组上良定义（命题 0.10.4.01）。
2. 热时间假设（结构命题 0.10.3.01）给出时间从态涌现的机制——几何论首次获得动力学。温度与时间是同一模流的不同参数标度（§3.3）。
3. KMS 条件 = 平衡态的公理化 = 模型族上的选择原理——与 0.9 的"随机不是公理"立场对接（§4.3）。
4. 分层：模理论/KMS（纯数学，可提交主库 A0 类）；热时间机制（结构命题，中间层）；统一猜想与离散类比（开放问题）。

**开放问题**：

1. **$S_{\text{total}} = 0$ 与 KMS 平衡的统一**（核心）：优选态 $\omega_*$ 是否同时为作用量零点与模流不动点？若是，物理时间 = $\sigma_t^{\omega_*}$（§4.2 统一猜想）。
2. **哪个态定义物理热时间**？三扇区编码态？$\sigma^*$ 观测者位置对应的态？（与 1.5 §3.7 输入层的关系未建立）
3. 模流的离散类比（0.9 格轨上的 KMS 型条件）——未建立。
4. 谱条件窗口（100 < S < 200）与热时间/温度的关系——未建立。
5. 0.8 的截断 $\Lambda$ 与 KMS 的 $\beta$ 的标度关系——未建立。
