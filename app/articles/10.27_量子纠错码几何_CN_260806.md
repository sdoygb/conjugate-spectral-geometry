# 10.27 量子纠错码的编码轨道几何：量子比特根源与稳定子判据

编号：10.27 | 日期：260806.1 | 系列：应用（信息层→编码理论接口） | 语言：CN

**摘要**：本文章建立量子纠错码的共扼谱几何定义层。三组既有结构提供接口：10.13 二能级定理（#289）给出量子比特的几何源头——几何最大纠缠对的低能激发空间恰好 2 维；1.1 编码轨道与 1.2 扇区-因子绑定给出"编码"与"张量积分解"的几何概念；10.18 时间纠缠判据（#290）给出"共享像素 = 纠缠"的图论判据。本文章的核心结果是命题 10.27.1.01（量子比特的 Clifford 根源）：Cl(3) 的偶子代数同构于四元数体 ℍ，其复化即单量子比特算符代数 Mat(2,ℂ)，实 Pauli 代数由 ℍ 虚单位在复化中的实现直接给出。由此，量子比特不再依赖物理映射层约定，而是 Cl(3) 偶部的复化的必然结构。§3-§4 给出编码的张量积结构与稳定子码的几何判据框架，并列出开放问题。

## §1 引言与设定

### 1.1 动机

量子纠错码是容错量子计算的理论基石：物理量子比特受退相干与门误差扰动，必须通过冗余编码（n 个物理比特编码 k 个逻辑比特）与稳定子测量来抑制错误。标准理论（稳定子码、Knill-Laflamme 条件、量子 Singleton 界与 Hamming 界）已成熟，但其根基结构——量子比特的 2 维性、Pauli 代数的来源、错误可纠正性的几何本质——在共扼谱几何框架内尚未被重建。

本文章的目标：从已入库的几何真理出发，重建量子纠错码的定义层。这不是对标准理论的替代，而是把其根基结构锚定到编码轨道几何上，使后续定理（码参数界、稳定子判据）可以沿几何推导链获得。

## §2 量子比特的 Clifford 根源

### 2.1 主命题

**命题 10.27.1.01（量子比特的 Clifford 根源）**

设 Cl(3) 为负定实 Clifford 代数（e_i² = -1，i = 1,2,3），则：

(i) Cl(3) 的偶子代数 Cl(3)⁰ = span{1, e₁e₂, e₁e₃, e₂e₃} 同构于四元数体 ℍ。具体地，令 u = e₁e₂，v = e₁e₃，则 u² = v² = (uv)² = -1 且 uv = -vu，与 ℍ 的生成关系一致；dimℝ Cl(3)⁰ = 4 = dimℝ ℍ。

(ii) 复化 (Cl(3)⁰)⊗ℂ ≅ ℍ⊗ℂ ≅ Mat(2,ℂ)（四元数的标准 2×2 复矩阵表示）。

(iii) Mat(2,ℂ) 含实 Pauli 代数 span{σₓ, σ_y, σ_z}：σ_α² = I，σ_α σ_β = -σ_β σ_α（α≠β）。该结构由 ℍ 虚单位在复化中的实现 i ↦ iσ_z、j ↦ iσ_y、k ↦ iσ_x 与 ℂ 标量 -i 相乘得到。

(iv) 设 H 为几何最大纠缠对的 2 维低能激发空间（定理 10.13.3.01），则其复化端射代数 End(H⊗ℂ) ≅ Mat(2,ℂ) ≅ (Cl(3)⁰)⊗ℂ。即：单量子比特算符代数正是 Cl(3) 偶子代数的复化。

**证明**：

步骤1（维度）：由命题 0.9.3.02（#128），dimℝ Cl(3) = 2³ = 8。偶次基元素为 {1, e₁e₂, e₁e₃, e₂e₃}（组合数 C(3,0) + C(3,2) = 1 + 3 = 4），故 dimℝ Cl(3)⁰ = 4。

步骤2（生成关系）：由 e_i² = -1 与反交换（定义 0.2.1.01）：
u² = (e₁e₂)² = e₁e₂e₁e₂ = -e₁e₁e₂e₂ = -(-1)(-1) = -1；
同理 v² = (e₁e₃)² = -1；
uv = e₁e₂e₁e₃ = -e₂e₃，vu = e₁e₃e₁e₂ = -e₃e₂ = e₂e₃，故 uv = -vu；
(uv)² = (e₂e₃)² = -1。
故 {1, u, v, uv} 满足 ℍ 的生成关系（i² = j² = k² = -1，ij = -ji）。

步骤3（同构）：Cl(3)⁰ 为 4 维实代数，中心 = span{1} ≅ ℝ，且由生成关系可验证无零因子（范数乘性：对 x = a + bu + cv + duv，xx̄ = a² + b² + c² + d² ∈ ℝ>0，其中 x̄ = a - bu - cv - duv）。由 Frobenius 定理（与引理 0.2.2.01 #88 步骤7 同源：4 维实可除代数唯一同构于 ℍ），得 Cl(3)⁰ ≅ ℍ。

步骤4（复化）：ℍ⊗ℂ ≅ Mat(2,ℂ) 为四元数复化的标准事实：ℍ 在 Mat(2,ℂ) 中的忠实表示 1 ↦ I、i ↦ iσ_z、j ↦ iσ_y、k ↦ iσ_x 满足 i² = j² = k² = -I、ij = k，且该表示在 ℂ 上张成全部 Mat(2,ℂ)（4 个复基元素线性无关）。

步骤5（Pauli 代数）：将 ℍ 虚单位的像乘以 ℂ 标量 -i，得 σ_z, σ_y, σ_x ∈ Mat(2,ℂ)。由 (iσ_α)(iσ_β) = -σ_ασ_β 与 ℍ 关系 (iσ_z)² = -I，得 σ_α² = I；由 iσ_α 与 iσ_β 反交换（α≠β），得 σ_α σ_β = -σ_β σ_α。故 span{σₓ, σ_y, σ_z} 为实 Pauli 代数。

步骤6（与二能级定理的连接）：由定理 10.13.3.01（#289），低能截断阈值 2λ₁^eff 位于 ℓ=1 本征值 3λ₁^eff/2 与 ℓ=2 本征值 4λ₁^eff 之间，故 H 恰好 2 维；其复化 H⊗ℂ 为 2 维复空间，端射代数 End(H⊗ℂ) ≅ Mat(2,ℂ)。结合步骤4，得 End(H⊗ℂ) ≅ (Cl(3)⁰)⊗ℂ。∎

### 2.2 对径反相的严格表述

**注 10.27.1.01（对径反相）**：10.13 定义 3.2 以 ε₂ = Φ₋ = Φ₊(-x) 表述二能级空间的正交基，字面上 Φ₋ = -Φ₊（因 S³ 上 ℓ=1 调和函数空间的对径映射 T: f(x) ↦ f(-x) 作用为 T x_i = -x_i，即 T = -id）。故"对径反相"的严格含义是：两个模式同为 ℓ=1 奇函数（TΦ = -Φ），而非 Φ₋ 与 Φ₊ 线性相关。二能级空间 H = P(L²(S³)) 由秩-2 谱投影 P 的像给出（#289 步骤3），其正交基由 P 的 Hermite 性自动保证，与奇性不冲突。本注仅澄清表述，不影响 #289 的结论。秩-2 投影的显式几何与二能级基的构造性实现由定理 10.27.1.03 给出。

**定理 10.27.1.03（二能级基的显式构造与反射实现）**：设 p_A, p_B 为几何最大纠缠对（10.13 定义 2.2），γ_AB 为关联测地线（ℳ-扇区大圆，命题 10.13.2.01）。则：

(i)（显式基）二能级空间 H 的显式正交基由关联测地线大圆 γ_AB = S¹ 上的 ℓ=1 模式给出：ε₁(φ) = cos φ、ε₂(φ) = sin φ（∫cos² = ∫sin² = π，∫cos·sin = 0）。构造性解释：定理 10.13.3.01 证明中的"Σ_η 二维切平面上的秩-2 投影"具体化为 ℳ-扇区反直径锁定（定义 2.2 条件 2）所确定的关联测地线大圆上的限制——S³ 的 ℓ=1 空间（4 维）限制到 γ_AB = S¹ 得 2 维 {cos φ, sin φ}。该具体化与 10.13 的秩-2 投影声明相容（Σ_η 切平面在 ℳ-扇区切空间中的 2 维像含 γ_AB 的切方向），但 10.13 原文未明说此等同，标注为构造性解释。

(ii)（对径反相的严格含义）对径映射 T: φ ↦ φ+π 在 H 上为 T = -id（cos(φ+π) = -cos φ、sin(φ+π) = -sin φ）——两个模式同为 ℓ=1 奇函数，而非一个模式的线性拷贝。

(iii)（反射实现）Pauli 代数由 S¹ 上夹角 π/4 的两条反射轴实现：Z = 反射(φ ↦ -φ) = diag(1,-1)（保持 ε₁、翻转 ε₂），X = 反射(φ ↦ π/2-φ) = [[0,1],[1,0]]（交换 ε₁ ↔ ε₂）。验证：X² = Z² = I；两反射合成旋转 π/2，即 XZ = R_{±π/2}，故 (XZ)² = R_π = -I 且 XZ = -ZX。

(iv)（二面体群）{±I, ±X, ±Z, ±XZ} ≅ D₄（8 阶二面体群，正方形的对称群）——单比特实 Pauli 群的几何实现。

(v)（推论）命题 10.27.1.01 的几何识别修正：对径翻转 T = -I 对应全局相位（射影空间平凡），不是 Pauli X；Pauli X 的几何对应是 S¹ 上反射轴 φ = π/4 的反射。§4.1 中"对径方向对应 X 的翻转作用"依此修正。

证明：(i) 由定义 2.2 条件 2（ℳ-扇区反直径锁定：p_A, p_B 位于大圆对径点），关联测地线 γ_AB 是 S³ 的大圆 S¹；S³ 的 Laplace-Beltrami ℓ=1 本征空间（4 维，本征值 3λ₁^eff/2，定理 10.13.3.01）在 γ_AB 上的限制为 S¹ 上 ℓ=1 空间（2 维，基 {cos φ, sin φ}），正交性由 ∫₀^{2π} cosφ sinφ dφ = 0 直接验证。(ii) 直接代入。(iii) 反射的矩阵计算：反射(φ ↦ -φ) 在基 {cos φ, sin φ} 上为 diag(1,-1)；反射(φ ↦ π/2-φ) 交换 cos φ 与 sin φ（cos(π/2-φ) = sin φ、sin(π/2-φ) = cos φ）。XZ 与 ZX 的差：XZ(cos) = sin、ZX(cos) = -sin，XZ(sin) = -cos、ZX(sin) = cos，故 XZ = -ZX。(iv) 由 (iii) 与 XZ = R_{±π/2}（阶 4）、Z² = I、Z(XZ)Z = (XZ)⁻¹ 验证 D₄ 关系。(v) 由 (ii)(iii)。∎

### 2.3 与奇偶配对的对应

由定理 7.13.2.02（#294），Cl(3) ≅ ℍ⊕ℍ 的中心对合 ω₃ 给出切空间分裂 T_odd ⊕ T_even（dim = 1 + 2），慢模方向（λ₁^eff）位于偶平面 T_even 内。结合命题 10.27.1.01：Cl(3)⁰ ≅ ℍ 为 4 维，其复化承载量子比特算符代数；偶平面 T_even 为 2 维，与 H 的维度一致。两者都由 Cl(3) 的偶部结构承载——H（L²(S³) 上的谱对象）与 T_even（切空间上的代数对象）是否经编码映射同构，列为开放问题 O1（§5）。

## §3 编码的张量积结构

### 3.1 从扇区-因子绑定到量子编码

1.2 扇区-因子绑定给出编码映射的形式分解 E_n = ε_n ⊗ M_n（因子分量与混合分量分离）。该张量积分解是"编码"概念在几何论中的代数表达。量子纠错码的编码同样是张量积结构上的等距嵌入：

**定义 10.27.2.01（量子编码）**：设 H 为单量子比特空间（命题 10.27.1.01(iv)，H⊗ℂ ≅ ℂ²）。量子编码是等距嵌入 V: (ℂ²)⊗ᵏ → (ℂ²)⊗ⁿ（k 个逻辑比特嵌入 n 个物理比特），其像 C = V((ℂ²)⊗ᵏ) 称为码空间，参数 (n, k) 记作 [[n, k]]。编码的因子结构 V = ε_n ⊗ M_n 的量子对应（若 V 容许该分解）称为因子化量子编码。

### 3.2 编码轨道与码嵌套

1.1 编码轨道给出六层递推 N₁ = 6000 → N₇ = 2.7×10⁸（素因子预算 {2,3,5}，消耗/回收操作）。量子层面的对应结构是码的嵌套：一族码 C₁ ⊂ C₂ ⊂ ⋯ 满足 dim C_j = 2^{k_j} 单调递增、稳定子生成元数单调递减（通过测量合并）。编码轨道的"预算-基因型"双层结构对应嵌套码的"生成元预算-码字基因型"结构——该对应为结构类比（探索性，非定理）。

**观察 10.27.2.01（探索性）**：最优小码的物理比特数与几何结构常数存在巧合：五比特码 [[5,1,3]]（ΔΘ = 5，复结构涌现 #90 的常数）、Steane 码 [[7,1,3]]（七层截断 #93 的 7）、Shor 码 [[9,1,3]]（9 素三分解标架 e₁..e₉）。n ∈ {5, 7, 9} 均为几何论结构常数。该观察仅为研讨会级猜想，需独立验证，不构成本文章的定理。

## §4 稳定子判据的几何框架

### 4.1 读数方向与稳定子

10.13 定义 4.2 给出读数方向测量：方向 a 上的测量结果 m(a) = sgn(∫Ψ Z_a dμ) ∈ {±1}，其中 Z_a(x) = a·x 为 zonal 函数。在命题 10.27.1.01(iii) 的 Pauli 代数语言中，固定方向测量对应 Z 算符的本征值符号（±1），X 算符对应 S¹ 上反射轴 φ = π/4 的反射（定理 10.27.1.03(iii)）；对径映射 T = -id 仅给出全局相位（约定 A：反直径反相的测量符号由 T = -I 体现）。

**定义 10.27.3.01（几何稳定子）**：设 n 个物理比特（n 个几何最大纠缠对），几何稳定子生成元为读数方向约束的乘积算符 s_j = ⊗_i Z_{a_{j,i}}（或含对径翻转因子 X_i），要求 s_j² = I 且生成元两两对易（阿贝尔条件）。码空间 C = {|ψ⟩ : s_j|ψ⟩ = |ψ⟩, ∀j}。若生成元数 m，则 k = n - m（dim C = 2ᵏ）。

**注 10.27.3.01（物理映射约定）**：Pauli 测量（X/Y/Z 的本征值符号）到读数方向的对应属于物理映射层约定（10.13 物理映射注记同类），不提交主库；纯几何部分为：Cl(3)⁰ 复化的算符代数结构（命题 10.27.1.01）与 ±1 符号测量（10.13 定义 4.2）。

### 4.2 错误与刚度分离

**定义 10.27.3.02（错误权重与码距）**：错误算符为作用在 ≤ t 个物理比特上的局域扰动（单比特错误 ∈ {X, Y, Z} 几何实现）。错误 E 的权重 w(E) = 受扰动的比特数。码距 d = min{w(E) : ∃ 码字 |ψ₁⟩, |ψ₂⟩ ∈ C，⟨ψ₁|E|ψ₂⟩ ≠ 0}。可纠错数 t = ⌊(d-1)/2⌋。

**定理 10.27.1.04（快慢模对齐的否定）**：二能级空间 H 的两个分支 ε₁, ε₂（定理 10.27.1.03(i)）均为 ℳ-扇区慢模：二者同属 S³ 上 ℓ=1 本征空间，能量 3λ₁^eff/2 < 2λ₁^eff（定理 10.13.3.01），处于低能截断窗内。快模（λ₂^eff = 59324.3 rad⁻²）位于 ℐ-扇区：由时间纠缠判据（#290），ξ = θ_I - θ_I⁰ 为 Dirac 谱方向即快模（#294 步骤4）。故：

(i) H 与快模方向不相交——二能级基 {ε₁, ε₂} 内不存在快慢分裂，旧设定 10.27.3.03（ε₁ = 慢、ε₂ = 快）不成立，予以撤销；

(ii) 刚度分离的几何结构为：码字空间 ⊂ H⊗ⁿ（ℳ-扇区慢模，能量 ≤ 2λ₁^eff 窗）与错误源（ℐ-扇区相位通道扰动，快模 λ₂^eff 尺度）之间的分离——刚度比 κ = λ₂^eff/λ₁^eff ≈ 151.7 是错误源对码字的扰动压制比，其机制为 ℐ-扇区冻结（10.13 定义 2.2 条件 1：λ₂^eff 高刚度使 ξ 方向偏离被强力压制）；

(iii) 码内错误（Pauli X, Z 反射，定理 10.27.1.03(iii)，作用在 H 内）不产生 λ₂ 尺度的能量激发，其一阶正交性不由能量分离给出，而由稳定子代数判据（定理 10.27.3.04）的 syndrome 正交性给出。

证明：(i) 定理 10.13.3.01：H 由 ℳ-扇区 S³ 的 ℓ=1 模式经秩-2 投影得到（本征值 3λ₁^eff/2，λ₁ 尺度）；#294 步骤4：快模沿 ξ = θ_I 方向（ℐ-扇区）。H ⊂ L²(S³)（ℳ-扇区函数空间）与 T_odd（参数空间 θ_I 方向）无交集。(ii) 10.13 定义 2.2 条件 1 与 §2.1（ℐ 扇区仅作信息相位通道）：码字（信息）驻留 ℳ-扇区慢模，环境扰动（错误源）经 ℐ-扇区相位通道注入——λ₂ 高刚度冻结该通道（ξ_A = ξ_B 稳定条件）。(iii) 定理 10.27.3.04：X_i 与稳定子 s_j 反交换 ⟹ X_i|ψ⟩ 处于 s_j 的 -1 本征空间，与 C（+1 本征空间）正交。∎

**注 10.27.3.03（ℓ=2 与呼吸模的数值吻合）**：4λ₁^eff = 1564.2 rad⁻² 与呼吸模本征值 ω_B² = 1564 rad⁻²（7.13 §2.1）在 0.013% 内吻合——S³ 的 ℓ=2 本征值（4λ₁^eff = 4×391.05）与 J_σ 偶平面第二本征值几乎相等。该吻合可能是巧合，也可能是 ℳ-扇区曲率与 θ_M-θ_C 平面谱结构的深层对应；列为开放问题 O7。

**定理 10.27.3.04（几何 Knill-Laflamme 判据）**：设 S = ⟨s₁,...,s_m⟩ 为几何稳定子（定义 10.27.3.01，s_j = ⊗_i P_{j,i}，P_{j,i} ∈ {I, X, Y, Z}），码 C(S)，错误集 E = {E_a}（权重 ≤ t）。则 C(S) 可纠 E 当且仅当对任意 E_a ≠ E_b ∈ E：E_a†E_b ∈ S，或 E_a†E_b 与某生成元 s_j 反交换；其中反交换按比特判定：E_a†E_b 与 s_j 在比特 i 上的方向因子 P_i, Q_i ∈ {X, Y, Z} 且 P_i ≠ Q_i 的比特数为奇数。

证明：
步骤1（标准判据）：稳定子码 C(S) 可纠错误集 E ⟺ 对任意 E_a ≠ E_b：E_a†E_b ∉ N(S) \ S，其中 N(S) 为 S 在 Pauli 群中的正规化子（Knill-Laflamme 条件的稳定子形式，标准量子纠错理论）。
步骤2（正规化子与生成元）：g ∈ N(S) ⟺ g 与每个生成元 s_j 交换（生成元的乘积与 g 的交换性逐因子传递）；故 g ∉ N(S) ⟺ 存在 j 使 g 与 s_j 反交换。
步骤3（反交换的比特判定）：对 Pauli 串 P = ⊗P_i, Q = ⊗Q_i，PQ = (-1)^N QP，其中 N = #{i : P_i, Q_i ∈ {X, Y, Z} 且 P_i ≠ Q_i}。单比特事实：X² = Z² = I、XZ = -ZX（命题 10.27.1.01(iii)），Y = iXZ（命题 10.27.1.01(ii)）推出 {X,Y} = {X,Z} = {Y,Z} = 0；I 与一切对易。反交换因子按比特累乘。
步骤4：合并步骤1-3：可纠 ⟺ ∀a≠b：E_a†E_b ∈ S 或 ∃j：N(E_a†E_b, s_j) 为奇数。∎

**命题 10.27.3.05（稳定子正交性与码距判据）**：设 C 为几何稳定子码（定义 10.27.3.01），s_j 为生成元。
(i)（syndrome 正交性）若错误 E 与某生成元 s_j 反交换，则对任意码字 |ψ⟩, |φ⟩ ∈ C：⟨φ|E|ψ⟩ = 0。即：E C ⊥ C——一阶 Knill-Laflamme 正交性由稳定子代数给出，不依赖能量分离（定理 10.27.3.04 的几何配对）。
(ii)（错误源分离）码字能量窗上界为 2λ₁^eff（定理 10.13.3.01 的低能截断），错误源能标为 λ₂^eff（ℐ-扇区快模，定理 10.27.1.04(ii)）——分离比 λ₂^eff/(2λ₁^eff) ≈ 75.9。ℐ-扇区冻结（10.13 定义 2.2 条件 1）是该分离的动力学机制。
(iii)（码距判定）码距 d = min{w(E) : E ∈ N(S) \ S}——不可检测的非平凡错误的最小权重（与所有生成元交换但不在 S 中）；可检测错误（与某生成元反交换）由 syndrome 测量识别（(i)），不进入码距。

证明：(i) E 与 s_j 反交换：s_j E|ψ⟩ = -E s_j|ψ⟩ = -E|ψ⟩（码字为 s_j 的 +1 本征态）——E|ψ⟩ 处于 s_j 的 -1 本征空间；|φ⟩ ∈ C 处于 +1 本征空间；不同本征空间正交。(ii) 定理 10.13.3.01（截断 2λ₁^eff）与定理 10.27.1.04(ii)。(iii) 定义 10.27.3.02 与定理 10.27.3.04 合并：⟨ψ₁|E|ψ₂⟩ ≠ 0 的最小权重非平凡错误即 N(S) \ S 的最小权重元素。∎

**注 10.27.3.02（刚度比的物理层推论）**：命题 10.27.3.05(ii) 给出错误源（ℐ-扇区快模 λ₂^eff）与码字能窗（≤ 2λ₁^eff）的分离比 ≈ 75.9（刚度比 κ = λ₂^eff/λ₁^eff ≈ 151.7 的一半）。在物理映射层（热库耦合约定下），错误注入率 ∝ exp(-βλ₂^eff) 而码字内部动力学 ∝ λ₁^eff 尺度——刚度比是几何论固有的错误抑制因子：快模冻结（ℐ-扇区冻结，10.13 定义 2.2 条件 1）把环境扰动压制在码字能窗之外。该推论属于物理映射层，不提交主库。

### 4.3 量子码参数界的几何表述（纲领）

标准理论中量子 Singleton 界 n - k ≥ 2(d-1) 与量子 Hamming 界 Σ_{j=0}^{t} 3^j C(n,j) ≤ 2^{n-k} 约束码参数。本框架的目标是给出这些界的几何推导：码距 d 与纠缠弦结构（10.13 定义 2.2：ℐ-扇区冻结 + ℳ-扇区反直径锁定，弦长 L = πR_ℳ）的关系、码长 n 与七层截断（#93）的约束。此为该课题的定理层工作，本文不展开。

## §5 开放问题

- **O1**：H（L²(S³) 上的 2 维谱对象）与 T_even（切空间上的 2 维代数对象，#294）是否经编码映射同构？若是，则二能级定理与奇偶配对定理统一为同一 2 维结构的两个投影。
- **O2**（解决）：几何 Knill-Laflamme 判据（定理 10.27.3.04）给出可纠错的代数判据（反交换 ⟺ 方向因子相异比特数为奇数）；一阶正交性由 syndrome 正交性给出（命题 10.27.3.05(i)）。代数判据不区分码型，混合码情形已含于定理 10.27.3.04。
- **O6**（解决）：定理 10.27.1.04 否定对齐标架假设——二能级基两分支同为慢模（ℳ-扇区 ℓ=1，能量 3λ₁^eff/2），快模位于 ℐ-扇区（θ_I 方向）；刚度分离修正为"码字能窗（≤ 2λ₁^eff）vs 错误源（λ₂^eff）"（分离比 ≈ 75.9），一阶正交性改由 syndrome 代数给出（命题 10.27.3.05(i)）。
- **O7**（部分解决）：数值吻合确认（ω_B²/λ₁^eff = 3.9995，偏差 0.013%）；预言不变性已证（命题 10.27.3.07(ii)：测度比公式在 ω_B² = 4λ₁^eff 下简化为 √λ₂^eff/(2λ₁^eff)，7.13 全部数值预言不变）；结构假说已提出——若 J_σ 的 θ_M-θ_C 块呈对称形式 (λ₁^eff/2)·[[ΔΘ, Λ], [Λ, ΔΘ]]，则 4 倍刚度比精确成立（引理 10.27.3.06）。
- **O7a**：J_σ 的 θ_M-θ_C 块对称性的第一性验证——需要 7.8/3.12 系列的原始谱分解中 J_σ 的显式矩阵元；若块不对称（σ*_M ≠ σ*_C 修正），4 倍关系为拟合巧合（在 ±3% 精度内无法排除）。
- **O3**：n 体联合信息场的构造——10.13 仅处理两体（一个纠缠对），n 个纠缠对的联合低能激发空间需要新的构造（张量积 ⊗ᵢHᵢ 与谱约束的相容性）。
- **O4**：七层截断对码长的约束——若像素自由度 n_eff ≤ 7（#93），单链码长是否有几何上界？
- **O5**：观察 10.27.2.01 的检验——n ∈ {5, 7, 9} 与结构常数的对应是巧合还是必然，需构造性验证。
