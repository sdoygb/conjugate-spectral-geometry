## §1 引言：从并列探针到探针复形

10.77 交付了 19 枚探针的并列全景。但探针之间不是无关的：⑯（两态 Markov）是⑰（风险排名）的前提，⑲（结构诊断）与⑳（饱和期）是同一全局状态的两个精度层次，㉔（传播序列）与㉕（长周期监测）共享 λ₂/BR 双指标框架，⑭（语言距离）是⑨（语言家族）的成对化。这些关系在 10.77 中散见于"→探针"注记与 §23 的对应表，**没有作为一个结构被陈述**。

本文回答元层问题：探针家族能否组织成一个可计算、可推导的几何结构？答案是肯定的——把探针作为单纯形的顶点、探针间关系作为边、互锁环作为面，探针网成为**单纯复形**，其谱与同调给出全网的结构不变量：

- **谱间隙** = 探针网的刚性（10.75 的刚性概念从数据层提升到预言层）；
- **Betti 数** = 预言一致性的约束结构（环 = 一致性约束，空洞 = 理论盲区）；
- **覆盖度** = 定理-探针二部结构，暴露预言层的冗余不足。

边集不是事后拼凑的：全部 25 条语义边都能从 10.77 §22/§23/§24 的既有推导中逐条定位（§4 给出每条边的出处）。这是"理论的价值在于预言"在元层的贯彻——探针之间的关系本身是可推导的，而非人工连线。

## §2 三维地址：探针的规范坐标

**定义 10.81.2.01（探针三维地址）**：每枚探针 p 有一个规范坐标 (s, t, o)：

| 轴 | 取值 | 含义 |
|---|---|---|
| 尺度 s | μ（微观：个体随机点）/ m（中观：集体量）/ M（宏观：全局图） | 数据粒度，对应 10.75 三尺度 |
| 状态 t | R（刚性检验，中性）/ B（破缺侧）/ G（补缺侧）/ BG（双侧） | 两态模型中的位置 |
| 对偶 o | S（结构侧：谱/刚性/纤维化）/ W（实现侧：事件/统计） | 10.80 谱-波型共轭的投影侧 |

坐标的判定规则（非人工标注）：
- s 由"随机点是谁"判定：受访者/国家个体 = μ；国家/区域均值 = m；全球图/76 年序列 = M；
- t 由探针的判别对象判定：检验锁是否存在 = R；预言破缺 = B；预言补缺/修复 = G；两者同判 = BG；
- o 由探针的观测通道判定：谱量（λ₂、BR、std 标度律、η² 的谱读法）= S；事件/统计量（冲突、满意度均值、贸易份额）= W。

**命题 10.81.2.02（坐标唯一性）**：21 枚实探针在三维格点上无重合（§3 表逐行可查）。编号空洞 ①②⑫⑬ 的坐标空缺位置见 §8.2。

**注**：⑲ 同时落在 B 与 G（破缺热点诊断 + 补缺窗口诊断），⑳ 同时落在 B 与 G（破缺过峰 + 补缺弱化）——这不是分类歧义，而是**互锁的签名**：同一结构预言的两个面（§4.2 边型 I 的定义依据）。

## §4 四类边：依赖 / 互锁 / 对偶 / 数据共享

**定义 10.81.4.01（四类边）**：探针 p, q 之间四类可推导关系：

- **依赖边 D**（有向，无向化进图）：p 的判别规则/机制前提引用 q 的结论。判据：10.77 正文存在"→探针"或"←探针"的显式机制迁移注记。
- **互锁边 I**（无向）：p 与 q 是同一结构预言的两个面，互相构成判别条件。判据：10.77 中两枚探针共享同一预言对象且互为检验（如 10.77.15.03 明示"与探针⑰…互补：同一区域既是最可能的破缺点，也是最可能的补缺点"）。
- **对偶边 C**（无向）：p 与 q 是同一理论结构的谱侧/实现侧投影。判据：10.80 谱-波型共轭在探针层的一一对应。
- **数据共享边 S**（无向）：p 与 q 使用同一数据源。判据：§3 盘点表的数据源列相同。

**命题 10.81.4.02（边集与出处）**：D=20 条、I=7 条、C=5 条、S=40 条，语义边（D∪I∪C 去重）=25 条。逐条出处：

## §5 邻接谱：各子图的谱不变量

**命题 10.81.5.02（谱的读法）**：

1. **语义谱间隙 Δ=1.4287 = 探针网的刚性**：10.75 的刚性概念从数据层（谱间隙 std 平坦）提升到预言层——探针网整体是一个"锁定的结构"，其连通性由一个主特征值（λ_max=3.717）统摄。语义 Δ 高于任一子图（除全图），说明跨类别的边（D 与 I/C 的耦合）使网络更"紧"。
2. **互锁子图 Δ_I=1.3602 独立于其他边而保持大间隙**：I 边自身构成刚性骨架——这是 §9 元层定理的前提数值。
3. **对偶子图 Δ=0**：C 边是 5 条两两不相交的独立边（每边是 K₂ 分量，特征值 ±1 成对），非零特征值 10 个、λ_max=1——对偶关系是"分散的镜像对"，不构成连通骨架。这符合 C 边的定义：共轭投影不必共边。
4. **全图谱间隙 3.34 最大，但这是数据冗余的贡献**（S 边把 WVS 团连成团簇）——谱意义上 S 边"加固"网络，但这种加固是统计相关性而非预言约束，§6 的同调分析将其排除。

2. **β₁=2**：语义复形有 2 个独立的一致性命循环——{⑲⑳㉔} 环（补缺压力→传播窗口→区域诊断）与 {⑰⑲⑳} 环（破缺预言→诊断→饱和期）经由 ⑲ 耦合。这两个环是"预言一致性约束"的代数实现：任何一条预言窗口的修订都会沿环传播。

## §8 三个结构发现

### 8.1 发现一：互锁骨架无矛盾，时序一致可判定

互锁复形 Δ_I=1.3602>0 且 β₁(I)=0（唯一环被填平），当前 7 条互锁边的时序指派无矛盾：

⑰⑲（2031-08-23 关闭，10.77.10.08/09）→ ⑳（补缺压力 2029–2035，10.77.16.04/10.77.10.12）→ ㉔（传播窗口 2034–2038，10.77.10.10）→ ㉕（BR 回落监测，10.77.10.12）

链上每一环的窗口与下一环衔接（2031 关闭 → 2029–2035 压力 → 2034–2038 传播 → 监测），构成一条无环链。**互锁环 {⑲⑳㉔} 被填成面意味着"区域诊断-饱和期-传播序列"三者构成一个一致的三元组**：⑲ 的区域窗口（东亚东南亚）是⑳ 的饱和期（全口径）的区域投影，㉔ 的传播序列是⑳ 的补缺压力的结构实现。

### 8.2 发现二：空洞是坐标空缺，且坐标自己指向探针候选

β₂=0 说明单纯复形意义上无拓扑空洞；但编号空洞 ①②⑫⑬ 的坐标位置暴露了四枚"该造而未造"的探针：

| 空洞 | 坐标 | 对应内容 | 依据 |
|---|---|---|---|
| ① | (μ·时间, R, S) | 时间尺度探针：累积量衰减 vs λ₁^eff=391.05 | 10.75 §6 第二探针，未实现为独立脚本 |
| ② | (M·群交叉, R, S) | 群尺度-大范围交叉：negacyclic d→∞ 零方差 + 结构指纹 ρ=‖b₁‖/GH | 10.75 §6 第三探针；开放问题 0.9.6.03 |
| ⑫ | (μ·成对, R, S) | 贸易成对通道（最强连续耦合 ρ=−0.171, p=0.0005） | 现仅以"⑩′"扩展存在，无独立圈号（10.77.10.01） |
| ⑬ | (μ·成对, R, S) | 移民网络（UN DESA）：第四独立耦合通道 | 10.77.10.01 开放问题 |

**关键点**：⑫⑬ 的坐标恰好落在排除链（⑨⑭⑩）与战争簇（⑮）之间——10.77 §10 之后、§11 之前的编号空隙，正是 10.77.10.01 开放问题（成对耦合通道序列：地理→语言→**贸易→移民**）的位置。**复形通过编号空隙自己指出该造探针的地方**，而不是靠人凭感觉补探针。①② 的空缺则暴露物理/数值侧的探针（10.75 §6 最早设计的第二、第三探针）从未进入圈号体系。

### 8.3 发现三：半孤立对 ⑩⑭ 与边集的完整性自检

⑩（CEPII 地理）曾是网络的边缘节点——它只有数据共享边的连接不足以进语义图，是 ⑭↔⑩ 的对偶边（两个独立耦合通道的共轭投影）把它救成"对"。严格计算显示这对探针形成第 3 个连通分量（β₀=3），仍是全网最弱连接。**这类"悬挂部件"是复形监督自身边定义完整性的信号**：若某探针只靠 S 边连网，要么它确实信息孤立（数据冗余但预言独立），要么边集漏了一条语义边。当前 ⑩⑭ 有 C 边与 D 边（⑩→⑭ 方法迁移），语义连接成立但分量独立——这是诚实的结构现状，不是缺陷。

## §9 元层定理猜想：探针网刚性

**猜想 10.81.9.01（探针网刚性）**：设探针复形的互锁图（仅 I 边）谱间隙 Δ_I。则 Δ_I>0 当且仅当互锁环上存在全局一致的时序指派（每枚预言探针的窗口可在同一时间轴上无矛盾地排列）。

**当前数值状态**：Δ_I=1.3602>0（命题 10.81.5.01）且 β₁(I)=0（唯一互锁环被填平，命题 10.81.6.02）——前提成立，时序指派显式给出（§8.1 的链）。

**论证要点**（局部推导，非定理证明）：
1. 互锁图的连通性（β₀(I)=1 有效分量）保证所有互锁预言属于同一约束系统；
2. 谱间隙 Δ_I>0 是图连通性与非二分性的综合度量（Fiedler 意义下：Δ_I>0 ⟺ 图连通；Δ_I>0 且 λ_min≠−λ_max ⟺ 非二分无符号振荡）；
3. 若互锁图含奇数符号环（时序矛盾环），λ_min=−λ_max（二分性）或出现零模（退化），Δ_I 塌缩或出现谱对称——当前 λ_min 与 λ_max 无对称性（非零特征值 6 个、无 ±λ_max 配对），与无矛盾一致；
4. 反方向：若时序一致，互锁边构成无矛盾约束系统，其谱无对称退化。

**性质**：A0 类（局部代数命题，谱论/图论，无物理量纲）——可作为候选提交主库验证。提交前需把"时序指派"形式化为图着色/区间调度问题，并检验猜想在构造反例（人为制造矛盾窗口）下是否成立。
