## §1 引言：从并列探针到探针复形

10.77 交付了 19 枚探针的并列全景。但探针之间不是无关的：⑯（两态 Markov）是⑰（风险排名）的前提，⑲（结构诊断）与⑳（饱和期）是同一全局状态的两个精度层次，㉔（传播序列）与㉕（长周期监测）共享 λ₂/BR 双指标框架，⑭（语言距离）是⑨（语言家族）的成对化。这些关系在 10.77 中散见于"→探针"注记与 §23 的对应表，**没有作为一个结构被陈述**。

本文回答元层问题：探针家族能否组织成一个可计算、可推导的几何结构？答案是肯定的——把探针作为单纯形的顶点、探针间关系作为边、互锁环作为面，探针网成为**单纯复形**，其谱与同调给出全网的结构不变量：

- **谱间隙** = 探针网的刚性（10.75 的刚性概念从数据层提升到预言层）；
- **Betti 数** = 预言一致性的约束结构（环 = 一致性约束，空洞 = 理论盲区）；
- **覆盖度** = 定理-探针二部结构，暴露预言层的冗余不足。

边集不是事后拼凑的：全部 25 条语义边都能从 10.77 §22/§23/§24 的既有推导中逐条定位（§4 给出每条边的出处）。这是"理论的价值在于预言"在元层的贯彻——探针之间的关系本身是可推导的，而非人工连线。

## §2 三维地址：探针的规范坐标

**定义 10.81.2.01（探针三维地址）**：每枚探针 p 有一个规范坐标 (s, t, o)：

| 轴 | 取值 | 含义 |
|---|---|---|
| 尺度 s | μ（微观：个体随机点）/ m（中观：集体量）/ M（宏观：全局图） | 数据粒度，对应 10.75 三尺度 |
| 状态 t | R（刚性检验，中性）/ B（破缺侧）/ G（补缺侧）/ BG（双侧） | 两态模型中的位置 |
| 对偶 o | S（结构侧：谱/刚性/纤维化）/ W（实现侧：事件/统计） | 10.80 谱-波型共轭的投影侧 |

坐标的判定规则（非人工标注）：
- s 由"随机点是谁"判定：受访者/国家个体 = μ；国家/区域均值 = m；全球图/76 年序列 = M；
- t 由探针的判别对象判定：检验锁是否存在 = R；预言破缺 = B；预言补缺/修复 = G；两者同判 = BG；
- o 由探针的观测通道判定：谱量（λ₂、BR、std 标度律、η² 的谱读法）= S；事件/统计量（冲突、满意度均值、贸易份额）= W。

**命题 10.81.2.02（坐标唯一性）**：21 枚实探针在三维格点上无重合（§3 表逐行可查）。编号空洞 ①②⑫⑬ 的坐标空缺位置见 §8.2。

**注**：⑲ 同时落在 B 与 G（破缺热点诊断 + 补缺窗口诊断），⑳ 同时落在 B 与 G（破缺过峰 + 补缺弱化）——这不是分类歧义，而是**互锁的签名**：同一结构预言的两个面（§4.2 边型 I 的定义依据）。

## §4 四类边：依赖 / 互锁 / 对偶 / 数据共享

**定义 10.81.4.01（四类边）**：探针 p, q 之间四类可推导关系：

- **依赖边 D**（有向，无向化进图）：p 的判别规则/机制前提引用 q 的结论。判据：10.77 正文存在"→探针"或"←探针"的显式机制迁移注记。
- **互锁边 I**（无向）：p 与 q 是同一结构预言的两个面，互相构成判别条件。判据：10.77 中两枚探针共享同一预言对象且互为检验（如 10.77.15.03 明示"与探针⑰…互补：同一区域既是最可能的破缺点，也是最可能的补缺点"）。
- **对偶边 C**（无向）：p 与 q 是同一理论结构的谱侧/实现侧投影。判据：10.80 谱-波型共轭在探针层的一一对应。
- **数据共享边 S**（无向）：p 与 q 使用同一数据源。判据：§3 盘点表的数据源列相同。

**命题 10.81.4.02（边集与出处）**：D=20 条、I=7 条、C=5 条、S=40 条，语义边（D∪I∪C 去重）=25 条。逐条出处：

**D（20 条）**：③→⑤、③→⑥（判别规则迁移，10.77 §2.2）；④→⑮、④→⑲、④→㉑、④→㉒（破缺判别，§22 行 9/12/14）；④→⑱、④→㉓（T3 假刚性→补缺谱论/外部场，§22 行 6/15，§23 行 6/15）；⑥→⑦、⑥→⑧、⑥→⑨（残差化方法迁移，§4 结论"→探针⑦⑧⑨"）；⑥→⑪（时间版，§9）；⑩→⑭（成对 Mantel 方法迁移，§10，10.77.10.01）；⑯→⑰、⑯→⑲、⑯→⑳（两态 Markov 前提，§22 行 11/12/13）；⑲→⑳（⑳=⑲ 的全口径高精度扩展，§16）；⑳→㉔（饱和期补缺压力窗口为传播时序前提）；㉓→㉔（外部场谱框架→传播模拟，§20）；㉔→㉕（λ₂/BR 双指标→76 年回溯，§21）。
