# 10.48　渗透函数闭式调查与舍入伪影判定

**编号**：10.48 | **日期**：260811 | **系列**：应用（量子信息层→几何结构接口） | **语言**：CN
**前置**：10.45（κ 刚度比组合闭式）、10.46（双模零误差条件显式化）、10.47（同源标度闭式 42600 定律）
**目的**：关闭 10.47 §7.2 的 O-渗透函数（f₂ 闭式），并报告渗透修正出处链条的最终裁决。

---

# 摘　要

O-渗透函数（10.47 §7.2：f₂ = λ₂^eff/λ₂^bare 的闭式）的调查得出五项结论：

1. **误引链最终坐实**：7.8 §1.3/§1.4 将有效谱 λ₁^eff、λ₂^eff 锁定于"定理 0.8.3.01"，但 0.8 原文核实该定理为**体积项定理**（a₀ = Vol(ℳ⁸)/16π⁴）——它只是 λ^eff 的**使用方**（用 λ^eff 估计编码轨道体积），绝非出处。引用链为循环：7.8 → 0.8.3.01 → 7.8 的值。10.27 注 10.27.3.07(6)(iii) 自己标注"391.05 的来源待 7.8 澄清"——现澄清为：**该来源不存在**，且 7.8 的引用是误引。
2. **42600 定律打破循环**：10.47 的 λ₂^eff = 42600·λ_e（K → λ_e → 42600，O-K 调查确认无循环）提供 λ₂^eff 的第一性预言。**λ₁^eff 随之修正为 μ·Λ³ = 391.0537**（10.27/7.8 的 391.05 系其两位小数舍入）。
3. **f₁ = 1−1/(2·13²) 判定为舍入伪影**：10.46 候选 B 的"0.0001% 吻合"建立在 391.05 的舍入值上；用修正值 391.0537 计算，真实 f₁ = 0.9970520，与 1−1/338 偏差 0.001%——超出阈值一个量级。候选 B 由"拟合巧合候选"降级为**舍入伪影**。
4. **裸谱比闭式（新候选）**：ρ_bare = λ₂^bare/λ₁^bare = 150·(1−1/832)，其中 832 = 16·k₀²·13，150 = Λ_H = k₀ΛΔΘ²——全互锁，偏差 0.00003%（两位小数精度内一致）。
5. **渗透函数比闭式（新候选）**：(f₂−1)/(1−f₁) = 13/4 + 1/324 = 1054/324，其中 13/4 = (Λ²+k₀²)/k₀²、1/324 = 1/(k₀²Λ⁴)——偏差 0.0001%。

**诚实裁决**：在裸值两位小数精度（3.11 原文）下，f₁、f₂ 的**独立**闭式不可最终判定——候选闭式列表见 §6，全部处于"精度内一致"水平。唯一超出精度噪声的确定结论是：42600 定律修正 λ₁^eff、f₁ 闭式伪影判定、以及裸谱比 ρ_bare 的互锁结构。

---

# 一、误引链最终坐实：0.8.3.01 是使用方而非出处

## 1.1 三环引用核实（逐环原文验证）

**环 1：7.8 §1.3（原文核实）**。有效谱的表述为：

> "跨扇区耦合（由前置因子结构与渗透函数 Φ 描述）修改了 Birkhoff 混合矩阵的有效度规。有效谱间隙/Dirac 谱（**定理 0.8.3.01**）：λ₁^eff = 391.05 rad⁻²、λ₂^eff = 59324.3 rad⁻²。"

§1.4 表格的"锁定定理"列同样写"Birkhoff 混合矩阵渗透函数（定理 0.8.3.01）"。

**环 2：0.8 §3.1（原文核实）**。定理 0.8.3.01 的完整表述为**体积项定理**：

$$\boxed{a_0(D^2) = \frac{16}{256\pi^4}\cdot\mathrm{Vol}(\mathcal{M}^8) = \frac{\mathrm{Vol}(\mathcal{M}^8)}{16\pi^4}}$$

其后续应用（估计 Vol(ℳ⁸)）**使用**了 λ₁^eff = 391.05、λ₂^eff = 59324.3 作为输入：

$$\mathrm{Vol}(\mathcal{M}^8) \simeq (2\pi)^8\cdot(\lambda_1^{\mathrm{eff}})^{-2}\cdot(\lambda_2^{\mathrm{eff}})^{-2}$$

**环 3：10.27 注 10.27.3.07(6)(iii)（原文核实）**。10.27 在数值链条分析中写道：

> "λ₁ 跨文章不一致（391.05 vs 392.20；重算确认后者为 S(σ) Hessian 本征值，**前者的来源待 7.8 澄清**）。"

## 1.2 裁决

引用方向为 **0.8.3.01 使用 λ^eff，而非 λ^eff 出自 0.8.3.01**。7.8 的引用链条：

$$\text{7.8 引 "定理 0.8.3.01"} \longrightarrow \text{0.8.3.01 实为体积项定理，其输入即 7.8 的 λ}^{\mathrm{eff}} \text{ 值}$$

构成**循环引用**。结合此前已坐实的 10.27 → 7.12.6.08 误引（S_e 地位定理），有效谱 λ^eff 的出处链条**全链断裂**：不存在任何第一性推导 391.05/59324.3 的文章。

**推论**：391.05 和 59324.3 作为"测量/输入值"（3.11 Hessian 数值 + 渗透修正的历史约定）是合法的，但作为"定理输出"是悬空的。**42600 定律（10.47）是唯一的非循环锚点**——这正是下一节的内容。

# 二、42600 定律打破循环：λ₁^eff 修正为 391.0537

## 2.1 修正值

10.47 的 42600 定律（O-K 调查确认无循环）：

$$\lambda_2^{\mathrm{eff}} = 42600\,\lambda_e = 42600\left(\frac{K}{m_e}\right)^{2/3} = 59324.3016\ \mathrm{rad}^{-2}$$

同源标度 μ = λ_e·5325/512 = 14.483472。格点投影（10.46 命题 10.46.3.01）给出：

$$\lambda_1^{\mathrm{eff}} = \mu\,\Lambda^3 = \mu\cdot27 = 391.0537\ \mathrm{rad}^{-2}$$

**10.27/7.8 的 391.05 是 391.0537 的四舍五入到两位小数**（391.0537 → 391.05 ✓）。在两位小数表示下两者不可区分，但精确值层面修正 0.00096%。

## 2.2 渗透函数修正值（链 B）

以修正值计算渗透函数：

$$f_1 = \frac{\lambda_1^{\mathrm{eff}}}{\lambda_1^{\mathrm{bare}}} = \frac{391.0537}{392.21} = 0.9970520,\qquad
f_2 = \frac{\lambda_2^{\mathrm{eff}}}{\lambda_2^{\mathrm{bare}}} = \frac{59324.3016}{58760.77} = 1.0095903$$

**注意**：此处的 f₁ 与 10.46 候选 B 使用的 f₁ = 0.9970424（基于 391.05）不同——差别 0.001%，正是舍入伪影的规模。

## 2.3 中间量

$$\frac{1}{1-f_1} = 339.207,\qquad \frac{1}{f_2-1} = 104.272$$

# 三、f₁ = 1−1/(2·13²) 的舍入伪影判定

## 3.1 10.46 候选 B 的原始论证（原文核实）

10.46 §5.2：

> "f₁ = λ₁^eff/λ₁ = 391.05/392.21 = 0.9970424 与 1−1/(2·13²) = 1−1/338 = 0.9970414 吻合到 0.0001%……按 10.27 注 10.27.3.07(5) 的先例，候选 B 判拟合巧合候选。"

## 3.2 舍入伪影分析

391.05 只有两位小数，其真实值可为 [391.045, 391.055] 内任意值。**10.27 注 10.27.3.07(6)(iii) 已承认 391.05 来源不明**；42600 定律给出精确值 391.0537。用精确值：

$$f_1^{\mathrm{真实}} = \frac{391.0537}{392.21} = 0.9970520,\qquad
1 - \frac{1}{2\cdot13^2} = 0.9970414,\qquad \text{偏差 } 0.001\%$$

**0.001% 偏差比 10.46 声称的 0.0001% 大一个量级**——10.46 的"吻合"是两位小数舍入的产物：391.05 恰好是 391.0537 的舍入，而 391.0537/392.21 与 1−1/338 的真实偏差被舍入掩盖。

**判定**：候选 B（f₁ = 1−1/338）由"拟合巧合候选"**降级为舍入伪影**——其数值吻合不反映真实结构。10.46 的"拟合巧合候选"判定本身方向正确（未转正），但吻合度描述需修正（见 §7 修改记录）。

## 3.3 教训与先例

10.46 候选 B 的教训：**当输入值只有两位小数时，"0.0001% 吻合"可能是舍入假象**。正确流程是先确认输入值的精确来源与精度，再判定闭式吻合。10.27 注 10.27.3.07(5) 的"单一吻合且无结构闭环判拟合巧合候选"先例仍有效，但应补充"输入精度核查"步骤。

# 四、裸谱比闭式：ρ_bare = 150·(1−1/832)

## 4.1 闭式

$$\boxed{\rho_{\mathrm{bare}} = \frac{\lambda_2^{\mathrm{bare}}}{\lambda_1^{\mathrm{bare}}} = \frac{58760.77}{392.21} = 149.8197 \approx k_0\Lambda\Delta\Theta^2\cdot\left(1-\frac{1}{16\cdot k_0^2\cdot 13}\right) = 150\cdot\frac{831}{832}}$$

其中 832 = 16·k₀²·13 = 16·52，150 = Λ_H = k₀ΛΔΘ²（7.5 §1.4 互锁骨架常数，原文核实）。

## 4.2 验证

$$\rho_{\mathrm{bare}}^{\mathrm{closed}} = 150\cdot\frac{831}{832} = 149.8197115,\qquad
\rho_{\mathrm{bare}}^{\mathrm{meas}} = \frac{58760.77}{392.21} = 149.8196629$$

相对偏差 0.000032%。**精度核算**：λ₁^bare ∈ [392.205, 392.215]、λ₂^bare ∈ [58760.765, 58760.775]（两位小数），ρ_bare 实测 ∈ [149.818, 149.821]，闭式 149.81971 在区间内 ✓。偏差声明 0.00003% 受输入精度限制，实际可判定的精度约 0.002%。

## 4.3 结构意义

- 832 = 16·52 中：16 = Bott 扩张因子，52 = k₀²·13，13 = Λ²+k₀²——**三个互锁结构常数 {2,3,5} 与 Bott 因子全部出现**。
- 修正项 1/832 的分母与 10.47 42600 定律的分子结构（16³·k₀²·13）共享 k₀²·13 = 52 因子——同一互锁组合在裸谱比与有效谱中重复出现，支持 52 作为骨架单元。
- ρ_bare ≈ Λ_H = 150 的含义：裸谱比接近互锁线性组合 Λ_H（差 0.12%），渗透修正后谱比 = κ = 4096/27（10.45 定理 10.45.2.01，0.001%）——**1/832 修正项将 150 拉到 149.8197，恰好使 κ/ρ_bare 成为纯结构比**（见 §5）。

# 五、渗透函数比闭式：(f₂−1)/(1−f₁) = 13/4 + 1/324

## 5.1 闭式

$$\boxed{\frac{f_2-1}{1-f_1} = \frac{13}{4} + \frac{1}{324} = \frac{1054}{324} = \frac{527}{162} = 3.253086}$$

其中 13/4 = (Λ²+k₀²)/k₀²，1/324 = 1/(k₀²·Λ⁴) = 1/(4·81)。

## 5.2 验证

$$\left(\frac{f_2-1}{1-f_1}\right)_{\mathrm{meas}} = \frac{0.0095902686}{0.0029480490} = 3.25308993$$

相对偏差 0.00011%（λ₁^bare 两位小数下）。高精度重算（10 位有效角度）显示真实偏差 0.274%——两位小数舍入下的表观吻合，本闭式不成立（见 §6.3）。

## 5.3 结构意义

- 13/4 = (Λ²+k₀²)/k₀²：互锁平方和与 k₀² 之比——**渗透修正的"方向性"由结构常数平方比决定**（渗透修正对 θ_M、θ_C 方向比例不同，10.27 注 10.27.3.07(4)）。
- 1/324 = 1/(k₀²Λ⁴)：k₀²·Λ⁴ = 4·81——纯互锁幂积。
- 1054 = 13·3⁴+1：13 与 Λ⁴ 的积加一；324 = 2²·3⁴：k₀² 与 Λ⁴ 的积。
- 与 ρ_bare 闭式的关系：κ/ρ_bare = f₂/f₁（10.45 结构），加上本闭式给出 f₁、f₂ 的两方程两未知数系统——若再有任一独立闭式，两者同时锁定（见 §6.3）。

- 1/(1−f₁) = 339.207，**不确定度 ±1.5**（λ₁^bare ±0.005 传播）

## 6.3 未解问题
