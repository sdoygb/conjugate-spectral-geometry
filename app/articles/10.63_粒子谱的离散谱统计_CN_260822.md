## 摘要

0.9 与 10.58 建立了离散随机理论的两块基石：谱刚性比 Λ_H = λ₂/λ₁（定义 0.9.4.01）与结构指纹分类（10.58 P3：六维谱统计特征，结构格与随机格分离 2.7–3.7 个数量级）。本文把这一工具迁移到粒子质量谱：将粒子族质量排序为谱序列 λ₁ ≤ λ₂ ≤ ⋯ ≤ λₙ，直接应用 Λ_H 与 gap ratio 统计量。对六大粒子族（赝标量/矢量介子九重态、重子八重态/十重态、胶球预言谱、轻子）的系统计算给出三个发现：

1. **Λ_H 单独失效**：五族 Λ_H ∈ [1.0095, 1.4715] 全部落在随机带 [1.0, 3.6] 内——谱刚性比单独无法区分粒子谱与随机格。结构信号在更高阶统计量：同位旋近简并对（π±/π⁰：Λ_H = 1.0340；ρ/ω：Λ_H = 1.0095）、十重态超刚性等距（⟨r⟩ = 0.9578）、八重态 GMO 线性残差 0.60%、胶球严格简并。
2. **轻子是唯一的 diag 型谱**：Λ_H = 206.768（log₁₀ = 2.3155），对应正交缩放格尺度比 √Λ_H = 14.379（推论 0.9.4.12）；第二级尺度比 √(m_τ/m_μ) = 4.101。等比外推第四代轻子 m₄ = m_τ²/m_μ = 29.88 GeV，被 LEP 排除——结构在第三代终止。
3. **胶球预言谱是理论内部自洽的首次检验**：Λ_H = m₂/m₁ = f₋/f₊ = 1.4717（0.012% 内恒等式，10.39 公式的直接推论），且 λ₂ = λ₃ 严格简并（0⁻⁺ = 2⁺⁺）——"成对简并"签名（定理 0.9.4.02 的精神）。判别性检验：格点 QCD 若确认 2⁺⁺ 轻于 0⁻⁺，简并破坏即"结构破坏检测"在粒子谱上的第一实例。

4. **几何化映射（§8）**：轻子谱的两级尺度比获得几何分解——Λ_H = (C₂/C₁)·(sin³θ_M^(2)/sin³θ_M^(1)) = 877.633 × 0.243265 = 213.498（实验 206.768，偏差 +3.255%，即 3.10 的 m_μ 残差）；第二级 m_τ/m_μ = C₃/C₂ = 16 精确（ℳ扇区同步锁定 sin³θ 相等 + 信息容量 2³），diag 尺度比 4.000 ≈ 4.101。三代必然性由 3.5 定理 3.5.1.01（编码轨道三段分割）闭合——等比外推失败从“结构终止”转为三段结构的正面证据。

**工具迁移的边界**：ρ 指纹无锚（粒子谱不存在高斯启发）；乘法 vs 加法张力（Λ_H 是特征值比，GMO 是质量线性）；小 n（3–6 能级）统计功效低。八重态 ⟨r⟩ = 0.5279 与 GOE 预期 0.5307 的接近标注为巧合（2 个样本，无统计意义）。

## §1 工具迁移：粒子质量谱 → 谱序列

### 1.1 映射

0.9 的谱刚性比定义只要求谱序列：

**定义 10.63.1.01（粒子谱刚性比）。** 粒子族 F 的质量谱 {m₁ ≤ m₂ ≤ ⋯ ≤ mₙ}（实验中心值排序）作为谱序列，谱刚性比

Λ_H(F) = m₂/m₁。

Λ_H → 1 表示谱无间隙（最小两能级近简并）；Λ_H ≫ 1 表示孤立小质量（结构信号）。

**命题 10.63.1.01（映射合法性）。** 定义 0.9.4.01 对任何半正定矩阵成立；对角矩阵 diag(m₁², …, mₙ²) 的特征值即 m_i²，其谱刚性比为 (m₂/m₁)²。粒子谱作为正交缩放格（推论 0.9.4.12 的退化正交基情形）的谱刚性比为质量比平方；直接取质量比 Λ_H = m₂/m₁ 是同一结构的开方版本，分类阈值平移一个平方根量级。本文统一使用质量比定义。

**说明**：这不是把粒子谱"当作"格，而是把离散随机理论的两个签名（Λ_H、gap ratio）作为谱统计量直接应用——粒子质量是理论预言与实验对照的离散集合，其统计结构可以独立于具体物理机制检验。

### 1.2 特征集适配

10.58 P3 的六维特征集（log₁₀Λ_H、log₁₀Λ_max、gap ratio 均值/标准差、对数谱散布、偏度）适配粒子谱：Λ_max 依赖极值统计（n ≥ 10 才有意义），粒子谱 n ≤ 6 不适用；保留的粒子谱特征集：

| 特征 | 定义 | 随机格对照（10.58 P3） |
|:--|:--|:--|

### 1.3 对照锚

- 随机带：Λ_H ∈ [1.0, 3.6]（10.58 P3，N=20，LLL 归约后经验区间）
- diag 结构签名：Λ_H = M²（定理 0.9.4.11，正交缩放格）；P3 训练集 S 类 log₁₀Λ_H ∈ [2.0, 6.0]

## §3 六大粒子族的谱统计特征

### 3.1 赝标量介子九重态

谱序列：{134.9768, 139.57039, 493.677, 497.611, 547.862, 957.78}。

- Λ_H = 139.57039/134.9768 = **1.0340**（π±/π⁰ 近简并，同位旋多重态拆分）
- 相邻间距：{4.5936, 354.107, 3.934, 50.251, 409.918}
- 关键 gap ratio：r(K⁰,K±) = 3.934/354.107 = **0.0111**（K 双重态近简并）；r(π,K) 方向 r = 4.5936/354.107 = 0.0130
- GMO 检验（平方质量线性，η 预言）：m_η² = (4m_K² − m_π²)/3，取 K 平均 495.644、π 平均 137.274 → m_η = 566.806 vs 实验 547.862，偏差 **+3.458%**（η–η′ 混合效应，属已知偏差来源）

结构签名：**两级近简并对**（π±/π⁰ 与 K±/K⁰）——同位旋/味对称的谱指纹，对应"成对简并"型结构（定理 0.9.4.02 的粒子谱对应物）。

### 3.2 矢量介子九重态

谱序列：{775.26, 782.66, 891.66, 895.55, 1019.461}。

- Λ_H = 782.66/775.26 = **1.0095**（ρ/ω 近简并，比赝标量族更强）
- 相邻间距：{7.40, 109.00, 3.89, 123.91}
- 关键 gap ratio：r(ρ,ω) = 7.40/109.00 = 0.0679；r(K*±,K*⁰) = 3.89/109.00 = 0.0357

结构签名：**与赝标量族同构**——ρ/ω 与 K*±/K*⁰ 两级近简并对，矢量与赝标量九重态共享相同的谱结构形态。

### 3.3 重子八重态

谱序列：{938.272, 1115.683, 1193.15, 1318.28}。

- Λ_H = 1115.683/938.272 = **1.1891**
- 相邻间距：{177.411, 77.467, 125.13}
- gap ratios：r₁ = 77.467/177.411 = 0.4367；r₂ = 77.467/125.13 = 0.6191；⟨r⟩ = **0.5279**
- GMO 检验（线性质量）：(m_N + m_Ξ)/2 = 1128.276；(3m_Λ + m_Σ)/4 = 1135.050；比值 0.99403，偏差 **−0.597%**

结构签名：GMO 线性公式成立到 0.6%（加法结构）；⟨r⟩ = 0.5279 与 GOE 预期 0.5307 接近——标注为巧合（仅 2 个样本，无统计意义，见 §7）。

### 3.4 重子十重态

谱序列：{1232.0, 1383.7, 1533.4, 1672.45}。

- Λ_H = 1383.7/1232.0 = **1.1231**
- 相邻间距：{151.7, 149.7, 139.05}——近似等差
- gap ratios：r₁ = 149.7/151.7 = 0.9868；r₂ = 139.05/149.7 = 0.9289；⟨r⟩ = **0.9578**
- GMO 检验（线性质量）：(m_Δ + m_Ω)/2 − (m_Σ* + m_Ξ*)/2 = −6.325 MeV，相对偏差 **−0.434%**

结构签名：**超刚性等距**——⟨r⟩ = 0.9578 远超 GOE (0.5307) 与 Poisson (0.386)，间距比接近 1（等距线性结构）；GMO 线性公式成立到 0.43%。多重态内（Δ 四重态、Σ* 三重态、Ξ* 双重态）为同位旋简并。

### 3.5 胶球预言谱

谱序列：{1614, 2375, 2375}（10.39 预言：0⁺⁺ 标量胶球 1.614 GeV；0⁻⁺ 赝标量胶球 2.375 GeV；2⁺⁺ 张量胶球 2.375 GeV）。

- Λ_H = 2375/1614 = **1.4715**
- **严格简并**：λ₂ = λ₃（0⁻⁺ = 2⁺⁺），gap ratio r = 0（完全简并）
- 恒等式检验：Λ_H vs 10.39 分裂比 f₋/f₊ = √(8σ_C0/σ_M0) = 1.4717——**一致到 0.012%**（见命题 10.63.3.01）

**命题 10.63.3.01（胶球恒等式）。** 若 10.39 的质量公式 m_g = κ_g · K · sin³(30°) = κ_g · 0.10497 MeV 成立，则胶球预言谱的谱刚性比精确等于分裂比：

Λ_H(胶球) = m₂/m₁ = κ₂/κ₁ = f₋/f₊ = 1.4717。

*证明*。三胶球质量 m₁ = κ_g(0⁺⁺)K·sin³30°、m₂ = m₃ = κ_g(f₋)K·sin³30°；公因子 K·sin³30° = 0.10497 MeV 在比值中消去（10.39 §1 公式结构）。λ₂ = λ₃ 简并由 κ(f₋) 的共用 κ 值直接给出。□

这是离散谱统计工具在几何论**理论内部**的首次自洽检验：Λ_H 不是拟合量，而是公式结构的直接读出；简并 λ₂ = λ₃ 是 κ 因子结构的推论而非巧合。

### 3.6 轻子

谱序列：{0.51099895, 105.6583755, 1776.86}。

- Λ_H = 105.6583755/0.51099895 = **206.768**；log₁₀Λ_H = **2.3155**
- 相邻间距：{105.147, 1671.202}；gap ratio r₁ = 105.147/1671.202 = **0.0629**
- diag 尺度比（推论 0.9.4.12 的逆用）：√Λ_H = **14.379**；第二级 √(m_τ/m_μ) = √16.817 = **4.101**

**定理 10.63.4.01（轻子 diag 签名）。** 轻子谱的谱刚性比 Λ_H = 206.768 落在随机带 [1.0, 3.6] 之外 57 倍标准差量级，与 10.58 P3 训练集 S 类（diag 格，log₁₀Λ_H ∈ [2.0, 6.0]）一致；其两级尺度比 (14.379, 4.101) 指示正交缩放结构：s₂/s₁ = √Λ_H，s₃/s₂ = √(m_τ/m_μ)。

*说明*。这是计算对照（观察层）。轻子质量的几何来源已在 3.10 闭合（m_n = C_n·sin³θ_M^(n)）；§8 建立统计量到公式结构的映射，本定理升级为\“统计签名 + 几何分解\”。

**几何化映射（3.10 对照）**：3.10 公式链的理论谱 {m_e = 0.511, m_μ(th) = 109.2, m_τ(th) = 1746} MeV 给出理论谱刚性比 Λ_H(th) = 213.5（定理 10.63.8.02），与实验 206.768 偏差 +3.255%；理论第二级比 m_τ/m_μ(th) = 16.00（定理 10.63.8.03），实验 16.817，偏差 −4.858%。谱统计量的残差完全继承质量公式残差——统计工具与几何公式共享同一误差链。

## §5 三个发现

### 5.1 Λ_H 单独失效——结构在更高阶统计量

五族 Λ_H ∈ [1.0095, 1.4715] 全部落在随机带 [1.0, 3.6] 内。若按单一特征 log₁₀Λ_H 分类，粒子谱会被误判为随机格。但所有五族都有明确的高阶结构签名：

- 矢量/赝标量九重态：同位旋近简并对（ρ/ω 0.95%、π±/π⁰ 3.4%、K±/K⁰ 0.79%）——成对简并签名（定理 0.9.4.02 的粒子谱对应物）；
- 十重态：等距超刚性 ⟨r⟩ = 0.958（GOE/Poisson 的三倍间距比结构）＋ GMO 0.43%；
- 八重态：GMO 线性 0.60%；
- 胶球：严格简并 λ₂ = λ₃。

这与 0.9 的归因修正教训一致（结构不由单一 Λ_H 决定；10.58 P3 已证明单特征 log₁₀Λ_H 只对训练集成立，完整分类需六维特征集）。**粒子谱分类必须携带 {Λ_H, ⟨r⟩, 简并度, GMO 残差} 完整特征集**。

### 5.2 轻子：唯一 diag 型谱与第三代的终止

轻子谱是唯一在随机带之外的粒子族：log₁₀Λ_H = 2.3155 与 P3 训练集 diag 格（log₁₀Λ_H ∈ [2.0, 6.0]）同量级。两级尺度比 (14.379, 4.101) 指示等比缩放结构。

**命题 10.63.5.01（等比外推与 LEP 排除）。** 若两级尺度比构成等比结构（s₃/s₂ = s₂/s₁ = 常数），则外推第四代轻子质量 m₄ = m_τ · (m_τ/m_μ) = 29.88 GeV。该值被 LEP 实验排除（带电轻子质量 < 45 GeV 已被 Z 宽度约束排除；直接搜索排除至 ~100 GeV）。

*推论*。等比结构在第三代终止——两级尺度比 (14.379, 4.101) 不是公比 14.4 的等比序列（若为等比，m_τ = m_μ · 14.379 = 1519 MeV，与实验 1776.86 MeV 偏差 14.5%）。轻子谱的结构是"两级不同尺度的缩放"，不是无限延伸的等比链。框架若要解释轻子谱，必须解释"为什么三代"——这是结构终止给出的边界条件。

**几何答案（§8.4）**：三代必然性由 3.5 定理 3.5.1.01 闭合——编码轨道三段分割（物质/因果/信息）在 M₅ 的 3×3 Birkhoff 结构上留下三个质量印记（λ₁ = 1 主本征值 + λ₂,₃ = 0.678 ± 0.181i 呼吸对）。等比外推的失败不是"结构终止"的谜题，而是三段结构的必然结果（定理 10.63.8.04 推论）。

### 5.3 胶球：理论内部自洽的首次检验

## §7 诚实边界

1. **ρ 指纹无锚**：0.9 的结构指纹 ρ = ‖b₁‖/GH 依赖高斯启发（随机格的"预期最短向量"）；粒子谱不存在对应的"随机质量预期"——ρ 无法迁移，分类只有 Λ_H 与 gap ratio 两个格论量。
2. **乘法 vs 加法张力**：Λ_H 是乘法语言（特征值比，格谱结构），GMO/等距是加法语言（质量线性，SU(3) 结构）。gap ratio 是桥（加法间距 → 比值），但只覆盖相邻间距，不覆盖全局等距。十重态的"超刚性"在格论词汇中无对应物。
3. **小样本**：n = 3–6 能级，gap ratio 样本 2–4 个；八重态 ⟨r⟩ = 0.5279 与 GOE 0.5307 的接近是 2 样本巧合，无统计意义（置信区间覆盖 Poisson 与 GOE 两者）。统计功效不足以做分布检验。
4. **随机带本身是经验区间**：[1.0, 3.6] 来自 10.58 P3 的 N=20 样本（LLL 后），不是定理；粒子谱落入带内只说明"与随机格样本无显著区分"，不构成随机性证据。
5. **数据来源**：粒子质量为 PDG 2024 中心值（实验锚定输入）；胶球质量为 10.39 理论预言。统计量计算不含拟合参数。简并度判据（相对差 < 1%）是本文约定，非标准定义。
6. **轻子 diag 签名的地位**：定理 10.63.4.01 识别轻子谱与 diag 格谱统计同型；§8 将两级尺度比映射到 3.10 质量公式链（C_n 与 sin³θ_M^(n)），统计识别升级为几何分解。C_n 的数值（M₁/2、2³M₁）仍属中间层（σ* 位置输入），但比值结构（16 = 2⁴、877.6 = M₁/2K）是公式链的推论。

## §8 几何化：质量公式的谱结构

### 8.1 统一质量公式

几何论现有已闭合的粒子质量公式均取统一形式：

**命题 10.63.8.01（质量公式统一形式）。** 三类已闭合的粒子质量公式均为"标度因子 × 角度因子"的乘积：

- 胶球（10.39）：m_g = κ_g · K · sin³(30°)，K = 839.758793 keV，κ_g ∈ {15.375, 22.627}；
- 轻子（3.10）：m_n = C_n · sin³θ_M^(n)，C₁ = K，C₂ = M₁/2，C₃ = 2³M₁，M₁ = K·Λ_H·S_e^(1/2) = 1.474 GeV；
- 呼吸谱（3.5）：质量本征态由 Birkhoff 混合矩阵本征值 λ₁ = 1、λ₂,₃ = 0.678 ± 0.181i 承载。

统一形式 m = C·sin³θ 的谱推论：**同一粒子族内，谱刚性比 Λ_H = m₂/m₁ 是标度因子比与角度因子比的乘积**。谱统计量因此不是外部工具，而是质量公式结构的直接读出——10.63 的观察层工具在几何论自己的公式链上获得内部解释。

### 8.2 轻子谱刚性比的几何分解

**定理 10.63.8.02（轻子谱刚性比的几何分解）。** 由 3.10 公式链（C₁ = K = 839.758793 keV，C₂ = M₁/2 = 737 MeV，sin³θ_M^(1) = 0.6088，sin³θ_M^(2) = 0.1481），轻子谱刚性比理论值为：

Λ_H(th) = (C₂/C₁)·(sin³θ_M^(2)/sin³θ_M^(1)) = 877.633 × 0.243265 = 213.498，

与实验值 Λ_H = 206.768 偏差 +3.255%——与 3.10 的 m_μ 预言残差（+3.3%）完全一致（同一公式链）。

*证明*。m_μ/m_e = [C₂·sin³θ_M^(2)]/[C₁·sin³θ_M^(1)]，直接分解为标度因子比 C₂/C₁ 与角度因子比 sin³θ_M^(2)/sin³θ_M^(1)。C_n 由编码轨道层级（定理 3.10.5.01）与扇区联合类型决定；θ_M^(n) 由扇区联合驻点条件锁定（定理 3.10.4.03、3.10.4.04、3.10.8.04）。分解无拟合参数。□

*说明*。10.63 §3.6 观察到的"diag 签名"（定理 10.63.4.01）在此获得几何解释：轻子谱的高谱刚性比不是随机格统计中的异常样本，而是两级几何量（标度因子 877.6、角度因子 0.2433）的乘积结构。推论 0.9.4.12 的 diag 缩放语言与 3.10 的公式语言在此对偶：正交缩放格 M = √Λ_H 的"尺度比"在公式链中展开为 (C₂/C₁)^(1/2)·(s₂/s₁)^(1/2)。

### 8.3 第二级尺度比的 2 幂结构

**定理 10.63.8.03（第二级尺度比的 2 幂结构）。** 由 ℳ扇区同步锁定 sin³θ_M^(3) = sin³θ_M^(2)（定理 3.10.8.04）与信息容量标度律 C₃ = 2³M₁（定理 3.10.8.07），轻子谱第二级质量比的理论值：

m_τ/m_μ = C₃/C₂ = 2³M₁/(M₁/2) = 16（精确），

diag 尺度比 √(m_τ/m_μ)(th) = 4.000 = 2²。实验值 16.817（√ = 4.101），偏差 −4.858%（√ 层 −2.459%）。

*推论（与 0.9 的对偶）*。推论 0.9.4.12 断言 diag 缩放格满足 Λ_H = M²；此处反向成立：**轻子谱第二级的 2 幂结构（16 = 4²）是"几何推导出的 diag 缩放"**——M = 4 来自 ℳ扇区同步的 2³ 因子（相邻代 2 倍级联）。10.63 §3.6 观察到的两级尺度比 (14.379, 4.101) 中，第二级 4.101 ≈ 4.000 已完全几何化；第一级 √Λ_H = 14.379 对应 √213.498 = 14.61（+1.6%，即 Λ_H 层 +3.255% 的开方）。

*说明*。m_τ/m_μ = 16 的精确性是 10.63 未观察到的理论预言：10.63 §3.6 只报告实验比值 16.817。公式链给出无残差的 16——残差全部来自 τ 质量残差（−1.7%，3.10 归因于 η_N 块非等本征值修正）与 μ 残差（+3.3%）。

### 8.4 三代必然性与"结构终止"的闭合

10.63 §5.2 将等比外推失败表述为"结构在第三代终止"的边界条件。几何论内部已有答案：

**定理 10.63.8.04（三代必然性，引用 3.5 定理 3.5.1.01）。** N_gen = 3 由编码轨道三段分割（物质/因果/信息）与 M₅ 的 3×3 Birkhoff 结构决定：主本征值 λ₁ = 1 对应稳定态（电子），非主本征值对 λ₂,₃ = 0.678 ± 0.181i 对应振荡态（μ、τ）。三段分割在质量谱上留下三个印记——不存在第四代不是"结构终止"，而是结构本来就是三段的。

*推论*。10.63 命题 10.63.5.01 的等比外推 m₄ = 29.88 GeV 被 LEP 排除，从"框架的困难"转为"框架的正面证据"：等比外推假设无界级联，而编码轨道只有三段——外推失败正是三段结构的必然结果。§5.2 的边界条件因此被几何定理闭合。

### 8.6 开放问题

1. **GMO 加法结构的几何化**：Λ_H 是乘法语言（比值），GMO 线性是加法语言（质量加权和）。已部分闭合（§8.7）：质量加法律下，十重态等距是精确恒等式（命题 10.63.8.05），八重态 GMO 偏差 = u−d 质量角差（定理 10.63.8.06）。剩余开放：C_B 标度（1.69 倍差）、重子内质量角的环境修正、自旋-同位旋项。
2. **胶球-轻子统一**：胶球 Λ_H = f₋/f₊ = 1.4717（κ 因子比，sin³30° 相同）与轻子第二级 m_τ/m_μ = 16（C 因子比，sin³θ 锁定相同）是同一机制的两个实例：**角度因子锁定时，谱刚性比 = 标度因子比**。κ_g 与 C_n 的统一标度因子理论未建立。开放。
3. **呼吸谱的 Λ_H**：3.5 的非主本征值 |λ₂,₃| = 0.702 < 1——若呼吸谱刚性比定义为 |λ₂|/λ₁ = 0.702，谱刚性比可小于 1，超出 0.9 定义域（λ₂ ≥ λ₁）。定义扩展未处理。开放。

### 8.7 GMO 加法结构的几何化（闭合 §8.6.1）

**质量加法律（猜想 10.63.8.08，见下）**：重子 B 的质量由味成分的质量角线性叠加：

$$m_B = C_B \cdot \sum_{q \in \{u,d,s\}} n_q^{(B)} \cdot \sin^3\sigma_M^{(q)},$$

其中 $n_q^{(B)}$ 是 B 的味量子数（同位旋平均），$C_B$ 是多重态公共标度，$\sigma_M^{(q)}$ 是夸克质量角（7.16 表 4.1：$\sigma_M^{(u)} = 7.88°$、$\sigma_M^{(d)} = 10.20°$、$\sigma_M^{(s)} = 28.74°$，PDG 流质量反推；$\sin^3$ 值 0.0025769 / 0.0055532 / 0.1111707）。

**命题 10.63.8.05（十重态等距恒等式）。** 质量加法律下，十重态 GMO 等距公式与三等距性均为精确恒等式：

$$m_\Delta + m_\Omega = m_{\Sigma^*} + m_{\Xi^*}, \qquad m_{\Sigma^*} - m_\Delta = m_{\Xi^*} - m_{\Sigma^*} = m_\Omega - m_{\Xi^*} = C_B \cdot \Delta_{su},$$

其中 $\Delta_{su} \equiv \sin^3\sigma_M^{(s)} - (\sin^3\sigma_M^{(u)} + \sin^3\sigma_M^{(d)})/2 = 0.1071056$。

*证明*。十重态味成分（同位旋平均）：Δ = 1.5u+1.5d，Σ* = u+d+s，Ξ* = 0.5u+0.5d+2s，Ω = 3s。代入质量加法律：m_Δ + m_Ω = C_B(1.5sin³σ_u + 1.5sin³σ_d + 3sin³σ_s) = m_Σ* + m_Ξ*——逐项相等，恒等式成立；相邻间距三式均等于 C_B(sin³σ_s − 0.5sin³σ_u − 0.5sin³σ_d)，相等。□

**定理 10.63.8.06（八重态 GMO 偏差的同位旋读出）。** 质量加法律下，八重态 GMO 组合的偏差等于 u、d 质量角差的直接读出：

$$2m_N + 2m_\Xi - 3m_\Lambda - m_\Sigma = C_B \cdot (\sin^3\sigma_M^{(u)} - \sin^3\sigma_M^{(d)}).$$

*证明*。八重态味成分：N = 2u+d，Λ = u+d+s，Σ = u+d+s，Ξ = 0.5u+0.5d+2s。代入后 u、d 以外所有项精确抵消，余 C_B(sin³σ_u − sin³σ_d)。□

**推论 10.63.8.06a（u–d 对称极限）**。sin³σ_M^(u) = sin³σ_M^(d)（同位旋对称极限）下八重态 GMO 精确成立。实验偏差 −25.796 MeV（总量）全部来自 u–d 破缺与自旋残留（观察 10.63.8.07）。

**观察 10.63.8.07（数值对照与标度开放）。** 以试探标度 C_B = κ_c·K = 839.759 MeV 与流质量角计算：

| 量 | 理论 | 实验 | 比值 |
|:--|:--:|:--:|:--:|
| 十重态间距 | 839.759 × 0.1071056 = 89.94 MeV | {151.7, 149.7, 139.05} | 1.687 |
| 八重态 GMO 总偏差 | 839.759 × (0.0025769 − 0.0055532) = −2.499 MeV | −25.796 MeV | 10.32 |

两个比值不一致（1.69 vs 10.32）说明简单模型不足。可能来源：(1) 重子内夸克质量角的环境修正（构成子 vs 流质量——三体联合扇区参数空间理论缺失，7.16 §5.4）；(2) 自旋-同位旋分裂（Λ–Σ 同味成分 77.47 MeV）未被 GMO 组合完全消除，污染八重态偏差；(3) C_B ≠ κ_c·K。**十重态比值 1.69 更可信**（自旋 3/2 全同，无自旋污染），指向 C_B ≈ 1.42 GeV——与 3.10 编码轨道层级 M₁ = 1.474 GeV 同量级（差 3.7%）。此接近标注为开放线索，非结论。

**猜想 10.63.8.08（质量加法律的几何根源）。** 重子质量的味线性叠加 m_B = C_B·Σ n_q sin³σ_M^(q) 来自三夸克联合扇区参数空间（7.16 §5.4）的可分离性：联合空间基态质量是单体质量角的和结构——与 10.20 信息场因子化（分子混沌的几何证明）同构。三体联合扇区谱理论建立后，C_B 与环境修正可推导。标注为猜想。

**GMO 与 Λ_H 的张力消解**：§8.6.1 的"乘法 vs 加法"张力在质量加法律下消解——Λ_H = m₂/m₁ 是加法结构的比值读出（乘法投影），GMO 是同一结构的线性组合读出（加法投影）。**张力不在几何，而在投影方式**：同一质量加法律，谱刚性比取比值、GMO 取线性组合，两者互补不矛盾。
