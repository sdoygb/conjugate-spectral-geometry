2. **投影测度变换（真理层，命题 10.60.3.01）**：可观测量的自然度量是 Hilbert–Schmidt 范数平方（迹结构，#2），投影强度 σᵢ = cᵢ²（#3、#257）；长度（振幅）按 |cos θ| 变换，测度按 cos²θ 变换——**模方测度的变换性质（cos²θ）是测度论事实；'概率取为投影强度'本身是锚定对应（Born 假设的代数表述），非几何推导**。
3. **随机性来源定理（真理层，定理 10.60.4.01）**：观测 = 商映射 + 截面（#48 塌缩即截面投影；10.59 定理 10.59.2.02）。随机性来源 = 折叠均匀化（定理 10.60.2.01）；概率数值（锚定） = 投影强度 σᵢ = cᵢ²（#257 归一化自动）；振幅–投影强度关系 = Δλᵢ = K√σᵢ（#259）。长时间极限测量频率 = 均匀基础 × 投影强度（#47 与 #257 同构）——**Born 法则的随机性来源由几何给出（折叠均匀化）；其数值形式 pᵢ = σᵢ = cᵢ² 作为锚定对应输入**（与 2026-08-09 参数化立场一致）。

## §2 折叠均匀化定理（真理层）

本节为纯几何命题，可提交主库验证（A0 类：局部代数/测度论命题，Berry 相位 = 0）。

**定理 10.60.2.01（折叠均匀化定理）。** 设 Φ_q: ℝ^d → [−q/2, q/2]^d 为模折叠映射（10.59 定义 10.59.2.01），X 为 ℝ^d 上分布为平移不变测度截断的随机向量（均匀分布于 [−L, L]^d，L ≫ q）。则折叠像 Φ_q(X) 在基本域 [−q/2, q/2]^d 上**均匀分布**：对任意可测集 I ⊂ [−q/2, q/2]^d，

$$\lim_{L \to \infty} P\big(\Phi_q(X) \in I\big) = \frac{|I|}{q^d}.$$

*证明*。由 10.59 命题 10.59.2.04（纤维结构）：Φ_q(x) = y ⟺ x = y + qk（k ∈ ℤ^d）——前像 Φ_q^{-1}(I) = ∪_{k∈ℤ^d} (I + qk) 是**等测度平移族**。与 [−L, L]^d 相交的平移片数 = (2L/q)^d + O(L^{d−1})（边界项），故

|Φ_q^{-1}(I) ∩ [−L, L]^d| = |I|·(2L/q)^d + O(L^{d−1}).

X 均匀于 [−L, L]^d：P(Φ_q(X) ∈ I) = |Φ_q^{-1}(I) ∩ [−L,L]^d|/(2L)^d → |I|/q^d（L → ∞）。∎

> **注 1（定理的意义——随机性的几何来源）**。Φ_q 是**确定性**映射（每个 x 有唯一折叠像），但前像等测度（10.59 命题 10.59.2.04）使像的分布**均匀化**。这是"确定性映射产生均匀随机性"的严格表述：不需要概率公理，只需要商结构的纤维等测度。折叠 = 随机化的几何来源。

> **注 2（10.59 推论 10.59.3.03 的回归）**。离散信号模型（|S| 个信号值，等概率）中"折叠像均匀散布，正确率 ≈ 1/|S|"正是本定理的离散特例：信号值集 {σs : s ∈ S} 在折叠下成为基本域内均匀散布的像集，每个像点的后验概率 = 1/|S|。

> **注 3（与遍历性的分工）**。#47 用信息扇区的**时间遍历性**（时间平均 = 系综平均）闭合测量统计；本定理给出**空间均匀化**（折叠像的系综分布 = 均匀测度）。两者互补：时间遍历性保证"长期观测收敛到系综"，折叠均匀化保证"系综就是均匀的"。测量统计 = 时间遍历 × 空间均匀 × 投影强度（§4）。

## §3 投影测度与振幅平方（真理层）

本节回答"投影强度为何是振幅的平方"——这是 Born 法则数值部分的代数结构：测度论给出模方测度的变换性质；"概率取为投影强度"是锚定对应（Born 假设的代数表述），非几何推导。

**命题 10.60.3.01（投影的测度变换——振幅平方的测度论性质）。** 设 P: ℝ⁴ → V（dim V = 2）为秩-2 正交投影（#3 语境），Lᵢ ∈ Cl(3) 左乘表示（Lᵢ² = −I₄）。则：

(i) **长度（振幅）变换**：方向 Lᵢv 在截面 V 上的投影幅度 |cᵢ| = |⟨u, Lᵢv⟩|（#3：PLᵢP = cᵢJ，cᵢ = ⟨u, Lᵢv⟩）——|cᵢ| 是内积的模，**线性量**（余弦法则：|cᵢ| = cos θᵢ，θᵢ 为方向与截面的夹角）。

(ii) **测度变换**：可观测量的自然度量是 Hilbert–Schmidt 范数平方（#2：∑ᵢ‖PLᵢP‖²_HS = 2），投影强度定义为 σᵢ = cᵢ² = ‖PLᵢP‖²_HS/2（#257 证明步骤 1）——**σᵢ = cos²θᵢ**（面积比 = 余弦²）。概率等同 pᵢ = σᵢ 为锚定对应（Born 假设的代数表述），见注。

(iii) **归一化自动**：∑σᵢ = ∑cᵢ² = 1（#257，四元数 Lagrange 恒等式）——投影强度构成概率分布，无需外部归一化。

*证明*。(i) #3 的直接内容。(ii) 由 #2 与 #257 的证明：‖PLᵢP‖²_HS = 2cᵢ²（因 PLᵢP = cᵢJ 且 ‖J‖²_HS = 2），故 σᵢ = ‖PLᵢP‖²_HS/2 = cᵢ²；几何上，|cᵢ| = cos θᵢ（内积的余弦），σᵢ = cos²θᵢ——面积元的投影变换（Gram 行列式）。(iii) #257 定理内容。∎

> **注（"平方"的几何来源）**。长度按 |cos θ| 变换（线性），面积/测度按 cos²θ 变换（二次）——这是**测度论的基本事实**（投影面积比 = 余弦²，Gram 行列式），与量子力学无关。投影强度 σ = c² 的"平方"是这一测度论事实的代数表达：可观测量的自然度量是迹（‖·‖²_HS），不是范数本身。**但"物理概率 = 投影强度"的等同（pᵢ = σᵢ）不在测度论之内**——测度论只保证模方测度的变换性质；把概率取为模方测度正是 Born 法则本身，本文将其作为锚定对应输入（参数化立场），而非几何推论。

## §4 Born 法则的涌现定理（真理层）

本节为本文主定理：把 §2（折叠均匀化）与 §3（投影测度）组装为 Born 法则的完整涌现链。

**定理 10.60.4.01（Born 法则涌现定理）。** 设观测（测量）的结构为商映射 + 截面（#48 塌缩即截面投影；10.59 定理 10.59.2.02：折叠 = φ∘π_q），扇区方向 Lᵢ（Cl(3) 左乘表示）在观测截面 V 上的投影强度为 σᵢ = cᵢ²（#3、#257）。则：

(i) **随机性的来源**：折叠均匀化（定理 10.60.2.01）——确定性商映射在像空间产生均匀测度基础；单次测量退化为二值符号（#46：m_k = sgn(Re P_kΨ)），正是折叠为混叠等价类的离散特例（10.59 推论 10.59.3.03）。

(ii) **概率的数值（锚定）**：投影强度 σᵢ = cᵢ²（命题 10.60.3.01），∑σᵢ = 1（#257 自动归一化）——观测扇区 i 的概率取为 pᵢ = σᵢ（锚定对应，Born 假设的代数表述）。

(iii) **振幅–概率关系**：Δλᵢ = K·√σᵢ（#259，Born 法则的代数形式，K 与扇区指标无关）——谱间隙（振幅）与投影强度的平方根成正比。

(iv) **遍历闭合**：长时间极限测量频率 = 均匀基础 × 投影强度 = σᵢ（#47 的 ⟨Z_kΨ⟩² 与 #257 的 cᵢ² 同构：都是投影强度的平方）。

**推论 10.60.4.02（随机性的几何来源；数值等同为锚定）。** 随机性来源由折叠均匀化（定理 10.60.2.01）几何给出：确定性商映射产生均匀测度基础；概率数值取为 pᵢ = σᵢ = cᵢ²（锚定对应），其代数结构由投影强度代数（#3、#257）与谱间隙-振幅关系（#259，Δλᵢ = K√σᵢ）支撑。Born 法则的"为什么是概率"部分几何化，"概率是多少"部分参数化——而非整体作为独立公设。

*证明*。(i) 定理 10.60.2.01 + #46：单次测量 m_k = sgn(Re P_kΨ) 是二值化——信息在观测截面上的符号投影；符号的统计由像空间测度决定（均匀基础）。(ii) 命题 10.60.3.01。(iii) #259 的直接引用。(iv) #47：lim_{T→∞} #{t : m_k(t)=1}/T = ∫(P_kΨ)²dμ = ⟨Z_kΨ⟩²；由 #3，P_kΨ 的投影强度 = c_k，其平方 = σ_k（#257）——频率 = σ_k。∎

> **注（完整涌现链）**。
> 观测 = 商 + 截面（#48 + 10.59.2.02）
> → 随机性 = 折叠均匀化（定理 10.60.2.01，前像等测度）
> → 数值 = 投影强度 σᵢ = cᵢ²（命题 10.60.3.01，迹结构）
> → 归一化 = 四元数 Lagrange（#257）
> → 振幅 = K√σᵢ（#259）
> → 测量统计 = 时间遍历 × 空间均匀 × 投影强度（#47 + 定理 10.60.2.01 + #257）
> = **Born 法则 pᵢ = |cᵢ|²**（数值等同 pᵢ = σᵢ 为锚定对应；随机性来源为几何）。

0.9 命题 0.9.5.05（信息唯一确定）与 0.9 命题 0.9.5.07（读取路径锁死）的区分在本文获得测量论版本：信息（Ψ）在商结构下唯一确定（#745：残余比例 0.825 是确定性衰减），但读取（测量）经过截面投影（#48）——读取的随机性来自截面（观测者选择），不是信息本身的随机性。**随机性在观测者与世界的耦合处（截面），不在世界本体**——与 1.5 §3.7"观测者位置是输入"一致。
