## §2 $2^7$：七层截断的终端代数容量

### 2.1 七层截断的回顾

**定理 0.3.3.01（七层截断）**。$\delta^8$ 的 Berry 相位 $= 2\pi \neq 0$。编码映射 $E_n$ 在 $n=7$ 处截断——$E_8$ 不是独立编码层，而是 Bott 回归步：

$$\delta^8(\mathcal{Z}) \sim \mathcal{Z} \otimes \text{Mat}(16, \mathbb{R})$$

$\delta^8$ 在结构类型上回归到 $\delta^0$（Berry $= 2\pi$，非零闭合），而非 $\delta^0$ 的平凡复制（Berry $= 0$）。

**推论**：编码映射的有效定义域为 $n = 0, 1, \ldots, 7$。终端编码层 $E_7$ 对应的代数是 $\text{Cl}(7)$。

### 2.2 $\text{Cl}(7)$ 的实维数

**命题 2.2.1**。Clifford 代数 $\text{Cl}(n)$ 的实维数为 $2^n$。

*证明*（标准）。$\text{Cl}(n)$ 由 $n$ 个生成元 $e_1, \ldots, e_n$ 生成，满足 $e_i^2 = -1, e_i e_j = -e_j e_i \ (i \neq j)$。一组基为：

$$\{e_{i_1} e_{i_2} \cdots e_{i_k} \mid 0 \leq k \leq n, \ 1 \leq i_1 < i_2 < \cdots < i_k \leq n\}$$

基元素个数 $= \sum_{k=0}^n \binom{n}{k} = 2^n$。∎

**推论 2.2.2**。$\dim_\mathbb{R}(\text{Cl}(7)) = 2^7 = 128$。

### 2.3 几何意义

$\text{Cl}(7) \cong \text{Mat}(8, \mathbb{R}) \oplus \text{Mat}(8, \mathbb{R})$。128 维的终端代数是 δ 在 Bott 闭合前能达到的最大编码空间——七层编码（$E_1$ 到 $E_7$）将所有可能的区分模式代数化为这 128 维中的结构。

**128 是"容器"——Bott 闭合的被动几何容量。** 它不关心闭合是非平凡（Berry $= 2\pi$）还是平凡（Berry $= 0$）的——它是 $\text{Cl}(7)$ 作为代数的不变维数，只取决于七层截断这一几何事实。

## §3 $\chi_C = 9$：因果扇区的编码累积拉伸

### 3.1 乘子序列与编码累积拉伸

**定理 1.1.3.01（乘子序列）**。从结构常数 {2,3,5} 和 Bott 周期出发，六个编码乘子唯一确定为：

$$\mu = (6, 100/3, 10, 10, 9/8, 2)$$

**定理 2.1.3.2（编码累积拉伸）**。在七层编码轨道中，三层对应三扇区：

| 扇区 | 编码层 | 代数范围 | $\dim_\mathbb{R}$ 扩展 |
|:--|:--|:--|:--|
| ℳ（物质） | $E_1, E_2, E_3$ | $\text{Cl}(0) \to \text{Cl}(3)$ | $1 \to 8$ |
| 𝒞（因果） | $E_4, E_5$ | $\text{Cl}(3) \to \text{Cl}(5)$ | $8 \to 32$ |
| ℐ（信息） | $E_6, E_7$ | $\text{Cl}(5) \to \text{Cl}(7)$ | $32 \to 128$ |

各扇区的编码累积拉伸 $\chi_i$ 由乘子序列的扇区分量确定：

$$\chi_M = 8,\quad \chi_C = 9,\quad \chi_I = 1$$

### 3.2 $\chi_C = 9 = 3^2$ 的根源

$\chi_C = 9$ 来自乘子序列的第五个乘子 $\mu_5 = 9/8$。$\mu_5$ 作用于编码层 $E_4 \to E_5$ 的过渡——即 $\text{Cl}(4) \to \text{Cl}(5)$。

$\text{Cl}(4) \to \text{Cl}(5)$ 的过渡是因果扇区（𝒞）的核心步骤。在这一步中，Spin(5) 的 triality 对称群 $S_3$ 破缺为 $Z_2$。

**$\chi_C = 9 = 3^2$ 是 triality 破缺 $S_3 \to Z_2$ 的代数代价。**

具体来说：

- $S_3$（三个对象的置换群）有 $|S_3| = 6$ 个元素。破缺到 $Z_2$（两个元素的群）后，陪集空间 $S_3/Z_2$ 有 $6/2 = 3$ 个元素。
- Triality 涉及三个 8 维表示的置换（$8_v, 8_s, 8_c$）。破缺固定了其中一个（$8_c$ → 信息扇区），剩下两个（$8_v, 8_s$）在 $Z_2$ 下交换。
- 破缺的代数代价 = $3^2 = 9$——其中因子 $3$ 来自结构常数 $\Lambda = 3$（物质常数，triality 破缺中 ℳ 扇区被突出），平方来自 triality 的三个表示中两个被锁定、一个被释放的二次结构代价。

这个 $3^2$ 不以 $\text{Cl}(4)$ 的维数（$2^4 = 16$）或 $\text{Cl}(5)$ 的维数（$2^5 = 32$）的形式出现——它是独立于维数扩展的"扭力"，编码了因果扇区在 Bott 周期中经历的代数破缺。

### 3.3 编码累积拉伸 vs 维数扩展

关键区分：

| | 维数扩展 | 编码累积拉伸 $\chi$ |
|:--|:--|:--|
| ℳ | $1 \to 8$（因子 8） | $\chi_M = 8$（与维数扩展一致） |
| 𝒞 | $8 \to 32$（因子 4） | $\chi_C = 9 \neq 4$（包含 triality 破缺代价） |
| ℐ | $32 \to 128$（因子 4） | $\chi_I = 1$（编码在 Cl(7) 终端二元性中平衡，无净拉伸） |

物质扇区的维数扩展与编码累积拉伸一致（8 = 8）——因为 Cl(0) → Cl(3) 的过渡不涉及 triality 破缺。因果扇区是唯一经历 triality 破缺的扇区，其编码累积拉伸（9）超过纯维数扩展（4）。信息扇区的编码在终端二元性中自我平衡，累积拉伸为 1（无净贡献）。

## §4 为什么是加法？

### 4.1 两种编码自由度

$2^7 = 128$ 是**被动容器**——终端代数 $\text{Cl}(7)$ 的维数。它测量的是"在 Bott 闭合前，δ 的迭代能占据多少代数自由度"。

$\chi_C = 9$ 是**主动扭力**——因果扇区在 triality 破缺中累积的代数代价。它测量的是"使 Bott 闭合非平凡（Berry $= 2\pi$ 而非 $0$）需要多少额外的编码自由度"。

两者的量纲一致：都是**编码空间中被占据的自由度**的度量。

| | 容器（$2^7$） | 扭力（$\chi_C$） |
|:--|:--|:--|
| 本质 | 被动几何容量 | 主动闭合代价 |
| 来源 | $\text{Cl}(7)$ 的代数维数 | Triality 破缺 $S_3 \to Z_2$ |
| 如果为零 | 无编码空间（不可能，δ 非平凡） | 平凡闭合（Berry $= 0$） |
| 在当前框架中 | $2^7 = 128$（七层截断刚性） | $\chi_C = 3^2 = 9$（{2,3,5} 刚性） |

### 4.2 加法的合理性

在 Bott 闭合点，终端代数 $\text{Cl}(7)$ 通过 $E_8$ 桥接回归到 $\text{Cl}(0) \otimes \text{Mat}(16, \mathbb{R})$。这个回归不是自由的——它需要支付因果扭力 $\chi_C$ 作为"闭合费用"。

总编码占据 = 容器容量 + 闭合扭力 = $2^7 + \chi_C = 128 + 9 = 137$。

加法在此处是自然的：容器是 Bott 闭合前的终端状态（$E_7$ 的结果），扭力是执行闭合（$E_8$）所需的代数代价。两者作用于编码空间的不同维度——容器是被动的"存储"，扭力是主动的"转换"——因此不重复计算，相加是合法的。

### 4.3 定理陈述

**定理 0.9.1（基数定理）**。在共扼谱几何中，精细结构常数逆 $\alpha^{-1}$ 的基数 $B_0$ 由 Bott 终端代数容量与因果闭合扭力之和给出：

$$B_0 = \dim_\mathbb{R}(\text{Cl}(7)) + \chi_C = 2^7 + 3^2 = 128 + 9 = 137$$

*证明*：
- $\dim_\mathbb{R}(\text{Cl}(7)) = 2^7 = 128$（命题 2.2.1 + 推论 2.2.2）
- $\chi_C = 9 = 3^2$（定理 2.1.3.2，根源见 §3.2）
- 加法合法性见 §4.2 论证
- 因此 $B_0 = 128 + 9 = 137$。∎

## §5 为什么不是 $\chi_M$ 或 $\chi_I$？

一个自然的问题是：为什么基数中的扭力项是 $\chi_C = 9$，而不是 $\chi_M = 8$ 或 $\chi_I = 1$？

### 5.1 $\chi_M = 8$ 已在容器之内

物质扇区的编码累积拉伸 $\chi_M = 8$ 对应于 $\text{Cl}(0) \to \text{Cl}(3)$ 的过渡。这个过程完全在 $\text{Cl}(7)$ 内部——$\text{Cl}(3)$ 是 $\text{Cl}(7)$ 的子代数。物质界的全部结构已被 128 维的容器覆盖。

**$\chi_M$ 不是额外的——它是容器建造过程的内部支出，已计入 $2^7$。**

类比：建造一座 128 平方米的房子需要 8 吨钢材。128 平方米是房子的最终面积，8 吨钢材是建造过程中消耗的材料。最终你统计的是 128 平方米——钢材已经包含在墙体中了。

### 5.2 $\chi_I = 1$ 无净贡献

信息扇区的编码累积拉伸 $\chi_I = 1$——无净拉伸。编码在 $\text{Cl}(7)$ 的终端二元性（$\text{Cl}(7) \cong \text{Mat}(8, \mathbb{R}) \oplus \text{Mat}(8, \mathbb{R})$）中自我平衡。$1$ 意味着信息扇区在 Bott 闭合中既不增加也不减少编码自由度。

### 5.3 只有 $\chi_C$ 是额外的

因果扇区的编码累积拉伸 $\chi_C = 9$ 来自 triality 破缺 $S_3 \to Z_2$。这个破缺**不在 $\text{Cl}(7)$ 内部**——它是 $\text{Cl}(7) \to \text{Cl}(8)$ 的 Bott 回归步骤中发生的代数事件。

$\text{Cl}(7)$ 的维数是 128——无论 triality 破缺是否发生。但当因果扇区带着 triality 破缺的遗产（$\chi_C = 9$）穿过 Bott 闭合点时，这 9 个额外的编码自由度被"激活"——它们作为闭合的非平凡性代价叠加在容器之上。

**$\chi_C$ 是使 Berry 相位 $= 2\pi$ 而非 $0$ 的代价。** 如果 triality 不破缺（$S_3$ 完整），Bott 闭合将是平凡的（Berry $= 0$），基数为 $128$（只有容器，没有扭力）。$S_3 \to Z_2$ 的破缺使得闭合非平凡——基数变为 $128 + 9 = 137$。

## §6 $\alpha^{-1}$ 的逐级逼近级数

### 6.1 级数结构

基数 $B_0 = 137$ 是零阶项。完整 $\alpha^{-1}$ 由逐级微扰修正构成：

$$\boxed{\alpha^{-1} = \underbrace{2^7 + 3^2}_{137} \;+\; \underbrace{\frac{1}{3^3}}_{1/27} \;-\; \underbrace{\frac{\Lambda \times \Delta\Theta}{d_{\text{total}} \times h^2}}_{15/14400} \;+\; O(10^{-6})}$$

数值上：$137 + 1/27 - 15/14400 = 137.035995370\ldots$

其中 $\varepsilon = \frac{1}{d_{\text{total}} \cdot h^2} = \frac{1}{16 \times 30^2} = \frac{1}{14400} \approx 6.94 \times 10^{-5}$ 是 Bott 回声的基本尺度。$B_2 = -15/14400$ 的精确分子 $15 = 3 \times 5 = \Lambda \times \Delta\Theta$ 来自 Cl(7) 终端直和结构中的交叉耦合。

### 6.2 各项的来源

| 项 | 符号 | 来源 | 依赖 | 证明状态 |
|:--|:--|:--|:--|:--|
| $B_0$ | **137** | Bott 终端容量 + 因果扭力 | $2^7$（Cl(7)）+ $\chi_C = 3^2$（triality 破缺） | ✅ 定理 0.9.1 |
| $B_1$ | $1/27 \approx 0.037037$ | 三层物质编码偏差 | $1/\Lambda^3 = 1/27$（$\Lambda=3$） | ⚠️ 几何猜想，数值吻合极好 |
| $B_2$ | **−15/14400 = −1/960** | Bott 周期回声 | $\varepsilon = 1/14400$，分子 $\Lambda \times \Delta\Theta = 15$ | ⚠️ 候选公式——数值吻合 $3.8\times10^{-6}$，几何推导清晰（见 §6.3） |
| $B_3$ | $\sim 4\times 10^{-6}$ | 扇区依赖因子精细修正 + 双周期回声 | $O(\varepsilon)$ 残留 + $\varepsilon^2$ | ⚠️ 量级确定，精确值待定 |

### 6.3 $B_2 = -15/14400$ 的推导

**定理 0.9.2（Bott 回声定理，候选）**。精细结构常数逆 $\alpha^{-1}$ 的 Bott 回声修正为：

$$B_2 = -\frac{\Lambda \times \Delta\Theta}{d_{\text{total}} \times h^2} = -\frac{15}{14400} = -\frac{1}{960} \approx -0.001041667$$

**推导**。

(1) **回声尺度**。Bott 同构 $\text{Cl}(n+8) \cong \text{Cl}(n) \otimes \text{Mat}(16, \mathbb{R})$ 意味着第二个 Bott 周期通过周期壁 $d_{\text{total}} = 16$ 渗入第一个周期。E$_8$ 的 Coxeter 共振产生衰减因子 $1/h^2 = 1/900$。基本尺度 $\varepsilon = 1/(d_{\text{total}} \cdot h^2) = 1/14400$。

(2) **终端直和结构与交叉耦合**。终端编码层对应 $\text{Cl}(7) \cong \text{Mat}(8,\mathbb{R}) \oplus \text{Mat}(8,\mathbb{R})$。两个直和块分别承载物质扇区（$\mathcal{M}$，绑定 $\Lambda = 3$）和信息扇区（$\mathcal{I}$，绑定 $\Delta\Theta = 5$）的终端编码。因果扇区（$\mathcal{C}$，绑定 $k_0 = 2$）位于 Bott 中心 $\text{Cl}(4)$，回声穿过时对称——不贡献净分子。

Bott 回声穿过周期壁后，在 $\text{Cl}(7)$ 的两个直和块之间产生交叉耦合。非对角耦合强度等于两个块的代表性结构常数的乘积：$\Lambda \times \Delta\Theta = 15$。

(3) **符号**。回声耦合在 $S(\sigma)$ 中表现为编码自由度在终端 $\mathcal{M}$-块和 $\mathcal{I}$-块之间的"短路"传输——原本需要完整编码轨道（$\mathcal{M} \to \mathcal{C} \to \mathcal{I}$）的连接现在可以通过 Bott 闭合的回声绕过。这略微降低了编码成本，符号为负。

**证明状态**：$\varepsilon = 1/14400$ 是 Bott 同构和 E$_8$ Coxeter 数的直接推论（严格）。分子 $\Lambda \times \Delta\Theta = 15$ 基于 Cl(7) 直和结构中的交叉耦合论证（方向性——待编码轨道正向推导验证）。

### 6.4 三圈零和体系

$B_0$ 和 $B_1$ 中的项可以追溯到结构常数的更高次零和：

| 圈 | 零和公式 | 验证 | 泄漏项（进入 $\alpha^{-1}$） |
|:--|:--|:--|:--|
| 第一圈 | $\Lambda + k_0 - \Delta\Theta = 0$ | $3+2-5=0$ ✅ | —（完全平衡） |
| 第二圈 | $\Lambda^2 - k_0^2 - \Delta\Theta = 0$ | $9-4-5=0$ ✅ | $\Lambda^2 = 9 \to B_0$ |
| 第三圈 | $\Lambda^3 - \Delta\Theta^2 - k_0 = 0$ | $27-25-2=0$ ✅ | $1/\Lambda^3 = 1/27 \to B_1$ |

$B_2$ 不来自单一零和圈的泄漏，而是两个终端扇区（$\mathcal{M}$ 和 $\mathcal{I}$）在 Bott 闭合处的交叉耦合——$\Lambda \times \Delta\Theta = 15$。因果扇区（$k_0$）只出现在分母的 $h = 2 \times 3 \times 5 = 30$ 中。

### 6.6 与 2.2 的关系

2.2 从不动点 $\sigma^*$ 出发，纯代数地计算出 $S(\sigma^*) \approx 137.036$。本文从反方向出发——从 Bott 周期和七层截断的纯几何数据构造基数 $B_0 = 137$，然后将 $S(\sigma^*) - 137 \approx 0.036$ 分解为 $B_1 + B_2 = 1/27 - 15/14400 = 0.035995$。剩余差值 $0.000004$ 由扇区依赖因子精细修正（$B_3$）覆盖。基数 $B_0 = 137$、编码累积 $B_1 = 1/27$ 和 Bott 回声 $B_2 = -15/14400$ 都是纯几何的——只依赖 Bott 周期和结构常数。

## §7 结论与逻辑地位

### 7.1 主要结论

**定理 0.9.1（基数定理）**。精细结构常数逆 $\alpha^{-1}$ 的基数由 Bott 终端代数容量（$2^7 = 128$）与因果闭合扭力（$\chi_C = 3^2 = 9$）之和给出：

$$B_0 = 128 + 9 = 137$$

### 7.2 逻辑地位

基数定理在共扼谱几何中的逻辑地位如下：

| 层级 | 内容 | 文章 |
|:--|:--|:--|
| 公理 | 零之动 δ（非平凡自映射，非满射） | 0.1 |
| 推导层 1 | 三层自指闭合 → Clifford 代数化 | 0.1-0.2 |
| 推导层 2 | Bott 周期（δ⁸ 闭合，Berry = 2π） | 0.3 |
| 推导层 3 | 结构常数 {2,3,5} | 0.4-0.5 |
| 推导层 4 | 七层截断 + 编码轨道 + 乘子序列 | 0.6-0.7, 1.1 |
| 推导层 5 | 编码累积拉伸 χ = (8,9,1) | 2.1 |
| **基数** | **$B_0 = 2^7 + \chi_C = 137$** | **0.9（本文）** |
| 微扰 | 编码累积修正 + Bott 回声 → 137.036 | 2.2 |

基数定理是**卷0的收官定理**——它将卷0的纯几何推导链（δ → Bott → {2,3,5} → 七层截断）与物理观测（$\alpha^{-1} \approx 137.036$）直接连接起来。它不需要任何观测输入或拟合参数——$2^7$ 和 $\chi_C = 3^2$ 都是已严格证明的几何必然性。

### 7.3 开放问题

1. **$B_1 = 1/27$ 的严格证明**：当前 $B_1 = 1/\Lambda^3 = 1/27$ 是几何猜想。严格证明需要从编码轨道的扇区容量分配正向推导 $\sigma_0$，或等价地证明 $S(\sigma_0) = 2^7 + 3^2 + 1/3^3$ 是编码轨道的不动点定理。

2. **$B_2$ 分子的严格证明**：$B_2 = -(\Lambda \times \Delta\Theta)/14400$ 的分子基于 Cl(7) 直和结构交叉耦合论证。严格证明需要 Cl(7) → Cl(8) Bott 映射的代数显式计算。

3. **三圈零和的推广**：是否存在第四圈及更高圈零和？它们的泄漏项是否对应 $B_3$ 及更高修正？

4. **$B_0$ 的唯一性证明**：如果存在替代的 Bott 周期实现，$B_0$ 是否仍为 137？
