# 双光子 MZ 干涉的相位敏感检验：10.50 预言的可执行实验方案

**编号**：10.52 | **日期**：260811 | **系列**：应用（时间纠缠→量子光学实验接口） | **语言**：CN | **性质**：实验方案

**摘要**：本文给出 10.50 预言（双光子干涉中的附加几何相位 δ_φ = S_ent）的可执行实验方案。方案基于现成装置（arXiv:2602.16350，尼斯大学 INPHYNI，2026：折叠 Franson 干涉仪 + 单/双光子 common-mode 同时采集）的组件，但作关键改造：**将干涉仪核心延迟线从 20 m 光纤线圈更换为压电光纤拉伸器控制的亚微米延迟线（相干极限）**——因为 Franson 的大路径差（67 ns）对应 Δη ~ 10⁷，预言信号被压至 ~10⁻¹⁹ rad 不可测；而预言敏感区在 Δη ~ 0.05–1（单程路径差 ΔL ~ 5–110 nm，折叠往返 ×2）。改造后装置退化为标准双光子 MZ（N00N 超分辨条纹，2φ 振荡——标准量子光学），判别判据为：**双光子条纹（二阶谐波）相对单光子条纹的残差相位 δ_φ(ΔL)，拟合 ½log(1 + 1/(A_effΔL² + 1))（A_eff 由框架常数决定，映射成立时无自由参数）**。统计预算：以 m = 3–5 信噪分辨弱信号区 δ_φ = 1.5×10⁻³ rad 需 ~4×10⁶–1.2×10⁷ 符合计数/点，40 kHz 符合率下每点 ~2–5 min，20 个扫描点总测量 ~1–2.5 h（m = 10 第二阶段 ~8 h）。判定分层：形状检验（log 形状，映射无关）与标度检验（A_eff 值，映射相关）。

## §1 目标与判别判据

**目标**：检验 10.50 的预言——双光子干涉条纹携带附加几何相位

$$\delta_\varphi(\Delta\eta, \Delta\xi) = \frac{1}{2}\log\left(1 + \frac{1}{\lambda_1(\Delta\eta)^2 + \lambda_2(\Delta\xi)^2}\right), \quad \Delta\xi = \frac{1}{\sqrt{\lambda_2}}$$

（命题 10.50.2.01，几何相位机制）。标准量子光学（含 arXiv:2403.04432 的完整时间纠缠理论）预言**无此相位**——单光子与双光子干涉条纹相位均由路径差线性决定（命题 10.50.5.02 对照）。

**判别判据**（命题 10.52.3.01）：设单光子条纹相位 Φ₁(ΔL)（线性，零基准）与双光子条纹相位 Φ₂(ΔL)（信号），定义残差

$$\delta_\varphi(\Delta L) = \Phi_2(\Delta L) - 2\Phi_1(\Delta L)$$

其中 2Φ₁ 为双光子 2φ 振荡的线性基准（N00N 超分辨的标准频率倍增，arXiv:2602.16350 的单光子通道提供精确校准）。框架预言 δ_φ(ΔL) = ½log(1 + 1/(AΔL² + 1))；标准预言 δ_φ(ΔL) ≡ 0。**同一装置、同一噪声条件、同时刻比较**——内置零基准，无需外部相位校准。

## §2 装置设计

### 2.1 关键改造：延迟线更换与相干极限（命题 10.52.2.01）

arXiv:2602.16350 的 Franson 干涉仪不平衡路径差 20 m 光纤（Δt = 67 ns ≫ 相干时间），对应 Δη = Δt/(χ_T√λ₁^eff) ≈ 9.4×10⁷ rad，预言信号 δ_φ ≈ ½·(392.21×8.8×10¹⁵)⁻¹ ≈ 10⁻¹⁹ rad——**不可测**。预言敏感区 Δη ∈ [0.05, 2.3] 对应单程路径差 ΔL ∈ [5, 110] nm（折叠 Michelson 往返光程差 2ΔL；映射 Δη = 2ΔL/(cχ_T√λ₁^eff)，命题 10.50.4.01，推断级）——**亚微米延迟线**。此量级 ≪ SPDC 相干长度（滤波后 ~ps × c ≈ 数百 μm），干涉对比度不受影响；装置退化为相干极限（Franson 干涉仪的相干极限 = 双光子 MZ 型干涉）。注意：20 m 延迟线**不能缩短**——它是 Franson 时间标记的本质组件，必须整体更换为压电控制的亚微米延迟线（工程核心改造，见 §2.2 第 3 条与 §4.3 稳定性预算）。

### 2.2 拓扑与组件（命题 10.52.2.02）

沿用 2602.16350 的组件（光源、锁定、采集），改造干涉仪本体：

1. **光源**：1560.61 nm CW 激光 → EOM（~10 GHz 边带，相位控制）→ 铌酸锂波导 SHG + SPDC（时间关联近简并对）→ DWDM 滤波（~ps 相干时间）
2. **输入**：简并对分别进入两个折叠 Michelson（信号 → M1、闲频 → M2，2602.16350 配置）——每个 Michelson 输入为单光子，**单光子条纹天然存在**（V₁ = 99.3% 实测，锁定与校准参考；|1,1⟩ 同端口输入的 MZ 无单光子条纹——输出平均光子数为常数，不可作参考，故排除此配置）；双光子符合给出联合条纹
3. **干涉仪**：折叠 Michelson 对（法拉第镜偏振自补偿，2602.16350 结构保留）；**核心改造：20 m 延迟线线圈整体更换为压电光纤拉伸器**（~3 m 光纤绕压电筒，应变控制单程路径差 ΔL ∈ [0, 100] nm，往返 2ΔL ∈ [0, 200] nm，步长 ~5 nm；压电应变分辨率 ~10⁻¹¹ → 光程分辨率 ~30 pm）
4. **双通道同时采集**：单光子通道（布拉格滤波 + PID 锁定 + SNSPD）与双光子通道（DWDM 分离 + SNSPD + TDC 符合）——common-mode 设计原样保留
5. **环境控制**：消声室 + 热稳定（2602.16350 配置）

## §3 测量协议

1. **扫描**：单程 ΔL ∈ [0, 100 nm]，20 点（步长 ~5 nm，ΔL < 15 nm 处加密至 2.5 nm——信号集中区）；驻留分段：强信号区（<15 nm，δ_φ > 0.09 rad）~10³ 计数（秒级），弱信号区（>50 nm）按 m = 3–5 信噪全驻留（§4.2）
2. **锁定**：每个 Michelson 的单光子条纹 mid-fringe PID 锁定补偿热漂移（2602.16350 方案；锁定电压记录 + 差分协议扣除残余漂移）；EOM 提供快相位控制
3. **采集**：每点同时记录单光子率 R₁(ΔL) 与双光子符合率 R_c(ΔL)
4. **每点内相位扫描**：固定 ΔL，EOM 扫描相位 2π 多周期，记录 R₁(φ)、R_c(φ) 条纹 → 正弦拟合（含 DC、一阶、二阶谐波）提取 Φ₁、Φ₂
5. **分析**：对每个 ΔL 点，残差 δ_φ(ΔL) = Φ₂ − 2Φ₁（无需解卷绕——2Φ₁ 自带线性基准）→ 拟合预言曲线 ½log(1+1/(AΔL²+1))（A 固定，映射成立时无自由参数）；单光子自检 δ_φ⁽¹⁾ = Φ₁ − 4πΔL/λ（往返因子；应为 0，标定 ΔL 标度误差）

## §4 参数预算与精度

### 4.1 预言曲线（命题 10.52.4.01）

映射（折叠 Michelson 配置，往返因子 ×2）：Δη = 2ΔL/(cχ_T√λ₁^eff)，cχ_T√λ₁^eff = 2.146×10⁻⁷ m/rad（χ_T = 3.616×10⁻¹⁷ s、λ₁^eff = 391.05，经 6.6 §7.2 推断级翻译；ΔL 为单程路径差）。则

$$\delta_\varphi(\Delta L) = \frac{1}{2}\log\left(1 + \frac{1}{A_{\text{eff}}(\Delta L)^2 + 1}\right), \quad A_{\text{eff}} = \frac{4\lambda_1}{(c\chi_T\sqrt{\lambda_1^{\text{eff}}})^2} = 3.41\times10^{16}\ \text{m}^{-2}$$

| ΔL（单程）| 往返 2ΔL | Δη | δ_φ |
|---|---|---|---|
| 0 | 0 | 0 | **0.347 rad**（上限）|
| 5 nm | 10 nm | 0.047 | 0.216 rad |
| 10.7 nm | 21.4 nm | 0.1 | 0.092 rad |
| 50 nm | 100 nm | 0.47 | 5.8×10⁻³ rad |
| 100 nm | 200 nm | 0.93 | 1.5×10⁻³ rad |

信号集中在单程 ΔL < 50 nm（δ_φ > 5×10⁻³ rad），且无自由参数（A_eff 由 λ₁、χ_T、c 决定）。注：若改用非折叠 MZ，往返因子消失（A_eff → A = 8.52×10¹⁵ m⁻²）——配置必须在方案中固定。

### 4.2 统计预算（命题 10.52.4.02）

条纹拟合相位精度 δφ ≈ 1/(V√N)，V ≈ 0.97（2602.16350 双光子可见度）。要分辨 ΔL = 200 nm 处的 δ_φ = 1.5×10⁻³ rad 以 m 倍信噪，需相位精度 1.5×10⁻³/m rad：

- m = 3：N = (m/(V·1.5×10⁻³))² ≈ 4.3×10⁶ 符合计数/点 → 40 kHz 下 ~2 min/点 → 20 点 ~40 min
- m = 5：N ≈ 1.2×10⁷ → ~5 min/点 → 20 点 ~1.7 h
- **第一阶段设计取 m = 3–5（总测量 ~1–2.5 h）**；m = 10（N = 4.7×10⁷，~20 min/点，总 ~8 h）作为第二阶段的终极排除标准

分段驻留：ΔL < 30 nm 强信号区（δ_φ > 0.1 rad）只需 ~10²–10³ 计数（秒级驻留）——统计上先出结果；ΔL > 100 nm 弱信号区按 m = 3–5 全驻留，用于形状约束。

### 4.3 系统误差控制

- **主动锁定（稳定性主方案）**：单光子条纹 mid-fringe PID 锁定（每个 Michelson 的 V₁ = 99.3% 条纹，伺服带宽 ~kHz 吸收热漂移）——锁定电压记录漂移，差分协议扣除（每测量点前后平均）——有效相位稳定性由伺服残余误差决定（~10⁻³ rad 级），而非被动温控
- **热预算**：压电拉伸器 ~3 m 光纤光程温度系数 ~30 μm/K——0.001 K 漂移 → 30 nm（0.12 rad @1560 nm）——**必须主动锁定**；消声室热稳定（2602.16350 配置）将漂移率压至秒级测量窗口内可忽略；法拉第镜偏振补偿
- 单光子相位自检 Φ₁(ΔL) = 4πΔL/λ 线性检验（往返因子；标定压电迟滞与 ΔL 标度误差）
- 残余泵浦抑制（级联 DWDM，2602.16350 方案）

## §5 预言与判定表（命题 10.52.5.01）

| 观测 | 判定 |
|---|---|
| 残差 δ_φ(ΔL) ≠ 0，拟合 ½log(1+1/(A_effΔL²+1)) 成功，单光子残差 = 0 | **证实**（映射成立下，A_eff 值检验通过）|
| 残差 ≠ 0，log 形状成立但 A_eff 偏离（>2σ）| 部分证实——形状确认、映射（χ_T 翻译）需修正 |
| 残差 ≠ 0 但形状不匹配 | 时间纠缠相位通道存在但机制/映射需修正 |
| 残差 ≡ 0（第一阶段精度 7.5×10⁻⁴ rad，第二阶段 1.5×10⁻⁴ rad）| **排除**（时间纠缠相位通道）|
| 单光子残差 ≠ 0 | 系统误差或新效应——先排查装置 |

## §6 风险与备选

1. **映射不确定性（最大风险）**：Δη ↔ ΔL 依赖 χ_T 作为双光子时间差的翻译标度——推断级（6.6 §7.2 标注"非全部定理级"；§8.2 Σ↔ℝ³¹ 桥未建）。缓解：判定分层（形状检验映射无关；A 值检验映射相关）；若 χ_T 不适用，预言曲线整体平移/缩放，log 形状仍是判别特征。
2. **波包重叠**：亚微米路径差 ≪ 相干长度（~数百 μm）——干涉对比度不受影响；联合条纹可见度需在相干极限重新标定（2602.16350 的 97.4% 是非相干极限值——相干极限联合条纹含 cos φ 与 cos 2φ 多频率成分，标准 Franson 理论给出 R_c ∝ 4cos²(φ₁/2)cos²(φ₂/2)，二阶谐波相位 = 2Φ₁ + δ_φ——判据结构不变，但可见度与谐波权重需实验标定）
3. **色散**：近简并对在光纤 MZ 中的色散差异——评估：若影响相位提取，改用自由空间 MZ 或色散补偿。
4. **信号上限**：ΔL → 0 处 δ_φ → 0.347 rad 需波包完全重叠且 Δξ = 1/√λ₂——实际 Δξ 由光子对的相关性决定（SPDC 近简并对的 ξ 共享程度未知）——上限值本身是待测量，不强加。
