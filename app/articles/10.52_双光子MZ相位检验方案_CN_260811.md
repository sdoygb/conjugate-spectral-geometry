# 双光子 MZ 干涉的相位敏感检验：10.50 预言的可执行实验方案

**编号**：10.52 | **日期**：260811 | **系列**：应用（时间纠缠→量子光学实验接口） | **语言**：CN | **性质**：实验方案

**摘要**：本文给出 10.50 预言（双光子干涉中的附加几何相位 δ_φ = S_ent）的可执行实验方案。方案基于现成装置（arXiv:2602.16350，尼斯大学 INPHYNI，2026：折叠 Franson 干涉仪 + 单/双光子 common-mode 同时采集）的组件，但作关键改造：**将干涉仪路径差从 20 m 光纤线圈缩短至亚微米（相干极限）**——因为 Franson 的大路径差（67 ns）对应 Δη ~ 10⁷，预言信号被压至 ~10⁻¹⁹ rad 不可测；而预言敏感区在 Δη ~ 0.05–1（ΔL ~ 10–215 nm）。改造后装置退化为标准双光子 MZ（N00N 超分辨条纹，2φ 振荡——标准量子光学），判别判据为：**双光子条纹相对单光子条纹的残差相位 δ_φ(ΔL)，拟合 ½log(1 + 1/(AΔL² + 1))（A 由框架常数决定，映射成立时无自由参数）**。统计预算：相位精度 1.5×10⁻³ rad 需 ~5×10⁵ 符合计数/点，40 kHz 符合率下每点 ~12 s，20 个扫描点总测量 ~10 min。判定分层：形状检验（log 形状，映射无关）与标度检验（A 值，映射相关）。

## §1 目标与判别判据

**目标**：检验 10.50 的预言——双光子干涉条纹携带附加几何相位

$$\delta_\varphi(\Delta\eta, \Delta\xi) = \frac{1}{2}\log\left(1 + \frac{1}{\lambda_1(\Delta\eta)^2 + \lambda_2(\Delta\xi)^2}\right), \quad \Delta\xi = \frac{1}{\sqrt{\lambda_2}}$$

（命题 10.50.2.01，几何相位机制）。标准量子光学（含 arXiv:2403.04432 的完整时间纠缠理论）预言**无此相位**——单光子与双光子干涉条纹相位均由路径差线性决定（命题 10.50.5.02 对照）。

**判别判据**（命题 10.52.3.01）：设单光子条纹相位 Φ₁(ΔL)（线性，零基准）与双光子条纹相位 Φ₂(ΔL)（信号），定义残差

$$\delta_\varphi(\Delta L) = \Phi_2(\Delta L) - 2\Phi_1(\Delta L)$$

其中 2Φ₁ 为双光子 2φ 振荡的线性基准（N00N 超分辨的标准频率倍增，arXiv:2602.16350 的单光子通道提供精确校准）。框架预言 δ_φ(ΔL) = ½log(1 + 1/(AΔL² + 1))；标准预言 δ_φ(ΔL) ≡ 0。**同一装置、同一噪声条件、同时刻比较**——内置零基准，无需外部相位校准。

## §2 装置设计

### 2.1 关键改造：相干极限（命题 10.52.2.01）

arXiv:2602.16350 的 Franson 干涉仪路径差 20 m 光纤（Δt = 67 ns ≫ 相干时间），对应 Δη = Δt/(χ_T√λ₁^eff) ≈ 9.4×10⁷ rad，预言信号 δ_φ ≈ ½·(392.21×8.8×10¹⁵)⁻¹ ≈ 10⁻¹⁹ rad——**不可测**。预言敏感区 Δη ∈ [0.05, 2.3] 对应 ΔL ∈ [10, 500] nm（映射 Δη = ΔL/(cχ_T√λ₁^eff)，命题 10.50.4.01，推断级）——**亚微米路径差**。此量级 ≪ SPDC 相干长度（滤波后 ~ps × c ≈ 数百 μm），干涉对比度不受影响；装置退化为相干极限双光子 MZ（标准 N00N 相位灵敏度，2φ 振荡）。

### 2.2 拓扑与组件（命题 10.52.2.02）

沿用 2602.16350 的组件（光源、锁定、采集），改造干涉仪本体：

1. **光源**：1560.61 nm CW 激光 → EOM（~10 GHz 边带，相位控制）→ 铌酸锂波导 SHG + SPDC（时间关联近简并对）→ DWDM 滤波（~ps 相干时间）
2. **聚束**：光子对经 50:50 BS（HOM 配置，可见度 ≥97%，2602.16350 已实现 97.4%）→ 输出 |2,0⟩ 态进入 MZ
3. **干涉仪**：光纤 MZ 或折叠 Michelson，**路径差 ΔL 由压电延迟线控制（0–500 nm，步长 ~10 nm）**；法拉第镜偏振自补偿（2602.16350 配置）
4. **双通道同时采集**：单光子通道（布拉格滤波 + PID 锁定 + SNSPD）与双光子通道（DWDM 分离 + SNSPD + TDC 符合）——common-mode 设计原样保留
5. **环境控制**：消声室 + 热稳定（2602.16350 配置）

## §3 测量协议

1. **扫描**：ΔL ∈ [0, 200 nm]，20 点（步长 ~10 nm，ΔL < 30 nm 处加密至 5 nm——信号集中区）；每点驻留 ~12 s（符合计数 ~5×10⁵）
2. **锁定**：单光子通道 mid-fringe PID 锁定补偿慢漂移（2602.16350 方案）；EOM 提供快相位控制
3. **采集**：每点同时记录单光子率 R₁(ΔL) 与双光子符合率 R_c(ΔL)
4. **分析**：对 R₁、R_c 分别做傅里叶相位提取（或条纹拟合）→ Φ₁(ΔL)、Φ₂(ΔL) → 残差 δ_φ(ΔL) = Φ₂ − 2Φ₁ → 拟合预言曲线

## §4 参数预算与精度

### 4.1 预言曲线（命题 10.52.4.01）

映射 Δη = ΔL/(cχ_T√λ₁^eff)，cχ_T√λ₁^eff = 2.146×10⁻⁷ m/rad（χ_T = 3.616×10⁻¹⁷ s、λ₁^eff = 391.05，经 6.6 §7.2 推断级翻译）。则

$$\delta_\varphi(\Delta L) = \frac{1}{2}\log\left(1 + \frac{1}{A(\Delta L)^2 + 1}\right), \quad A = \frac{\lambda_1}{(c\chi_T\sqrt{\lambda_1^{\text{eff}}})^2} = 8.52\times10^{15}\ \text{m}^{-2}$$

| ΔL | Δη | δ_φ |
|---|---|---|
| 0 | 0 | **0.347 rad**（上限）|
| 10 nm | 0.047 | 0.20 rad |
| 21.5 nm | 0.1 | 0.092 rad |
| 100 nm | 0.47 | 5.8×10⁻³ rad |
| 200 nm | 0.93 | 1.5×10⁻³ rad |

信号集中在 ΔL < 100 nm（δ_φ > 5×10⁻³ rad），且无自由参数（A 由 λ₁、χ_T、c 决定）。

### 4.2 统计预算（命题 10.52.4.02）

条纹拟合相位精度 δφ ≈ 1/(V√N)，V ≈ 0.97（2602.16350 双光子可见度）。要分辨 ΔL = 200 nm 处的 δ_φ = 1.5×10⁻³ rad（10 倍信噪 → 相位精度 1.5×10⁻⁴ rad）：

- N = 1/(V·δφ)² ≈ 4.7×10⁵ 符合计数/点（10 倍信噪）
- 40 kHz 符合率（2602.16350）→ 每点 ~12 s
- 20 点 → ~4 min 采集 + 锁定/扫描开销 → **总测量 ~10–30 min**

ΔL < 30 nm 区间的强信号（δ_φ > 0.1 rad）只需 ~10²–10³ 计数——统计上先出结果，弱信号区（>100 nm）用于形状约束。

### 4.3 系统误差控制

- 单光子通道同时锁定与校准（2Φ₁ 基准自带相位漂移补偿——common-mode 消除）
- 法拉第镜偏振补偿；消声室温度稳定（2602.16350 已达 99.3%/97.4% 可见度）
- 残余泵浦抑制（级联 DWDM，2602.16350 方案）

## §5 预言与判定表（命题 10.52.5.01）

| 观测 | 判定 |
|---|---|
| 残差 δ_φ(ΔL) ≠ 0，拟合 ½log(1+1/(AΔL²+1)) 成功，单光子残差 = 0 | **证实**（映射成立下，A 值检验通过）|
| 残差 ≠ 0，log 形状成立但 A 偏离（>2σ）| 部分证实——形状确认、映射（χ_T 翻译）需修正 |
| 残差 ≠ 0 但形状不匹配 | 时间纠缠相位通道存在但机制/映射需修正 |
| 残差 ≡ 0（精度 1.5×10⁻⁴ rad）| **排除**（时间纠缠相位通道）|
| 单光子残差 ≠ 0 | 系统误差或新效应——先排查装置 |

## §6 风险与备选

1. **映射不确定性（最大风险）**：Δη ↔ ΔL 依赖 χ_T 作为双光子时间差的翻译标度——推断级（6.6 §7.2 标注"非全部定理级"；§8.2 Σ↔ℝ³¹ 桥未建）。缓解：判定分层（形状检验映射无关；A 值检验映射相关）；若 χ_T 不适用，预言曲线整体平移/缩放，log 形状仍是判别特征。
2. **波包重叠**：亚微米路径差 ≪ 相干长度（~数百 μm）——干涉对比度不受影响；HOM 聚束可见度 97.4% 已达标。
3. **色散**：近简并对在光纤 MZ 中的色散差异——评估：若影响相位提取，改用自由空间 MZ 或色散补偿。
4. **信号上限**：ΔL → 0 处 δ_φ → 0.347 rad 需波包完全重叠且 Δξ = 1/√λ₂——实际 Δξ 由光子对的相关性决定（SPDC 近简并对的 ξ 共享程度未知）——上限值本身是待测量，不强加。
