# 双光子双缝干涉的相位敏感检验：10.50 预言的可执行实验方案

**编号**：10.52 | **日期**：260812 | **系列**：应用（时间纠缠→量子光学实验接口） | **语言**：CN | **性质**：实验方案

**摘要**：本文给出 10.50 预言（双光子干涉中的附加几何相位 δ_φ = S_ent）的可执行实验方案——**双光子双缝干涉（双光子杨氏干涉，Ghosh–Mandel 1987 型）**。原理：SPDC 简并对（810 nm）同时通过同一双缝，符合计数 R_c(x₁,x₂) 携带二阶关联条纹（可见度理论可达 100%）；预言 δ_φ 作为条纹相位的附加偏移出现。**装置为桌面级 DIY（淘宝组件 ~4000 元）：405 nm 激光二极管泵浦 BBO + 教学双缝 + 2×SiPM（TEC）+ FPGA 符合计数——无压电延迟线、无 Michelson、无 EOM**——双缝几何的光程差沿屏面自然展开，扫描探测器位置 x 即扫描装置光程差。判别判据（同步扫描 x₁ = x₂ = x）：**和条纹（两光子同过缝 A vs 同过缝 B）相位相对几何预期的偏移 = ½log2 = 0.347 rad 常数（上限检验——同步扫描下相关组合的时刻间隔恒为 0，无 χ_T 映射依赖）**；标准量子光学（含 arXiv:2403.04432）预言偏移 = 0——约 10σ 判别。差条纹（分过 A/B vs B/A）偏移在对称配置中抵消 = 0——装置对称性对照。统计预算：相位精度 0.035 rad 需 ~1.7×10⁵ 符合计数/点，kHz 符合率下每点 ~3 min，40 点总测量 ~2 h（上限检验区先行，~30 min 出结果）。判定分层：上限检验（模型无关）→ 对称性对照 → 非零偏移的 Δξ 标度修正（若实测 ≠ 0.347）。

## §1 目标与判别判据

**目标**：检验 10.50 的预言——双光子干涉条纹携带附加几何相位

$$\delta_\varphi(\Delta\eta, \Delta\xi) = \frac{1}{2}\log\left(1 + \frac{1}{\lambda_1(\Delta\eta)^2 + \lambda_2(\Delta\xi)^2}\right), \quad \Delta\xi = \frac{1}{\sqrt{\lambda_2}}$$

（命题 10.50.2.01，几何相位机制）。标准量子光学（含 arXiv:2403.04432 的完整时间纠缠理论）预言**无此相位**——干涉条纹相位均由路径差线性决定（命题 10.50.5.02 对照）。

**双光子双缝的条纹结构**（Ghosh–Mandel 1987）：SPDC 对（s、i）同时产生，各自经过缝 A 或缝 B 后到达探测器 D₁(x₁)、D₂(x₂)。符合率含四个路径组合——AA（s、i 同过 A）、BB（同过 B）、AB（s 过 A、i 过 B）、BA（s 过 B、i 过 A）：

- **和条纹**（AA↔BB 干涉）：相位 Φ_sum(x₁,x₂) = −kd(x₁+x₂)/D（k = 2π/λ，d 缝间距，D 缝屏距，近轴近似）
- **差条纹**（AB↔BA 干涉）：相位 Φ_diff(x₁,x₂) = kd(x₂−x₁)/D
- **单光子频率项**（AA↔AB 等交叉项）：相位 ∝ kdx₁/D 或 kdx₂/D——频率为和/差条纹之半

**同步扫描（x₁ = x₂ = x）的"两个时刻"间隔**（预言自变量 Δη 的装置映射，命题 10.50.4.01，推断级）：

| 组合 | 时刻间隔 | Δη |
|---|---|---|
| AA | \|(x₁−d/2)² − (x₂−d/2)²\|/(2Dc) = 0 | 0 |
| BB | \|(x₁+d/2)² − (x₂+d/2)²\|/(2Dc) = 0 | 0 |
| AB | \|(x₁−x₂)(x₁+x₂) − d(x₁+x₂)\|/(2Dc) = dx/(Dc) | dx/(D·cχ_T√λ₁^eff) |
| BA | 同上（对称）| 同上 |

**判别判据**（命题 10.52.3.01）：同步扫描下——

1. **和条纹相位偏移**（主判据）：δ_φ^sum = Φ_sum(x) − Φ_sum^geo(x)，其中 Φ_sum^geo = −2kdx/D 为几何预期（d、D、λ 独立标定）。预言：**δ_φ^sum = ½log2 = 0.347 rad 常数**（AA、BB 组合时刻间隔恒为 0 → Δη = 0，无 χ_T 映射依赖；上限值 0.347 对应 Δξ = 1/√λ₂，若实测非零但 ≠ 0.347 则 Δξ 假设需修正——非零即证实时间纠缠通道）。标准预言：δ_φ^sum ≡ 0。
2. **差条纹零偏移**（对称性对照）：AB、BA 组合时刻间隔相等（对称）→ 预言偏移在干涉项中抵消 → δ_φ^diff ≡ 0（框架与标准预言一致）——验证装置对称性与 Fourier 分离正确性。
3. 单光子频率项提供同数据集内部基准（x → 0 区域偏移 → 0），与几何基准交叉验证。

**同一装置、同一噪声条件、同数据集内比较**——内置零基准。

**文献现状与测量空白**：双光子双缝干涉已有多个实验先例——Ghosh–Mandel 1987 首次证明双光子符合条纹的非经典性；Hong–Noh 1998 在"两光子分过两缝"配置下测量符合条纹；Peeters et al. 2009 调控双缝后的空间量子关联。但这些工作测量的都是条纹可见度（非经典性证明）与空间关联结构——**从未标定条纹相对几何预期 −2kdx/D 的绝对相位**。已发表数据不可直接用于本方案判据：① 绝对相位零点未标定（归一化过程抹掉相位信息）；② 统计量 ~10³–10⁴ 符合/点（相位精度 ~0.1–0.3 rad，无法分辨 0.347 rad 偏移）；③ 配置不匹配（多为固定-扫描或二维符合图，同步扫描 x₁ = x₂ = x 非标准配置）；④ 原始数据不公开。相应地，**预言也未被任何已有实验排除**——已发表数据点大多位于 Δη > 2.3 区（预言偏移 < 0.05 rad，低于其相位精度），中心区（Δη < 2.3）的绝对相位从未被测量。因此本方案的核心测量——和条纹绝对相位相对几何预期的标定（δ_φ^sum = Φ_sum − Φ_geo）——**是文献空白**：据我们所知，这是首次将双光子杨氏条纹的绝对相位（相对几何预期）作为测量对象。

## §2 装置设计

### 2.1 为何双缝而非干涉仪（命题 10.52.2.01）

预言敏感区 Δη ∈ [0.05, 2.3] 对应装置光程差 ΔL ∈ [10, 500] nm——此前方案（本文章前版）需压电亚微米延迟线（Michelson/MZ 配置）。**双缝几何将光程差沿屏面天然展开**：缝屏距 D = 1 m 下，探测器位置 x 与光程差的关系由缝间距 d 标定（ΔL ~ dx/D），x ∈ [0, 8] mm 即覆盖 ΔL ∈ [0, 800] nm——**无需任何延迟线组件**。且二阶关联（符合）条纹在双缝中由 SPDC 对的能量-时间纠缠自动产生（Ghosh–Mandel 1987 先例，理论可见度 100%）——不需要单光子参考通道（单光子频率项来自同一符合数据集）。

## §3 测量协议

1. **对准与标定**：强光（405 nm 泵浦的残余 SHG 或 LED 白光）直照双缝，手机相机拍摄双缝条纹标定 d、D（条纹周期 λD/d 的独立测量，~0.5% 精度）；随后转入单光子模式（泵浦 ~1–10 mW，符合率 ~kHz）
2. **扫描（同步）**：x₁ = x₂ = x，x ∈ [0, 8] mm，步长 0.2 mm（和条纹周期 4.05 mm → 每周期 ~20 点）；每点驻留至 ≥1.7×10⁵ 符合计数（分钟级）
3. **采集**：FPGA 同时记录单计数 R₁(x)、R₂(x) 与符合计数 R_c(x)；单计数用于强度归一化与装置监测
4. **Fourier 分离**：R_c(x) 分解为 0 频（直接项，归一化基准）、kdx/D 频（单光子频率项，内部基准）、2kdx/D 频（和条纹）——频率 1:2 干净分离；差条纹（同步扫描相位恒定）表现为慢调制基线，与 0 频一同处理
5. **相位提取**：和条纹分量相位 Φ_sum(x) 线性拟合——斜率标定几何预期 −2kdx/D，**截距 = 偏移 δ_φ^sum**（斜率/截距分离，几何标度误差不影响偏移提取）；单光子频率项相位 Φ₁(x) 交叉验证（x < 1 mm 区偏移 → 0）
6. **对称性对照**：差条纹慢调制基线拟合——偏移应为 0（对称抵消），非零则装置不对称（检查双缝、探测器对准）
7. **Δξ 标度修正**：若 δ_φ^sum = δ₀ ≠ 0.347（非零），按 δ₀ = ½log(1+1/(λ₂(Δξ)²)) 反推 Δξ 实验值——与 1/√λ₂ 比较

## §4 参数预算与精度

### 4.1 预言值（命题 10.52.4.01）

同步扫描下和条纹偏移（主判据）：

$$\delta_\varphi^{\text{sum}} = \frac{1}{2}\log\left(1 + \frac{1}{\lambda_2(\Delta\xi)^2}\right) = \frac{1}{2}\log 2 = 0.347\ \text{rad} \quad (\Delta\xi = 1/\sqrt{\lambda_2})$$

与 x 无关（常数）——上限检验，无 χ_T 映射依赖（仅依赖 Δξ 假设）。标准量子光学：δ_φ^sum = 0。**判别信号 0.347 rad ≫ 相位精度 0.035 rad——约 10σ**。

### 4.2 统计预算（命题 10.52.4.02）

和条纹相位拟合精度 δφ ≈ 1/(V√N)，V ≈ 0.7（保守估计；Ghosh–Mandel 型实验理论可见度 100%，实际受模式匹配与 SiPM 均匀性限制）。要分辨 0.347 rad 偏移（相对 0）以 m = 10 信噪，需相位精度 0.035 rad：

- N = (10/(0.7×0.035))² ≈ 1.7×10⁵ 符合计数/点 → kHz 符合率下 ~3 min/点 → 40 点 ~2 h（全程扫描）
- 若仅上限检验区（x ∈ [0, 2] mm，10 点）：~30 min
- **设计取全程 40 点 ~2 h**；上限检验区数据先行分析（30 min 内出结果）

### 4.3 系统误差控制

- **几何标定**：d、D、λ 独立标定（强光条纹 + 卷尺 + 波长已知）~0.5% → 和条纹相位标度误差 ~0.5%×2kdx/D（x = 8 mm 处 ~0.08 rad）——但偏移是**截距**（常数），线性拟合分离斜率/截距，斜率误差不影响截距提取（偏移精度 ~0.01 rad 级）
- **SiPM 面积平滑**：0.3 mm 狭缝 → 可见度损失 sin(π×0.3/4.05)/(π×0.3/4.05) ≈ 0.99（可忽略）
- **偶然符合**：FPGA 窗口 5 ns，暗计数（TEC 制冷 ~10 kHz）→ 偶然符合率 ~1 Hz ≪ 真符合 ~kHz
- **强度漂移**：直接项（0 频分量）逐点归一化，消除泵浦/效率慢漂移
- **相位漂移**：装置无活动相位元件（无压电）——机械稳定性由铝底板 + 短光路保证；测量为统计平均，慢漂移平均掉

## §5 预言与判定表（命题 10.52.5.01）

| 观测 | 判定 |
|---|---|
| 和条纹偏移 δ_φ^sum = 0.347 rad（±0.035），差条纹偏移 = 0 | **证实**（Δξ = 1/√λ₂ 假设下，上限检验通过）|
| 偏移 0 < δ₀ < 0.347（非零但 < ½log2）| 部分证实——时间纠缠通道存在，Δξ 假设需修正（按 §3 第 7 条反推 Δξ）|
| 偏移 = 0（精度 0.035 rad）| **排除**（时间纠缠相位通道）|
| 偏移 ≠ 0 且 > 0.347 | 超出 Δξ 假设范围——机制或映射需重新审视 |
| 差条纹偏移 ≠ 0 | 装置对称性破坏/系统误差——先排查（双缝、对准）|

## §6 风险与备选

1. **可见度不足**：模式匹配（SPDC 空间模式 vs 双缝）不理想时 V < 0.5——缓解：泵浦光斑 ~1 mm ≫ d = 100 μm（两缝都被照射）；Ghosh–Mandel 先例验证可行；V 是拟合参数，不影响偏移提取（仅影响精度）
2. **和/差条纹 Fourier 分离**：频率 1:2 干净分离（周期 4.05/8.1 mm）——扫描范围 ≥ 2 周期保证频率分辨
3. **上限值依赖 Δξ 假设**：0.347 对应 Δξ = 1/√λ₂——但判别不依赖精确值（非零即证实；§5 分层）
4. **曲线检验缺失**：同步扫描下和条纹 Δη ≡ 0——δ_φ(Δη) 曲线需非对称扫描（x₂ ≠ x₁）+ 组合平均模型细化（AB/BA 组合的偏移不再抵消，需逐组合建模）——列为后续工作；**上限检验已构成判别**（0.347 vs 0，10σ）
5. **备选方案**：若双缝方案受挫（可见度/对准不可克服）——压电亚微米延迟线 Michelson 方案（本文章前版主方案，git 历史 9511fcb5 完整保留）作为备选——判据结构相同（上限检验 + 对称性对照），仅装置复杂度高一个量级
