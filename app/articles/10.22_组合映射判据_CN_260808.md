## 摘　要

10.21 建立映射形式谱（深度带 → 形式）并给出修正猜想：映射形式 = 因果闭合所用算子类型。本文在其上增加第二个自由度——**提取层**（从信息层定理的哪个数学对象提取物理量），提出组合判据：

> **映射规律由二元组 (C, X) 唯一确定**：
> - C（闭合算子）：定理如何闭合自身因果链——决定**映射形式 F**（常数/量子化/场方程/结构/统计）；
> - X（提取层）：从定理的哪个几何对象提取——决定**物理对象 O**（质量/耦合/周期表/场/常数……）；
> - C 与 X 独立：同一 C 不同 X 给出不同物理对象（热核展开五系数 → 五类物理）；同一 X 不同 C 给出不同物理对象（编码权重 σ → 质量 m∝√σ via 代数归一化；σ → α⁻¹ via 级数收敛 + 变分）。

对 29 条有物理映射的定理逐条标注 (C, X) 二元组（第2章表），给出四方向独立性证据（第3章），并回答 10.21 开放问题 O4 的一部分：**扇出度 = 同一闭合算子下可提取的独立几何对象数**——0.8.3.x 的 5 个热核系数是 5 个独立几何对象 → 扇出 5；1.5 §3.7 的谱展开 $S(\sigma^*)$ 是同一常数 α 的单一映射 → 扇出 1。

## 第1章　判据陈述

### §1.1　从单自由度到双自由度

10.21 的映射形式谱（观察 10.21.8.02）与修正猜想（猜想 10.21.8.03）给出单自由度判据：

> 映射形式 F = f(闭合算子 C)，因果深度 d 决定 C 的复杂度层级。

该判据只解释"形式"（公式长什么样），不解释"对象"（公式对应哪个物理量）。对象由什么决定？本文的回答：**由提取层 X 决定**——从信息层定理的哪个几何对象提取，物理层就得到哪个物理量。

**定义 10.22.1.01（组合映射判据）**：设信息层定理 T 的因果闭合算子为 C，物理提取对象为 X。则 T 的物理映射由二元组 (C, X) 唯一确定：

$$
T \xmapsto{(C, X)} (F, O)
$$

其中 F = 映射形式（由 C 决定），O = 物理对象（由 X 决定）。

## 第3章　独立性检验

### §3.1　同一 C、不同 X → 不同 O

- **热核展开算子** × {a₀, a₂, a₄, a₆, a₈} → 五个不同物理对象（宇宙常数、引力、Yang–Mills、Higgs、CS 项）。同一算子、同一谱作用量 S(D) = Tr f(D/Λ)，五个系数是五个独立的几何对象（体积/曲率/规范/标量/拓扑）——映射形式同为"场方程/数值"，物理对象完全不同。
- **谱展开算子** × {σ*} → α⁻¹ = 137.036（1.5 §3.7）。单一几何对象映射到单一常数——物理对象为 α（扇出 1）。
- **环路积分算子** × {Berry 曲率, 闭环积分, 指标} → 量子化电导（0.3.2.01）、Bohr–Sommerfeld（0.4.4.01）、量子数（0.7.3.01）。同一算子、不同被积对象 → 不同量子化对象。
- **代数运算算子** × {体积元, 半单分裂, 复结构, 终端二元性, 权重} → γ₅、Λ、ΔΘ、k₀、混合态分解。同一算子、不同代数对象 → 不同结构常数/分解。

### §3.2　同一 X、不同 C → 不同 O

**编码权重 σ 的双通道**：

- 通道一（C = 代数归一化，Born 提取）：σ ↦ Δλ = C√σ（归一化 2pC³ + C² = 1，定理 1.4.3.01）→ **质量谱 m ∝ √σ**；
- 通道二（C = 级数收敛 + 变分，Spectral 提取）：作用量 S(σ) 极小值（κ = 1 定型，定理 1.5.2.01）→ **α⁻¹ = S(σ*) = 137**。

同一提取对象 σ，两个闭合算子、两个物理量。这是独立性最干净的证据——它同时说明：**同一信息层对象可以承载多个物理映射，通道由闭合算子区分**。

### §3.3　小结

**命题 10.22.3.01（二元组独立性）**：闭合算子 C 与提取层 X 为映射的两个独立自由度。C 决定映射形式 F，X 决定物理对象 O；联合决定映射 (F, O)。（基于 32 条样本的初步检验；单射性见 §7.1。）

## 第4章　扇出度：独立提取对象数

### §4.1　判据

**命题 10.22.4.01（扇出度判据）**：定理 T 的扇出度 = 同一闭合算子 C 下可提取的独立几何对象数 |{X}|。

扇出度不是参数空间维数，而是**展开系数的几何独立性个数**：

- 0.8.3.x：热核展开的 5 个系数 a₀, a₂, a₄, a₆, a₈ 是 5 个独立几何对象（体积/曲率/规范/标量/拓扑）→ 扇出 5；
- 1.5 §3.7：谱展开 $S(\sigma^*)$ 映射到单一常数 α（同一对象）→ 扇出 1。

### §4.2　对 10.21 O4 的回答

10.21 开放问题 O4："扇出度是否本身是几何性质？是否等于参数空间的维数？"本文回答：

- 扇出度是几何性质（= 独立提取对象数）；
- 不等于参数空间维数（0.8.3.x 的参数空间为编码轨道，扇出为 5；1.5 §3.7 的参数空间为观测者位置，扇出为 1）；
- 等于闭合算子展开中独立几何对象的个数——由谱作用量/级数的展开结构决定。

## 第5章　边界案例再解释

### §5.1　0.4.4.01（深度 9，量子化形式）

10.21 §8.4 记为"反例或特例"：深度 9 按"深 → 连续动力学"应为场/数值带，实为量子化（离散）。组合判据给出解释：0.4.4.01 的闭合算子为**环路积分**（∮A = 2πn 的闭环积分），属中层算子——**形式由算子决定，不由深度带决定**。深度 9 只说明它位于因果链深层（复杂度高），不改变其算子类型。

### §5.2　3.8.2.02/04（环内锁定）

10.21 §8.4：环结构"锁定"映射形式。组合判据：环内定理的闭合算子由环的相互引用固定（3.8.2.02 ↔ 3.8.2.04 双向依赖）——算子为变分/谱，映射为连续（谱间隙/平衡态）。环的存在使 C 无选择余地——**互扼环是闭合算子的锁定机制**。

### §5.3　形式 = 算子，层级 = 深度

两个边界案例共同支持：**映射形式 F 由闭合算子 C 决定（与深度无关）；因果深度 d 决定 C 的复杂度层级**。此与猜想 10.21.8.03 一致，且组合判据多出的 X 自由度不参与形式决定——C 与 X 的分工在边界案例中进一步清晰：C 管形式，X 管对象。

**关键条件：X 必须标到"结构对象"级**——半单分裂、复结构、终端二元性、各阶热核系数 a_k、各阶级数项 B_k、体积元（ω₃/ω₅/ωₙ 分别标注）。若 X 粗化为"展开系数"或"代数结构"，单射性立即破坏（同一 (热核展开, 系数) 将对应 a₀–a₈ 五个物理对象）。X 的细分粒度 = 展开/分解中独立几何对象的具体性——与第4章扇出度判据一致（扇出度 = 独立 X 的个数）。

**纤维化观察**：全表显示 X 并非在 C × X 全空间中自由选取——**X 属于 C 的展开/分解结构的独立项集合**（热核展开算子的 X ∈ {a₀, a₂, a₄, a₆, a₈}；级数求和算子的 X ∈ {B₀, …, B₅, 部分和, 截断}）。σ 双通道（§3.2）不构成反例：两通道的 X 实为不同对象（σ 本身 vs 作用量极值 S(σ*)）。故 (C, X) 的独立是"纤维上的独立"：C 决定展开结构（纤维），X 从纤维中选取。此观察同时解释了第4章扇出度判据：扇出度 = 纤维中独立 X 的个数。

**检验边界**：定义类 6 条（#94、#113–116、#263）无物理映射（O = —），不参与单射性检验；C 的 6 类与 X 的结构对象级标注含分类主观成分，但映射描述均有文章原文依据（10.21 §7 映射表），可复核。

### §7.2　算子表完备性

已识别 6 类算子（级数求和/环路积分/热核展开/代数运算/算法复杂度/不动点自指）。是否还有第七类（随机过程、测度论、范畴论算子）？完备性未证——若某定理的闭合机制不属任何已知类，算子表需扩展。

### §7.3　路径步数与深度-路径关联

**定义 10.22.7.02（路径步数 s）**：设定理 T 的闭合算子为 C，提取层 X 位于观测映射链第 i 层（i ∈ {1, 3, 4}；M₂ 无提取对象，M₅ 为可观测化终点）。T 的路径步数 s(T) 为沿 C 的标准路径从 X 所在层到 M₅ 的箭头数：

- **完整链**（C = 代数运算、数论/格论、组合运算、不动点/自指）：M₁→M₂→M₃→M₄→M₅，s = 4；
- **量子化路径**（C = 环路积分、谱构造）：M₃→M₄→M₅，s = 2；
- **桥梁路径**（C = 热核展开）：M₃→M₄→M₅，s = 2（a_k 是 Spec(D) 的几何展开——谱直接给场方程）；
- **捷径路径**（C = 级数求和、变分、算法复杂度）：X→M₅ 直接，s = 1。

s 是 C 的精确函数（由定义保证），与因果深度 d 无直接函数关系。

**观察 10.22.7.03（深度-路径统计关联）**：对 39 条有深度数据的映射定理（26 条原样本 + #285–#297 十三条，深度按依赖链最长路径递推），按深度带统计 s 的分布：

- 浅层带（d = 1–4）：**s = 4 占 100%**（8 条全为完整链——公理、0.1.3.06、0.2.1.01/02、0.2.2.01–03、2.1.2.01）；
- 中层带（d = 5–7）：s = 2 占 47%（7/15）、s = 1 占 33%（5/15）、s = 4 占 20%（3/15）——混合区（#285/#286 加入完整链）；
- 深层带（d = 8–9）：s = 2 占 43%（6/14）、s = 4 占 36%（5/14）、s = 1 占 21%（3/14）——原“无 s = 4”由 #287/#288/#294/#295/#297 五条推翻：深层带为结构通道（代数/组合 → 完整链）与数值通道（热核/级数/变分 → 短路径）双通道并存；
- 超深带（d = 10）：新现 2 条（#291 完整链、#296 捷径）——代数结构通道可深入 d = 10。

**强形式 d + s = 8 不成立**（25 条中仅 7 条命中：0.2.2.01–03、2.1.2.01（4+4）、0.3.2.01、0.7.1.01（6+2）、3.8.2.04（7+1）；未命中散布 5–11）。候选常数 8 的诱惑（Bott 周期）未获数据支持——明确放弃。

**命题 10.22.7.04（s 的精确性）**：s(T) 由 C 精确决定（定义性）；d 与 s 的关联是二阶统计（经“深度带 ↔ 算子类别”）：浅层带 → 代数算子 → 完整链（s = 4）；中层带 → 环路/谱算子为主 → 量子化路径（s = 2）；深层带 → 热核/级数/变分算子 → 短路径（s ∈ {1, 2}）。#285–#297 加入后，深层带的算子分布修正为双通道并存：代数/组合算子可深入 d = 8–10 并走完整链（s = 4），与热核/级数/变分算子的短路径（s ∈ {1, 2}）并列——“深度带决定算子分布”降级为趋势而非定律，算子类别可超越深度带（强相互作用扇区定理即此例）。边界案例（0.4.4.01：d = 9 但 s = 2）与 10.21 §8.4 深度-形式错位案例同步——s 的异常与深度带的异常同步发生，支持“算子决定路径、深度带决定算子的统计分布”的两层结构。

**预测价值**：(d, s) 构成定理的映射坐标——d 给复杂度层级，s 给映射路径类型。对任意新定理，只需识别闭合算子即可精确确定 s ∈ {1, 2, 4}（与 d 无关）；d 的带给出 s 的统计期望。1.x 系列（C = 代数运算）预测 s = 4——完整链路径（经 Born 法则到质量谱），与 §6.2 预测一致。

**开放问题**：深度带"约 2 层一级"间隔的起源仍未解（与 δ 迭代或 Clifford 周期 8 = 2³ 是否同源待研究；锚点序列 θ_I = 32.07° → 55.0° → 72.53° 的间隔 22.93° → 17.53° 递减，与信息扇区独立自由度的关系待研究）；s 的三值离散化（1/2/4）是映射链层结构（捷径/桥梁/完整链）的必然结果，还是存在更细的中间路径，待形式化；2.1.3.01（d = 5，s = 4）与 #285（d = 7）、#286（d = 6）构成中层带三条完整链定理——代数求值算子经 Born 法则直达质量谱（2.1.3.01）与代数结构算子直达对称性（#285/#286）的通道区分待统一解释。

### §7.4　提取层分类——映射链分层（已形式化，2026-08-05）

对 5.4 观测映射链五阶段（M₁: σ → M₂: Δλ = C√σ → M₃: Spec(D) → M₄: {m, g, …} → M₅: O）与附录 B 的 96 条标注表对照，X 的分类获得理论来源：

**命题 10.22.7.01（映射链分层）**：闭合算子 C 的操作对象域（纤维）按观测映射链分层：
- **编码层（M₁）**：C ∈ {代数运算, 级数求和, 数论/格论, 组合运算, 算法复杂度, 不动点/自指}——X ∈ 编码结构对象（σ、θ、半单分裂、体积元、级数项 B_k、测量序列……）；
- **谱层（M₃）**：C ∈ {环路积分, 谱构造, 热核展开, 变分（谱泛函）}——X ∈ 谱的几何对象（Berry 曲率、闭环积分、Fredholm 指标、谱三元组、谱间隙 λ₁、热核系数 a_k）；
- **物理层（M₄/M₅）**：C ∈ {变分（作用量求值）, 级数求和（求值）}——X ∈ 作用量/可观测对象（S(σ*)、凸性域、Σ_joint）。

**映射路径**：不同 C 走不同路径——
- 代数运算：**完整链**（M₁→M₅ 全程，经 Born 法则）——1.x 系列的 σ 通道即此；
- 热核展开：**桥梁**（M₃→M₄——谱的几何化直接给场方程）——扇出度最高（5 个独立系数 a₀–a₈）；
- 级数求和：**捷径**（M₁→M₅——编码自洽闭合直接给常数）；
- 环路积分：**拓扑量子化**（M₃→M₄）；
- 变分：**作用量极值**（M₁/M₃→M₅）。

**纤维化的理论来源**：C 是映射链中某路径的对象化操作，X 是该操作的展开项——操作类型决定对象域（纤维），对象域按映射链分层。σ 双通道（§3.2）由此获得更精确表述：不是两个独立自由度，而是**同一源头对象 σ 在链上不同位置的提取**（M₁ 的 σ 本身 vs M₄/M₅ 的作用量 S(σ*)）——(C, X) 的"独立性"实为映射链分层的体现，正交性获得结构来源。

**深度-路径趋势**：因果深度 d 与映射路径长度呈反比趋势——深层定理（d = 7–9，热核/级数）走捷径/桥梁直接给物理；浅层定理（d = 1–4，代数结构）走完整链只给结构。强形式"d + 路径步数 = 常数"未获支持（0.2.1.02：d = 3，X 在 M₁，3 + 4 = 7 ≠ 8）——趋势可靠，精确定义与完整检验见 §7.3（定义 10.22.7.02、观察 10.22.7.03、命题 10.22.7.04）。
