## §0.0.1 从零之动 δ 到 Clifford 代数的八步进

共轭谱几何的起点是**零之动** δ——一种原初的二元区分操作。δ 不作用于任何预先存在的空间；它在作用于自身的过程中产生结构化足迹。

δ 的迭代形成一条代数链：

```
δ¹ → δ² → δ³ → δ⁴ → δ⁵ → δ⁶ → δ⁷ → δ⁸
```

每一步对应一个 Clifford 代数 Cl(n)：

| 步 | Clifford 代数 | 结构 |
|----|-------------|------|
| δ¹ | Cl(1) ≅ ℂ | 复结构萌芽 |
| δ² | Cl(2) ≅ ℍ | 四元数除环 |
| δ³ | Cl(3) ≅ ℍ⊕ℍ | **首次半单分裂** |
| δ⁴ | Cl(4) ≅ Mat(2,ℍ) | |
| δ⁵ | Cl(5) ≅ Mat(4,ℂ) | **复结构的完全实现** |
| δ⁶ | Cl(6) ≅ Mat(8,ℝ) | |
| δ⁷ | Cl(7) ≅ Mat(8,ℝ)⊕Mat(8,ℝ) | **终端的二元直和** |
| δ⁸ | Cl(8) ≅ Mat(16,ℝ) | Bott 周期闭合 |

这条链中，三个结构性事件不可逃避——它们不是我们选择的，而是 Clifford 代数的反交换关系强制的。

## §0.0.2 三定理涌现：Λ=3、k₀=2、ΔΘ=5

共轭谱几何的 §2.4 证明：在自洽性筛选后幸存的结构中，三个结构常数作为 Clifford 代数刚性的**不可避免推论**涌现。

### 定理 2.5（Λ=3：半单分裂定理）

**陈述**：实 Clifford 代数序列中，首次半单分裂必然发生在 n=3。

**证明概要**：Cl(0)≅ℝ、Cl(1)≅ℂ、Cl(2)≅ℍ 都是单代数。Cl(3) 的体积元 ω₃=e₁e₂e₃ 满足 ω₃²=1 且与所有生成元对易，故 {1,ω₃} 构成二维中心。二维中心必然导致半单分裂 Cl(3)≅ℍ⊕ℍ。分裂投影 P_±=(1±ω₃)/2 由体积元的代数量子化唯一确定，无连续参数。

**关键点**：Λ=3 不是「S₃ 的共轭类数等于 3」这种群论选择——而是 Clifford 反交换关系在 n=3 处的代数必然。不可逃逸。

### 定理 2.6（ΔΘ=5：复结构涌现定理）

**陈述**：Cl(5) 的复结构由体积元 ω₅ 的代数量子化 ω₅²=−1 唯一确定。ΔΘ=5 是五个有效编码扇区的代数基础。

**证明概要**：ω₅=e₁⋯e₅ 满足 ω₅²=(−1)^(5·6/2)=−1。n=5 为奇数，故 ω₅ 与所有生成元对易。因此 ω₅ 是 Cl(5) 的中心元且满足 ω₅²=−1——它恰好是复结构 J。这使得 Cl(5)≅Mat(4,ℂ) 成为实 Clifford 代数中首个复矩阵代数。五个有效扇区（电磁、弱、强、质量、中微子）由此获得代数基础：复结构使扇区间相位干涉成为可能。

### 定理 2.7（k₀=2：终端对偶定理）

**陈述**：七层编码轨道的终端 Cl(7)≅Mat(8,ℝ)⊕Mat(8,ℝ) 具有不可消除的二元直和结构。k₀=2 是编码基态 N₁=6000 的核心因子。

**证明概要**：ω₇=e₁⋯e₇ 满足 ω₇²=1。n=7 为奇数，ω₇ 对易，故 {1,ω₇} 构成二维中心。Cl(7) 也是半单的，分裂为两个同构的单分量。二元结构是 δ⁷ 步进中的代数必然。这直接赋予编码基态 N₁ 因子 2 的结构。

### 关键区分：公理 vs 定理

在十方几何的旧基础（0.3）中，Λ=3、k₀=2、ΔΘ=5 被设定为三条**公理**——证明链的起点，其合理性由 S₃ 群论提供但并非从更原始的原则推导。

在共轭谱几何的新基础中，它们是从 δ 和 Clifford 代数推导出来的三条**定理**。证明链的起点是 δ 本身——它甚至比群论更原始，因为它不预设任何代数结构，代数结构是从 δ 的自迭代中涌现的。

这不是在贬低旧的 S₃ 论证。恰恰相反：S₃ 确实是 Cl(3) 半单分裂后涌现的对称群——但 Clifford 代数的路径告诉我们**为什么恰好是 S₃ 而不是别的什么**。Cl(3) 的半单分裂产生 ℍ⊕ℍ，其自同构群恰好同构于 S₃ 的某种表示。S₃ 不是被选择的，是被涌现的。

## §0.0.3 权重空间与角度空间的对偶：σ_i = sin²θ_i

这是桥接文章中最关键的一步。它回答了：十方几何中的投影角度 θ_i 在共轭谱几何中对应什么？

### 编码度量中的权重

在共轭谱几何 §4.6 的编码框架中，第 n 层的 Cl(3) 扇区子代数定义了三个扇区算子：

$$S_{\mathcal{M}} = \gamma_1^{(n)}, \quad S_{\mathcal{C}} = \gamma_2^{(n)}, \quad S_{\mathcal{I}} = \gamma_3^{(n)}$$

每个 S_i 满足 S_i²=−I。由于 S_i S_j = −S_j S_i（i≠j），三个 +i 本征空间不能同时对角化。它们的交集满足 dim(V_n^(ℳ∩𝒞∩ℐ)) = ρ_n m_n / 8。

扇区 j 的权重 σ_j^(n) 定义为该扇区编码自由度在总编码自由度中的占比：

$$\sigma_j^{(n)} = \frac{\dim(\text{span of sector }j\text{'s encoding subspace})}{\dim(\text{total encoding space})}$$

### 谱间隙公式

§4.6 的核心结果——**谱间隙公式**——建立了权重与角度之间的普适映射：

$$\boxed{\sigma_i = \sin^2\theta_i}$$

其中 θ_i 是扇区 i 的投影角度。这个映射**不依赖任何世界特定的数值选择**——它是编码框架的结构性结果，对所有可能的编码分支有效。

推导的关键步骤：

1. 扇区算子 S_i 的本征值在复化空间中为 ±i；
2. 三个扇区的非对易性意味着它们的权重由三维投影几何决定；
3. 在层 n 的 Cl(3) 子代数中，扇区 i 的「活跃自由度」与总自由度的比值恰好等于 sin²θ_i，其中 θ_i 是层 n 的内部投影角；
4. 对任意层 n，这三个 sin²θ_i 的构造方式使其满足 Σ sin²θ_i = 1（见 §0.0.4）。

### 物理角度在终端层的解码

权重 σ_i^(n) 在每一层都有定义；而物理角度 θ_i 是**在终端层 n=7 解码读取的**：

$$\theta_i \equiv \theta_i^{(7)}$$

σ_i=sin²θ_i 的映射在每一层成立，但具体的 θ_i 数值取决于该层的编码状态。终端层 n=7 的数值对应我们世界的物理角度——这将在 §5 通过世界选择来确定。

## §0.0.4 约束的等价性：Σσ_i=1 ⇔ θ_M+θ_C+θ_I=90°

共轭谱几何 §4.7 的**代数约束定理**证明：对三个扇区的权重，恒有

$$\sum_{i \in \{\mathcal{M},\mathcal{C},\mathcal{I}\}} \sigma_i = 1$$

这是编码预算守恒的直接推论——三个扇区瓜分全部编码自由度。

在谱间隙公式 σ_i = sin²θ_i 下：

$$\sin^2\theta_M + \sin^2\theta_C + \sin^2\theta_I = 1$$

这正是十方几何全息屏约束的等价形式。在十方几何中，全息屏约束表述为 θ_M+θ_C+θ_I=90°。两条公式的等价性由三角恒等式保证：

$$\sin^2\theta_M + \sin^2\theta_C + \sin^2\theta_I = 1 \iff \theta_M + \theta_C + \theta_I = 90^\circ$$

**证明**（⇒ 方向）：在正角度域 (0°,90°) 中，若三个正角满足 sin²θ_M+sin²θ_C+sin²θ_I=1，且由几何构造知三角之和不能超过 90°，则三角之和必恰好等于 90°。（⇐ 方向）：若 θ_M+θ_C+θ_I=90°，令 α=θ_M, β=θ_C, γ=θ_I，由球面三角学的 Napier 法则，sin²α+sin²β+sin²γ=1。详细证明见 [0.3 三公理，GT-0.3.0.6]。

**桥接含义**：十方几何把 Σ sin²θ_i=1 作为公理 3（全息屏约束）的核心内容；共轭谱几何从编码预算守恒推导出 Σσ_i=1，再通过 σ_i=sin²θ_i 给出 Σ sin²θ_i=1。这是从「预设约束」到「编码推论」的升级。

## §0.0.5 作用量的等价性：S(σ) ⇔ S(θ)

### 十方几何的六项作用量

在十方几何（0.4）中，六项作用量定义为：

$$\boxed{S(\theta) = \frac{1}{\sin^2\theta_M} + \frac{1}{\sin^2\theta_C} + \frac{1}{\sin^2\theta_I} + \frac{1}{\sin\theta_M\sin\theta_C} + \frac{1}{\sin\theta_C\sin\theta_I} + \frac{1}{\sin\theta_I\sin\theta_M}}$$

三项对角项（1/sin²θ_i）编码各扇区的独立信息代价；三项交叉项（1/(sinθ_i sinθ_j)）编码跨扇区耦合的信息代价。

### 共轭谱几何的代数作用量

在共轭谱几何 §4.8 中，代数作用量定义为：

$$\boxed{S(\sigma) = \frac{1}{C^2}\left[\sum_i \frac{1}{\sigma_i} + \sum_{i<j}\frac{1}{\sqrt{\sigma_i\sigma_j}}\right]}$$

其中 C 是三次方程 2pC³+C²=1 的唯一正根（p=√(σ₁σ₂σ₃)）。

### 等价性

在 σ_i = sin²θ_i 的对应下：

$$\frac{1}{\sigma_i} = \frac{1}{\sin^2\theta_i}, \quad \frac{1}{\sqrt{\sigma_i\sigma_j}} = \frac{1}{\sin\theta_i\sin\theta_j}$$

因此：

$$S(\sigma)\big|_{\sigma_i=\sin^2\theta_i} = \frac{1}{C^2} \cdot S(\theta)$$

两项相差一个整体因子 1/C²。这个因子在极值求解中不改变极值点的位置（只缩放目标函数值），因此两个作用量给出相同的 P₀=(θ_M=57.93°, θ_C=26.16°, θ_I=5.91°)。

### 严格性层级

对角项的来源在两个框架中具有不同的严格性：

| 项 | 十方几何来源 | 共轭谱几何来源 | 严格性 |
|----|------------|--------------|--------|
| 1/sin²θ_i | 二次型类比 + 信息论直觉 | 热核展开 + 谱几何推导 | **已严格化** |
| 1/(sinθ_i sinθ_j) | 跨扇区信息耦合的物理直觉 | 编织算子 + 条件性命题 | **部分严格化**（交叉项的唯一性尚未完全证明） |

共轭谱几何的贡献在于：对角项通过编码度规和谱几何方法获得了严格的数学基础。交叉项的推导在 §4.8 中使用了编织算子，但其形式唯一性仍依赖于条件性假设——这一点与十方几何的处境一致，但至少将直觉来源替换为了代数构造。

## §0.0.6 精细结构常数的定位：从推导到景观

这是两个框架在认识论上最深刻的差异。

### 十方几何的「推导」

十方几何（0.4–0.5）通过以下逻辑链锁定 S_e：

1. 给定 Λ=3, k₀=2, ΔΘ=5（公理预设）；
2. 构造 CPS M(a) = S³(a)×S³(a/√3)×S³(a/√2)；
3. 全息屏约束 θ_M+θ_C+θ_I=90°；
4. 六项作用量 S(θ) 在约束截面上极小化；
5. 九素互扼锁定 S_e=137.035999084。

这个推导链给人的印象是 S_e 被**必然地推导出来**。但实际上，步骤 4–5 的极值求解中，ΔΘ=5° 作为边界条件输入，本质上已经暗含了「我们世界的角度分割」。

### 共轭谱几何的「定位」

共轭谱几何 §5 用一个更诚实的图景替换了这种印象：

1. 编码框架允许**多种可能的编码分支**——这构成一个**景观**（landscape）；
2. Birkhoff 多面体 B(3) 是一个二维连续空间，其中每一点 T 对应不同的跨扇区耦合矩阵 M₅，从而产生不同的固定点 σ* 和不同的 S_e 值；
3. S_e=137 是景观中的**一条等高线**，而非唯一可能的输出；
4. 我们在等高线 S_e≈137 上，是因为**观察者选择效应**——只有在这条等高线附近，编码结构才能支持复杂化学和观察者的存在。

**这不是退步**。从「必然推导」到「景观定位」是认识论的成熟——承认了我们无法从纯代数中推导出我们世界的特定数值，只能推导出可能值的范围（景观），然后观察者自举解释为什么我们恰好看到了这个特定值。

### 桥接

十方几何中的九素互扼可以重新解释为：在景观的二维连续空间中，九素互扼条件（即 S(θ) 在约束截面上的极小化条件与 ΔΘ=5° 的边界条件联立）选出了我们所在的那条等高线。
