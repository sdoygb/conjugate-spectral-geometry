## 摘　要

将 10.75 三尺度统计刚性猜想应用于人类社会集体行为：把人（国家、受访者）当作随机微观点，集体（区域、国家）作为纤维结构，检验"集体服从底层规律"是否具有严格统计形态。本文记录十一个递进探针（⑤–⑪、⑭、⑮、⑯、⑰）的完整推导与结果：世界银行面板（217 国 7 区域）、WVS Wave 7 个体级数据（95,162–96,700 受访者 66 国）、GDP/教育协变量、制度质量（WGI）/文化维度（Hofstede）、结构级候选（地理集群/语言家族/组合模式）、CEPII 成对地理距离（65 国 2016 对）、WVS 三波纵向匹配（28 国）、ASJP 成对语言距离（66 国 2145 对）。核心结果：**集体层排序稳定性被结构锁定（bootstrap ρ≈0.99，免疫个体重采样），个体层涨落符合中心极限定理（随机条款），且该锁定不可还原为任何标量属性（GDP、教育、制度得分、文化维度）或粗粒度分组（地理、语言、聚类组合）**。几何论读法：宏观集体量由纤维的耦合配置（结构特征值）锁定，标量属性只是该配置的粗糙投影——与探针③"纤维内稀疏化不影响宏观速率"及定理 5.8.3.02 精确平行。成对耦合层确认为锁的载体：地理（Mantel ρ=0.059, p=0.011；共同边界 Δ=−0.257, p=0.005）与语言（ρ=0.105, p=0.033，控制地理后仍 0.085）是两条不可约的独立通道；时间上锁定为有限相关时间（跨波 ρ 0.91→0.65，τ_corr≈20–70 年），结构本身在十年尺度慢演化。战争作为集体输出（探针⑮，UCDP v26.1，66 国）：冲突爆发时间近似随机（ρ=0.238, p=0.16，未锁定）而战死烈度显著锁定（ρ=0.423, p=0.049）——和平=纤维化锁定态、战争=纤维化破缺事件的两态图景确认；国内离散度与冲突烈度正相关（ρ=0.318），与破缺判别预言方向一致。两态转移动力学（探针⑯，UCDP 全窗口 1946–2025，123 国）：单国和平段完全服从几何分布（35 国 0 拒绝，无记忆泊松破缺），冲突段微弱自持（11% vs 名义 5%）；λ_b=0.061/年、λ_r=0.190/年，π_W 理论 0.243 vs 实际 0.215，弛豫 τ≈4.0–4.6 年；破缺判别纵向化方向一致不显著（λ_b×国内 std ρ=0.19, p=0.18）。国家冲突风险排名（探针⑰，UCDP 全窗口）：以历史破缺率 λ_b 为主、结构脆弱修正为辅构造风险分，分三层——Tier A 当前冲突中（37 国，自持非预言）、Tier B 当前和平但历史高破缺率（81 国，预测核心：乍得、津巴布韦、中国前三）、Tier C 无冲突史+结构脆弱（外推）；无记忆性推论下，Tier B 前三与全 81 国已作为可证伪预言正式记录（5 年窗口 2026–2031，UCDP 门槛判定，分层冲突率对比为判别标准）。

## §1 引言：猜想的社会版本与验证目标

10.75 提出三尺度统计刚性猜想：长时间（τ→∞）下高阶累积量按严格指数速率衰减；大范围（N→∞）下重标度收敛到连续极限；群尺度下统计量在对称群作用下零方差。统一表述：**随机化只提供样本多样性，群对称（结构）提供统计确定性——极限下的统计规律是群表示的影子**。

将此猜想移植到人类社会：**把人当作随机微观点，集体（社会结构）服从底层规律**。这一直觉有二百年的思想史（凯特勒"平均人"1835、涂尔干"社会事实"1895），但几何论的目标是给出**严格统计形态**：集体规律 = 纤维化结构锁定的宏观量；个体随机性 = 被结构平均掉的微观涨落。

验证目标（五个递进问题）：

1. **集体规律是否存在**（探针⑤⑥）：集体量是否被结构锁定（排序稳定、方差可分解）？
2. **个体随机性是否进入集体层**（探针⑥）：个体重采样是否扰动集体排序？
3. **锁是什么——标量属性？**（探针⑦⑧）：GDP、教育、制度得分、文化维度能否还原锁定？
4. **锁是什么——结构分组？**（探针⑨）：地理、语言、组合模式能否解开锁定？
5. **几何论预言**（§8）：锁应位于纤维的**耦合配置**层，任何标量标签或粗粒度分组都只是其投影。

## §2 理论框架与判别规则（几何论计算推导）

### 2.1 纤维化结构与谱间隙锁定

定理 5.8.3.02（谱间隙纤维化不变性）断言：在纤维化信息场中，宏观弛豫速率由纤维结构（耦合配置）唯一锁定，纤维内细节（连通度、稀疏化、随机化）不进入宏观层。数值面由探针③确认：纤维化系综的谱间隙逐位不变（std≈3.3×10⁻¹⁴），破缺纤维化后 std 出现。

社会版本射（本报告统一使用）：

| 几何概念 | 探针⑤映射 | 探针⑥–⑨映射 |
|---|---|---|
| 纤维 | 区域（7 个） | 国家（66 个） |
| 纤维内随机点 | 国家（217 个） | 受访者（95,162–96,700 个） |
| 集体量（宏观速率类比） | 区域均值/排序 | 国家均值/排序 |
| 耦合配置 | 区域内的国家集合结构 | 国家内的个体分布结构 |
| 标量属性（非锁候选） | — | GDP、教育、WGI、Hofstede |

### 2.2 判别规则：std(m) 标度律（探针③的移植）

探针③扩展 2 建立判别规则：**刚性 = 集体量涨落 std 随纤维数 m 平坦（结构锁定）；随机 = std/μ ~ m^{-1/2}（中心极限标度）**。数据验证：纤维化系综 std 平坦（1.5×10⁻¹³ → 6.7×10⁻¹⁵），破缺系综 std/μ ~ m^{-1/2}（0.184 → 0.044，与 √(64/4)=4 精确吻合），两者相差约 12 个数量级。

社会版判别：对集体量（国家均值满意度、信任率等），若其跨重采样涨落符合 CLT 预期（随机条款）而跨国家散布远超 CLT 预期且排序稳定（结构条款），则"个体随机、集体锁定"成立。

### 2.3 统计量定义（本报告统一口径）

设 y_{ij} 为第 i 个国家第 j 个受访者的观测值（或第 r 个区域第 c 个国家的长期均值），n_i 为第 i 组样本量，N 为总样本，μ_i 为组均值，μ 为总均值，σ_pooled 为合并标准差。

**(a) 方差分解 η²**（组间解释比例）：

```
η² = SSB/SST = Σ_i n_i(μ_i − μ)² / Σ_{ij}(y_{ij} − μ)²
```

η² = 0.675 表示分组结构解释 67.5% 的总体方差。探针⑥–⑨ 用个体级数据（n_i = 国家内受访者数），探针⑤用国家级数据（n_i = 区域内国家数）。

**(b) CLT 判别比值**（结构 vs 随机）：

```
R = σ_obs / (σ_pooled / √n̄)
```

其中 σ_obs 为观察到的组均值散布（组均值的标准差），σ_pooled/√n̄ 为纯随机采样（组内独立同分布）下组均值的 CLT 预期标准误。R ≫ 1 ⟹ 组间差异远超抽样噪声（结构锁定）；R ≈ 1 ⟹ 组均值只是随机平均（随机条款）。

**(c) 排序稳定性 ρ**（bootstrap）：

对个体级数据：有放回重采样个体（保持国家分组），重算国家均值排序，与原始排序计算 Spearman ρ；重复 200 次取均值。ρ ≈ 1 ⟹ 排序由结构锁定（个体重采样不动排序）；ρ 塌缩 ⟹ 排序由抽样偶然决定。

**(d) 残差化**（探针⑦⑧⑨ 核心操作）：

对协变量 x（GDP、教育、WGI、Hofstede 或分组虚拟变量）：先拟合 y ~ x（或减组均值），取残差 y_resid = y − ŷ，再对残差重算 η²(国家) 与 bootstrap ρ。**若残差化后 ρ 塌缩 → 该变量解释了锁；若 ρ 纹丝不动（仍 ≈0.99）→ 锁不可还原为该变量**。

**(e) 四重检验（G1–G4，探针⑨专用）**：

对结构分组 G：G1 = η²(G) 个体级（分组解释多少个体方差）；G2 = R²(G→组均值)（分组解释多少国家均值方差）；G3 = 组内 bootstrap ρ（≥3 国组，去掉组间差异后组内是否仍锁定）；G4 = 残差化（减组均值）后 η²(国家) 与 ρ。判定：ρ_resid 塌缩 → 分组解释了锁；ρ_resid 仍 ≈0.99 → 锁比该分组更细。

### 2.4 几何论推导的判定逻辑

综合 (a)–(e)：若集体排序 ρ≈0.99 且免疫一切标量残差化与粗粒度分组残差化，则几何论断言**锁位于纤维的完整耦合配置层**——即定理 5.8.3.02 中决定宏观速率（特征值）的纤维结构本身，而非任何可标签化的属性。这与零方差定律（定理 0.9.4.02：结构对称 ⟹ 统计量逐样本不变）同构：**排序稳定性 = 集体层统计量的零方差形式**。

## §3 探针⑤：世界银行面板——区域纤维、国家随机点

### 3.1 数据与设计

- **数据源**：世界银行开放数据 API（https://api.worldbank.org）
  - SP.DYN.TFRT.IN 生育率（1960–2025，17,490 行）
  - SP.DYN.LE00.IN 预期寿命（1960–2025，17,490 行）
  - 国家元数据含区域分组：217 真实国家、7 区域（已排除 Aggregates 聚合体）
- **映射**：纤维 = 区域（7 个）；微观随机点 = 国家（区域内 n_r 个）；时间 = 1960–2023；国家长期水平 μ_c = 时间均值；集体量 = 区域均值 M_r 与排序
- **判别**：探针③扩展 2 的 std(m) 标度律——刚性 = 集体量被结构锁定；随机 = 集体量只是微观平均（涨落 ~1/√n）

### 3.2 推导过程

**检验 1（排序稳定性）**：将时间分成前半（1960–1990）与后半（1991–2023），分别计算国家（区域）长期水平，求 Spearman ρ。ρ 高 ⟹ 长期排序稳定（结构锁定）；ρ 低 ⟹ 排序漂移（随机）。

**检验 2（方差分解）**：区域间平方和 SSB、区域内 SSW、总平方和 SST，η² = SSB/SST。区域均值 M_r 的 bootstrap 子样本涨落与 CLT 预期 σ/√n 对比（比值 ≈1 ⟹ 区域内国家是随机浮动；≫1 ⟹ 区域均值本身被锁定）。

**检验 3（区域均值时间稳定性）**：前半 vs 后半区域均值排序的 ρ。

### 3.3 结果

| 层级 | 范围 | ρ | 判定 |
|---|---|---|---|
| 宏观 | 全部 217 国 | 0.9025 | 结构锁定 |
| 宏观 | 区域均值 | 0.9429 | 强锁定 |
| 微观 | 欧洲 | 0.6541 | 漂移 |
| 微观 | 撒哈拉以南 | 0.5190 | 漂移 |
| 微观 | 拉美 | 0.8522 | 较稳 |
| 微观 | 东亚 | 0.8063 | 较稳 |
| 微观 | 中东北非 | 0.7144 | 漂移 |
| 微观 | 南亚 (n=6) | −0.03 | 样本太小 |

- **方差分解**：SSB(区域间)=374.1，SSW(区域内)=180.4，SST=554.5 → **η²=0.675**：区域结构解释 68% 的跨国家生育率差异
- **CLT 对照**：区域内 bootstrap 子样本均值涨落 / σ/√n = 0.87–0.98 ≈ 1（符合 CLT）→ 区域内国家差异是"随机浮动"，区域均值=国家随机平均
- **时间稳定性**：ρ=0.9429；所有区域生育率同步下降（Δ=−0.95 ~ −3.00），但相对排序保持 → **集体规律 = 结构锁定（排序）+ 统一趋势（同步演化）**
- **交叉验证（预期寿命）**：全部国家 ρ=0.8885，与生育率一致

### 3.4 结论

社会版三尺度刚性在聚合数据上获得初步证据：宏观层（区域）刚性（ρ≈0.94，η²=0.68），微观层（国家）随机（ρ=0.52–0.85，CLT 比值≈1）。形态与猜想一致：**个体的随机性被集体结构锁定**。但国家=点是聚合数据，需个体级验证（→探针⑥）。

## §4 探针⑥：WVS 个体级——国家纤维、受访者随机点

### 4.1 数据与清洗

- **数据**：WVS Wave 7（2017–2022），Cross-National csv v6.0
- **样本**：95,162 有效受访者（原始 97,220），66 个国家/地区
- **变量**：Q49 生活满意度（1–10）、Q50 家庭财务满意度（1–10）、Q57 人际信任（1=多数人可信任，2=需谨慎）
- **缺失编码**：−1（不知道）、−2（拒绝）、−5（缺失）全部剔除
- **每国样本**：min=436（NIR），max=4018（CHN?），mean=1442
- **映射**：纤维 = 国家（66）；随机点 = 受访者；集体量 = 国家均值与排序

### 4.2 推导过程

**检验 [1] 方差分解**：η²(国家) 与 η²(区域)（UN 地理分区），个体级。

**检验 [2] CLT 判别**：国家均值散布 σ_obs = std(μ_i) 与纯随机采样预期 σ_pooled/√n̄ 的比值 R。

**检验 [3] 排序稳定性**：bootstrap 200 次——有放回重采样个体（保持国家分组），重算国家均值，与原始排序求 Spearman ρ，取均值与范围。

**检验 [4] 信任率散布**：Q57=1 比例（2−mean）的跨国家 std 与极值，与 WVS 经典信任排名对照。

### 4.3 结果

| 检验 | 指标 | 结果 | 判定 |
|---|---|---|---|
| [1] | η²(国家) | **0.1074** | 国家解释 10.7% 个体差异（与幸福文献 10–15% 一致） |
| [1] | η²(区域 UN) | 0.0368 | 区域解释 3.7% |
| [2] | 观察散布 σ_obs | 0.7808 | — |
| [2] | CLT 预期 σ_pooled/√n̄ | 0.0557 | — |
| [2] | **比值 R** | **14.0** | 国家间差异是抽样噪声的 14 倍（结构锁定） |
| [3] | bootstrap ρ | **0.9951**（min=0.989, max=0.998） | 排序在个体重采样下几乎不动 |
| [4] | 信任率 std | 0.1534，范围 2.1%–65.4% | 与 WVS 经典排名一致 |

区域均值（Q49）：Americas 7.58 > Oceania 7.53 > Asia 7.06 > Europe 6.92 > Africa 6.03。

信任率极值：最高 CHN 65.4%、NLD 61.9%、NZL 59.9%、AUS 54.1%；最低 ZWE 2.1%、NIC 4.2%、COL 4.5%、IDN 5.2%。

### 4.4 结论

三尺度刚性（社会版）在个体级数据上确认：

1. **个体（点）随机**：国家内涨落符合 CLT（检验 [2] 的预期项）
2. **国家（纤维）结构锁定**：均值差异是噪声的 14 倍（R=14.0），η²=0.107
3. **排序（集体）锁定**：bootstrap ρ=0.9951，个体重采样几乎不动排序

与探针③判别规则对应：纤维化系综宏观速率逐位不变（刚性）；此处国家均值排序在重采样下不变（锁定）。**个体随机性不进入集体层**——国家间幸福/信任差异是结构性的，不是抽样巧合。下一步：这个"锁"是什么？（→探针⑦⑧⑨）

## §5 探针⑦：协变量——GDP 与教育不是锁

### 5.1 数据与设计

- **数据**：WVS Wave 7 v6.0（95,497 有效受访者，66 国）+ World Bank GDP per capita（2017–2022 均值，64 国匹配）
- **核心问题**：探针⑥发现国家排序被结构锁定（ρ=0.995）。这个"锁"是 GDP/教育可还原的吗？
- **设计**：把"锁"当作纤维（国家）的属性来检验——GDP 协变量（国家均值满意度 vs log(人均GDP) 的 R²；GDP 残差化后个体级 bootstrap 排序稳定性，与探针⑥同款；个体级 GDP 调整后 η²(国家)）；教育协变量（国家内教育梯度 Q275 vs Q49；国家均值教育 vs 满意度；教育残差化后 η²(国家)）；组合（GDP+教育 双调整后 η²(国家)）。

### 5.2 推导过程

**A) GDP 协变量**：回归 μ_i ~ log(GDP_i) 得 R²；对每个受访者取残差 y_resid = y − b·log(GDP_i)（国家级回归系数 b），在残差上重跑 bootstrap ρ 与 η²(国家)。

**B) 教育协变量**：国家内教育-满意度梯度（各国分别回归 Q275→Q49 取平均 r）；国家均值教育 vs 满意度；教育残差化后 η²(国家)。

**C) 组合**：双协变量回归残差后 η²(国家)。

判定：残差化后 ρ 仍 ≈0.99 → 锁定不可还原为 GDP/教育；ρ 塌缩 → 锁定由该变量解释。

### 5.3 结果

**A) GDP**：r=0.1389，**R²=0.019**（GDP 只解释国家差异的 1.9%）；排序稳定性原始 ρ=0.9951 → **GDP 残差化后 ρ=0.9960**（完全不变）；η²(国家)：0.1067 → 0.1069（−0.2%，无变化）。

**B) 教育**：国家内教育-满意度梯度平均 r=0.0515（极小）；国家均值教育 R²=0.008；η²(国家)：0.1067 → 0.1074（−0.7%，无变化）。

**C) 组合**：η²(国家)=0.1084（+1.6%，无变化）；系数 b_logGDP=0.0435、b_edu=0.0482（均很小）。

### 5.4 结论

**国家排序的锁定不可还原为 GDP 或教育**：

1. GDP 只解释 1.9%、教育 0.8%——经济/教育组成几乎不进入集体差异
2. GDP 残差化后 ρ=0.9960，与原始 0.9951 逐位相同——去掉 GDP 效应，锁依然在
3. η² 在 GDP/教育/组合调整后全部不变（±2% 以内）

**几何读法**：纤维的标量属性（GDP、教育）≠ 纤维结构（耦合配置）。零方差定律锁定的是集体层速率（特征值），与纤维内部标量组成无关——与探针③"纤维内稀疏化到期望度 1.5 也不影响宏观速率"结构完全平行。**"锁"住在纤维结构本身（制度/文化/规范配置），不在纤维的经济/教育组成里**。

与文献一致：Easterlin 悖论传统（收入/教育对跨国幸福解释力弱）、涂尔干"社会事实"（集体规律独立于个体属性）。GDP 为名义值（非 PPP）的局限已标注，但结论鲁棒：即便 GDP 解释力翻十倍（R²=0.2），残差化后 ρ 仍将 ≈0.99。

## §6 探针⑧：制度质量（WGI）与文化维度（Hofstede）不是锁

### 6.1 数据与设计

- **数据**：WVS Wave 7 v6.0（95,497 有效受访者，66 国）+ QoG 标准时间序列（WGI 六维度，2017–2022 均值）+ Hofstede 六文化维度 + World Bank GDP per capita
- **核心问题**：探针⑦排除 GDP/教育后，"锁"还在。它是制度质量（WGI）还是文化维度（Hofstede）？
- **设计**：三组协变量检验（与探针⑦同框架）：
  - **A) WGI 制度质量**：六维度（话语权/问责、政治稳定、政府效能、监管质量、法治、腐败控制）——国家均值满意度 vs 各维度单变量 R²；六维复合；多变量全模型 R²_adj；复合残差化后排序稳定性 ρ（探针⑥同款 bootstrap）
  - **B) Hofstede 文化维度**：六维度（权力距离、个人主义、男性气质、不确定性规避、长期取向、放纵）——同上三检验
  - **C) 组合**：WGI(6)+Hofstede(6)+log(GDP) 全模型，残差化后 ρ

判定：残差化后 ρ 仍 ≈0.99 → 锁定不可还原为制度/文化标量属性；ρ 塌缩 → 锁定由该组变量解释。

### 6.2 推导过程

**A) WGI**：六维度分别单变量回归得 R²；六维复合（标准分均值）回归；多变量全模型得 R²_adj（惩罚过拟合）；用全模型残差 y_resid 重跑 bootstrap ρ 与 η²(国家)。

**B) Hofstede**：同 A 框架（注意仅 38/66 国匹配）。

**C) 组合**：13 参数全模型（36 国），R² 与 R²_adj，残差化后 ρ。

### 6.3 结果

**A) WGI 制度质量（62/66 国匹配）**：

| 维度 | r | R² |
|---|---|---|
| 政治稳定 | +0.324 | 0.1047 |
| 监管质量 | +0.200 | 0.0401 |
| 政府效能 | +0.198 | 0.0390 |
| 话语权/问责 | +0.193 | 0.0374 |
| 腐败控制 | +0.183 | 0.0336 |
| 法治 | +0.146 | 0.0214 |

六维复合 R²=0.0486；多变量全模型 R²=0.1825，**R²_adj=0.0934**；**复合残差化后 ρ=0.9956**（原始 0.9951，纹丝不动）；残差化后 η²(国家)=0.1013（Δ=−0.005）。

**B) Hofstede 文化维度（38/66 国匹配）**：

| 维度 | r | R² |
|---|---|---|
| 放纵 | +0.306 | 0.0934 |
| 长期取向 | −0.214 | 0.0460 |
| 权力距离 | −0.164 | 0.0269 |
| 不确定性规避 | −0.086 | 0.0074 |
| 男性气质 | +0.005 | 0.0000 |
| 个人主义 | −0.001 | 0.0000 |

六维复合 R²=0.0062；多变量全模型 R²=0.1581，**R²_adj=−0.0049**（无解释力）；**复合残差化后 ρ=0.9916**（仅微降）；残差化后 η²(国家)=0.0558（Δ=−0.051，含子集效应）。

**C) 组合全模型（36 国）**：子集基准（仅这 36 国）η²=0.0556、ρ=0.9916；全模型 R²=0.4433（名义），**R²_adj=0.1143**（36 国 13 参数，调整后仅 11.4%）；**全模型残差化后 ρ=0.9839**（min=0.944）。

### 6.4 结论

**"锁"不可还原为制度质量、文化维度、经济——任何标量属性都不是锁**：

1. **WGI 解释力弱**：最强维度（政治稳定）R²=0.105，六维全模型 R²_adj 仅 0.093；残差化后 ρ=0.9956，逐位相同
2. **Hofstede 无解释力**：六维全模型 R²_adj<0；复合残差化 ρ 仍 0.9916
3. **三者组合也只有名义解释力**：13 参数解释 36 国方差的 44.3%（名义），调整后仅 11.4%；残差化后 ρ 仍有 0.984

**几何读法**（比探针⑦更强）：纤维的标量属性（GDP、教育、制度得分、文化维度）全部不是锁。制度质量（WGI）和文化维度（Hofstede）本质上是把"结构"压缩成 6 个标量——但压缩丢掉了结构本身（耦合配置/规范组合）。零方差定律锁定的是结构特征值，不随任何标量属性平移。这与探针③完全平行：**标量属性进不了宏观速率，只有结构配置能**。

## §7 探针⑨：结构级候选——语言家族唯一松动锁定

### 7.1 数据与设计

- **数据**：WVS Wave 7 v6.0（96,700 有效受访者，66 国）+ World Bank 区域分类 + Ethnologue/Glottolog 风格语言家族（手工映射 66 国，18 语族）+ QoG-WGI 六维 + Hofstede 六维
- **核心问题**：探针⑧排除标量属性后，"锁"还在。结构级候选——地理集群、语言家族、制度/文化的**组合模式**——能否解开锁？
- **设计**：对每个结构分组 G（区域/语族/制度簇/文化簇），与探针⑥⑦⑧同口径四重检验：
  - **G1**：η²(G) 个体级——分组解释多少个体方差
  - **G2**：国家均值级 R²(G→均值)——分组解释多少国家间均值方差（锁的直接载体）
  - **G3**：组内排序稳定性 bootstrap ρ（≥3 国组）——去掉组间差异后组内是否仍锁定
  - **G4**：残差化（减组均值）后 η²(国家) 与排序稳定性 ρ——去掉组结构后锁是否还在

判定：ρ_resid 塌缩（→0~0.5）→ 该分组解释了锁（结构级锁定）；ρ_resid 仍 ≈0.99 → 锁比该分组更细（组内仍有稳定排序），锁在更精细的配置。

### 7.2 推导过程

**A) 地理集群**：WB 区域（64/66 国）。G1: η²(区域) 个体级；G2: 区域虚拟变量回归国家均值；G3: 组内 bootstrap ρ；G4: 减区域均值后 η²(国家) 与 ρ。

**B) 语言家族**：66 国映射 18 语族（罗曼、日耳曼、斯拉夫、汉藏、亚非、尼罗-撒哈拉等）。同 A 四重检验。

**C) 制度组合模式**：WGI 六维 k-means（k=3,4，62/66 国）。G1–G4 同上。

**D) 文化组合模式**：Hofstede 六维 k-means（k=3,4，38/66 国）。G1–G4 同上。

注意：k-means 的 R²(簇→均值) 很高（0.92–0.99）是聚类在均值特征空间收敛的自然结果，不是解释力——**残差化 ρ 才是判定依据**。

### 7.3 结果

**A) 地理集群（WB 区域，64/66 国）**：

| 检验 | 结果 |
|---|---|
| η²(地理集群) | 0.0489（4.9% 个体差异） |
| R²(区域→国家均值) | 0.5282 |
| 组内 ρ | 0.92–0.99（8 组全部稳定） |
| 残差化后 η²(国家) | 0.1086 → 0.0628（Δ=−0.046） |
| **残差化后 ρ** | 0.9956 → **0.9919**（min=0.986） |

**B) 语言家族（66/66 国，18 语族）**：

| 检验 | 结果 |
|---|---|
| η²(语言家族) | **0.0653**（全部候选中最强） |
| R²(语族→国家均值) | 0.3873 |
| 组内 ρ | 罗曼 15 国 0.981、汉藏 6 国 0.991、斯拉夫 5 国 0.982…（0.92–0.99） |
| 残差化后 η²(国家) | 0.1073 → **0.0449**（Δ=−0.062，最大下降） |
| **残差化后 ρ** | 0.9953 → **0.9817**（min=0.965，唯一明显松动） |

**C) 制度组合模式（WGI k-means，62/66 国）**：

| k | η²(组合) | R²(簇→均值) | 残差化后 η²(国家) | 残差化后 ρ |
|---|---|---|---|---|
| k=4 | 0.0078 | 0.9271 | 0.1056→0.0986（Δ=−0.007） | 0.9952→0.9959 |
| k=3 | 0.0089 | 0.9172 | 0.1056→0.0976（Δ=−0.008） | 0.9952→0.9944 |

**D) 文化组合模式（Hofstede k-means，38/66 国）**：

| k | η²(组合) | R²(簇→均值) | 残差化后 η²(国家) | 残差化后 ρ |
|---|---|---|---|---|
| k=4 | 0.0014 | 0.9665 | 0.0557→0.0544（Δ=−0.001） | 0.9917→0.9914 |
| k=3 | 0.0004 | 0.9878 | 0.0557→0.0553（Δ=−0.000） | 0.9917→0.9918 |

### 7.4 结论

**结构候选整体优于标量候选，但没有任何分组解开锁**：

1. **语言家族是最强结构候选**：η²=0.0653 远超标量属性（GDP 0.019、WGI 调整后 0.093、Hofstede 负值），是唯一让残差化 ρ 明显松动的候选（0.995→0.982）。语言 ≈ 文化传播/互动的历史结构，是"纤维耦合配置"最接近的粗粒度代理。
2. **地理集群次之**：η²=0.0489，残差化后 ρ=0.992——区域解释部分差异，但组内排序依然锁定。
3. **制度/文化组合模式几乎无解释力**：WGI k-means η²≈0.008、Hofstede k-means η²≈0.001，残差化后 ρ 纹丝不动（0.994–0.996）。**组合模式 ≠ 结构配置**——k-means 只是标量的重新打包，没有引入真正的耦合信息。
4. **锁比所有粗粒度分组更细**：即便最强的语言家族，残差化后 ρ 仍 0.982，语族内国家（罗曼 15 国 ρ=0.981、汉藏 6 国 ρ=0.991）排序依然稳定。

**几何读法**：锁在纤维的具体耦合配置，而非任何可标签化的分组。语言家族（文化传播结构）是唯一能"擦掉"一部分锁的候选——它携带了真实的互动结构信息；地理集群部分携带；制度/文化标量（无论单维还是组合）完全不携带。与探针③完整版本平行：**宏观速率由纤维的耦合配置（特征值）决定，一切分组标签都只是该配置的粗糙投影**。

## §8 探针⑩：CEPII 地理/结构距离——成对耦合的第一通道

### 8.1 数据与设计

- **数据**：CEPII GeoDist（dist_cepii.xls：225 国成对贸易加权距离 distw；geo_cepii.xls：共同边界、殖民关系、共同语言）；国家满意度均值沿用探针⑥（WVS Wave 7 v6.0）
- **核心问题**：探针⑨ 显示语言家族是唯一松动锁的结构候选——若锁在**成对耦合层**（纤维间的两两连接强度），则国家间距离/连接关系应携带耦合信息。地理邻近、共同边界、殖民纽带、共同语言是耦合强度的四种候选实现
- **设计**：与探针⑭同口径的成对检验三件套：
  - **M1（连续）**：Mantel 检验 log(地理距离) × |Δsat|（国家对满意度差异绝对值）——地理越远，满意度差异是否越大？
  - **M2（二元）**：共同边界/殖民/族群共同语言/官方共同语言——组内 vs 组外 |Δsat| 均值差 Δ + 置换检验
  - **M3（偏 Mantel）**：控制地理距离后，语言距离是否仍有独立于地理的耦合信息？

### 8.2 推导过程

**A) 码表对齐**：CEPII iso3 ↔ WVS 国家码——ROU→ROM、SRB→YUG、NIR→GBR（北爱并入英国）；65/66 国全覆盖（1 国 distw 缺失剔除）。

**B) 矩阵构建**：65×65 成对 |Δsat| 矩阵 + distw 对数矩阵；distw 缺失 64 对剔除；NIR→GBR 重复索引用 groupby 合并修复。

**C) Mantel 置换检验**：2000 次随机重排 |Δsat| 矩阵行/列，得相关 ρ 的零分布、z 得分与双侧 p。

**D) 偏 Mantel**：语言距离对 log(地理距离) 线性残差化，残差再与 |Δsat| 做 Mantel——分离两条通道的独立信息。

### 8.3 结果

| 检验 | 结果 | 判定 |
|---|---|---|
| Mantel：log(地理距离) × \|Δsat\| | ρ=+0.059，z=+2.6σ，**p=0.011** | 显著——第二个存活的连续预测子 |
| 三分位单调性 | 0.801 → 0.900 → 0.938 | 严格单调（距离越远差异越大） |
| **共同边界** | 内 0.630 vs 外 0.888，**Δ=−0.257，p=0.005** | **迄今最强二元耦合** |
| 殖民关系 | Δ=−0.226，p=0.046 | 显著（前殖民纽带趋同） |
| 族群共同语言 | Δ=−0.092，p=0.042 | 显著 |
| 官方共同语言 | p=0.35 | 不显著 |
| **偏 Mantel（控制地理后）** | 语言 ρ 0.105 → **0.085** | 语言有独立于地理的耦合信息 |

### 8.4 结论

1. **地理是第二个存活的连续预测子**（ρ=0.059, p=0.011），三分位严格单调——地理邻近确实携带耦合信息，与语言（探针⑭ ρ=0.105, p=0.033）互为独立通道。
2. **共同边界是最强二元结构效应**（Δ=−0.257, p=0.005）——直接相邻国家满意度显著趋同，对应探针④"纤维间完全二分连接锁定宏观速率"的图景：最直接的连接产生最强的耦合。
3. **不存在"哪个是锁"**：偏 Mantel 显示语言在控制地理后仍保留 ρ=0.085 的耦合信息——耦合配置层有多个不可约的结构投影，锁是成对耦合矩阵的整体谱结构，而非单一标签。

## §9 探针⑪：跨波次时间锁定——长时间条款的个体级证据

### 9.1 数据与设计

- **数据**：WVS Wave 5（2005–2009）/ Wave 6（2010–2014）/ Wave 7（2017–2022），28 个三波共同国家，生活满意度（1–10 域）
- **核心问题**：探针⑥ 的 ρ=0.995 是**单波内重采样**稳定性；集体锁定**跨真实时间**（8–18 年）成立吗？——10.75 长时间条款的个体级检验
- **设计**：三波对（WV5→6、WV6→7、WV5→7）国家均值排序 Spearman ρ + 200 次 bootstrap + 零假设对照（打乱国家标签）

### 9.2 推导过程

**A) 变量校正（重要）**：WV6 V11 是 1–4 域幸福、WV5 V11 是 1–5 域健康——首版误用同编号变量得到虚假负 ρ；经分布域扫描，WV6 用 V23、WV5 用 V22（生活满意度 1–10），均值 6.83 vs 6.70 交叉验证一致。

**B) 共同国家交集**：三波均出现且样本量 ≥500 的国家（28 国）——"长寿"国家子集。

**C) bootstrap**：200 次个体重采样 → ρ 分布（均值、min）。

**D) 零假设**：国家标签随机置换 200 次 → ρ 零分布（std=0.196），真实 ρ 与之比较。

### 9.3 结果

| 跨波对 | 时间跨度 | ρ（真实均值） | bootstrap ρ | ρ_min |
|---|---|---|---|---|
| WV5→WV6 | 5–8 年 | **0.9086** | 0.8773 | 0.8298 |
| WV6→WV7 | 3–9 年 | **0.7444** | 0.7304 | 0.6815 |
| WV5→WV7 | 8–18 年 | **0.6492** | 0.6297 | 0.5846 |

- 零假设对照：std=0.196 → 真实 ρ=0.649 为 **3.3σ**
- 时间变化：Δ(WV7−WV5) 均值 +0.182，范围 [−0.94, +1.43]——全球满意度普遍微升但国家相对位置基本保持

### 9.4 结论

1. **跨波锁定确认**：18 年尺度 ρ=0.65（3.3σ）、5–8 年 ρ=0.91——集体规律跨真实时间成立，"长时间"条款的个体级证据到位。
2. **有限相关时间锁定**：ρ 随 Δt 单调下降（0.91→0.74→0.65），粗略相关时间 τ_corr≈20–70 年——对应几何论累积量衰减条款"相关性随滞后衰减"；单波内 ρ=0.995 ≫ 跨波 ρ=0.65，**结构锁定宏观量，但结构本身在十年尺度上缓慢演化**（社会非平稳性）。
3. **与探针③精确平行**：纤维结构固定时刚性无边界（std 平坦）；结构改变时刚性受限（ρ 衰减）——社会版"结构演化打破锁定"。

## §10 探针⑭：ASJP 语言距离——耦合层的第一个显著连续预测子

### 10.1 数据与设计

- **数据**：ASJP 语言谱系距离（lists.txt，7000+ 语言成对距离，0–1 连续值，越小越近）；66 国主导语言映射
- **核心问题**：探针⑨ 的语言家族是 18 个离散桶；连续成对语言距离能否直接检验"耦合强度 ∝ 语言相似度"——且是否显著？
- **设计**：Mantel 检验语言距离 × |Δsat|（66 国 → 2,145 成对）+ 三分位（近/中/远）+ 同语言 vs 不同语言；2000 次置换

### 10.2 推导过程

**A) 解析器修正**：ASJP 元数据行含两个代码（旧书目码 + ISO 639-3），首版取错丢 12 国；修正取 ISO 639-3 → 63 国。

**B) 宏码映射**：三个宏观码不匹配 ASJP 具体码——swa→swh（斯瓦希里）、mon→khk（蒙古语）、uzb→uzn（乌兹别克语）；修正后 66 国全覆盖。

**C) 口径说明**：首版 54 国 p=0.17 不显著；覆盖补齐到 66 国后 p=0.033——覆盖度是显著性前提（小样本丢失信号）。

### 10.3 结果

| 检验 | 结果 | 判定 |
|---|---|---|
| Mantel ρ（语言距离 × \|Δsat\|） | **+0.105** | 正相关 |
| 置换零假设（2000 次） | z=+2.1σ，**p=0.033** | <0.05，排除链第一个存活的连续预测子 |
| 三分位 | 0.783 → 0.900 → 0.946 | 严格单调（语言越近，满意度越相似） |
| 同语言 vs 不同语言 | 0.674 vs 0.883 | 组内显著趋同 |

### 10.4 结论

1. **排除链闭合的第一个正证据**：GDP（1.9%）、教育（r=0.05）、WGI（9.3%）、Hofstede（<0）、地理（探针⑩）之后，语言距离是**第一个显著**的连续预测子——"锁"的可测部分位于结构性耦合层，语言是其最粗的连续边缘。
2. **方向正确**：语言越近满意度差异越小（三分位严格单调）——耦合强度 ∝ 传播/互动结构相似度。
3. **边界**：ρ≈0.10 只捕捉耦合的约 1%——锁的主体仍在未测维度（贸易流、移民网络、制度交互，探针⑩⑭ 之外）。

## §11 探针⑮：战争作为集体输出——破缺事件与烈度锁定

### 11.1 数据与设计

- **数据**：UCDP/PRIO Armed Conflict Dataset v26.1（国家-年，1946–2025：冲突年数与战死数 best estimate）；与 WVS 66 国框架对齐，53 国有冲突记录
- **核心问题**：战争是否服从集体锁定？——若和平=纤维化锁定态，战争应表现为**破缺事件**：爆发时间近似随机（泊松式），而冲突烈度一旦发生则自持锁定
- **设计**：A) 时间锁定检验——冲突年数前半（1946–84）vs 后半（1985–2023）排序 ρ，战死数（1989–07 vs 2008–25）排序 ρ；B) 破缺判别——国家内满意度 std × log10(战死+1) 相关，检验探针④"破缺使涨落恢复 CLT"的社会预言

### 11.2 推导过程

**A) 事件性量 vs 强度量的区分**：冲突年数是事件性计数（近似泊松），战死数是强度量（受结构自持）。三尺度刚性预言：事件性量不锁定，强度量锁定——分别检验。

**B) 窗口划分**：冲突年数以冷战为界（1946–84 / 1985–2023，n=33 有冲突国家）；战死数以 UCDP 战死覆盖范围为界（1989–07 / 2008–25，n=22 有战死国家）。

**C) 破缺判别映射**：探针④发现纤维化完整→宏观速率锁定、破缺→涨落恢复 CLT。社会版对应：国家内满意度离散度 std 是纤维化完整度的代理——若战争=破缺，冲突烈度应与国内离散度正相关。

### 11.3 结果

| 检验 | 窗口 | ρ | p | 判定 |
|---|---|---|---|---|
| 冲突年数（有冲突国家） | 1946–84 vs 1985–2023（n=33） | 0.238 | 0.16 | 不锁定（爆发随机轮换） |
| 冲突年数含零 | 66 国 | 0.608 | — | 和平国长期和平 |
| 战死数 | 1989–07 vs 2008–25（n=22） | **0.423** | **0.049** | **显著锁定**（冲突自持） |
| 满意度国内 std × log10(战死+1) | 66 国 | **0.318** | — | 破缺判别方向一致 |

### 11.4 结论

1. **两态图景确认**：和平=纤维化锁定态（含零冲突年数 ρ=0.608——长期和平国家锁定）；战争=纤维化破缺事件（爆发时间近似随机 ρ=0.238, p=0.16——泊松式，对应探针④破缺使涨落恢复 CLT）。
2. **烈度自持锁定**（战死 ρ=0.423, p=0.049）：冲突一旦发生即进入"冲突陷阱"，对应探针④"破缺后 std 不再平坦"。
3. **破缺判别方向一致**：国内离散度越高卷入冲突越深（ρ=0.318；冲突国 std=2.30 > 和平国 2.23）——几何论机制在集体输出上的第一个方向性验证。
4. **集体量锁定梯度**：生育率（0.94）≫ 满意度（0.65–0.91）≫ 战死烈度（0.42）≫ 冲突频率（0.24，不显著）——结构性越强的集体量越锁定，事件性越强的越随机。

### 11.5 诚实边界

战死仅 1989–2025 冷战后窗口；p=0.16 是"未检测到"非"证明随机"；满意度（2017–22）与战死（1989–2025）窗口不重叠，方向解释需谨慎；聚合数据非个体参与；战争为稀有重尾事件，超出均值锁定框架的尾部能力（框架目前无尾部定理）——探针⑮ 验证的是集体输出的两态结构，不是战争爆发预测。

## §12 探针⑯：和平↔战争两态 Markov——泊松破缺与有限弛豫

### 12.1 模型与设计

- **模型**：两态 Markov——和平态 P=纤维化锁定态，战争态 W=破缺事件；λ_b=P→W 破缺率（=1/平均和平段长），λ_r=W→P 重构率（=1/平均冲突段长）；平稳分布 π_W=λ_b/(λ_b+λ_r)，弛豫 τ=1/(λ_b+λ_r)
- **数据**：UCDP v26.1 全窗口（1946–2025，123 国，2112 国家-年冲突）；与 WVS 满意度匹配 51 国
- **核心问题**：探针⑮ 的两态图景是否有转移动力学支撑？——若和平=锁定态，破缺应是泊松过程（无记忆）；若冲突自持，重构应偏离无记忆

### 12.2 推导过程

**A) 状态序列与段长度**：每国 80 年状态序列（冲突年=1），提取和平段/冲突段长度。两态 Markov 预言段长度服从几何分布（无记忆）。

**B) 异质性控制**：全局合并段分布会混合不同国家的 λ（异质性→表观重尾）。按国检验（≥5 段）区分"异质性"与"内在记忆"：单国拒绝几何率 ≈5% 名义水平 ⟹ 全局重尾纯系异质性；≫5% ⟹ 有内在记忆。

**C) 自相关**：两态 Markov 预言 C(Δt)=exp(−(λ_b+λ_r)|Δt|)；从 lag 1–10 log 线性拟合弛豫 τ。

**D) 破缺判别**：λ_b（每国破缺率）× 国内满意度 std（纤维化完整度代理）——探针⑮ 横截面判别的纵向化。

### 12.3 结果

| 检验 | 结果 | 判定 |
|---|---|---|
| 转移率 | λ_b=0.0611/年（平均和平段 16.37 年），λ_r=0.1899/年（平均冲突段 5.27 年） | 破缺慢、重构快 |
| 平稳分布 | π_W 理论 0.2434 vs 实际 0.2146（偏差 13%） | 一阶近似成立 |
| 和平段分布（全局） | KS p=2.15e-11，重尾 | 拒绝几何（表观） |
| **和平段分布（单国）** | **35 国 0 拒绝几何（0% vs 名义 5%）** | **破缺=泊松过程（无记忆）** |
| 冲突段分布（全局） | KS p=7.82e-25，重尾 | 拒绝几何（表观） |
| **冲突段分布（单国）** | 28 国中 3 国拒绝（11% vs 5%） | **微弱自持信号** |
| 弛豫时间 | 理论 τ=3.98 年，拟合 τ=4.64 年；C(1)=0.477 vs 理论 0.778 | 同量级，观测衰减更快（异质性） |
| 破缺判别 | λ_b×国内 std ρ=0.192 (p=0.176)；λ_b×均值 ρ=−0.171 (p=0.231) | 方向一致，不显著 |

### 12.4 结论

1. **破缺是泊松过程（单国无记忆）**：和平段 0/35 国拒绝几何——战争爆发的"随机性"（探针⑮ ρ=0.238 不锁定）获得机制解释：锁定态对破缺无记忆，等待时间是几何分布。
2. **全局重尾=异质性，不是内在记忆**：全局 KS 强烈拒绝几何（p≈10⁻²⁵），单国 0/35 拒绝——国家间 λ_b 差异（纤维化完整度差异）完全解释重尾。
3. **冲突微弱自持**：冲突段单国 11% vs 5% 名义——破缺态有粘性（冲突陷阱），与探针⑮ 烈度锁定 ρ=0.423 呼应。
4. **两态 Markov 一阶成立**：π_W 偏差 13%、τ 同量级（3.98 vs 4.64 年）——和平↔战争转移可用两态 Markov 描述；偏差来源为冲突段微弱自持（非纯几何）。
5. **破缺判别纵向化方向一致不显著**：λ_b 与国内离散度正相关（ρ=0.19）、与满意度均值负相关（ρ=−0.17）——方向与"纤维化完整度越低破缺率越高"预言一致，51 国样本 + 时间错配限制显著性。

### 12.5 诚实边界

年度离散化（亚年过程不可见）；UCDP 25 战死/年门槛；冲突段样本小（28 国 ≥5 段，3 国拒绝）；满意度（2017–22）与冲突历史（1946–2025）时间错配；λ_b/λ_r 未检验时变（非平稳）；全局参数为异质均值，单国参数噪声大。

## §13 探针⑰：国家冲突风险排名与可证伪预言——Tier B 前三

### 13.1 数据与设计

- **模型**：风险分 risk = 历史破缺率 λ_b（=1/平均和平段长，探针⑯ 纵向量）为主 + 结构脆弱修正（国内满意度 std；探针⑯ 方向一致但不显著 p=0.176，权重压低）
- **分层**：Tier A=当前冲突中（37 国，现状非预测）；Tier B=当前和平但历史高破缺率（81 国，预测核心）；Tier C=无冲突史+结构脆弱（外推，置信度最低）
- **无记忆性推论**：探针⑯ 已证单国和平段无记忆——"和平越久越危险"不成立；正确排序是"历史上频繁破缺且当前处于和平期"者最接近下一次破缺

### 13.2 推导过程

**B) 结构脆弱修正**：国内满意度 std（纤维化完整度代理）× λ_b 相关 ρ=0.192（p=0.176）方向一致——保留但压低权重。

| ⑪ | 时间维度 | 跨波 ρ：0.91→0.74→0.65 (18年 3.3σ)，τ_corr≈20–70 年 | 长时间条款：有限相关时间锁定（结构慢演化） |

| ⑮ | 战争（集体输出） | 冲突频率 ρ=0.238 (p=0.16) 不锁定；战死烈度 ρ=0.423 (p=0.049) 锁定；离散度×烈度 ρ=0.318 | 和平=锁定态，战争=破缺事件；两态图景确认 |
| ⑯ | 战争（转移动力学） | 单国和平段 0/35 拒绝几何（泊松破缺）；冲突段 3/28 拒绝（11%）；λ_b=0.061，λ_r=0.190；π_W 0.243 vs 0.215；τ≈4.6 年 | 破缺=无记忆泊松；异质性=纤维化差异；冲突微弱自持；两态 Markov 一阶成立 |
| ⑰ | 战争（风险排名） | Tier A 37 国自持；Tier B 前三 TCD/ZWE/CHN（λ_b 0.257/0.042/0.232）；结构修正 p=0.176 不显著已压低权重；Tier B 全 81 国作可证伪预言（5 年窗口） | 破缺倾向=λ_b 驱动；无记忆性→"频繁破缺且当前和平"最接近下次破缺；预言分层检验 |

**几何论结论（五条）**：

1. **集体规律存在且严格**：国家排序在个体重采样下 ρ=0.9951 稳定，差异是抽样噪声的 14 倍——集体层统计量是结构锁定的，等价于零方差定律（定理 0.9.4.02）在集体层的表现形式。
2. **个体随机性不进入集体层**：个体涨落符合 CLT（随机条款），集体排序免疫重采样（结构条款）——与定理 5.8.3.02（谱间隙纤维化不变性）的数值面（探针③：宏观速率 std 平坦）精确同构。
3. **锁位于耦合配置层，不可标签化**：一切标量属性（GDP/教育/WGI/Hofstede）与粗粒度分组（地理/聚类）都无法还原锁定；语言家族（文化传播结构）是唯一部分携带真实耦合信息的候选。这支持 10.75 群尺度条款的强形式：**集体统计量由结构的对称（配置）决定，而非任何可观测标签**。
4. **耦合配置层有多条不可约的独立通道，且锁定有有限相关时间**：成对地理距离（ρ=0.059, p=0.011）与成对语言距离（ρ=0.105, p=0.033，控制地理后仍 0.085）是两个独立的结构投影——不存在"哪个是锁"的单一答案，锁是成对耦合矩阵的整体谱结构；时间上，跨波次锁定随滞后衰减（0.91→0.65，3.3σ，τ_corr≈20–70 年）——结构锁定宏观量，但结构本身在十年尺度慢演化，对应探针③"纤维结构固定时刚性无边界、结构改变时刚性受限"。
5. **集体输出的两态图景（探针⑮）**：结构性集体量锁定（生育率 0.94、满意度 0.65–0.91、战死烈度 0.42），事件性集体量随机（冲突频率 0.24 不显著）——和平=纤维化锁定态、战争=纤维化破缺事件，且破缺程度（国内离散度）与冲突烈度正相关（ρ=0.318），与探针④"破缺使涨落恢复 CLT"的预言方向一致。
6. **破缺动力学是泊松的，异质性即纤维化差异（探针⑯）**：单国和平段完全无记忆（0/35 拒绝几何）——战争爆发是锁定态的泊松破缺；全局重尾纯粹由国家间 λ_b 差异产生，即"纤维化完整度"的国家差异本身是结构性事实；冲突段微弱自持（11%）对应破缺态的粘性（冲突陷阱）；两态 Markov 一阶近似成立（π_W 偏差 13%、τ 同量级）。
7. **破缺倾向可排序、可证伪（探针⑰）**：风险分=λ_b 为主+结构脆弱修正；Tier B（当前和平、历史高破缺）是预测核心——无记忆性推论"频繁破缺且当前和平者最接近下次破缺"；Tier B 前三（TCD/ZWE/CHN）与全 81 国已记录为 5 年窗口可证伪预言（2026–2031，UCDP 门槛判定），分层冲突率对比为判别标准。

## §16 诚实边界与开放问题

### 诚实边界

1. **聚合 vs 个体**：探针⑤国家=点（聚合）；探针⑥–⑪、⑭ 个体=点（WVS）——严格对应"人当随机点"的是 ⑥–⑪、⑭
2. **横截面（部分缓解）**：⑥–⑨ 为单波横截面；探针⑪ 以三波纵向匹配（28 国）补充时间稳定性，但波次间隔不均、长寿国家选择偏差（偏稳定/发达）可能高估跨波 ρ
3. **区域/语族分类人为性**：η² 部分反映分类方式；语族为手工映射的主导语言
4. **聚类抽样**：WVS 为聚类抽样（设计效应），CLT 预期为保守下界，bootstrap 略乐观
5. **Hofstede 局限**：仅 38/66 国（偏发达国家子集），1967–73 数据源——B 的 ρ 微降可能部分是子集效应
6. **结构锁定 ≠ 因果**：排除了候选，未识别"锁"的具体载体（制度实现方式？规范网络拓扑？历史路径？）
7. **GDP 口径**：名义值（非 PPP）、2017–2022 均值——R² 数值敏感，但结论鲁棒
8. **战争数据边界（探针⑮）**：战死仅 1989–2025 冷战后窗口；冲突频率 p=0.16 是"未检测到"非"证明随机"；满意度与战死窗口不重叠；战争为稀有事件，超出均值锁定框架尾部能力（无尾部定理）；战争预测的反身性与非平稳性（战争改变结构本身）是框架的根本边界

### 开放问题

1. **10.77.10.01（锁的载体，部分解决）**：探针⑩⑭ 已用成对矩阵（地理/语言）确认耦合层存在且多通道；但贸易流（BACI/IMF DOTS）与移民网络（UN DESA）通道仍开放——经济交换与人流动是否为第三、第四条独立通道？
2. **10.77.10.02（时间维度，已解决）**：探针⑪ 完成三波匹配（28 国），时间锁定确认（3.3σ）且发现有限相关时间（τ_corr≈20–70 年）；30 年以上尺度与结构演化的驱动机制仍开放
3. **10.77.10.03（因果方向）**：结构锁定 ⟸ 制度配置 vs 历史路径——需自然实验或准实验（制度冲击前后排序变化）
4. **10.77.10.04（反身性边界）**：社会规律被知道后改变行为（索罗斯反身性）——几何论框架未纳入，是物理-社会映射的根本差异
5. **10.77.10.05（伦理边界）**：集体锁定不否定个体自由（流体方程不否定分子自由）——统计层描述不构成个体行为控制依据
6. **10.77.10.06（战争状态转移，部分解决）**：探针⑯ 建立两态 Markov：破缺=泊松（单国无记忆）、异质性=纤维化差异、冲突微弱自持、τ≈4.6 年。仍开放：λ_b/λ_r 的时变检验（非平稳）、破缺判别纵向化（λ_b 与纤维化完整度关联在 51 国样本不显著，需更多国家或更长窗口）
7. **10.77.10.07（破缺的触发机制，新增）**：泊松破缺意味着等待时间无记忆——但 λ_b 本身因国而异。什么决定 λ_b（纤维化完整度的可测代理）？需 λ_b 对制度/耦合配置的回归（探针⑯ 方向一致不显著：样本问题还是 λ_b 不可测？）
8. **10.77.10.08（可证伪预言检验，新增）**：探针⑰ 记录 Tier B 前三（TCD/ZWE/CHN）与全 81 国为 5 年窗口预言（2026-08-23 ~ 2031-08-23，UCDP v26.1+ 逐年判定"新冲突年"）；分层冲突率对比（预期 0.59 vs 基准 0.26）为判别标准；2031-08-23 关闭检验并裁决"λ_b 驱动风险排序"是否成立
