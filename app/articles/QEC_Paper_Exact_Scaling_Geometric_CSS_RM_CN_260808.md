## 摘要

我们在独立每量子比特倾斜噪声下，推导了仿射完备 Reed–Muller CSS 码 $[[2^m,\, 2^m - 2\sum_{i=0}^{r}\tbinom{m}{i},\, 2^{r+1}]]$（$2r < m-1$）的精确闭式逻辑失效率。统一标度律为

$$\mathrm{loss}(\theta_{\max}) = C(n,w_0)\,P(w_0)\,\mathrm{fail}(w_0)\,2^{-2w_0}\,\theta_{\max}^{2w_0} + O(\theta_{\max}^{2w_0+2}), \qquad w_0 = \lceil d/2\rceil,$$

其中简并分数 $P(w_0)$ 与最小重量译码失效率 $\mathrm{fail}(w_0) = 1 - \langle 1/v \rangle$ 均为 $\mathrm{GF}(2)^m$ 高斯二项式平坦计数的闭式，类大小为 $v(A) = 1 + \bigl[\begin{smallmatrix}m-s\\ r+1-s\end{smallmatrix}\bigr]_2$。距离的奇偶性决定失效机制：对 PG 完备族（奇 $d = 3$），类型 $XX, XY, YX, YY$（占该层的 $4/9$）留下含 $X$ 分量的逻辑残差而失效，$XZ, ZX$ 完美恢复，$YZ, ZY, ZZ$ 留下在 $|0_L\rangle$ 上作用为 $\pm 1$ 的纯 $Z$ 逻辑算符（无损失）：$\mathrm{fail}(2) = 4/9$；偶 $d$ 给出 $\mathrm{fail} = 1-\langle 1/v \rangle$，统一了射影几何族与仿射完备族。一个普适性定理将该结果推广到任意独立 Pauli 信道。我们确定了横向门集合 $\{$Pauli、CNOT、$H$、对角相位门、逻辑测量$\}$：横向 $H$ 合法，因为 $X$-与 $Z$-稳定子空间重合；横向 $S^{\otimes n}$ 诱导精确计算的相位门 $\bar X_a \mapsto i^{|a|}\,\bar X_a$。所有结构断言均由 $O(n^2)$ 综合征结构证书在 $[[1024, 252, 32]]$ 及以下码上验证。固定 $n = 1024$ 下四个不同的前导指数 $\theta^4, \theta^8, \theta^{16}, \theta^{32}$ 提供了无参数实验判别器。

## 1. 引言

### 1.1 为何需要精确失效率分析

量子纠错承诺将带噪声的物理量子比特转化为可靠的逻辑量子比特，但该承诺的定量内容是标度律：逻辑失效率如何随物理噪声降低而衰减。标准阈值定理 [1, 2, 3, 4] 确立了噪声阈值*存在性*——低于该阈值可实现任意低的逻辑错误率，但它们并不给出具体码的*闭式*失效率。数值模拟为具体实例提供失效率，却随码规模扩展性差，且对所观测指数与系数的结构缺乏解释。

本文为一族杰出的 CSS 码发展了一套互补的、完全解析的研究纲领：失效率以闭式计算——指数*与*系数均为闭式——且进入计算的每条结构断言均由免枚举证书验证，该证书在多达 1024 个物理量子比特的码上以 $O(n^2)$ 时间运行。这些闭式揭示了码的*几何*（环境 $\mathrm{GF}(2)^m$ 中的仿射平坦集）与*性能*（失效率）之间直接的定量联系，这种联系在阈值分析中不可见，在数值研究中仅部分可见。

精确方法的动机有三条。

(i) **实验判别**。不同的码族在固定物理量子比特预算（$n = 1024$）下表现出失效率 $\theta^4$、$\theta^8$、$\theta^{16}$、$\theta^{32}$。在小噪声区这些指数相差多个数量级，提供了锐利的定量判别器——预测中不引入任何拟合参数。

(ii) **噪声模型层析**。前导项的系数是错误层结构的函数（简并分数 $P(w_0)$ 与失效率 $\mathrm{fail}(w_0)$）。在两个噪声强度下测量损失曲线可将指数（结构）与系数（层统计）分离，从而检验噪声模型本身。

(iii) **恢复设计**。类大小闭式 $v(A) = 1 + \bigl[\begin{smallmatrix}m-s\\ r+1-s\end{smallmatrix}\bigr]_2$ 精确量化有多少错误图样与给定错误 $A$ 共享同一综合征；失效率 $1-\langle 1/v\rangle$ 是最小重量译码选错伙伴的概率。这把简并从障碍转化为精确受控的资源。

### 1.2 倾斜噪声与几何完备性

本文研究的噪声模型——*倾斜相干噪声*——在每个量子比特上注入一个独立旋转

$$U(\theta_i) = \cos(\theta_i/2)\,I + i\sin(\theta_i/2)\,E_i$$

其中 $E_i$ 为随机 Pauli 算符，角度 $\theta_i \in [0, \theta_{\max}]$ 由单一参数界定。它与阈值分析中常假设的去极化信道有两处区别。第一，它是*相干的*：态保留振幅信息，单量子比特旋转的检测概率恰为 $\sin^2(\theta_i/2)$——一个本身可测量的闭式。第二，它是*非均匀的*：不同量子比特接受不同旋转角，只有上界 $\theta_{\max}$ 进入标度预测。损失的 $\theta_{\max}$ 幂级数展开按注入错误图样的*重量*组织，每层 $w$ 贡献 $\theta_{\max}^{2w}$，其系数由三个因子构成：二项式系数 $C(n,w)$、简并分数 $P(w)$（拥有同综合征伙伴的重量-$w$ 错误的占比）与译码失效率 $\mathrm{fail}(w)$（最小重量译码选错伙伴的概率）。

核心结构断言是：对本文研究的码族，这三个因子全部由*几何决定*：$P(w)$ 与 $\mathrm{fail}(w)$ 是 $\mathrm{GF}(2)^m$ 仿射/射影平坦计数的闭式。我们称这样的码为*几何完备*（定义 2.4）：(i) 非平凡逻辑算符的最小重量等于距离 $d$；(ii) 重量 $w \ge d/2$ 错误的伙伴结构由平坦计数闭式支配。两个族满足该定义：射影几何（PG 完备）Hamming CSS 码 $[[2^m-1,\,2^m-1-2m,\,3]]$ 与仿射完备（AG 完备）Reed–Muller CSS 码 $[[2^m,\, 2^m-2s,\, 2^{r+1}]]$，其中 $s = \dim \mathrm{RM}(r,m)$。

### 1.3 贡献

1. **统一标度律（定理 16）**。对任意几何完备 CSS 码，在界为 $\theta_{\max}$ 的独立倾斜噪声下，最小重量译码给出闭式
$$\mathrm{loss}(\theta_{\max}) = C(n,w_0)\,P(w_0)\,\mathrm{fail}(w_0)\,2^{-2w_0}\,\theta_{\max}^{2w_0} + O(\theta_{\max}^{2w_0+2}),$$
其中 $w_0 = \lceil d/2 \rceil$；前导指数对偶 $d$ 为 $d$，对奇 $d$ 为 $d+1$。失效率的奇偶二分法得到解决：奇 $d$ 迫使跨层伙伴，且在 $|0_L\rangle$ 编码下 PG 完备族有 $\mathrm{fail}(2) = 4/9$（纯 $Z$ 逻辑残差无损失）；偶 $d$ 给出同层伙伴与 $\mathrm{fail} = 1 - \langle 1/v\rangle$。

2. **类大小与失效率闭式（定理 17–18）**。对仿射完备族，重量 $2^r$ 层的类大小为 $v(A) = 1 + \bigl[\begin{smallmatrix}m-s\\ r+1-s\end{smallmatrix}\bigr]_2$，其中 $s = \dim \mathrm{aff}(A)$；由此 $\mathrm{fail}(w_0) = 1 - P(3)/2 - P(\le 2)\,2^{2-m}$（$r=2$），$= 1 - 2^{1-m}$（$r=1$），$\approx 1/2$（$r \ge 3$，含指数小修正）。表 3 全部条目无拟合参数地复现。

3. **Pauli 信道普适性（定理 21）**。标度律逐字成立地推广到任意独立每量子比特 Pauli 信道：设 $X$ 侧错误概率为 $\varepsilon$（错误算符含 $X$ 或 $Y$ 的概率），则 $X$ 侧失效率等于 $\sum_{w\ge w_0} C(n,w)\,\varepsilon^w(1-\varepsilon)^{n-w}\,\mathrm{fail}(w)$，其中 $\mathrm{fail}(w)$ 与相干情形下*无条件*相同——译码器是综合征与重量的确定性函数，信道仅通过 $\varepsilon$ 进入。相干倾斜：$\varepsilon = \sin^2(\theta/2)$；去极化：$\varepsilon = 2p/3$；相位阻尼（扭对称化后）：$\varepsilon = 0$；振幅阻尼（扭对称化后）：$\varepsilon = \gamma/2$。未扭对称化的相干非 Pauli 过程超出本框架（综合征响应变为概率性的）；Pauli 扭对称化——标准实验操作 [5, 6]——将其恢复。

4. **免枚举验证（第 3.3 节）**。进入标度律的结构断言无需枚举错误图样即可验证：生成矩阵的列互异性蕴含 $O(n^2)$ 时间内完全重量-2 检测；常量坐标块阻断跨重量综合征简并（定理 5）；二次单项式块在 $r \ge 2$ 时阻断重量-2 内部简并（定理 6）。$[[1024, 252, 32]]$ 的完整结构证书运行 8.8 秒。

5. **横向操作（第 6 节）**。仿射完备族支持横向 Pauli、CNOT 与 $H$ 门；横向 $S^{\otimes n}$ 保持码空间并诱导方向相关相位门 $\bar X_a \mapsto i^{|a|}\,\bar X_a$，其中 $\gamma_a = i^{|a|}$（定理 23）。容错操作集合为 $\{$横向 Pauli、CNOT、$H\} \cup \{$对角相位门$\} \cup \{$逻辑测量$\}$，$T$ 门通过标准魔法态蒸馏接口——仅需 $d \ge 5$，$r \ge 2$ 的所有成员均满足。

6. **四阶实验判别器（第 8 节）**。在 64–1121 量子比特平台上，成员 $[[1024, 1002, 4]]$、$[[1024, 912, 8]]$、$[[1024, 672, 16]]$、$[[1024, 252, 32]]$ 预测双对数坐标下损失斜率 $\theta^4, \theta^8, \theta^{16}, \theta^{32}$。斜率四元组是几何结构的无参数签名；任何偏离都在对应层证伪类大小机制。

### 1.4 相关工作

本文与现有文献的关系在第 7 节详细分析。简述：CSS 构造归于 Calderbank–Shor [7] 与 Steane [2]；稳定子形式体系归于 Gottesman [8]；Reed–Muller 码及其重量分布是经典内容 [9–12]；魔法态蒸馏归于 Bravyi–Kitaev [13] 及容错路线图与教学综述 [14, 15, 17]；级联码与拓扑码的阈值分析见 [3, 16]。本文呈现的*带几何系数的精确闭式失效率分析*似乎是新的：Reed–Muller CSS 码的标准处理（如 Steane 码 $[[7,1,3]]$ 即 $\mathrm{RM}(1,3)$）聚焦于距离与阈值，而非逐层简并结构及其闭式失效率。第 7 节给出系统比较，包括将早期数值研究中观测到的 $[[15,7,3]]$ 码 315/945 $= 1/3$ 跨重量简并解析为总损失分数 $4/9$（损失集合 $\{XX, XY, YX, YY\}$ 不同于跨重量集合 $\{XX, ZZ, YY\}$：$ZZ$ 与单量子比特错误共享综合征，但其残差是纯 $Z$ 逻辑算符，在 $|0_L\rangle$ 编码下无损失）。
