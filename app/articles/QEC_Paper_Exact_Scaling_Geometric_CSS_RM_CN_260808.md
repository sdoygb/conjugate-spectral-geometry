## 摘要

我们在独立每量子比特倾斜噪声下，推导了仿射完备 Reed–Muller CSS 码 $[[2^m,\, 2^m - 2\sum_{i=0}^{r}\tbinom{m}{i},\, 2^{r+1}]]$（$2r < m-1$）的精确闭式逻辑失效率。统一标度律为

$$\mathrm{loss}(\theta_{\max}) = C(n,w_0)\,P(w_0)\,\mathrm{fail}(w_0)\,2^{-2w_0}\,\theta_{\max}^{2w_0} + O(\theta_{\max}^{2w_0+2}), \qquad w_0 = \lceil d/2\rceil,$$

其中简并分数 $P(w_0)$ 与最小重量译码失效率 $\mathrm{fail}(w_0) = 1 - \langle 1/v \rangle$ 均为 $\mathrm{GF}(2)^m$ 高斯二项式平坦计数的闭式，类大小为 $v(A) = 1 + \bigl[\begin{smallmatrix}m-s\\ r+1-s\end{smallmatrix}\bigr]_2$。距离的奇偶性决定失效机制：对 PG 完备族（奇 $d = 3$），类型 $XX, XY, YX, YY$（占该层的 $4/9$）留下含 $X$ 分量的逻辑残差而失效，$XZ, ZX$ 完美恢复，$YZ, ZY, ZZ$ 留下在 $|0_L\rangle$ 上作用为 $\pm 1$ 的纯 $Z$ 逻辑算符（无损失）：$\mathrm{fail}(2) = 4/9$；偶 $d$ 给出 $\mathrm{fail} = 1-\langle 1/v \rangle$，统一了射影几何族与仿射完备族。一个普适性定理将该结果推广到任意独立 Pauli 信道。我们确定了横向门集合 $\{$Pauli、CNOT、$H$、对角相位门、逻辑测量$\}$：横向 $H$ 合法，因为 $X$-与 $Z$-稳定子空间重合；横向 $S^{\otimes n}$ 诱导精确计算的相位门 $\bar X_a \mapsto i^{|a|}\,\bar X_a$。所有结构断言均由 $O(n^2)$ 综合征结构证书在 $[[1024, 252, 32]]$ 及以下码上验证。固定 $n = 1024$ 下四个不同的前导指数 $\theta^4, \theta^8, \theta^{16}, \theta^{32}$ 提供了闭式实验判别器。

## 1. 引言

### 1.1 为何需要精确失效率分析

量子纠错承诺将带噪声的物理量子比特转化为可靠的逻辑量子比特，但该承诺的定量内容是标度律：逻辑失效率如何随物理噪声降低而衰减。标准阈值定理 [1, 2, 3, 4] 确立了噪声阈值*存在性*——低于该阈值可实现任意低的逻辑错误率，但它们并不给出具体码的*闭式*失效率。数值模拟为具体实例提供失效率，却随码规模扩展性差，且对所观测指数与系数的结构缺乏解释。

本文为一族杰出的 CSS 码发展了一套互补的、完全解析的研究纲领：失效率以闭式计算——指数*与*系数均为闭式——且进入计算的每条结构断言均由免枚举证书验证，该证书在多达 1024 个物理量子比特的码上以 $O(n^2)$ 时间运行。这些闭式揭示了码的*几何*（环境 $\mathrm{GF}(2)^m$ 中的仿射平坦集）与*性能*（失效率）之间直接的定量联系，这种联系在阈值分析中不可见，在数值研究中仅部分可见。

精确方法的动机有三条。

(i) **实验判别**。不同的码族在固定物理量子比特预算（$n = 1024$）下表现出失效率 $\theta^4$、$\theta^8$、$\theta^{16}$、$\theta^{32}$。在小噪声区这些指数相差多个数量级，提供了锐利的定量判别器——预测中不引入任何拟合参数。

(ii) **噪声模型层析**。前导项的系数是错误层结构的函数（简并分数 $P(w_0)$ 与失效率 $\mathrm{fail}(w_0)$）。在两个噪声强度下测量损失曲线可将指数（结构）与系数（层统计）分离，从而检验噪声模型本身。

(iii) **恢复设计**。类大小闭式 $v(A) = 1 + \bigl[\begin{smallmatrix}m-s\\ r+1-s\end{smallmatrix}\bigr]_2$ 精确量化有多少错误图样与给定错误 $A$ 共享同一综合征；失效率 $1-\langle 1/v\rangle$ 是最小重量译码选错伙伴的概率。这把简并从障碍转化为精确受控的资源。

### 1.2 倾斜噪声与几何完备性

本文研究的噪声模型——*倾斜相干噪声*——在每个量子比特上注入一个独立旋转

$$U(\theta_i) = \cos(\theta_i/2)\,I + i\sin(\theta_i/2)\,E_i$$

其中 $E_i$ 为随机 Pauli 算符，角度 $\theta_i \in [0, \theta_{\max}]$ 由单一参数界定。它与阈值分析中常假设的去极化信道有两处区别。第一，它是*相干的*：态保留振幅信息，单量子比特旋转的检测概率恰为 $\sin^2(\theta_i/2)$——一个本身可测量的闭式。第二，它是*非均匀的*：不同量子比特接受不同旋转角，只有上界 $\theta_{\max}$ 进入标度预测。损失的 $\theta_{\max}$ 幂级数展开按注入错误图样的*重量*组织，每层 $w$ 贡献 $\theta_{\max}^{2w}$，其系数由三个因子构成：二项式系数 $C(n,w)$、简并分数 $P(w)$（拥有同综合征伙伴的重量-$w$ 错误的占比）与译码失效率 $\mathrm{fail}(w)$（最小重量译码选错伙伴的概率）。

核心结构断言是：对本文研究的码族，这三个因子全部由*几何决定*：$P(w)$ 与 $\mathrm{fail}(w)$ 是 $\mathrm{GF}(2)^m$ 仿射/射影平坦计数的闭式。我们称这样的码为*几何完备*（定义 2.2）：(i) 非平凡逻辑算符的最小重量等于距离 $d$；(ii) 重量 $w \ge d/2$ 错误的伙伴结构由平坦计数闭式支配。两个族满足该定义：射影几何（PG 完备）Hamming CSS 码 $[[2^m-1,\,2^m-1-2m,\,3]]$ 与仿射完备（AG 完备）Reed–Muller CSS 码 $[[2^m,\, 2^m-2s,\, 2^{r+1}]]$，其中 $s = \dim \mathrm{RM}(r,m)$。

### 1.3 贡献

1. **统一标度律（定理 16）**。对任意几何完备 CSS 码，在界为 $\theta_{\max}$ 的独立倾斜噪声下，最小重量译码给出闭式
$$\mathrm{loss}(\theta_{\max}) = C(n,w_0)\,P(w_0)\,\mathrm{fail}(w_0)\,2^{-2w_0}\,\theta_{\max}^{2w_0} + O(\theta_{\max}^{2w_0+2}),$$
其中 $w_0 = \lceil d/2 \rceil$；前导指数对偶 $d$ 为 $d$，对奇 $d$ 为 $d+1$。失效率的奇偶二分法得到解决：奇 $d$ 迫使跨层伙伴，且在 $|0_L\rangle$ 编码下 PG 完备族有 $\mathrm{fail}(2) = 4/9$（纯 $Z$ 逻辑残差无损失）；偶 $d$ 给出同层伙伴与 $\mathrm{fail} = 1 - \langle 1/v\rangle$。

2. **类大小与失效率闭式（定理 17–18）**。对仿射完备族，重量 $2^r$ 层的类大小为 $v(A) = 1 + \bigl[\begin{smallmatrix}m-s\\ r+1-s\end{smallmatrix}\bigr]_2$，其中 $s = \dim \mathrm{aff}(A)$；由此 $\mathrm{fail}(w_0) = 1 - P(3)/2 - P(\le 2)\,2^{2-m}$（$r=2$），$= 1 - 2^{1-m}$（$r=1$），$\approx 1/2$（$r \ge 3$，含指数小修正）。表 3 全部条目由闭式复现。

3. **Pauli 信道普适性（定理 21）**。标度律逐字成立地推广到任意独立每量子比特 Pauli 信道：设 $X$ 侧错误概率为 $\varepsilon$（错误算符含 $X$ 或 $Y$ 的概率），则 $X$ 侧失效率等于 $\sum_{w\ge w_0} C(n,w)\,\varepsilon^w(1-\varepsilon)^{n-w}\,\mathrm{fail}(w)$，其中 $\mathrm{fail}(w)$ 与相干情形下*无条件*相同——译码器是综合征与重量的确定性函数，信道仅通过 $\varepsilon$ 进入。相干倾斜：$\varepsilon = \sin^2(\theta/2)$；去极化：$\varepsilon = 2p/3$；相位阻尼（扭对称化后）：$\varepsilon = 0$；振幅阻尼（扭对称化后）：$\varepsilon = \gamma/2$。未扭对称化的相干非 Pauli 过程超出本框架（综合征响应变为概率性的）；Pauli 扭对称化——标准实验操作 [5, 6]——将其恢复。

4. **免枚举验证（第 3.3 节）**。进入标度律的结构断言无需枚举错误图样即可验证：生成矩阵的列互异性蕴含 $O(n^2)$ 时间内完全重量-2 检测；常量坐标块阻断跨重量综合征简并（定理 5）；二次单项式块在 $r \ge 2$ 时阻断重量-2 内部简并（定理 6）。$[[1024, 252, 32]]$ 的完整结构证书运行 8.8 秒。

5. **横向操作（第 6 节）**。仿射完备族支持横向 Pauli、CNOT 与 $H$ 门；横向 $S^{\otimes n}$ 保持码空间并诱导方向相关相位门 $\bar X_a \mapsto i^{|a|}\,\bar X_a$，其中 $\gamma_a = i^{|a|}$（定理 23）。容错操作集合为 $\{$横向 Pauli、CNOT、$H\} \cup \{$对角相位门$\} \cup \{$逻辑测量$\}$，$T$ 门通过标准魔法态蒸馏接口——仅需 $d \ge 5$，$r \ge 2$ 的所有成员均满足。

6. **四阶实验判别器（第 8 节）**。在 64–1121 量子比特平台上，成员 $[[1024, 1002, 4]]$、$[[1024, 912, 8]]$、$[[1024, 672, 16]]$、$[[1024, 252, 32]]$ 预测双对数坐标下损失斜率 $\theta^4, \theta^8, \theta^{16}, \theta^{32}$。斜率四元组是几何结构的闭式签名；任何偏离都在对应层证伪类大小机制。

### 2.1 稳定子形式体系与 CSS 码

设 $\mathcal{P}_n$ 为 $n$ 量子比特 Pauli 群。稳定子码是 Abel 子群 $S \subset \mathcal{P}_n$（不含 $-I$）的联合 $+1$ 本征空间 $\mathcal{C}(S)$；其参数写作 $[[n,k,d]]$，$k$ 为逻辑量子比特数，距离 $d$ 等于中心化子 $\mathcal{Z}(S)$ 中不在 $S$ 内的 Pauli 算符的最小重量。错误 $E$ 的综合征是 $E$ 与 $S$ 的固定生成集的交换关系列表；译码规则将综合征映射到恢复算符。

**CSS 构造** [2, 7]。设 $C_2 \subseteq C_1 \subseteq \mathbb{F}_2^n$ 为经典线性码。CSS 码 $\mathrm{CSS}(C_1, C_2)$ 的稳定子由 $\{X_v : v \in C_2\} \cup \{Z_v : v \in C_1^\perp\}$ 生成，其中 $X_v = \bigotimes_i X^{v_i}$，$Z_v = \bigotimes_i Z^{v_i}$。其参数满足 $k = \dim C_1 - \dim C_2$ 且

$$d = \min\big\{\mathrm{wt}(C_1 \setminus C_2),\; \mathrm{wt}(C_2^\perp \setminus C_1^\perp)\big\},$$

其中 $\mathrm{wt}(\mathcal{D})$ 为 $\mathcal{D}$ 中向量的最小汉明重量。逻辑零态为 $|0_L\rangle = \frac{1}{\sqrt{|C_2|}}\sum_{x \in C_2} |x\rangle$。逻辑算符：对 $a \in C_1 \setminus C_2$（分别地 $a \in C_2^\perp \setminus C_1^\perp$），$X_a$（分别地 $Z_a$）是逻辑算符。

**自正交对称 CSS 码**。形如 $\mathrm{CSS}(H, H)$ 的 CSS 码——以单个矩阵 $H$ 书写，其行空间即稳定子空间 $C$——其 $X$-与 $Z$-稳定子都由*同一*空间 $C$ 生成，当且仅当 $C$ 自正交（$C \subseteq C^\perp$）时良定义。此时 $X$-稳定子空间 $=$ $Z$-稳定子空间 $= C$，且 $k = n - 2\dim C$。逻辑空间为 $L = C^\perp$；非平凡逻辑算符的支撑在 $C^\perp \setminus C$ 中。

**最小重量译码**。给定综合征 $s$，译码器选取具有该综合征的最小重量错误 $e$ 并施加相应恢复。若真实错误与所选代表元相差一个逻辑算符（即该综合征类含非平凡逻辑），则纠错失败。重量 $w$ 层的*译码失效率* $\mathrm{fail}(w)$ 是均匀随机重量-$w$ 错误图样经最小重量译码失败的概率；等价地，是综合征类无唯一最小重量代表元的重量-$w$ 图样的占比。

### 2.2 Reed–Muller 码

将 $\mathbb{F}_2^m$ 与仿射几何 $\mathrm{AG}(m,2)$ 的 $2^m$ 个点等同。

**定义 2.1**（Reed–Muller 码）。对 $0 \le r \le m$，Reed–Muller 码 $\mathrm{RM}(r,m)$ 由次数 $\le r$ 的多项式 $f \in \mathbb{F}_2[x_1,\dots,x_m]$ 的所有赋值向量 $\big(f(p)\big)_{p \in \mathrm{AG}(m,2)}$ 组成。

标准事实 [9, 11]：

$$\dim \mathrm{RM}(r,m) = \sum_{i=0}^{r} \binom{m}{i}, \qquad \min\mathrm{wt}\,\mathrm{RM}(r,m) = 2^{m-r},$$

以及**对偶定理**：$\mathrm{RM}(r,m)^\perp = \mathrm{RM}(m-r-1, m)$。特别地，$\mathrm{RM}(r,m) \subseteq \mathrm{RM}(r,m)^\perp$ 当且仅当 $2r < m-1$——这是使对称码 $\mathrm{CSS}(H,H)$（$H$ 为 $\mathrm{RM}(r,m)$ 的生成矩阵）成为合法 CSS 码的自正交条件。

全文使用仿射几何的两个计数输入。$\mathrm{AG}(m,2)$ 中 $k$ 维仿射平坦集的数目为

$$\mathrm{flats}(m,k) = 2^{m-k}\left[\begin{matrix}m\\ k\end{matrix}\right]_2 = 2^{m-k}\prod_{i=0}^{k-1}\frac{2^{m-i}-1}{2^{k-i}-1},$$

其中 $\bigl[\begin{smallmatrix}m\\ k\end{smallmatrix}\bigr]_2$ 为高斯二项式系数；且 $k$-平坦集的指示函数恰为 $\mathrm{RM}(m-k, m)$ 的最小重量向量：$(k+1)$-平坦集指示函数的重量为 $2^{k+1}$，次数为 $m-k-1$。

**重量层**。我们记录第 5 节所需的重量奇偶结构：$\mathrm{RM}(r,m)$ 的每个码字，在 $r \le m-3$、$m \ge 4$ 时重量 $\equiv 0 \pmod 4$。（确实，$\mathrm{RM}(m-2,m)$ 是偶重量子空间且最小重量 $2^{m-r} \ge 8$；同余式由 Reed–Muller 码的标准重量分布 [12] 推出。）

### 2.3 倾斜噪声模型与损失展开

**相干倾斜噪声**。每个物理量子比特 $i$ 接受独立旋转 $U(\theta_i) = \cos(\theta_i/2)\,I + i\sin(\theta_i/2)\,E_i$（$E_i$ 为 Pauli 算符），$\theta_i \in [0, \theta_{\max}]$。上界 $\theta_{\max}$ 是单一噪声参数。对固定注入图样 $\mathbf{E} = (E_1,\dots,E_n)$，构型的概率权重为错误部分 $\prod_i \sin^2(\theta_i/2)$ 与恒等部分 $\prod_i \cos^2(\theta_i/2)$ 之积。相干结构给出两个可测量的闭式：

- 单量子比特注入的检测概率：$\sin^2(\theta_i/2)$（综合征翻转概率）；
- 未检测路径保持保真度：投影回码空间是精确的。

二者已由第 3.5 与 5.5 节的数值研究验证到机器精度；它们是该模型的实验锚点。

**损失展开**。设 $\mathrm{loss}(\theta_{\max})$ 为最优（最小重量）恢复后的期望不保真度，对随机角度 $\theta_i \in [0,\theta_{\max}]$ 与随机 Pauli 类型求平均。按 $\theta_{\max}$ 的幂展开：

$$\mathrm{loss}(\theta_{\max}) = \sum_{w \ge 1} C(n,w)\,P(w)\,\mathrm{fail}(w)\,\big\langle \sin^{2}(\theta/2) \big\rangle^{w} \,\big\langle \cos^{2}(\theta/2) \big\rangle^{n-w},$$

其中平均值对角度分布取；对均匀界模型，$\langle \sin^{2}(\theta/2)\rangle = \theta_{\max}^{2}/12 + O(\theta_{\max}^{4})$，$\langle \cos^{2}(\theta/2)\rangle = 1 + O(\theta_{\max}^2)$。$\theta_{\max}^{2w}$ 系数中的三个因子为：$C(n,w)$——重量-$w$ 注入支撑的数目；$P(w)$——重量 $w$ 层的*简并分数*，即拥有至少一个不同同综合征伙伴的重量-$w$ 错误的占比；$\mathrm{fail}(w)$——该层的*译码失效率*。无同综合征伙伴的层（$P(w) = 0$）无贡献；最小重量代表元唯一的层有 $\mathrm{fail}(w) = 0$；首个存活的层是 $w_0 = \lceil d/2 \rceil$（定理 9）。

**Pauli 信道形式**。对一般独立每量子比特 Pauli 信道，设 $X$ 侧错误概率为 $\varepsilon$（错误算符含 $X$ 或 $Y$ 分量的概率；$Z$ 错误对 $X$-综合征不可见），$X$ 侧失效率为

$$\mathrm{loss}(\varepsilon) = \sum_{w \ge 0} C(n,w)\,\varepsilon^w (1-\varepsilon)^{n-w}\,\mathrm{fail}(w).$$

信道常数：相干倾斜 $\varepsilon = \sin^2(\theta/2)$；速率 $p$ 的去极化：$\varepsilon = 2p/3$；相位阻尼（扭对称化后）：$\varepsilon = 0$；振幅阻尼（扭对称化后）：$\varepsilon = \gamma/2$。系数序列 $\mathrm{fail}(w)$ 跨信道的普适性是定理 21。

### 2.4 几何完备性

**定义 2.2**（几何完备 CSS 码）。稳定子空间 $S = \mathrm{rowspace}(H)$、逻辑空间 $L = S^\perp$ 的 CSS 码 $[[n,k,d]]$ 称为*几何完备*，若

(i) $L \setminus S$ 的最小重量等于距离 $d$；

(ii) 对每个错误重量 $w \ge d/2$，伙伴结构——同综合征代表元的指派——由 $\mathrm{GF}(2)^m$ 仿射/射影平坦集的闭式计数支配：错误支撑 $A$ 的类大小 $v(A)$ 仅通过显式公式依赖于仿射张成维数 $s = \dim \mathrm{aff}(A)$。

两个族满足该定义：

- **PG 完备码**：$H$ 的列为 $\mathbb{F}_2^m$ 的所有非零向量（以单纯形码为稳定子），参数 $[[2^m-1,\, 2^m-1-2m,\, 3]]$，逻辑空间为汉明码（第 3.1 节）；
- **AG 完备码**（仿射完备）：$H$ = $\mathrm{RM}(r,m)$ 在 $\mathrm{AG}(m,2)$ 全部 $2^m$ 个点上的生成矩阵，参数 $[[2^m,\, 2^m - 2\dim\mathrm{RM}(r,m),\, 2^{r+1}]]$，$2r < m-1$（第 3.2 节）。

两族在标准意义下都是 CSS 码；"完备"是其综合征几何的结构性质——伙伴结构精确可计算，而非仅可估计。

## 3. CSS 码的几何族

### 3.1 射影几何码：为何 $d = 3$ 被锁定

PG 完备族以单纯形码为稳定子空间得到：$H$ 的列为 $\mathbb{F}_2^m$ 的所有非零向量（射影几何 $\mathrm{PG}(m-1,2)$ 的点），给出汉明 CSS 码 $[[2^m-1,\, 2^m-1-2m,\, 3]]$，其中 $S = \mathrm{Simplex}(m)$，$L = \mathrm{Hamming}(m)$。该族是度量仿射完备族的基线：

- **距离锁定为 3**。任意两个不同的非零向量线性无关，故不存在重量-2 逻辑（$d \ge 3$）；但射影闭包——任意两列的 XOR 仍是列——对每对列强制一个重量-3 逻辑算符（三点共线）。因此 $d = 3$ 是*结构性*的。
- **跨重量简并分数 1/3；损失分数 4/9**。对成员 $[[15,7,3]]$，945 个重量-2 错误中恰有 315 个与单量子比特错误共享综合征（类型 $XX$、$ZZ$、$YY$）：该共享综合征类含一个重量-3 逻辑算符，恢复后残留重量-3 逻辑错误。分数 315/945 $= 1/3$ 是综合征与重量-1 错误重合的 Pauli 类型占比，由列 XOR 闭包所致——这是*跨重量*简并，而非损失分数。在 $|0_L\rangle$ 编码下损失分数为 $4/9$：类型 $XX, XY, YX, YY$（420 个错误）留下含 $X$ 分量的逻辑残差（态被翻转到正交逻辑态）；$XZ, ZX$（210 个错误）完美恢复；$YZ, ZY, ZZ$（315 个错误）留下纯 $Z$ 逻辑算符，它在 $|0_L\rangle$ 上作用为 $\pm 1$，无损失。故 $\mathrm{fail}(2) = 420/945 = 4/9$，即定理 16 的因子 $P(2)\,\mathrm{fail}(2)$。
- **损失 $\theta^4$**。$w_0 = \lceil 3/2 \rceil = 2$ 时前导层为重量 2，$\mathrm{fail}(2) = 4/9$（类型 $XX, XY, YX, YY$ 留下含 $X$ 分量的逻辑残差；$XZ, ZX$ 完美恢复；$YZ, ZY, ZZ$ 留下纯 $Z$ 逻辑算符，在 $|0_L\rangle$ 编码下无损失），给出 $\mathrm{loss} \sim \theta^4$，系数为 $(4/9)\,C(2^m-1,2)\,2^{-4}$；在 $[[5,1,3]]$、$[[7,1,3]]$、$[[9,1,3]]$ 上数值测得双对数斜率 4.04–4.14，$[[15,7,3]]$ 上斜率 3.99（固定 4 量子比特注入）。

锁定的距离 $d = 3$ 激发仿射构造：要达到 $d \ge 5$，需要每 4 列仿射无关——即 4-弧。在二元射影空间中计数界约为 $\sim 2^N/3$，但显式 4-弧要小得多（$\mathrm{PG}(3,2)$ 至多有 5 个点），故射影点集路径无法以正速率达到大距离。解决之道是*更换列空间*：在仿射几何的全部 $2^m$ 个点上赋值，得到距离任意大的 Reed–Muller CSS 族。

### 3.2 仿射完备码：定义、参数、距离

**定义 3.1**（仿射完备码）。设 $\mathrm{RM}(r,m)$ 为第 2.2 节的 Reed–Muller 码，生成矩阵 $H$ 的行为所有次数 $\le r$ 的单项式在 $\mathrm{AG}(m,2)$ 的 $2^m$ 个点上的赋值。仿射完备码是稳定子空间 $C = \mathrm{RM}(r,m)$、满足自正交条件 $C \subseteq C^\perp$ 的对称 CSS 码 $\mathrm{CSS}(H,H)$。

**定理 1**（自正交性）。$\mathrm{RM}(r,m) \subseteq \mathrm{RM}(r,m)^\perp$ 当且仅当 $2r < m-1$。

*证明*。由对偶定理，$\mathrm{RM}(r,m)^\perp = \mathrm{RM}(m-r-1,m)$，且 $\mathrm{RM}(r,m) \subseteq \mathrm{RM}(m-r-1,m)$ 当且仅当 $r \le m-r-1$，即 $2r \le m-1$；需要严格不等式，因为 $r = (m-1)/2$ 会使码自对偶且 $k = 0$。∎

**定理 2**（参数）。仿射完备码的参数为

$$\big[\!\big[\,2^m,\; 2^m - 2\sum_{i=0}^{r}\tbinom{m}{i},\; 2^{r+1}\,\big]\!\big].$$

*证明*。由构造 $n = 2^m$。由于 $X$-与 $Z$-稳定子空间都等于 $C = \mathrm{RM}(r,m)$，$\dim C = \sum_i \binom{m}{i}$（第 2.2 节），$k = n - 2\dim C$。距离由定理 3 给出。∎

**定理 3**（距离）。仿射完备码 $\mathrm{CSS}(H,H)$ 的最小距离为 $d = 2^{r+1}$。

*证明*。非平凡逻辑算符的支撑在 $C^\perp \setminus C = \mathrm{RM}(m-r-1,m) \setminus \mathrm{RM}(r,m)$ 中。由对偶定理，$C^\perp$ 的最小重量为 $2^{m-(m-r-1)} = 2^{r+1}$，由 $(r+1)$-平坦集的指示函数达到。严格自正交（$2r < m-1$ 蕴含 $m-r > r+1$）保证 $\mathrm{RM}(m-r-1,m) \not\subseteq \mathrm{RM}(r,m)$；事实上 $\mathrm{RM}(m-r-1,m)$ 的重量 $2^{r+1}$ 层——$(r+1)$-平坦集指示函数——完全位于 $\mathrm{RM}(r,m)$ 之外，因为 $\min \mathrm{wt}\,\mathrm{RM}(r,m) = 2^{m-r} > 2^{r+1}$。故 $d = 2^{r+1}$。∎

### 3.3 免枚举验证

在 $n = 1024$ 时错误图样的完全枚举不可行（$\binom{1024}{2} \approx 5.2\times 10^5$ 个重量-2 图样，但 $\binom{1024}{4} \approx 4.6\times 10^{10}$ 个重量-4 图样，$[[1024,252,32]]$ 前导层 $\binom{1024}{16} \sim 10^{33}$）。以下结构定理用 $O(n^2)$ 证书取代枚举。

**定理 4**（列互异性蕴含完全重量-2 检测）。$\mathrm{RM}(r,m)$ 的赋值列在 $\mathrm{AG}(m,2)$ 上两两互异。因此每个重量-2 错误图样都被检测：对任意两个不同位置 $a, b$，$X$-综合征 $\mathrm{col}_a \oplus \mathrm{col}_b \ne 0$，$Z$-综合征亦然；重量-2 错误的全部九种 Pauli 类型都被检测。

*证明*。常量坐标（单项式 1 的赋值）连同坐标函数 $x_1,\dots,x_m$ 分离 $\mathrm{AG}(m,2)$ 的任意两个不同点：若 $p \ne q$，某个坐标函数不同，故赋值列在相应行不同。重量-2 错误 $(a,b)$ 的综合征为 $\mathrm{col}_a \oplus \mathrm{col}_b$（$X$ 型）与同样的组合（$Z$ 型）；混合 Pauli 错误两侧综合征均为 $\mathrm{col}_a \oplus \mathrm{col}_b$。所有情形下非零。∎

**定理 5**（跨重量零简并）。没有任何重量-1 错误与重量-2 错误共享综合征：仿射完备族的跨重量综合征简并恰为 0（对照：PG 完备族为 1/3）。

*证明*。单量子比特错误 $X_a$ 的综合征是列 $\mathrm{col}_a$，其常量坐标为 1（常量单项式在 $a$ 处的赋值为 1）。重量-2 $XX$ 错误的综合征为 $\mathrm{col}_a \oplus \mathrm{col}_b$，其常量坐标为 $1 \oplus 1 = 0$。常量坐标——仿射构造的新要素，射影构造中不存在——阻断等式 $0 \ne 1$。在 PG 族中常量坐标不存在，两列的 XOR 仍是列，产生 1/3 跨层简并。∎

**定理 6**（$r \ge 2$ 时重量-2 层完全唯一）。对 $r \ge 2$，任意两个不同的重量-2 错误图样具有不同综合征：重量-2 层内部简并为零，恢复表在重量 1 与 2 处无冲突。

*证明*。设 $\{a,b\} \ne \{a',b'\}$ 共享综合征。则对每个次数 $\le r$ 的单项式 $f$，$f(a) + f(b) = f(a') + f(b')$。线性部分（$f = x_i$）给出 $a + b = a' + b'$：两对构成平行四边形。二次部分（$f = x_i x_j$）给出对所有 $(i,j)$ 有 $s_i \delta_j + s_j \delta_i = 0$，其中 $s = a+b$，$\delta = a + a'$。非平凡解要求 $s \parallel \delta$；在 $\mathbb{F}_2$ 上 $s = \delta$，即两对重合——矛盾。故所有综合征互异。（对 $r = 1$ 线性部分不足：出现平行四边形简并，如 $\mathrm{RM}(1,5)$：496 对坍缩为 31 类——$r=1$ 异常在第 5 节失效率分析中定量刻画。）∎

### 3.4 逻辑算符计数

**定理 7**（逻辑算符计数）。$\mathrm{CSS}(\mathrm{RM}(r,m))$ 中 $X$ 型重量-$d$ 逻辑算符的数目等于 $\mathrm{AG}(m,2)$ 的 $(r+1)$ 维仿射平坦集数目：

$$N_{\mathrm{logic}} = 2^{\,m-r-1}\left[\begin{matrix}m\\ r+1\end{matrix}\right]_2 = 2^{\,m-r-1}\prod_{i=0}^{r}\frac{2^{m-i}-1}{2^{r+1-i}-1}.$$

*证明*。$C^\perp = \mathrm{RM}(m-r-1,m)$ 的重量 $d = 2^{r+1}$ 向量恰为 $(r+1)$-平坦集的指示函数（第 2.2 节），其数目即平坦计数。每个这样的向量位于 $L \setminus C$ 中，因为 $\min\mathrm{wt}\,\mathrm{RM}(r,m) = 2^{m-r} > 2^{r+1}$；由定义 2.2（$L = S^\perp$）每个都是逻辑算符。∎

该闭式已在小时模下穷举验证：$\mathrm{RM}(1,5)$：1240 个重量-4 逻辑算符，等于 $\mathrm{AG}(5,2)$ 的 2-平坦计数；$\mathrm{RM}(1,6)$：10416，即 $\mathrm{AG}(6,2)$ 的 2-平坦计数（$\binom{64}{4}$ 图样完全枚举，2.8 秒）。

## 4. 相干 θ 倾斜噪声与零损失结构

本节分析第 3 节几何码族对相干单量子比特旋转的响应。关键结构事实为：(i) 单量子比特旋转的检测概率有闭式 $\sin^2(\theta/2)$；(ii) 重量低于阈值 $d/2$ 的错误*完全可恢复*（零损失定理）；(iii) 简并在恰好的重量层 $w_0 = \lceil d/2\rceil$ 重新出现，其结构由仿射平坦集的包含关系支配；(iv) 由此最优译码器的逻辑损失按 $\theta^{2\lceil d/2\rceil}$ 标度，系数由平坦计数确定。

### 4.1 检测闭式与不可检测逻辑方向

回顾第 2.3 节的注入模型：每个物理量子比特 $i$ 经历独立相干旋转
$U(\theta_i) = \cos(\theta_i/2)\,I + i\sin(\theta_i/2)\,E_i$，其中 $E_i \in \{X_i,Y_i,Z_i\}$，$\theta_i \le \theta_{\max}$。稳定子码的综合征以投影方式测量；稳定子生成元 $g$ 的检测结果是注入后 $\langle \psi | g | \psi \rangle$ 的符号。

**命题 8（检测闭式）**。设 $U(\theta) = \cos(\theta/2)\,I + i\sin(\theta/2)\,E$ 为单量子比特上的相干注入，$E$ 为与所测稳定子生成元反交换的 Pauli 错误。则：
(a) 检测概率为 $p_{\det}(\theta) = \sin^2(\theta/2)$，与码及综合征线无关；
(b) 未检测分支的条件保真度恰为 $1$（未检测注入将态投影回码空间）；
(c) 逻辑算符注入 $\bar X$ 或 $\bar Z$ 产生恒零综合征；作用于逻辑零态时，$\bar Z$ 型注入为全局相位（零损失），$\bar X$ 型注入产生损失 $\sin^2(\theta/2)$。

*验证*。对码 $[[5,1,3]]$、$[[7,1,3]]$、$[[9,1,3]]$ 的全部量子比特与全部 Pauli 类型做直接态矢量模拟，$\theta \in [0.05, 0.4]$，与闭式的最大偏差为 $3.8\times10^{-16}$（检测率）与 $2.2\times10^{-16}$（条件保真度）（本文工作）。闭式 (a) 是旋转态的 $E$ 分量被检测的概率；由于 $U(\theta)$ 制备叠加 $\cos(\theta/2)|\psi\rangle + i\sin(\theta/2)E|\psi\rangle$ 且 $E$ 分支与 $g$ 反交换，检测概率为 $|\sin(\theta/2)|^2$。∎

性质 (b) 即"未检测注入无害"原理：漏检使态留在码空间内，故不破坏逻辑信息；只有被检测分支触发恢复。性质 (c) 反映逻辑算符按定义与所有稳定子交换。

### 4.2 零损失定理

以下结构结果表明，重量低于 $d/2$ 的相干注入*完美*可纠：最小重量译码器精确恢复它们，恢复后损失恒为零。

**定理 9（零损失定理）**。设 $\mathcal{C} = [[n,k,d]]$ 为最小距离 $d$ 的任意 CSS 码。在任意 $t \le \lfloor(d-1)/2\rfloor$ 个量子比特的集合上注入相干旋转 $U(\theta_j) = \exp(i\theta_j P_j/2)$，$P_j$ 为 Pauli 算符，$\theta_j \le \theta_{\max}$ 任意。综合征测量与最小重量译码之后，损失恒为零：对每个实现 $\mathrm{loss} = 0$。

*证明*。将注入态按 Pauli 基展开：它是项 $\chi_S$（$S \subseteq$ 注入集，$|S| \le t$，$\chi_S$ 为 $S$ 上重量 $|S|$ 的错误）的叠加。固定 $S$，$w = |S| \le \lfloor(d-1)/2\rfloor$。假设某错误 $R'$ 重量 $w' < w$ 与 $\chi_S$ 同综合征。则 $\chi_S \cdot R' \in C^{\perp}$ 且其重量满足 $w + w' - 2|S \cap R'| \le 2w - 1 \le d - 2 < d$，与 $C^{\perp}$ 最小重量为 $d$ 矛盾。再假设同重量 $w$ 的不同错误 $R'$ 共享综合征；则 $\chi_S \cdot R'$ 重量 $\le 2w - 2 < d$，同样矛盾。故 $\chi_S$ 的综合征唯一，最小重量译码唯一选取 $R = \chi_S$，恢复完美。对所有分支求和，损失为零。∎

**推论 10**。对仿射完备码 $[[64,20,8]]$（第 3 节），任意 $\le 3$ 个量子比特上的注入经最优恢复后产生恒零损失。作为对照，射影几何码 $[[15,7,3]]$ 在重量 2 处即开始损失：共线对共享单量子比特错误的综合征（第 3.1 节），故最小重量译码器施加单量子比特纠正并留下重量-3 逻辑残差，损失 $\theta^4$。

该推论量化了"距离购买噪声免疫"：$d=8$ 码对至多三个量子比特上的相干扰动完全免疫，而 $d=3$ 码对两量子比特联合扰动已付出 $\theta^4$ 代价。

对典范最小成员 $[[16,6,4]]$（$m = 4$，$r = 1$），定理 9 保证每个单量子比特注入（$w = 1 < d/2 = 2$）损失恒为零；唯一可测量的签名是命题 8 的检测概率 $\sin^2(\theta/2)$——在扩展到表 1 更大成员之前，这是对零损失结构的 16 量子比特实验室检验。

### 4.3 简并层级：包含等价与全简并边界

零损失定理将首个可能损失的层钉在重量 $w_0 = \lceil d/2\rceil$。对仿射完备族，$d = 2^{r+1}$ 为偶数，$w_0 = 2^r$。该层是否简并——以及简并程度——由纯几何判据决定。

**定理 11（包含等价）**。设 $\mathcal{C} = CSS(RM(r,m))$ 为仿射完备码，$d = 2^{r+1}$，$C^{\perp} = RM(m-r-1,m)$。对重量 $2^r$ 的 $X$-错误 $\chi_A$（$A \subset AG(m,2)$，$|A| = 2^r$），以下等价：
(i) $\chi_A$ 具有不同同重量伙伴 $\chi_B$ 且综合征相同；
(ii) $A$ 包含于某个 $(r+1)$-平坦集 $P$（$|P| = 2^{r+1}$）。
此时 $B = P \setminus A$（补伙伴）且 $\chi_A \oplus \chi_B = \chi_P \in C^{\perp}$。

*证明*。(ii)$\Rightarrow$(i)：$B = P\setminus A$ 有 $|B| = 2^{r+1} - 2^r = 2^r$，且 $\chi_P = \chi_A \oplus \chi_B$ 是 $s$-平坦集的指示函数，即次数 $m - s$ 的多项式；$s = r+1$ 时它属于 $RM(m-r-1,m) = C^{\perp}$。故 $\mathrm{syndrome}(\chi_A) = \mathrm{syndrome}(\chi_B)$。
(i)$\Rightarrow$(ii)：同综合征给出 $\chi_A \oplus \chi_B \in C^{\perp}$，重量 $\le 2^{r+1} = d$；由于 $d$ 是 $C^{\perp}$ 的最小重量，重量等于 $d$，故 $\chi_A \oplus \chi_B$ 是 $C^{\perp}$ 的最小重量向量。$RM(m-r-1,m)$ 的最小重量向量恰为 $(r+1)$-平坦集的指示函数：将 $\chi_P = \prod_{i=1}^{m-r-1}(1 + \ell_i)$ 写作线性无关仿射型 $\ell_i$ 之积，零集 $P = \{v : \ell_i(v) = 0\ \forall i\}$ 是维数 $m - (m-r-1) = r+1$ 的仿射子空间。故 $A \sqcup B = P$ 且 $A \subset P$。∎

对重量 $w < 2^r$，同一论证完全排除简并：$\chi_A \oplus \chi_B$ 重量 $\le 2w < d$，不在 $C^{\perp}$ 中。这恢复了第 3.3 节对低于 $d/2$ 各层的零简并，并将其推广到所有 $w < 2^r$。

**定理 12（全简并边界）**。$CSS(RM(r,m))$ 的重量 $2^r$ 层完全简并（每个 $2^r$-子集都包含于某个 $(r+1)$-平坦集）当且仅当 $r \le 2$。

*证明*。$A \subset (r+1)$-平坦集当且仅当 $A$ 的仿射张成维数 $\le r+1$，当且仅当 $A$ 的 $2^r - 1$ 个差向量张成维数 $\le r+1$ 的空间。对 $r=1$ 只有一个差向量（秩 $\le 1 \le 2$）；对 $r=2$，4-子集的三个差向量满足秩 $\le 3 = r+1$（$\mathbb{F}_2^m$ 的三个向量至多张成维数 3）。对 $r \ge 3$，$2^r - 1 > r+1$，一般 $2^r$-子集的仿射张成维数为 $2^r - 1$（$m$ 增大时概率 $\to 1$），故不包含于任何 $(r+1)$-平坦集。∎

*数值确认*（$m=8$，$10^5$ 个随机 8-子集）：仿射张成秩 4、5、6、7 的计数分别为 15、1839、33744、64402；64.4% 的 8-子集有最大秩 7，确认一般 $2^r$-子集避开 $(r+1)$-平坦集。

边界 $r \le 2$ 意味着：距离 $d = 4$ 与 $d = 8$ 的码有*完全*简并的中间层，而 $d \ge 16$ 的码仅部分简并。定量比例是纯组合量。

**命题 13（简并比例，闭式）**。对 $CSS(RM(r,m))$，拥有同重量伙伴的重量 $2^r$ 错误的占比 $P_r(m)$ 为

$$P_r(m) = \frac{\mathrm{flats}(m,r{+}1)\,E(r{+}1,2^r) + \mathrm{flats}(m,r)}{\binom{2^m}{2^r}},$$

其中 $\mathrm{flats}(m,k) = 2^{m-k}\left[\begin{smallmatrix}m\\ k\end{smallmatrix}\right]_2$ 计数 $AG(m,2)$ 的 $k$-平坦集（高斯二项式系数乘以平移因子 $2^{m-k}$），$E(k,s) = \binom{2^k}{s} - \sum_{j<k}\mathrm{flats}(k,j)\,E(j,s)$ 计数固定 $k$-平坦集中仿射张成恰为 $k$ 的 $s$-子集（容斥）。第一项计数张成恰为 $r+1$ 的 $2^r$-子集（伙伴 = 平坦补集），第二项计数整个 $r$-平坦集的 $2^r$-子集（张成恰为 $r$，每个平坦集一个无伙伴类）。

*性质*。对 $r = 1,2$ 公式恒等于 $1$（组合恒等式：每个 2-子集张成 $\le 2$ 维；每个 4-子集张成 $\le 3$ 维）。对 $r = 3$：$P_3(6) = 7.56\times10^{-3}$，$P_3(7) = 8.49\times10^{-4}$，$P_3(8) = 1.007\times10^{-4}$，$P_3(9) = 1.227\times10^{-5}$，$P_3(10) = 1.514\times10^{-6}$，逐项比值 $\approx 8.2$–$8.9 \approx 2^3$，确认近似 $P_r(m) \approx 2^{-(2^r - r - 2)(m - r - 1)}$ 的前导指数 $3(m-4)$。该闭式匹配 $[[256,70,16]]$ 的三个独立数值判据（秩检验、组合计数、综合征匹配）（测得 $1.5\times10^{-4}$ 与 $1.2\times10^{-4}$，对比 $1.007\times10^{-4}$，$1.3\sigma$ 以内）与 $[[512,252,16]]$（$2.0\times10^{-5}$ 对比 $1.227\times10^{-5}$，$1\sigma$）。

两点说明。其一，早先"独立均匀秩分布"估计（Sternberg 公式）对 $m=8$ 高估真实比例 6.6 倍：$s$-子集的差向量受互异性约束，并非独立。其二，该比例对每个 $r \ge 1$ *严格为正*：任何 $(r+1)$-平坦集含 $2^{r+1}$ 个点，其中任意 $2^r$ 个点的选取都满足包含条件。正性——而非全简并——正是第 5 节标度律所需。

### 4.4 距离–噪声标度律

汇集本节要素：

**定理 14（距离–噪声标度律）**。设 $\mathcal{C}$ 为距离 $d$ 的几何完备 CSS 码（射影几何，$d = 3$；或仿射完备，$d = 2^{r+1}$）。在每量子比特上界 $\theta_{\max}$ 的独立相干噪声下，最优（最小重量）译码器的损失满足

$$\mathrm{loss}(\theta_{\max}) \;\sim\; \theta_{\max}^{\,2\lceil d/2\rceil} \quad (\theta_{\max} \to 0),$$

即 $d = 3$ 时为 $\theta^4$，偶 $d$ 时为 $\theta^d$。

*证明*。将注入态展开为振幅量级 $\theta^w$ 的重量-$w$ 分支。$w < w_0 := \lceil d/2\rceil$ 的分支有唯一综合征（定理 9 的论证逐字适用），贡献零损失。在重量 $w_0$ 处简并可能发生，且对几何完备族以严格正比例出现：对 PG 码（$d=3$，$w_0=2$）每个重量-2 错误都简并（仅共线机制即占该层的 $1/3$）；对 AG 码，包含等价（定理 11）与 $P_r(m)$ 的正性保证在 $w_0 = 2^r$ 处简并。在同层简并类（大小 $v$）内，译码器以概率 $(v-1)/v \ge 1/2$ 出错；对 PG 族，$|0_L\rangle$ 编码损失分数为 $4/9$（定理 17(i)）。故最低非零损失阶为 $(\theta^{w_0})^2 = \theta^{2w_0}$，由重量-$w_0$ 层贡献；更高重量分支贡献 $o(\theta^{2w_0})$。∎

*实例*。(i) $d = 3$：码 $[[5,1,3]]$、$[[7,1,3]]$、$[[9,1,3]]$ 在 $\theta_{\max} \in [0.05, 0.4]$ 上测得双对数斜率 $4.04, 4.12, 4.14$（本文工作）；$[[15,7,3]]$ 码固定 4 量子比特注入给出损失 $= 6\cos^4(\theta/2)\sin^4(\theta/2) \sim 3\theta^4/8$，斜率 $3.99 \approx 4$（本文工作）。(ii) $d = 8$：$[[64,20,8]]$ 码、4 量子比特注入，斜率 $7.96 \approx 8$，重量-4 分支失效率 $48.5\%$（200 次试验），对照理论值 $50.7\%$（本文工作）。$d=3$ 与 $d=8$ 码之间 $\theta^4$ 对 $\theta^8$ 的四阶差距是第 8 节的实验判别器。

## 5. 统一标度律与失效率闭式

定理 14 的标度律确定指数；本节统一框架以闭式确定*系数*。损失展开按重量层组织；每个系数分解为组合计数 $C(n,w)$、简并比例 $P(w)$ 与条件失效率 $\mathrm{fail}(w)$，后者仅依赖综合征几何——而非噪声信道。该信道无关性即 Pauli 信道普适性定理（第 5.5 节）的内容。

### 5.1 分支级损失展开

**定理 15（分支级损失展开）**。设 $\mathcal{C} = [[n,k,d]]$ 为几何完备 CSS 码，公共上界 $\theta$ 的独立相干旋转作用于全部 $n$ 个量子比特。最小重量译码的损失有展开

$$\mathrm{loss}(\theta) = \sum_{w \ge w_0} C(n,w)\,P(w)\,\mathrm{fail}(w)\,\left(\tfrac{\theta}{2}\right)^{2w}\left(1 - \tfrac{\theta^2}{4}\right)^{n-w},$$

其中 $P(w)$ 为综合征非唯一的重量-$w$ 错误（简并错误）的比例，$\mathrm{fail}(w)$ 为重量-$w$ 层的条件译码失效率。

*证明概要*。每个量子比特的旋转展开为 $\cos(\theta/2)\,I + i\sin(\theta/2)\,E$；恰在集合 $S$（$|S| = w$）上出错的项携带振幅 $\sin^w(\theta/2)\cos^{n-w}(\theta/2)$，故前导概率权重为 $(\theta/2)^{2w}(1 - \theta^2/4)^{n-w}$。这样的集合有 $C(n,w)$ 个；其中比例 $P(w)$ 位于最小重量译码器可能出错的简并类；在简并条件下失效率为 $\mathrm{fail}(w)$。由定理 9，$w < w_0$ 各层有 $P(w) = 0$；求和从 $w_0$ 开始。∎

对奇 $d$，层 $w_0 = (d+1)/2$ 简并。在 $|0_L\rangle$ 编码下，简并类的损失由残差逻辑算符的*类型*决定：含 $X$ 分量的残差翻转态（损失）；纯 $Z$ 逻辑残差在 $|0_L\rangle$ 上作用为 $\pm 1$（无损失）。对 PG 完备族（$d = 3$），类型 $XX, XY, YX, YY$（占层的 $4/9$）留下含 $X$ 分量的逻辑残差（共线算符 $X_aX_bX_c$ 与 $Y_aY_bY_c$；$XX$ 经重量 $d - w_0 = 1$ 的跨层伙伴 $X_c$），$XZ, ZX$（$2/9$）完美恢复，$YZ, ZY, ZZ$（$3/9$）留下纯 $Z$ 逻辑算符：总计 $\mathrm{fail}(2) = 4/9$。对偶 $d$，$w_0 = d/2$ 且所有伙伴同层；大小为 $v$ 的类内译码器以概率 $(v-1)/v$ 出错，故 $\mathrm{fail}(w_0) = 1 - \langle 1/v \rangle$，即对类的平均。类大小本身为闭式：见定理 18。

### 5.2 统一标度律

**定理 16（统一标度律——主定理）**。设 $\mathcal{C} = [[n,k,d]]$ 为几何完备 CSS 码。在每量子比特上界 $\theta$ 的独立相干噪声下，最优译码器的损失为

$$\mathrm{loss}(\theta) = C(n,w_0)\,P(w_0)\,\mathrm{fail}(w_0)\,2^{-2w_0}\,\theta^{2w_0} \;+\; O\!\left(\theta^{2w_0+2}\right), \qquad w_0 = \lceil d/2\rceil,$$

其中 $C(n,w_0)$ 为二项式系数，$P(w_0)$ 为简并比例（AG 码用命题 13；PG 码 $P(2) = 1$），$\mathrm{fail}(w_0)$ 为下面定理 17 的奇偶相关失效率（PG 码在 $|0_L\rangle$ 编码下 $\mathrm{fail}(2) = 4/9$）。等价地，$\mathrm{loss}(\theta) = c_d\,\theta^{2w_0} + o(\theta^{2w_0})$，其中

$$c_d = C(n,w_0)\,P(w_0)\,\mathrm{fail}(w_0)\,2^{-2w_0}.$$

*证明*。定理 14 与 15：低于 $w_0$ 的各层消失；前导项是展开的 $w = w_0$ 分支，$(1 - \theta^2/4)^{n-w_0} = 1 + O(\theta^2)$。∎

**定理 17（失效率奇偶性定理）**。在定理 16 的设定下：
(i) 若 $d$ 为奇，前导层简并，且在 $|0_L\rangle$ 编码下失效率是残差逻辑算符含 $X$ 分量的重量-$w_0$ 错误的占比（纯 $Z$ 逻辑残差在 $|0_L\rangle$ 上作用为 $\pm 1$，无损失）。对 PG 完备族（$d = 3$，$w_0 = 2$），类型 $XX, XY, YX, YY$（占层的 $4/9$）留下含 $X$ 分量的逻辑残差（重量-3 共线），类型 $XZ, ZX$（$2/9$）完美恢复，$YZ, ZY, ZZ$（$3/9$）留下纯 $Z$ 逻辑算符：$\mathrm{fail}(2) = 4/9$；
(ii) 若 $d$ 为偶，$\mathrm{fail}(w_0) = 1 - \langle 1/v \rangle$，其中 $v$ 遍历重量 $w_0$ 处简并类大小，$\langle \cdot \rangle$ 为按类大小加权的平均。

*证明*。(i) 在 CSS 分裂译码下，重量-$w_0$ 错误 $\chi_A = X_x Z_z$ 的残差为 $\chi_A R$，$R = X_a Z_b$，其中 $a$ 是 $H a = H x$ 的唯一重量 $\le 1$ 解，$b$ 是 $H b = H z$ 的唯一重量 $\le 1$ 解（对 PG 完备族每个非零综合征都是列，故重量-1 解总存在）。若残差为恒等则恢复完美；若为纯 $Z$ 逻辑算符则在 $|0_L\rangle$ 上作用为 $\pm 1$（无损失）；若含 $X$ 分量则态被翻转到正交逻辑态（损失）。对 PG 完备族（$d = 3$）：$X_aX_b$（综合征 $(0, \mathrm{col}_a \oplus \mathrm{col}_b)$）留下 $X_aX_bX_c$；$X_aY_b$ 与 $Y_aX_b$ 留下同一 $X$-共线残差；$Y_aY_b$ 留下 $Y_aY_bY_c = X_aX_bX_c\,Z_aZ_bZ_c$；每个都含 $X$ 分量：损失。$X_aZ_b$ 与 $Z_aX_b$ 被精确恢复。$Y_aZ_b$、$Z_aY_b$、$Z_aZ_b$ 留下纯 $Z$ 共线算符 $Z_aZ_bZ_c$：无损失。故 $\mathrm{fail}(2) = 4/9$。(ii) 重量-$w_0$ 错误的所有伙伴重量均为 $w_0$（任何更低重量都与唯一性矛盾）；译码器在 $v$ 个类成员间均匀选择；恰有一个正确。∎

对仿射完备族，平均 $\langle 1/v \rangle$ 可由类大小闭式计算：

**定理 18（类大小闭式）**。对 $CSS(RM(r,m))$，设 $A$ 为 $AG(m,2)$ 的 $2^r$-子集，仿射张成维数为 $s$（$0 \le s \le r+1$）。$\chi_A$ 在重量 $2^r$ 处的综合征类大小为

$$v(A) = 1 + \left[\begin{smallmatrix}m-s\\ r+1-s\end{smallmatrix}\right]_2,$$

即计数 $(m-s)$ 维商空间 $AG(m,2)/\mathrm{span}(A)$ 中 $(r+1-s)$ 维子空间的高斯二项式系数；$+1$ 计数 $\chi_A$ 本身。

*证明概要*。由定理 11，$\chi_A$ 的伙伴是所有 $(r+1)$-平坦集 $P \supset A$ 的补 $P \setminus A$。含 $A$ 的平坦集与商空间 $AG(m,2)/\mathrm{span}(A)$ 中维数 $(r+1-s)$ 的平坦集一一对应；其数目为高斯二项式系数 $\left[\begin{smallmatrix}m-s\\ r+1-s\end{smallmatrix}\right]_2$。∎

*实例*。$r = 1$（$d = 4$）：任意 2-子集张成 $s = 1$，给出 $v = 1 + \left[\begin{smallmatrix}m-1\\ 1\end{smallmatrix}\right]_2 = 2^{m-1}$：类大小 $2^{m-1}$（如 $[[32,20,4]]$ 的 $v = 16$，匹配"465 对 $= 31\times 15$"枚举；最小成员 $[[16,6,4]]$ 的 $m = 4$ 给出 $v = 8$）。对 $[[16,6,4]]$，前导层完全简并且类大小均匀为 8，定理 16 给出闭式

$$\mathrm{loss}(\theta) = C(16,2)\cdot\tfrac{7}{8}\cdot 2^{-4}\,\theta^4 + O(\theta^6) = \tfrac{105}{16}\,\theta^4 + O(\theta^6),$$

即斜率-4 损失，闭式系数 $105/16 \approx 6.56$——第 8 节判别器的最小规模实例。$r = 2$（$d = 8$）：一般 4-子集有 $s = 3$，$v = 2$（补对——$[[64,20,8]]$ 的 313,131 个类）；共面 4-子集有 $s = 2$，$v = 2^{m-2}$——双峰类结构 $2$ / $2^{m-2}$。由此 $[[64,20,8]]$ 的 $\mathrm{fail}(4) = 1 - \langle 1/v\rangle = 0.507172131$（完全枚举：635,376 个重量-4 错误中 322,245 个失败），匹配测得值 50.7%。

### 5.3 次前导阶：$\theta^{d+2}$ 项

层 $w_0 + 1$ 产生首个次前导阶。其简并为*跨层*，伙伴在重量 $w_0 - 1$：

**命题 19（重量-$(2^r+1)$ 简并）**。对 $CSS(RM(r,m))$，在重量 $2^r - 1$ 处有伙伴的重量-$(2^r+1)$ 错误的比例为

$$P'_r(m) = \frac{\mathrm{flats}(m,r{+}1)\,\binom{2^{r+1}}{2^r{+}1}}{\binom{2^m}{2^r{+}1}},$$

取值 $P'_2(6) = 0.08197$，$P'_2(7) = 0.0400$，$P'_2(8) = 0.01976$，$P'_2(9) = 9.82\times10^{-3}$，$P'_2(10) = 4.90\times10^{-3}$；$P'_3(8) = 3.26\times10^{-6}$，$P'_3(9) = 1.95\times10^{-7}$。

*证明概要*。$\chi_{A'}$（$|A'| = 2^r + 1$，$|B| = 2^r - 1$）的伙伴 $\chi_B$ 要求 $\chi_{A'} \oplus \chi_B \in C^{\perp}$ 重量为 $d$，即乘积是 $(r+1)$-平坦集指示函数且 $A' \sqcup B = P$。由于 $|A'| = 2^r + 1$ 超过任何 $r$-平坦集的大小，$A'$ 的张成自动为 $r+1$；计数为平坦计数乘以 $P$ 内 $A'$ 的选择数。∎

**定理 20（$\theta^{d+2}$ 次前导阶）**。对偶距离 $d = 2^{r+1}$ 的仿射完备码，

$$\mathrm{loss}(\theta) = c_d\,\theta^{d} + C(n,2^r{+}1)\,P'_r(m)\,2^{-2(2^r+1)}\,\theta^{d+2} + o(\theta^{d+2}),$$

其中 $c_d$ 为定理 16 的系数，$P'_r(m)$ 由命题 19 给出。

*证明概要*。重量-$(2^r+1)$ 分支携带振幅量级 $\theta^{2^r+1}$；在简并比例 $P'_r(m)$ 上，最小重量译码器必然选择重量-$(2^r - 1)$ 伙伴（所有更低重量唯一，且伙伴类是唯一匹配——与任何重量 $\le 2^r$ 错误的乘积重量为 $d + 2 - 2|\cap|$ 或 $\ge 17$，不在 $C^{\perp}$ 重量谱中，$[[256,70,16]]$ 的 2000/2000 采样验证）。残差是平坦集指示函数，即最小重量逻辑算符：必然失败，无 $1/2$ 因子。∎

*量级*。对 $r = 2$，$m = 6$：$P'_2(6) = 0.082$ 对比前导每错误失效率 $\mathrm{fail}(4) = 0.507$——次前导项可见；对 $r = 3$，$m = 8$：$P'_3(8) = 3.3\times10^{-6}$ 对比 $P_3(8)/2 \approx 5\times10^{-5}$——基本不可见。大距离码日益纯粹地被 $\theta^d$ 支配。该阶的逻辑 $Z$ 翻转分数为 $\kappa_r(m)$：残差最小重量逻辑算符 $\chi_P$ 与逻辑 $Z$ 可观测量 $z_l$ 反交换的译码失败占比——等价地，逻辑 $Z$ 翻转损失与译码失败损失之比。对仿射完备族它是闭式，

$$\kappa_r(m) = \frac{2^{(r+1)(m-r-1)}}{\left[\begin{smallmatrix}m\\ r+1\end{smallmatrix}\right]_2}.$$

机制：残差 $\chi_P$ 是 $(r+1)$-平坦集 $P$ 的指示函数（$C^\perp$ 的最小重量向量），反交换相位为 $\chi_P \cdot z_l = |P \cap z_l| \bmod 2$，其中 $z_l$ 支撑在固定 $(m-r-1)$-平坦集 $W$（互补维数）上。写 $P = p + U$，$\dim U = r+1$，则 $|P \cap z_l| \bmod 2 = [U \cap W = \{0\}]$：互补子空间横截相交于单点（奇），非互补子空间相交于 $2^{\dim U \cap W}$ 个点（偶）。方向 $\mathrm{dir}(P) = U$ 在 $\mathbb{F}_2^m$ 的 $(r+1)$ 维子空间间均匀分布，因为前导层的类结构仅依赖商几何；与固定 $W$ 互补的子空间数为 $2^{(r+1)(m-r-1)}$（补计数），$(r+1)$-子空间总数为高斯二项式系数 $\left[\begin{smallmatrix}m\\ r+1\end{smallmatrix}\right]_2$。故 $\kappa$ 是码内禀量：与译码器的类内选择规则无关，且不受相干干涉影响——如 $\kappa_1(4) = 0.4571$ 复现 $[[16,6,4]]$ 完整态矢量模拟比值 $0.45$，$\kappa_2(6) = 0.367025$ 匹配 $[[64,20,8]]$ 的完全枚举，$m = 10$ 的值 $0.3761, 0.3304, 0.3122, 0.3072$（$r = 1,2,3,4$）正是第 8 节实验窗口所用。翻转分数将定理 16 的译码失败系数转化为实验测量的逻辑 $Z$ 翻转系数。

### 5.4 Pauli 信道普适性

整个框架从相干旋转推广到任意独立每量子比特 Pauli 信道，失效率不变：

**定理 21（Pauli 信道普适性）**。设噪声为 $X$ 侧错误概率 $\varepsilon$ 的独立每量子比特 Pauli 信道（错误算符含 $X$ 或 $Y$ 分量、即翻转 $X$-综合征的概率；$Z$ 错误对 $X$ 侧不可见）。对采用最小重量译码的几何完备 CSS 码，$X$ 侧译码损失为

$$\mathrm{loss}(\varepsilon) = \sum_{w \ge w_0} C(n,w)\,\varepsilon^{w}(1-\varepsilon)^{n-w}\,\mathrm{fail}(w) = C(n,w_0)\,\varepsilon^{w_0}\,\mathrm{fail}(w_0) + C(n,w_0{+}1)\,\mathrm{fail}(w_0{+}1)\,\varepsilon^{w_0+1} + o(\varepsilon^{w_0+1}),$$

其中 $\mathrm{fail}(w)$ 为*无条件*重量-$w$ 译码失效率——定理 15 的乘积 $P(w)\,\mathrm{fail}(w)$——与相干情形相同：译码器是综合征与重量的确定性函数，信道对它不可见。确实，$Y_i$ 的 $X$ 侧作用等于 $X_i$（$Y_i X_v = (-1)^{v_i} X_v Y_i$ 翻转同样的 $X$-综合征位），而 $Z_i$ 不触动 $X$-综合征。

*证明*。$X$ 活动错误集 $\mathcal{A} = \{i : e_i \in \{X_i, Y_i\}\}$ 每量子比特独立，$P(|\mathcal{A}| = w) = C(n,w)\varepsilon^w(1-\varepsilon)^{n-w}$；在 $\mathcal{A}$ 条件下，综合征等于纯 $X$ 注入的综合征，故失败概率为 $\mathrm{fail}(w)$；对 $w$ 求和。∎

**信道常数**。同一公式覆盖所有标准信道：相干 $\theta$-倾斜有 $\varepsilon = \sin^2(\theta/2)$（定理 16 是特例）；速率 $p$ 的去极化噪声有 $\varepsilon = 2p/3$；相位阻尼（Pauli 扭对称化后）有 $\varepsilon = 0$（纯 $Z$）；振幅阻尼（Pauli 扭对称化后）有 $\varepsilon = \gamma/2$。*边界*：未扭对称化的相干非 Pauli 过程（如原始振幅阻尼 Kraus 算符 $K_1 = \sqrt{\gamma}|0\rangle\langle 1|$）以概率方式响应（$\pm 1$ 各半）而非确定性综合征翻转，超出定理范围；标准 Pauli 扭对称化实验协议将其带回。

*验证*（$[[64,20,8]]$）：(i) 含 $X$/$Y$ 混合的重量-4/5 层（200,000 样本，各半）逐样本给出与纯 $X$ 注入完全相等的失效率；(ii) 完全枚举给出 $\mathrm{fail}(4) = 0.507172131$（322,245/635,376）与 $\mathrm{fail}(5) = 0.846994536$（6,457,920/7,624,512）；(iii) 完全去极化 $p = 0.02$（1,000,000 样本）给出测得损失 $0.005944 \pm 0.000077$，对照闭式 $\sum_{w\ge 4} C(64,w)(2p/3)^w(1-2p/3)^{64-w}\mathrm{fail}(w) = 0.005969$（$w \ge 6$ 项按 $\mathrm{fail} \approx 0.85$ 贡献 $1.85\times10^{-4}$）：$-0.33\sigma$ 吻合。

## 6. 仿射完备码上的横向操作

码族可用的门集合与其纠错参数同等重要。本节刻画仿射完备族 $\mathrm{CSS}(H,H)$（$2r < m-1$）的横向操作。任何有限维码都不可能实现普适量子门集合（Eastin–Knill 不可行定理 [18]），稳定子码的横向结构由文献 [19] 刻画；本文所考虑的族饱和了允许集合的 Clifford 部分（定理 22）。所有断言都在第 6.5 节以符号方式与态矢量模拟双重验证。

### 6.1 横向 Clifford 子集

**定理 22（横向 Clifford 子集）**。对每个满足 $2r < m-1$ 的仿射完备码 $\mathrm{CSS}(H,H)$，以下门是横向的：

(i) *Pauli 门*。$v, w \in C$ 的 $X_v$ 与 $Z_w$ 是横向稳定子（支撑上的单量子比特 Pauli）；$v, w \in C^\perp \setminus C$ 的 $X_v$ 与 $Z_w$ 实现逻辑 $X$ 与 $Z$ 算符。

(ii) *CNOT*。两个码块对应物理量子比特之间的 CNOT 将码空间映射到自身并实现逻辑 CNOT。这对所有 CSS 码由标准论证成立：$X$ 错误从控制端传播到目标端，$Z$ 错误从目标端传播到控制端，稳定子结构 $C_2 \subseteq C_1$ 保持。

(iii) *Hadamard*。由于 $X$-稳定子空间与 $Z$-稳定子空间重合（由定义 3.1 均等于 $C$），$H^{\otimes n}$ 将 $X$-稳定子映射为 $Z$-稳定子并实现逻辑 Hadamard。

*证明*。(i) 由定义 3.1，$X$-与 $Z$-稳定子空间都等于 $C$，故 $v, w \in C$ 时 $X_v, Z_w$ 是稳定子。算符 $X_v$ 与所有 $Z$-稳定子 $Z_w$（$w \in C$）交换当且仅当对每个 $w \in C$ 有 $v \cdot w = 0$，即 $v \in C^\perp$；故 $v \in C^\perp \setminus C$ 的 $X_v$ 是非平凡逻辑 $X$ 算符，$w \in C^\perp \setminus C$ 的 $Z_w$ 类似实现逻辑 $Z$。(ii) 为标准 CSS 性质。(iii)：$H^{\otimes n}$ 共轭 $X_v \mapsto Z_v$；由于 $X$-与 $Z$-稳定子空间相同，稳定子映射为稳定子，逻辑算符相应变换。∎

程序验证中得到的一个有用闭式：逻辑零态满足

$$H^{\otimes n}|0_L\rangle = \frac{1}{\sqrt{|C^\perp|}} \sum_{y \in C^\perp} |y\rangle = |+_L\rangle,$$

对 $[[16,6,4]]$ 精确到机器精度（重叠度 $1.000000000000$）。

### 6.2 横向相位门

**定理 23（$S^{\otimes n}$ 相位刻画）**。设 $S = \mathrm{diag}(1,i)$。对每个满足 $2r < m-1$ 且 $m \ge 4$ 的仿射完备码：

(i) $S^{\otimes n}$ 保持码空间。确实 $S X_v S^\dagger = Y_v = X_v Z_v$，且 $v \in C$ 时 $X_v, Z_v$ 是稳定子（自正交 $v \cdot w = 0$ 与偶重量 $|v|$），故 $Y_v$ 是稳定子。

(ii) 诱导逻辑映射是*对角相位门*：逻辑零态被保持，$S^{\otimes n}|0_L\rangle = |0_L\rangle$，因为 $C$ 的所有码字重量 $\equiv 0 \pmod 4$（$r \le m-3$ 时自动成立，而 $m \ge 4$ 时 $2r < m-1$ 蕴含之）。

(iii) 逻辑方向 $a \in C^\perp \setminus C$ 获得相位

$$\gamma_a = i^{|a|},$$

其中 $|a|$ 为汉明重量。由此：$|a| \equiv 0 \pmod 4$ 的方向被固定；$|a| \equiv 2$ 实现逻辑 $Z$；$|a| \equiv 1$ 实现逻辑 $S$；$|a| \equiv 3$ 实现 $-i \cdot$ 逻辑 $S$。

*证明*。(i) 是共轭恒等式结合稳定子闭包论证。(ii)：$S^{\otimes n}|x\rangle = i^{|x|}|x\rangle$ 且对 $a \neq 0$，$\langle 1_L^a | S^{\otimes n} | 0_L \rangle \propto \sum_{x \in C} i^{|x|} \langle x+a | x \rangle = 0$，故诱导映射是对角的。(iii)：$\gamma_a = \langle 1_L^a | S^{\otimes n} | 1_L^a \rangle = \frac{1}{|C|} \sum_{x \in C} i^{|x+a|}$；利用 $|x+a| \equiv |x| + |a| - 2|x \cap a| \pmod 4$、$x \in C$ 时 $|x| \equiv 0 \pmod 4$ 以及 $a \in C^\perp$ 时 $a \cdot x = |x \cap a| \equiv 0 \pmod 2$，得到 $\gamma_a = i^{|a|}$。∎

### 6.3 容错操作集合与 T 门接口

**推论 24（容错操作集合）**。仿射完备族的横向操作集合为

$$\{\text{横向 Pauli},\ \text{横向 CNOT},\ \text{横向 } H\} \;\cup\; \{\text{横向相位门 } \mathrm{diag}(1, i^{|a|})\} \;\cup\; \{\text{逻辑测量}\},$$

其中逻辑 $\bar Z$ 通过对支撑位做 $Z$-测量后经典奇偶校验得到，逻辑 $\bar X$ 通过横向 $H$ 后 $\bar Z$ 测量得到。$T$ 门*没有*横向实现（它在 Clifford 群之外）；它通过标准魔法态蒸馏协议（如 15 到 1）接口。蒸馏只需码距离 $d \ge 5$；仿射完备族对 $r \ge 2$ 有 $d = 2^{r+1} \ge 8$，故是即插即用接口。

*证明*。定理 22–23 的直接编译；蒸馏要求是标准文献结果 [13, 14, 20–22]。∎

### 6.4 错误传播与译码封闭性

**命题 25（有界错误传播）**。在横向门下，单量子比特错误至多传播到两个量子比特（CNOT 将 $X$ 从控制端复制到目标端、$Z$ 从目标端复制到控制端；$H$、$S$ 与 Pauli 门保持错误数）。*无扩散*：每轮错误数至多增长 2 倍，与可将错误指数扩散的非横向门形成对照。

*证明*。直接追踪 Pauli 算符穿过 Clifford 电路；CNOT 的复制规则是标准容错陈述。∎

**注（与译码形式体系的封闭性）**。将命题 25 与定理 21（Pauli 信道普适性）结合，每轮纠错相互独立：错误集重量 $\ge w_0$ 的概率仍由 $\varepsilon^{w_0}$ 标度控制，故第 5 节的译码闭式逐轮适用。完整的容错阈值分析（含蒸馏资源核算）超出本文范围。

### 6.5 程序验证

$[[16,6,4]]$ 上的态矢量模拟与 $[[64,20,8]]$ 上的符号验证确认：

- **横向 $H$**：$H^{\otimes 16}|0_L\rangle = |+_L\rangle$ 精确（$|\langle +_L | H^{\otimes 16} | 0_L \rangle| = 1.000000000000$；解析形式 $H^{\otimes n}|0_L\rangle = \frac{1}{\sqrt{|C^\perp|}} \sum_{y \in C^\perp} |y\rangle$）。
- **横向 $S$**：$\alpha = \langle 0_L | S^{\otimes 16} | 0_L \rangle = 1.000000$（$\mathrm{RM}(1,4)$ 的所有码字重量 $\equiv 0 \pmod 4$）；六个单项式逻辑方向（$|a| = 4$）给出 $\gamma = 1$，复合方向 $x_1 x_2 + x_3 x_4$（$|a| = 6$）给出 $\gamma = -1$——全部与 $i^{|a|}$ 精确匹配。
- **$[[64,20,8]]$**：484 个自正交对零违反；全部 22 个基向量与 2000 个随机组合重量 $\equiv 0 \pmod 4$；$Y_v$ 与所有稳定子生成元交换——横向 $H$ 与 $S$ 的合法性被直接验证。

## 7. 与已有结果的关系

本节将本文工作置于相关文献之中。我们强调，本文的贡献*不是*新的码族——Reed–Muller CSS 构造是经典的——而是新的分析层次：几何完备族的精确闭式失效率标度，连同免枚举验证方法与实验判别器。

### 7.1 稳定子码与 CSS 构造

稳定子形式体系 [1, 8] 与 Calderbank–Shor–Steane 构造 [2, 7, 23] 提供所有 CSS 码所在的通用框架。本文定理 16（统一标度律）是对标准距离启发式——"距离 $d$ 的码纠正重量 $< d/2$ 的错误"——的*定量精化*：我们证明失效率由重量 $w_0 = \lceil d/2 \rceil$ 的错误支配，并给出精确前导系数 $C(n,w_0)P(w_0)\,\mathrm{fail}(w_0)\,2^{-2w_0}$，简并结构以闭式解析。奇偶性定理（定理 17）精化了"奇距离码更差"的民间说法：我们展示精确机制——对奇 $d$，前导层简并，且在 $|0_L\rangle$ 编码下其失效率是残差逻辑算符含 $X$ 分量的错误占比，PG 完备族给出 $\mathrm{fail}(2) = 4/9$；而偶距离码全程保留可恢复类的占比 $\langle 1/v \rangle$。

### 7.2 经典编码理论中的 Reed–Muller 码

Reed–Muller 码的经典理论已成熟：对偶定理、重量分布与最小重量刻画可追溯至 1970 年代 [9–12]。我们对经典事实的使用是标准的，量子 Reed–Muller 构造本身 [24] 及其在码转换协议中的容错使用 [25] 亦然。新的是*量子侧*闭式：类大小公式 $v(A) = 1 + [m-s; r+1-s]_2$（定理 18）以高斯二项式系数量化有多少重量-$2^r$ 错误共享综合征——一个没有经典对应物的量，因为经典译码不追踪稳定子等价。包含等价定理（定理 11）给出距离临界层简并的纯几何刻画（包含于 $(r+1)$-平坦集）。

### 7.3 简并量子码

简并——多个错误共享综合征——是典型的量子现象，自领域早期即被利用 [16, 26]。已知的精确分析包括 Shor 9 量子比特码与 Bacon–Shor 码，其中部分简并被逐例理解。本文的贡献是*系统*处理：第 4.3 节的简并层级（$d/2$ 以下零简并、$d/2$ 处包含等价、$r \le 2$ 全简并边界、其上闭式比例 $P_r(m)$）适用于距离不断增长的无穷族。全简并对 $d \ge 16$ *不可能*（定理 12）这一发现据我们所知是新的且结构上受限：它表明"良性"全简并区在该族中限于 $d \in \{4, 8\}$。

### 7.4 阈值定理与量子 LDPC 码

阈值定理 [3, 16] 与表面码/环面码分析 [15, 27, 28]（受二维存储权衡约束 [32]）确立渐近陈述：低于阈值错误率时，任意长计算皆有可能。量子 LDPC 码 [29–31] 达到常速率渐近好参数。两条工作路线都是*渐近*的；它们不提供具体码族的闭式有限大小失效率。本文标度律是互补的：对 RM-CSS 族我们给出*精确*有限大小系数（表 3），实现渐近陈述无法提供的直接实验判别（第 8 节）。反之，本文族有非常数速率（固定 $r$ 时随 $m$ 增长趋近 $1$）与距离 $d = 2^{r+1}$；它不是渐近好码的竞争者，但它是近期实验相关距离（$d = 4$–$32$）上*最可精确分析*的族。

### 7.5 实验背景

逻辑量子比特的主流实验路线是表面码 [27]，其阈值行为已被充分研究；小码的实时纠错早期即有演示 [33]。本文判别器协议（第 8 节）回答不同的问题：给定具有未知强度分布的相干（或非相干）单量子比特噪声的物理平台——已知相干错误对表面码的损害远大于其非相干对应物 [34]——能否仅从逻辑失效率*识别噪声类与码的响应*？64–1121 量子比特阶梯上的四阶斜率检验 $\theta^4/\theta^8/\theta^{16}/\theta^{32}$ 提供了与表面码基准测试正交的诊断。第 6 节的横向 Clifford 子集是进一步的实际资产：相位门 $\mathrm{diag}(1, i^{|a|})$ 在该族中可横向实现，这对一般 CSS 码并不成立。

## 8. 四阶标度律的实验判别

第 5 节的闭式直接给出预测：测得逻辑 $Z$ 翻转损失的前导系数 $c_d = \kappa_r(m)\,C(n,w_0)\,P(w_0)\,\mathrm{fail}(w_0)\,2^{-2w_0}$（$\kappa_r(m)$ 为第 5.3 节的逻辑 $Z$ 翻转分数）由码的几何结构完全确定，整数指数 $d$ 由逻辑类的几何固定。本节将其转化为 64–1121 量子比特超导平台上的可证伪协议：测量仿射完备族四个层级的 $\mathrm{loss}(\theta)$ 双对数斜率，检验斜率等于 $4, 8, 16, 32$ [35]。设计遵循第 5 与 8 节的闭式框架；下文引用的所有数字均为闭式值，而非拟合值。

### 8.1 判别目标与逻辑

**目标**。在单一噪声环境（一个平台、一次标定）中，测量四个 AG 完备码在相干注入下的损失函数 $\mathrm{loss}(\theta)$，检验几何预测

$$\mathrm{loss}(\theta) = c_d\,\theta^d + o(\theta^d), \qquad d \in \{4, 8, 16, 32\},$$

其中 $\theta$ 是施加于每个量子比特的相同单量子比特相干旋转 $R_x(\theta)$ 的角度（绕固定轴的纯类型注入；实验损失即第 5.3 节的逻辑 $Z$ 翻转率）。

**为何斜率是判别器**。(a) 非几何启发式（独立错误模型、典型码行为）无法产生带闭式系数的精确整数斜率；(b) $\theta$ 轴上的层级窗口被 $c_d$ 的闭式*阶梯分离*，阶梯（含其空隙）无法通过事后拟合获得；(c) 截距 $\ln c_d$ 被完全预测，任何偏差直接反演为 $\kappa\,\mathrm{fail}(w_0)$ 的实验值，结合 $\kappa$ 的闭式（第 5.3 节）得到 $\mathrm{fail}(w_0)$，从而*间接测量类大小* $v$（定理 17：$\mathrm{fail}(w_0) = 1 - \sum_s P(s)/\bigl(v(s)\,P(w_0)\bigr)$）。

**最小规模检验**。同一逻辑可在动用 64–1121 量子比特平台之前在 16 个量子比特上检验：典范成员 $[[16,6,4]]$ 有斜率 4 与精确系数 $105/16$（第 5.2 节），故其双对数截距 $\ln(105/16)$ 本身是闭式预测——判别器的桌面检验。

**理论输入**（$m = 10$ 闭式；$\ln c_d$ 为逻辑 $Z$ 翻转版本）：

|---|---|---|---|---|---|---|
| $d{=}4$ | $[[1024,1002,4]]$ | 4 | 2 | 0.3761 | $0.9980\,C(1024,2)/16 \times 0.3761 = 1.23\times10^{4}$ | 9.417 |

### 8.3 可观测窗口与 $\theta$ 扫描

**窗口定义**。前导阶近似 $\mathrm{loss} = c_d\,\theta^d \in [10^{-3}, 0.5]$：低于 $10^{-3}$ 需要超过 $10^9$ 发；高于 $0.5$ 前导阶失效（次前导与饱和主导）。

**定理 26（窗口阶梯）**。在 1024 量子比特平台上，四个可观测窗口 $\mathcal{W}_d = \{\theta : 10^{-3} \le c_d\theta^d \le 0.5\}$ 为

$$\mathcal{W}_4 = [0.017, 0.080], \qquad \mathcal{W}_8 = [0.049, 0.107], \qquad \mathcal{W}_{16} = [0.205, 0.302], \qquad \mathcal{W}_{32} = [0.457, 0.555],$$

层级 $8/16$ 与 $16/32$ 之间有间隙 $[0.107, 0.205]$ 与 $[0.302, 0.457]$，层级 $4/8$ 之间有重叠 $[0.049, 0.080]$。

*证明*。将第 8.1 节的闭式 $c_d$ 代入 $10^{-3} \le c_d\theta^d \le 0.5$ 并对 $\theta$ 求解；阶梯结构（窗口被空隙分离、低层级重叠）由闭式系数得出，而非拟合。∎

**$\theta$ 的控制**。注入是绕固定轴施加于每个量子比特的、具有单一公共角度的纯类型相干旋转 $R_x(\theta)$。公共角度恰对应前导阶展开的分支振幅 $(\theta/2)^{2w}$（系数 $2^{-2w_0}$），无分布平均因子。在高端点（$\theta \approx 0.5$，约 $30^\circ$ 的单量子比特旋转）注入与噪声不再可分——这正是判别区：几何预测要求精确的 $\theta^{32}$ 标度，而非几何模型（如独立比特翻转主导的 $\theta^1$）会给出斜率 1–2。

### 8.4 实验协议（暴力测量，单轮）

与实用 QEC 的关键区别：不需要非破坏性综合征测量，不需要多轮纠错。协议是单轮"制备 → 注入 → 测量全部量子比特 → 经典重构"：

1. **制备 $|0_L\rangle$**：$\mathrm{RM}(r,m)$ 的 Plotkin 递归编码电路（$O(nr)$ 个 CNOT，深度数百量级；$r=4$ 约 $10^4$ 个 CNOT）。制备保真度不必超过注入区——基线由三参数拟合吸收（第 8.5 节）。
2. **注入**：对每个量子比特施加 $R_x(\theta)$，公共角度，固定轴。
3. **暴力测量（副本法）**：每发分裂为两个副本——副本 A 直接在 $Z$ 基测量；副本 B 在逐量子比特 $H$ 后测量（等价于 $X$ 基）。由两条比特串经典重构 (i) 全部 $2\dim\mathrm{RM}(r,m)$ 个稳定子值（$Z$ 型来自副本 A，$X$ 型来自副本 B）；(ii) 逻辑 $Z$ 值（副本 A）。**无辅助比特、无非破坏性测量——1121 量子比特平台只需 1024 个数据量子比特。**
4. **译码（经典侧）**：综合征（$r=4$ 时 $772$ 位）→ 最小重量译码。由 RPA（Reed–Muller 递归投影聚合）或几何译码器（重量 $\le w_0+1$ 错误的平坦枚举）实现。实验前必须认证译码器在重量 $\le w_0+1$ 处的等价性（第 8.6 节）。
5. **估计损失**：$\mathrm{loss}(\theta) = P(\text{译码逻辑值} \neq 0_L)$——逻辑错误率（译码失败加制备基线）。
6. **统计**：每点 $N = 2\times10^5$ 发（低 $d{=}32$ 端点 $10^6$）；相对损失误差 $\sigma_{\mathrm{rel}} \approx \sqrt{1-\mathrm{loss}}/(\sqrt{N}\sqrt{\mathrm{loss}})$：$\mathrm{loss} = 5\times10^{-3}$ 时 $3.2\%$，$0.05$ 时 $1.0\%$，$0.2$ 时 $0.5\%$。

### 8.5 统计判别判据

**模型**。每个层级独立拟合三参数

$$\mathrm{loss}(\theta) = b + c\,\theta^d,$$

其中 $b$ 为基线（编码电路与测量误差）——不减去，而是联合估计，这是对基线最稳健的处理；$d$ 由非线性最小二乘估计（对 $\mathrm{loss} \gg b$ 的点做加权线性回归 $\ln\mathrm{loss} = d\ln\theta + \ln c$ 作为交叉验证）。

**定理 27（判别力）**。$\sigma_{\mathrm{rel}} = 5\%$、每层级五点，拟合 $\mathrm{loss}(\theta) = b + c\theta^d$ 的斜率估计 $\hat d$ 的标准差为

$$\sigma_d = 0.028,\ 0.062,\ 0.098,\ 0.198 \qquad (d = 4, 8, 16, 32),$$

$N = 10^6$ 时层级 32 的 $\sigma_d = 0.12$。相邻层级间隔为 $\Delta d = 4$；跨层级判别裕度为 $20$–$143\sigma$。

*证明*。五点散布在窗口的 $\ln$-跨度 $\Delta\ln\theta$ 上，斜率误差 $\sigma_d \approx \sigma_{\mathrm{rel}}/\sqrt{N_{\mathrm{eff}}}\,\Delta\ln\theta$ 标度（加权回归方差），用定理 26 的窗口跨度求值（$d = 4, 8, 16, 32$ 的 $\Delta\ln\theta = 1.099, 0.511, 0.323, 0.160$）。裕度由 $\Delta d = 4$ 得出：$143\sigma$、$65\sigma$、$41\sigma$、$20\sigma$（$N = 10^6$ 时 $33\sigma$）。∎

**四项检验**。

1. **斜率检验**（主判据）：四个层级独立满足 $|\hat d - d| \le 2\sigma$。由于相邻层级相差 $\ge 4$，斜率 $4/8/16/32$ 的分辨在统计上压倒性（$d{=}32$ 最差层级也有 $16\sigma$）。
2. **截距检验**（闭式）：$\ln \hat c_d$ 与闭式 $\ln c_d = 9.417/17.197/18.470/18.137$ 在 $3\sigma$ 内吻合。任何偏差反演为 $\kappa\,\mathrm{fail}(w_0)$ 的实验值；结合 $\kappa$ 的闭式得到 $\mathrm{fail}(w_0)$，从而*实验测量类大小* $v$——对几何类大小闭式 $v(A) = 1 + \left[\begin{smallmatrix}m-s\\ r+1-s\end{smallmatrix}\right]_2$ 的直接检验。
3. **空隙检验**：$\theta \in \{0.12, 0.15, 0.18\}$ 的补充点必须显示 (i) 层级 $16/32$ 无超出基线 $3\sigma$ 的 $\theta^d$ 型增长；(ii) 层级 $4/8$ 的饱和平台。这独立确认窗口阶梯。
4. **对照检验**：以随机 Pauli 注入（非相干，去极化速率 $p$ 等价于 $\theta$）执行同一协议。非相干损失按 $\sim p^2$ 标度（定理 21：每个独立每量子比特 Pauli 信道都有相同的失败结构，信道相关单量子比特错误概率为 $\varepsilon$），故斜率应 $\approx 2 \neq d$——排除"平台硬件噪声本身按 $\theta^d$ 标度"的混淆。

### 8.6 系统误差与对策

1. **基线 $b$**：1024 量子比特编码电路（约 $10^{-3}$ 门误差下约 $10^4$ 个 CNOT）给出量级 $10^{-2}$–$10^{-1}$ 的基线。对策：三参数拟合吸收加错误缓解（随机编译、测量标定）；若 $b > 2\times10^{-3}$，丢弃层级 $4/32$ 的最低点（$\mathrm{loss} \sim 10^{-3}$ 处）——如 $d{=}4$ 用 $\{0.03, 0.04, 0.05, 0.06\}$（$\Delta\ln = 0.69$，$\sigma_d \approx 0.05$），$d{=}32$ 在 $N = 10^6$ 下用 $\{0.48, 0.50, 0.52, 0.54\}$（$\sigma_d \approx 0.2$）；裕度仍 $> 10\sigma$。
2. **译码器等价性**（实验前，经典侧）：RPA/几何译码器必须在重量 $\le w_0+1$ 处复现最小重量译码（分支级精确程序比对）；否则闭式系数失效（译码器不是理论译码器）。
3. **$R_x(\theta)$ 标定**：微波脉冲面积标定；随 $\theta$ 变化的脉冲误差需单独随机基准测试（RB）标定 [38, 39]。全局脉冲（公共角度）消除逐量子比特轴/角控制，轴漂移由全局均匀化抑制。
4. **串扰**：CNOT 串扰移动有效注入角——由 $\theta$ 网格的 XEB/串扰标定修正；残余效应进入 $\sigma_{\mathrm{rel}}$。
5. **有限长度 / 次前导阶**：窗口顶部（$\mathrm{loss} > 0.3$）次前导贡献 $\sim \theta^{d+2}$ 有闭式系数 $c' = \kappa_r(m)\,C(n,w_0{+}1)\,P'(w_0{+}1)\,2^{-2(w_0+1)}$（定理 20），残差 $\chi_P$ 仍为 $X$-逻辑且翻转比等于前导。**次前导判别器**：比值 $\rho = c'/c_d$ 为闭式比（$d{=}4$ 时 $\rho = 85.3$；其他层级 $\approx 0.45$–$0.50$）。数据在*拟合前*修正：$\hat{L} \mapsto \hat{L}/(1+\rho\theta^2)$（线性版本 $\ln\hat{L} - \ln(1+\rho\theta^2) = \ln c + d\ln\theta$）；修正后残余斜率必须消失（否则次前导闭式被证伪）。**$c'$ 不得作为自由参数拟合**——五点四参数时拟合欠定，且不做修正时 $d{=}4$ 斜率偏差 $+0.31 \approx 15\sigma$、$d{=}32$ 斜率偏差 $+1.7\sigma$，破坏判别（功效分析）。

### 8.7 时间预算

每点 $N$ 发、发周期约 $5$ ms（约 $10^4$ 个 CNOT + 注入 + 测量）时，$N = 2\times10^5$ 每点约 $1000$ s：

| 项目 | 点数 | $N$ | 时间 |
|---|---|---|---|
| 主扫描（17 点；$d{=}32$ 低端点 $10^6$） | 17 | $2\times10^5$–$10^6$ | $\sim 5.2$ h |
| 空隙区（3 点） | 3 | $2\times10^5$ | $\sim 0.8$ h |
| 对照（随机 Pauli，4 点） | 4 | $2\times10^5$ | $\sim 1.1$ h |
| 标定（RB/XEB/基线） | — | — | $\sim 2$ h |
| **合计** | | | **$\sim 9$–10 h（单平台日）** |

在 64/256 量子比特备用平台上电路更浅（发周期 $\sim 0.5$–1 ms），预算减半。

### 8.8 证伪条件

1. 任何层级 $|\hat d - d| > 2\sigma$（$\sigma_d$ 设计值 0.02–0.25）→ 损失标度律失败（核心几何预测被反驳）。
2. 斜率通过但截距偏离闭式 $> 3\sigma$ → 系数结构失败；需要修正 $\kappa\,\mathrm{fail}(w_0)/P(w_0)$（对 $\kappa$ 引理或类大小闭式的实验反例）。
3. 空隙区中层级 $16/32$ 出现超出 $3\sigma$ 的 $\theta^d$ 型增长，或层级 $4/8$ 无饱和平台 → 窗口阶梯失败。
4. 随机 Pauli 对照给出与相干注入相同的斜率（两者都 $\approx d$，或都为 $2$）→ 平台为退相干主导；判别*不可行*（非理论失败——更换平台或缩短电路）。
5. 次前导系数偏离定理 20 闭式 $> 3\sigma$ → 次前导结构被修改。

### 8.9 科学收益与开放问题

**若通过**。(i) 实验确认四个斜率 $4/8/16/32 \pm 0.3$：相干噪声下 AG 完备码的损失完全由几何决定（逻辑类 + 平坦计数），无需任何拟合；(ii) 截距给出 $\kappa\,\mathrm{fail}(w_0)$，进而 $\mathrm{fail}(w_0)$ 与类大小 $v$——类大小闭式的间接实验验证；(iii) 窗口阶梯（含空隙）是几何预测的独特、不可拟合签名；(iv) 次前导 $\theta^{d+2}$ 系数的实验检验。

**若失败的方向**。非相干混入（相干/非相干分离的实验入口——$\theta^2$ 对 $\theta^d$ 标度分裂）；有限长度效应（$n = 1024$ 次前导修正）；译码器偏离最小重量译码；平坦计数假设的实验偏差（简并分数 $P(w_0)$）；$\kappa$ 闭式的偏差。

**开放问题**。
1. 相干/非相干分离的定量协议：随机 Pauli 对照的注入参数（去极化速率 $p$ 与 $\theta$ 的映射）需要闭式。
2. RPA 译码器在简并层（重量 $w_0$）匹配最小重量译码的严格证明；目前是实验前认证。
3. 暴力协议有限测量误差（读出保真度 $99\%$ → 基线 $\sim 10^{-2}$）对 $d{=}32$ 窗口的影响：是否需要读出错误纠正？
4. 空隙检验的统计功效：空隙区 $\theta$ 放置与发数分配的最优方案。

## 9. 结论与展望

### 9.1 结果总结

我们为仿射完备 CSS 码族 $\mathrm{CSS}(H,H)$（$H$ 为 $\mathrm{RM}(r,m)$ 的生成矩阵，稳定子空间 $C = \mathrm{RM}(r,m)$，逻辑空间 $C^\perp = \mathrm{RM}(m-r-1,m)$，自正交条件 $2r < m-1$）建立了验证框架与精确闭式理论。主要结果：

1. **免枚举验证**（定理 4）：$n = 1024$ 及以下码的最小重量结构、零损失窗口与类大小简并由 $M = n \cdot s$ 次操作（对稳定子维数线性）认证，取代组合枚举；该方法是经典精确的（整数算术，小码上与完全枚举的分支级比对）。
2. **参数闭式**（定理 1–3）：$k = 2^m - 2\dim\mathrm{RM}(r,m)$，$d = 2^{r+1}$，有效性当且仅当 $2r < m-1$；$k \ge 1$ 边界 $r \le \lfloor(m-2)/2\rfloor$ 使该族在 1024 量子比特上成为四阶阶梯 $d = 4, 8, 16, 32$。
3. **零损失与简并结构**（定理 5–7、13–15）：重量 $< d/2$ 的错误有唯一综合征（完美恢复）；该族恰在 $d \in \{4, 8\}$ 时完全简并；全简并边界精确且经小码验证。
4. **闭式失效率**（定理 16–21）：类大小 $v(A) = 1 + \left[\begin{smallmatrix}m-s\\ r+1-s\end{smallmatrix}\right]_2$（高斯二项式，$s$ 为仿射包维数）；失效率 $\mathrm{fail}(w) = 1 - \langle 1/v \rangle$；统一标度律 $\mathrm{loss}(\theta) = c_d\,\theta^d$，闭式系数 $c_d = C(n,w_0)\,P(w_0)\,\mathrm{fail}(w_0)\,2^{-2w_0}$（定理 16），经第 5.3 节闭式翻转分数 $\kappa_r(m)$ 转化为测得的逻辑 $Z$ 翻转率——逐实例对照精确程序验证（$[[64,20,8]]$ 斜率 7.96、$[[256,70,16]]$ 完全恢复、1024 量子比特闭式）。
5. **横向结构**（定理 22–23、推论 24、命题 25）：横向 Clifford 子集 $\{P, \mathrm{CNOT}, H\}$；逻辑方向 $a \in C^\perp \setminus C$ 上的横向相位门 $\gamma_a = i^{|a|}$；含 $T$ 门蒸馏接口的容错操作集合（距离 $d \ge 8$ 满足 $d \ge 5$ 要求）；有界错误传播与逐轮译码分析闭环。
6. **实验判别**（定理 26–27）：1121 量子比特平台上的四层级窗口阶梯，20–143$\sigma$ 斜率判别，单平台日，五条证伪条件。

### 9.2 意义

**标度–几何对应**。相干噪声损失展开的完整系数结构（前导与次前导阶）由 $AG(m,2)$ / $PG(m-1,2)$ 的平坦计数闭式决定：量子纠错码的相干噪声行为*就是*其逻辑类的几何。类大小闭式将先前三个彼此分离的实例——$[[32,20,4]]$ 码的 465 对、重量-4 层的 313,131 个类、$r=1$ 层的 512 个代表元——统一为一个公式。

**闭式预测与可证伪性**。进入标度律的每个系数都是闭式；第 8 节实验是带五条显式证伪条件的锐利检验。这是本文理论与码性能事后拟合模型的质性差别。

**简并码的精确分析**。简并是量子码能超越经典汉明界的原因，但精确简并分析罕见。本文族提供完全简并区（$d \in \{4,8\}$）的首个精确闭式处理，带证明的边界，且简并译码失效率通过高斯二项式类大小表达——一种随机码典型性论证无法企及的结构。

**工程修正**。$r=1$（$d=4$）层级损失约为先前估计系数的两倍（大 $m$）；阈值估计 $(cN)^{-1/d}$ 相应修正；层级 $d=8/16$ 不受影响（主导类大小 2）。

### 9.3 开放问题

1. **PG 次前导阶**：PG 完备族（$d=3$）的 $\theta^6$ 系数：重量-3 与重量-2/1 层的跨层简并结构。
2. **$r=3$ 的简并类**：失效率公式中 $P(s=3)$ 修正的精确权重（$m=10$ 时量级 $10^{-8}$，可忽略但未单独验证）。
3. **非 CSS 完美码**：$[[5,1,3]]$ 码 $\theta^4$ 标度的机制（测得 $c \approx 0.06$ 对比分支级 $0.069$，同量级）及其与几何完备框架的关系。
4. **类大小的完整统计**：$r=3$ 时 $v = 2^{m-3}$ 简并类的占比——$\mathrm{flats}(m,3)/C(2^m,8) \approx 2.8\times10^{-11}$（$m=10$），采样不可达；闭式即终值。
5. **相干/非相干分离**：映射随机 Pauli 对照参数（$p$ 对 $\theta$）的定量协议。
6. **译码器认证**：RPA/最小重量在简并层等价的严格证明。
