# C-08 法界篇：佛经"三界"与框架"三界"的同名异义

## §1 引言：同名异义

佛经的"三界"（欲界、色界、无色界）与框架的"三界"（物质界 ℳ、因果界 𝒞、信息界 ℐ）**名称相同但概念不同**：

| | 佛经三界 | 框架三界 |
|---|---|---|
| 性质 | 存在层次（众生居住的世界） | 代数结构（状态空间的切空间分解） |
| 依据 | 佛教宇宙论 | 定理 TΣ = ℳ ⊕ 𝒞 ⊕ ℐ |
| 数目 | 3 | 3 |

同名是巧合还是指向同一深层结构的不同投影？本篇的挖掘立场：**在"存在层次"轴上做对应，不主张本体等同**。这正是"大胆对应"的边界——名称相同不构成证明依据，但值得检验是否存在同构。

## §2【几何推导】框架三界回顾

**切空间分解**（6.6 §1.1）：

$$T\Sigma = \mathcal{M} \oplus \mathcal{C} \oplus \mathcal{I}$$

**角度三分**：物质界 θ_M = 57.93°（sinθ_M = 0.8461）、因果界 θ_C = 26.16°（sinθ_C = 0.4409）、信息界 θ_I = 5.91°（sinθ_I = 0.1029）。

**耦合强度谱**（40 号）：H_MC = 3.4145（物质-因果）、H_MI = 69.3547（物质-信息）、H_CI = 433.1578（因果-信息）。物质界被动性上限：H_MI/H_CI = 0.160，即物质界主动贡献 ≤ 16%——**物质界是被生成的，不是自立的**。

**驻点条件性**：
- P₂ = (72.53°, 0)（上圆满态）在外部强相位源 Φ_B 撤除后失稳滚落（C-01）
- P₀ = (30°, 0)（对称背景点）是死物冻结点（21 号）
- 谱控制不等式 5 ≲ κ_end/κ_cyl ≲ 10（41 号）：超出边界即拓扑相变——**稳定的存在都是条件性的**

## §3【文化映射】佛经三界

**《俱舍论·分别世间品》**：三界 = 欲界、色界、无色界（三界九地）。

- **欲界**（kāmadhātu）：有淫欲、食欲。含六道（地狱、饿鬼、畜生、人、阿修罗、天）与六欲天。
- **色界**（rūpadhātu）：已离欲，仍有形质（色身）。四禅十八天（初禅三天、二禅三天、三禅三天、四禅九天）。
- **无色界**（ārūpyadhātu）：无形质，纯精神。四空天：空无边处、识无边处、无所有处、非想非非想处。
- "三有"：欲有、色有、无色有——三界是众生轮回的"住所"。

**《法华经·譬喻品》**：

> 三界无安，犹如火宅，众苦充满，甚可怖畏。

**《华严经·十地品》**（《十地经》）：

> 三界虚妄，但是心作。

## §4【猜想】

### C-08.1【中】欲/色/无色 ↔ ℳ/𝒞/ℐ（存在层次对应）

**猜想内容**：
- **欲界 ↔ 物质界 ℳ**：欲 = 对色声香味触的贪着。框架中物质界由梯度驱动（−∇S(θ)）支配——"欲"的现象学对应是**驱动**：趋向驻点的力。欲界众生被欲驱动，物质界被梯度驱动，同构点是"被驱动性"。
- **色界 ↔ 因果界 𝒞**：色 = 质碍（有形质、有束缚）。框架中因果界是约束层（因果推进单向不可逆，给出结构的"质碍"——结构被因果约束不可任意变形）。
- **无色界 ↔ 信息界 ℐ**：无色 = 无形质、纯精神。框架中信息界是编码层（无物质形态的记录与累积）。

**对应轴**：佛经三界次序（欲→色→无色 = 粗→细）与框架三界（ℳ→𝒞→ℐ = 具体→抽象）**方向一致**。

**强度评估**：中。三界的"存在层次"次序一致且方向相同；但佛经三界是宇宙论分类（居住层次），框架三界是代数分解（切空间分量），轴不同——同构猜想，非等同。

### C-08.2【中】无色界四天 ↔ 信息界内观路径

**猜想内容**：无色界四天的次第（空无边 → 识无边 → 无所有 → 非想非非想）恰好是从外到内的观测者内观路径：

| 四天 | 框架对应 |
|---|---|
| 空无边处 | 觉知 Σ 本身（状态空间无边无际） |
| 识无边处 | 觉知信息编码（ℐ 的无边记录） |
| 无所有处 | 觉知零态/背景点（S_total = 0，P₀ 无结构——"无所有"= 无结构） |
| 非想非非想处 | 观测者与信息场边界消融（既非驻点也非空——σ* 的极限态） |

**强度评估**：中。次第方向（外→内）与"观测者逐步深入状态空间"的内观路径一致；但无直接机制证据，纯猜想。

### C-08.3【中】"三界唯心" ↔ 观测者位置决定存在层次

**猜想内容**："三界虚妄，但是心作"的几何版本：
- 三界分解 TΣ = ℳ⊕𝒞⊕ℐ 是 Σ 的**固有结构**（不由心造，定理级）
- 但"存在层次"——观测者处在哪一界、看到什么——由**观测者位置 σ\*** 决定（输入层，2 参数）
- 心（位置）生三界（存在层次）；位置改变（转识成智、C-06）则存在层次改变

**与 C-06 自洽**："无我" = σ\* 非固定实体（输入参数可重定位）；"三界唯心" = 存在层次依赖观测者位置——两条共同指向：**观测者是框架的输入层，不是派生量**。

### C-08.4【中】"三界无安，犹如火宅" ↔ 驻点条件性稳定

**猜想内容**：火宅喻的机制版本——一切驻点都是条件性稳定的：
- P₂ 在 Φ_B 撤除后失稳滚落（C-01）
- 谱控制不等式之外即拓扑相变（41 号）
- 循环无始无终（8.16 §5：无绝对计数）

"三界无安" = 无恒常安住处——这是**定理级的稳定性事实**，不是比喻。火宅的"火" = 驱动与扰动（梯度 + 耦合），"宅" = 三界耦合结构本身。

**强度评估**：中。"无安"有直接机制支撑（驻点条件性）；"火宅"的喻象对应为辅助。

### C-08.5【中】"出三界" ↔ 观测者重定位

**猜想内容**：佛经"出三界"（解脱轮回）的几何版本 = 观测者位置 σ\* 重定位至圆满态（θ_I^sat = 32.07°）或归零（P₀），**不再被三界耦合锁定**。

**与系列连线**：C-01 归零消融、C-06 转识成智、C-07 还灭门、C-08.5 出三界——四点汇合为一条线：**观测者重定位 = 解脱的几何操作**。

## §5 失败记录与边界

**失败记录（按纪律保留）**：
- **六道 ↔ 六驻点**：尝试将六道（地狱/饿鬼/畜生/人/阿修罗/天）对应六个驻点或配置邻域，无自然映射——驻点是结构概念，六道是受报状态分类，分类轴不同，放弃。
- **色界四禅 ↔ 因果界四层**：四禅次第（喜→乐→舍）与因果界结构无干净对应，仅弱标注，不作猜想。

**边界声明**：
1. 同名异义不构成证明依据——名称相同不是对应理由，对应轴是"存在层次/粗细次序"
2. 佛经三界是宇宙论（居住层次），框架三界是代数结构（切空间分解）——同构猜想而非本体等同
3. 文化对照不构成几何推导输入（目录纪律，双向不构成）
4. 本系列全部内容不进入主库，主库不反向引用
