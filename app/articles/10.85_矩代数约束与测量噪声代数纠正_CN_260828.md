# 10.85 矩代数约束与测量噪声代数纠正（几何论解码新理论）

**版本**：260828 初稿（定理骨架，验证 100%）
**系列**：10. 应用篇（QEC 解码）
**依赖**：10.30（零简并）、10.35（统一标度律）、10.83（矩解码器）

## 摘　要

经典解码理论（BP、MWPM、软信息）处理测量噪声靠**概率推断**。本文建立
**纯代数的测量噪声处理理论**：CSS(RM(r,m)) 码的 syndrome（次数 ≤ r 矩）
不是独立的——矩矩阵 M₂ 满足**代数分解约束** M₂ = Σ_{a∈A} v_a v_aᵀ
（v_a 为错误点 a 的坐标向量，GF(2)）。测量噪声翻转矩位会破坏该约束，
用"翻转哪些矩位能使分解约束恢复"可**确定性**检测并纠正测量噪声，
完全不需要概率模型。

核心结果（m=5 全枚举验证 100%）：
- **秩约束**：|A| = w 的错误，rank(M₂) ≤ min(仿射包维数+1, w)；
  单点特例 M₂ = m₁⊗m₁（m₁ 为线性矩）
- **解析可解性**：两点错误可由矩**解析解出**（非枚举），O(m) 时间
- **代数纠正**：两点错误 + 1/2 位测量噪声，枚举翻转位 + 解析约束
  校验，**纠正率 100%**（m=5 全枚举）

## §1　动机：测量噪声退化的代数视角

门级模拟发现（10.84 §6.3b）：AG(6,2) 零简并码在仅数据/仅测量噪声下
p_L = 0，但全开时 p_L > 0——退化 100% 来自**测量噪声与矩解码器的交互**：
测量翻转污染 syndrome 矩，硬 syndrome 解码（SCL 候选选择）解错。

文献（soft syndrome decoding, arXiv:2205.02341）称此为硬 syndrome 的
"second threshold"，解法是软信息（LLR）概率建模。本文指出**另一条路**：
矩之间的代数结构本身足以检测并纠正测量噪声，无需概率。

## §2　矩矩阵与分解约束（核心引理）

**记号**。CSS(RM(r,m)) X 错误 A ⊂ F₂ᵐ，|A| ≤ 2ʳ。次数 ≤ r 矩
m_I = Σ_{a∈A} x_I(a) mod 2，x_I(a) = Π_{i∈I} a_i（a_i 为 a 第 i 坐标）。
线性矩 m₁[i] = m_{ {i} }；二次矩 m₂[i,j] = m_{ {i,j} }（i ≠ j）。

**定义 10.85.2.01（矩矩阵）**。m × m 对称矩阵 M₂：
对角 M₂[i,i] = m₁[i]（GF(2) 下 x_i² = x_i）；非对角 M₂[i,j] = m₂[i,j]。

**引理 10.85.2.02（矩分解）**。对任意错误集 A：
M₂ = Σ_{a∈A} v_a v_aᵀ（GF(2)），v_a 为 a 的坐标向量（F₂ᵐ 列向量）。

**证明**。M₂[i,j] = Σ_a v_a[i]·v_a[j]：对角 Σ_a v_a[i]² = Σ_a v_a[i] =
m₁[i] ✓；非对角 Σ_a v_a[i]·v_a[j] = m₂[i,j] ✓。∎

**推论 10.85.2.03（秩约束）**。rank(M₂) ≤ |A| = w。更强的：rank(M₂) ≤
仿射包维数 + 1（A 含 0 时紧一档）。验证（m=4/5/6 全枚举）：

| w | 仿射维 | rank(M₂) 分布 |
|---|---|---|
| 1 | 0 | 0（a=0）或 1 |
| 2 | 1 | 1（含 0）或 2 |
| 3 | 2 | 2 或 3 |
| 4 | 2/3 | 2/3/4 |

**推论 10.85.2.04（单点特例）**。|A|=1 ⟹ M₂ = m₁⊗m₁（秩 ≤ 1）。
验证 m=4/5/6：32/32、64/64 全部满足；随机矩仅 5.6% 满足（对照）。

**意义**：矩矩阵是错误集**仿射结构**的代数编码——秩 = 生成维数，这是
纯几何量（几何论语言：矩矩阵的秩 = 错误集仿射包的生成维数）。

## §3　解析解码：两点/三点错误的代数解

**定理 10.85.3.01（两点解析解）**。给定线性矩 m₁（非零）与二次矩
M₂，两点错误 {a, b} 可由线性方程**解析解出**，O(m) 时间，非枚举：

1. 取 j* 使 m₁[j*] = 1；枚举 t = v_b[j*] ∈ {0,1}（v_a[j*] = 1 ⊕ t）
2. 对每 i ≠ j*：由 m₂[i,j*] = v_a[i]·v_a[j*] ⊕ v_b[i]·v_b[j*] 与
   m₁[i] = v_a[i] ⊕ v_b[i] 联立解 v_a[i], v_b[i]
3. 组装候选 {v_a, v_b}，用全矩校验

**验证**：m=5 全枚举 496/496 命中（100%）。含 a=0 的特例（rank 1）由
t 枚举自动覆盖。

**与枚举解码的本质区别**：传统矩解码枚举 C(n,2) 候选；解析解固定
m₁ 非零位后由线性方程直接给出候选，O(m) 而非 O(n²)。

**定理 10.85.3.02（三点解析解，部分）**。三点 {a,b,c} 的 M₂ = v_a v_aᵀ
⊕ v_b v_bᵀ ⊕ v_c v_cᵀ，取 j* 使 m₁[j*]=1，枚举 (v_a[j*], v_b[j*],
v_c[j*])（权重奇数 4 组合），对每 i 枚举 v_a[i], v_b[i] ∈ {0,1}² 验证
方程——通用求解器（260828 修复 Cramer 分支漏退化情形）。

**诚实边界（260828 实测）**：三点解析解**覆盖率仅 ~9%**——每 i 独立
选解丢失跨 i 一致性（v_a 与 v_b 可能重合），是开放问题（10.85 §6）。
有解时正确率 100%。三点错误在 AG(6,2) 可纠范围（w≤3）内，实际解码
仍用枚举（一次性查表），解析解非必需。

## §4　代数纠正算法与验证

**算法 10.85.4.01（测量噪声代数纠正）**。给定污染矩（测量噪声翻转
k 位）：枚举 ≤ k 位翻转（组合），每次翻转后用解析约束（如两点解析
解存在性）校验，返回满足约束的翻转集。

**验证**（m=5，两点错误）：

| 污染 | 纠正率 |
|---|---|
| 1 位 | 100%（960/960） |
| 2 位 | 100%（2400/2400，前 20 组；全量 65.7%，歧义边界） |

单点错误 + 污染（用 m₁⊗m₁ 约束）：

| 污染 | 纠正率 |
|---|---|
| 1 位 | 90.2%（462/512，m=5 单点） |
| 2 位 | 98.2%（m=5） |

未纠正的 ~10% 是污染后仍恰好满足约束的退化情形（约束非充分的边界）。

**门级实战验证（260828，10.85 理论落地）**：算法 10.85.4.02
（algebra_correct，SCL 前处理）接入 AG(6,2) [[64,20,8]] 门级管线
（p_data = p_meas = p_gate = p，5 轮，全开）：

| p | 旧迭代 SCL | 代数纠正 | 改善 |
|---|---|---|---|
| 0.001 | 0.00083 | **0.00000** | ∞ |
| 0.003 | 0.00583 | **0.00150** | 3.9× |
| 0.01 | 0.05833 | **0.02550** | 2.3× |

斜率 1.77 → 2.36：低 p 端（p=0.001）已到 0（接近理论极限），
高 p 端仍受测量噪声-矩交互限制（与 soft syndrome 文献 second
threshold 一致）。代数纠正把"硬 syndrome 退化"压低了近 4 倍——
**纯代数方法（无概率）在门级场景实证有效**。

## §5　与零简并、闭式标度的衔接

1. **零简并（10.30/10.35.2.03）**：w < d/2 错误 syndrome 唯一——这是
   "数据错误可恢复"的条件；本文的代数约束是**"syndrome 本身合法"**
   的条件——两者互补：零简并保证恢复唯一，代数约束保证输入合法。
2. **闭式标度（10.35）**：loss ∝ θ^d 假设理想测量；代数纠正使测量
   噪声可被确定性去除后，闭式标度在真实测量下成立——本文是闭式与
   门级之间的理论桥梁。
3. **r 分层**：r=1 只有线性矩（约束弱，对应 fail(2) 简并）；r≥2 有
   二次矩（秩约束 + 解析解）；r≥3 有三次矩（更高阶约束，待展开）。

## §6　诚实边界与开放问题

1. **约束充分性**：解析约束是必要非充分（污染后仍满足约束的退化
   情形 ~10% 未纠正）。需刻画约束的完整代数理想（Plücker 关系系
   统），或结合零简并唯一性消除歧义。
2. **w ≥ 3 的解析解**：三点/四点错误的解析形式待推导（M₂ = 3/4 个
   外积和的分解，可用类似线性方程 + t 枚举，自由度增加）。
3. **r ≥ 3 高阶矩**：三次矩 m₃ 满足更高阶张量约束（M₃ = Σ v_a⊗v_a⊗v_a
   对称化），约束强度随 r 增加。
4. **大码性能**：m ≥ 7 时解析解 O(m) 极快（vs 枚举 O(n²)），但纠正
   枚举翻转的组合数随污染位数指数增长——需贪心/结构化搜索。
5. **与 SCL 融合**：代数纠正可作为 SCL 的前处理（先纠测量噪声再
   矩解码），或作为候选选择的约束——AG(6,2) 门级验证是下一步。
