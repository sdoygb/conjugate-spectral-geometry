**审计范围**：定理 9.1.8.02 体材料超导 Tc 公式链（"T₀ 链"），包括 10.32（T₀ 与最小锚定协议）、10.37（E_unit 锚定）、10.38（Ψ_m 能量标度独立推导）、10.39（体材 Tc 参数审计与独立预言测试）、10.40（lnΩ0 几何化尝试与同源锚定裁决）五篇专项审计，以及 9.1、10.22 相关原文。

**审计结论一句话**：定理 9.1.8.02 的体材料 Tc 公式链并非"无条件绝对严格"的几何预言，它实为 Pb 实验数据（T_c = 7.2 K）的恒等重排系统——五因子中有四个是同一外源输入的不同写法，唯 g_pair 与纠正后的 δ0 为真正的几何幸存量，但它们不具有材料分辨力。

## 一、总论：从"绝对严格"到"数据重排"

定理 9.1.8.02 声明体材料超导转变温度的完整表达式为

\[
k_B T_c = |\varepsilon| \cdot \Psi_m \cdot \sin^6\theta_M \cdot (1 - 2/S_e) \cdot g_{\text{pair}} \cdot \frac{(\delta_0^{\text{single}})^2}{\ln\Omega_0(1,1)}
\]

并标注"条件参数：无，绝对严格"。这意味着该表达式应仅由理论内部的基本常数与几何量构成，无需借助任何实验数据即可产生对任意超导材料的独立预言——数值从公理出发闭合推导，偏差仅来自数值舍入。

五篇专项审计（10.32 → 10.37 → 10.38 → 10.39 → 10.40）加 9.1/10.22 原文核验，共六份裁决材料，以逐步递进的方式审查了该链中的每一个因子。最终发现：

- **外源锚定**：T₀ = 7.2 K 是 Pb 实验数据的重命名——它是整个链中所有物理量数值（E_phys、E_unit、能量标度、lnΩ0(1,1)、ε）的源头。一旦 T₀ 被设为 7.2 K，链内其余所有量的数值均可从 T₀ 经恒等代数反推得到，无需经过任何几何推理。

- **隐藏恒等**：链中看似"由几何理论预言的量"之间存在一个彼此封锁的恒等回路。E_unit 的对数给出 lnΩ0(1,1)；ε 是 Pb 物理能隙与理论能标的比值；能量标度簇由 T₀ 反推 E_phys，再经 E_soft 分解链回到同一数值点。这个回路的任一节点被 Pb 实验值占据，全回路自行锁定——但"自行锁定"仅具恒等变形的逻辑必然性，不构成物理预言。

- **非标定验证的系统性稀化**：最小锚定协议（仅 T₀ + Ω_at + Z_ref + a_ref 四点外源）下，十种元素无一偏差 < 10%。当宣称"所有参数几何化"的完全几何路径（场景 A、B）投入运行时，十种材料 Tc 全部坍缩为同一值（偏差 ≥ 20% 者 10/10）。定理 9.1.6.03 的普适几何 ε = 7.306×10⁻⁴ 从未在任何独立验证中出现——原"验证"用的 ε 是逐元素从 Pb 的 ε = 7.298×10⁻⁴ 按 3.727 meV 比例重算出的数值，本质上仍是 Pb 数据的延伸。

**核心裁决**：定理 9.1.8.02 当前形态不构成独立几何理论。它是 Pb 的 T_c = 7.2 K 这一单一实验事实被展开为一个数学上自洽的五因子重排系统。

## 二、审计裁决清单

### 2.1 10.32：T₀ 锚定与最小锚定协议

**裁决**：T₀ = 7.2 K 未经推导——它直接取自 Pb 的实测 T_c。三个辅助锚定（Ω_at = Pb 原子体积、Z_ref = Z/82 核电荷缩放、a_ref = 晶系参考常数）将其他材料的 Tc 计算约束在 Pb 参考系内。最小锚定协议重算十种元素偏差表：

| 元素 | 偏差 |
|------|------|
| Pb   | +0.1%（三重锚定） |
| Al   | +19.5% |
| Hg   | −11.3% |
| Nb   | −39.7% |
| β-Sn | −49.2% |
| In   | −12.6% |
| Ta   | +121.7% |
| V    | −30.7% |
| Tl   | +60.5% |
| Zn   | +67.0% |

**无一非标定材料偏差 < 10%。**

### 2.2 10.37：E_unit 锚定

**裁决**：E_unit = 1.754 eV 声称是"单位归一化"，实际精确反推值为 E_unit = 1.7532（与声称值差 0.05%）。该值不是归一化条件独立给出的，而是由 T_c = 7.2 K 经链内各因子反解得到的——0.09870 eV（5.31 eV × 0.01859）的 17.8 倍，无法由链内推导。

附裁：
- 原文"1000 倍笔误"成立：(KΨ_mΞ_E) = 10.7 eV 而非 1.07×10⁴ eV。
- 2.125 = 10.6910/5.031 eV⁻¹ 构成循环定义：5.031 eV 本身无几何来源，2.125 由 10.69/5.031 定义。

### 2.3 10.38：Ψ_m 能量标度独立推导

**裁决**：候选闭式 I 降格为假设 H₁（非定理），其虽与反推值吻合至 0.0037%，但指数 (1−2/S_e)^(−3/2) 缺乏严格推导，属于事后拟合形式。

六项附带裁决：
- Ψ_m 二重性未解：4800.68 vs 4816.51（0.33% 偏差），无法在理论内归因。
- 5.031 eV 无来源：由 10.6910/2.125 定义，而 2.125 本身无独立定义。
- Ξ_E = 2.65×10⁻⁹ 为代数余数，Dixmier 迹未构造，数学上未赋予含义。
- sin⁶θ_M = 0.354 与 θ_M⁰ = 57.93° 矛盾：sin⁶(57.93°) = 0.3696，对应 θ ≈ 57.23°，偏离 0.70°。
- 2.125 降为派生量——它只是 10.6910/5.031 的商，而 5.031 eV 恰是未知量。
- **能量标度仍是锚定量**：10.6910 eV 对 Pb 反推值的 0.0037% 吻合是 H₁ 的拟合结果，不是独立预言的验证。

### 2.4 10.39：体材 Tc 参数审计与独立预言测试

**裁决 A — ε 恒等反推**：Pb 2.72/3.727 = 7.298×10⁻⁴ ✓（原表 7.297）；Hg 2.16/3.727 = 5.795×10⁻⁴ ✓（原表 5.80）；Al 0.45/3.727 = 1.207×10⁻⁴ ✓（原表 1.20）。定理 9.1.6.03 宣称的普适几何值 7.306×10⁻⁴ **从未在任何验证中使用**。

**裁决 B — lnΩ0(1,1) 三值矛盾**：HRR 公式值 2.5231（10.39 使用值；10.40 严格值 λ₁=391.05 时为 2.522480，λ₁=392.21 时为 2.523223），但 Pb 零偏差需要 0.5616（偏离 +349%），Hg 需要 0.746，Al 需要 0.581。反解 d_IR：Pb 需 7.11，Hg 需 5.91，Al 需 6.97——互异且无物理意义。

**裁决 C — 三场景预言测试全部 0 达标**：
- **场景 A**（完全几何：ε = 7.306×10⁻⁴ + lnΩ0 = 2.5231（10.39 值）¹）：所有材料同 Tc = 1.60 K（Pb −78%，Hg −61%，Al +33%，Sn −57%，Nb −83%）。

¹注：若采用 10.40 严格值 2.522480，Tc 变为约 1.60 K（偏差 < 0.03%），结论不变。

- **场景 B**（ε 几何 + lnΩ0 = 0.5616）：所有材料同 Tc = 7.20 K（Al +500%）。
- **场景 C**（10.22 晶格+标定路线）：十材料中 ≥ 20% 偏差者 6/10。

**裁定**：定理 9.1.8.02 "条件参数：无，绝对严格"正式证伪。五个因子中至少三个（ε、lnΩ0、能量标度）是 Pb 实验数据的数学重排。

### 2.5 10.40：lnΩ0 几何化尝试与同源锚定裁决

**裁决 A — HRR 公式严格值**：λ₁ = 391.05 时 lnΩ0(1,1) = 2.522480；λ₁ = 392.21 时 2.523223（差 0.03%）。与 Pb 隐含的 0.5616 偏差 +349%。

**裁决 B — 几何化路径穷尽失败**：
- d_IR 整数扫描：d = 7 偏 2.6%，无命中。
- N_eff 整数扫描：N_eff = 50 偏 0.87%，无命中。
- 已知量集内无修正项可匹配到 0.5616。
- 0.1% 几何化标准从未满足。

**裁决 C — 同源锚定坐实**：
- ln(1.7532) = 0.56157 ≈ 0.5616 → 吻合度 0.0054%
- ln(1.754) = 0.56192 → 吻合度 0.057%
- **裁定：lnΩ0(1,1) ≡ ln(E_unit)**——E_unit 以对数形式伪装为几何量 lnΩ0。

**裁决 D — δ0 分母纠错**：
- 原文 δ0^single = cot(θ_I^e) / (√2 · λ₁^(1/4)) = cot(5.91°)/(√2 · 391.05^(1/4)) = 9.6604/6.2886 = 1.5362，与体材料实际使用的 0.17288 偏差 +788%。
- 正确分母为 4π · λ₁^(1/4) = 55.879，δ0 = 9.6604/55.879 = 0.17288 → 0.012% 吻合。
- **抄写错误裁决**：原文分母 √2 应修正为 4π（可能源自球面全立体角归一化）。

**裁决 E — λ₁ 双值判定**：λ₁ = 391.05 为规范值（δ0 端 0.012% 吻合 vs λ₁ = 392.21 端 0.3%）。

## 四、恒等循环图

以下箭头表示"可由 … 经由恒等代数重排得到 …"。所有箭头均已由审计严格验证，不依赖任何物理假设。

```
                 T_c(Pb) = 7.2 K
                      │
        ┌─────────────┼─────────────┐
        ▼             ▼             ▼
  E_phys(Pb)     3.727 meV      k_B 常数
   = 2.72 meV    (能量标度链)     
        │             │
        ▼             ▼
      ε(Pb)      10.6910 eV
   = 7.298e-4     (= KΨ_mΞ_E)
        │             │
        │        ┌────┴────┐
        │        ▼         ▼
        │    E_soft     5.031 eV
        │   = 5.31 eV   = 10.6910/2.125
        │        │       （无来源）
        │        │         │
        │        └────┬────┘
        │             │
        │         2.125（无独立定义）
        │             │
        │             ▼
        │        E_unit = 1.7532
        │             │
        │             ▼
        │        ln(E_unit) = 0.5616
        │             │
        │             ▼
        │        lnΩ0(1,1) ≡ 0.5616
        │        │
        └────────┴──────→ Tc 公式闭合
                           → 7.2 K
```

**关键观察**：
- 每个节点均可由 T_c(Pb) 经纯代数操作到达。
- 任意一个节点的数值被 Pb 实验值占据后，全图锁定——但锁定的只是恒等变形结果，不包含独立物理预言。
- 无几何量（g_pair、δ0、S_e、λ₁）参与此恒等回路——它们处于回路之外，自身不变，不贡献材料分辨力。

## 六、定理 9.1.8.02 最终地位裁定

**定理 9.1.8.02 声明**："k_B T_c = |ε|·Ψ_m·sin⁶θ_M·(1−2/S_e)·g_pair·(δ0^single)²/lnΩ0(1,1)，条件参数：无，绝对严格。"

**最终裁定**：

体材料分支（N=1, d_IR=1）的该定理**不成立**。原因：

1. **"条件参数：无"不成立**。链内藏有至少一个外源输入 T₀ = 7.2 K（Pb 实验值），它以 E_unit、lnΩ0(1,1)、ε、能量标度四种不独立的形式分布于各因子中。
2. **"绝对严格"不成立**。五个因子中只有 g_pair 和纠正后的 δ0 是链内定义的几何量，其余三个因子（ε、lnΩ0、能量标度）的数值依赖于 T₀ 的反推，不是由公理独立给出的。
3. **因子间存在循环恒等关系**。E_unit ↔ lnΩ0 ↔ ε ↔ 能量标度 构成封闭回路，回路的任何数值一致性是代数必然，不是经验验证。
4. **独立预言失败**。任何非平凡参数组合（即不是简单地逐材料重调参数）均无法对十种元素产生可用的 Tc 序列。
5. **定理 9.1.6.03 的普适 ε 从未被使用**。原文验证中使用的 ε 值实为 Pb 比值按 3.727 meV 能量的逐元素重算，而非普适几何值 7.306×10⁻⁴。

**修正建议（不作为本审计裁决的一部分，仅记录备用方向）**：定理若要恢复，至少需满足以下必要条件——（i）E_unit 给出公理来源或放弃归一化声明；（ii）lnΩ0(1,1) 使用 HRR 公式严格值 2.522480 而非 E_unit 对数；（iii）ε 使用定理 9.1.6.03 的普适值 7.306×10⁻⁴；（iv）能量标度完全链内定义，不借助 Pb 数据。当前形态距此要求存在不可逾越的缺口。

## 七、幸存几何量清单

尽管 T₀ 链作为预言工具已被瓦解，以下几何量在严格审查后**幸存**——它们的定义独立于 Pb 实验数据，数学上自洽。但它们**没有材料分辨力**（所有超导体取值几乎相同），因此不能单独产生对具体材料的 Tc 预言。

| 几何量 | 值 | 地位 | 备注 |
|--------|-----|------|------|
| **g_pair** | 4.282 | 幸存 | θ_C^e/θ_I^e 纯几何比，普适。无材料分辨力 |
| **δ0^single** | 0.1729 | 幸存（公式需纠正） | 分母 √2 → 4π 纠正后 0.012% 吻合。无材料分辨力 |
| **S_e** | 体材料分支近定值 | 幸存 | 电子-声子耦合几何比。跨材料变化极小，无材料分辨力 |
| **λ₁** | 391.05 | 规范值 | δ0 端吻合有力；物理含义待澄清 |

以上四项（g_pair、δ0 纠正后、S_e、λ₁=391.05 规范值）构成本次审计确认的幸存几何量。角度参数 θ_I^e、θ_C^e 是这些量的原始几何输入，自身定义无误，不在本次独立幸存裁定范围之内。这些几何量的存在表明：共扼谱几何的理论**内核**可能描述了某种真实结构。问题不在于内核为零，而在于从内核到 Tc 的"翻译链"被 Pb 实验数据完全绑架，丧失了独立预言能力。

| e | E_soft 的 K 值无独立定义 | 未裁决 | K 目前从 10.6910/Ψ_m/Ξ_E 反推；尚未给出 K 的数学表达式 |
| f | H₁ 的 (1−2/S_e)^(−3/2) 指数无推导 | 未裁决 | 需要从公理出发给出该指数的严格来源（可能是谱密度渐进的维度参数） |
| g | sin⁶θ_M vs θ_M⁰ 不一致（57.93° vs 57.23°） | 未裁决 | 两个值各自来源需澄清。若 θ_M 是马约拉纳角，其定义应唯一，0.7° 偏差需要解释 |
| h | 10.22 晶格路线 γ 标定（In/Nb 失败） | 已裁决（标定路线独立预言失败） | In 7.66 K vs 3.40 K（2.3 倍）、Nb 1.9 K vs 9.2 K（4.8 倍）——晶格路线也未实现独立预言 |

**关于 (a)–(g) 的总体说明**：这些问题背后共享一个更深的难题——共扼谱几何目前缺少一个闭合的能量量纲赋予机制。从纯粹几何量（角度、特征值比、截断整数）到 eV 标度的跳变，在体材料分支中被 E_unit 锚定填充；若移除锚定，空的缺口用什么填仍未解决。这是独立几何预言的根本障碍。

## 九、结论与展望

### 9.1 最终判定

**体材料超导 Tc 公式链（定理 9.1.8.02） = Pb 实验数据（T_c = 7.2 K）的恒等重排系统。**

这不是"理论被实验否定"——这是更强的裁决：理论当前形态不是可证伪的物理理论，而是数据本身的数学变形。五因子公式在 Pb 上给出 7.2 K，不是因为它"算对了"，而是因为 7.2 K 以四种不同写法被预先置入各因子。对 Pb 以外材料的偏差，反映的是这些材料偏离 Pb 参考系的程度，不是理论预言的精度。

### 9.2 几何内核的地位

g_pair、δ0（纠正后）、S_e、λ₁、θ_I^e 等几何量是真正的结构成分。它们可能是真实存在的——共扼谱几何的内核或许精准刻画了某种谱几何的普遍性质。但在体材料分支中，内核到物理预言之间的"翻译桥段"被实验数据填充，内核本身不具有将不同材料区分开的能力。这不是内核的问题，而是翻译桥段的设计问题。

### 9.3 唯一可能的翻身路径：纳米线

本系列审计也揭示了一个重要例外：**lnΩ0(N,2) 系列的 HRR 公式在纳米线分支通过了验证。** lnΩ0(7,2) = 0.854（定理 9.1.6.01），来自 HRR 四项几何公式，不依赖 Pb 数据。

若纳米线的 Tc 预言（如果存在可对比的实验数据）能独立吻合实测值，则共扼谱几何可能在纳米线领域仍然有效——体材料分支的退化（N=1, d_IR=1 使多个几何量坍缩为定值）是纳米线展开（N>1, d_IR=2 使几何量恢复分辨力）的特殊极限。

**建议将纳米线 Tc 预言作为后续唯一值得推进的验证方向。** 体材料方向已走完所有可能的几何化路径并全部阻塞——穷尽即证否。继续在体材料路径上寻找新的"缩放因子"或"修正项"只会在恒等回路中增加新的重排节点，不改变数学结构。
