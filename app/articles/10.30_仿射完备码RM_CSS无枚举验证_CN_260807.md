# 10.30 仿射完备码：RM CSS 码族的无枚举验证、零简并结构与距离闭式

**编号**：10.30 | **日期**：260807.1 | **系列**：应用（信息层→编码理论接口） | **语言**：CN

**摘要**：(1) 10.28 的方向完备码（PG 完备，Hamming CSS）距离被射影几何结构锁死在 d=3：任意三点共线给出权重 3 逻辑。本文引入**仿射完备码**（AG 完备，Reed-Muller CSS 码族）：列取 AG(m,2) 全部 2^m 个点（含常数位），距离由 RM 对偶定理解析给出 d = 2^{r+1}，可达 [[1024, 252, 32]]。(2) 无枚举验证方法整体移植：评估列互异 ⟹ 权重 2 全检测（O(n²) 结构判定）；d 由对偶定理保证；权重 d 逻辑算符数 = AG(m,2) 的 (r+1)-平坦数（闭式，小 n 全量枚举验证 1240/10416 精确吻合）。(3) 新结构事实——**零简并**：常数位封锁射影共线，跨权重 syndrome 简并恒为 0（PG 完备码为 1/3）；r ≥ 2 时二次单项式封锁平行四边形，权重 2 层 syndrome 完全唯一（内部简并亦为 0），恢复表无任何冲突。(4) 程序验证：7 个码族成员全部通过，[[1024,252,32]] 全结构核验 8.8 秒、内存 KB 级——距离 32 的千比特码，不再是玩具码。

## 一、引言：为什么必须离开 d=3

10.28 的方向完备码（CSS(H,H)，H 列 = PG(m−1,2) 全部点）给出了族级闭式：d=3 结构性证明、权重 2 全检测、1/3 跨权重简并、174,251 个权重 3 逻辑算符。但该族的距离被射影几何锁死：

- 任意两列线性无关 ⟹ 权重 2 无逻辑（d ≥ 3）；
- 任意三点共线（PG 封闭性：两列异或必为第三列）⟹ 权重 3 逻辑恒存在（d = 3）。

要 d ≥ 5，需"任意 4 列线性无关"（4-弧）。二元射影空间中 4-弧极小：计数上界 ~2^N/3 但显式构造远小于此（PG(3,2) 最大 5 点），n ≪ 2r ⟹ k < 0。**纯 PG 点集路径不可行**。

出路：**换列空间**。取列 = AG(m,2) 全部 2^m 个点（向量 v ∈ F₂^m，列为 m+1 位评估向量 (1, v)），行空间 C = RM(r,m)（次数 ≤ r 的单项式评估）。此即经典 Reed-Muller 码的 CSS 构造（量子 RM 码族，码本身传统已知——本文贡献为无枚举验证方法学、零简并结构闭式与逻辑计数闭式）。

## 二、构造与参数闭式

**定义 10.30.1.01**（仿射完备码）：RM(r,m) = {f : AG(m,2) → F₂，f 为次数 ≤ r 的多项式}，生成矩阵行 = 全部次数 ≤ r 的单项式在 2^m 个点上的评估值。CSS(H,H) 取 C = RM(r,m)，要求自正交 C ⊂ C⊥。

**命题 10.30.1.02**（自正交条件）：RM(r,m) ⊂ RM(r,m)⊥ = RM(m−r−1, m) 当且仅当 2r < m−1。

**命题 10.30.1.03**（参数闭式）：dim RM(r,m) = Σ_{i=0}^{r} C(m,i)；仿射完备码参数

$$[[\,n,\ k,\ d\,]] = [[\,2^m,\ 2^m - 2\sum_{i=0}^{r}\tbinom{m}{i},\ 2^{r+1}\,]]$$

其中 d = 2^{r+1} 由 RM 对偶定理：C⊥ = RM(m−r−1,m) 最小权重 2^{m−(m−r−1)} = 2^{r+1}，且严格自正交（2r < m−1 ⟹ m−r > r+1）保证该权重层的向量 ∉ C。

**定理 10.30.1.04**（距离闭式）：仿射完备码 CSS(RM(r,m), RM(r,m)) 的最小距离 d = 2^{r+1}。

代表成员：

| r, m | 码参数 | d | dim C |
|---|---|---|---|
| 1,5 | [[32, 20, 4]] | 4 | 6 |
| 1,6 | [[64, 50, 4]] | 4 | 7 |
| 2,6 | [[64, 20, 8]] | 8 | 22 |
| 2,7 | [[128, 70, 8]] | 8 | 29 |

| 4,10 | [[1024, 252, 32]] | 32 | 386 |

## 三、无枚举验证定理

**定理 10.30.2.01**（列互异 ⟹ 权重 2 全检测）：RM(r,m) 的评估列在 AG(m,2) 不同点处互异（常数位 + 坐标函数区分任意两点）。对权重 2 错误 (a,b)，X 型 syndrome = 列a ⊕ 列b ≠ 0（PG 完备码的论证逐字移植）；9 种 Pauli 型的 syndrome 非零等价于列 a ⊕ 列 b ≠ 0 且列 a ⊕ 列 b ≠ 0（同式），故**全部 9 型权重 2 错误可检测**，O(n²) 结构判定免枚举。

**定理 10.30.2.02**（跨权重零简并）：对任意单比特错误与权重 2 错误，syndrome 必不同。证明：单比特 X_a 的 syndrome = 列 a（常数位 1）；权重 2 XX 型 syndrome = 列 a ⊕ 列 b（常数位 0）。**常数位封锁**：0 ≠ 1，跨权重 syndrome 简并恒为 0。对比 PG 完备码：无常数位，列 a ⊕ 列 b 仍是列（共线），简并比例 1/3。

**定理 10.30.2.03**（r ≥ 2 时权重 2 层完全唯一）：对 r ≥ 2，任意两对不同权重 2 错误 syndrome 互异。证明：设 {a,b} ≠ {a′,b′} 同 syndrome，则对全部次数 ≤ r 单项式 f：f(a)+f(b) = f(a′)+f(b′)。线性部分给出 a+b = a′+b′（平行四边形构型）；二次部分（f = x_i x_j）给出 s_i δ_j + s_j δ_i = 0 对全部 (i,j)，其中 s = a+b、δ = a+a′。非平凡解仅当 s ∥ δ，二元域上 s = δ 即同一对——矛盾。故**r ≥ 2 的仿射完备码权重 2 层无任何 syndrome 冲突**（跨权重 0 + 内部 0），恢复表完全干净。r = 1 时线性部分不足，出现平行四边形简并（RM(1,5)：496 对落入 63 类）。

**定理 10.30.2.04**（逻辑算符计数闭式）：仿射完备码 CSS(RM(r,m)) 的权重 d = 2^{r+1} 逻辑算符（X 型）数等于 AG(m,2) 中 (r+1)-维仿射平坦数：

$$N_{\text{logic}} = 2^{\,m-r-1}\cdot\left[\begin{matrix}m\\ r+1\end{matrix}\right]_2 = 2^{\,m-r-1}\prod_{i=0}^{r}\frac{2^{m-i}-1}{2^{r+1-i}-1}$$

（权重 d 的 C⊥ 向量 = (r+1)-平坦的指标函数；RM(r,m) 最小权重 2^{m−r} > d，故全部为逻辑。）

## 六、意义

1. **软肋消除**：10.29 评述中"d=3 不缩放"的短板被直接打掉——[[1024,252,32]] 距离 32，纠错能力随规模增长（d = 2^{r+1}，k ≈ n·(1−2·2^{−r}) 当 m 大），验证成本仍为 O(n²) 级、内存 KB 级。
2. **码预验证赛道落地**：无枚举验证方法学对整族有效——构造码后 8.8 秒完成千比特级全结构核验（列互异、权重 2 全检测、简并结构、逻辑计数闭式），无需超算，任何高码距候选码可低成本预检。
3. **零简并层的工程价值**：r ≥ 2 时权重 2 层 syndrome 完全唯一——恢复查表零冲突、解码无歧义，比 PG 完备码（1/3 跨权重简并需处理残留逻辑）更干净。
4. **统一几何图景**：两个完备家族（PG 点集 / AG 点集）的列互异论证、逻辑计数闭式（射影线数 / 仿射平坦数）呈对偶结构——逻辑算符 = 平坦子空间指标的统一表述。

## 七、开放问题

1. r ≥ 2 的零简并定理（定理 10.30.2.03）在 r = 1 失效（平行四边形简并）——RM(1,m) 的简并类计数闭式（63 类对 496 对的精确结构）未解。
2. 权重 d−1 层（2^{r+1}−1）的 syndrome 分布与逻辑结构——恢复循环的完整刻画。
3. RM CSS 码的 θ⁴ 损失标度律系数（10.29 预言 1 的推广）——零简并是否压低系数 c？需程序验证。
4. 与容错阈值的衔接：d = 32 的码在刚度分层框架下的阈值解析估计（10.29 长远愿景的下一站）。
