## 摘　要

本文两件事：(1) **补全 10.35 的失败率闭式到全 Pauli 型视角**——10.35 的 fail(w₀) = 1 − ⟨1/v⟩ 对 AG r=1 权重 2 层给出 1 − 2^{1−m}，但这是**纯型（单侧 X 或 Z 错误）**视角；实际解码面对全部 9 种 Pauli 型（含 XZ/XY 等混合型），本文证明混合型在 AG 完备码权重 2 层**完全唯一**（类大小 1），故全型失败率修正为
$$\mathrm{fail}^{(9)}(2) = \frac{1}{3}\left(1 - 2^{1-m}\right) + \frac{2}{3}\cdot 0 = \frac{1}{3} - \frac{1}{3\cdot 2^{m-1}},$$
即 1/3 的纯型错误（XX/ZZ/YY，各 2^{m-1} 元类）贡献单侧 fail，2/3 的混合型（6 种）无简并贡献 0。(2) **实现自研查表解码器** `LookupDecoder`（qec-geometry ≥ 0.3.3）：零依赖（无 stim/pymatching）、Mac 毫秒级构建 syndrome→最小权重恢复表，恢复代表 = 类内最小权重（几何论恢复表设计），解码失败 ⟺ 残留 ∉ 稳定子群。两件事统一：**解码器直接枚举验证全型失败率闭式**，并实证 AG r≥2 权重 2 层零简并（唯一率 1.0、fail(2) = 0）。

## §1　引言：10.35 的视角缺口

10.35 定理 10.35.1.02 的家族失败率谱系中，AG r=1 权重 2 层 fail(2) = 1 − 2^{1−m}（m=10: 0.998），对应的类大小 v = 2^{m−1}（10.34 实测 512 代表）。该闭式在**单侧视角**（仅 X 型或仅 Z 型错误）下正确——10.35 定理 10.35.1.08（Pauli 通道普适性）明确以"X 侧活跃错误集"展开。

但**真实解码器面对全部 9 种 Pauli 型错误**（每比特 I/X/Z/Y，权重 w 错误共 C(n,w)·3^w 个）。混合型错误（如 X_a Z_b）的 syndrome 与纯型不同，其简并结构未被 10.35 单独刻画。本文补全：混合型权重 2 错误在 AG 完备码上完全唯一（类大小 1），从而全型失败率 ≠ 单侧失败率。

**核心问题**：一台 Mac 能否"执行纠错"（syndrome → 恢复操作），而非仅"分析参数"？本文给出肯定回答：自研查表解码器在毫秒级构建恢复表并 O(1) 解码，同时用枚举直接验证全型失败率闭式。

## §2　全型失败率闭式

**记号**（沿用 10.33/10.35）：AG 完备码 CSS(RM(r,m))，n = 2^m，d = 2^{r+1}，w₀ = 2^r。syndrome 类 C(s) = {错误 E : syndrome(E) = s}，类大小 v = |C(s)|。失败率 fail(w) = 1 − ⟨1/v⟩_w（10.35 引理 10.35.2.07）。

**定理 10.83.1.01**（混合型唯一性）：CSS(RM(r,m))（r ≥ 1）的权重 2 **混合型**错误（支撑含 X 与 Z 型，即 X_a Z_b 类，a ≠ b）的 syndrome 全部唯一——类大小恒 1，不参与任何简并。

**证明**：设 E = X_a Z_b（a ≠ b，混合型）。其 syndrome 由与各稳定子的对易决定。若存在 F ≠ E 与 E 同 syndrome，则 E·F ∈ C^⊥（10.32 包含性等价）。E·F 权重 ≤ 4 = d（r=1 时）或 < d（r≥2 时）。r ≥ 2：d ≥ 8 > 4，C^⊥ 最小权重 d ⟹ E·F = I ⟹ F = E，矛盾。r = 1：d = 4，E·F 权重 ≤ 4 ∈ C^⊥ = RM(m−2,m)；RM(m−2,m) 最小权重 4 = d，故 E·F 是 3-平坦指标或单位元。但 E·F 的支撑：X_a Z_b · X_c Z_d 含 X 分量（{a,c} 型）与 Z 分量（{b,d} 型）——若 E·F = χ_P（3-平坦指标，纯 X 或纯 Z？χ_P 是 4 点平坦的**纯 X** 指标或**纯 Z**？）。注意 X 错误与 Z 错误的 syndrome 空间不同：X 错误 syndrome 只由 Z 稳定子给出，Z 错误只由 X 稳定子给出——**X 型与 Z 型错误的 syndrome 永不相等**（跨权重零简并 10.30 定理 10.30.2.02 的推广：常数位封锁）。故 E（含 X）与 F（含 X 的混合型）同 syndrome ⟺ E·F 的 X 支撑 ∈ Z-稳定子核…；而 E·F 若为纯 X 平坦指标则 E,F 的 Z 分量必须抵消，混合型约束下只有 F = E。细节：E = X_a Z_b，F = X_c Z_d 同 syndrome ⟺ 对全部 Z 稳定子 g_Z：E·F 与 g_Z 对易（X 部分）+ 对全部 X 稳定子 g_X：E·F 与 g_X 对易（Z 部分）。E·F = (X_a X_c)(Z_b Z_d)。X 部分 X_a X_c 权重 ∈ {0,2}（a=c 时 0）；Z 部分同理。若 a≠c 且 b≠d：E·F 权重 4 = d，是 3-平坦指标 χ_P，但 χ_P 的 X/Z 分量混合——RM(m−2,m) 的元素是**纯 X 或纯 Z 的**（CSS 码的 C^⊥ 元素为单侧 Pauli）。混合权重 4 向量 ∉ C^⊥ ⟹ 不同 syndrome。若 a=c（同 X 位）：E·F = Z_b Z_d 纯 Z，权重 2 < d，∉ C^⊥（最小权重 d）⟹ 不同 syndrome（且 F 与 E 的 X 分量同——但 Z 分量不同 ⟹ syndrome 差 Z_b Z_d 非平凡）。若 b=d 同理。故仅 F = E。∎

**推论 10.83.1.02**（全型失败率）：CSS(RM(1,m))（AG r=1）权重 2 层全型失败率
$$\mathrm{fail}^{(9)}(2) = \frac{1}{3} - \frac{1}{3\cdot 2^{m-1}},$$
其中 1/3 为纯型比例（XX/ZZ/YY 各 1/3×1/3×…：权重 2 错误共 C(n,2)·9 个，纯型 3×C(n,2) 个，混合型 6×C(n,2) 个），纯型类大小 2^{m−1}（10.35），混合型类大小 1（定理 10.83.1.01）。

**证明**：fail = 1 − ⟨1/v⟩ = 1 − [(1/3)(1/2^{m−1}) + (2/3)(1)] = 1/3 − 1/(3·2^{m−1})。∎

**对比**：
| 视角 | fail(2) | m=4 | m=5 | m=10 |
|---|---|---|---|---|
| 单侧（10.35） | 1 − 2^{1−m} | 0.875 | 0.9375 | 0.9980 |
| **全型（本文）** | 1/3 − 1/(3·2^{m−1}) | **0.2917** | **0.3125** | **0.3333** |

**推论 10.83.1.03**（AG r≥2 全型零简并）：CSS(RM(r,m))（r ≥ 2）权重 2 层全型失败率 = 0——纯型与混合型全部唯一（10.30 定理 10.30.2.03 对纯型 + 定理 10.83.1.01 对混合型）。

## §3　自研查表解码器

**设计**（qec-geometry `qecgeo/decoder.py`，v0.3.3）：`LookupDecoder(gens, n)`：

1. **build(w_max)**：枚举权重 ≤ w_max 的全部 Pauli 错误（Σ_w C(n,w)·3^w 个），按 syndrome 分组；恢复表 = 每类最小权重代表（几何论恢复表设计：类内最小权重 = 最优查表解码，与 MWPM 同义但纯组合）。
2. **decode(syndrome)**：O(1) 查表返回恢复 Pauli。
3. **correct(E)**：给定实际错误，恢复后残留 = E·R(s)；残留 syndrome ≠ 0 ⟺ 残留 ∉ 稳定子群 ⟺ 逻辑错误。
4. **fail_rate(w)**：枚举权重 w 错误的 ⟨1/v⟩（直接验证 10.35 闭式）。
5. **weight2_uniqueness()**：权重 2 层 syndrome 唯一率（零简并证据）。

**性能**（一台 Mac，实测）：[[5,1,3]] 表构建 0.8 ms、[[15,7,3]] 30 ms、[[16,6,4]] 50 ms、[[32,·,8]] 秒级。表大小 = 非零 syndrome 数（≤ 2^m − 1，实际远小于）。

**几何论恢复表设计原则**：恢复代表 = 类内最小权重 ⟹ 解码失败 ⟺ 实际错误与代表的组合残留为逻辑算符。类结构 = 10.30 定理 10.30.2.05 的简并类——恢复表设计 = 简并类结构的直接应用（每类选一个代表，类内其余成员共享恢复）。

**(9) Reed-Muller 矩解码器 `rm_x_decode`——大码执行层**（260827，qecgeo ≥ 0.3.5）：查表法（含 build_fast）的表大小随 n 指数增长，n=1024 时 C(1024,2)·9 ≈ 470 万错误不可行。**关键数学映射**：量子 CSS(RM(r,m)) 的 X 错误 syndrome = 错误支撑 A 与次数 ≤ r 单项式的点积（"矩"）——这恰好等于经典码 RM(m−r−1,m) 的 syndrome（该校验矩阵 = 对偶 RM(r,m) 的生成矩阵）。故量子 X 解码 ≡ 经典 RM 码的 syndrome 解码，可用**矩恢复**（O(n·poly(m))，非查表）。**矩唯一性**（|A| ≤ 2^r 的矩唯一决定 A）已验证：m=8, r=4 随机 2000 次无碰撞。

- **r=1**（错误 ≤ 2，O(n)）：矩读出——m_∅=1 → A={a}（a = 线性矩向量）；m_∅=0 且差分向量 d≠0 → A = {a, a⊕d}（枚举 a 匹配矩，取最小权重）；
- **r=2**（错误 ≤ 4）：矩方程 + 锚点枚举（2 点锚 + 差分约束，覆盖平行四边形与一般 4 点）；
- **r=3,4**（错误 ≤ 8/16）：通用解码器 `RMMomentDecoder`（矩阵查表）——预计算单点矩表 M_pt（n×K, K=C(m,≤r)），单点/两点/三点/四点分别用 M_pt 行匹配、线性矩差分、2 锚+单点、2 锚+差分；全部 numpy 向量查表。

**实测（关键跃迁）**：
- CSS(RM(1,10)) [[1024,·,4]]：10000 次解码 0.09 s（每次 9 微秒）
- **CSS(RM(4,10)) [[1024,·,32]]（d=32）：权重 ≤ 2 解码 0.75 ms/次**——查表构建需 470 万错误不可行，矩解码毫秒级
- CSS(RM(3,8)) [[256,·,16]]（d=16）：权重 ≤ 3 全恢复

**验证**：r=1 m=4..10 全过（200×200）；r=2 m=4/5 全过；r=3 m=8、r=4 m=10 权重 ≤ 2/3 全过；CSS(RM(1,m)) 端到端与 LookupDecoder 对照 100/100 一致（矩解码给出类内最小权重代表，与查表等价）。**低权重优先**：实际噪声下错误 ≤ 2 占 99.89%（§4(7) 实测）→ 实用解码几乎全命中快速路径。**诚实边界**：|A| ≥ 8（r≥3 高权重错误）未实现快速路径（返回 None 标注）；3/4 点锚点枚举 O(n²)，大 m 慢（但罕见）。

## §5　意义与边界

1. **10.35 的视角补全**：单侧 fail 与全型 fail 的区分对**真实噪声模型**重要——若噪声为单侧（如纯 X 或纯 Z 信道），用 10.35 闭式；若为退极化（X/Z/Y 等概率），全型闭式（本文）才是解码器实际面对的失败率。
2. **一台 Mac 执行纠错**：自研解码器把"分析参数"（闭式秒算）推进到"执行纠错"——先查表（O(1)，n ≤ 128），后 **RM 矩解码（O(n·poly)，n = 1024 毫秒级）**——解码器是经典算法，不依赖量子硬件；syndrome 可由 stim 模拟器产生（10.55 的电路无关管道已对接）。端到端实测六码扫描：[[16,6,4]] 在 p=0.001 下 p_L 从 0.0025 降至 0（253×），**[[64,20,8]]（d=8）降至 0（1075×）、[[128,70,8]]（d=8）降至 0.0001（260×）**，100k shots 向量化后秒级；**RM 矩解码（r=1..4）把执行规模从 n ≤ 128 跃迁到 n = 1024**——[[1024,·,32]]（d=32）权重 ≤ 2 解码 0.75 ms/次——**"一台 Mac 执行纠错"从口号变为可复现数字，且执行层不再受查表指数增长限制**。
3. **几何论恢复表**：恢复代表 = 类内最小权重，简并类结构（10.30）直接决定恢复表设计——这是"理论 → 可执行工具"的完整闭环。**零简并的工程价值量化**：[[64,20,8]]（r=2 零简并）比同规模 [[64,50,4]]（r=1 部分简并）纠错能力强 24×（1075× vs 45×）——10.30 定理 10.30.2.03 的"零简并层"不仅是结构性质，更是实际纠错性能的来源。

**诚实边界**：
- 查表解码覆盖权重 ≤ w_max（超出需 MWPM）——小/中码专用，数百比特 LDPC 不适用（表大小指数增长）；RM 矩解码突破表限制（r=1..4，n=1024 毫秒级），但 **|A| ≥ 8 的高权重错误未实现快速路径**（返回 None 标注）——真 Reed 递推多数逻辑（O(n·poly) 覆盖全部错误权重）留作后续。
- 全型失败率闭式仅在 AG 完备码验证（CSS(RM(r,m))）；PG 完备码的混合型结构未单独验证（10.35 定理 1.03 的 d 奇偶定理已覆盖单侧，全型待后续）。
- 解码器为码容量模型（无电路级噪声、无测量错误传播）。
