# 10.58 离散随机对偶：几何论的缺失块与研究纲领

## 摘要

本文记录一个理论判断：**几何论缺少"离散随机的机制"**——这是以连续场论为核心的几何论面对离散随机对象（密码学模格）系统性失效的根源。证据来自 10.56/10.57 的四轮攻击探索（谱刚性带、方向统计、交替条件化、CVP 谱 round-off）的全部封闭：每一轮失败都可追溯到连续谱与模结构之间的鸿沟，其中"模折叠"（q-周期化抹除谱方向信息）是最根本的封闭机制。数学世界中该缺失块已有成熟对应物：随机矩阵理论（RMT）、随机格理论、离散高斯分析、以及 Tao–Vu 特征值刚性。本文提出研究纲领的核心猜想：**几何论的拓扑谱刚性（10.17）与随机矩阵的统计刚性（Tao–Vu）是同一个"刚性原理"在连续/离散两端的表现**——连接两者的桥将给出"攻击排除定理"的定量形式，并可能重新定义几何论的对象域。

---

## §1 判断的提出

### 1.1 背景

2026-08-21，在四轮攻击探索（10.56 谱刚性带、10.57 三个猜想版本 + CVP 谱 round-off）全部封闭之后，对话中提出：

> "几何论还缺一块很重要的理论：离散的随机的机制。"

形式化：几何论当前是一个**连续决定论**理论——对象域（流形、叶空间、谱、拓扑不变量）与工具域（谱分析、Berry 相位、互锁常数、圆满性判据）均不含离散随机结构。

### 1.2 判断的三层含义

1. **对象域缺失**：几何论没有处理"随机化模格"（密码学格）这类对象的词汇——它是离散的（Z 格、q-周期）、随机的（A 均匀、s/e 小分布）。
2. **工具域缺失**：几何论没有概率/统计工具（随机矩阵、分布族、统计距离、极值统计）。
3. **结构缺失**：几何论的核心概念"刚性/谱"没有离散随机版本——这可能是最深的缺失。

## §2 缺失的核实

### 2.1 几何论现有的"统计"词汇（全部连续场论语境）

| 概念 | 出处 | 语境 |
|---|---|---|
| Liouville 提升与熵单调性 | 4.2 | 动力系统（连续） |
| 信息场累积量 | 5.6/5.7/5.8 | 信息场（连续场论） |
| 分子混沌 | 10.20 | 统计物理（连续场） |

向量库检索确认：文章库中"随机"仅作为对象属性（"随机化格"）出现，从未作为理论工具。

### 2.2 缺失清单

随机矩阵、随机格、离散高斯分布、概率分布族、统计距离、极值统计、Smoothing 参数、特征值刚性——**零覆盖**。

### 2.3 缺失的直接后果

在 10.56/10.57 的探索中，几何论把"谱"当作连续决定论对象使用（Gram 特征值、SVD、谱刚性带），而模格是离散随机的。结果：**每一轮攻击推导都在"连续→离散"的翻译中丢失信息**。最典型的丢失是"模折叠"：连续谱的"方向"（特征向量）在 q-周期化下被折叠，几何论甚至没有词汇描述"折叠"这件事——于是攻击的正确率退化为随机猜测（1/5），而数学上可证明这是因为窗口恒为空。

## §3 四层封闭作为缺失的证据（10.57 数据摘要）

### 3.1 四层封闭一览

| 通道 | 封闭机制 | 关键数值 |
|---|---|---|
| V1 谱刚性带（SVP） | δ² < 1 ⟺ Λ_H > n·Λ_max^{(n-1)/n} | Λ_H = 1.0001 vs 需求 10¹⁸ |
| V2 方向统计 | 最短向量不齐 λ₁ 特征方向 | 12 样本无信号 |
| V4 交替条件化 | Λ_max 平台不可消除 | Λ_H 1→3.4，需求 10¹² |
| CVP 谱 round-off | 模混叠：窗口恒为空 | σ_min ~ 1010 >> 52；正确率 = 随机 |

### 3.2 统一根源

四条独立通道的失败共享同一根源：

> **连续谱（Gram 特征值、SVD、谱刚性带）与模格（q-周期离散结构）结构性不相容。**

具体机制（CVP 谱 round-off 实验，10.57 §8）：
- 奇异基分解下，MLWE 方程化为逐坐标独立形式：t'_i = σ_i·s'_i + e'_i (mod q)
- 恢复 s'_i 需要 σ_i 落在窗口 [2‖e'‖_∞, q/(2‖s'‖)] 内（低噪声且无混叠）
- 实测负循环块矩阵 σ_min ~ 700–1300（不随维数缩小），窗口恒为空：**所有方向都被 q-周期化混叠**
- 对照实验（噪声已知的信息论上限）恢复率 100%——证明封闭机制**不是噪声，而是模折叠**

### 3.3 证据的效力

四层封闭不是"参数没调好"，而是**结构性排除**：每一条通道的失败都可追溯到模格的离散随机本质（谱展宽、无结构、q-周期）。这正是"几何论缺离散随机机制"这一判断的实证基础。

## §4 数学对应物（外部锚定）

缺失块在数学中**已存在且成熟**。以下均为文献参考（非几何论定理）：

| 缺失块 | 数学对应物 | 状态 |
|---|---|---|
| 随机谱 | 随机矩阵理论（RMT）：Marchenko–Pastur 定律、Wigner 半圆、极值统计 | 成熟 |
| 随机格 | Siegel 测度、高斯启发（GH）、Rogers 公式、Smoothing 参数（Micciancio–Regev） | 成熟（密码学安全性论证的基础） |
| 离散谱 | 格的 theta 函数、离散高斯分析（Banaszczyk 等） | 成熟 |
| **统计刚性** | **Tao–Vu 特征值刚性**（随机矩阵特征值的位置集中在全局谱密度期望附近，偏差 ~ N^{-1} 量级） | 成熟 |

### 4.1 关键观察：两个"谱刚性"

- **几何论谱刚性**（10.17）：微分流形上的谱，拓扑不变量，**微扰稳定**（连续、决定论）
- **统计谱刚性**（Tao–Vu）：随机矩阵特征值的位置**典型集中**（离散、统计）

两个"刚性"从未被放在同一个框架中。**这可能是"缺失块"的精确坐标**：几何论缺的不是随机理论本身，而是连接两个刚性的桥。

## §5 桥的猜想（核心纲领）

以下为猜想（非定理），标注证据强度与检验路径。

### 猜想 G-1（两刚性统一）

> 存在一个框架，其中 10.17 拓扑谱刚性（微扰稳定）与 Tao–Vu 统计刚性（典型集中）是同一个"刚性原理"在连续/离散两端的表现。

- 证据强度：低（仅结构类比）
- 检验路径：形式化"刚性原理"的最小公理（稳定性 + 集中性），看两端能否作为特例导出
- 风险：两个刚性的数学机制完全不同（拓扑 vs 概率），统一可能需要全新结构

### 猜想 G-2（典型无异常）

> 典型随机格（Siegel 测度下，或 ML-KEM 实例族）的谱统计无异常——即不存在可利用的"谱结构异常"。

- 证据强度：中（10.56/10.57 实验：Λ_H = 1.0001±0.0002、特征值成对简并、方向无偏——均符合"无异常"预期）
- 检验路径：把 10.57 四层封闭推广为"谱攻击族无效性定理"（统计刚性 → 攻击排除的定量证明）
- 意义：若成立，几何论从"攻击者"转为"防御者的数学"——刚性 = 无异常 = 安全的几何表达

### 猜想 G-3（偏离可检测）

> 结构化格（10.56 diag 型，Λ_H 大）与随机格（Λ_H = 1.0001）在谱统计上可区分——"偏离典型"是可检测的。

- 证据强度：高（实验已显示 Λ_H 分布完全分离：1.36–17.5 vs 1.0001–1.0005）
- 检验路径：构建谱统计分类器（Λ_H、极值统计、特征值间隙分布）
- 意义：检测结构化异常是几何论+统计的可行应用（识别"伪装成随机的结构"）

## §6 哲学定位

### 6.1 开放问题：共扼是否预留了对偶空间？

几何论之名"共扼谱几何"（Conjugate Spectral Geometry）中的"共扼"，是否预留了连续/离散、决定/随机的对偶空间？

- 若预留：缺失块是"先天另一半"——本文纲领的性质是**出柜**（另一半理论公开亮相）
- 若未预留：缺失块是"补丁"——本文纲领的性质是**扩展**

本文暂不裁决，作为开放问题。但注意一个间接证据：物理应用中几何论已多次处理量子随机性（如 8.9 黑洞辐射频谱），但那是以"物理输入"身份出现，从未作为"理论机制"——理论机制层面，离散随机确实缺席。

### 6.2 公理层的立场

按当前框架分层：真理层（主库）只接受纯几何推导。离散随机机制若引入，应位于**中间层**（实验数据锚定的物理量推导层）——随机格/密码学格的统计性质属于"物理世界的数据"，不属于纯几何真理。G-1 若成立（两刚性统一），统一原理本身或可进入真理层，但两端的具体实现留在中间层。

### §7.1 P3 首轮结果（2026-08-21）

**设计**：结构化类 S = 10.56 §4 diag 格（n=3–64，M∈{10,100,1000}，90 样本）；随机类 R = ML-KEM 负循环块格（n=4–32，q=3329，k=2，40 样本；代码形式为无调制 B = [[A, I],[0, qI]]——与 P2 相同，其 λ₁ = q 是真实格性质，0.9 定理 0.9.4.08）；中间态 I = diag + s·E（E 均匀 [-1,1] 非对角扰动，s=0.1–100）。特征：6 维谱统计（log₁₀Λ_H、log₁₀Λ_max、gap ratio 均值/标准差、对数谱散布、偏度），kNN(5) 五折交叉验证。

**结果**：

| 指标 | 数值 |
|---|---:|
| 分类准确率（5 折） | 100%（90 vs 40） |
| Mahalanobis 距离² | 40.4 |
| 单特征 log₁₀Λ_H：S | [2.0, 6.0]（Λ_H=10²–10⁶） |
| 单特征 log₁₀Λ_H：R | [0.0, 0.0]（Λ_H=1.0000…） |
| 泛化（10.56 表 n=2 格） | 正确分类为结构化 |
| 灵敏度 | s≤10（≤10%M）100% 检测；临界点 s*≈M/2 |

**解读**：G-3 获数值支持——谱统计可检测偏离典型，且灵敏度高（扰动 ≤ 10%M 时结构信号 100% 可检）。单特征 log₁₀Λ_H 即完全分离：谱刚性比是"结构指纹"。**注（归因修正）**：Λ_H = 1 侧是 negacyclic 谱共轭对称的**确定性签名**（0.9 定理 0.9.4.02，与随机化无关），diag 侧已理论化：Λ_H = M² 精确（0.9 定理 0.9.4.11——正交缩放格谱刚性比；推论 0.9.4.12——正交基 Λ_H = 列范数比平方；推论 0.9.4.13——P3 分离的确定性内核：旋转对称 → Λ_H ≡ 1、缩放结构 → Λ_H = (尺度比)²，均为确定性）——分类器区分的是两类**结构**签名（negacyclic 随机系数 vs diag 缩放），分离是**定理级**的，本实验是数值确认；随机化的作用在排除其他结构（P3 扩展与中间态实验验证的正是这一区分）。**局限**：样本规模小（n≤64）；特征空间人工选定；未覆盖更广格族（非对角结构化、加权嵌入）。

### §7.2 P3 扩展：随机幺模伪装（非标准嵌入，回应 10.56 开放问题 4）

**设计**：结构化格 diag(1,M,…,M)（n∈{8,16,32}，M∈{10,100}）× 随机幺模矩阵 U（行操作序列：交换/加整数倍/取负；操作数 c·n，c∈{1,3,10}；幅度 K∈{1,10}）→ 伪装基 B′=U·B（同一格，非标准嵌入）。检测管线：直接 6 维谱统计 vs fpylll LLL 归约后谱统计。kNN(5) 分类器同 §7.1。

**结果**：

| 指标 | 数值 |
|---|---:|
| 直接检测率（伪装下） | 0%–100%（参数依赖，波动剧烈） |
| 伪装压低 Λ_H | 从 M² 压至 ~10（log₁₀ 从 2.0/4.0 降至 0.81–1.5） |
| **LLL 解伪装检测率** | **100%（全部参数）** |
| LLL 后 Λ_H（log₁₀） | 精确恢复 2.00（M=10）/ 4.00（M=100）——0.9 推论 0.9.4.12（LLL 输出近似正交基：Λ_H = (s₂/s₁)²） |
| 对照：随机格 LLL 前后 | 0% 判结构（LLL 不创造结构） |

**解读**：

1. **非标准嵌入可以隐藏结构信号**：随机幺模基把 Λ_H 从 M² 压到 ~10，直接谱统计检测率可降至 0%——10.56 开放问题 4 的第一部分有答案：谱分离在非标准嵌入下会失效。
2. **但伪装挡不住 LLL**：归约后 100% 恢复，Λ_H 精确回到 M²——结构在格层面不可伪装。机制已定理化：伪装 = Gram 的**合同变换**（U·G·Uᵀ，U 幺模非正交——特征值改变，故 Λ_H 偏离 M²）；LLL 输出近似正交基，其 Λ_H = (s₂/s₁)²（0.9 推论 0.9.4.12）——正交化恢复列范数结构，Λ_H 回到 M²。LLL 是"解伪装器"：格基的标准化提取结构指纹。对照实验证明 LLL 不创造结构（随机格归约后仍 0%）。
3. **新认识——Λ_H 的基依赖性**：谱刚性比是基依赖的量（同一格、不同行表示，Λ_H 从 M² 变到 ~10——机制：左乘幺模 = Gram 的合同变换 U·G·Uᵀ，特征值改变；LLL 正交化恢复——0.9 推论 0.9.4.12 给出恢复目标）。谱刚性带的正确作用域是**归约基**（标准嵌入）。攻击视角的推论：ML-KEM 的随机基本身就是"伪装"（非标准嵌入），即使 LLL 解伪装，随机格的 Λ_H 也只到 17.5（10.57），远低于阈值 n——双保险。
4. **检测管线成型**：谱统计 + LLL 归约两步 = "检测-解伪装"——归约 = 随机基的标准化 = 结构指纹提取。这是"离散随机机制"的第二块砖：**归约算子作为随机基的规范化**。

**局限**：行操作生成的 U 未必均匀覆盖幺模群（均匀随机幺模采样本身是开放问题）；仅测 diag 型；n≤32。

### §7.3 BKZ 深度实验：归约深度不伪造结构，λ₁/GH 是基无关指纹

**动机**：LLL 解伪装后，更强的归约（BKZ）是否会改变结构信号？随机格的 Λ_H 是否会随归约深度增长（伪造结构）？同时修正指纹定义：`λ_min(G)` 对非正交基 ≠ 最短向量²（它是 σ_min(B)²，基的实退化度）；最短向量的正确估计是**归约基第一行长度** ‖b₁‖。

**设计**：伪装 diag 格（n∈{8,16}，M∈{10,100}，强伪装 ops=10n, K=1）× 归约深度 {LLL, BKZ-5, BKZ-10, BKZ-15}；随机格（负循环块 q-ary，n∈{8,16}）对照。指纹：log₁₀Λ_H 与 log₁₀(‖b₁‖/GH)。

**结果**：

| 类别 | log₁₀Λ_H（全部深度） | log₁₀(σ_min(B_r)/GH) | σ_min(B_r) 恢复值 |
|---|---|---|---|
| 伪装 diag（M=10） | 2.0000（精确） | −0.71 / −0.92 | **1.0000**（精确） |
| 伪装 diag（M=100） | 4.0000（精确） | −1.59 / −1.86 | **1.0000**（精确） |
| 随机格（LLL） | 0.14–0.74 | −0.19 / +0.01 | σ_min ~ GH（基退化度） |
| 随机格（BKZ-10/15） | 0.00–0.46 | −0.34 | σ_min → q（与真实 λ₁ = q 一致——0.9 定理 0.9.4.08） |

> **注（列名修正）**：本表第三、四列原写作 ‖b₁‖/GH，实际计算的是归约基 Gram 最小特征值的平方根 σ_min(B_r)（p3_bkz.py 的 `l1 = np.sqrt(lam1)`）——基的退化度，不是最短向量（解读 4 的测量教训）。σ_min ~ GH 是 LLL 后基的典型退化度，**不**表示随机格有 ~GH 的短向量；真实最短向量 = q（0.9 定理 0.9.4.08）。

**解读**：
1. **BKZ 不伪造结构**：随机格归约深度增加后 log₁₀Λ_H ∈ [0.00, 0.74]，log₁₀(‖b₁‖/GH) ∈ [−0.34, +0.01]——始终远离结构区间（Λ_H ∈ [10², 10⁴]，λ₁/GH ≤ 10^{−0.7}）。更深归约不产生结构信号——检测器对随机格安全。
2. **LLL 已饱和**：β=2（LLL）与所有更深 BKZ 输出相同——对 diag 型结构，LLL 已完美提取；解伪装器无需更深的归约。
3. **λ₁/GH 是基无关指纹（修正）**：结构格的最短向量指数级短于高斯启发（λ₁=1 vs GH=5–73）；无调制随机格的真实 λ₁ = q（0.9 定理 0.9.4.08——平凡下界即真实最短，negacyclic 无调制结构）——**不是"符合 GH"**（σ_min ~ GH 是基退化度，见解读 4 与表注）。λ₁ = q 是格不变量（基无关、与 A 无关），伪装无法压低——比基依赖的 Λ_H 更本质。
4. **q-ary 平凡短向量（修正）**：BKZ-10/15 后 σ_min → q——与真实 λ₁ = q 一致（0.9 定理 0.9.4.08：无调制格必含 q·Z^d 子格且无更短的 negacyclic 非平凡向量）——随机格的最短向量是平凡的（与密钥无关）——再次印证 10.57 的"目标错位"结论。
5. **测量教训**：λ_min(G) ≠ λ₁²（非正交基）——连续谱量与离散格量的对应需要归约基作为"翻译器"——归约 = 连续-离散的翻译算子，这是"离散随机机制"的第三块砖。

**局限**：n≤16（BKZ 深度受限）；随机格样本少；未测真实 ML-KEM 维度的 BKZ（计算成本高）。

### §7.4 收官验证：λ₁/GH 指纹在真实参数（n=256）下的区分度

**设计**：训练集用小 n（S 类 36：diag n∈{8,16,32,64}×M∈{10,100,1000}×3；R 类 20：q-ary n∈{8,16,32,64}×5），7 维特征（6 维谱统计 + λ₁/GH，均取 LLL 归约后）。测试集 n=256（k=1，格 512 维）：diag M=10/100 各 2 样本、ML-KEM 型 3 样本。λ₁/GH 用对数域计算（logdet/n 避免 det 溢出）。

**结果**：

| 指标 | 数值 |
|---|---:|
| 训练集留一准确率 | 100%（36+20） |
| n=256 测试准确率 | **7/7 正确** |
| diag 格 λ₁/GH（log₁₀） | −1.74（M=10）/ −2.73（M=100） |
| ML-KEM 格 λ₁/GH（log₁₀） | **+1.02（三样本完全一致）** |
| 单特征分离度 | **2.7–3.7 个数量级** |

**解读**：
1. **λ₁/GH 是跨维度稳定的指纹**：小 n 训练的 kNN 直接适用于 n=256——归一化（除以 GH）消除了维度依赖。分离度 2.7+ 个数量级，强于 Λ_H（2.00/4.00 vs 0.08–0.44）。
2. **ML-KEM 型（无调制变体）的 λ₁/GH 恒为 +1.02 = log₁₀(q/GH)**：真实最短向量 = 平凡 q 向量（长度 q=3329——negacyclic 无调制格的 λ₁ = q，0.9 定理 0.9.4.08；这是真实格性质，非"LLL 可见"的计算假象）——**无调制随机 q-ary 格的"最短向量"是格结构的平凡指纹，与 A、与密钥完全无关**——第四次印证"随机格无密钥结构"（10.57 目标错位结论）。
3. **检测管线收官**：谱统计（基依赖）→ LLL（解伪装）→ λ₁/GH（基无关指纹）。三块砖完整，真实参数验证通过。

**局限**：k=1（非 ML-KEM 真实 k=2/3/4——但 q-ary 结构相同，k 仅改变格维度）；本实验的无调制格真实 λ₁ = q（0.9 定理 0.9.4.08——此处无 SIS 假设适用；SIS 假设（λ₁ ~ GH）对应有调制标准 q-ary 格，见 §7.6 P4.3 的修正）。

### §7.5 P2 首轮：典型无异常——零方差定律（n=256, N=20）

**设计**：n=256, k=1, q=3329，20 个随机实例（种子 0–19）；每实例测原始 Gram 谱统计 + LLL 后谱统计；检验集中性（CV）、3σ 异常、结构化对照。

**结果**：

| 统计量 | 均值 | 标准差 | min–max | CV |
|---|---|---|---|---|
| λ₁/GH（真实 λ₁ = q） | +1.0228 | **0.0000** | 恒等 | **0** |
| 原始 Λ_H | 1.000000 | **0.0000** | 恒等 | **0** |
| LLL 后 Λ_H | 2.10 | 0.78 | [1.02, 3.55] | 0.37 |
| 原始 Λ_max | 1.3×10⁵ | 3.3×10⁵ | [1.2×10⁴, 1.6×10⁶] | 2.6 |

**3σ 异常检查**：raw Λ_H 的"异常"（seed 5）为浮点假象（std=0 时 3σ 无意义）；Λ_max 的"异常"为随机矩阵极值统计的正常重尾（λ_min(G)=σ_min(B)² 波动）——**无真实结构异常**。

**结构化对照**：diag M=10/100 的 Λ_H = 100/10000（LLL 前后不变）、λ₁/GH = −1.74/−2.73——与随机典型区间（Λ_H ∈ [1, 3.6]；λ₁/GH = +1.02）分离 1.5–3.7 个数量级。

**解读**：

1. **"典型无异常"的最强形式是零方差定律，不是统计集中**：20/20 实例 λ₁ = q = 3329（b₁ 全部恒等）——因为本实验的格是无调制变体（B = [[A, I],[0, qI]]）：λ₁ = q 是**真实最短长度**（negacyclic 结构 + 无调制——0.9 定理 0.9.4.08，概率 1 − exp(−Ω(d))；LLL 只是找到它），不是"可见层面"的偶然。这不是"高概率无异常"，是**结构必然**（无调制 + negacyclic）。原始 Λ_H = 1.000000 同理（negacyclic 谱共轭对称——0.9 定理 0.9.4.02——**确定性结构，与随机化无关**；随机化的作用是排除其他结构（P3 分离），不产生零方差）。
2. **LLL 后 Λ_H ∈ [1.0, 3.6]**（N=20 经验区间）：有波动（CV=0.37）但远低于 10.56 谱刚性带的阈值（需 Λ_H > n ~ 512）——波动是随机格 GSO 尾部的正常随机性，不是结构信号。
3. **诚实边界（修正——格形式区分）**：本实验的无调制格真实 λ₁ = q（0.9 定理 0.9.4.08）——可见无异常 = 格无异常（**真实性质**，非计算保护）。SIS 假设（λ₁ ~ GH ~ 316 < q）适用于**有调制**标准 q-ary 格（ML-KEM 安全性格——§7.6 P4.3）——两种格需明确区分：无调制格的谱"无异常"是结构性的，有调制格的短向量存在但提取 = 破 SIS（计算性）。这与几何论的连续谱形成对照——连续谱信息直接可读（谱 = 信息），有调制离散结构的短向量"锁在计算里"（信息在，读取路径锁死——§7.6 的精确表述）。
4. **分离度收官**：Λ_H 差 1.5–3.7 个数量级、λ₁/GH 差 2.7–3.7 个数量级——P2 与 P3 共享同一组指纹，从两个方向（随机典型区间 vs 结构异常区间）互相印证。

**定理（理论化——0.9 §4.3）**：negacyclic 无调制格族（n=256, q=3329）：λ₁ = q 与 Λ_H ≡ 1 是定理（0.9 定理 0.9.4.02/0.9.4.08——结构性质），N=20 零方差是数值确认；Λ_H^(LLL) ∈ [1.0, 3.6] 仍是经验区间（归约过程波动——其定量是开放问题）。

### §7.6 P4 攻击排除框架（完全形式化）

**定义（谱攻击族）**：

- **格谱层攻击 A₁**：输出只依赖 B(A) 的谱统计量（Gram/SVD 特征值、LLL/BKZ 归约后谱统计），不读取密文 t。
- **陪集统计层攻击 A₂**：读取 (A, t)，但对 t 的利用限于线性统计（CVP round-off 残差、范数、NTT 系数等）。

**定理 P4.1（格谱层——信息论排除，完备）**：

- **命题**：任意 A₁（输出为 B(A) 谱统计量的任意函数 F）的输出与密钥 s 独立。
- **证明**：B = φ(A)（B = [[A, I],[0, qI]]——代码形式，无调制）；A ⊥ s（密钥独立于公钥生成——ML-KEM 生成规范）；F∘φ 是 A 的函数；独立随机变量的函数仍独立。□
- **强化（P2 数值确认 + 理论）**：F(B(A)) 甚至与 A 独立（20/20 零方差——negacyclic 无调制结构性质：0.9 定理 0.9.4.02/0.9.4.10——λ₁ = q 与 Λ_H ≡ 1 均与 A 无关）——攻击者连"实例区分"都做不到。
- **推论**：格谱层不含 s 的任何信息——攻击者必须使用 t。

**信息论真相（关键修正——数值锚定，2026-08-21）**：

骨架版曾声称陪集层"信息论排除"——**这个声称被数值验证推翻**。真相是：

- s、e 的系数 ∈ [-2,2]（中心二项 B_2，支撑 5 值）→ t = As+e 的支撑 ≤ 25^d；q^d = 3329^512——稀疏因子 25^d/q^d = 10^(−1088)：**t 高度稀疏**。
- 碰撞 (s′,e′)≠(s*,e*) 需 A·δs = δe（δs,δe ∈ [-4,4]^d 非零）：期望碰撞数 (81/q)^d = 10^(−826)——几乎必然无碰撞 → **(s,e) 从 t 唯一确定，后验熵 H(s|A,t) = 0**。
- 数值：H(B_2) = 2.0306 bits/坐标；H(s) = H(e) = 1039.7 bits；H(t|A) ≈ H(s)+H(e) = 2079.4 bits ≪ d·log₂q = 5990.8 bits。
- **推论：搜索 LWE 信息论可解（s 唯一确定）——LWE 的困难纯是计算的**。陪集层不存在信息论保护。

**命题 P4.2（陪集层——算法排除，10.57 实证）**：

- 谱型方法（CVP round-off、方向统计、交替条件化——10.57 四层封闭）正确率 = 随机（0.53/0.58）。
- 机制：σ_i·s′_i mod q 的折叠在**线性框架**内丢失方向信息（混叠窗口恒空：σ_min ≈ 1010 ≫ 52）。
- **定位**：这是算法族排除（已检验成员失败 + 机制论证），**不是**信息论定律——信息论上 s 唯一确定，未来新谱算法在原理上未被排除（除非折叠机制严格化）。CVP 型失败的稳健性：四轮探索、多种方法、同一折叠机制。

**命题 P4.3（结构层——计算保护）**：

- **有调制标准 q-ary 格**（ML-KEM 安全性分析的标准格形式）：λ₁ ≤ 2R₀ = (2+o(1))·GH < q——**短向量存在是定理**（0.9 命题 0.9.4.09：Minkowski 第一定理上界；d=512 锚定：GH ≈ 447、2R₀ ≈ 897 ≪ 3329，远满足 d < qπe/4 ≈ 7107）。SIS 的困难**不在"短向量是否存在"**（存在性已被保证），而在**提取** = 解 SIS（假设困难）。注意：P2/P3 实验的无调制变体（λ₁ = q——0.9 定理 0.9.4.08）**不是**此层的对象——本层针对 ML-KEM 安全性分析的标准格形式，两种格不可混用。
- **边界声明**：P4 不证明"格密码安全"——非谱攻击（代数、枚举、MIP、量子）的困难性归入此层（假设）。

**定理 P4.4（谱攻击族排除的最终形态）**：

- **格谱层**：信息论排除（P4.1——原理性，完备）
- **陪集层**：算法排除（P4.2——实证 + 机制，非原理性）
- **结构层**：计算保护（P4.3——假设）
- **结论**：谱攻击族对随机 q-ary 格无效——**性质分层：原理（格谱）/算法（陪集）/假设（结构）**。

**理论贡献："信息→计算转移"的精确表述**：

- 连续谱（几何论世界观）：信息直接可读——谱 = 信息，读 = 多项式计算。
- 离散随机（模格）：**信息没有藏起来**（s 唯一确定，后验熵 = 0）——**锁的是读取路径**：唯一候选的寻找 = 枚举 2^2378 或解 SIS（指数）。
- 随机化的本质：把"可读性"从信息中剥离，转成计算成本——不是信息缺失，是读取代价指数化。
- 这修正了 §7.5 的表述（"信息锁在计算里"）：更精确的说法是——**信息在，读取路径锁死**。信息论上没有锁（唯一性），锁在计算复杂性。

**局限**：

- P4.1 完备（纯逻辑）；"与 A 独立"是 P2 经验（20 样本）。
- P4.2 是算法族排除（非原理性）——折叠机制的严格形式化（H(s′\|σs′ mod q)）仍未完成。
- P4.3 是假设。决策 LWE（区分 t 与均匀）与侧信道不在范围。
- 剩余工作：① P4.2 折叠机制严格化；② P2 扩样本（N=200）；③ 非谱攻击族分层（超出几何论）。
