# 10.58 离散随机对偶：几何论的缺失块与研究纲领

## 摘要

本文记录一个理论判断：**几何论缺少"离散随机的机制"**——这是以连续场论为核心的几何论面对离散随机对象（密码学模格）系统性失效的根源。证据来自 10.56/10.57 的四轮攻击探索（谱刚性带、方向统计、交替条件化、CVP 谱 round-off）的全部封闭：每一轮失败都可追溯到连续谱与模结构之间的鸿沟，其中"模折叠"（q-周期化抹除谱方向信息）是最根本的封闭机制。数学世界中该缺失块已有成熟对应物：随机矩阵理论（RMT）、随机格理论、离散高斯分析、以及 Tao–Vu 特征值刚性。本文提出研究纲领的核心猜想：**几何论的拓扑谱刚性（10.17）与随机矩阵的统计刚性（Tao–Vu）是同一个"刚性原理"在连续/离散两端的表现**——连接两者的桥将给出"攻击排除定理"的定量形式，并可能重新定义几何论的对象域。

---

## §1 判断的提出

### 1.1 背景

2026-08-21，在四轮攻击探索（10.56 谱刚性带、10.57 三个猜想版本 + CVP 谱 round-off）全部封闭之后，对话中提出：

> "几何论还缺一块很重要的理论：离散的随机的机制。"

形式化：几何论当前是一个**连续决定论**理论——对象域（流形、叶空间、谱、拓扑不变量）与工具域（谱分析、Berry 相位、互锁常数、圆满性判据）均不含离散随机结构。

### 1.2 判断的三层含义

1. **对象域缺失**：几何论没有处理"随机化模格"（密码学格）这类对象的词汇——它是离散的（Z 格、q-周期）、随机的（A 均匀、s/e 小分布）。
2. **工具域缺失**：几何论没有概率/统计工具（随机矩阵、分布族、统计距离、极值统计）。
3. **结构缺失**：几何论的核心概念"刚性/谱"没有离散随机版本——这可能是最深的缺失。

## §2 缺失的核实

### 2.1 几何论现有的"统计"词汇（全部连续场论语境）

| 概念 | 出处 | 语境 |
|---|---|---|
| Liouville 提升与熵单调性 | 4.2 | 动力系统（连续） |
| 信息场累积量 | 5.6/5.7/5.8 | 信息场（连续场论） |
| 分子混沌 | 10.20 | 统计物理（连续场） |

向量库检索确认：文章库中"随机"仅作为对象属性（"随机化格"）出现，从未作为理论工具。

### 2.2 缺失清单

随机矩阵、随机格、离散高斯分布、概率分布族、统计距离、极值统计、Smoothing 参数、特征值刚性——**零覆盖**。

### 2.3 缺失的直接后果

在 10.56/10.57 的探索中，几何论把"谱"当作连续决定论对象使用（Gram 特征值、SVD、谱刚性带），而模格是离散随机的。结果：**每一轮攻击推导都在"连续→离散"的翻译中丢失信息**。最典型的丢失是"模折叠"：连续谱的"方向"（特征向量）在 q-周期化下被折叠，几何论甚至没有词汇描述"折叠"这件事——于是攻击的正确率退化为随机猜测（1/5），而数学上可证明这是因为窗口恒为空。

## §3 四层封闭作为缺失的证据（10.57 数据摘要）

### 3.1 四层封闭一览

| 通道 | 封闭机制 | 关键数值 |
|---|---|---|
| V1 谱刚性带（SVP） | δ² < 1 ⟺ Λ_H > n·Λ_max^{(n-1)/n} | Λ_H = 1.0001 vs 需求 10¹⁸ |
| V2 方向统计 | 最短向量不齐 λ₁ 特征方向 | 12 样本无信号 |
| V4 交替条件化 | Λ_max 平台不可消除 | Λ_H 1→3.4，需求 10¹² |
| CVP 谱 round-off | 模混叠：窗口恒为空 | σ_min ~ 1010 >> 52；正确率 = 随机 |

### 3.2 统一根源

四条独立通道的失败共享同一根源：

> **连续谱（Gram 特征值、SVD、谱刚性带）与模格（q-周期离散结构）结构性不相容。**

具体机制（CVP 谱 round-off 实验，10.57 §8）：
- 奇异基分解下，MLWE 方程化为逐坐标独立形式：t'_i = σ_i·s'_i + e'_i (mod q)
- 恢复 s'_i 需要 σ_i 落在窗口 [2‖e'‖_∞, q/(2‖s'‖)] 内（低噪声且无混叠）
- 实测负循环块矩阵 σ_min ~ 700–1300（不随维数缩小），窗口恒为空：**所有方向都被 q-周期化混叠**
- 对照实验（噪声已知的信息论上限）恢复率 100%——证明封闭机制**不是噪声，而是模折叠**

### 3.3 证据的效力

四层封闭不是"参数没调好"，而是**结构性排除**：每一条通道的失败都可追溯到模格的离散随机本质（谱展宽、无结构、q-周期）。这正是"几何论缺离散随机机制"这一判断的实证基础。

## §4 数学对应物（外部锚定）

缺失块在数学中**已存在且成熟**。以下均为文献参考（非几何论定理）：

| 缺失块 | 数学对应物 | 状态 |
|---|---|---|
| 随机谱 | 随机矩阵理论（RMT）：Marchenko–Pastur 定律、Wigner 半圆、极值统计 | 成熟 |
| 随机格 | Siegel 测度、高斯启发（GH）、Rogers 公式、Smoothing 参数（Micciancio–Regev） | 成熟（密码学安全性论证的基础） |
| 离散谱 | 格的 theta 函数、离散高斯分析（Banaszczyk 等） | 成熟 |
| **统计刚性** | **Tao–Vu 特征值刚性**（随机矩阵特征值的位置集中在全局谱密度期望附近，偏差 ~ N^{-1} 量级） | 成熟 |

### 4.1 关键观察：两个"谱刚性"

- **几何论谱刚性**（10.17）：微分流形上的谱，拓扑不变量，**微扰稳定**（连续、决定论）
- **统计谱刚性**（Tao–Vu）：随机矩阵特征值的位置**典型集中**（离散、统计）

两个"刚性"从未被放在同一个框架中。**这可能是"缺失块"的精确坐标**：几何论缺的不是随机理论本身，而是连接两个刚性的桥。

## §5 桥的猜想（核心纲领）

以下为猜想（非定理），标注证据强度与检验路径。

### 猜想 G-1（两刚性统一）

> 存在一个框架，其中 10.17 拓扑谱刚性（微扰稳定）与 Tao–Vu 统计刚性（典型集中）是同一个"刚性原理"在连续/离散两端的表现。

- 证据强度：低（仅结构类比）
- 检验路径：形式化"刚性原理"的最小公理（稳定性 + 集中性），看两端能否作为特例导出
- 风险：两个刚性的数学机制完全不同（拓扑 vs 概率），统一可能需要全新结构

### 猜想 G-2（典型无异常）

> 典型随机格（Siegel 测度下，或 ML-KEM 实例族）的谱统计无异常——即不存在可利用的"谱结构异常"。

- 证据强度：中（10.56/10.57 实验：Λ_H = 1.0001±0.0002、特征值成对简并、方向无偏——均符合"无异常"预期）
- 检验路径：把 10.57 四层封闭推广为"谱攻击族无效性定理"（统计刚性 → 攻击排除的定量证明）
- 意义：若成立，几何论从"攻击者"转为"防御者的数学"——刚性 = 无异常 = 安全的几何表达

### 猜想 G-3（偏离可检测）

> 结构化格（10.56 diag 型，Λ_H 大）与随机格（Λ_H = 1.0001）在谱统计上可区分——"偏离典型"是可检测的。

- 证据强度：高（实验已显示 Λ_H 分布完全分离：1.36–17.5 vs 1.0001–1.0005）
- 检验路径：构建谱统计分类器（Λ_H、极值统计、特征值间隙分布）
- 意义：检测结构化异常是几何论+统计的可行应用（识别"伪装成随机的结构"）

## §6 哲学定位

### 6.1 开放问题：共扼是否预留了对偶空间？

几何论之名"共扼谱几何"（Conjugate Spectral Geometry）中的"共扼"，是否预留了连续/离散、决定/随机的对偶空间？

- 若预留：缺失块是"先天另一半"——本文纲领的性质是**出柜**（另一半理论公开亮相）
- 若未预留：缺失块是"补丁"——本文纲领的性质是**扩展**

本文暂不裁决，作为开放问题。但注意一个间接证据：物理应用中几何论已多次处理量子随机性（如 8.9 黑洞辐射频谱），但那是以"物理输入"身份出现，从未作为"理论机制"——理论机制层面，离散随机确实缺席。

### 6.2 公理层的立场

按当前框架分层：真理层（主库）只接受纯几何推导。离散随机机制若引入，应位于**中间层**（实验数据锚定的物理量推导层）——随机格/密码学格的统计性质属于"物理世界的数据"，不属于纯几何真理。G-1 若成立（两刚性统一），统一原理本身或可进入真理层，但两端的具体实现留在中间层。

建议优先级：P3 → P4 → P2 → P1 → P5。

### §7.1 P3 首轮结果（2026-08-21）

**设计**：结构化类 S = 10.56 §4 diag 格（n=3–64，M∈{10,100,1000}，90 样本）；随机类 R = ML-KEM 负循环块格（n=4–32，q=3329，k=2，40 样本）；中间态 I = diag + s·E（E 均匀 [-1,1] 非对角扰动，s=0.1–100）。特征：6 维谱统计（log₁₀Λ_H、log₁₀Λ_max、gap ratio 均值/标准差、对数谱散布、偏度），kNN(5) 五折交叉验证。

**结果**：

| 指标 | 数值 |
|---|---:|
| 分类准确率（5 折） | 100%（90 vs 40） |
| Mahalanobis 距离² | 40.4 |
| 单特征 log₁₀Λ_H：S | [2.0, 6.0]（Λ_H=10²–10⁶） |
| 单特征 log₁₀Λ_H：R | [0.0, 0.0]（Λ_H=1.0000…） |
| 泛化（10.56 表 n=2 格） | 正确分类为结构化 |
| 灵敏度 | s≤10（≤10%M）100% 检测；临界点 s*≈M/2 |

**解读**：G-3 获数值支持——谱统计可检测偏离典型，且灵敏度高（扰动 ≤ 10%M 时结构信号 100% 可检）。单特征 log₁₀Λ_H 即完全分离：谱刚性比是"结构指纹"。**局限**：样本规模小（n≤64）；特征空间人工选定；未覆盖更广格族（非对角结构化、加权嵌入）。

### §7.2 P3 扩展：随机幺模伪装（非标准嵌入，回应 10.56 开放问题 4）

**设计**：结构化格 diag(1,M,…,M)（n∈{8,16,32}，M∈{10,100}）× 随机幺模矩阵 U（行操作序列：交换/加整数倍/取负；操作数 c·n，c∈{1,3,10}；幅度 K∈{1,10}）→ 伪装基 B′=U·B（同一格，非标准嵌入）。检测管线：直接 6 维谱统计 vs fpylll LLL 归约后谱统计。kNN(5) 分类器同 §7.1。

**结果**：

| 指标 | 数值 |
|---|---:|
| 直接检测率（伪装下） | 0%–100%（参数依赖，波动剧烈） |
| 伪装压低 Λ_H | 从 M² 压至 ~10（log₁₀ 从 2.0/4.0 降至 0.81–1.5） |
| **LLL 解伪装检测率** | **100%（全部参数）** |
| LLL 后 Λ_H（log₁₀） | 精确恢复 2.00（M=10）/ 4.00（M=100） |
| 对照：随机格 LLL 前后 | 0% 判结构（LLL 不创造结构） |

**解读**：

1. **非标准嵌入可以隐藏结构信号**：随机幺模基把 Λ_H 从 M² 压到 ~10，直接谱统计检测率可降至 0%——10.56 开放问题 4 的第一部分有答案：谱分离在非标准嵌入下会失效。
2. **但伪装挡不住 LLL**：归约后 100% 恢复，Λ_H 精确回到 M²——结构在格层面不可伪装。LLL 是"解伪装器"：格基的标准化提取结构指纹。对照实验证明 LLL 不创造结构（随机格归约后仍 0%）。
3. **新认识——Λ_H 的基依赖性**：谱刚性比是基依赖的量（同一格、不同基，Λ_H 从 M² 变到 ~10）。谱刚性带的正确作用域是**归约基**（标准嵌入）。攻击视角的推论：ML-KEM 的随机基本身就是"伪装"（非标准嵌入），即使 LLL 解伪装，随机格的 Λ_H 也只到 17.5（10.57），远低于阈值 n——双保险。
4. **检测管线成型**：谱统计 + LLL 归约两步 = "检测-解伪装"——归约 = 随机基的标准化 = 结构指纹提取。这是"离散随机机制"的第二块砖：**归约算子作为随机基的规范化**。

**局限**：行操作生成的 U 未必均匀覆盖幺模群（均匀随机幺模采样本身是开放问题）；仅测 diag 型；n≤32。

## §8 开放问题

1. 两个刚性的统一需要什么数学结构？（拓扑 vs 概率的最小公理是什么？）
2. 统计刚性能否给出超越个案的攻击排除（从"四层封闭"到"攻击族无效"）？
3. 几何论引入离散随机机制后，公理层是否扩展？（当前立场：公理层保持纯几何，离散随机放中间层）
4. "模折叠"能否形式化为几何概念？（q-周期化 = 离散纤维化？——若可，折叠就从"信息杀手"变为"可计算的几何对象"）
