## 0. 摘要

10.29 给出四条可实验检验的定量预言。本程序把预言做成可发布、可复现、可自动判定的验证工具：

- **模拟路径**：独立重实现 P2/P3/P4 的验证逻辑（态矢量 + stabilizer 符号模拟），复现 §3 的程序证据（斜率 4.04/4.12/4.14 等）；
- **实验路径**：导入公开量子硬件（IBM Quantum 5/7 比特档位）的 shots 数据，走同一套统计管线，与闭式预言逐点对比；
- **判定路径**：把 §6.1 证伪条件编码为自动 PASS/FAIL 判据，输出统一 report（JSON + 图）。

**设计原则**：闭式锚点优先（检测率 sin²(θ/2)、315/945=1/3、线计数公式），不引入拟合参数；判据可证伪（对应 §6.1）；实验不可分辨时程序必须输出"不可检验"而非强行判定（§6.1 判据 4）。

## 1. 预言清单（判定规格来源）

### 预言一：θ⁴ 损失标度律（§4.1）

设 $[[n,k,3]]$ 码制备 $|\psi_L\rangle$，每物理比特注入独立旋转 $U(\theta_i)$（Pauli 型随机，$\theta_i$ 均匀取自 $[0,\theta_{\max}]$），最优纠错后：

$$L(\theta_{\max}) = c\,\theta_{\max}^4 + O(\theta_{\max}^6), \qquad c \sim 10^{-2}$$

log-log 斜率 $=4$。程序预拟合（30 次试验平均，$\theta_{\max}\in\{0.05,0.1,0.2,0.4\}$）：

| 码 | 损失序列 $L$ | 斜率 | 系数 $c$ |
|---|---|---|---|
| $[[5,1,3]]$ | 3.2e-7, 5.3e-6, 8.5e-5, 1.4e-3 | 4.04 | ≈0.06 |
| $[[7,1,3]]$ | 4.0e-7, 8.7e-6, 9.9e-5, 2.4e-3 | 4.12 | ≈0.10 |
| $[[9,1,3]]$ | 1.6e-7, 1.9e-6, 3.9e-5, 8.4e-4 | 4.14 | ≈0.03 |

**判定输入**：四 θ_max 点损失值 → 线性拟合 log L vs log θ_max → 斜率。

### 预言二：检测率闭式与漏检无害（§4.2）

单比特 Pauli 型旋转注入 $U(\theta)$：
- (a) 检测率 $p_{\det}(\theta)=\sin^2(\theta/2)$（闭式，无参数）；
- (b) 漏检路径（syndrome=0）条件保真度 $F_{\text{miss}}=1$；
- (c) 检测路径条件保真度 $F_{\det}=1$。

程序实测偏差：检测率 $<3.8\times10^{-16}$，保真度 $<2.2\times10^{-16}$（机器精度级）。

### 预言三：逻辑方向不可检测（§4.3）

逻辑算符注入（$\bar X$ 或 $\bar Z$）：syndrome 恒零；$Z$ 型对 $|0_L\rangle$ 损失 $=0$；$X$ 型损失 $=\sin^2(\theta/2)$。保真度 $F=|c+is\langle\psi|E|\psi\rangle|^2$ 闭式成立。

### 预言四：权重 2 共线结构与 1/3 比例（§4.4）

- (a) $[[15,7,3]]$：945 个权重 2 错误中恰 315 个与单比特错误同 syndrome（$=1/3$）；
- (b) 一般方向完备码 $[[2^m-1,\,2^m-1-2m,\,3]]$：所有权重 2 错误均为共线型（$PG(m-1,2)$ 列异或封闭），权重 3 逻辑计数 $=(2^m-1)(2^m-2)/6$（$m=4$：35；$m=10$：174,251）。

**结构锚点**（§3.3 已实测）：$[[1023,1003,3]]$ 3069 单比特全检测（0.12 s）、4,704,777 权重 2 全检测（0.12 s）、174,251 条线精确吻合公式。

## 3. 模块规格

### 3.1 codes.py — 码定义

- stabilizer 生成元表：$[[5,1,3]]$（4 生成元）、$[[7,1,3]]$ Steane（6 生成元）、$[[9,1,3]]$ Shor（8 生成元，退化码对照）、$[[15,7,3]]$（8 生成元，RM(1,4) CSS——预言四）；
- 接口：`get_code(name) -> Code`，Code 提供 `generators`（Pauli 字符串表）、`logicals`、`distance`；
- 生成元正确性用锚点测试锁定（见 §5）。

### 3.2 sim_statevector.py — 态矢量模拟（预言一/二/三）

复现 P2 逻辑（10.28 §6 O6）：
- 制备 $|0_L\rangle$（由 stabilizer 生成元的 +1 本征态投影）；
- 注入：单比特 $U(\theta)=cI+isP$（预言二/三）或全比特独立随机 $\theta_i$（预言一）；
- syndrome 测量：逐生成元投影测量（非破坏性）；
- 恢复：查表（小码全表预计算）；
- 损失：$L=1-F$，$F$ 以码空间投影概率估计；
- 抽样：预言一 30 trials/点（与 §3.1 一致），预言二/三每 (θ,P) 点 $N\ge5000$（与 §5.1 一致）。

**复杂度**：n=9 → 512 维复数态；30 trials × 4 θ × 3 码 → 秒级。n=15 不走进此路径（stabilizer 模拟）。

### 3.3 sim_stabilizer.py — 符号模拟（预言四）

复现 P3/P4 逻辑（纯符号、位运算）：
- 全量枚举权重 1/2 错误（$[[15,7,3]]$：45 + 945；$[[1023,1003,3]]$：3069 + 4,704,777）；
- syndrome 计算（与生成元反交换型）；
- 同 syndrome 判定 + 共线型判定（$SX[a]=H$ 第 $a$ 列、列异或封闭性）；
- 线计数 $=(2^m-1)(2^m-2)/6$ 枚举对照；
- 输出：计数 + 时间标度（对照 §3.3 的 0.12 s 量级）。

### 3.4 predictions.py — 闭式计算器

- `detection_rate(theta)` = sin²(θ/2)；
- `logical_loss_x(theta)` = sin²(θ/2)；`logical_loss_z(theta)` = 0；
- `same_syndrome_fraction(m)` = 1/3（推导：每权重 2 错误恰与一单比特同 syndrome——PG 列异或封闭）；
- `line_count(m)` = (2^m−1)(2^m−2)/6。

### 3.5 criteria.py — 自动判据（§6.1 编码）

| ID | 预言 | 判据 | 阈值（模拟/实验） |
|---|---|---|---|
| C1 | 一 | log-log 斜率 ∈ [3.5, 4.5]（硬证伪界）；附加软判据：拟合 CI 不含 2 且不含 6 | 模拟：CI 由 4 点拟合给出；实验：±3σ |
| C2a | 二(a) | max\|p_det − sin²(θ/2)\| < 3σ | 模拟：1e-14（机器精度容差）；实验：4.2e-2（σ≈1.4e-2，N=5000） |
| C2b | 二(b) | 1 − F_miss < 3σ | 同上 |
| C2c | 二(c) | 1 − F_det < 3σ | 同上 |
| C3 | 三 | syndrome 非零计数 = 0（模拟）；≤ 硬件串扰基线（实验，基线由空注入对照标定） | — |
| C4a | 四(a) | 同 syndrome 计数 = 315 精确（945 中） | 整数精确 |
| C4b | 四(b) | 线计数 = 公式值精确（m=4→35，m=10→174,251） | 整数精确 |
| C5 | 对照 | 随机 Pauli 信道 log-log 斜率 ≈ 2 | [1.5, 2.5] |

**不可检验判定**（§6.1 判据 4）：若对照实验（C5）与相干注入给出相同标度，程序输出 `INCONCLUSIVE（硬件退相干主导，预言一在该平台不可检验）`——不强行判定。

**输出**：`report.json` 结构——

```json
{
  "predictions": {
    "P1": {"slope": 4.04, "ci": [3.9, 4.2], "c": 0.06, "verdict": "PASS"},
    "P2a": {"max_dev": 3.8e-16, "verdict": "PASS"},
    ...
  },
  "mode": "simulation" | "experiment",
  "hardware": {"platform": null, "shots": null},
  "verdicts": {"summary": "PASS x6, INCONCLUSIVE x0"},
  "generated": "2026-08-13T..."
}
```

### 3.6 experiment.py — 实验数据接口

- 导入：IBM Quantum jobs 导出的 shots 计数 JSON（`{"counts": {"0000": 512, ...}, "meas_level": 2}`）；
- 管线：shots → 检测率估计 $\hat p_{\det}$（非零 syndrome 比例）→ 条件保真度估计（$\bar Z$ 基测量 + 码空间投影）→ 与闭式对比 → C2/C3 判据；
- 噪声标定：空注入（θ=0）对照 → 硬件基线（串扰/退相干预算）→ C3 的基线阈值来源；
- 合成数据生成器（测试用）：按闭式预言生成 shots 分布，验证管线无偏。

### 3.7 cli.py — 命令行

```
qec-theta4 simulate --code 5 --theta-max 0.2 --trials 30 [--plot figs/]
qec-theta4 anchors --code 15             # 结构锚点：1/3、线计数、时间标度
qec-theta4 verify --report report.json   # 判据汇总（读任意 report）
qec-theta4 experiment --shots ibm.json --code 5 --baseline empty.json
qec-theta4 compare --sim sim.json --exp exp.json   # 模拟-实验逐点对比
qec-theta4 all --outdir results/         # 一键：模拟 → 判据 → 报告
```

## 4. 测试策略

1. **锚点测试**（test_anchors.py）：闭式数值——sin²(θ/2) 在 θ∈{0.05,0.1,0.2,0.4} 的机器精度值；315/945=1/3；35、174,251；生成元表的 stabilizer 条件（对易/生成元独立性）——**锚点不通过即构建失败**；
2. **复现测试**（test_slopes.py）：三码斜率复现 4.04/4.12/4.14 ± 0.2（模拟随机性容差，30 trials 下统计波动估计 ~0.1）；检测率偏差 <1e-14；漏检保真度 1−F<1e-14；
3. **判据测试**（test_criteria.py）：构造 PASS 数据（闭式生成）与 FAIL 数据（注入 θ² 标度）→ 判据正确分类；INCONCLUSIVE 分支测试；
4. **管线测试**（test_experiment.py）：合成 shots → 统计估计无偏（N=5000 下 |偏差|<3σ）；格式容错（IBM 变体 JSON）。

CI：GitHub Actions（pytest，Python 3.9/3.12）——模式同 qec-distance-certificates。

## 7. 风险与对策

| 风险 | 影响 | 对策 |
|---|---|---|
| 态矢量模拟 n=9 的 30 trials 随机性使斜率波动 >0.2 | M1 验收模糊 | 固定随机种子复现 §3.1 精确值（10.28 参考实现同种子可对）；波动分析写入测试容差依据 |
| 实验侧退相干主导，θ⁴ 不可分辨 | 预言一在实验平台不可检验 | 程序必须输出 INCONCLUSIVE（§6.1 判据 4），不强行判定——判定诚实性优先 |
| [[15,7,3]] 需要 15 比特（IBM 127 比特档位，排队成本） | 预言四实验延迟 | 预言四判据 C4 是纯结构判据，模拟侧即可全量判定；实验侧（双比特旋转 syndrome 分布）降级为可选 |
| 系数 c 的码依赖（0.06/0.10/0.03）无闭式 | 不能作为判据 | 明确：c 只输出拟合值，标注为开放问题（§7.1），不进入 PASS/FAIL |
| 参考实现 geo_qec/ 的种子/细节不可考 | 复现偏差 | 独立重实现 + 锚点锁定；偏差 > 容差时以锚点为准并记录 |
