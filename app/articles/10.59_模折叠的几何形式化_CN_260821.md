# 10.59 模折叠的几何形式化：离散纤维化与混叠窗口定理

**编号**：10.59 | **日期**：260821 | **系列**：应用（后量子密码 → 理论机制） | **语言**：CN | **性质**：定理化与机制形式化

## 摘要

本文兑现 10.58 §8 开放问题 4 的承诺：将"模折叠"（q-周期化抹除谱方向信息）形式化为几何概念。主要结果：

1. **折叠映射的结构定理（真理层）**：模折叠 Φ_q 是商映射 π_q: ℝ^d → T^d_q = ℝ^d/qℤ^d 的规范截面——**离散纤维化**（基 = 平坦环面，纤维 = qℤ^d 陪集，等距群平移传递）。折叠边 Σ_q = {x_i = q/2 + qk} 是 d 族平行超平面；ℝ^d \ Σ_q 上 Φ_q 局部等距。
2. **混叠窗口定理（真理层）**：方向信息丢失的精确条件是**信号跨度超折叠半周期**（σ_i·‖s'‖ > q/2）；可恢复窗口 [2‖e'‖, q/(2‖s'‖)] 的上下界分别对应噪声分离与无混叠两个几何条件。
3. **数值锚定（中间层，10.57 §7 实验输入）**：ML-KEM 负循环块的窗口恒空是**几何必然**——σ_min = 1010 ∈ [q/4, q/3] = [832, 1110]，窗口上界 q/(2‖s'‖) = 3329/64 = 52.02（‖s'‖ = 32 精确：E[s²] = 2 的 5 值均匀分布，d = 512），超出 19.42 倍；混叠等价类 ≈ 2σR/q = 19.42（log₂ = 4.279 bits）；正确率退化为随机猜测（≈ 1/5，|S| = 5，实测 20.3%）。
4. **折叠成为可计算几何对象**：混叠分类 = 折叠边超平面族的几何位置；窗口空的可计算判据 = σ_min 对 q/(2‖s'‖) 的闭式比较；P4.2 的条件熵 H(s'|σs' mod q) 获得几何载体（混叠等价类上的熵分解）。

## §1 问题的几何化

### 1.1 10.58 开放问题 4 的坐标

10.58 §8 开放问题 4："模折叠能否形式化为几何概念？（q-周期化 = 离散纤维化？——若可，折叠就从'信息杀手'变为'可计算的几何对象'）"

背景（10.57 §7 的封闭机制）：CVP 谱 round-off 攻击在奇异基下把 MLWE 方程化为逐坐标独立形式 t'_i = σ_i·s'_i + e'_i (mod q)。恢复 s'_i 需要 σ_i 落在窗口 [2‖e'‖, q/(2‖s'‖)] 内；实测负循环块矩阵 σ_min ≈ 700–1300（不随维数缩小），窗口恒为空——所有方向被 q-周期化混叠。10.57 的结论：杀手不是噪声（无混叠信息论上限恢复率 100%），而是**模 q 周期化**——σ_i s'_i 被折叠进 [0, q)，连续谱方向的信息被抹掉。

本文的任务：给"折叠"一个几何词汇——不是比喻，而是可证明的定理。

### 1.2 设置：CVP round-off 的奇异基坐标

设 t = As + e mod q（MLWE，A ∈ ℤ_q^{d×d}，s、e 小系数）。SVD：A = UΣV^T（U、V 正交），t' = U^T t、s' = V^T s、e' = U^T e：

$$
t'_i = \sigma_i \cdot s'_i + e'_i \pmod{q}, \qquad i = 1, \ldots, d
$$

——逐坐标独立形式。σ_i 是第 i 个奇异方向上的"放大倍数"；s'_i 是信号在该方向的坐标（‖s'‖ = ‖s‖，酉不变）；e'_i 是噪声坐标。恢复任务：从 t'_i (mod q) 恢复 s'_i。

几何对象：映射 x ↦ x mod q（逐坐标折叠到基本域 [−q/2, q/2]^d）。这就是**模折叠**。

## §2 折叠映射的结构定理（真理层）

本节为纯几何命题：折叠映射的定义、商映射分解、奇异层结构、纤维结构。全部为初等几何/拓扑事实（A0 类——局部几何命题）。

**定义 10.59.2.01（模折叠映射）。** 对模数 q ∈ ℕ，模折叠映射

$$
\Phi_q: \mathbb{R}^d \to [-\tfrac{q}{2}, \tfrac{q}{2}]^d, \qquad \Phi_q(x)_i = x_i - q \cdot \mathrm{round}(x_i / q)
$$

逐坐标定义（round: ℝ → ℤ 取最近整数；半整数处的约定不影响结构结论——见定理 10.59.2.03 的注）。

**定理 10.59.2.02（商映射分解——离散纤维化）。** Φ_q 分解为 Φ_q = φ ∘ π_q，其中：

- π_q: ℝ^d → T^d_q := ℝ^d / (qℤ^d) 是商映射（qℤ^d 是 ℝ^d 的子格，T^d_q 是平坦环面）；
- φ: T^d_q → [−q/2, q/2]^d 是陪集的最小代表元截面（φ([x]) = x + qℤ^d 中范数最小的代表）。

π_q 是平坦环面纤维化：基空间 T^d_q 是紧致交换李群，纤维 qℤ^d 的陪集是离散可数集，等距群 = T^d_q 的平移群自身（传递作用）。

*证明*。π_q(x) = x + qℤ^d 是陪集。逐坐标取最小代表：每个陪集 x + qℤ^d 与基本域 [−q/2, q/2]^d 的交是单点 {x − q·round(x/q)}（round 给出最近整数，x_i − q·round(x_i/q) ∈ [−q/2, q/2]；唯一性由最近整数的唯一性保证，半整数两侧同值）。故 φ∘π_q = Φ_q。□

**定理 10.59.2.03（奇异层——折叠边）。** Φ_q 的不连续点集是 d 族平行超平面：

$$
\Sigma_q = \bigcup_{i=1}^{d} \bigcup_{k \in \mathbb{Z}} H_{i,k}, \qquad H_{i,k} = \{x \in \mathbb{R}^d : x_i = \tfrac{q}{2} + qk\}
$$

（第 i 族超平面法向量 e_i、间距 q）。在 ℝ^d \ Σ_q 上，Φ_q 是逐坐标线性映射：在每片开方块 ∏_i (qk_i − q/2, qk_i + q/2) 上 Φ_q(x) = x − qk，Jacobian = I_d——**局部等距**。

*证明*。round 在 x_i/q = k + 1/2 处跳变（左极限 k、右极限 k+1，函数值跳 ±q）——正是 H_{i,k}。其余点 round 局部常数，Φ_q(x) = x − qk 线性，J = I。□

> 注（半整数约定）。round(±1/2) 的取值只影响 H_{i,k} 上单点的像，不影响超平面结构、纤维结构或任何定量结论——约定任意。

**命题 10.59.2.04（纤维结构）。** 对 y ∈ (−q/2, q/2)^d（像的开核），

$$
\Phi_q^{-1}(y) = y + q\mathbb{Z}^d.
$$

纤维是可数离散集；相邻纤维成员相差 q·e_i，穿过折叠边 H_{i,k}。

*证明*。Φ_q(x) = y ⟺ 逐坐标 x_i − q·round(x_i/q) = y_i ⟺ x_i ≡ y_i (mod q) 且 x_i 落在 y_i 的最近整数邻域——即 x = y + qk（k ∈ ℤ^d）。□

> 注（三条定理的几何统一）。定理 10.59.2.02–10.59.2.04 给出模折叠的完整几何图像：**折叠 = 商映射 + 规范截面**；"折叠边"是商映射的奇异层；"纤维"是子格陪集。这回答了 10.58 开放问题 4 的前半：q-周期化就是离散纤维化，折叠边超平面族就是它的几何签名。

## §3 混叠窗口定理（真理层）

本节把"窗口恒空"（10.57 §7 的经验事实）提升为几何定理：混叠的精确条件是信号跨度超折叠半周期。

**定理 10.59.3.01（折叠的单射性判据——方向信息丢失的精确条件）。** 设 D = diag(σ_1, …, σ_d)（σ_i > 0，奇异值），信号 s' ∈ S^d，S ⊂ [−R, R]（R = sup_{s'∈S^d} ‖s'‖，信号范数的上界；连续或离散均适用）。映射 Φ_q ∘ D 在 S^d 上单射（从折叠像可无歧义恢复信号）的必要条件是

$$
\sigma_i \cdot R \le \tfrac{q}{2} \quad \text{对所有 } i = 1, \ldots, d.
$$

若存在 i 使 σ_i·R > q/2（信号跨度超折叠半周期），则 Φ_q ∘ D 在 S^d 上非单射——方向 i 上存在 s' ≠ s''（‖s'‖, ‖s''‖ ≤ R）使 Φ_q(D s') = Φ_q(D s'')——**方向信息在折叠下不可恢复**。

*证明*。（必要条件）设 σ_i·R > q/2。取 s' = R e_i、s'' = (R − q/σ_i) e_i。σ_i·R > q/2 ⟹ q/σ_i < 2R ⟹ |R − q/σ_i| < R，故 s'' 与 s' 同落在信号域内（连续情形 S = [−R, R]；离散情形取最近格点，折叠像差小于半周期的舍入——连续论证已足）。则 D s' − D s'' = q e_i ∈ qℤ^d——由定理 10.59.2.04 的纤维结构（折叠像相同 ⟺ 差 ∈ qℤ^d），Φ_q(D s') = Φ_q(D s'')。非单射。□

（充分性方向的边界：σ_i·R ≤ q/2 对所有 i 时，|σ_i s'_i| ≤ σ_i·R ≤ q/2——折叠前信号幅度不超半周期，Φ_q ∘ D 逐坐标单调保持 s'_i 的顺序——但单调不保证从折叠像恢复（仍需幅度标定与噪声分离）——故必要条件的形式是诚实的。窗口定理的完整条件由"无混叠 + 噪声分离"共同给出，见定理 10.59.3.02。）

**定理 10.59.3.02（窗口定理）。** 奇异基坐标 t'_i = σ_i·s'_i + e'_i (mod q) 中，坐标 i 的**可恢复窗口**为

$$
2\|e'\| < \sigma_i < \frac{q}{2\|s'\|}.
$$

- **下界（噪声分离）**：σ_i ≤ 2‖e'‖ 时噪声 e'_i 主导，信号 s'_i 不可分辨（折叠像被噪声淹没）；
- **上界（无混叠）**：σ_i ≥ q/(2‖s'‖) 时信号幅度超折叠半周期，方向信息在折叠下丢失（定理 10.59.3.01 的判据，取 R = ‖s'‖——逐坐标幅度 |s'_i| ≤ ‖s'‖₂ 的范数上界）。

窗口空 ⟺ 对所有 i，σ_i ∉ (2‖e'‖, q/(2‖s'‖))。

*证明*。上界：|σ_i s'_i| ≤ σ_i·|s'_i| ≤ σ_i·‖s'‖——σ_i ≥ q/(2‖s'‖) 时存在 s' 使 |σ_i s'_i| ≥ q/2（取 s'_i 满幅度），定理 10.59.3.01 的条件 σ_i·R > q/2（R = ‖s'‖）满足——非单射，方向信息丢失。下界：round-off 恢复 ŝ'_i = round(t'_i/σ_i) 的误差 |ŝ'_i − s'_i| ≥ |e'_i|/σ_i——σ_i ≤ 2‖e'‖ 时误差 ≥ 1/2 量级（噪声幅度不小于信号幅度的一半），s'_i 的离散取值不可分辨。□

**推论 10.59.3.03（混叠等价类与正确率退化）。** 连续模型（S = [−R, R]）：σ_i·R > q/2 时，坐标 i 的混叠等价类大小（折叠到同一像的信号跨度 ÷ 折叠周期）

$$
\#_{\mathrm{alias}}(i) = \frac{2\sigma_i R}{q}.
$$

离散模型（|S| 个信号值，等概率）：折叠像在基本域内近似均匀散布时，round-off 恢复正确率 ≈ 1/|S|（随机猜测）。

*证明*。跨度 2R 内可区分信号间隔 = 折叠周期 q/σ_i（定理 10.59.2.04：折叠像相同 ⟺ 差 ∈ (q/σ_i)ℤ）——等价类 = 2R/(q/σ_i) = 2σ_i R/q。离散：|S| 个像点落入混叠等价类的分布近似均匀（折叠映射在跨度 ≫ q/2 时的像散布）——恢复退化为均匀猜测，正确率 1/|S|。□

> 注（三条定理的地位）。定理 10.59.3.01–10.59.3.02 与推论 10.59.3.03 是纯几何/初等分析命题（分段线性映射、单射性、计数），不依赖任何物理数据——真理层候选，可提交主库验证（A0 类）。

## §4 数值锚定：ML-KEM 的窗口恒空（中间层）

本节为实验锚定：数据全部来自 10.57 §7（2026-08-21，numpy SVD，均匀 ±2 秘密/误差，q = 3329）；本节的贡献是**精确数值链的验证**与**窗口恒空的几何必然性论证**。

### 4.1 数值链

**实验输入（10.57 §7）**：负循环块矩阵（ML-KEM 结构），n = 16/64/256，k = 2，q = 3329；SVD 奇异值 σ_min = 728/836/1010；窗口方向数 = 0。

**验证（2026-08-21，calculate_math）**：

| 量 | 公式 | 数值 | 来源 |
|---|---|---|---|
| 信号范数 | ‖s'‖ = ‖s‖ = √(2d)，d = 2n = 512，E[s²] = 2（5 值均匀 {−2,−1,0,1,2}） | **32**（精确） | 酉不变性 + 5 值均匀（E[s²] = (4+1+0+1+4)/5 = 2） |
| 窗口上界 | q/(2‖s'‖) = 3329/64 | **52.02** | 与 10.57 "~52" 精确一致 |
| σ_min（n=256） | SVD 实测 | **1010** ∈ [q/4, q/3] = [832.25, 1109.67] | 10.57 §7 |
| 超出倍数 | σ_min ÷ 窗口上界 = 64640/3329 | **19.42** | 本文（calculate_math） |
| 混叠等价类 | 2σR/q，R = ‖s'‖ = 32 | **19.42**（与超出倍数同值） | 推论 10.59.3.03 |
| 混叠信息量 | log₂(2σR/q) | **4.279 bits** | 本文（calculate_math） |

**窗口恒空的几何必然性**：σ_min = 1010 ≫ 52.02 是数量级差距（19.4 倍）——不是"参数没调好"，而是定理 10.59.3.01 的条件 σ_i·R > q/2 在**所有坐标**上满足（σ_min 已超窗口上界 19.4 倍，σ_i ≥ σ_min 全部超出）——每个奇异方向上的信号幅度都超折叠半周期，方向信息在所有方向丢失。这与 10.57 的实测"窗口方向数 = 0"精确一致。

### 4.2 正确率退化为随机猜测

**实测（10.57 §7）**：含混叠 round-off 正确率 21.9/21.1/20.3%（≈ 1/5，随机猜测）；无混叠信息论上限 100%。

**几何解释（推论 10.59.3.03）**：s 的系数支撑 |S| = 5（{−2,−1,0,1,2}）——混叠条件下折叠像在基本域内近似均匀散布，round-off 的输出 ≈ 均匀猜测，正确率 ≈ 1/|S| = 1/5。连续混叠等价类 19.42 表明每个折叠像对应约 19 个连续候选——离散 5 值支撑下正确恢复概率由 5 值均匀猜测主导（20%）。

**对照实验的判定力**：无混叠信息论上限 100% 证明噪声（e'）可以克服（信息论上 s 唯一确定——0.9 命题 0.9.5.05）；含混叠 20.3% 证明折叠是唯一杀手。这为"折叠 = 信息杀手"提供了因果判定：**不是噪声，是折叠**。

## §5 离散纤维化：信息丢失的机制

### 5.1 基空间的平移齐性抹平方向

定理 10.59.2.02 给出折叠的纤维化结构：π_q: ℝ^d → T^d_q，基空间 T^d_q 是平坦环面——**紧致交换李群**。关键性质：T^d_q 的等距群是它自身的平移群（传递作用）——基空间上没有任何点、任何方向是特殊的。

**结构命题 10.59.5.01（信息丢失机制 = 平移齐性）。** 连续谱的"方向可读性"来自谱定理的正交分解（特征方向全局、基无关——0.9 命题 0.9.5.01）；商映射 π_q 把 ℝ^d 上的方向投影到模 q 等价类，而等价类（T^d_q 的点）在平移齐性下**完全不可区分**——所有方向在商空间上等价。**折叠抹除方向信息 = 商空间的平移齐性**。σ_i·R > q/2（定理 10.59.3.01）是"信号沿第 i 方向跨越折叠边"的定量条件——跨越折叠边即进入平移不可区分区。

### 5.2 与连续轨的精确对偶

| 连续轨（0.2–0.8） | 离散轨（0.9 + 本文） |
|:--|:--|
| 谱的基无关性自动（谱定理，0.9 命题 0.9.5.01） | 谱的基依赖（0.9 命题 0.9.2.02）——折叠是基依赖的几何来源之一 |
| 谱方向可读（特征向量全局正交分解） | 方向在折叠下混叠（商映射平移齐性，定理 10.59.2.02 + 结构命题 10.59.5.01） |
| 信息 = 谱，读 = 多项式（0.9 命题 0.9.5.02） | 信息唯一确定，读 = 指数（0.9 命题 0.9.5.07） |
| 观测者位置 σ*（输入，1.5 §3.7） | 模型族选择（输入，0.9 §3.3） |

**结构命题 10.59.5.02（折叠是"读取路径锁死"的机制层）。** 0.9 结构命题 0.9.5.07 断言离散轨中"信息在，读取路径锁死"；本文给出锁死的**机制**：不是信息缺失（0.9 命题 0.9.5.05：s 从 (A, t) 唯一确定，后验熵 0），而是读取路径必须穿过折叠映射 Φ_q——折叠在信号幅度超半周期的方向上把候选值混叠（定理 10.59.3.01），攻击者面对的是混叠等价类而非单个候选。**折叠 = 读取路径上的几何障碍物**。

### 5.3 折叠边作为结构指纹

定理 10.59.2.03 给出折叠边 Σ_q 的几何：d 族平行超平面，法向量 e_i（奇异方向），间距 q（模数）。混叠发生 ⟺ 信号沿某奇异方向的幅度跨越折叠边（|σ_i s'_i| > q/2 穿越 H_{i,k}）。**混叠的分类 = 折叠边的几何位置**：

- **结构格**（10.56 diag 型，Λ_H = M²——0.9 定理 0.9.4.11）：σ 跨度大（σ_1 = 1, σ_2 = M）——大 σ 方向信号跨越多条折叠边，小 σ 方向不跨越——混叠各向异性，部分方向信息保留（可定位可压缩）；
- **随机格**（ML-KEM）：σ_min 已超窗口上界 19.4 倍——所有方向跨越折叠边，混叠各向同性（全部不可用）。

这给出 10.58 G-3（偏离可检测）的机制层：Λ_H 分离（0.9 推论 0.9.4.13）对应折叠边跨越模式的分离——结构格与随机格的谱统计分离（10.58 §7.1 P3：100% 分类）的几何根源是折叠边跨越模式的各向异性 vs 各向同性。

## §6 折叠作为可计算几何对象

### 6.1 窗口空的可计算判据

定理 10.59.3.02 把"窗口恒空"化为**闭式比较**：

$$
\text{窗口空} \iff \sigma_{\min} \ge \frac{q}{2\|s'\|} \quad \text{或} \quad \sigma_{\max} \le 2\|e'\|.
$$

对 ML-KEM：σ_min = 1010 ≥ 52.02——一次性判定（比较两个数），无需搜索。10.58 §8 开放问题 4 的目标"折叠从信息杀手变为可计算对象"在此实现：**混叠不再是不可言说的"信息丢失"，而是可计算判据的几何事实**。

### 6.2 混叠等价类上的熵分解（P4.2 的几何载体）

10.58 §7.6 P4.2 的剩余工作：折叠机制的严格化（H(s'|σs' mod q) 仍未完成）。本文给出几何载体：条件熵分解到混叠等价类上——设折叠像 y = Φ_q(σ s')：

$$
H(s' \mid \sigma s' \bmod q) = H(s' \mid y) = \log_2 \#_{\mathrm{alias}} + H(s' \bmod q/\sigma)
$$

（混叠等价类大小 #_alias（推论 10.59.3.03）给出模信息的香农量；类内剩余熵来自噪声与离散格点分布）。数值：log₂(19.42) ≈ 4.279 bits（连续模型）——折叠后每坐标模信息保留约 4.28 bits；离散 5 值支撑时类内剩余由噪声主导，正确率退化 1/5（§4.2）。

## §7 开放问题

1. **σ_min ≈ q/3–q/4 的极值统计理论化**：10.57 实测 σ_min ∈ [q/4, q/3] 恒定（不随维数缩）。机制线索：σ_min(B)² = λ_min(BB^T) ≈ λ_min(AA^T) = min_j |â(ω_j)|²（负循环谱共轭成对——0.9 定理 0.9.4.02 的分块结构；q ≫ 1 时 λ_min(BB^T) 是 λ_min(AA^T) 的连续单调函数）——min |â| 的极值分布（Parseval 总量守恒下的近零特征值）决定 σ_min。严格化 = 负循环谱的近零特征值极值定理（中间层，随机矩阵浓度工具）。
2. **折叠与 G-1（两刚性统一）**：折叠边跨越模式在结构格/随机格上的分离（§5.3）是否就是 Tao–Vu 统计刚性的"离散端对偶"？——拓扑谱刚性（10.17 微扰稳定）在折叠语言下 = "折叠边位置微扰稳定"（σ_i 微小变化不改变跨越模式），统计刚性 = "折叠边跨越模式典型集中"（随机格族的跨越模式一致：全部各向同性）。这是 G-1 的候选几何形式。
3. **折叠的量子版本**：10.56 谱刚性带攻击对 diag 格给出 0.8%–6.9% 压缩；折叠语言下，结构格的各向异性混叠（§5.3）是否允许量子搜索（Grover）在未跨越折叠边的方向上压缩候选空间——量子折叠搜索的复杂度分析。
4. **半整数约定的唯一化**：round(±1/2) 的约定不影响结构结论（定理 10.59.2.03 注）——但"向偶取整"（银行家舍入）给出折叠边的规范归属（H_{i,k} 归属于一侧），是否对熵分解（§6.2）有可测影响？
