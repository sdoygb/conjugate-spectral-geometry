# 10.35 统一标度律：PG 与 AG 的同一引理链、类大小闭式与失败率-几何对应

**编号**：10.35 | **日期**：260807.1 | **系列**：应用（信息层→编码理论接口） | **语言**：CN

**摘要**：10.29（PG 完备，d=3，θ⁴）与 10.31–10.34（AG 完备，d=2^{r+1}，θ^d）两条验证链在此会师为一条引理链。指数统一（loss ~ θ^{2⌈d/2⌉}）已由 10.31 定理 10.31.1.05 建立；本文统一**系数**：主阶系数 = C(n,w₀)·P(w₀)·fail(w₀)·2^{−2w₀}，其中简并比例 P(w₀) 由平坦计数闭式给出（10.33），**失败率 fail(w₀) = 1 − ⟨1/v⟩ 由类大小 v 的几何闭式决定**：v(A) = 1 + [m−s choose r+1−s]₂（s = A 的仿射包维数，高斯二项）。推论：(i) r=1 权重 2 层类大小恒 2^{m−1}（10.34 实测 512），失败率 1 − 2^{1−m}——修正 10.32 定理 10.32.1.05 的系数 c_r = P_r/2（对 r=1 低估约 2 倍）；(ii) r=2 层类大小 v ∈ {2, 2^{m−2}}（主体 2、退化 2^{m−2}），失败率 1 − P(3)/2 − P(≤2)·2^{2−m}——10.31 实测 50.7% 与闭式精确吻合；(iii) r=3 类大小 v ∈ {2, 2^{m−3}}——解答 10.33 开放问题 1 的类大小部分。**d 奇偶定理**：d 奇（PG）⟹ 主阶层跨层简并（伙伴在 w₀−1 层）⟹ fail = 1；d 偶（AG）⟹ 同层简并 ⟹ fail = 1 − ⟨1/v⟩——10.29（d=3）与 10.31–10.34（d 偶）的失败率差异由 d 的奇偶性统一解释。统一标度律对全部已验证实例（[[7,1,3]]、[[15,7,3]]、[[32,12,4]]、[[64,20,8]]、[[256,70,16]]、[[512,252,16]]、[[1024,1002,4]]、[[1024,912,8]]、[[1024,672,16]]）逐点吻合。

## 一、引言：两条链的会师点

10.29 的 θ⁴：d=3 方向完备码（[[2^m−1, ·, 3]]，PG(m−1,2)）——权重 2 错误与权重 1 错误跨层同 syndrome（PG 列异或封闭：col_i ⊕ col_j = col_k 恒成立），恢复残留权重 3 共线逻辑，损失 θ⁴（log-log 斜率 3.99–4.14 实测）。

10.31–10.34 的 θ^d：AG 完备码（[[2^m, ·, 2^{r+1}]]，CSS(RM(r,m))）——权重 2^r 层简并从 (r+1)-平坦补集伙伴机制出现（10.32 定理 10.32.1.01），损失 θ^d。

两条链的指数在 10.31 定理 10.31.1.05 已统一（loss ~ θ^{2⌈d/2⌉}），但**系数分裂**：PG 用"跨层 100% 失败"，AG 用"同层 50%（10.31）/ P_r/2（10.32）/ 简并比例 × 失败率（10.33）"——而 10.34 发现 r=1 的失败率是 511/512 而非 50%。分裂的根源：**失败率不是普适常数，而是类大小的几何函数**。本文目标：一条引理链，从逻辑类出发，同时推出指数、简并比例、失败率、次主阶——PG 与 AG 共用同一条链。

## 二、统一框架

**定义 10.35.2.01**（几何完备 CSS 码）：CSS 码 [[n,k,d]]（校验矩阵 H，稳定子 S = rowspace(H)，逻辑类 L = S⊥）称为**几何完备**的，若 (i) L\S 的最小权重 = d；(ii) 权重 w ≥ d/2 的错误的伙伴结构（同 syndrome 代表）由 GF(2) 仿射/射影几何的平坦计数闭式决定。**PG 完备**（[[2^m−1, 2^m−1−2m, 3]]：S = Simplex 码，L = Hamming 码）与 **AG 完备**（[[2^m, 2^m−2s, 2^{r+1}]]，s = dim RM(r,m)：S = RM(r,m)，L = RM(m−r−1,m)）均为几何完备。

**记号**：w₀ = ⌈d/2⌉（主阶注入权重）；P(w) = 权重 w 层简并比例（存在伙伴的错误占比）；fail(w) = 权重 w 层解码失败率；v = 类大小（同 syndrome 代表数）；[m choose k]₂ = 高斯二项；flats(m,k) = 2^{m−k}·[m choose k]₂（k-平坦数）；E(k,s) = 固定 k-平坦内仿射包恰 k 维的 s 点子集数（容斥，10.33 记号）。分支级损失展开：loss(θ) = Σ_w C(n,w)·P(w)·fail(w)·(θ/2)^{2w}·(1−θ²/4)^{n−w}（独立相干旋转注入，每比特 θ_i ≤ θ_max）。

## 三、引理链

**引理 10.35.2.02**（逻辑类与最小距离）：对 CSS 码：(i) syndrome 零的错误集 = L = S⊥；(ii) 伙伴判据：e, e' 同 syndrome ⟺ e⊕e' ∈ L；(iii) 非平凡逻辑 = L\S，d = min wt(L\S)。
实例：PG——S = Simplex（最小权重 2^{m−1}），L = Hamming（最小权重 3，∉ Simplex）⟹ d = 3；AG——S = RM(r,m)（最小权重 2^{m−r}），L = RM(m−r−1,m)（最小权重 2^{r+1} = (r+1)-平坦指标，∉ RM(r,m)，因 r ≤ (m−1)/2）⟹ d = 2^{r+1}。
**证明**：CSS 定义与对偶码标准事实（S⊥ = L 直接；d 的实例逐一核验）。∎

**引理 10.35.2.03**（零简并）：权重 w < d/2 的错误 syndrome 唯一，最小权重解码完美恢复，损失贡献 0。
**证明**：e, e' 同 syndrome ⟹ e⊕e' ∈ L（引理 10.35.2.02(ii)），wt(e⊕e') ≤ 2w < d。L\S 最小权重 = d ⟹ e⊕e' ∈ S（PG：wt ≥ 2^{m−1} ≥ 3 > 2w；AG：2^{m−r} ≥ 2^{r+1} > 2w）⟹ e, e' 属同一稳定子类 ⟹ 解码恢复等价。∎（= 10.31 定理 10.31.1.01 的引理化重述）

**引理 10.35.2.04**（主阶机制）：设 w₀ = ⌈d/2⌉。(i) **简并对存在**：任取 v ∈ L\S（wt v = d），A ⊂ supp(v)（|A| = w₀），B = supp(v)\A——wt B = d − w₀ = w₀（d 偶）或 w₀−1（d 奇）——χ_A⊕χ_B = v ∈ L ⟹ A, B 同 syndrome。(ii) **失败率正性**：d 偶——伙伴 B 同层（wt = w₀），最小权重解码在 ≥ 2 个同层代表中选，选错概率 ≥ 1/2，残留 = A⊕B = v ∈ L\S 逻辑 ⟹ 失败；d 奇——伙伴在更低层（wt = w₀−1），最小权重解码必选更低代表 B′，残留 = A⊕B′ ∈ L\S（wt ≥ d 且非零）⟹ 失败率 = 1。(iii) **主阶**：权重 w < w₀ 项 = 0（引理 10.35.2.03），w₀ 项 fail(w₀) > 0 ⟹ loss = c·θ^{2w₀} + o(θ^{2w₀})，c = C(n,w₀)·P(w₀)·fail(w₀)·2^{−2w₀}。∎

**引理 10.35.2.05**（包含性等价）：AG 完备码中，权重 2^r 错误 A 存在同层伙伴 ⟺ A 包含于某 (r+1)-平坦 P，此时伙伴与"包含 A 的 (r+1)-平坦"一一对应：B = P\A。
**证明**：10.32 定理 10.32.1.01。∎

**引理 10.35.2.06**（类大小闭式）：AG 完备码权重 2^r 层，设 s = aff(A)（A 的仿射包维数，s ≤ r+1）。包含 A 的 (r+1)-平坦 P = aff(A) ⊕ U，U 为商空间 F2^m/span(aff(A)) 中的 (r+1−s) 维线性子空间——计数 = [m−s choose r+1−s]₂——类大小

**v(A) = 1 + [m−s choose r+1−s]₂**

与 A 的具体位置无关，仅由仿射包维数 s 决定。
实例：r=1：s = 1 恒成立（F2 中任意 2 点仿射包 1 维）⟹ v = 1 + [m−1 choose 1]₂ = 2^{m−1}（m=10: 512，10.34 程序分布 {512: 5000} 全一致；m=5: 16，10.32 的 465 对 = 31 类 × 15 伙伴）；r=2：s = 3（主体）⟹ v = 2；s = 2（退化，A 恰为整个 2-平坦）⟹ v = 2^{m−2}；r=3：s = 4 ⟹ v = 2；s = 3 ⟹ v = 2^{m−3}。
**解答 10.33 开放问题 1 的类大小部分**：类大小由仿射包维数唯一决定——"v 全部为 2"仅在主体（s = r+1）成立；退化平坦共享使少数类呈幂次大小。
**证明**：引理 10.35.2.05 的伙伴一一对应 + 商空间线性子空间计数（固定 s-平坦的 (r+1)-平坦扩展 = 商空间中的格拉斯曼数）。∎

**引理 10.35.2.07**（失败率-几何对应）：AG 完备码主阶层 w₀ = 2^r（d 偶）：

**fail(w₀) = 1 − Σ_{s ≤ r+1} P(s)·1/v(s)**

其中 P(s) = flats(m,s)·E(s,2^r)/C(n,2^r)（权重 2^r 子集仿射包恰 s 维的比例，10.33 记号），v(s) = 1 + [m−s choose r+1−s]₂。
**证明**：同 syndrome 的权重 2^r 代表构成类（引理 10.35.2.05、06）；最小权重解码在类内均匀选代表，选回 A 的概率 1/v；选到 B ≠ A 时残留 = A⊕B = χ_P ∈ L\S（权重 d 逻辑）⟹ 失败。∎
实例：r=1：fail = 1 − 2^{1−m}（m=10: 511/512 = 0.998047 ✓ 10.34）；r=2：fail = 1 − P(3)/2 − Σ_{s≤2}P(s)·2^{2−m}——m=6: P(3) = 1 − flats(6,2)/C(64,4) = 1 − 0.01639 = 0.98361，P(≤2) = 0.01639 ⟹ fail = 1 − 0.49181 − 0.00102 = 0.5072（10.31 程序全量统计 50.7% ✓）；m=10: P(≤2) = 44,608,256/45,545,029,376 = 9.79e−4 ⟹ fail = 0.50049 + 0.00098·2^{−8} ≈ 0.5005（10.34 ✓）；r=3：主体 fail ≈ 1/2，修正项 P(s=3)·2^{3−m}（m=10: 1.5e−6·2^{−7} ≈ 1.2e−8，可忽略）。

**引理 10.35.2.08**（跨层失败率与方向类）：d 奇（PG）主阶层 w₀ = 2：fail = 1（引理 10.35.2.04(ii) 跨层部分）。结构：X 型权重 2 错误 {a,b} 的 syndrome = 列 a⊕列 b = 列 c（PG(m−1,2) 列异或封闭）——syndrome 恰为**方向**——类 = {单比特 c} ∪ {过 c 的线上除 c 外的边对}——类总大小 = 2^{m−1}（m=4: 1 + 7 = 8），其中权重 1 代表 1 个、权重 2 代表 2^{m−1}−2 个——与 AG r=1 的平行边类（2^{m−1} 个同层代表）同构，组成由 d 奇偶决定。
全 Pauli 型注入的失败率：纯型（XX/ZZ/YY，各 C(n,2) 个）fail = 1；混合型（XZ/ZX 等 6 型）syndrome = (列 b, 列 a) 唯一（列互异）——零简并、完美恢复、贡献 0——故全 Pauli 失败率 = 3/9 = **1/3**——10.29 的 315/945 = 1/3 即此（[[15,7,3]]：XX、ZZ、YY 各 105 个 = C(15,2)，共 315）。
**证明**：直接列运算（PG 列互异 + 异或封闭）。∎

**引理 10.35.2.09**（次主阶）：AG 完备码权重 w₀+1 = 2^r+1 层：伙伴在 w₀−1 = 2^r−1 层（跨层，10.33 定理 10.33.1.02：A′⊔B = P 为 (r+1)-平坦）⟹ fail = 1——简并比例 P′(w₀+1) = flats(m,r+1)·C(2^{r+1}, 2^r+1)/C(n, 2^r+1)——θ^{2w₀+2} 系数 = C(n,w₀+1)·P′(w₀+1)·2^{−2(w₀+1)}。实例：r=1：P′ = 1（任意 3 点 ⊂ 2-平坦，补点 = 平行四边形第 4 点，10.34 实测 1.000000）；r=2, m=10：P′ = 4.8976e−3（10.34 实测 0.004887，0.2% 差）。PG 的次主阶（θ⁶ 系数）留作开放问题（10.29 §7 系数问题）。
**证明**：10.33 定理 10.33.1.02、10.33.1.03 + 引理 10.35.2.04(ii) 跨层失败率。∎
