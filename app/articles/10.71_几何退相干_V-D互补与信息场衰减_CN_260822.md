# 10.71 几何退相干：V-D 互补恒等式与信息场衰减

**编号**：10.71 | **日期**：260822 | **系列**：应用（量子测量 → 退相干动力学） | **语言**：CN | **性质**：定理化

## 摘要

本文攻取离散随机家族覆盖审核的第 5 项缺口（量子退相干机制），给出两个结果：

1. **静态互补恒等式（纯代数，A0 类，可提交主库）**：对双通道投影强度 σ₁、σ₂（#257 归一化 σ₁+σ₂=1），干涉可见度 V = 2√(σ₁σ₂)/(σ₁+σ₂)（10.61 推论 10.61.3.03）与路径不平衡度 D = |σ₁−σ₂|/(σ₁+σ₂) 满足

$$V^2 + D^2 = 1.$$

这是量子信息中 Englert 对偶关系（D²+V² ≤ 1）在纯态双缝几何中的精确等号形式——干涉清晰度与路径可分辨度是单位圆上的两个互补坐标。注意 V 与 D 由同一对投影强度 (σ₁,σ₂) 定义，V²+D²=1 是归一化 σ₁+σ₂=1 的代数恒等式（形式对应，非两个独立结构的偶然相遇）。

2. **退相干动力学（中间层构造）**：环境印记重叠按信息场衰减率衰减（5.1 定理 5.1.2.01，Γ_geo = μ₁/N_info = 0.02308625），⟹ 可见度指数衰减

$$V(t) = V_0 e^{-\Gamma_{\text{geo}} t}, \qquad \tau_{\text{dec}} = 1/\Gamma_{\text{geo}} = 43.32 \ \text{编码步}, \qquad t_{1/2} = 30.02.$$

5.1 §2 早已列出的"信息场衰减 vs 量子退相干"类比表（e^{−Γ_geo t} vs e^{−t/T₂}）在此获得定量定理形式（衰减率 Γ_geo 为构造锚定，见 §5）。

**关键依赖**：5.1 定理 5.1.2.01（信息场衰减定理）、10.61 推论 10.61.3.03（对比度公式）、10.61 命题 10.61.2.02（等权重归一化）；#257（扇区权重归一化）、#259（Born 法则代数形式 Δλᵢ = K√σᵢ）；10.70 定理 10.70.3.01（几何 Zeno 冻结，关联对比）。

## §2 静态互补恒等式（真理层/纯代数）

### 2.1 路径不平衡度

**定义 10.71.2.01（路径不平衡度）。** 设双通道投影强度 σ₁、σ₂（σ₁+σ₂ = 1，#257），定义

$$D = \frac{|\sigma_1 - \sigma_2|}{\sigma_1 + \sigma_2} = |\sigma_1 - \sigma_2|.$$

D 是 which-way 可分辨度的自然度量：σ₁ = σ₂ 时 D = 0（路径完全对称，不可分辨）；σ₂ → 0 时 D → 1（单路径极限，完全可分辨）。

**命题 10.71.2.02（D 与 Fisher 信息的联系）。** D² = 1 − 4σ₁σ₂ = (σ₁+σ₂)² − 4σ₁σ₂，恰为二项分布 σ₁、σ₂ 的方差归一化（σ₁σ₂ = Var）的四倍补。D² = 1 − 4σ₁σ₂ 与量子 Fisher 信息 F_Q = 4/σ₁ + 4/σ₂ 的关系留作开放问题（§6 O1）。

*证明*。直接展开：(σ₁+σ₂)² − 4σ₁σ₂ = σ₁² − 2σ₁σ₂ + σ₂² = (σ₁−σ₂)² = D²(σ₁+σ₂)² = D²（#257 归一化）。∎

### 2.2 互补恒等式

**定理 10.71.2.01（V-D 互补恒等式）。** 对任意双通道投影强度 σ₁、σ₂（σ₁+σ₂ = 1），干涉可见度 V（10.61 推论 10.61.3.03）与路径不平衡度 D（定义 10.71.2.01）满足

$$V^2 + D^2 = 1.$$

*证明*。V = 2√(σ₁σ₂)/(σ₁+σ₂)，D = |σ₁−σ₂|/(σ₁+σ₂)（#257 归一化下分母为 1）。计算：

$$V^2 + D^2 = \frac{4\sigma_1\sigma_2}{(\sigma_1+\sigma_2)^2} + \frac{(\sigma_1-\sigma_2)^2}{(\sigma_1+\sigma_2)^2} = \frac{4\sigma_1\sigma_2 + \sigma_1^2 - 2\sigma_1\sigma_2 + \sigma_2^2}{(\sigma_1+\sigma_2)^2} = \frac{(\sigma_1+\sigma_2)^2}{(\sigma_1+\sigma_2)^2} = 1.$$

（symbolic 验证：simplify((2√(ab)/(a+b))² + ((a−b)/(a+b))²) = 1，calculate_math 精确结果。）∎

**推论 10.71.2.02（Englert 对偶的几何等号形式）。** D² + V² = 1 即 Englert 对偶关系 D² + V² ≤ 1 对纯态双缝取等号。两个极端：
- V = 1 ⟺ D = 0：完全对称（σ₁ = σ₂ = 1/2，命题 10.61.2.02 等权重），干涉完全清晰，路径不可分辨；
- V = 0 ⟺ D = 1：单路径极限（σ₂ = 0），干涉消失，路径完全可分辨。

*证明*。直接代入定理 10.71.2.01。∎

> **注（互补性的几何读数）**。V 与 D 是单位圆上的两个坐标：(V, D) = (cos φ, sin φ)，φ = 2 arctan√(σ_min/σ_max) 类结构角。干涉清晰度与路径可分辨度是同一纯态的两个互补投影——不是竞争（此消彼长），是互补（√(1−V²) = D 精确给出对方）。这是 10.61 注 2"干涉 = 两通道共存于同一截面的测度后果"的定量延伸。V 与 D 同为 σ₁、σ₂ 的函数，恒等式源于归一化，属形式对应（10.74 第3章分类），不构成独立发现。

## §3 退相干动力学（中间层构造）

### 3.1 环境印记重叠

**构造 10.71.3.01（环境印记与相干因子）。** 设双缝通道 L₁、L₂ 与信息场（环境）耦合：|Ψ⟩ = c₁|L₁⟩|E₁⟩ + c₂|L₂⟩|E₂⟩，其中 E₁、E₂ 是通道的环境印记（信息场自由度上的印记态）。约化到系统后干涉项携带相干因子

$$\gamma(t) = \langle E_1(t) | E_2(t) \rangle,$$

|γ| ≤ 1，γ(0) = 1（初始印记未分离，不可分辨）。

**锚定声明（中间层）**：印记重叠的衰减率取信息场特征衰减率（5.1 定理 5.1.2.01）：

$$\gamma(t) = e^{-\Gamma_{\text{geo}} t}, \qquad \Gamma_{\text{geo}} = \frac{\mu_1}{N_{\text{info}}} = \frac{0.36938}{16} = 0.02308625.$$

机制：信息场在图 G_ℐ 上扩散（∂_tρ = −L_ℐρ，5.1 §2.1），最慢模式 μ₁ 主导长时间行为——通道印记在信息网络上弥散，两印记的重叠度按扩散核衰减。"稀释而不可恢复"（5.1 §2.1 原话）精确对应退相干的不可逆性：相干信息流入环境后不可恢复。

### 3.2 退相干定理

**定理 10.71.3.01（几何退相干定理）。** 在构造 10.71.3.01 下，双缝干涉的可见度与路径不平衡度按

$$V(t) = V_0\, e^{-\Gamma_{\text{geo}} t}, \qquad D(t) = \sqrt{1 - V_0^2 e^{-2\Gamma_{\text{geo}} t}}$$

演化，其中 V₀ = 2√(σ₁σ₂)/(σ₁+σ₂) 为初始可见度（10.61 推论 10.61.3.03）。退相干时间与半衰期：

$$\tau_{\text{dec}} = \frac{1}{\Gamma_{\text{geo}}} = 43.32 \ \text{编码步}, \qquad t_{1/2} = \frac{\ln 2}{\Gamma_{\text{geo}}} = 30.02.$$

*证明*。三步：

(i) **干涉项携带相干因子**：|Ψ⟩ = c₁|L₁⟩|E₁⟩ + c₂|L₂⟩|E₂⟩ 约化到系统（对 E 取迹），干涉项 2√(σ₁σ₂)cosΔφ → 2√(σ₁σ₂)·γ(t)·cosΔφ（标准部分迹论证）。

(ii) **可见度**：I_max = σ₁+σ₂+2√(σ₁σ₂)γ(t)，I_min = σ₁+σ₂−2√(σ₁σ₂)γ(t)，代入 V = (I_max−I_min)/(I_max+I_min)：

$$V(t) = \frac{4\sqrt{\sigma_1\sigma_2}\,\gamma(t)}{2(\sigma_1+\sigma_2)} = \frac{2\sqrt{\sigma_1\sigma_2}}{\sigma_1+\sigma_2}\cdot\gamma(t) = V_0\,e^{-\Gamma_{\text{geo}} t}.$$

(iii) **不平衡度**：由互补恒等式（定理 10.71.2.01）V(t)² + D(t)² = 1，D(t) = √(1−V(t)²) = √(1−V₀²e^{−2Γ_geo t})。∎

### 3.3 数值锚定

**结构命题 10.71.3.02（V-D 衰减联动）。** 等幅双缝（V₀ = 1，命题 10.61.2.02）下：

| 时刻 | V(t) | D(t) | 意义 |
|:---|:---|:---|:---|
| t = 0 | 1 | 0 | 完全清晰，路径不可分辨 |
| t = t₁/₂ = 30.02 | 1/2 | **√3/2** | 半衰：V 半衰，D 精确 = sin 60° |
| t = τ_dec = 43.32 | e^{−1} ≈ 0.3679 | 0.9299 | 退相干时间：V 衰减到 1/e |
| t → ∞ | 0 | 1 | 完全退相干：单路径统计 |

D(t₁/₂) = √3/2 是**精确值**（V(t₁/₂) = 1/2 ⟹ D² = 1−1/4 = 3/4，calculate_math 验证）。√3/2 = sin 60° 的出现是否反映框架的结构角（θ 参数的 60° 类角色）留作开放问题（§6 O2）。

**与 10.70 Zeno 的互补（推论）。** 同一干涉系统有两个独立的时间尺度：

| 通道 | 速率 | 几何来源 | 时间尺度 |
|:---|:---|:---|:---|
| 环境退相干（本文） | Γ_geo = μ₁/N_info = 0.023086 | 信息网络代数连通度（5.1） | τ_dec = 43.3 |
| 测量冻结（10.70） | 冻结条件 δτ ≪ 2ħ_geom = 1/λ₁^eff ≈ 0.002557 | 谱间隙（3.12 §4.3） | 测量间隔 δτ |

环境退相干是**慢**过程（编码步尺度），测量冻结是**快**约束（步内尺度）——退相干"偷走"干涉，测量"锁定"通道。两者来源不同（信息网络 vs 谱间隙），不互锁。

## §4 物理意义

1. **5.1 类比表的定量升级**。5.1 §2 的"信息场衰减 vs 量子退相干"表格（e^{−Γ_geo t} vs e^{−t/T₂}）在此获得定理形式：信息场衰减率**就是**退相干率。"遗忘"与"退相干"是同一几何机制的两种语言——信息不可恢复地稀释为均匀，对应相干不可恢复地流入环境。

2. **波粒二象性的几何读数**。V² + D² = 1：干涉清晰度 V（波动性）与路径可分辨度 D（粒子性）是单位圆上的两个坐标。量子信息中 Englert 对偶 D²+V² ≤ 1 的上界在此精确取等——不是新的不确定关系，而是**同一纯态的两个互补投影**的恒等式。10.61 注 2（干涉 = 两通道共存于同一截面的测度后果）由此闭合：共存度 V 与分辨度 D 由投影强度 σ₁、σ₂ 完全决定。

3. **退相干是通道印记的扩散**。γ(t) = e^{−Γ_geo t} 的几何图像：通道印记在信息网络上弥散（图 Laplacian 最慢模式），两印记重叠度指数衰减。10.61 O4（谷点 = 信息零点）在此获得动力学版本：退相干极限 V→0 是**全空间**的"信息零点"——不再只是谷点处两通道相消，而是所有点的干涉项消失。

## §5 诚实边界

1. **γ(t) = e^{−Γ_geo t} 是构造锚定，非纯定理**。5.1 的衰减对象是信息场密度 ρ_ℐ，本文把它解释为通道印记的重叠度衰减——机制方向（扩散抹匀 → 印记弥散 → 重叠下降）合理，但"速率恰好 = Γ_geo"是中间层假设，不是从公理推导。这是本文最脆弱的一环。
2. **Englert 对偶的完整形式（D²+V² ≤ 1，混合态取不等号）未几何化**。本文给出纯态等号形式；混合态的几何来源（哪里的信息使等式变不等式）未探。
3. **单一环境模式假设**。多模式环境 → 相干因子为多指数和 γ(t) = Σcₖe^{−μₖt}（5.1 特征基展开），本文只取最慢模式 μ₁。
4. **编码步 → 物理时间映射未闭合**（与 10.68、10.70 相同：呼吸周期锚定在 4.3.1.01，中间层）。
5. **§2 纯代数（可提交主库 A0 类）；§3 中间层（构造 + 锚定）**。

## §6 开放问题

**O1（D² 与量子 Fisher 信息）**。D² = 1 − 4σ₁σ₂（命题 10.71.2.02）。量子 Fisher 信息 F_Q = 4/σ₁ + 4/σ₂（0.11 语境）与 D 的关系：是否 F_Q ≥ 4/D² 类的不等式成立？D 是否是 Fisher 信息的归一化版本？

**O2（D(t₁/₂) = √3/2 的结构角）**。半衰期处 D 精确 = sin 60°。60° = π/3 是框架的 θ 参数候选结构角。巧合还是结构？

**O3（μ₁·λ₁^eff = 144.45）**。信息网络代数连通度 μ₁ = 0.36938 与谱间隙 λ₁^eff = 391.05 之积 = 144.45，接近 144 = 12²（偏差 0.3%）。两个独立几何量的乘积接近整数平方——是否闭合？目前不闭合（0.3% 超误差），保持开放。

**O4（混合态的不等式来源）**。Englert 对偶在混合态取严格不等号（D²+V² < 1）：几何论中什么机制（环境部分纠缠？10.61 非理想缝？）产生"等号损失"？
