# 几何中子寿命之谜：信息扇区泄漏与暗衰变道

> **文章编号**：10.73
> **日期**：2026-08-22
> **依赖**：3.9（中子衰变）、1.5（代数作用量 S(σ)）、2.3（观测者位置）、10.68（几何隧穿）
> **核心结果**：信息扇区权重 σ_I* = 0.011484（1.5 §3.7）作为暗衰变分支比预言，与中子寿命之谜的实测暗衰变分支比 1.1543% 偏差仅 0.51%；几何预言束流寿命 888.605 s 与 NIST 2013 实测 888.0 ± 2.0 s 偏差 0.07%。

---

## 摘　要

中子寿命之谜——瓶装法（877.75 ± 0.28 s，UCNτ 2021）与束流法（888.0 ± 2.0 s，NIST 2013）相差 10.25 s（约 5σ）——是当前粒子物理最著名的实验反常之一。本文给出共扼谱几何对该反常的一个判别性检验框架：信息扇区权重 σ_I* = 0.011484 恰可作为暗衰变道 n → χ + γ 的分支比预言，由此导出束流法寿命预言 888.605 s（偏差 0.07%）、束流-瓶装差预言 10.205 s（偏差 0.4%）、暗衰变分支比预言 1.1484%（偏差 0.51%）。该框架的可证伪性清晰：若未来束流实验将差异压至 0.3% 以下则理论失效；若差异稳定在 1.08 ± 0.2%，则 σ_I* 预言可接受检验。

---

## 第1章　中子寿命之谜

### 1.1　实验现状

| 方法 | 数值 | 实验 | 测量量 |
|:---:|:---:|:---|:---|
| 瓶装法（UCNτ 2021） | 877.75 ± 0.28 s | 超冷中子存储 | 总消失率 |
| 束流法（NIST 2013） | 888.0 ± 2.0 s | 束流 β 衰变产物计数 | β 衰变率 |
| PDG 2024 世界平均 | 878.4 ± 0.5 s | — | — |

束流法测 β 衰变率（数衰变产物），瓶装法测总衰变率（数存活中子）。若中子只有 β 衰变一个衰变道，两者应相等。实测差异：

$$\Delta\tau_{\text{meas}} = 888.0 - 877.75 = 10.25\ \text{s},$$

组合误差 $\sqrt{2.0^2 + 0.28^2} = 2.0195$ s，显著度：

$$\frac{\Delta\tau_{\text{meas}}}{\sigma_{\text{comb}}} = \frac{10.25}{2.0195} = 5.0755\ (5.08\sigma).$$

### 1.2　暗衰变解释

若存在非 β 衰变道（如 n → χ + γ，χ 为暗粒子），则瓶装法总率 > 束流法 β 率。实测暗衰变分支比：

$$\text{BR}_{\text{meas}} = 1 - \frac{877.75}{888.0} = \frac{41}{3552} = 0.0115428 = 1.1543\%.$$

这是"中子寿命之谜"的标准暗衰变解读（如 Koch 2024, PRD 110, 073004 的暗衰变解谜提示）。几何论的任务：能否独立预言这个分支比？

## 第2章　几何输入与暗衰变假设

### 2.1　几何输入（基于原文核实）

**τ_geom = 878.4 s**：3.9 §5.3 的中子寿命几何计算值，恰等于 PDG 2024 世界平均（3.9 已修正实验数据标注，见 git 44a795d9）。该计算依赖外部输入 G_F、f(Q)，几何独立输出为 |V_ud|、λ、δ_RC（3.9 §6.3 诚实标注）。

**σ_I* = 0.011484**：1.5 §3.7"作用量的景观结构"中观测者位置零阶近似 σ* ≈ (0.777912, 0.210603, 0.011484)，满足 S(σ*) ≈ 137.036。更精确的观测者位置 σ*_ours = (0.777428, 0.211091, 0.011481) 由 2.3 §5.6 给出（S = 137.036 不变）。σ_I* 是信息扇区（Interaction）的编码权重——第三个扇区，对应框架中"最弱"的观测者位置分量（0.011484 ≈ 1.15%）。

### 2.2　暗衰变假设（中间层锚定）

> **假设 H1（信息扇区泄漏）**：信息扇区权重 σ_I* 对应一个非 β 衰变道——中子经信息扇区耦合衰变 n → χ + γ，其中 χ 是信息扇区的"鬼场"（无电磁、无强、无弱标准相互作用）。暗衰变分支比等于信息扇区权重：BR_dark = σ_I*。

该假设是**中间层的机制映射**，不是从公理推导——框架给出"信息扇区是最弱耦合分量"（1.5 §3.7 层级结构 r_M : r_C : r_I ≈ 0.882 : 0.459 : 0.105），但"泄漏 = 暗衰变"的对应是构造性假设，其正当性完全由下面的预言-实测对照判定。

## 第3章　预言与实测对照

### 3.1　预言公式

设 β 衰变道寿命为 τ_β，信息扇区泄漏道寿命为 τ_dark，总寿命（瓶装法测得的消失率）：

$$\tau_{\text{bottle}} = \tau_{\text{geom}} = 878.4\ \text{s}, \quad \frac{1}{\tau_{\text{geom}}} = \frac{1}{\tau_\beta} + \frac{1}{\tau_{\text{dark}}}, \quad \frac{1/\tau_{\text{dark}}}{1/\tau_{\text{geom}}} = \sigma_I^*.$$

由此：

$$\tau_\beta = \frac{\tau_{\text{geom}}}{1 - \sigma_I^*} = \frac{878.4}{1 - 0.011484} = 888.605\ \text{s},$$

$$\Delta\tau_{\text{pred}} = \tau_\beta - \tau_{\text{geom}} = \frac{\tau_{\text{geom}}\,\sigma_I^*}{1 - \sigma_I^*} = \frac{0.011484 \times 878.4}{0.988516} = 10.205\ \text{s}.$$

### 3.2　对照表（全部数值工具验证）

| 量 | 几何预言 | 实测 | 偏差 | 显著度 |
|:---|:---:|:---:|:---:|:---:|
| 束流法寿命 τ_β | **888.605 s** | 888.0 ± 2.0 s（NIST 2013） | **+0.60 s（0.07%）** | 0.30σ |
| 束流−瓶装差 Δτ | **10.205 s** | 10.25 s | **0.045 s（0.4%）** | — |
| 暗衰变分支比 BR | **1.1484%** | 41/3552 = 1.1543% | **0.0059 pp（0.51%）** | — |
| 瓶装法寿命 τ_bottle | 878.4 s | 877.75 ± 0.28 s（UCNτ 2021） | 0.65 s | 2.32σ |

### 3.3　结果评估

1. **束流寿命预言 888.605 s 与实测 888.0 ± 2.0 s 偏差 +0.60 s（0.07%），远在误差内**——这是最强的单项符合：几何预言恰好落在束流法测量区间中心偏上 0.3σ。
2. **暗衰变分支比预言 1.1484% 与实测 1.1543% 偏差 0.51%**（比值 BR_pred/BR_meas = 0.99491）。按 9.7 方法论（SPARC 检验），0.5% 偏差属于"支持区间"——但注意：束流法误差本身是 2.0 s（0.23%），分支比预言与实测的偏差（0.51%）超出束流法误差的两倍，因此**该符合是"强的数值巧合候选"，尚不构成独立判别**——除非 σ_I* 的机制（为何恰好是 1.15% 而非其他数）能从框架独立推出。
3. **几何值 878.4 = PDG 世界平均的巧合**：3.9 独立计算出 878.4 s，而 PDG 平均恰为 878.4 ± 0.5 s。修正 3.9 的数据标注后，这个"巧合"有了新含义——几何值锚定瓶装侧（总消失率），与束流侧的张力 9.6 s = 4.80σ（(888.0−878.4)/2.0 = 4.80）成为判别性检验的起点。

## 第4章　判别性预言

### 4.1　单色 γ 线

若暗衰变道为 n → χ + γ 两体衰变，γ 是**单色**的：

$$E_\gamma = \frac{m_n^2 - m_\chi^2}{2m_n}.$$

若 χ 质量远小于中子（信息扇区鬼场候选），则 E_γ ≈ m_n/2 ≈ 469.8 MeV。这与 Koch 2024（PRD 110, 073004）的暗衰变解谜方案对照：该方案同样预言 n → χ + γ 单色线，且分支比 ~1%。**判别点**：若未来实验（如 J-PARC 精密中子束、Belle II 类单色 γ 搜索）在 469.8 MeV 附近找到分支比 ~1.15% 的单色 γ 峰，则框架预言被直接证实；若无，则 H1 假设失效，但 τ_β_pred = 888.605 s 与束流法的 0.07% 符合仍可作为"数值巧合"保留。

### 4.2　CKM 幺正性关联（开放问题）

若 n → χ + γ 拿走 1.15% 的衰变率，则核 β 衰变提取的 |V_ud| 应含相应修正。3.9 §4.2 的几何输出 |V_ud| = 0.9741 与超允许核 β 衰变全球拟合的 0.97435 偏差 −0.026%（已在 3.9 §6.1 标注）；而 CKM 第一行幺正性亏缺 0.15%（约 2.2σ，来自 |V_ud| 与 |V_us| 的更新值）是粒子物理的独立已知张力。**开放问题 O1**：信息扇区泄漏是否同时解释 CKM 幺正性亏缺？量级上 σ_I* = 1.15% 与 0.15% 差一个数量级，两者是否同源未闭合。

## 第5章　与框架内其他泄漏的对照

### 5.1　隧穿 vs 暗衰变的量级问题

8.9 §4.1（黑洞辐射）与 10.68（几何隧穿）给出单像素隧穿概率 exp(−128π²) ≈ 10⁻⁵⁴⁹——严格为零。而这里信息扇区泄漏分支比 σ_I* = 1.15%——可观测量级。**同一信息扇区为何在黑洞语境泄漏为零、在中子衰变语境泄漏 1.15%？**

候选答案（开放）：黑洞单像素隧穿是"跨越 Dirac 谱禁闭势垒"（λ₂^eff = 59324.3 rad⁻²，10.68），势垒高度由谱间隙决定；而中子暗衰变是"信息扇区耦合常数 σ_I*"的直接作用，无势垒跨越。两者是信息扇区的两种不同耦合方式（耦合常数 vs 隧穿振幅），非同一机制。**该区分目前是定性的，定量机制未闭合（开放问题 O2）**。

### 5.2　σ_I* 的三处出场

| 位置 | σ_I* 的角色 | 数值 |
|:---|:---|:---:|
| 1.5 §3.7 | 观测者位置第三分量 | 0.011484 |
| 10.63 §8 | 轻子谱刚性分解 | 0.011481（精确版） |
| 本文 | 暗衰变分支比预言 | 0.011484 |

同一信息扇区权重在观测者位置、轻子谱、中子暗衰变三处独立出场——这是框架内"σ* 是合法参数化而非循环"（2026-08-09 核心立场决定）的又一例证。

## 第6章　结论与开放问题

### 6.1　结论

1. **3.9 数据错误已修正**：瓶装法/束流法数值归属还原（UCNτ 2021 = 877.75 瓶装、NIST 2013 = 888.0 束流），"~1% tension"修正为"~5σ 中子寿命之谜"。
2. **判别性预言已建立**：σ_I* = 1.1484% ↔ 实测 1.1543%（偏差 0.51%）；τ_β_pred = 888.605 s ↔ 实测 888.0 ± 2.0 s（偏差 0.07%）。
3. **可证伪性清晰**：束流-瓶装差异被压至 <0.3% 则理论失效；稳定在 1.08 ± 0.2% 则 σ_I* 预言经受检验。

### 6.2　开放问题

| # | 优先级 | 问题 | 状态 |
|:--:|:--:|:---|:---|
| O1 | P0 | 信息扇区泄漏是否同时解释 CKM 幺正性亏缺（0.15%，2.2σ）？ | σ_I* 大一个数量级，未闭合 |
| O2 | P0 | 隧穿 10⁻⁵⁴⁹ 与暗衰变 1.15% 的量级差异的定量机制 | 定性区分，未闭合 |
| O3 | P1 | σ_I* 的机制推导（为何观测者位置第三分量恰为 0.011484） | 依赖 1.5 §3.7 的编码权重代数，待封闭 |
| O4 | P1 | χ 粒子的质量与自旋 | 单色 γ 预言 E_γ ≈ 469.8 MeV 需要 m_χ 锚定 |
| O5 | P2 | 束流法新实验（J-PARC 等）对 1.08 ± 0.2% 区间的检验 | 待实验 |

### 6.3　诚实边界

- H1（σ_I* = BR_dark）是**中间层机制假设**，非公理推导；其正当性完全由预言-实测对照判定。
- 分支比 0.51% 偏差超出束流法误差（0.23%）两倍——"支持区间"而非"判别成立"，除非 O3 闭合。
- τ_geom = 878.4 s 依赖外部输入 G_F、f(Q)（3.9 §6.3），σ_I* 来自观测者位置参数化（1.5 §3.7）——两者均非零参数预言，是"2 参数框架"（2026-08-09 立场）内的合法使用。
