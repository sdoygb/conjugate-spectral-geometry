# 10.33 简并比例精确闭式与 θ^{d+2} 次主阶：开放问题 1、2 的解答

日期：260807.3 | 系列：仿射完备码噪声行为

## 摘要

10.32 的两个开放问题在此解答。核心发现：简并比例的精确闭式是**仿射平坦计数**（高斯二项 × 平移因子 2^{m−k}），而非独立向量秩分布——无放回点集抽样的互异约束使"独立均匀模型"高估简并比例 6.6 倍（m=8, r=3）。闭式对 r=1, 2 恒等于 1（全简并，组合恒等），对 r=3 给出 1.007e−4（m=8）等数值，与程序三种独立判据（rank 判据、组合闭式、syndrome 匹配）全部吻合。权重 2^r+1 层的简并闭式为 P'_r(m) = flats(m,r+1)·C(2^{r+1}, 2^r+1)/C(2^m, 2^r+1)；其伙伴落在权重 2^r−1 层（乘积 = d 的平坦指标），最小权重解码必选低层伙伴 → 100% 失败 → **θ^{d+2} 次主阶系数 = P'_r(m)**（r=2, m=6: 0.08197，三判据吻合）。

## 一、引言：开放问题重述与方法论教训

10.32 开放问题 1 问：简并比例与主阶近似 2^{−(2^r−r−2)(m−r−1)} 的差距（表观 ~1.6–2 倍）的精确常数是什么。开放问题 2 问：权重 2^r+1 层是否主导 θ^{d+2} 次主阶。

**方法论教训**：最初用"7 个独立均匀随机向量的秩分布"（斯滕伯格公式）估计简并比例，得 m=8 时 6.66e−4，与实测 1.2e−4 差 5.5 倍——经诊断（rank 实现对照 0 不一致、独立样本与公式逐项吻合）确认程序无 bug，差异源于**模型错误**：8 个点的差向量受"互异、非零、对异或互异"约束，并非独立均匀。正确的模型是组合计数：8 点子集仿射包 ≤ 4 维 ⟺ 8 点落入某个 4-平坦（16 点仿射子空间）。

## 二、定理 10.33.1.01（简并比例精确闭式）

**记号**：高斯二项 [m choose k]_2 = Π_{i=0}^{k−1}(2^{m−i}−1)/(2^{k−i}−1)；AG(m,2) 的 k-平坦数 flats(m,k) = 2^{m−k}·[m choose k]_2（注意平移因子 2^{m−k}——格拉斯曼数只数线性子空间）；E(k,s) = 固定 k-平坦内仿射包恰为 k 维的 s 点子集数，由容斥 E(k,s) = C(2^k, s) − Σ_{j<k} flats(k,j)·E(j,s) 给出（s > 2^{k−1} 时自动 E(k,s) = C(2^k, s)，因 s 点装不进 (k−1)-平坦）。

**定理**：AG 完备码 [[2^m, ·, 2^{r+1}]]（CSS(RM(r,m))）的权重 2^r 层简并比例

P_r(m) = [flats(m, r+1)·E(r+1, 2^r) + flats(m, r)] / C(2^m, 2^r)

其中第一项计"仿射包恰为 r+1 维"的 2^r 子集（伙伴 = (r+1)-平坦补集，10.32 定理 10.32.1.01 的包含性等价），第二项计"仿射包恰为 r 维"的 2^r 子集（= 整个 r-平坦本身，1 个）。

**推论 10.33.1.01a（全简并的组合恒等）**：r=1 与 r=2 时 P_r(m) = 1 恒成立（任意 m ≥ r+1）。即"任意 2 点子集仿射包 ≤ 2 维"与"任意 4 点子集仿射包 ≤ 3 维"的计数等式：flats(m,2)·E(2,2) + flats(m,1) = C(2^m,2) 等。这与 10.32 定理 10.32.1.02（r ≤ 2 全简并）一致，但现在是精确等式而非秩论证。

**数值（r=3）**：m=6 → 7.56e−3；m=7 → 8.49e−4；m=8 → 1.007e−4；m=9 → 1.227e−5；m=10 → 1.514e−6。相邻比值 ≈ 8.2–8.9 ≈ 2³，精确确认 10.32 定理 10.32.1.04 的主阶指数 3(m−4)。主阶 2^{−3(m−4)} 是闭式的渐近：m=8 时主阶 2.44e−4 vs 闭式 1.007e−4——**"1.6 倍差"的完整解释**：独立均匀秩分布（6.66e−4）高估真实值 6.6 倍（无放回约束），而主阶近似又漏掉秩分布公式的 Π 因子（≈2.72 倍），两个误差部分抵消后呈现表观 ~2.4 倍（10.32 实测 1.5e−4 与闭式 1.007e−4 差 1.3σ，统计吻合）。

## 三、定理 10.33.1.02（权重 2^r+1 层简并闭式）

**定理**：权重 2^r+1 层（跨层简并，伙伴在权重 2^r−1 层）的简并比例

P'_r(m) = flats(m, r+1)·C(2^{r+1}, 2^r+1) / C(2^m, 2^r+1)

证明：伙伴 χ_B（|B| = 2^r−1）与 χ_A'（|A'| = 2^r+1）同 syndrome ⟺ χ_{A'}⊕χ_B ∈ C⊥ 权重 = (2^r+1)+(2^r−1) = 2^{r+1} = d（C⊥ 最小权重）⟺ 乘积 = (r+1)-平坦指标 ⟺ A' ⊔ B = P。因 |A'| = 2^r+1 > 2^r = |r-平坦|，A' 不可能含于 r-平坦，仿射包自动 = r+1——故无容斥项，闭式比 P_r(m) 更简洁。

**数值**：r=2: m=6 → 0.08197；m=7 → 0.0400；m=8 → 0.01976；m=9 → 9.82e−3；m=10 → 4.90e−3。r=3: m=8 → 3.26e−6；m=9 → 1.95e−7。注意 r=2 时权重 5 层简并比例达 8.2%（m=6）——远非可忽略，是 d=8 码 θ^{10} 次主阶的真实来源。

## 四、定理 10.33.1.03（θ^{d+2} 次主阶）

**定理**：AG 完备码 [[2^m, ·, 2^{r+1}]] 相干独立噪声最优纠错（最小权重解码）的损失展开为

loss(θ) = c_d·θ^d + P'_r(m)·θ^{d+2} + o(θ^{d+2})

其中 c_d = 权重 d/2 层的解码失败率（r=2: 0.507，10.31 程序实测；r=3: P_r(m)/2，内部简并对半选错），d = 2^{r+1}。

**证明要点**：权重 2^r+1 项（幅度 θ^{2^r+1}）的 syndrome 与权重 2^r−1 伙伴相同（定理 10.33.1.02），且与任何权重 ≤ 2^r−2 或 = 2^r 的错误不同（乘积权重 = d+2−2|交| 或 17 ∉ C⊥ 权重谱，程序 2000/2000 抽样确认权重 9 与权重 8 全区分）——故最小权重解码**必选** 2^r−1 层伙伴 → 残留 = (r+1)-平坦逻辑（权重 d）→ 100% 失败。与权重 d/2 层不同（伙伴同层、解码器对半选错），跨层简并无 1/2 因子。

**系数级差**：r=2, m=6: c_10 = 0.082 vs c_8 = 0.507——次主阶可观；r=3, m=8: c_18 = 3.3e−6 vs c_16 ≈ 5e−5——次主阶几乎不可见。**大距离码的噪声行为被 θ^d 主导得越来越纯粹**。

## 六、意义

1. **简并比例是纯组合量**：闭式 = 高斯二项 × 平移因子 × 平坦内子集计数——"噪声几何"的系数完全由 AG(m,2) 的平坦计数决定，无任何概率近似。这是 10.32 定理 10.32.1.04 主阶近似的精确化：渐近指数 3(m−4) 被相邻 m 比值 ≈ 2³ 精确确认。
2. **方法论教训**：独立均匀秩分布（斯滕伯格）不可直接用于无放回点集抽样——互异约束压低低秩概率 6.6 倍。凡涉及"随机子集落入子空间"的计数，必须以平坦计数为基准。
3. **次主阶的层级结构**：θ^d（d/2 层内部简并，系数 ~1/2 或 P_r/2）→ θ^{d+2}（d/2+1 层跨层简并，系数 = P'_r）→ θ^{d+4}（d/2+2 层，伙伴在 d/2−2 层，乘积 = d 仍可能）——每一层系数按 flats·C 组合数衰减，大距离码的损失展开被 θ^d 绝对主导。
4. **对阈值估计的修正**：10.32 意义 3 的阈值 ~(c_r·N)^{−1/d} 现在有精确 c_r = P_r(m)/2（r=3 时含闭式 1.007e−4 而非主阶 2.44e−4——阈值估计上修 2.4 倍）。

**开放问题**：
1. 类大小分布 v：r=3 的简并类是否全部为 2（唯一平坦补集对），还是存在多平坦共享的大类（10.32 开放问题 3 延续）。
2. 随机 Pauli 噪声（非相干）在 d ≥ 16 码上的标度（10.32 开放问题 4 延续）。
3. P'_r(m) 的 θ^{d+2} 系数在注入受限（k 比特）场景下的可观测性：r=2, m=6 注入 5 比特时 θ^{10} 项与 θ^8 项的分离需要 θ ≲ 0.15 的数值精度窗口。
