# 10.43 候选 A 推进：D_+ 的代数来源与 χ 的互锁身份

**摘要。** 候选 A（拓扑通道计数）的判别核心是 $D_+ = \sigma_{\mathcal{M}}/\sigma_{\mathcal{C}}$ 的机制。本文建立三点：(i) 10.39/10.40 使用的 $(0.777912, 0.210603, 0.011484)$ 是 2.2 §1.4 的**零阶编码权重** $\sigma_0$（Cramer 法则导出），物理编码权重 $\sigma^* = (0.777428, 0.211091, 0.011481)$（Bott 周期回声修正）用于 $\alpha^{-1} = 137.036$——引用已修正，数值影响 0.14%；(ii) 编码累积拉伸 $\chi = (8, 9, 1)$ 本身是互锁常数组合 $\chi = (k_0^3, \Lambda^2, k_0^0)$，其中 $\chi_{\mathcal{M}} = 8 = \dim(\mathrm{adj}) = D_-$——"8"的第四重身份，连接候选 A 与候选 C；(iii) 因此 $D_+$ 是框架内导出量（非拟合参数）：$\sigma_0 = \mathrm{Cramer}(\theta_k, \chi)$，$0^{++}$ 质量 $= \kappa_c K\sqrt{\sigma_{\mathcal{M}0}/\sigma_{\mathcal{C}0}} = 1.614$ GeV 是**完全框架内**的预言。代数逼近观察：$\sigma_{\mathcal{M}0} \approx 7/9$（0.017%）、$\sigma_{\mathcal{C}0} \approx 4/19$（0.037%）。候选 A 结算：观测者绑定从"奇怪性质"升级为"框架内自洽"，判别仍需 f₀ 混合分析。

## §1 问题

10.41 候选 A（拓扑通道计数）：

$$D_+ = \frac{\sigma_{\mathcal{M}}^*}{\sigma_{\mathcal{C}}^*}, \qquad m_{0^{++}} = \kappa_c K\sqrt{D_+} = 1.614\ \text{GeV}.$$

判别手段：0⁺⁺ 纯态质量的精确值。推进 A 的核心问题：**观测者位置 $\sigma^*$ 本身是第一性的吗？** 若 $\sigma^*$ 是框架内导出量，则 $D_+$ 非拟合参数，候选 A 的"观测者绑定"从可疑变为自洽；若 $\sigma^*$ 是自由输入，则 $D_+$ 的命中有选择偏差风险。

## §2 零阶 vs 物理编码权重（引用修正的事实基础）

2.2 §1.4 明确区分两个 $\sigma$：

| 量 | 数值 | 来源 | 用途 |
|:---|:---|:---|:---|
| 零阶 $\sigma_0$ | (0.777912, 0.210603, 0.011484) | Cramer 法则（定理 2.2.1.01）+ 结构常数 + $\chi$ | 编码框架的代数结构 |
| 物理 $\sigma^*$ | (0.777428, 0.211091, 0.011481) | $\sigma_0$ + Bott 周期回声修正（$\varepsilon \approx 6.94\times10^{-5}$） | $S(\sigma^*) = 137.036$（定理 2.2.2.01） |

**引用修正**（10.39 §2.1、10.40 §3.2 已执行）：胶球 $D$ 因子采用的 0.777912 是 $\sigma_0$，此前标注"$\sigma^*$（Birkhoff 不动点）"不精确。数值影响：$D_+(\sigma_0) = 3.69375$ vs $D_+(\sigma^*) = 3.68293$（差 0.29%），$m_{0^{++}} = 1.6139$ vs $1.6117$ GeV（差 0.14%）——在 f₀(1500)/f₀(1710) 判定阈值内无实质影响，但引用必须精确。

**选择说明**：$D$ 因子采用 $\sigma_0$（而非物理 $\sigma^*$）的理由——质量算符路径（7.16）的扇区权重是纯代数量，Bott 修正服务于 $S(\sigma^*) = 137.036$ 的电磁精细结构常数导出，胶球质量谱不经过 $S$。这一选择本身是开放的（0.14% 内不可辨），列入诚实边界。

## §3 χ 的互锁身份（新观察）

**观察 10.43.3.01（χ 的互锁分解）**。编码累积拉伸（2.1 §3.2；2.2 §1.5：$\chi_i$ 编码扇区 $i$ 的内禀尺度）为

$$\chi = (\chi_{\mathcal{M}}, \chi_{\mathcal{C}}, \chi_{\mathcal{I}}) = (8, 9, 1) = (k_0^3, \Lambda^2, k_0^0).$$

即：$\chi_{\mathcal{M}} = 8 = k_0^3 = \dim(\mathrm{adj})$，$\chi_{\mathcal{C}} = 9 = \Lambda^2$，$\chi_{\mathcal{I}} = 1 = k_0^0$。

**"8"的第四重身份**。10.41 汇总了三重身份（$k_0^3$、$\dim(\mathrm{SU}(3)) = 8$、Cl(7) 8 维旋量），10.42 加入 $\gamma$ 主项 8（第五处）。现在 $\chi_{\mathcal{M}} = 8$——**编码累积拉伸的 ℳ 扇区分量**与 $D_- = 8$（胶球闭合通道维度）精确相等。这意味着：

$$D_- = \chi_{\mathcal{M}} = 8.$$

0⁻⁺/2⁺⁺ 的闭合通道维度 = 观测者编码框架的 ℳ 内禀尺度。**候选 A（观测者框架）与候选 C（γ 主项 8）在 χ 处汇合**——"8"不再是孤立巧合，而是 $k_0^3$ 在伴随维数、Cl(7) 旋量、编码拉伸、胶球通道、γ 主项五处的同源投影。

**χ_C = 9 = Λ² 的旁证**。$\chi_{\mathcal{C}} = 9 = \Lambda^2$：互锁常数 Λ = 3 的平方出现在因果扇区内禀尺度中。pullback 权重 $w_j = 1/\chi_j^2$（2.2 §1.5）随之有闭式 $w = (1/64, 1/81, 1) = (1/k_0^6, 1/\Lambda^4, 1)$。

## §4 D_+ 的代数来源

**观察 10.43.4.01（候选，10.44 已降级）。** $D_+$ 是**条件导出量**（给定观测者位置坐标）：

$$D_+ = \frac{\sigma_{\mathcal{M}0}}{\sigma_{\mathcal{C}0}} = 3.69375,$$

其中 $\sigma_0$ 的确定链为：$S(\sigma^*) = 137.036$（实验）→ $\sigma^*$（反推定位，2.2 §3.3）→ $\sigma_0$（去 Bott 修正，2.2 §5）。2.2 声称的独立路径"$\sigma_0$ 由 Cramer 法则（定理 2.2.1.01）从结构常数与 $\chi$ 确定"需要 $\theta_k$ 输入，而 $\theta_k$ 无互锁闭式（10.44 结算：不动点反解 $\theta = (1.0816, -0.1219, 0.0403)$ 含负分量，有理解分子分母均为 13 位数；$T_{\text{ours}}$ 为近似定位，2.2 §3.2）。因此：

$$m_{0^{++}} = \kappa_c K \sqrt{\frac{\sigma_{\mathcal{M}0}}{\sigma_{\mathcal{C}0}}} = 1614\ \text{MeV}$$

是**条件预言**（$\kappa_c$、$K$ 为框架内对象；$\sigma_0$ 依赖观测者位置定位）——非无条件预言。判别力不变：若 0⁺⁺ 纯态质量最终测量远离 1.61 GeV，被排除的是"观测者位置-质量算符耦合链"（定位坐标与质量耦合假设）。

## §5 代数逼近观察（候选级）

对 Cramer 结果的代数逼近（与 2.2 §1.4 表格"分量比值的代数逼近"同款）：

| 分量 | 数值 | 逼近 | 偏差 |
|:---|:---:|:---|:---:|
| $\sigma_{\mathcal{M}0}$ | 0.777912 | $(\Delta\Theta+k_0)/\Lambda^2 = 7/9 = 0.777778$ | 0.017% |
| $\sigma_{\mathcal{C}0}$ | 0.210603 | $k_0^2/(k_0(\Delta\Theta+k_0)+\Delta\Theta) = 4/19 = 0.210526$ | 0.037% |
| $\sigma_{\mathcal{I}0}$ | 0.011484 | $1/87$（弱） | 0.09% |
| 归一化 | $\sum = 0.999999$ | $7/9+4/19+1/87 = 0.999798$ | 0.02% |
| $D_+$ | 3.69375 | $7\times19/6^2 = 133/36 = 3.69444$ | 0.019% |

结构：$7 = \Delta\Theta+k_0$、$9 = \Lambda^2$、$4 = k_0^2$、$19 = k_0(\Delta\Theta+k_0)+\Delta\Theta = 14+5$、$36 = (k_0\Lambda)^2$、$133 = 7\times19$。$\sigma_{\mathcal{I}0} \approx 1/87$ 的 $87 = \Lambda(k_0\Delta\Theta\Lambda-1) = 3\times29$ 分解含 $-1$ 项，拼凑感强——**列为弱观察**。

**定位**：这些是逼近（偏差 $10^{-4}$ 量级），不是精确闭式——Cramer 法则是精确值。**S 检验（10.44）**：$S(7/9, 4/19, 1/87) = 136.950$，偏离 $137.036$ 达 $-0.063\%$——比物理 $\sigma^*$ 的偏差（$+0.0031\%$）差 20 倍。**有理闭式组合不能作为观测者位置候选**：分量级命中（0.017%/0.037%）未通过整体 S 检验，性质为"数值巧合"而非闭式。与 10.42 的 $\gamma = 60/7$（通过多闭式互锁网络检验）形成对照：单一命中可被整体检验否决。

## §6 候选 A 结算与判别路径

**支撑**：
1. $D_+$ 是框架内导出量（§4）——观测者绑定自洽化；
2. $D_- = \chi_{\mathcal{M}} = 8$（§3）——候选 A 与候选 C 在 χ 处汇合，"8"的五重同源（$k_0^3$、$\dim(\mathrm{adj})$、Cl(7) 旋量、$\chi_{\mathcal{M}}$、γ 主项）；
3. 代数逼近网络（§5）——$\sigma_0$ 数值结构接近互锁常数有理比。

**与候选 B（伴随体积提升）的区分**：B 预言 $0^{-+}/2^{++}$ 严格简并（已量化于 10.39 §5）；A 的独有预言是 $0^{++}$ 质量与 $\sigma_0$ 的精确绑定（1.614 GeV）。两候选在 0⁺⁺ 处不冲突（A 给 $D_+$，B 只约束 $D_-$ 部分）——**A 与 B 可共存**：$D_- = \chi_{\mathcal{M}}$（观测者框架）与 $D_- = 8$（伴随体积）是同一数值的两个解释，仍不可区分（10.41 开放歧义保留）。

**判别路径**（优先级）：
1. f₀(1500)/f₀(1710) 混合分析的纯胶球质量（vs 1.614 GeV）；
2. $D_- = \chi_{\mathcal{M}}$ 的推广预言：若其他纯色对象（如 1⁻⁺ 奇异胶球）的通道维度也取 $\chi$ 分量值，可检验"χ 通道"假设；
3. ~~$\theta_k$ 的互锁闭式~~（10.44 已结算：不存在简洁闭式；$\theta$ 为结构性参数，2.2 §4.3）——$\sigma_0$ 的独立计算（不经 $S$ 反推）仍开放，但不再经 $\theta_k$ 路径。

## §7 诚实边界与开放问题

1. **全部候选级**：观察 10.43.3.01、命题 10.43.4.01 无定理支撑；χ = (8,9,1) 的互锁分解是观察（2.1 §3.2 未给出 χ 的推导，χ 是"编码累积拉伸"的定义输入）；
2. **$\sigma_0$ vs $\sigma^*$ 的选择**：$D$ 因子采用 $\sigma_0$ 的理由是"质量算符路径不经 S"——若未来发现胶球质量应耦合 Bott 修正，0⁺⁺ 预言移至 1.612 GeV（差 0.14%）；两值不可辨，判别需要更高精度；
3. **$\sigma_{\mathcal{I}0} \approx 1/87$ 弱**：87 的分解含 $-1$ 项，拼凑风险；
4. **$\theta_k$ 的闭式已结算（10.44）**：不存在简洁互锁闭式——不动点反解 $\theta = (1.0816, -0.1219, 0.0403)$（$F$ 版本）与 $(1.0093, 0.0230, -0.0323)$（$M_5$ 版本）均含负分量，有理解分子分母为 13 位数；2.1 §3.4 原数值 $(1.081, 0.219, 0.041)$ 的 $\theta_\tau$ 符号错误（应为 $-0.1219$），已随 2.1 修正（git 19f3cb25）；$\theta$ 是结构性参数（收敛性、Berry 相位不依赖其精确值，2.2 §4.3）；
5. **开放问题**：
   - $\theta_k$ 的互锁闭式（最高优先——决定 A 的第一性强度）；
   - Cramer 法则在 $\chi = (k_0^3, \Lambda^2, k_0^0)$ 下的解析极限（$7/9$、$4/19$ 是否精确）；
   - $\sigma_{\mathcal{I}0} \approx 1/87$ 的干净分解；
   - f₀ 混合分析的纯胶球质量（实验判别）。
