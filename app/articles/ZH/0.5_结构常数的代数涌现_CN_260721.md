## 摘要

本文证明三个结构常数 Λ = 3、k₀ = 2、ΔΘ = 5 从唯一公理（零之动 δ）经 Clifford 代数刚性与自洽性筛选联合涌现。


**关键新增：E₈ 桥接定理（§0）。** 本文新增 §0，证明素因子集 {2, 3, 5} 是 E₈ 格——即 Bott 周期维度 8 中唯一的偶幺模格——的拓扑不变量。证明链为：Bott 周期 → 维度 8 → E₈ 唯一性 → Coxeter 数 h = 30 = 2 × 3 × 5 → 素因子 {2, 3, 5}。个体赋值通过 E₈ 中 D₄ 三重性轨道的最高根系数 {3, 4, 5} 实现。这一桥接将素因子集的来源从"读代数下标"提升为标准 Lie 理论 / 格论的定理，不依赖任何语义类比。

本文进一步证明三者的互锁性，并给出共扼三元组的严格表述。**互锁性正是圆满筛选的数学内核**——它解释了为什么 {2, 3, 5} 能满足圆满条件并再现为结构常数。

## §0 E₈ 桥接定理——素因子集的拓扑起源

### 0.1 批评与回应

一种合理的批评指出：从 Clifford 代数 Bott 周期表中"读出" Λ = 3、ΔΘ = 5、k₀ = 2——即将 Cl(n) 的下标 n 直接提取为全局结构常数——不是标准 Clifford/Bott 文献中的构造。Cl(3) ≅ ℍ ⊕ ℍ 是标准定理（Atiyah–Bott–Shapiro），但将"3"提取为全局结构常数 Λ 并作为素因子预算的来源，是作者的额外建构。

**这一批评是正确的。** 本节通过 E₈ 桥接定理回应：素因子集 {2, 3, 5} 不是从代数下标"读出"的，而是 E₈ 格——Bott 周期维度 8 中唯一的偶幺模格——的拓扑不变量。证明链完全使用标准 Lie 理论和格论的已知定理，不引入任何新公理，不依赖任何语义类比。

### 0.2 证明链

**定理6（E₈ 桥接定理）。** 设 Bott 周期为 8（Atiyah–Bott–Shapiro）。则素因子集 {2, 3, 5} 由以下证明链唯一确定为维度 8 的拓扑不变量：

$$Bott 周期 \xrightarrow{\text{步骤1}} 维度 8 \xrightarrow{\text{步骤2}} E_8\text{ 唯一} \xrightarrow{\text{步骤3}} h = 30 \xrightarrow{\text{步骤4}} \{2, 3, 5\}.$$

**证明。**

**步骤1：Bott 周期 → KO 理论 8-周期性 → 偶幺模格存在条件。**

Bott 周期的"8"与 E₈ 格的"8"之间的连接不是直接等同，而是通过 **KO 理论**（实 K-理论）的严格链：

**(a) Bott 周期 → KO 群 8-周期性。**

Atiyah–Bott–Shapiro（1964）证明实 Clifford 代数满足 Bott 周期：Cl(n+8) ≅ Cl(n) ⊗ Mat(16, ℝ)。这一周期性等价于 KO 群的 8-周期性：

$$KO^{n+8}(X) \cong KO^n(X),$$

即实 K-理论的约化群以 8 为周期。Clifford 代数的分类由 KO 群给出：Cl(n) 的不可约表示空间类型由 KO^{-n}(pt) 决定。

**(b) KO 8-周期 → 旋量流形 → 偶幺模格存在条件。**

KO 理论的 8-周期性与格论中**偶幺模格的存在条件**有深刻联系。具体地：

- **偶幺模格存在定理**：ℝⁿ 中存在偶幺模格当且仅当 n ≡ 0 (mod 8)。这一"8"与 Bott 周期的"8"是**同一个 8**——偶性条件 v·v ∈ 2ℤ 要求二次型的整性约束与 KO 理论的特征类理论一致。
- **E₈ 格的旋量构造**：E₈ 根格可以构造为 E₈ = D₈ ∪ (D₈ + ρ)，其中 D₈ 是 Spin(16) 的根系，ρ 是半旋量权。半旋量权 ρ 恰好来自 Clifford 代数的旋量表示——这直接将 E₈ 格的构造与 Clifford 代数联系起来。
- **Spin(16) 的半旋量表示**：Spin(16) 的半旋量表示 S^± 各为 128 维实表示，由 Cl(16) ≅ Mat(16, ℝ) ⊗ Mat(16, ℝ) 的结构给出。E₈ 格是 D₈ 格加上一个半旋量权 coset——这一构造是 Clifford 旋量理论的标准应用。

**(c) 因此连接链为：**

$$Bott 周期 (8) \xrightarrow{KO 理论} KO^{n+8} \cong KO^n \xrightarrow{旋量流形} 偶幺模格存在条件 n \equiv 0 \pmod{8} \xrightarrow{n=8} E_8 \text{ 唯一}$$

这条链中的每一步都是标准数学定理（Atiyah–Bott–Shapiro；Minkowski–Serre；E₈ 的旋量构造见 Conway–Sloane *Sphere Packings, Lattices and Groups*）。不存在"8=8"的语义跳跃——两个"8"通过 KO 理论的 8-周期性和偶幺模格的存在条件严格连接。

**步骤2：维度 8 中 E₈ 是唯一的偶幺模格。**

**定理（Minkowski–Serre）。** 在维度 8 中，E₈ 格是唯一的偶幺模格。

这是格论的经典定理。其证明要点如下：

- **偶性（even）**：格 Λ 中每个向量 v 满足 v·v ∈ 2ℤ。
- **幺模性（unimodular）**：det(Λ) = 1，即格的 Gram 行列式为 1。
- **唯一性**：在维度 8 中，满足偶性和幺模性的格恰有一个，即 E₈。

维度比较：在维度 < 8 时不存在偶幺模格（因为偶性要求维度 ≥ 8）。在维度 8 时恰有一个（E₈）。在维度 16 时有两个（E₈ ⊕ E₈ 和 D₁₆⁺）。在维度 24 时有 24 个（Niemeier 格）。维度 8 的唯一性是关键的——E₈ 不只是一个例子，而是该维度中唯一的可能性。

因此，Bott 周期的维度 8 唯一确定 E₈ 格——不需要任何选择或假设。

**步骤3：E₈ 的 Coxeter 数 h = 30。**

E₈ 的 Coxeter 数是标准 Lie 理论的已知量，由 Cartan 矩阵计算：

$$h = \frac{|\Phi(E_8)|}{\text{rank}(E_8)} = \frac{240}{8} = 30.$$

其中 |Φ(E₈)| = 240 是 E₈ 的根系中的根数（标准结果），rank(E₈) = 8 是 E₈ 的秩。

等价地，h 是 E₈ 的 Weyl 群 W(E₈) 中最长元素（Coxeter 元）的阶数，也是最高根 θ 在所有单根上的系数之和加 1。这些计算不涉及任何选择或拟合——h = 30 是 E₈ 的刚性不变量。

**步骤4：h = 30 = 2 × 3 × 5 给出素因子集 {2, 3, 5}。**

$$30 = 2 \times 3 \times 5.$$

30 的素因子分解是唯一的。因此 {2, 3, 5} 是 E₈ 的 Coxeter 数的素因子集——这是 E₈ 格的拓扑不变量，由 Bott 周期唯一确定。∎

### 0.3 个体赋值——D₄ 三重性轨道

上述步骤证明了素因子**集合** {2, 3, 5} 的唯一性。本节证明三个素因子到三个结构常数的**个体赋值**也由 E₈ 的内部结构唯一确定。

**定理7（个体赋值）。** E₈ Dynkin 图包含 D₄ 子图（即 Spin(8)），D₄ 具有三重性对称 S₃。在 E₈ 的最高根中，D₄ 三重性轨道的三个节点的系数恰为 {3, 4, 5}，其素因子分别给出 Λ = 3、k₀ = 2、ΔΘ = 5。

**证明。**

**步骤1：E₈ 包含 D₄ 子图。**

E₈ 的 Dynkin 图（Bourbaki 编号）为：

```
          α₃
          |
α₁ — α₂ — α₄ — α₅ — α₆ — α₇ — α₈
```

其中 α₄ 是三价节点（连接 α₂、α₃、α₅）。子图 {α₂, α₃, α₄, α₅} 构成 D₄ Dynkin 图，对应李代数 𝔰𝔬(8)（即 Spin(8)）。

D₄ 是唯一具有三重性对称 S₃ 的 Dynkin 图——其三个外节点 {α₂, α₃, α₅} 在 S₃ 作用下置换。这是标准 Lie 理论事实。

**步骤2：E₈ 最高根在 D₄ 三重性轨道上的系数为 {3, 4, 5}。**

E₈ 的最高根（在 Bourbaki 编号下）为：

$$θ = 2α₁ + 3α₂ + 4α₃ + 6α₄ + 5α₅ + 4α₆ + 3α₇ + 2α₈.$$

系数向量为 (2, 3, 4, 6, 5, 4, 3, 2)。D₄ 三重性轨道的三个外节点及其系数为：

| 三重性轨道节点 | 最高根系数 | 臂深（从 α₄ 到臂端点的节点数） |
|:---:|:---:|:---:|
| α₂ | 3 | 1（经 α₁） |
| α₃ | 4 | 0（垂直分支终止） |
| α₅ | 5 | 3（经 α₆, α₇, α₈） |

三个系数恰为 {3, 4, 5}。

**关键观察**：在 D₄ 作为独立 Dynkin 图时，三重性 S₃ 完美对称——三个外节点不可区分。但当 D₄ 嵌入 E₈ 时，三条臂的长度不同（分别为 1, 0, 3），三重性被 E₈ 的全局结构**破缺**，使三个原本等价的节点获得不同的最高根系数 {3, 4, 5}。这一破缺是 E₈ 格的刚性结构——不可调节。

**步骤3：素数核赋值（统一规则）。**

三个系数 {3, 4, 5} 的素数核（radical，即不同素因子之积）为：

| 三重性轨道节点 | 系数 n | rad(n) | 结构常数赋值 | Bott 位置 |
|:---:|:---:|:---:|:---:|:---:|
| α₂ | 3 | rad(3) = 3 | Λ = 3 | Cl(3)，首次半单分裂 |
| α₃ | 4 = 2² | rad(4) = 2 | k₀ = 2 | Cl(7)，终端二元性 |
| α₅ | 5 | rad(5) = 5 | ΔΘ = 5 | Cl(5)，复结构涌现 |

**radical 是标准数论函数**，统一适用于三个系数——不需要为不同系数使用不同规则。物理动机：结构常数是"素数级"的不可分解代数单元。系数 4 = 2² 含有重复的素因子，取 radical 提取其素数核 2——正如 Cl(7) ≅ Mat(8, ℝ) ⊕ Mat(8, ℝ) 的两个直和项虽然各有 8 维，但其代数不可分解单元数是 2（不是 8）。

**步骤4：个体赋值的唯一性。**

三个系数 {3, 4, 5} 分别出现在三个不同的三重性轨道节点上，且三个节点的臂深不同（1, 0, 3），使三者不可置换。具体地：

- 系数 3 出现在臂深 1 的节点（α₂，连接 α₁）——这是从 E₈ 的"左端"数起的第二个节点，对应 Bott 周期表中"最早"的结构变化（n = 3）。
- 系数 4 出现在臂深 0 的节点（α₃，垂直分支终端）——这是 E₈ 中唯一的垂直分支，对应 Bott 周期表中"终端"的结构变化（n = 7，最后一步）。
- 系数 5 出现在臂深 3 的节点（α₅，连接最长臂 α₆→α₇→α₈）——这是 E₈ 中臂深最大的三重性轨道节点，对应 Bott 周期表中"中间"的结构变化（n = 5）。

因此，三个素因子到三个结构常数的赋值是唯一的——不可置换、不可调节。∎

### 0.4 结构印证

E₈ 桥接定理的结论——素因子集 {2, 3, 5} 是维度 8 的拓扑不变量——在 E₈ 格的多个不变量中得到一致体现：

**印证1：E₈ 根数。**

$$|\Phi(E_8)| = 240 = 2^4 \times 3 \times 5.$$

240 的素因子集恰为 {2, 3, 5}。根数是 E₈ 格的基本不变量，与 Coxeter 数 h = 240/8 = 30 一致。

**印证2：McKay 对应——二元二十面体群。**

McKay 对应将二元二十面体群 2I（A₅ 的双重覆盖）与 E₈ 的 McKay 图（扩展 Dynkin 图 Ẽ₈）相关联。2I 的阶为：

$$|2I| = 120 = 2^3 \times 3 \times 5.$$

120 的素因子集仍为 {2, 3, 5}。McKay 对应是有限群与 Lie 代数之间的深刻对应——它独立地将 E₈ 与一个阶为 2³ × 3 × 5 的群联系起来。

**印证3：二十面体旋转群的旋转阶。**

二十面体旋转群 A₅（2I 的商群）的元素旋转阶恰为 {1, 2, 3, 5}（排除单位元 1 后为 {2, 3, 5}）。即正二十面体的旋转对称中，非平凡旋转的阶恰好是 2（半转）、3（三重轴）和 5（五重轴）——不多不少，恰好 {2, 3, 5}。

> **诚实声明（2026-07-22 v3）。** 上述三个印证并非完全独立的来源——它们都来自 E₈ 格的同一数学结构（Coxeter 数、根系、McKay 对应是同一对象的三个侧面）。它们不是"多个独立来源的交叉验证"，而是"同一结构的多个一致性检查"。真正的独立性来自步骤1中 KO 理论 → 偶幺模格 → E₈ 的连接链（来自拓扑 K-理论）与步骤2中 Minkowski–Serre 唯一性定理（来自格论）——这是两个不同数学领域的交叉验证。

### 0.5 E₈ 桥接与 Bott 周期的逻辑关系

E₈ 桥接定理与 §1 的三个结构常数定理有精确的分工：

| 层次 | 定理 | 证明内容 | 证明方法 |
|:---|:---|:---|:---|
| **WHY**（为什么是这些素数？） | 定理6（E₈ 桥接） | 素因子集 {2, 3, 5} 是 E₈ 的拓扑不变量 | 标准 Lie 理论 + 格论 |
| **WHERE**（在 Bott 表的哪个位置？） | 定理8–13 | Λ = 3 在 n = 3，ΔΘ = 5 在 n = 5，k₀ = 2 在 n = 7 | Clifford 代数 Bott 周期 |

- **E₈ 桥接（§0）回答"为什么"**：为什么素因子恰好是 {2, 3, 5} 而不是其他素数？因为 Bott 周期给出维度 8，维度 8 唯一确定 E₈，E₈ 的 Coxeter 数 h = 30 = 2 × 3 × 5。这是拓扑刚性——不可选择、不可调节。
- **Bott 周期（§1）回答"在哪里"**：这三个素数在 Bott 周期表的哪个位置凝结为结构常数？Λ = 3 在 n = 3（首次半单分裂），ΔΘ = 5 在 n = 5（复结构涌现），k₀ = 2 在 n = 7（终端二元性）。这是代数刚性——不可绕过。

两层互补：E₈ 桥接提供素因子集的拓扑起源（不依赖语义类比），Bott 周期提供结构常数的代数位置（不依赖拓扑论证）。二者独立给出相同的结果 {Λ = 3, k₀ = 2, ΔΘ = 5}，构成交叉验证。

## §1 三个结构常数定理

整个体系只有一条公理：零之动 δ（0.1）。以下三个结构常数都是从 δ 经 Clifford 代数化（0.2）和 Bott 周期（0.3）推导出的定理——不引入任何额外公理。

**与 §0 的关系。** §0 的 E₈ 桥接定理证明了素因子**集** {2, 3, 5} 是 E₈ 格的拓扑不变量（回答"为什么是这些素数"）。本节证明这三个素数在 Bott 周期表中的**位置**——Λ = 3 在 n = 3、ΔΘ = 5 在 n = 5、k₀ = 2 在 n = 7（回答"在哪里凝结"）。两层互补，构成交叉验证。

### 1.1 Λ = 3：半单分裂

**定理8（Λ = 3，半单分裂）。** Cl(3) ≅ ℍ ⊕ ℍ 是 Clifford 代数从单代数到半单代数的首次分裂。分裂投影 P_± = (1 ± e_1 e_2 e_3)/2 由体积元 ω_3（ω_3² = 1）唯一确定，无连续参数。

**证明（详细）。**

**步骤1：Cl(n) 对于 n < 3 都是单代数。**
- Cl(0) = ℝ：可换体，中心为 ℝ，单代数。
- Cl(1) = ℂ：可换体，中心为 ℂ，单代数。
- Cl(2) = ℍ：不可换体，中心为 ℝ，单代数。

这三者都是单代数——没有直和分解。

**步骤2：Cl(3) 首次出现直和分解。** 由 0.2 引理8.1，Cl(3) ≅ ℍ ⊕ ℍ。分裂由 ω_3 = e_1 e_2 e_3 唯一确定——ω_3² = +1 意味着 P_± = (1 ± ω_3)/2 是真正的投影。

**步骤3：分裂的唯一性。** P_± 由 ω_3 唯一确定，而 ω_3 = e_1 e_2 e_3 由生成元 e_1, e_2, e_3 唯一确定（在 Clifford 代数的定义下）。因此分裂方式没有连续参数——不存在「调节分裂方式」的自由度。

**步骤4：Λ = 3 的凝结。** Λ = 3 表示半单分裂在第 3 步凝结。这是刚性的——不可早（n < 3 时无分裂）、不可晚（n > 3 时分裂已发生且被后续结构覆盖）。∎

**意义。** Λ = 3 是物质扇区的结构常数。它意味着物质扇区的代数基础在 δ 的第 3 步凝结。

### 1.2 ΔΘ = 5：复结构涌现

**定理9（ΔΘ = 5，复结构涌现）。** Cl(5) ≅ Mat(4, ℂ) 是实 Clifford 代数中首个复矩阵代数。体积元 ω_5 满足 ω_5² = −1 且与所有生成元交换——它充当复结构 J，定义了五个有效扇区的代数基础。

**证明（详细）。**

**步骤1：Cl(n) 对于 n < 5 不含复结构。**
- Cl(0)–Cl(4) 均无由体积元定义的中心复结构（详见原文）。

**步骤2：Cl(5) 首次出现复结构。** 由 0.2 引理9.1，Cl(5) ≅ Mat(4, ℂ)。复结构由 ω_5 定义：ω_5² = −1，ω_5 与所有生成元交换。

**步骤3：复结构的唯一性。** ω_5 的性质（ω_5² = −1，与所有生成元交换）使其成为唯一的复结构——没有其他元素能满足这两个条件。

**步骤4：ΔΘ = 5 的凝结。** ΔΘ = 5 表示复结构涌现发生在第 5 步。这是刚性的——不可早（n < 5 时无复结构）、不可晚（n > 5 时复结构已存在）。∎

**意义。** ΔΘ = 5 是因果扇区的结构常数。ΔΘ − Λ = 5 − 3 = 2 是因果扇区的「厚度」。

### 1.3 k₀ = 2：终端二元性

**定理10（k₀ = 2，终端二元性）。** Cl(7) ≅ Mat(8, ℝ) ⊕ Mat(8, ℝ) 是七层编码轨道的终端——其中心维数为 2，产生不可消除的二元直和结构。

**证明（详细）。**

**步骤1：Cl(7) 的体积元平方。** 由 0.2 引理10.1，ω_7² = +1。与 Cl(3) 同理，ω_7 产生直和分裂。

**步骤2：终端性质。** Cl(7) 是编码轨道的终端——δ⁸ 的 Berry 相位 = 2π 阻止了进一步的独立编码层。

**步骤3：不可消解性。** Cl(7) 的二元分裂不能被后续步进消解——因为下一步（Cl(8)）是 Bott 回归。

**步骤4：k₀ = 2 的凝结。** k₀ = 2 表示终端二元性产生两个直和项。由 ω_7² = +1 唯一确定，无连续参数。∎

## §2 互锁性

### 2.1 共扼三元组

三个结构常数不是独立的——它们形成**互锁**结构：

**命题2（互锁性）。** Λ = 3、ΔΘ = 5、k₀ = 2 在 Bott 周期表中占据不可绕过的结构位置，三者形成结构耦合的共扼三元组：
$$Λ + (ΔΘ - Λ) + (7 - ΔΘ) + 1 = 3 + 2 + 2 + 1 = 8.$$

**证明（完整）。**

**步骤1：Λ = 3 是 ΔΘ = 5 的前提。** Cl(3) → Cl(4) → Cl(5) 是必然路径——Cl(5) 的复结构依赖 Cl(4) 的四元数矩阵结构，而后者依赖 Cl(3) 的半单分裂。

**步骤2：k₀ = 2 依赖前两者。** Cl(7) 的终端二元性依赖 ω_7² = +1，而 7 = 3 + 2 + 2 的分割直接来自 Λ = 3 和 ΔΘ = 5。如果 Λ 或 ΔΘ 改变，终端不在第 7 步，k₀ 也会改变。

**步骤3：三者在 Bott 周期中的位置不可绕过。** 半单分裂（n=3）、复结构涌现（n=5）、终端二元性（n=7）是 Bott 周期表中仅有的三个「结构跳跃点」：

| n | Cl(n) | 结构变化 | 跳跃点？ |
|:---:|:---|:---|:---:|
| 0 → 1 | ℝ → ℂ | 添加虚方向 | 小跳跃 |
| 1 → 2 | ℂ → ℍ | 可换 → 不可换 | 小跳跃 |
| 2 → 3 | ℍ → ℍ ⊕ ℍ | 单 → 半单 | **结构跳跃**（Λ = 3） |
| 3 → 4 | ℍ^{⊕2} → Mat(2, ℍ) | 半单 → 单 | 缝合 |
| 4 → 5 | Mat(2, ℍ) → Mat(4, ℂ) | 实 → 复 | **结构跳跃**（ΔΘ = 5） |
| 5 → 6 | Mat(4, ℂ) → Mat(8, ℝ) | 复 → 实 | 实化 |
| 6 → 7 | Mat(8, ℝ) → Mat(8, ℝ)^{⊕2} | 单 → 半单 | **结构跳跃**（k₀ = 2） |
| 7 → 8 | Mat(8, ℝ)^{⊕2} → Mat(16, ℝ) | 半单 → 单 | Bott 回归 |

三个结构跳跃点（n = 3, 5, 7）是 Bott 周期表中仅有的「质变」点。∎

### 2.2 共扼三元组与互扼三元组的对应

三个结构常数与 0.1 中的互扼三元组（抑制-痕迹-涌现）有精确的对应关系：

| 0.1 互扼三元组（语义层） | → | 本文共扼三元组（代数层） | 对应机制 |
|:--|:--|:--|:--|
| **抑制**（否定/划定界限） | → | Λ = 3（物质扇区的分裂） | 半单分裂是「划定界限」 |
| **痕迹**（记忆/累积） | → | ΔΘ = 5（因果扇区的复结构） | 复结构 J² = −1 是「记忆」 |
| **涌现**（模式/不可逆） | → | k₀ = 2（信息扇区的终端二元性） | 终端二元性是「模式闭合」 |

### 2.3 语义映射的形式化证明

> **注。** 本节的语义映射证明是**辅助性**的——它提供了语义层与代数层之间的概念对应。素因子集 {2, 3, 5} 和个体赋值的**严格基础**由 §0 的 E₈ 桥接定理提供（纯拓扑证明，不依赖语义）。

**命题3（语义映射的必然性）。** 设 δ 的三个语义性质（抑制、痕迹、涌现）按 0.1 定义。则在 Bott 周期表中：

1. **抑制的唯一代数实现是 n = 3 的半单分裂**（Λ = 3）。
2. **痕迹的唯一代数实现是 n = 5 的复结构涌现**（ΔΘ = 5）。
3. **涌现的唯一代数实现是 n = 7 的终端二元性**（k₀ = 2）。

证明详见原文。每个语义性质在 Bott 周期表中有且仅有一个代数实现。

## §3 从结构常数到物理扇区

| 结构常数 | 代数位置 | 物理扇区 | 含义 |
|:---:|:---|:---|:---|
| Λ = 3 | Cl(3) 半单分裂 | 物质 ℳ | 物质扇区在 3 步凝结 |

| k₀ = 2 | Cl(7) 终端二元性 | 信息 ℐ | 信息扇区在 7 步凝结 |

三扇区的「厚度」：物质 3 步 + 因果 2 步 + 信息 2 步 + 闭合步 1 = 8。

### 3.2 结构常数到物理扇区的映射详细说明

**Λ = 3 → 物质扇区 ℳ。** Cl(3) = ℍ ⊕ ℍ 的半单分裂产生两个独立的直和项，对应两种「物质基态」。物质扇区厚度为 3 步。

**ΔΘ = 5 → 因果扇区 𝒞。** Cl(5) = Mat(4, ℂ) 的复结构赋予因果扇区「振荡」能力。因果扇区厚度为 2 步。

**k₀ = 2 → 信息扇区 ℐ。** Cl(7) = Mat(8, ℝ) ⊕ Mat(8, ℝ) 的终端二元性产生两种「信息基态」，对应比特 0 和 1。信息扇区厚度为 2 步。
