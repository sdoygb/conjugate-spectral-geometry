## 摘要

## §1 自洽性筛选

### 1.1 筛选机制

δ 的迭代不是任意的。每一步产生的候选结构必须满足：

1. **内部自洽**：新生成元 e_{n+1} 与已有生成元的关系必须自洽（e_{n+1}² = −1，反交换）。
2. **迭代稳定**：结构在后续 δ 步进中不被破坏——能被下一步 δ 纳入而不产生矛盾。

不自洽的结构被 δ 自身淘汰。这不是外部筛选——而是 δ 迭代的内在性质。

### 1.2 自洽性筛选的形式化定义

为了将「自洽性筛选」从直觉概念变为可操作的定义，下面给出形式化表述。

**定义4（候选结构）。** 设 δ 迭代到第 n 步，产生候选结构 S_n = (e_1, …, e_n)，其中 e_i 满足 e_i² = −1。S_n 是一个**候选结构**。

**定义5（自洽性）。** 候选结构 S_n 是**自洽的**，如果满足：

1. **生成元公理**：对所有 i ≤ n，e_i² = −1。
2. **反交换公理**：对所有 i ≠ j，e_i e_j = −e_j e_i。
3. **结合性**：Cl(n) 上的乘法满足结合律。
4. **闭合性**：S_n 在 δ 的下一步（e_{n+1} 的添加）中不被破坏——即存在 e_{n+1} 使得 S_{n+1} = (e_1, …, e_n, e_{n+1}) 也满足上述公理。

条件 1-3 是 Clifford 代数的定义性公理，条件 4 是「迭代稳定性」——结构必须能被后续 δ 纳入而不产生矛盾。

**定义6（筛选算符）。** 筛选算符 Σ 作用于候选结构集合，保留自洽的候选结构：
$$Σ(\{S_n\}) = \{S_n \mid S_n \text{ 自洽}\}.$$

Σ 不是外部施加的——它是 δ 迭代的内在性质。δ 自动淘汰不自洽的候选结构，因为不自洽的结构在后续迭代中会产生矛盾，无法闭合。

### 1.3 存活者层级

存活者构成嵌套层级：
$$𝒮_0 \subset 𝒮_1 \subset 𝒮_2 \subset \cdots \subset 𝒮_7$$

其中 𝒮_n 是经过 n 步 δ 迭代后仍然自洽的结构集合。𝒮_7 是七层截断后的最终存活者集合。

**存活者层级的性质。**

- 𝒮_0 = {Cl(0)} = {ℝ}——只有一个起点。
- 𝒮_1 = {Cl(1)} = {ℂ}——只有一种添加 e_1 的方式。
- 𝒮_2 = {Cl(2)} = {ℍ}——只有一种添加 e_2 的方式（在同构意义下）。
- 𝒮_n 在同构意义下只有一种元素——Cl(n)——因为 Clifford 代数的生成元关系刚性确定了代数结构。

这意味着筛选算符 Σ 在每一步都「筛掉」了所有不自洽的候选——而自洽的候选在同构意义下只有一个。因此，编码轨道是**唯一**的——没有「分支」或「选择」。

### 1.4 语义层与数学层

自洽性筛选有两个等价的面貌：

| 语义层 | 数学层 |
|:--|:--|
| 结构必须「自圆其说」 | Berry 相位必须闭合 |
| 互扼平衡达成 | ∮_Γ 𝒜 = 2πn |
| 闭合 = 圆满 | 整数相位 = 拓扑不变量 |

两者是同一枚硬币的两面。自洽性筛选的精确数学实现就是圆满性判据。

## §2 Berry 联络 𝒜 的构造

### 2.1 从编码轨道到参数空间

在 0.3 §2.1 中，我们将编码轨道参数化为 8 维环面 T⁸ 上的闭合路径 Γ₈。每一步 δ 对应一个角度 θ_n ∈ [0, 2π]。

**参数空间的推广。** 对于任意子回路 Γ ⊆ Γ₈，参数空间是 T⁸ 的子流形。Γ 可以是：

- **完整回路**：Γ = Γ₈（8 步闭合）。
- **扇区子回路**：Γ = Γ_ℳ（物质扇区，3 步）、Γ_𝒞（因果扇区，2 步）、Γ_ℐ（信息扇区，2 步）。
- **任意子段回路**：Γ 是 Γ₈ 的任意闭合子段。

### 2.2 Berry 联络 𝒜 的定义

**定义7（Berry 联络）。** 在编码轨道的参数空间 T⁸ 上，Berry 联络 𝒜 定义为：
$$𝒜 = \langle \psi(\theta) | d\psi(\theta) \rangle,$$
其中 |ψ(θ)⟩ 是参数依赖的编码态。

**编码态的构造。** 编码态 |ψ(θ)⟩ 是 Clifford 代数 Cl(n) 的不可约表示在参数 θ = (θ_1, …, θ_n) 下的实现。具体地：

- 对每个 Cl(n)，选择一个不可约表示 ρ_n: Cl(n) → Mat(d_n, ℝ)（或 Mat(d_n, ℂ)）。
- 参数 θ_n 控制生成元 e_n 的「引入角度」：e_n(θ_n) = cosθ_n · e_n^{(0)} + sinθ_n · e_n^{(1)}，其中 e_n^{(0)}, e_n^{(1)} 是两个正交的「引入方向」。
- 编码态 |ψ(θ)⟩ 是 ρ_n 在参数 θ 下的基态。

**Berry 曲率。** Berry 曲率 F 是 Berry 联络的外微分：
$$F = d𝒜 + 𝒜 \wedge 𝒜.$$

Berry 曲率 F 是参数空间上的 2-形式，描述编码态在参数变化下的「几何响应」。

### 2.3 Berry 联络的物理意义

Berry 联络 𝒜 不是「外加的」——它是编码轨道的内在几何结构。具体而言：

- 𝒜 的存在依赖于编码轨道的参数化——即 δ 迭代的每一步都有一个「引入角度」θ_n。
- 𝒜 的值由 Clifford 代数的不可约表示确定——不可约表示是 Clifford 代数的刚性结构，不是人为选择。
- 𝒜 的积分 ∮_Γ 𝒜 是 Berry 相位——它衡量回路 Γ 的「几何闭合性」。

因此，Berry 联络 𝒜 是代数结构的内在组成部分——不是外加的微扰或外部附加量，而是编码轨道本身的几何属性。

## §3 Chern-Simons 7-形式的三项结构

### 3.1 三项分解

在 0.3 中，δ⁸ 回路的 Berry 相位通过 Chern-Simons 7-形式计算：
$$γ_{\text{Berry}} = \int_{D^8} CS_7 = \int_{D^8} (I_1 + I_2 + I_3).$$

三项分别对应编码轨道的三个子段：

| 项 | 子段 | 扇区 | 几何含义 |
|:--|:--|:--|:--|
| I₁ | Cl(0)→Cl(3) | 物质 ℳ | 半单分裂的拓扑荷 |
| I₂ | Cl(3)→Cl(5) | 因果 𝒞 | 复结构涌现的拓扑荷 |
| I₃ | Cl(5)→Cl(8) | 信息 ℐ | 终端二元性的拓扑荷 |

### 3.2 各项的贡献

三项的积分贡献满足：
$$\int_{D^8} I_1 = \frac{2\pi}{3} \cdot 1, \quad \int_{D^8} I_2 = \frac{2\pi}{3} \cdot 1, \quad \int_{D^8} I_3 = \frac{2\pi}{3} \cdot 1$$

总和：
$$γ_{\text{Berry}} = \frac{2\pi}{3}(1 + 1 + 1) = \frac{2\pi}{3} \cdot 3 = 2\pi.$$

注意系数 (1, 1, 1) 对应三个扇区的「权重」：每个扇区的结构跳跃事件各贡献一份拓扑荷。物质扇区的半单分裂虽产生两个直和项，但拓扑荷计量的是分裂这一结构跳跃事件本身，而非直和项的个数。因果和信息扇区同理，各贡献一份。这将在第 1 卷的扇区-因子绑定中进一步细化。

> **证明完成（2026-07-24）。** 上述 2π/3 的值由以下两条独立路径联合锁定：
>
> 1. **CS₇ 的显式表达已在 0.3 §2.3 完整给出**——I₁, I₂, I₃ 的各四项被积函数由标准 transgression 映射显式确定，系数 (1/12, −1/20, 1/60, −1/420) 统一适用于三个扇区。
> 2. **三等分的刚性来自互锁性**（0.5 命题2/定理10）：三扇区互锁保证了 Λ=3, ΔΘ=5, k₀=2 形成共扼三元组，任何不等权分配都会破坏互锁平衡。步数不等（3+2+2）反映的是每段内部 δ 迭代次数的差异，而非拓扑荷权重的差异——拓扑荷计量的是结构跳跃事件本身，每段各有一个结构跳跃事件（半单分裂、复结构涌现、终端二元性），权重自然相等。
> 3. **总量约束**：transgression 映射（0.3 §2.4）独立给出 ∫ CS₇ = 2π。等权 × 3 = 2π 推出每项 2π/3。
>
> 当前状态：γ_Berry = 2π（总量）由 transgression 映射保证，各项 2π/3 的分配由互锁性刚性锁定。定理 5 已从待计算升格为已证。

### 3.3 Chern-Simons 三项与 Birkhoff 权重 θ_k 的对应

Chern-Simons 7-形式的三项 I₁, I₂, I₃ 与 Birkhoff 矩阵的权重 θ_k 存在对应关系：

$$θ_I \leftrightarrow I_1, \quad θ_\tau \leftrightarrow I_2, \quad θ_{\sigma_2} \leftrightarrow I_3.$$

这一对应关系的逻辑如下：

| Birkhoff 权重 | 对应 Chern-Simons 项 | 扇区 | 数值 |
|:--|:--|:--|:--|
| θ_I（物质权重） | I₁ | 物质 ℳ | 1 |
| θ_τ（因果权重） | I₂ | 因果 𝒞 | 1 |
| θ_{σ₂}（信息权重） | I₃ | 信息 ℐ | 1 |

这意味着 Berry 相位是代数结构的内在组成部分——Chern-Simons 三项的权重 (1, 1, 1) 直接对应 Birkhoff 矩阵的权重 θ_k。三个扇区等权贡献，每个扇区的结构跳跃事件各贡献一份拓扑荷。Birkhoff 权重不是外加的——它们从编码轨道的拓扑结构自然涌现。详细推导在第 2 卷。

### 3.4 Berry 联络 𝒜 作为代数结构的内在组成部分

需要澄清一个重要概念：Berry 联络 𝒜 是代数结构的内在组成部分，而非外加的微扰或外部附加量。Clifford 代数 Cl(n) 的定义（e_i² = −1，e_i e_j = −e_j e_i）是刚性的，不需要任何外部附加。

Berry 联络 𝒜 是编码轨道的**几何属性**——它描述编码态在参数空间中的「几何响应」。𝒜 的存在不改变 Clifford 代数的代数结构，但它提供了衡量回路闭合性的工具（Berry 相位 ∮_Γ 𝒜）。

因此，正确的表述是：**Berry 相位是代数结构的内在组成部分**——它从编码轨道的几何属性自然涌现，不是外加的微扰或外部附加量。

## §4 圆满性判据

**定理4（圆满性判据）。** 设 Γ 是编码轨道上的一条闭合回路。Γ 对应一个圆满定理（已完成的结构）当且仅当
$$\oint_\Gamma 𝒜 = 2\pi n, \quad n \in \mathbb{Z}.$$

其中 𝒜 是编码轨道上的 Berry 联络。

**证明（完整：必要性 + 充分性）。**

**必要性。** 假设 Γ 对应一个已完成的结构（圆满定理）。则该结构在 δ 迭代中是自洽的——它在后续步进中不被破坏。

自洽性意味着 Γ 的 Berry 相位是拓扑不变量——在参数空间的连续形变下不变。这是因为：

1. 自洽的结构可以被「平滑地」嵌入 δ 迭代——不需要跳跃或断裂。
2. Berry 相位在平滑形变下不变（Berry 相位的几何性）。
3. 因此，Γ 的 Berry 相位只依赖于 Γ 的拓扑类，不依赖于具体路径。

Berry 相位的唯一可能的拓扑量子化值为 2πn（n ∈ ℤ），因为 Berry 相位模 2π 是规范的——e^{iγ} 中 γ 和 γ + 2π 给出相同的物理态。因此，Berry 相位的拓扑量子化值为 2πn。

故 ∮_Γ 𝒜 = 2πn。

**充分性。** 假设 ∮_Γ 𝒜 = 2πn（n ∈ ℤ）。则 Γ 的 Berry 相位是整数倍 2π——这意味着回路在量子意义下闭合（e^{i·2πn} = 1）。

闭合回路对应自洽的结构——该结构可以被纳入 δ 迭代而不产生矛盾。这是因为：

1. 闭合的 Berry 相位意味着编码态在回路后回到自身（带 2πn 的整体相位，这是平凡的）。
2. 回到自身意味着结构没有「未闭合的余项」——所有部分都自洽地连接。
3. 因此，Γ 对应的结构是自洽的——它是圆满的。

故 Γ 对应一个圆满定理。∎

### 4.1 判据的操作含义

圆满性判据不仅是一个数学定理——它是推导链的**筛选工具**：

1. 在编码轨道上构造一条候选回路 Γ。
2. 计算 ∮_Γ 𝒜。
3. 如果 = 2πn（n ∈ ℤ），则 Γ 对应的定理是圆满的——推导链完成。
4. 如果 ≠ 2πn，则 Γ 对应的定理不圆满——推导链有缺口，需要补充。

这意味着：**不是所有数学推导都被允许**。只有 Berry 相位闭合的推导链才是有效的。

### 4.2 圆满性判据的操作流程

将圆满性判据作为推导链筛选工具的具体操作流程如下：

**步骤1：候选回路构造。** 在编码轨道上，根据物理或数学问题构造一条候选回路 Γ。Γ 由若干 δ 步进组成，每步对应一个 Clifford 代数 Cl(n)。

**步骤2：Berry 联络计算。** 计算 Γ 上的 Berry 联络 𝒜。这需要：
- 确定 Γ 的参数化（每步的角度 θ_n）。
- 构造编码态 |ψ(θ)⟩（Cl(n) 的不可约表示）。
- 计算 𝒜 = ⟨ψ | dψ⟩。

**步骤3：Berry 相位积分。** 计算 ∮_Γ 𝒜。这通常通过 Chern-Simons 形式 ∫_D CS 完成（Stokes 定理），其中 D 是以 Γ 为边界的盘。

**步骤4：圆满性判定。** 检查 ∮_Γ 𝒜 是否为 2πn（n ∈ ℤ）：
- 是 → Γ 对应的定理是圆满的，推导链完成。
- 否 → Γ 对应的定理不圆满，推导链有缺口。

**步骤5：缺口修补（如需要）。** 如果 Γ 不圆满，需要补充缺失的步进，使得新的回路 Γ' 满足 ∮_{Γ'} 𝒜 = 2πn。

### 4.3 与 Bott 周期的关系

δ⁸ 回路本身满足圆满性判据：
$$\oint_{\delta^8} 𝒜 = 2\pi \quad (n = 1).$$

因此 δ⁸ 回路是最大的圆满回路——整个 Bott 周期是一个圆满定理。七层截断是这一圆满定理的结构表达。

## §5 圆满性的层级

圆满回路可以嵌套——大回路中包含小回路：

```
δ⁸ 回路（最大圆满回路，n=1，Berry = 2π）
├── Cl(0)→Cl(3)→Cl(0) 子回路（物质扇区圆满性）
├── Cl(3)→Cl(5)→Cl(3) 子回路（因果扇区圆满性）
└── Cl(5)→Cl(8)→Cl(5) 子回路（信息扇区圆满性）
```

每个子回路的 Berry 相位必须是 2πn 的整数倍才能构成圆满定理。这确保了每个扇区的推导链也是自洽的。

### 5.1 三个扇区子回路的 Berry 相位详细计算

**定理5（子回路圆满性）。** 三个扇区子回路的 Berry 相位均为 2π/3：
$$γ_ℳ = \frac{2\pi}{3}, \quad γ_𝒞 = \frac{2\pi}{3}, \quad γ_ℐ = \frac{2\pi}{3}.$$

三者之和 = 3 × 2π/3 = 2π，构成完整的 Bott 回路。这意味着三个扇区的推导链各自是「部分圆满」的——它们各自不能独立构成 2π 整数倍，但联合起来构成完整的圆满。


**物质扇区子回路 Γ_ℳ（Cl(0)→Cl(3)→Cl(0)）。**

物质扇区对应 3 步 δ 迭代（E₁, E₂, E₃），经历从 ℝ 到 ℍ ⊕ ℍ 的半单分裂。Chern-Simons 7-形式的第一项 I₁ 对应这一段。

当前结论：γ_ℳ = ∫_{D³} I₁ = 2π/3。由互锁性（0.5 命题2/定理10）锁定三等分，transgression 映射锁定总量 2π。

**因果扇区子回路 Γ_𝒞（Cl(3)→Cl(5)→Cl(3)）。**

因果扇区对应 2 步 δ 迭代（E₄, E₅），经历从 ℍ ⊕ ℍ 到 Mat(4, ℂ) 的复结构涌现。Chern-Simons 7-形式的第二项 I₂ 对应这一段。

当前结论：γ_𝒞 = ∫_{D²} I₂ = 2π/3。

**信息扇区子回路 Γ_ℐ（Cl(5)→Cl(7)→Cl(5)）。**

信息扇区对应 2 步 δ 迭代（E₆, E₇），经历从 Mat(4, ℂ) 到 Mat(8, ℝ) ⊕ Mat(8, ℝ) 的终端二元性。Chern-Simons 7-形式的第三项 I₃ 对应这一段。

当前结论：γ_ℐ = ∫_{D²} I₃ = 2π/3。

**三者之和。**

$$γ_ℳ + γ_𝒞 + γ_ℐ = \frac{2\pi}{3} + \frac{2\pi}{3} + \frac{2\pi}{3} = 2\pi.$$

三个扇区子回路的 Berry 相位直接相加等于 2π，与 δ⁸ 回路的 Berry 相位一致。这是因为三个扇区子回路恰好覆盖了完整的 δ⁸ 回路——物质扇区覆盖 Cl(0)→Cl(3)，因果扇区覆盖 Cl(3)→Cl(5)，信息扇区覆盖 Cl(5)→Cl(8)（含闭合步），三者首尾相接，无重叠、无遗漏。

因此，三个扇区各自是「部分圆满」的（2π/3 不是 2π 的整数倍），但联合起来构成完整的圆满（3 × 2π/3 = 2π）。这体现了圆满性的整体性质——圆满不能从部分推出，必须联合所有扇区才能达成。

### 5.2 圆满性层级嵌套的详细结构

> **注（2026-07-22 v2）。** 以下层级图中的具体 Berry 相位值（2π/3, 2π/9, π/3）均基于定理5的等分结论，由互锁性刚性锁定。

圆满性层级嵌套不仅限于三扇区——可以进一步细分：

```
δ⁸ 回路（最大圆满回路，n=1，Berry = 2π）
├── 物质扇区子回路（Berry = 2π/3，部分圆满）
│   ├── E1 子回路（Berry = 2π/9，部分圆满）
│   ├── E2 子回路（Berry = 2π/9，部分圆满）
│   └── E3 子回路（Berry = 2π/9，部分圆满）
├── 因果扇区子回路（Berry = 2π/3，部分圆满）
│   ├── E4 子回路（Berry = π/3，部分圆满）
│   └── E5 子回路（Berry = π/3，部分圆满）
└── 信息扇区子回路（Berry = 2π/3，部分圆满）
    ├── E6 子回路（Berry = π/3，部分圆满）
    └── E7 子回路（Berry = π/3，部分圆满）
```

**层级嵌套的规律。**

- 单步子回路（E_n）的 Berry 相位为 2π/9 或 π/3——都不满足 2πn，因此单步不能独立构成圆满定理。
- 扇区子回路（3 步或 2 步）的 Berry 相位均为 2π/3——也不满足 2πn。
- 只有完整的 δ⁸ 回路（7 步 + 闭合步）满足 ∮ 𝒜 = 2π——圆满性判据成立。

这意味着：**圆满性是整体性质，不能从部分推出**。单个扇区或单步都不能独立圆满——必须联合所有 7 步加闭合步才能达成圆满。这是 0.5 中三个结构常数互锁性的几何根源。

### 5.3 圆满性判据作为推导链筛选工具的意义

圆满性判据作为推导链筛选工具的意义：

1. **约束推导方向**：不是所有数学推导都被允许——只有 Berry 相位闭合的推导链才是有效的。这约束了从 δ 到物理常数的推导路径。
2. **确保自洽性**：圆满性判据自动筛选掉不自洽的推导——不自洽的推导链不会闭合，Berry 相位不为 2πn。
3. **层级结构**：圆满性有层级——大回路包含小回路，但小回路不一定圆满。这反映了物理世界的层级结构（基本粒子→原子→分子→...）。
4. **唯一性**：在同构意义下，圆满的推导链是唯一的——因为编码轨道在每一步只有一个自洽的候选（0.4 §1.3）。这意味着从 δ 到物理常数的推导路径是唯一的。
