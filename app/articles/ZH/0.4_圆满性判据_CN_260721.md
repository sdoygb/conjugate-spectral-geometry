## §1 自洽性筛选

### 1.1 筛选机制

$\delta$ 的迭代不是任意的。每一步产生的候选结构必须满足：

1. **内部自洽**：新生成元 $e_{n+1}$ 与已有生成元的关系必须自洽（$e_{n+1}^2 = -1$，反交换）。
2. **迭代稳定**：结构在后续 $\delta$ 步进中不被破坏——能被下一步 $\delta$ 纳入而不产生矛盾。

不自洽的结构被 $\delta$ 自身淘汰。这不是外部筛选——而是 $\delta$ 迭代的内在性质。

### 1.2 自洽性筛选的形式化定义

为了将「自洽性筛选」从直觉概念变为可操作的定义，下面给出形式化表述。

**定义4（候选结构）。** 设 $\delta$ 迭代到第 $n$ 步，产生候选结构 $S_n = (e_1, \dots, e_n)$，其中 $e_i$ 满足 $e_i^2 = -1$。$S_n$ 是一个**候选结构**。

**定义5（自洽性）。** 候选结构 $S_n$ 是**自洽的**，如果满足：

1. **生成元公理**：对所有 $i \leq n$，$e_i^2 = -1$。
2. **反交换公理**：对所有 $i \neq j$，$e_i e_j = -e_j e_i$。
3. **结合性**：$\text{Cl}(n)$ 上的乘法满足结合律。
4. **闭合性**：$S_n$ 在 $\delta$ 的下一步（$e_{n+1}$ 的添加）中不被破坏——即存在 $e_{n+1}$ 使得 $S_{n+1} = (e_1, \dots, e_n, e_{n+1})$ 也满足上述公理。

条件 1-3 是 Clifford 代数的定义性公理，条件 4 是「迭代稳定性」——结构必须能被后续 $\delta$ 纳入而不产生矛盾。

**定义6（筛选算符）。** 筛选算符 $\Sigma$ 作用于候选结构集合，保留自洽的候选结构：
$$\Sigma(\{S_n\}) = \{S_n \mid S_n \text{ 自洽}\}.$$

$\Sigma$ 不是外部施加的——它是 $\delta$ 迭代的内在性质。$\delta$ 自动淘汰不自洽的候选结构，因为不自洽的结构在后续迭代中会产生矛盾，无法闭合。

### 1.3 存活者层级

存活者构成嵌套层级：
$$\mathcal{S}_0 \subset \mathcal{S}_1 \subset \mathcal{S}_2 \subset \cdots \subset \mathcal{S}_7$$

其中 $\mathcal{S}_n$ 是经过 $n$ 步 $\delta$ 迭代后仍然自洽的结构集合。$\mathcal{S}_7$ 是七层截断后的最终存活者集合。

**存活者层级的性质。**

- $\mathcal{S}_0 = \{\text{Cl}(0)\} = \{\mathbb{R}\}$——只有一个起点。
- $\mathcal{S}_1 = \{\text{Cl}(1)\} = \{\mathbb{C}\}$——只有一种添加 $e_1$ 的方式。
- $\mathcal{S}_2 = \{\text{Cl}(2)\} = \{\mathbb{H}\}$——只有一种添加 $e_2$ 的方式（在同构意义下）。
- $\mathcal{S}_n$ 在同构意义下只有一种元素——$\text{Cl}(n)$——因为 Clifford 代数的生成元关系刚性确定了代数结构。

这意味着筛选算符 $\Sigma$ 在每一步都「筛掉」了所有不自洽的候选——而自洽的候选在同构意义下只有一个。因此，编码轨道是**唯一**的——没有「分支」或「选择」。

### 1.4 语义层与数学层

自洽性筛选有两个等价的面貌：

| 语义层 | 数学层 |
|:--|:--|
| 结构必须「自圆其说」 | Berry 相位必须闭合 |
| 互扼平衡达成 | ∮_Γ 𝒜 = 2πn |
| 闭合 = 圆满 | 整数相位 = 拓扑不变量 |

两者是同一枚硬币的两面。自洽性筛选的精确数学实现就是圆满性判据。

## §2 Berry 联络 $\mathcal{A}$ 的构造

### 2.1 从编码轨道到参数空间

在 中，我们将编码轨道参数化为 8 维环面 $T^8$ 上的闭合路径 $\Gamma_8$。每一步 $\delta$ 对应一个角度 $\theta_n \in [0, 2\pi]$。

**参数空间的推广。** 对于任意子回路 $\Gamma \subseteq \Gamma_8$，参数空间是 $T^8$ 的子流形。$\Gamma$ 可以是：

- **完整回路**：$\Gamma = \Gamma_8$（8 步闭合）。
- **扇区子回路**：$\Gamma = \Gamma_{\mathcal{M}}$（物质界，3 步）、$\Gamma_{\mathcal{C}}$（因果界，2 步）、$\Gamma_{\mathcal{I}}$（信息界，2 步）。
- **任意子段回路**：$\Gamma$ 是 $\Gamma_8$ 的任意闭合子段。

### 2.2 Berry 联络 $\mathcal{A}$ 的定义

**定义7（Berry 联络）。** 在编码轨道的参数空间 $T^8$ 上，Berry 联络 $\mathcal{A}$ 定义为：
$$\mathcal{A} = \langle \psi(\theta) | d\psi(\theta) \rangle,$$
其中 $|\psi(\theta)\rangle$ 是参数依赖的编码态。

**编码态的构造。** 编码态 $|\psi(\theta)\rangle$ 是 Clifford 代数 $\text{Cl}(n)$ 的不可约表示在参数 $\theta = (\theta_1, \dots, \theta_n)$ 下的实现。具体地：

- 对每个 $\text{Cl}(n)$，选择一个不可约表示 $\rho_n: \text{Cl}(n) \to \text{Mat}(d_n, \mathbb{R})$（或 $\text{Mat}(d_n, \mathbb{C})$）。
- 参数 $\theta_n$ 控制生成元 $e_n$ 的「引入角度」：$e_n(\theta_n) = \cos\theta_n \cdot e_n^{(0)} + \sin\theta_n \cdot e_n^{(1)}$，其中 $e_n^{(0)}, e_n^{(1)}$ 是两个正交的「引入方向」。
- 编码态 $|\psi(\theta)\rangle$ 是 $\rho_n$ 在参数 $\theta$ 下的基态。

**Berry 曲率。** Berry 曲率 $F$ 是 Berry 联络的外微分：
$$F = d\mathcal{A} + \mathcal{A} \wedge \mathcal{A}.$$

Berry 曲率 $F$ 是参数空间上的 2-形式，描述编码态在参数变化下的「几何响应」。

### 2.3 Berry 联络的物理意义

Berry 联络 $\mathcal{A}$ 不是「外加的」——它是编码轨道的内在几何结构。具体而言：

- $\mathcal{A}$ 的存在依赖于编码轨道的参数化——即 $\delta$ 迭代的每一步都有一个「引入角度」$\theta_n$。
- $\mathcal{A}$ 的值由 Clifford 代数的不可约表示确定——不可约表示是 Clifford 代数的刚性结构，不是人为选择。
- $\mathcal{A}$ 的积分 $\oint_\Gamma \mathcal{A}$ 是 Berry 相位——它衡量回路 $\Gamma$ 的「几何闭合性」。

因此，Berry 联络 $\mathcal{A}$ 是代数结构的内在组成部分——不是外加的微扰或外部附加量，而是编码轨道本身的几何属性。

## §3 Chern-Simons 7-形式的三项结构

### 3.1 三项分解

在 中，$\delta^8$ 回路的 Berry 相位通过 Chern-Simons 7-形式计算：
$$\gamma_{\text{Berry}} = \int_{D^8} \text{CS}_7 = \int_{D^8} (I_1 + I_2 + I_3).$$

三项分别对应编码轨道的三个子段：

| 项 | 子段 | 扇区 | 几何含义 |
|:--|:--|:--|:--|
| I₁ | Cl(0)→Cl(3) | 物质 ℳ | 半单分裂的拓扑荷 |
| I₂ | Cl(3)→Cl(5) | 因果 𝒞 | 复结构涌现的拓扑荷 |
| I₃ | Cl(5)→Cl(8) | 信息 ℐ | 终端二元性的拓扑荷 |

### 3.2 Berry 联络 $\mathcal{A}$ 作为代数结构的内在组成部分

需要澄清一个重要概念：Berry 联络 $\mathcal{A}$ 是代数结构的内在组成部分，而非外加的微扰或外部附加量。Clifford 代数 $\text{Cl}(n)$ 的定义（$e_i^2 = -1$，$e_i e_j = -e_j e_i$）是刚性的，不需要任何外部附加。

Berry 联络 $\mathcal{A}$ 是编码轨道的**几何属性**——它描述编码态在参数空间中的「几何响应」。$\mathcal{A}$ 的存在不改变 Clifford 代数的代数结构，但它提供了衡量回路闭合性的工具（Berry 相位 $\oint_\Gamma \mathcal{A}$）。

因此，正确的表述是：**Berry 相位是代数结构的内在组成部分**——它从编码轨道的几何属性自然涌现，不是外加的微扰或外部附加量。

## §4 圆满性判据

**定理 0.4.4.01（圆满性判据）。** 设 $\Gamma$ 是编码轨道上的一条闭合回路。$\Gamma$ 对应一个圆满定理（已完成的结构）当且仅当
$$\oint_\Gamma \mathcal{A} = 2\pi n, \quad n \in \mathbb{Z}.$$

其中 $\mathcal{A}$ 是编码轨道上的 Berry 联络。

**证明（完整：必要性充分性）。**

**必要性。** 假设 $\Gamma$ 对应一个已完成的结构（圆满定理）。则该结构在 $\delta$ 迭代中是自洽的——它在后续步进中不被破坏。

自洽性意味着 $\Gamma$ 的 Berry 相位是拓扑不变量——在参数空间的连续形变下不变。这是因为：

1. 自洽的结构可以被「平滑地」嵌入 $\delta$ 迭代——不需要跳跃或断裂。
2. Berry 相位在平滑形变下不变（Berry 相位的几何性）。
3. 因此，$\Gamma$ 的 Berry 相位只依赖于 $\Gamma$ 的拓扑类，不依赖于具体路径。

Berry 相位的唯一可能的拓扑量子化值为 $2\pi n$（$n \in \mathbb{Z}$），因为 Berry 相位模 $2\pi$ 是规范的——$e^{i\gamma}$ 中 $\gamma$ 和 $\gamma + 2\pi$ 给出相同的物理态。因此，Berry 相位的拓扑量子化值为 $2\pi n$。

故 $\oint_\Gamma \mathcal{A} = 2\pi n$。

**充分性。** 假设 $\oint_\Gamma \mathcal{A} = 2\pi n$（$n \in \mathbb{Z}$）。则 $\Gamma$ 的 Berry 相位是整数倍 $2\pi$——这意味着回路在量子意义下闭合（$e^{i \cdot 2\pi n} = 1$）。

闭合回路对应自洽的结构——该结构可以被纳入 $\delta$ 迭代而不产生矛盾。这是因为：

1. 闭合的 Berry 相位意味着编码态在回路后回到自身（带 $2\pi n$ 的整体相位，这是平凡的）。
2. 回到自身意味着结构没有「未闭合的余项」——所有部分都自洽地连接。
3. 因此，$\Gamma$ 对应的结构是自洽的——它是圆满的。

故 $\Gamma$ 对应一个圆满定理。∎

### 4.1 判据的操作含义

圆满性判据不仅是一个数学定理——它是推导链的**筛选工具**：

1. 在编码轨道上构造一条候选回路 $\Gamma$。
2. 计算 $\oint_\Gamma \mathcal{A}$。
3. 如果 $= 2\pi n$（$n \in \mathbb{Z}$），则 $\Gamma$ 对应的定理是圆满的——推导链完成。
4. 如果 $\neq 2\pi n$，则 $\Gamma$ 对应的定理不圆满——推导链有缺口，需要补充。

**4.1.1 圆满性判据与 S_total = 0 的等价性**。圆满性判据 $\oint_\Gamma \mathcal{A} = 2\pi n$ 与总作用量为零（S_total = 0）是等价陈述：

- 当 $n = 1$，$\oint_{\Gamma_8} \mathcal{A} = 2\pi$，对应 $\delta^8$ 最大圆满回路。此时 $S_{\text{total}} \equiv 2\pi \equiv 0 \pmod{2\pi}$。
- 当 $n = 0$，$\oint_\Gamma \mathcal{A} = 0$，对应平凡回路（无编码结构）。
- 当 $n > 1$，对应多重圆满回路（$\delta^8$ 的整数倍）。

因此，圆满性判据可以等价地表述为：**编码轨道上的闭合回路 $\Gamma$ 对应圆满定理，当且仅当该回路上的总作用量为零（模 $2\pi$）。** 这一等价性将 0.1 的语义概念（互扼平衡 = S_total = 0）与 0.3 的拓扑计算（Berry 相位 = 2π）统一起来。圆满性判据是 S_total = 0 在编码轨道上的拓扑实现。

这意味着：**不是所有数学推导都被允许**。只有 Berry 相位闭合的推导链才是有效的。

### 4.2 圆满性判据的操作流程

将圆满性判据作为推导链筛选工具的具体操作流程如下：

**步骤1：候选回路构造。** 在编码轨道上，根据物理或数学问题构造一条候选回路 $\Gamma$。$\Gamma$ 由若干 $\delta$ 步进组成，每步对应一个 Clifford 代数 $\text{Cl}(n)$。

**步骤2：Berry 联络计算。** 计算 $\Gamma$ 上的 Berry 联络 $\mathcal{A}$。这需要：
- 确定 $\Gamma$ 的参数化（每步的角度 $\theta_n$）。
- 构造编码态 $|\psi(\theta)\rangle$（$\text{Cl}(n)$ 的不可约表示）。
- 计算 $\mathcal{A} = \langle \psi | d\psi \rangle$。

**步骤3：Berry 相位积分。** 计算 $\oint_\Gamma \mathcal{A}$。这通常通过 Chern-Simons 形式 $\int_{D} \text{CS}$ 完成（Stokes 定理），其中 $D$ 是以 $\Gamma$ 为边界的盘。

**步骤4：圆满性判定。** 检查 $\oint_\Gamma \mathcal{A}$ 是否为 $2\pi n$（$n \in \mathbb{Z}$）：
- 是 → $\Gamma$ 对应的定理是圆满的，推导链完成。
- 否 → $\Gamma$ 对应的定理不圆满，推导链有缺口。

**步骤5：缺口修补（如需要）。** 如果 $\Gamma$ 不圆满，需要补充缺失的步进，使得新的回路 $\Gamma'$ 满足 $\oint_{\Gamma'} \mathcal{A} = 2\pi n$。

### 4.3 与 Bott 周期的关系

$\delta^8$ 回路本身满足圆满性判据：
$$\oint_{\delta^8} \mathcal{A} = 2\pi \quad (n = 1).$$

因此 $\delta^8$ 回路是最大的圆满回路——整个 Bott 周期是一个圆满定理。七层截断是这一圆满定理的结构表达。

## §5 圆满性的层级

圆满回路可以嵌套——大回路中包含小回路：

```
δ⁸ 回路（最大圆满回路，n=1）
├── Cl(0)→Cl(3)→Cl(0) 子回路（物质界圆满性）
├── Cl(3)→Cl(5)→Cl(3) 子回路（因果界圆满性）
└── Cl(5)→Cl(8)→Cl(5) 子回路（信息界圆满性）
```

每个子回路的 Berry 相位必须是 $2\pi n$ 的整数倍才能构成圆满定理。这确保了每个扇区的推导链也是自洽的。



### 5.1 圆满性层级嵌套的详细结构

圆满性层级嵌套不仅限于三扇区——可以进一步细分：

```
δ⁸ 回路（最大圆满回路，n=1，Berry = 2π）
├── 物质界子回路（3 步：E₁, E₂, E₃）
│ ├── E1 子回路
│ ├── E2 子回路
│ └── E3 子回路
├── 因果界子回路（2 步：E₄, E₅）
│ ├── E4 子回路
│ └── E5 子回路
└── 信息界子回路（2 步：E₆, E₇）
 ├── E6 子回路
 └── E7 子回路
```

**层级嵌套的规律。**

- 完整的 $\delta^8$ 回路（7 步加闭合步）满足 $\oint \mathcal{A} = 2\pi$——圆满性判据成立。

这意味着：**圆满性是整体性质，不能从部分推出**。

### 5.2 圆满性判据作为推导链筛选工具的意义

圆满性判据作为推导链筛选工具的意义：

1. **约束推导方向**：不是所有数学推导都被允许——只有 Berry 相位闭合的推导链才是有效的。这约束了从 $\delta$ 到物理常数的推导路径。
2. **确保自洽性**：圆满性判据自动筛选掉不自洽的推导——不自洽的推导链不会闭合，Berry 相位不为 $2\pi n$。
3. **层级结构**：圆满性有层级——大回路包含小回路，但小回路不一定圆满。这反映了物理世界的层级结构（基本粒子→原子→分子→...）。
4. **唯一性**：在同构意义下，圆满的推导链是唯一的——因为编码轨道在每一步只有一个自洽的候选。这意味着从 $\delta$ 到物理常数的推导路径是唯一的。
