## §1 物质界的代数基础

### 1.1 Cl(3) 的半单分裂

物质界的代数基础是 Cl(3) ≅ ℍ ⊕ ℍ（引理 0.2.2.01）。体积元 $\omega_3 = e_1 e_2 e_3$ 满足 $\omega_3^2 =1$，产生投影：

$$P_+ = \frac{1+\omega_3}{2}, \quad P_- = \frac{1 - \omega_3}{2}.$$

两个投影将 Cl(3) 分为两个独立的四元数子代数：

$$\text{Cl}(3) = P_+ \text{Cl}(3) \oplus P_- \text{Cl}(3) \cong \mathbb{H} \oplus \mathbb{H}.$$

### 1.2 半单分裂的几何实现

半单分裂不仅是代数事实，也是几何实现。将 Cl(3) 的生成元 $e_1, e_2, e_3$ 选取为 $S^3(r_M)$ 上三个相互正交的法向量场，则体积元 $\omega_3 = e_1 e_2 e_3$ 在 $S^3$ 的每一点处给出一个法向 3-形式。由于 $S^3$ 在 $\mathbb{R}^4$ 中的法丛是一维的，$\omega_3$ 实际上定义了 $S^3$ 上的一个**整体手征结构**。

具体地，将 $\mathbb{R}^4$ 的坐标记为 $(x_1, x_2, x_3, x_4)$，并定义两个复结构：

$$J_+ : (x_1, x_2, x_3, x_4) \mapsto (-x_2, x_1, -x_4, x_3),$$
$$J_- : (x_1, x_2, x_3, x_4) \mapsto (-x_2, x_1, x_4, -x_3).$$

可以验证 $J_+^2 = J_-^2 = -\text{id}$，且 $J_+ J_- = -J_- J_+$。这两个复结构分别与 $P_+, P_-$ 对易，从而将 $S^3$ 实现为两个四元数子代数所对应的几何分支。

半单分裂的几何意义在于：$S^3(r_M)$ 在 $\mathbb{R}^4$ 中容许两个不等价的复结构，它们分别对应右手与左手 Weyl 旋量的几何载体。这与 Bott 周期表中 Cl(3) 的实型结构 $Cl_{3,0} \cong \mathbb{H} \oplus \mathbb{H}$ 一致。

### 1.3 螺旋性分裂

半单分裂的两个直和项对应物质的两种螺旋性：

| 直和项 | 投影 | 螺旋性 | 物理对应 |
| :----------------- | :---- | :-: | :--- |
| $P_+ \text{Cl}(3)$ | $P_+$ | 右手 | 右手粒子 |
| $P_- \text{Cl}(3)$ | $P_-$ | 左手 | 左手粒子 |

**定理 3.1.1.01（螺旋性分裂定理）。** 物质界的左手和右手螺旋性由 Cl(3) 的半单分裂唯一确定，不引入额外参数。

**证明。** $\omega_3^2 =1$ 是 Clifford 代数的刚性性质——$\omega_3$ 的符号不可调节。投影 $P_{\pm}$ 是 $\omega_3$ 的代数函数，不存在连续参数来改变分裂方式。因此螺旋性分裂是代数刚性的。∎

### 1.4 不可约表示

Cl(3) 的不可约表示维数 $\rho_3 = 4$，但半单分裂将其分为两个 2 维表示：

$$\rho_3^{(+)} = 2, \quad \rho_3^{(-)} = 2.$$

这两个 2 维表示对应 Weyl 旋量——左手和右手 Weyl 旋量各 2 个分量。这是物质界作为「最小完整旋量载体」的代数根据：Cl(3) 是编码轨道上第一个同时容纳左、右手 Weyl 旋量的 Clifford 代数。

## §2 法向几何

### 2.1 S³ 球面

物质界的法向几何由三维球面 $S^3(r_M)$ 描述：

$$S^3(r_M) = \{(x_1, x_2, x_3, x_4) \in \mathbb{R}^4 : x_1^2 + x_2^2 + x_3^2 + x_4^2 = r_M^2\}.$$

$S^3$ 是紧致、单连通、具有常曲率 $6/r_M^2$ 的流形。在共扼谱几何中，$S^3$ 不是任选的背景——它是 Cl(3) 不可约表示空间 $\mathbb{R}^4$ 的「单位球」，由代数结构唯一确定。

### 2.2 法向投影算子的构造

法向投影是物质界几何的核心构造。给定 $S^3(r_M)$ 上的切丛 $TS^3$ 和法丛 $NS^3$，法向投影算子 $\Pi_N$ 将任意向量场 $V \in \Gamma(T\mathbb{R}^4|_{S^3})$ 投影到法丛：

$$\Pi_N(V) = \langle V, \hat{n} \rangle \hat{n},$$

其中 $\hat{n} = x / r_M$ 是 $S^3$ 的单位外法向。法丛 $NS^3$ 在 $\mathbb{R}^4$ 中是一维的，由 $\hat{n}$ 张成。

将法向投影与 Clifford 乘法结合，定义**法向 Clifford 乘子**：

$$\hat{n}_{\text{Cl}} = \sum_{i=1}^{4} \frac{x_i}{r_M} \gamma_i \in \text{Cl}(4),$$

其中 $\gamma_i$ 是 $\mathbb{R}^4$ 上的标准 Dirac 矩阵。$\hat{n}_{\text{Cl}}$ 满足 $\hat{n}_{\text{Cl}}^2 =1$，因此诱导出 $S^3$ 上旋量丛的螺旋性分裂：

$$\Sigma_\pm = \frac{1 \pm \hat{n}_{\text{Cl}}}{2} \cdot \Sigma.$$

这正是 §1.2 中 $P_\pm$ 在几何层面的实现——代数投影 $P_\pm$ 与几何投影 $\Sigma_\pm$ 通过法向 Clifford 乘子 $\hat{n}_{\text{Cl}}$ 等同。

**命题 3.1.2.01（法向-代数对应）。** 法向 Clifford 乘子 $\hat{n}_{\text{Cl}}$ 与体积元 $\omega_3$ 在旋量表示下共轭：

$$\hat{n}_{\text{Cl}} = U^{-1} \omega_3 U,$$

其中 $U$ 是 $\text{Cl}(4) \to \text{Cl}(3)$ 的限制映射。因此，几何上的法向投影与代数上的半单分裂是同一结构的两种描述。

### 2.3 半径的锁定

物质界的半径 $r_M$ 由互锁常数锁定。三个扇区的半径比为：

$$r_M : r_C : r_I = 1 : \frac{1}{\sqrt{3}} : \frac{1}{\sqrt{6}}.$$

这一比例由三个结构常数 $\Lambda = 3$、$\Delta\Theta = 5$、$k_0 = 2$ 联合确定——不可调节。

**定理 3.1.2.02（半径锁定定理）。** 三个扇区的半径比 $r_M : r_C : r_I = 1 : 1/\sqrt{3} : 1/\sqrt{6}$ 由互锁常数唯一确定。

**证明。**

- $r_M = 1$（归一化基准）
- $r_C = 1/\sqrt{\Lambda} = 1/\sqrt{3}$（$\Lambda = 3$ 的半单分裂使因果界半径缩小 $\sqrt{3}$ 倍）
- $r_I = 1/\sqrt{\Lambda k_0} = 1/\sqrt{3 \times 2} = 1/\sqrt{6}$（信息界的半径由 $\Lambda$ 和 $k_0$ 联合确定）

比例的精确值由 Bott 周期表中各步的不可约表示维数增长率确定。∎

> **注（半径比与 χ 的关系）**：半径比 $r_M:r_C:r_I = 1:1/\sqrt{3}:1/\sqrt{6}$ 由结构常数 $\Lambda=3$、$k_0=2$ 确定，与累积拉伸因子 $\chi=(8,9,1)$ 是不同的几何量。$\chi$ 描述编码轨道上各扇区的「累积拉伸」（来自 Bott 周期步数与不可约表示维数的乘积），而半径比描述各扇区法向球面 $S^3$ 的「紧凑度」（来自半单分裂的步数）。两者通过 $M_5 = T \cdot \text{diag}(\chi)$ 的不动点间接关联——$\chi$ 影响 Birkhoff 混合后的终端权重 $\sigma^*$，而 $\sigma^*$ 通过 Born 法则与谱间隙 $\Delta\lambda \propto 1/r$ 联系——但不存在简单的 $r_i \propto \chi_i$ 或 $r_i \propto 1/\chi_i$ 关系。

### 2.4 标量曲率

$S^3(r_M)$ 的标量曲率为：

$$R_M = \frac{6}{r_M^2} = 6.$$

三个扇区的标量曲率：

| 扇区 | 半径 | 标量曲率 |
|:---|:---:|:---:|
| ℳ | $r_M = 1$ | $R_M = 6$ |
| 𝒞 | $r_C = 1/\sqrt{3}$ | $R_C = 18$ |
| ℐ | $r_I = 1/\sqrt{6}$ | $R_I = 36$ |

因果界的曲率是物质界的 3 倍，信息界的曲率是物质界的 6 倍——这反映了扇区在编码轨道中的「紧凑度」递增。

### 2.5 法向联络

法丛 $NS^3$ 虽然是一维的，但仍然承载一个平凡的 $U(1)$ 联络。在共扼谱几何中，这个法向 $U(1)$ 联络对应物质界的**电磁相位**：

$$\nabla^{\text{normal}} = di A_M,$$

其中 $A_M$ 是法向联络的势函数。由于 $S^3$ 是单连通的，$A_M$ 在整体上可以取为零，但在局部坐标系下仍贡献相位因子。法向联络的曲率为零——这与电磁场的整体无曲率（无磁单极）一致。

## §3 物质场的 Dirac 算子

### 3.1 Dirac 算子的定义

物质界的 Dirac 算子 $\mathcal{D}_M$ 作用于 $S^3(r_M)$ 上的旋量场：

$$\mathcal{D}_M = \sum_{i=1}^{3} e_i \cdot \nabla_{e_i},$$

其中 $e_i$ 是 Cl(3) 的生成元，$\nabla$ 是 $S^3$ 上的 Levi-Civita 联络。等价地，利用法向投影，可以将 $\mathcal{D}_M$ 写为 $\mathbb{R}^4$ 上 Dirac 算子 $\mathcal{D}_{\mathbb{R}^4}$ 在 $S^3$ 上的切向限制：

$$\mathcal{D}_M = \Pi_T \circ \mathcal{D}_{\mathbb{R}^4} \circ \Pi_T,$$

其中 $\Pi_T = 1 - \Pi_N$ 是切向投影。这一形式表明 $\mathcal{D}_M$ 完全由法向几何决定——法向投影 $\Pi_N$ 是质量算符的几何原型。

### 3.2 谱

$S^3$ 上 Dirac 算子的谱是离散的：

$$\lambda_n = \pm \frac{n+1}{r_M}, \quad n = 0, 1, 2, \dots$$

每个本征值的重数为 $(n+1)(n+2)$。基态（$n=0$）的本征值为 $\lambda_0 = \pm 1/r_M = \pm 1$，重数为 2——对应两个 Weyl 旋量分量。

### 3.3 谱间隙

**定理 3.1.3.01（物质界谱间隙）。** 物质界的基态谱间隙为：

$$\Delta\lambda_M = |\lambda_0^+ - \lambda_0^-| = \frac{2}{r_M} = 2.$$

由 Born 法则（定理 1.3.4.01），这与编码权重 $\sigma_M$ 的关系为：

$$\Delta\lambda_M \propto \sqrt{\sigma_M}.$$

**证明。** Dirac 算子 $\mathcal{D}_M$ 在 $S^3(r_M)$ 上的谱由球面调和分析完全确定。基态由 $n = 0$ 的 Weyl 旋量给出，本征值为 $\pm 1/r_M$。间隙 $2/r_M$ 是 Cl(3) 不可约表示的最小「能量差」，反映半单分裂将左、右手旋量分离为两个独立能级。间隙的非零性是物质界具有质量的几何前提。∎

### 3.4 谱的对称性与螺旋性

谱 $\lambda_n = \pm (n+1)/r_M$ 的正负对称性对应螺旋性翻转：$\lambda_n^+$ 对应右手 Weyl 旋量，$\lambda_n^-$ 对应左手 Weyl 旋量。当物质界与因果界解耦（$\theta_\tau \to 0$）时，正负谱严格对称，质量本征态是螺旋性本征态——质量为零。

当 ℳ-𝒞 耦合开启（$\theta_\tau \neq 0$）时，triality 3-循环 $\tau$ 混合左右螺旋性，正负谱不再对称，质量本征态成为左右旋量的线性组合——质量涌现。这一机制在第 3.2、3.3 节中详细展开。

## §4 ℳ 扇区的编码权重

### 4.1 初始权重

物质界的初始编码权重由 pullback 初始化（定理4.19d）确定：

$$\sigma_M^{(3)} \propto \frac{1}{\chi_M^2},$$

其中 $\chi_M = 8$ 是物质界的累积拉伸因子。因此：

$$\sigma_M^{(3)} \propto \frac{1}{64}.$$

### 4.2 终端权重

经 $M_5$ Birkhoff 混合矩阵（定理 2.3.7.02）的自洽迭代，物质界的终端权重为：

$$\sigma_M^* \approx 0.777912.$$

这是三个扇区中最大的权重——物质界在编码权重中占主导地位，这与物质在物理世界中的主导角色一致。

### 4.3 物理含义

$\sigma_M^* \approx 0.777912$ 意味着：

1. 物质界贡献了约 78% 的编码信息
2. 物质界的谱间隙最大——物质场的能级间距最大
3. 物质界在代数作用量 $S(\sigma)$ 中的个体贡献 $1/\sigma_M \approx 1.285$ 最小——物质场是「最稳定」的

### 4.4 代数归一化约束

物质界权重 $\sigma_M^*$ 与代数归一化条件 $2 p C^3 + C^2 = 1$（$p = \sqrt{\sigma_M \sigma_C \sigma_I}$）相容。代入不动点：

$$p^* = \sqrt{0.777912 \times 0.210603 \times 0.011484} \approx 0.0434,$$

对应的归一化常数 $C^* \approx 0.9607$（代数归一化定理 1.4.3.01）。这一约束将物质界与因果、信息界以非线性方式绑定——任何单一扇区的权重变化都会通过 $C$ 传播到其他扇区。

## §5 质量算符的代数定义

### 5.1 质量算符的构造

在共扼谱几何中，质量不是外部参数，而是几何结构的算符输出。定义**质量算符** $\hat{M}$ 为法向 Clifford 乘子与 Dirac 算子的复合：

$$\hat{M} = \hat{n}_{\text{Cl}} \cdot \mathcal{D}_M\mathcal{D}_M \cdot \hat{n}_{\text{Cl}}.$$

由于 $\hat{n}_{\text{Cl}}^2 =1$ 且 $\hat{n}_{\text{Cl}}$ 与 $\mathcal{D}_M$ 反交换（法向与切向的正交性），上述反对称组合为零。因此，质量算符的正确定义应取**对称组合**：

$$\hat{M} = \frac{1}{2} \{\hat{n}_{\text{Cl}}, \mathcal{D}_M\} + \text{Cl}(3) \text{ 结构修正}.$$

在 Cl(3) 半单分裂下，$\hat{M}$ 的本征值由谱间隙 $\Delta\lambda_M$ 与编码权重 $\sigma_M$ 联合确定：

$$m_M = K \cdot \Delta\lambda_M \cdot \sqrt{\sigma_M^*} = K \cdot \frac{2}{r_M} \cdot \sqrt{0.777912},$$



其中 $K$ 是由 $\sin^3\theta_M$ 给出的几何因子（详见第 3.2 节）。质量算符的这种构造保证了质量是**法向几何与代数权重的乘积**——纯粹由 ℳ 扇区的结构决定。

### 5.2 质量算符与螺旋性

质量算符 $\hat{M}$ 与螺旋性投影 $P_\pm$ 的对易关系决定了质量的螺旋性结构。由于 $\hat{n}_{\text{Cl}}$ 在 $P_\pm$ 下分别取本征值 $\pm 1$，质量算符在对角基下分裂为：

$$\hat{M} = \hat{M}_+ \cdot P_+ + \hat{M}_- \cdot P_-.$$

在 ℳ 扇区自洽不动点处，$\hat{M}_+ = \hat{M}_-$——左右手质量相等，这就是质量的本征态为 Dirac 旋量的几何原因。当 ℳ-𝒞 耦合开启时，$\hat{M}_+ \neq \hat{M}_-$，给出 Majorana 质量分裂的几何条件。

### 5.3 质量算符的谱

质量算符 $\hat{M}$ 的谱与 Dirac 算子 $\mathcal{D}_M$ 的谱一一对应：

| Dirac 本征值 | 质量算符本征值 | 物理对应 |
|:---:|:---:|:---|
| $\lambda_0 = \pm 1/r_M$ | $m_0 = K \cdot 2/r_M \cdot \sqrt{\sigma_M^*}$ | 基态质量 |
| $\lambda_1 = \pm 2/r_M$ | $m_1 = K \cdot 4/r_M \cdot \sqrt{\sigma_M^*}$ | 第一激发态 |
| $\lambda_n = \pm (n+1)/r_M$ | $m_n = K \cdot 2(n+1)/r_M \cdot \sqrt{\sigma_M^*}$ | 第 $n$ 激发态 |

质量谱的离散性与 Dirac 谱的离散性同源——都来自 $S^3$ 的紧致性。激发态质量与基态质量之比为 $m_n / m_0 = n+1$，这一等间距结构在呼吸模式的调制下产生非等间距的三代轻子谱（详见第 3.5 节）。

### 5.4 与后续章节的衔接

质量算符 $\hat{M}$ 的本征值表达式 $m_M = K \cdot \Delta\lambda_M \cdot \sqrt{\sigma_M^*}$ 中，几何因子 $K = \sin^3\theta_M$ 的具体推导、常数 $K$ 的数值确定，以及三代轻子质量比的计算，将在第 3.2 节（质量生成动力学）中给出。法向几何结构是质量生成的「硬件」，而 Born 法则与 Birkhoff 混合的自洽迭代则是质量生成的「软件」——两者共同确定物质粒子的完整质量谱。

需要强调的是，质量算符 $\hat{M}$ 的构造完全依赖 ℳ 扇区的法向几何——法向 Clifford 乘子 $\hat{n}_{\text{Cl}}$ 与 Dirac 算子 $\mathcal{D}_M$ 的对称组合给出了质量的代数定义。这一构造由本区域属性确定，完全由 Cl(3) 半单分裂与 $S^3$ 球面几何确定。

## §6 Birkhoff 联合谱分解

单粒子质量算符谱（§5.3）由 ℳ 扇区法向几何完全确定。当多个粒子经扇区联合（ℳ𝒞扇区联合或 ℳ扇区同步）耦合时，代际质量标度 $C_n$ 由联合系统的谱分解确定。本节建立 Birkhoff 联合谱分解的基础定理：联合作用量 Hessian 的准块对角结构、行列式因子化、谱矩主导判据（扇区联合类型的谱论表述）、信息界 Dirac 谱二稳态与 $2^N$ 标度律。这些定理是三代轻子质量闭合（3.10 §8.12–8.14）与夸克偶素谱（3.8）的公共谱论基础。

设 $N$ 个粒子处于 ℳ 扇区同步（$\theta_M^{(i)} \equiv \theta_M$），联合代数作用量取和的形式（3.10 定理 6.5.1.01）：

$$S_{\text{joint}} = \sum_{i=1}^{N} S^{(i)} + \sum_{i<j} W_{ij},$$

其中 $S^{(i)}$ 是第 $i$ 粒子的代数作用量（定理 1.6.4.01），$W_{ij} = b'(\Delta\theta_I^{(i)} - \Delta\theta_C^{(j)})(\Delta\theta_I^{(j)} - \Delta\theta_C^{(i)})$ 是最近邻信息界耦合（3.10 §3.1），$\Delta\theta_\alpha^{(i)} = \theta_\alpha^{(i)} - \theta_\alpha^0$ 是相对构型A的偏移。

**定理 3.1.6.01（Birkhoff联合谱分解：准块对角结构）。** 在 ℳ 扇区同步约束下，$S_{\text{joint}}$ 在 $(\theta_C^{(i)}, \theta_I^{(i)})_{i=1}^N$ 子空间上的 Hessian $H_{\text{eff}}$（$2N \times 2N$）具有准块对角结构：

$$H_{\text{eff}} = \bigoplus_{i=1}^{N} H_i + \Delta H,$$

其中 $H_i$ 是第 $i$ 粒子的 $2 \times 2$ 对角块（$\theta_M$ 同步约束下 $(\theta_C, \theta_I)$ 方向的 Hessian），$\Delta H$ 是耦合块。性质：

- (i) $\|\Delta H\| \leq 2Nb'$；
- (ii) 扰动比 $\|\Delta H\|/\min_i\|H_i\| \leq 2Nb'/\lambda_1^{\text{eff}} \approx N \cdot 0.44\%$（$\lambda_1^{\text{eff}} = 391.05$ rad⁻²，0.8 §3.1；$N=3$ 时为 1.3%）；
- (iii) Gershgorin：$H_{\text{eff}}$ 的每个本征值落在对角块 $H_i$ 的 Gershgorin 圆盘之并内——联合谱由单粒子块谱主导。

**证明。** 由最近邻耦合定理（3.10 定理 3.10.8.08），$W_{13} \approx 0$，耦合仅存在于相邻粒子之间。$W_{ij}$ 是双线性形式，其 Hessian 的非零矩阵元为交叉项系数 $\pm b'$，故 $\|\text{Hess}(W_{ij})\| \leq b'$；每粒子至多两个最近邻，耦合块总范数 $\|\Delta H\| \leq \sum_{i<j}\|\text{Hess}(W_{ij})\| \leq 2Nb'$。单粒子块的谱间隙方向曲率由 $\lambda_1^{\text{eff}} = 391.05$ rad⁻² 给出（0.8 §3.1，Birkhoff 不动点邻域的主导本征值），$\min_i\|H_i\| \geq \lambda_1^{\text{eff}}$；代入 $b' = 0.867$（7.12 §6，定理 2.3.7.02）得每粒子扰动比 $2b'/\lambda_1^{\text{eff}} = 0.44\%$。由 Gershgorin 圆盘定理，联合谱位于对角块圆盘之并内。∎

**定理 3.1.6.02（行列式因子化）。** 至 $O(Nb'/\lambda_1^{\text{eff}})$ 阶：

$$\det(H_{\text{eff}}) = \prod_{i=1}^{N} \det(H_i) \cdot \bigl(1 + O(Nb'/\lambda_1^{\text{eff}})\bigr).$$

**证明。** 记 $D = \bigoplus_i H_i$，$H_{\text{eff}} = D + \Delta H$。$\det(H_{\text{eff}}) = \det(D) \cdot \det(I + D^{-1}\Delta H)$。由定理 3.1.6.01，$\|D^{-1}\Delta H\| \leq \|D^{-1}\| \cdot \|\Delta H\| \leq 2Nb'/\lambda_1^{\text{eff}}$。$\det(I + X) = 1 + \text{tr}\,X + O(\|X\|^2)$，且 $|\text{tr}(D^{-1}\Delta H)| \leq 2N\|D^{-1}\Delta H\|$，故 $\det(I + D^{-1}\Delta H) = 1 + O(Nb'/\lambda_1^{\text{eff}})$。∎

对 $N=3$：$Nb'/\lambda_1^{\text{eff}} = 0.00665$，因子化修正约 1.3%。

**定理 3.1.6.03（谱矩主导：刚度比判据）。** 设 $R = H_{CC}/H_{MM}$ 为 $\theta_C$ 与 $\theta_M$ 方向的曲率刚度比。联合系统的信息容量由谱矩主导区决定：

- (i) **迹主导（$R \gg 1$）**：$\text{Tr}(H_{\text{eff}}) \approx N \cdot H_{CC}$，容量线性叠加——联合类型为 **ℳ𝒞 扇区联合**；
- (ii) **行列式主导（$R \sim O(1)$）**：$\det(H_{\text{eff}}) \approx \prod_i \det(H_i)$（定理 3.1.6.02），容量按乘积叠加——联合类型为 **ℳ 扇区同步**。

刚度比判据与谱矩主导等价：$R \gg 1 \iff$ 迹主导，$R \sim O(1) \iff$ 行列式主导。构型A（基态）处 $R = a'/\lambda_1^{\text{eff}} = 29475.4/391.05 = 75.4$（$a' = H_{CC}$，7.12 §6）——迹主导；双方激发态处 $S$ 函数偏离构型A驻点，$\theta_C$ 方向刚度降至 $\lambda_1^{\text{eff}}$ 量级——$R \sim O(1)$——行列式主导。两种联合类型对应谱矩主导区的切换。

**证明。** 谱矩：$\text{Tr}(H_{\text{eff}}) = \sum_i \text{Tr}(H_i) + \text{tr}(\Delta H)$——$H_{CC}$ 主导对角元时迹由 $\theta_C$ 方向贡献；$\det(H_{\text{eff}})$ 由定理 3.1.6.02 因子化。信息容量-谱矩对偶：迹主导时容量 $\propto (\text{Tr})^{1/2}$（线性叠加），行列式主导时容量 $\propto (\det)^{1/2}$（乘积叠加，D-最优）。构型A数值（7.12 §6）：$H_{MM} = \lambda_1^{\text{eff}} = 391.05$，$H_{CC} = a' = 29475.4$。∎

**推论 3.1.6.08（$C_n$ 递推统一）。** 迹主导（ℳ𝒞 扇区联合）下容量线性叠加，$N$ 层等价粒子均分——$C_n = M_{n-1}/n$；对 $n=2$：$C_2 = M_1/2$（$m_\mu$ 标度，3.10 命题H2）。行列式主导（ℳ 扇区同步）下容量乘积叠加——$C_n = 2^n M_1$（定理 3.1.6.05）；对 $n=3$：$C_3 = 8M_1$（$m_\tau$ 标度，3.10 §8.14）。两种联合类型的标度律由谱矩主导区统一——$C_n$ 递推的严格导出（3.10 P0-9、P0-10）由此封闭。

**推论 3.1.6.09（联合约束不相容）。** ℳ𝒞 扇区联合约束（$\theta_C^{(i)} = \theta_C^{(j)}$）与 ℳ 扇区同步约束（$\theta_M^{(i)} = \theta_M^{(j)}$）不能共存于同一粒子对：同时施加将连同完备性约束 $\theta_M + \theta_C + \theta_I = \pi/2$ 强制 $\theta^{(i)} = \theta^{(j)}$ 全部分量相等——联合系统退化，联合 Hessian 沿差方向出现零本征值。混合扇区联合（3.10 §8.11）因此必须采用交叠而非合并结构（3.10 §8.15）。

**定理 3.1.6.04（信息界Dirac谱二稳态）。** 信息界 Dirac 谱（§3 的 Cl(7) 推广）在扇区参数空间产生两个饱和稳定态：

- (i) **上饱和**：$\theta_I^{\text{sat}} \approx 72.53^\circ$——信息界编码容量最大（8.9 §1.1，互锁常数 $\Lambda = 3$ 约束）；
- (ii) **下饱和**：$\theta_M^{\text{sat}} \approx 72.53^\circ$——物质界编码容量最大，由代数作用量 $S(\sigma)$ 的全排列对称性（定理 1.6.4.01）经 $\theta_M \leftrightarrow \theta_I$ 对偶给出。

每个 $2 \times 2$ 块 $H_i$ 在 $(C,I)$ 平面上因此具有**二分自由度**——两个独立编码倾向（偏 $\theta_C$ 或偏 $\theta_I$），对应饱和态的两种投影选择。

**证明。** 上饱和态的存在性与数值由互锁常数 $\Lambda = 3$ 的谱约束确定（8.9 §1.1：信息场上饱和稳态 $\theta_I \sim 72.53^\circ$）。$S(\sigma) = \sum_i 1/\sin^2\theta_i + \sum_{i<j} 1/(\sin\theta_i \sin\theta_j)$ 对角度全排列不变（定理 1.6.4.01），$\theta_M \leftrightarrow \theta_I$ 对换是排列对称性的元素——下饱和态满足 $\theta_M^{\text{sat}} = \theta_I^{\text{sat}}$。约束平面 $\theta_C + \theta_I = \pi/2 - \theta_M$ 与两个饱和态交截，给出每块两个稳定编码方向。∎

> **注（数值观察与结构分解）**：$\cos\theta_I^{\text{sat}} \approx 0.3 = \Lambda/(k_0\Delta\Theta) = 3/10$（偏差 0.1%），与互锁常数 $\{2,3,5\}$ 相容。该数值具有精确的结构分解：$\sin^2\theta_I^{\text{sat}} = [(k_0\Delta\Theta)^2 - \Lambda^2]/(k_0\Delta\Theta)^2 = L(2L-1)/(k_0\Delta\Theta)^2 = 91/100$，其中 $L = 7$ 为七层截断秩（定理 0.3.3.01），$2L-1 = 13$；由零和约束 $\Lambda + k_0 - \Delta\Theta = 0$（命题（互锁性））与 $k_0 = 2$（定理 0.5.1.03）得 $k_0\Delta\Theta - \Lambda = \Delta\Theta + k_0 = 7$ 且 $k_0\Delta\Theta + \Lambda = 13$——分子 $91 = 7 \times 13$ 分解为分子共享复合 $\Delta\Theta + k_0$ 与 $k_0\Delta\Theta + \Lambda$ 的乘积，与七层截断秩 $L$ 数值重合。

**定理 3.1.6.05（$2^N$ 标度律）。** 在 ℳ 扇区同步联合（行列式主导）上，$N$ 层系统的信息容量为：

$$C_N = 2^N \cdot \eta_N \cdot M_1,$$

其中 $\eta_N$ 是块等本征值修正（命题 3.1.6.06），等本征值基准（$\eta_N = 1$）下 $C_N = 2^N M_1$。对第 $n$ 代轻子（$n \geq 2$，ℳ 扇区同步）：$C_n = 2^n M_1$。

**证明。** 信息容量-行列式对偶（D-最优）：$C_N \propto \sqrt{\det(H_{\text{eff}})}$。由定理 3.1.6.02，$\sqrt{\det(H_{\text{eff}})} = \prod_i \sqrt{\det(H_i)} \cdot (1 + O(Nb'/\lambda_1^{\text{eff}}))$。二分自由度（定理 3.1.6.04）给每块两个独立编码倾向——等本征值基准下 $\sqrt{\det(H_i)} = 2$。$N$ 块乘积：$C_N \propto 2^N$。归一化至基态标度 $C_1 = M_1$（编码轨道层级，$M_1 = K\Lambda_H S_e^{1/2} = 1.474$ GeV，3.10 §2.3）：$C_n = 2^n M_1$。∎

数值：$C_3 = 8 \times 1.474 = 11.79$ GeV，$m_\tau^{\text{th}} = C_3\sin^3\theta_M^{(3)} = 1.746$ GeV（偏差 −1.7%，3.10 §8.14）。**第四代预测**：$C_4 = 16M_1 = 23.58$ GeV，$m_4^{\text{th}} = 23.58 \times 0.1481 = 3.49$ GeV——可检验预言（3.10 开放问题 O3 由此闭合）。

**命题 3.1.6.06（块等本征值与 $\eta_N$ 修正）。** 设 $H_i$ 的本征值为 $\lambda_i^{\pm}$（$\lambda_i^+ \geq \lambda_i^-$）。等本征值条件 $\lambda_i^+ = \lambda_i^-$（块各向同性）由 ℳ 扇区同步与 $\theta_M \leftrightarrow \theta_I$ 对偶的一阶近似给出——此时 $\sqrt{\det(H_i)} = \lambda_i = 2$（二分基准）。非等本征值下，修正因子

$$\eta_N = \prod_{i=1}^{N} \frac{\sqrt{\lambda_i^+ \lambda_i^-}}{2}$$

满足 $\eta_N > 1$ 当且仅当 $\prod_i \det(H_i) > 4^N$。对三代轻子系统（$N = 3$），$m_\tau$ 残差 −1.7% 要求 $\eta_3 \approx 1.017$，即 $\prod_i \sqrt{\det(H_i)} \approx 8.14$——每块几何平均 $\sqrt{\det(H_i)} \approx 2.011$，仅高于二分基准 0.6%。精确值由 $H_i$ 的矩阵元确定（单粒子 Hessian 输入：7.12 §6）。

**证明。** 等本征值条件：$2\times2$ 块各向同性当且仅当对角元相等且非对角元为零——在 $\theta_M \leftrightarrow \theta_I$ 对偶下 $(\theta_C, \theta_I)$ 块的对角元对称，一阶近似给出等本征值。$\eta_N$ 的定义由 $\det(H_i) = \lambda_i^+\lambda_i^-$ 直接给出；$\eta_N > 1$ 的判据等价于 $\prod_i \det(H_i) > 4^N$。数值：$\eta_3 = 1.017 \iff \prod_i \sqrt{\det(H_i)} = 8 \times 1.017 = 8.14$。∎

**定理 3.1.6.07（饱和态对偶）。** 设 $\Delta = \{(\theta_M, \theta_C, \theta_I) : \theta_i \in (0, \pi/2), \theta_M + \theta_C + \theta_I = \pi/2\}$ 为扇区参数约束面，$S(\sigma) = \sum_i 1/\sin^2\theta_i + \sum_{i<j} 1/(\sin\theta_i \sin\theta_j)$ 为代数作用量，$H(\theta)$ 为 $S$ 在 $\Delta$ 上的 Hessian（以 $\theta_M, \theta_I$ 为独立坐标，$\theta_C = \pi/2 - \theta_M - \theta_I$）。则：

(i) D-最优容量 $C(\theta) = \sqrt{\det H(\theta)}$ 在 $\theta_M \leftrightarrow \theta_I$ 对换 $\tau$ 下不变：$C(\tau\theta) = C(\theta)$；

(ii) 信息界方向饱和角与物质界方向下饱和角相等：$\theta_M^{\text{sat}} = \theta_I^{\text{sat}}$。

**证明。** $S(\sigma)$ 对角度全排列不变（定理 1.6.4.01），对换 $\tau: \theta_M \leftrightarrow \theta_I$ 保持 $S(\tau\theta) = S(\theta)$。由 Hessian 的变量置换变换律，$H(\tau\theta) = P H(\theta) P^{\mathsf{T}}$，其中 $P = \begin{pmatrix} 0 & 1 \\ 1 & 0 \end{pmatrix}$ 为 $(\theta_M, \theta_I)$ 坐标的置换矩阵——$P^{\mathsf{T}}P = I$ 且 $\det P = -1$，故 $\det H(\tau\theta) = \det(P)^2 \det H(\theta) = \det H(\theta)$，即 $C(\tau\theta) = C(\theta)$——(i) 得证。方向极大在对称映射下保持：若 $C$ 沿 $\theta_I$ 方向（固定 $\theta_C$、$\theta_M$）在 $\theta_I = \theta_I^{\text{sat}}$ 取最大，则由 $C(\tau\theta) = C(\theta)$，$C$ 沿 $\theta_M$ 方向（固定 $\theta_C$、$\theta_I = \theta_I^{\text{sat}}$）在 $\theta_M = \theta_I^{\text{sat}}$ 取最大——物质界方向下饱和角 $\theta_M^{\text{sat}} = \theta_I^{\text{sat}}$——(ii) 得证。∎
