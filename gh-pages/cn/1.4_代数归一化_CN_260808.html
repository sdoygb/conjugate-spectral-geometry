1.4 代数归一化

版本: 260808

摘要

$$\sum_i \sigma_i = \sum_i c_i^2 = 1$$ 是 Cl(3) 代数的定理 1.3.2.02（本文 §2 给出重证）。

§1 引言与问题

$$\theta_M + \theta_C + \theta_I = \frac{\pi}{2}.$$

这是一个超越约束——它涉及 $\arcsin$ 函数，无法用代数（多项式）方法精确求解。超越约束的存在意味着推导链中存在不可代数化的步骤。

1.1 问题

超越约束导致：
1. 推导链中出现超越函数，无法用纯代数方法验证
2. 数值求解引入浮点误差，影响精确性
3. 理论结构不自洽——代数框架中不应出现超越约束

§2 扇区权重归一化 $\sum\sigma_i = 1$ 的代数证明

2.1 $\mathrm{Cl}(3)$ 扇区分解与投影强度

设 $\mathrm{Cl}(3)$ 为三维欧氏空间的 Clifford 代数，同构于 $M_2(\mathbb{C})$（二阶复矩阵环）。其三个生成元 $e_1, e_2, e_3$ 满足 Clifford 关系：
$$e_i e_j + e_j e_i = 2\delta_{ij}, \quad i,j = 1,2,3.$$

左乘表示。 取 $\mathrm{Cl}(3) \cong M_2(\mathbb{C})$ 在 $\mathbb{C}^2 \cong \mathbb{R}^4$ 上的标准表示。三个生成元的左乘作用给出 $\mathbb{R}^4$ 上的实线性映射 $L_1, L_2, L_3$（即 Pauli 矩阵的实化）：
取 Cl(0,3) $\cong \mathbb{H} \oplus \mathbb{H}$ 在 $\mathbb{R}^4 \cong \mathbb{H}$ 上的四元数左乘表示。三个生成元的左乘作用给出 $\mathbb{R}^4$ 上的实线性映射 $L_1, L_2, L_3$（即四元数 $i, j, k$ 的左乘）：
$$L_i^2 = -\text{id}, \quad L_i L_j + L_j L_i = -2\delta_{ij}\,\text{id}.$$
这三个算子构成 $\mathrm{Cl}(3)$ 的不可约表示，编码了三个扇区（$M, C, I$）的代数结构。

秩-2 正交投影。 编码空间中的全息投影由秩-2 正交投影 $P: \mathbb{R}^4 \to V$（$\dim V = 2$）描述。投影 $P$ 选取 $\mathbb{R}^4$ 中的一个二维平面 $V$，代表三个扇区联合覆盖的编码子空间。

2.2 投影强度恒等式

引理 1.4.2.01（投影强度）。 对任意秩-2 正交投影 $P$，存在实数 $c_1, c_2, c_3$ 使得
$$P L_i P = c_i \cdot J, \quad i = 1,2,3,$$
其中 $J$ 是平面 $V$ 上由 $\mathrm{Cl}(3)$ 体积元 $\omega = e_1 e_2 e_3$ 诱导的唯一复结构（$J^2 = -\mathrm{id}_V$）。

证明。 平面 $V$ 作为 $\mathbb{R}^4$ 的二维定向子空间，由 $\mathrm{Cl}(3)$ 的体积元诱导一个殆复结构 $J$。算子 $L_i$ 在 $V$ 上的压缩 $PL_iP$ 是 $V$ 上的线性算子；由于 $\dim V = 2$，$V$ 上的反自伴算子空间是一维的，由 $J$ 张成。因此 $PL_iP$ 必为 $J$ 的标量倍。设 $PL_iP = c_i J$，标量 $c_i$ 即为投影强度。∎

编码权重与投影强度。 编码权重 $\sigma_i$ 定义为投影强度的平方：
$$\sigma_i = c_i^2, \quad i = M, C, I.$$
这一定义确保 $\sigma_i \geq 0$，且 $\sigma_i$ 衡量扇区 $i$ 在投影 $P$ 下的编码强度。

2.3 扇区权重归一化（定理 1.3.2.02 的代数重证）

定理 1.3.2.02（扇区权重归一化）。 在 $\mathrm{Cl}(3)$ 扇区分解下，编码权重满足：
$$\sigma_M + \sigma_C + \sigma_I = 1.$$

本节给出该定理基于四元数叉积恒等式的代数重证。原证明见 1.3 §2.4。

证明（基于投影强度恒等式与四元数叉积恒等式）。

步骤1. 设 $u, v$ 为平面 $V$ 的一组标准正交基（$\|u\| = \|v\| = 1$，$\langle u, v\rangle = 0$）。投影 $P$ 由 $Px = \langle x, u\rangle u + \langle x, v\rangle v$ 给出。

步骤2. 计算投影强度 $c_i$。由 $PL_iP = c_i J$，对基向量取矩阵元可导出：
$$c_i = \langle L_i u, v\rangle.$$

即 $c_i$ 恰好是 $L_i u$ 在 $v$ 方向的分量——$u$ 经 $L_i$ 作用后投影到 $v$ 的内积。

步骤3. 计算 $\sum c_i^2$。由 $c_i = \langle L_i u, v\rangle$：
$$\sum_{i=1}^{3} c_i^2 = \sum_{i=1}^{3} \langle L_i u, v\rangle^2.$$

步骤4（四元数叉积恒等式）。 将 $\mathbb{R}^4 \cong \mathbb{H}$（四元数）。左乘算子 $L_1, L_2, L_3$ 对应四元数单位 $\mathbf{i}, \mathbf{j}, \mathbf{k}$ 的左乘。对四元数 $u, v$，有恒等式：
$$\sum_{i=1}^{3} \langle \mathbf{e}_i \, u, v\rangle^2 = \|u\|^2 \|v\|^2 - \langle u, v\rangle^2,$$
其中 $\mathbf{e}_i \in \{\mathbf{i}, \mathbf{j}, \mathbf{k}\}$。这是四元数版本的 Lagrange 恒等式——左边是叉积分量的平方和，右边是 Gram 行列式。

步骤5. 对标准正交基 $u, v$（$\|u\|=\|v\|=1$，$\langle u,v\rangle=0$）：
$$\sum_{i=1}^{3} c_i^2 = \|u\|^2\|v\|^2 - \langle u,v\rangle^2 = 1 - 0 = 1.$$

步骤6. 由 $\sigma_i = c_i^2$：
$$\sigma_M + \sigma_C + \sigma_I = \sum_{i=1}^{3} c_i^2 = 1. \qquad \blacksquare$$

2.4 归一化的代数根源——非公设性

上述证明的关键在于：$\sum\sigma_i = 1$ 不是作为完备性假设引入的公设，而是从以下三个纯代数事实导出的定理：

  1. $\mathrm{Cl}(3)$ 表示结构：$L_i$ 满足 Clifford 关系（代数公理）
  2. 投影-复结构对应：$PL_iP = c_i J$（线性代数引理）
  3. 四元数 Lagrange 恒等式：$\sum c_i^2 = \|u\|^2\|v\|^2 - \langle u,v\rangle^2$（代数恒等式）

这三个前提中没有任何一个是关于编码权重的假设——它们全部是 $\mathrm{Cl}(3)$ 代数结构的内在性质。因此 $\sum\sigma_i = 1$ 是 $\mathrm{Cl}(3)$ 代数的定理 1.4.2.03。，其地位等同于「$\mathrm{Cl}(3)$ 的表示是四维的」这样的代数事实。

这一结论直接影响后续三次方程的推导：步骤中使用的 $\sum\sigma_i = 1$（见 §3.3）具有严格的代数基础，而非循环论证。

§3 代数归一化条件

3.1 从角度到正弦

由 Born 法则（定理 1.3.4.01–20），编码角度通过正弦函数与编码权重关联：
$$\sin\theta_i = \sqrt{\sigma_i}\cdot C,$$
其中 $C$ 为归一化常数，由 §3.3 的三次方程唯一确定。

归一化条件应直接约束 $\sin\theta_i$，而非 $\theta_i$ 本身——这样避免 $\arcsin$ 的出现。

3.2 不完备度

定义20（不完备度）。 设
$$C^2 = \sin^2\theta_M + \sin^2\theta_C + \sin^2\theta_I.$$

$C^2$ 衡量全息投影的「不完备度」——三个投影方向的正弦强度平方和。

  • $C^2 = 1$：完备投影（三个方向覆盖全部信息，Parseval 条件）
  • $C^2 < 1$：不完备投影（存在信息丢失）

由 $\sin\theta_i = \sqrt{\sigma_i}\cdot C$ 及 $\sum\sigma_i = 1$（定理，§2）：
$$C^2 = \sum_i \sin^2\theta_i = \Bigl(\sum_i \sigma_i\Bigr) C^2 = C^2,$$
不完备度恰为归一化常数的平方；$C$ 的具体值由 §3.3 的三次方程 $2pC^3 + C^2 = 1$ 唯一确定，$C^2 < 1$ 由定理 1.4.3.03 保证。

3.3 三次方程的完整推导

定理 1.4.3.01（代数归一化）。 归一化常数 $C$ 满足三次方程：
$$2p\,C^3 + C^2 = 1, \qquad p = \sqrt{\sigma_M \sigma_C \sigma_I}.$$

证明。

关键三角恒等式

引理 1.4.3.02（三正弦恒等式）。 当 $\theta_1 + \theta_2 + \theta_3 = \pi/2$ 时，有恒等式：
$$\sin^2\theta_1 + \sin^2\theta_2 + \sin^2\theta_3 + 2\sin\theta_1\sin\theta_2\sin\theta_3 = 1.$$

证明。 由 $\theta_3 = \pi/2 - \theta_1 - \theta_2$，得 $\sin\theta_3 = \cos(\theta_1 + \theta_2)$。展开：
$$\sin^2\theta_3 = \cos^2(\theta_1 + \theta_2) = 1 - \sin^2(\theta_1 + \theta_2).$$

再展开 $\sin^2(\theta_1 + \theta_2)$。由 $\sin(\theta_1 + \theta_2) = \sin\theta_1\cos\theta_2 + \cos\theta_1\sin\theta_2$：
$$\sin^2(\theta_1 + \theta_2) = \sin^2\theta_1\cos^2\theta_2 + \cos^2\theta_1\sin^2\theta_2 + 2\sin\theta_1\cos\theta_2\cos\theta_1\sin\theta_2.$$

代入回 $\sin^2\theta_3$：
$$\sin^2\theta_3 = 1 - \sin^2\theta_1\cos^2\theta_2 - \cos^2\theta_1\sin^2\theta_2 - 2\sin\theta_1\cos\theta_1\sin\theta_2\cos\theta_2.$$

于是三个 $\sin^2$ 项之和为：
$$\sin^2\theta_1 + \sin^2\theta_2 + \sin^2\theta_3 = \sin^2\theta_1(1-\cos^2\theta_2) + \sin^2\theta_2(1-\cos^2\theta_1) + 1 - 2\sin\theta_1\cos\theta_1\sin\theta_2\cos\theta_2.$$

利用 $1-\cos^2 = \sin^2$ 化简：
$$= \sin^2\theta_1\sin^2\theta_2 + \sin^2\theta_2\sin^2\theta_1 + 1 - 2\sin\theta_1\cos\theta_1\sin\theta_2\cos\theta_2$$
$$= 1 + 2\sin\theta_1\sin\theta_2\bigl(\sin\theta_1\sin\theta_2 - \cos\theta_1\cos\theta_2\bigr).$$

注意到 $\sin\theta_1\sin\theta_2 - \cos\theta_1\cos\theta_2 = -\cos(\theta_1 + \theta_2) = -\sin\theta_3$，故：
$$\sin^2\theta_1 + \sin^2\theta_2 + \sin^2\theta_3 = 1 - 2\sin\theta_1\sin\theta_2\sin\theta_3.$$

移项即得：
$$\sin^2\theta_1 + \sin^2\theta_2 + \sin^2\theta_3 + 2\sin\theta_1\sin\theta_2\sin\theta_3 = 1. \qquad\blacksquare$$

代数化推导

将 Born 法则的代数形式 $\sin\theta_i = \sqrt{\sigma_i}\cdot C$（$C$ 为归一化常数）代入三正弦恒等式。

个体项。 每个 $\sin^2\theta_i$ 贡献 $\sigma_i C^2$，三项求和：
$$\sum_i \sin^2\theta_i = \Bigl(\sum_i \sigma_i\Bigr) C^2 = 1 \cdot C^2 = C^2,$$
其中第三个等号使用了扇区权重归一化 $\sum\sigma_i = 1$（§2 定理）。

交叉项。 乘积 $\sin\theta_1\sin\theta_2\sin\theta_3$ 贡献：
$$\sin\theta_M\sin\theta_C\sin\theta_I = \sqrt{\sigma_M\sigma_C\sigma_I}\cdot C^3 = p\cdot C^3,$$
其中 $p = \sqrt{\sigma_M\sigma_C\sigma_I}$ 是由编码权重完全确定的代数参数。

合并。 将个体项与交叉项代入恒等式 $\sum\sin^2\theta_i + 2\prod\sin\theta_i = 1$：
$$\underbrace{\Bigl(\sum_i \sigma_i\Bigr)}_{=\,1}\cdot C^2 + 2\underbrace{\sqrt{\sigma_M\sigma_C\sigma_I}}_{=\,p}\cdot C^3 = 1.$$

即：
$$\boxed{2p\,C^3 + C^2 = 1, \qquad p = \sqrt{\sigma_M\sigma_C\sigma_I}.}$$

系数 $2$ 来自三角恒等式中交叉项的系数（源自 $\sin(\theta_1 + \theta_2)$ 展开的二项对称性），$p$ 由编码权重完全确定。整个推导仅涉及多项式运算与代数恒等式，不出现任何超越函数。$\blacksquare$

3.4 三次方程的性质

三次方程 $f(C) = 2pC^3 + C^2 - 1 = 0$ 具有以下性质。

（1）判别式与非负性。 三次方程 $aC^3 + bC^2 + cC + d = 0$（此处 $a=2p, b=1, c=0, d=-1$）的判别式为：
$$\Delta = 18abcd - 4b^3d + b^2c^2 - 4ac^3 - 27a^2d^2 = 4 - 108p^2.$$

由 AM-GM 不等式，对满足 $\sum\sigma_i=1$ 的非负 $\sigma_i$：
$$\sigma_M\sigma_C\sigma_I \leq \left(\frac{\sigma_M + \sigma_C + \sigma_I}{3}\right)^3 = \frac{1}{27},$$
故 $p = \sqrt{\sigma_M\sigma_C\sigma_I} \leq \dfrac{1}{3\sqrt{3}}$，从而：
$$\Delta = 4 - 108p^2 \geq 4 - \frac{108}{27} = 4 - 4 = 0 \geq 0.$$

判别式 $\Delta \geq 0$ 恒成立，保证三次方程的根均为实数。

（2）三个实根（casus irreducibilis）。 当 $\sigma$ 非完全对称时 $p < 1/(3\sqrt{3})$，此时 $\Delta > 0$，三次方程有三个不同的实根。这是三次方程的不可约情形（casus irreducibilis）——三个实根虽存在，但无法仅用实数根式表达，需借助三角函数（见 §3.5）。

（3）正根唯一性。 考察 $f(C) = 2pC^3 + C^2 - 1$：
- $f(0) = -1 < 0$，
- $f(1) = 2p > 0$（当 $p>0$），
- $f'(C) = 6pC^2 + 2C = C(6pC + 2) > 0$ 对 $C > 0$。

故 $f$ 在 $(0,\infty)$ 上严格单调递增，在 $(0,1)$ 中恰有一个零点。因此三次方程在 $(0,1]$ 中恰有一个正根 $C$，对应唯一的物理解。

（4）对称极限。 当 $\sigma = (1/3,\, 1/3,\, 1/3)$ 时：
$$p = \sqrt{\tfrac{1}{27}} = \frac{1}{3\sqrt{3}} \approx 0.19245, \quad \Delta = 0.$$
此时三次方程有重根。代入验证 $C = \dfrac{\sqrt{3}}{2}$：
$$2\cdot\frac{1}{3\sqrt{3}}\cdot\left(\frac{\sqrt{3}}{2}\right)^3 + \left(\frac{\sqrt{3}}{2}\right)^2 = \frac{2}{3\sqrt{3}}\cdot\frac{3\sqrt{3}}{8} + \frac{3}{4} = \frac{1}{4} + \frac{3}{4} = 1. \;\checkmark$$
故 $C = \sqrt{3}/2 \approx 0.86603$，归一化常数 $\Lambda = 1/C = 2/\sqrt{3} \approx 1.1547$。

（5）极端极限。 当某扇区占主导（如 $\sigma_M \to 1$，$\sigma_C, \sigma_I \to 0$）时，$p \to 0$，三次方程退化为 $C^2 = 1$，即 $C \to 1$，$\Lambda \to 1$。此时全息投影趋于完备。

3.5 三次方程的根式解

三次方程 $2pC^3 + C^2 - 1 = 0$ 可通过三角函数法求解（适用于 casus irreducibilis）。

化简为简型三次方程。 除以 $2p$（$p > 0$）得 $C^3 + \dfrac{1}{2p}C^2 - \dfrac{1}{2p} = 0$。作代换 $C = t - \dfrac{1}{6p}$ 消去二次项，得简型三次方程：
$$t^3 + Pt + Q = 0, \quad P = -\frac{1}{12p^2}, \quad Q = \frac{1-54p^2}{108p^3}.$$

三角函数解。 当 $\Delta > 0$（即 $4P^3 + 27Q^2 < 0$）时，三个实根为：
$$t_k = 2\sqrt{-\frac{P}{3}}\,\cos\!\left(\frac{1}{3}\arccos\!\left(\frac{3Q}{2P}\sqrt{-\frac{3}{P}}\right) - \frac{2\pi k}{3}\right), \quad k=0,1,2.$$

代入 $P, Q$ 的表达式，各部分化简为：
$$2\sqrt{-\frac{P}{3}} = \frac{1}{3p}, \qquad \frac{3Q}{2P}\sqrt{-\frac{3}{P}} = 54p^2 - 1.$$

因此：
$$\boxed{C_k = -\frac{1}{6p} + \frac{1}{3p}\cos\!\left(\frac{1}{3}\arccos(54p^2 - 1) - \frac{2\pi k}{3}\right), \quad k = 0,1,2.}$$

物理解选取。 三个根 $C_0, C_1, C_2$ 中，恰有一个落在 $(0, 1]$ 内——对应 $k=0$ 的根（可由 $f$ 的单调性验证）。该正根即为归一化常数 $C$。

对称情形验证。 当 $p = 1/(3\sqrt{3})$ 时 $54p^2 - 1 = 1$，$\arccos(1) = 0$，$k=0$ 给出：
$$C_0 = -\frac{1}{6p} + \frac{1}{3p}\cos(0) = \frac{1}{6p} = \frac{1}{6\cdot 1/(3\sqrt{3})} = \frac{\sqrt{3}}{2}. \;\checkmark$$

整个求解过程仅用代数运算与三角函数（三角函数在此作为代数方程求解的工具，而非出现在理论结构中的超越约束），不涉及 $\arcsin$ 等超越约束。

$C$ 的具体值依赖于 $p$，而 $p$ 由编码结构确定。$p$ 的值在第 2 卷中通过 Birkhoff 混合矩阵确定。

$(0.854,\,0.134,\,0.012)$ $0.03706$ $0.96602$ $-0.0068$ $90.000°$ $1.000000$

验证说明。

  1. 三次方程残差：所有情形下 $2pC^3 + C^2-1$ 的残差均在机器精度（$<10^{-15}$）内为零，证实 $C$ 确为三次方程的解。
  2. 角度求和：由 $\sin\theta_i = \sqrt{\sigma_i}\cdot C$ 反解 $\theta_i = \arcsin(\sqrt{\sigma_i}\cdot C)$，求和 $\sum\theta_i$ 在所有情形下精确等于 $90°$——验证了三次方程确实编码了 $\sum\theta = \pi/2$ 约束。
  3. 正切恒等式：$\sum\tan\theta_i\tan\theta_j = 1$ 是 $\sum\theta = \pi/2$ 的代数推论（由 $\tan(\theta_1 + \theta_2 + \theta_3)\to\infty$ 的发散条件导出），数值上精确成立。

注意：表中的 $\arcsin$ 仅用于验证（确认角度约束被满足），不出现于理论推导链本身——推导链中 $C$ 完全由三次方程（代数方程）确定。

3.7 $C^2 < 1$ 的证明

定理 1.4.3.03（不完备投影定理）。 当 $p > 0$（即所有 $\sigma_i > 0$）时，三次方程给出 $C < 1$，因此 $C^2 < 1$。

证明。 考察 $f(C) = 2pC^3 + C^2 - 1$。

  • 当 $p > 0$ 时，$f(1) = 2p\cdot 1^3 + 1^2 - 1 = 2p > 0$。
  • $f(0) = -1 < 0$。
  • $f$ 在 $(0, \infty)$ 上严格单调递增（$f'(C) = C(6pC + 2) > 0$ 对 $C>0$）。

由 $f(0) < 0 < f(1)$ 及 $f$ 的严格单调性，$f$ 的唯一正零点 $C^*$ 满足 $0 < C^* < 1$。因此 $C < 1$，从而：
$$C^2 < 1.$$

物理意义。 $C^2 < 1$ 衡量全息投影的不完备度——三个投影方向不能完全覆盖编码空间。这种不完备是内禀的：只要三个扇区均有非零权重（$p > 0$），投影就必然是不完备的。

退化情形。 仅当 $p = 0$（某 $\sigma_i = 0$，即某扇区权重为零）时，三次方程退化为 $C^2 = 1$，$C = 1$，对应完备投影。此时缺失的扇区不参与编码，投影退化为二维平面上的完备覆盖。$\blacksquare$

§4 Parseval 不兼容性

4.1 两种归一化约束的冲突

全息投影的归一化有两种自然候选：

  • 角度约束（$\sum\theta = \pi/2$）：三个编码角度之和为直角，对应三次方程 $2pC^3 + C^2=1$。
  • Parseval 约束（$\sum\sin^2\theta = 1$）：三个正弦分量的平方和为 $1$，对应 Parseval 恒等式（完备性）。

注（Parseval 不兼容性）。 $\sum\theta = \pi/2$ 与 $\sum\sin^2\theta = 1$（Parseval 条件）不可能同时成立，除非某个角度为零（退化情形）。

4.2 对称分布的验证

以对称分布 $\sigma = (1/3,\, 1/3,\, 1/3)$ 为例。

情形 A：角度约束 $\sum\theta = \pi/2$（三次方程）。 由对称性 $\theta_M = \theta_C = \theta_I = \pi/6 = 30°$。三次方程给出 $C = \sqrt{3}/2$，$C^2 = 3/4$。验证：
$$\sum\sin^2\theta_i = 3\sin^2 30° = 3\cdot\frac{1}{4} = \frac{3}{4} = C^2 < 1.$$
Parseval 条件 $\sum\sin^2\theta = 1$ 不满足（$3/4 \neq 1$）。

情形 B：Parseval 约束 $\sum\sin^2\theta = 1$。 由对称性 $\sin^2\theta_i = 1/3$，$\sin\theta_i = 1/\sqrt{3}$，$\theta_i = \arcsin(1/\sqrt{3}) \approx 35.264°$。此时：
$$\sum\theta_i = 3 \times 35.264° \approx 105.79° \neq 90°.$$
角度约束 $\sum\theta = \pi/2$ 不满足。

4.3 结论

两种约束在对称情形下给出不同的角度（$30°$ vs $35.26°$）和不同的 $C^2$（$3/4$ vs $1$），且无法同时满足。这说明：

  1. 归一化必须做出选择：$\sum\theta = \pi/2$（代数路径，三次方程）与 $\sum\sin^2\theta = 1$（Parseval）二者只能取其一。
  2. 本框架选择角度约束：因 $\sum\theta = \pi/2$ 通过三次方程 $2pC^3 + C^2=1$ 实现代数化，整个推导链不含超越函数；而 Parseval 条件虽形式简单，却与编码角度的几何结构不自洽。
  3. $C^2 < 1$ 是必然结果：选择角度约束后，$C^2 = \sum\sin^2\theta < 1$（定理 1.4.3.03），全息投影的内禀不完备度被三次方程自然编码。

|:--|:--|
| $\theta_M + \theta_C + \theta_I = \pi/2$（超越约束） | $2pC^3 + C^2=1$（代数方程） |
| $\arcsin$ 函数 | 多项式方程 |
| 浮点求解（数值误差） | 根式求解（精确） |
| Berry 修正 $f=(8/9)^{C^2/2}$（外部超越修正） | Birkhoff 混合矩阵 $T$ 内在编码（第 2 卷） |
| $\sum\sigma_i=1$ 作为公设 | $\sum\sigma_i=1$ 作为 $\mathrm{Cl}(3)$ 代数定理（§2） |
| $C^2<1$ 由经验观察 | $C^2<1$ 严格证明（定理 1.4.3.03，§3.7） |
| 归一化与 Parseval 关系不明 | Parseval 不兼容性明确（§4） |

5.2 Berry 修正的消解

$$\theta_I \leftrightarrow I_1, \quad \theta_\tau \leftrightarrow I_2, \quad \theta_{\sigma_2} \leftrightarrow I_3.$$

Chern-Simons 三项结构不再是外部的——它是 $T$ 的矩阵元的代数表达。详细推导在第 2 卷。

§6 代数作用量的前置

6.1 归一化的角色

代数归一化 $2pC^3 + C^2 = 1$ 为代数作用量 $S(\sigma)$（1.5）提供了归一化基础：

  • $C$ 确定了编码权重 $\sigma_i$ 的归一化标度
  • $C^2 < 1$ 衡量信息不完备度——作用量 $S(\sigma)$ 将惩罚这种不完备
  • $p$ 通过 triality 约束交叉项的结构——作用量中的交叉项系数由 $p$ 确定

6.2 无超越函数的推导链

代数归一化确保整个推导链不含超越函数：

结构常数定理→ 乘子序列（1.1）→ 扇区绑定（1.2）→ Born法则（1.3）
→ 扇区权重归一化 ∑σ_i=1（§2，Cl(3)定理）→ 代数归一化 2pC³ + C² = 1（本文§3）
→ 代数作用量 S(σ)（1.5）→ Birkhoff 混合矩阵 T（2.1）→ 不动点 σ*（观测者位置输入）→ α⁻¹（1.5 §3.7）

每一步都是代数（多项式）运算，不涉及 $\arcsin$、$\exp$ 或任何超越函数。扇区权重归一化 $\sum\sigma_i=1$ 作为 $\mathrm{Cl}(3)$ 代数定理（§2），进一步巩固了推导链的代数纯粹性。
