10.38 赝标量胶球量子数 0⁻⁺ 的几何来源

版本: 260808

状态: 未提交主库。依赖主库定理 #295、#307、#267、定理 7.1.1.01（#285）、定理 7.8.6.03，以及文章 6.6（Σ时空涌现）、7.10（强CP消解）、7.9（夸克禁闭）、10.37（纯色闭合构型稳定性）。本文含一处明确标注的探索性假设（假设 2.1）。

摘要

文章 10.37 已证明：胶球（纯色闭合构型 $G = \sum_a\lambda_a\otimes\lambda_a$）作为 SU(3) 单态在框架内代数稳定地存在。本文回答第二个问题：为什么这个色单态的量子数是 $0^{-+}$（赝标量胶球，X(2370)）。

论证核心：赝标量胶球的最低维算符 $O = \mathrm{Tr}(G_{\mu\nu}\tilde{G}^{\mu\nu})$ 的量子数由三个独立结构决定——(i) $J=0$：全缩并（无自由洛伦兹指标）；(ii) $P=-$：含 4 维体积元 $\varepsilon_{\mu\nu\rho\sigma}$（赝张量）；(iii) $C=+$：迹缩并（电荷共轭不变）。这三者在框架中各有几何对应：色单态缩并 = 文章 10.37 的 Killing 收缩 $G$；体积元的赝标量性 = Clifford 体积元（$\omega_3 = \gamma_1\gamma_2\gamma_3$ 在 $\mathrm{Cl}(3)_\mathbb{C} \cong \mathrm{Mat}(4,\mathbb{C})$ 中扮演手征元，$\omega_5$ 已是框架的复结构 $J$）；辛形式的体积元投影（定理 7.8.6.03）已建立"体积元 → 时空结构"的桥梁。

主要结果：
- 定理 X2.1：胶球态 $O = \mathrm{Tr}(G\tilde{G})$ 的量子数 $J^{PC} = 0^{-+}$ 由色单态缩并（$C=+$）、全缩并（$J=0$）、体积元缩并（$P=-$）三要素确定——与 X(2370) 一致；
- 推论 X2.2（缩并张量宇称规则）：胶球的宇称 = 色单态缩并张量的宇称——标量胶球 $0^{++}$（算符 $\mathrm{Tr}(G^2)$，无体积元）与赝标量胶球 $0^{-+}$（算符 $\mathrm{Tr}(G\tilde{G})$，含体积元）在框架语言中的区分 = 是否含体积元缩并；
- 与 triality 锁定（#307）自洽：真空 $\bar\theta = 0$（CP 偶基态）与赝标量胶球（CP 奇激发态）不矛盾——胶球态是 $\bar\theta$ 项算符 $O$ 的激发模式，其 CP 奇性由体积元缩并决定，与真空的 CP 偶性分属不同层次。

诚实边界：假设 2.1（时空体积元 $\varepsilon_{\mu\nu\rho\sigma}$ 与 Clifford 体积元层的显式对应）是探索性的——文章库已建立"辛形式 = 体积元投影"（定理 7.8.6.03）与"复结构 $J = \omega_5$"（7.1 §1.3），但 $\varepsilon$ 张量 ↔ 框架体积元的完整对应尚未建成。质量次序（$0^{++}$ 轻于 $0^{-+}$）未推出，属第三条路径。

§1 问题：0⁻⁺ 从哪来

1.1 X(2370) 的量子数

BESIII 合作组确认的 X(2370) 具有量子数 $J^{PC} = 0^{-+}$：自旋零、宇称负、电荷共轭正。在 QCD 中，这是赝标量胶球——纯胶子束缚态的最低维算符为

$$O = \mathrm{Tr}(G_{\mu\nu}\tilde{G}^{\mu\nu}), \qquad \tilde{G}^{\mu\nu} = \tfrac{1}{2}\varepsilon^{\mu\nu\rho\sigma}G_{\rho\sigma},$$

其中 $G_{\mu\nu} = G^a_{\mu\nu}\lambda_a/2$ 是 SU(3) 场强，$\tilde{G}$ 是霍奇对偶场强。

探索稿 X1 已证明色单态组合 $G = \sum_a\lambda_a\otimes\lambda_a$（Killing 收缩，$8\otimes 8 \to 1$）在框架内代数稳定地存在。本文的任务：从框架的结构推出 $0^{-+}$，即解释 $J=0$、$P=-$、$C=+$ 三个量子数各来自框架的哪个几何结构。

1.2 框架已有的结构

三条既有结果直接相关：

  1. 色单态缩并（X1，定理 X1.2）：$G = \sum_a\lambda_a\otimes\lambda_a$ 是唯一（Killing 型）的 $8\otimes 8$ 单态，扇区权重等权 $w(G) = (8,8,8)$，驻留 $\theta_0 = (30°,30°,30°)$ 全局极小。这是 $O$ 的色部分（$\delta_{ab}$ 缩并）——给出 $C=+$（迹缩并在电荷共轭下不变）。

  2. 体积元在框架中的先例：
    - 辛形式来自 Clifford 代数体积元投影（定理 7.8.6.03，6.6 §1.1）：$\omega = d\xi\wedge d\eta$——体积元已经产生时空结构；
    - 复结构 $J = \omega_5$（Cl(5) 的伪标量）涌现并破坏 triality（定理 7.1.1.01 的 §1.3）：$J|_V = i$，$J|_{S^+} = -i$，$J|_{S^-} = i$——伪标量体积元已是手征性（轴性）的根源；
    - 强CP参数 $\bar\theta$ 的 triality 锁定（#307）：$\bar\theta \in \{0, \pi\}$——框架已处理含 $\varepsilon_{\mu\nu\rho\sigma}$ 的赝标量密度算符 $\mathrm{Tr}(G\tilde{G})$（7.10 §1.1）。

  3. Cl(3) 的手征结构：$\mathrm{Cl}(3)\otimes\mathbb{C} \cong \mathrm{Mat}(4,\mathbb{C})$（定理 7.1.1.01），体积元 $\omega_3 = \gamma_1\gamma_2\gamma_3$ 满足 $\omega_3^2 = -1$，$\{\omega_3, \gamma_i\} = 0$（$i=1,2,3$）——$\omega_3$ 是 $\mathrm{Mat}(4,\mathbb{C})$ 中的手征元（$\gamma_5$ 类），$(1 \pm i\omega_3)/2$ 给出手征投影。

§2 算符识别：O = Tr(G·G̃)

2.1 赝标量胶球的最低维算符

赝标量胶球（$0^{-+}$）的最低维规范不变算符是 $O = \mathrm{Tr}(G_{\mu\nu}\tilde{G}^{\mu\nu})$。三个量子数的结构来源：

量子数 值 结构来源
$J$ 0 所有洛伦兹指标（$\mu,\nu,\rho,\sigma$）全部缩并，无自由指标
$P$ $-$ 含 4 维 Levi-Civita 张量 $\varepsilon_{\mu\nu\rho\sigma}$（赝张量，空间反射下变号）
$C$ $+$ 色迹缩并 $\delta_{ab}$（或 $\mathrm{Tr}$）；电荷共轭下 $G \to -G^T$，迹不变

对比：标量胶球（$0^{++}$）的最低维算符 $\mathrm{Tr}(G_{\mu\nu}G^{\mu\nu})$ 只含度规缩并 $\eta_{\mu\rho}\eta_{\nu\sigma}$（无 $\varepsilon$）——宇称正。

观察：两个算符的色结构相同（都是色单态迹缩并），唯一区别是时空缩并张量：$\eta\eta$（P 偶）vs $\varepsilon$（P 奇）。胶球的宇称 = 缩并张量的宇称。

2.2 框架中已有的位置：θ̄ 项

$O = \mathrm{Tr}(G\tilde{G})$ 在框架中不是一个陌生对象——它就是强CP参数 $\bar\theta$ 项中的赝标量密度（7.10 §1.1）：

$$\mathcal{L}_\theta = \bar\theta\cdot\frac{g_s^2}{32\pi^2}\mathrm{Tr}(G_{\mu\nu}\tilde{G}^{\mu\nu}).$$

框架已处理这个算符的两个层面：
- 真空层面：$\bar\theta \in \{0,\pi\}$ 由 triality 锁定（#307），$\bar\theta = 0$ 由 Birkhoff 行列式实数性确定（定理 7.1）；
- 激发层面（本文）：$O$ 作为算符的激发模式 $O|0\rangle$ 携带量子数 $0^{-+}$——即赝标量胶球。

关键认识：赝标量胶球不是框架外的对象，而是 $\bar\theta$ 项算符的量子化激发。框架对 $\bar\theta$ 的处理（7.10、#307）已隐含对 $O$ 的承认；本文把 $O$ 的量子数结构与框架的几何结构显式对应。

§3 体积元与宇称

3.1 Clifford 体积元的赝标量性

Clifford 代数标准事实：体积元是赝标量。对 $\mathrm{Cl}(3)$：

$$\omega_3 = \gamma_1\gamma_2\gamma_3, \qquad \omega_3^2 = -1, \qquad \{\omega_3, \gamma_i\} = 0.$$

在空间反射 $P$（$\gamma_i \to -\gamma_i$）下：

$$P: \omega_3 \to (-\gamma_1)(-\gamma_2)(-\gamma_3) = -\gamma_1\gamma_2\gamma_3 = -\omega_3.$$

体积元在反射下变号——赝标量性。霍奇对偶 $*X = \omega_3 X$（左乘体积元）将 k-形式映射到 (3−k)-形式，且宇称翻转。对 $\mathrm{Cl}(1,3)$（时空），体积元 $\omega_4 = \gamma_0\gamma_1\gamma_2\gamma_3$ 同样是赝标量，对应 $\varepsilon_{\mu\nu\rho\sigma}$。

3.2 框架中的体积元先例

框架已两次使用体积元的赝标量性：

  1. 辛形式（定理 7.8.6.03，6.6 §1.1）：$\Sigma$ 上的辛形式 $\omega = d\xi\wedge d\eta$ 来自 Clifford 代数体积元的投影——体积元 → 时空结构的桥梁已经建立；
  2. 复结构（定理 7.1.1.01 §1.3）：$J = \omega_5$（Cl(5) 伪标量）是复结构（$J^2 = -1$），在三个 8 维表示上取 $i, -i, i$——伪标量体积元 = 手征性（轴性）的根源已确立；$J$ 的涌现破坏 triality 的 $S_3$，保留 $Z_2$。

这两个先例说明：框架中"体积元"不是外来概念，而是结构性的——它产生辛结构（时空的几何）与手征结构（粒子物理的轴性）。

3.3 假设 2.1（ε ↔ 体积元层）

假设 2.1（探索性）：时空体积元 $\varepsilon_{\mu\nu\rho\sigma}$（$P$ 奇性来源）对应框架的 Clifford 体积元层——具体地，4 维时空的 $\varepsilon_{\mu\nu\rho\sigma}$ 与 $\mathrm{Cl}(5)$ 伪标量 $\omega_5$（或其在 $\Sigma \to \mathbb{R}^{3,1}$ 投影下的辛形式 $\omega = d\xi\wedge d\eta$，定理 7.8.6.03）同源。

依据：
1. 定理 7.8.6.03：辛形式 = 体积元投影——时空结构的宇称性质继承自体积元；
2. 定理 7.1.1.01 §1.3：$J = \omega_5$ 已是框架的复结构/轴性根源；
3. Clifford 标准事实：所有维数的体积元均为赝标量（反射下变号），$\varepsilon_{\mu\nu\rho\sigma}$ 与 $\omega_4$ 同构。

这一假设未在文章库中显式建立（6.6 的辛形式是"投影"桥梁，未展开 $\varepsilon$ 张量的完整对应）——本文将其作为探索性假设，其严格化属后续工作。

§4 定理 X2.1：0⁻⁺ 的三步推导

定理 X2.1（赝标量胶球的量子数）。设 $O = \mathrm{Tr}(G_{\mu\nu}\tilde{G}^{\mu\nu})$ 为胶球最低维算符，其色单态缩并为探索稿 X1 的 Killing 收缩 $G = \sum_a\lambda_a\otimes\lambda_a$（定理 X1.2）。则 $O$ 的量子数 $J^{PC} = 0^{-+}$：$J=0$（全缩并）、$P=-$（体积元缩并）、$C=+$（迹缩并）。

证明：

步骤 1（$J = 0$：全缩并）。$O$ 的所有洛伦兹指标成对缩并：$\mu$ 与 $\nu$（$G_{\mu\nu}$ 内部）、$\rho$ 与 $\sigma$（$\tilde{G}^{\rho\sigma}$ 内部）、以及 $\varepsilon^{\mu\nu\rho\sigma}$ 的四指标——无自由洛伦兹指标 ⇒ 洛伦兹标量 ⇒ $J = 0$。色指标由 $\mathrm{Tr}$（= $\delta_{ab}$ 缩并）饱和，即 X1 的 Killing 收缩 $G$（定理 X1.2 (i)）。$\square$

步骤 2（$P = -$：体积元缩并）。$\varepsilon^{\mu\nu\rho\sigma}$ 是赝张量：空间反射下 $\varepsilon^{\mu\nu\rho\sigma} \to -\varepsilon^{\mu\nu\rho\sigma}$（Levi-Civita 符号在右手系约定下反射变号）。由假设 2.1，$\varepsilon$ 的赝张量性与 Clifford 体积元的赝标量性同源（§3.1：$\omega_3$、$\omega_5$ 在反射下变号）。因此 $\tilde{G} = \tfrac{1}{2}\varepsilon G$ 是赝张量场，$O = \mathrm{Tr}(G\tilde{G})$ 在 $P$ 下：

$$P: O \to \mathrm{Tr}((-G)(-\tilde{G})) = -\mathrm{Tr}(G\tilde{G}) = -O,$$

故 $P = -$。$\square$

步骤 3（$C = +$：迹缩并）。电荷共轭下规范场强 $G^a_{\mu\nu} \to -G^{a\,T}_{\mu\nu}$（伴随表示转置）。则：

$$C: O \to \mathrm{Tr}\big((-G^T)(-\tilde{G}^T)\big) = \mathrm{Tr}(G^T\tilde{G}^T) = \mathrm{Tr}(G\tilde{G}) = O,$$

（矩阵转置不改变迹），故 $C = +$。色单态缩并本身（$\delta_{ab}$，X1 的 $G$）在 $C$ 下不变。$\square$

步骤 4（汇总）。$J^{PC} = (0)(-)(+) = 0^{-+}$——与 X(2370) 的量子数一致。∎

证明要点：三个量子数各绑定一个独立几何结构——$J=0$ ↔ 全缩并（色单态 $G$ + 时空全缩并）；$P=-$ ↔ 体积元（$\varepsilon$ ↔ $\omega$ 层，假设 2.1）；$C=+$ ↔ 迹缩并（Killing 收缩的电荷共轭不变性）。

§5 推论：缩并张量宇称规则

5.1 0⁺⁺ 与 0⁻⁺ 的框架区分

推论 X2.2（缩并张量宇称规则）。胶球的宇称等于色单态缩并张量的宇称：标量胶球（算符 $\mathrm{Tr}(G^2)$，度规缩并 $\eta\eta$）$P = +$；赝标量胶球（算符 $\mathrm{Tr}(G\tilde{G})$，体积元缩并 $\varepsilon$）$P = -$。

证明：$O_{++} = \mathrm{Tr}(G_{\mu\nu}G^{\mu\nu})$ 在 $P$ 下 $G \to -G$，$\eta\eta$ 不变：$O_{++} \to \mathrm{Tr}((-G)(-G)) = O_{++}$（$P=+$）；$O_{-+}$ 由定理 X2.1 步骤 2：$P=-$。∎

物理内容：两种胶球共享色单态结构（都是 $8\otimes 8 \to 1$ 的 Killing 收缩，定理 X1.2 的唯一性），区别仅在时空缩并张量。框架语言：胶球的宇称 = 缩并中是否含体积元。这与实验图景一致——标量胶球候选 f₀(1500)/f₀(1710)（$0^{++}$）与赝标量胶球 X(2370)（$0^{-+}$）是同一色单态结构的两种时空实现。

5.2 与 triality 锁定的自洽性

真空的 CP 性质（#307：$\bar\theta \in \{0,\pi\}$，锁定为 0）与胶球态的 CP 奇性不矛盾：

  • 真空 $|0\rangle$：$\bar\theta = 0$，CP 偶（$\langle 0|O|0\rangle = 0$——真空期望值为零，因为 $O$ 是 CP 奇算符而真空 CP 偶）；
  • 激发态 $O|0\rangle$：CP 奇（$P(O|0\rangle) = -O|0\rangle$），即赝标量胶球。

事实上，$O$ 的 CP 奇性与 $\bar\theta = 0$ 的真空是互相一致的：CP 偶真空对 CP 奇算符的期望值为零，这正是不存在 CP 破缺（$\bar\theta = 0$）的算符语言表述。赝标量胶球的存在不引入 CP 破缺——它是 CP 奇激发，与 CP 偶真空正交。

5.3 对混合态的预期

实验确认 X(2370) 是"胶球主导"而非纯胶球——胶球与 $q\bar{q}$ 介子（如 $\eta'$ 类）混合。框架语言：混合 = 色单态结构（X1 的 $G$）与物质单态（#295 的 $T$、$\varepsilon$）之间的耦合。混合幅度在框架中对应什么——$\theta_0$ 极小值附近的混合模式（$G$ 与 $T$ 都是 $\theta_0$ 构型）——是一个开放问题（§6.2）。

§6 诚实边界

6.1 假设 2.1 的开放地位

假设 2.1（$\varepsilon_{\mu\nu\rho\sigma}$ ↔ Clifford 体积元层）是本文的主要探索性环节。文章库已确立的支撑：辛形式 = 体积元投影（定理 7.8.6.03）、复结构 $J = \omega_5$（7.1 §1.3）、$\bar\theta$ 项的赝标量密度（7.10）。但 $\varepsilon$ 张量 ↔ 框架体积元的完整显式对应（含 $\Sigma \to \mathbb{R}^{3,1}$ 投影下的指标结构）尚未建成——这与 6.6 §8.2 标注的最高优先级缺口（$\Sigma \leftrightarrow \mathbb{R}^{3,1}$ 对偶映射）是同一个缺口。

严格化路径：在 6.6 的投影机制（$\eta \to$ 时间，$\xi \to$ 空间）下，构造 $\varepsilon$ 的显式表达——$\varepsilon$ 的 4 指标结构应从快慢模展开（3 空间 + 1 时间）的体元涌现。

6.2 未推出的内容

  1. 质量次序：实验上 $0^{++}$（~1.5–1.7 GeV）轻于 $0^{-+}$（2.37 GeV）。框架的推论 X2.2 只给出量子数区分，未给出质量次序——"体积元缩并的额外拓扑代价"是定性猜想，定量推导属第三条路径；
  2. 混合幅度：X(2370) 的"胶球主导"成分比例（与 $q\bar{q}$ 的混合）未推出；
  3. 衰变模式：$\pi^+\pi^-\eta'$ 等衰变通道的框架推导未做。
