## 3. 关键发现

1. **T3 二部图 = 零方差但非刚性（判别陷阱确认）**：λ_min(L)≡0 精确（std~1e-15），但这是结构必然的平凡零模（连通图 Perron–Frobenius），不是群对称刚性。对照 negacyclic：λ_min>0（mean=5.8e-3）且 Λ_H≡1（std=6.2e-12）——真正刚性。
2. **谱关于 0/1 对称的数值确认**：二部图 λ_max(L)=2.000000 精确（σ(L) 关于 1 对称 ⟹ 0↔2 配对）；邻接谱配对残差 2.4e-14（σ(A) 关于 0 对称）。
3. **T2 随机核违反 (D2)**：λ_min(KᵀK) mean=3.3e-3 且 std=5.5e-3——随机 Gram 矩阵最小特征值聚团于 0，无谱间隙下界，累积量衰减无统一下界（10.76 T1 失效）。
4. **T1 d-正则**：λ₂ std=7.2e-3 正常涨落（无群对称结构，谱间隙非锁定）——对照组。
5. **circulant 复核**：Λ_H mean=1.28、std=0.65——自配对块破坏刚性（与 0.9/10.75 §4 一致）。

## 4. 严格命题（10.76.7.01）

**命题 10.76.7.01（二部图谱配对与平凡零模——谱刚性判别的失败模式）**。
设 G=(U,V,E) 为无孤立顶点的有限二部图，A 为邻接矩阵，L=I−D^{−1/2}AD^{−1/2} 为归一化拉普拉斯。

(i) σ(A) 关于 0 对称：λ∈σ(A) ⟺ −λ∈σ(A)。
(ii) σ(L) 关于 1 对称：μ∈σ(L) ⟺ 2−μ∈σ(L)。
(iii) G 连通 ⟹ 0 是 L 的单特征值，λ_min(L)≡0 恒成立，且 2∈σ(L)；谱刚性比 Λ_H=λ₂/λ₁（定义 0.9.4.01）无定义（发散）。
(iv) 二部图族呈现跨系综"零方差"（λ_min(L) std→0），但该确定性来自平凡零模而非群对称刚性。

**判别式**：谱刚性 = 谱配对（无固定点）**且** λ_min>0（无平凡零模）。二部图违反第二项 ⟹ 落入"零方差误判陷阱"，10.76 条件 (D2) 不满足，普适流体涌现定理对其不适用。

**证明**。
(i) 重排后 A=[[0,B],[Bᵀ,0]]。若 A(x;y)=λ(x;y)（即 By=λx, Bᵀx=λy），则 A(x;−y)=−λ(x;−y)。□
(ii) L=I−S，S=D^{−1/2}AD^{−1/2}=[[0,C],[Cᵀ,0]]（C=D_U^{−1/2}BD_V^{−1/2}）同为二部块结构，由 (i) σ(S) 关于 0 对称 ⟹ σ(L)=1−σ(S) 关于 1 对称。□
(iii) 连通 ⟹ Perron–Frobenius：0 是 L 的单特征值；由 (ii) 2=2−0∈σ(L)。λ₁=0 ⟹ Λ_H 发散。□
(iv) 由 (iii) 每个连通二部图的 λ_min(L)=0 ⟹ 系综 std=0（数值：1.0e-15）。对照定理 0.9.4.02（negacyclic：配对且 λ_min>0 ⟹ Λ_H≡1 良定义）。□
