# 探针⑧ 报告：制度质量（WGI）与文化维度（Hofstede）——"锁"的进一步定位

**日期**: 2026-08-23
**数据**: WVS Wave 7 v6.0（95,497 有效受访者，66 国）+ QoG 标准时间序列（WGI 六维度，2017–2022 均值）+ Hofstede 六文化维度 + World Bank GDP per capita
**核心问题**: 探针⑦排除 GDP/教育后，"锁"还在。它是制度质量（WGI）还是文化维度（Hofstede）？

## 设计

三组协变量检验（与探针⑦同框架）：
- **A) WGI 制度质量**: 六维度（话语权/问责、政治稳定、政府效能、监管质量、法治、腐败控制）——国家均值满意度 vs 各维度单变量 R²；六维复合；多变量全模型 R²_adj；复合残差化后排序稳定性 ρ（与探针⑥同款 bootstrap）
- **B) Hofstede 文化维度**: 六维度（权力距离、个人主义、男性气质、不确定性规避、长期取向、放纵）——同上三检验
- **C) 组合**: WGI(6)+Hofstede(6)+log(GDP) 全模型，残差化后 ρ

判定：残差化后 ρ 仍 ≈0.99 → 锁定不可还原为制度/文化标量属性；ρ 塌缩 → 锁定由该组变量解释。

## 判定

**"锁"不可还原为制度质量、文化维度、经济——任何标量属性都不是锁**：

1. **WGI 制度质量解释力弱**：最强维度（政治稳定）R²=0.105，六维全模型 R²_adj 仅 0.093；残差化后 ρ=0.9956，与原始 0.9951 逐位相同
2. **Hofstede 文化维度无解释力**：六维全模型 R²_adj<0（负数）；复合残差化 ρ 仍 0.9916
3. **三者组合也只有名义解释力**：13 参数解释 36 国方差的 44.3%（名义），调整后仅 11.4%；残差化后 ρ 仍有 0.984

几何读法（比探针⑦更强）：**纤维的标量属性（GDP、教育、制度得分、文化维度）全部不是锁**。制度质量（WGI）和文化维度（Hofstede）本质上是把"结构"压缩成 6 个标量——但压缩丢掉了结构本身（耦合配置/规范组合）。零方差定律锁定的是结构特征值，不随任何标量属性平移。这与探针③"纤维内稀疏化到期望度 1.5 也不影响宏观速率"完全平行：**标量属性进不了宏观速率，只有结构配置能。**

## 与文献的一致

- 制度-幸福感文献（Helliwell 等）：制度质量与幸福感正相关但跨国解释力中等——我们的结果（政治稳定 10.5% 最强）与之吻合
- Hofstede 维度对幸福感的解释力弱是已知现象（与 Easterlin 悖论同族）
- 涂尔干"社会事实"传统再次强化：集体规律独立于个体属性，也独立于聚合标量属性

## 诚实边界

- Hofstede 仅覆盖 38/66 国（偏发达国家子集），且为 1980s–2010s 固定值（非 2017–2022 测量）——B 的 ρ 微降可能部分是子集效应而非文化解释力
- C 全模型 13 参数 / 36 国，过拟合风险高；R²_adj 才是诚实指标（11.4%）
- 聚类抽样使 bootstrap 略乐观
- 仍未识别"锁"的具体内容：结构（制度/文化的**组合配置**）还是更深层（历史路径、地理、语言家族）？——这是探针⑨的自然问题
