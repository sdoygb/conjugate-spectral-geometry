# 探针⑤：社会版三尺度统计刚性——世界银行面板数据判别报告

**日期**: 2026-08-23
**数据源**: 世界银行开放数据 API（https://api.worldbank.org）
- SP.DYN.TFRT.IN 生育率（1960-2025，17490 行）
- SP.DYN.LE00.IN 预期寿命（1960-2025，17490 行）
- 国家元数据含区域分组（217 真实国家，7 区域，已排除 Aggregates 聚合体）
**脚本**: `gpu_spectra/society/probe5_society.py`
**原始数据**: `gpu_spectra/society/wb_*.json`

## 设计（对应探针③扩展2 的 std(m) 标度律判别）

- 纤维 = 区域（7 个高层纤维）
- 微观随机点 = 国家（区域内 n_r 个）
- 时间 = 1960-2023，国家长期水平 μ_c = 时间均值
- 集体量 = 区域均值 M_r 与排序
- 判别规则：刚性 = 集体量被结构锁定（涨落不随微观细节收缩）；随机 = 集体量只是微观平均（涨落 ~1/√n）

## 结果

### 检验1：长期排序稳定性（Spearman ρ，前半1960-1990 vs 后半1991-2023）

| 层级 | 范围 | ρ | 判定 |
|---|---|---|---|
| 宏观 | 全部 217 国 | **0.9025** | 结构锁定 |
| 宏观 | 区域均值（检验3） | **0.9429** | 强锁定 |
| 微观 | 欧洲 | 0.6541 | 漂移 |
| 微观 | 撒哈拉以南 | 0.5190 | 漂移 |
| 微观 | 拉美 | 0.8522 | 较稳 |
| 微观 | 东亚 | 0.8063 | 较稳 |
| 微观 | 中东北非 | 0.7144 | 漂移 |
| 微观 | 南亚 (n=6) | -0.03 | 样本太小 |

**分层结构明确**：区域间排序高度稳定，区域内国家排序漂移——宏观锁定、微观随机。

### 检验2：方差分解 η² = SSB/SST

- SSB(区域间)=374.1, SSW(区域内)=180.4, SST=554.5
- **η² = 0.675**：区域结构解释 68% 的跨国家生育率差异
- 区域内 bootstrap 子样本均值涨落 vs 随机预期 σ/√n：**比值 0.87-0.98 ≈ 1（符合 CLT）**
  → 区域内国家差异是"随机浮动"（区域均值=国家随机平均），区域本身是结构锁定

### 检验3：区域均值时间稳定性

ρ = 0.9429（6 区域）。所有区域生育率同步下降（Δ=-0.95 ~ -3.00），但**相对排序保持**。
→ 集体规律 = 结构锁定（排序）+ 统一趋势（同步演化）

### 交叉验证：预期寿命

全部国家 ρ = 0.8885，与生育率一致（结构锁定）。

## 结论

社会版三尺度统计刚性获得数据证据：

1. **宏观层（区域/集体结构）刚性**：区域排序 ρ≈0.94 稳定，方差 68% 由结构解释——集体规律可预测
2. **微观层（国家/个体）随机**：区域内排序漂移（ρ=0.52-0.85），涨落符合 CLT 随机预期——个体在结构内随机浮动
3. 形态与猜想一致："把人当随机点，集体服从底层规律"——个体的随机性被集体结构（区域、发展阶段、制度）锁定

## 诚实边界

1. **聚合数据**：国家=点，非个体=点。严格对应"人当随机点"需个体级数据（WVS，下一步）
2. **分类人为性**：区域分类是世界银行定义，η² 部分反映分类方式
3. **路径依赖**：排序稳定可能是历史惯性（发展阶段延续），作为"集体规律"的统计证据成立，但不直接证明几何机制
4. **样本限制**：南亚 n=6、北美 n=3 样本过小，已标注
5. **共同趋势**：全球生育率同步下降是跨区域共同趋势，支持"统一趋势+结构锁定"的叠加模型

## 与理论链条的对应

- 定理 5.8.3.02（谱间隙纤维化不变性）：宏观速率由纤维结构锁定，微观细节不进入——数据面 = 区域均值稳定、国家随机浮动
- 10.75 群尺度条款：集体统计量由结构对称决定——数据面 = η²=0.68 结构主导
- 探针③判别规则：std 平坦=刚性，~1/√n=随机——数据面 = 区域均值 CLT（随机）+ 排序稳定（刚性），两层并存
