## 核心发现
1. **BR 历史峰值在 2012 (0.0857)，不是 2019/2020**。2008–2013 危机峰值期 BR 均值 0.0765 为七个时代最高，2014–2023 回落至 0.0642（较峰值 −21%）。全球贸易网络的阵营化在 2012 年见顶，之后整体去阵营化。
2. **λ₂ 峰值 2009/2011 (0.0368)**，2014 后回落至 0.024–0.029（较峰值 −25%）。危机后全球贸易连通度达到战后最高，随后缓慢下降。
3. **与 6 节点子图对照（关键）**：6 节点 BR 峰值 2019 (0.1154)、64 国 BR 峰值 2012 (0.0857)——**全球去阵营化与核心圈（中美欧台日印）阵营化同时发生**："脱钩"不是全球现象，是核心圈现象；全球贸易网络 2012 后整体更分散、更不二部，但核心地缘子图在 2019 单独加深裂缝。
4. **冷战不是贸易二部化最严重时期**：1975–1989 BR 均值仅 0.028（远低于 2008–2013 的 0.077）——铁幕分裂在贸易网络层面不如当代阵营化显著（苏东集团贸易量小，不构成 top100 核心边主要分量）。
5. **λ₂ 与 BR 解耦在长周期同样成立**：2009–2013 λ₂ 与 BR 同步高位（危机后"连接加深+阵营化加深"），2014–2023 λ₂ 回落但 BR 回落更快——连通度缓慢下降、阵营化快速回落。

## 交叉验证 (1995–2023 与 BACI 重叠期)
- BR: 相关 r=0.855, 比值均值 0.95 —— 两独立源高度一致, BR 稳健
- λ₂: 相关 r=0.421, 比值均值 1.45 —— λ₂ 对归一化口径敏感, 趋势大体一致

## 边界
- DOTS 出口 FOB 单边报告 vs BACI 镜像流: 边权定义不同, 绝对 λ₂ 不可直接比较 (比值 1.45)
- BR 峰值年份双源不同 (DOTS 2012 vs BACI 2020): 与 64/66 国名单差异、单边/镜像口径有关; 但"2010s 为 BR 高位期"两源一致
- top100 阈值影响绝对值, 方向稳健 (probe29 已证)
- 1948–1950 数据完整性: 战后初期部分国家缺报, 早期年份总量偏低, 趋势可信度低于 1960 后
