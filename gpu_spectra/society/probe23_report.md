# 探针㉓报告：欧美外部场对东亚子系统谱结构的影响

日期：2026-08-23
方法：加权 Laplacian 谱分析（6 节点：CN TW JP IN US EU；边权=2025 双边贸易额/785.8）
数据：web_search 核实的 2025 贸易数据（中国海关、Eurostat、BEA、Wikipedia、政策文件）

## 情景设计

| 情景 | 操作 | 依据 |
|---|---|---|
| S0 现状 | 原始边权 | 2025 基线 |
| S1 中美脱钩 | CN-US ×0.3 | 关税覆盖近 100% 双边贸易（2025-04 起） |
| S2 美台强化 | US-TW ×1.5 | 美台贸易协定 2025-06 + $500B 投资承诺 |
| S3 欧印强化 | EU-IN ×2.0 | 欧印 FTA 达成（2026-01） |
| S4 组合 | S1+S2+S3 | 当前政策组合 |
| S5 两岸削弱 | CN-TW ×0.5 | 极端情景 |
| S6 危机组合 | CN-TW ×0.5 + US-TW ×1.5 | 两岸削弱+美台强化 |
| S7 极端 | CN-TW ×0.3 + US-TW ×2.0 | 台湾归属反转 |
| S8 完全二部 | 去掉跨阵营边 | 理论极限 |

## 核心发现

1. **中美脱钩是最强的裂缝加深操作**：二部残差 -24.7%，强于两岸削弱（-13.3%）。
   外部桥（CN-US，全图最大边 0.731）的撤走比内部桥（CN-TW，0.318）的削弱更伤结构。

2. **台湾阵营归属反转点就在当前政策附近**：S0 时 CN 46% > US 28%；S2（美台协定后）
   已到 41% vs 37%；S6（两岸削弱×0.5 + 美台×1.5）反转 26% vs 46%。
   US-TW/CN-TW 强度比 r≈1 是临界区。

3. **λ₂ 与二部残差解耦（本次最重要发现）**：S6/S7 的 λ₂（0.661/0.664）几乎不低于 S0
   （0.692），但裂缝显著加深（残差 0.160/0.152 < 0.174）。连通度总量未降，结构已二部化
   （Z₂ 对称出现）——探针④ T3 "零方差但裂缝"的社会版：**用 λ₂ 监测会漏报危机（假刚性），
   必须用二部残差**。

4. **与探针⑳ 的连接**：λ_r 下降 36%（补缺变慢）的可能机制——不是"没有连接"（λ₂ 甚至
   上升至 0.739），而是"连接在错误的地方"：耦合从 CN 转向 TW/IN（友岸外包），系统整体
   连通度不变但结构裂缝加深。

5. **补缺策略的谱论答案**：最优补缺 = 恢复 CN-TW 桥（S5 反向）或重建跨阵营边（S1 反向），
   而非美台强化（单独是加桥，与两岸削弱组合后成为裂缝加深的一部分）。

## 诚实边界

- 贸易额为 2025 快照（部分 2024），未含时序演化
- 6 节点图是极度简化；边权未含服务贸易、投资存量、军事耦合
- 二部残差为加权邻接谱配对，与探针④ T3 的严格 ±λ 配对（无权）是近似对应
- 模拟给出结构诊断，不预测事件（破缺无记忆，探针⑯）
- 台湾耦合的"度贡献"是耦合强度描述，不构成政治立场声明
