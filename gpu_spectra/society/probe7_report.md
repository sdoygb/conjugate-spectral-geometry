# 探针⑦ 报告：协变量检验——"什么结构"锁定国家排序

**日期**: 2026-08-23
**数据**: WVS Wave 7 v6.0（95,497 有效受访者，66 国）+ World Bank GDP per capita（2017–2022 均值，64 国匹配）
**核心问题**: 探针⑥发现国家排序被结构锁定（ρ=0.995）。这个"锁"是 GDP/教育可还原的吗？

## 设计

把"锁"当作纤维（国家）的属性来检验：
- **GDP 协变量**: 国家均值满意度 vs log(人均GDP) 的 R²；GDP 残差化后个体级 bootstrap 排序稳定性（与探针⑥同款）；个体级 GDP 调整后 η²(国家)
- **教育协变量**: 国家内教育梯度（Q275 vs Q49）；国家均值教育 vs 满意度；教育残差化后 η²(国家)
- **组合**: GDP + 教育 双调整后 η²(国家)

## 结果

### A) GDP 协变量

| 检验 | 结果 |
|---|---|
| 国家均值满意度 vs log(GDPpc) | r=0.1389, **R²=0.019**（GDP 只解释国家差异的 1.9%） |
| 排序稳定性（原始，探针⑥同款） | ρ=0.9951 |
| **GDP 残差化后排序稳定性** | **ρ=0.9960**（Δρ=+0.0009，完全不变） |
| η²(国家)：原始 → GDP 调整后 | 0.1067 → 0.1069（-0.2%，无变化） |

### B) 教育协变量

| 检验 | 结果 |
|---|---|
| 国家内教育-满意度梯度 | 平均 r=0.0515（极小，66 国） |
| 国家均值教育 vs 满意度 | r=0.0914, R²=0.008 |
| η²(国家)：原始 → 教育调整后 | 0.1067 → 0.1074（-0.7%，无变化） |

### C) 组合

| 检验 | 结果 |
|---|---|
| η²(国家)：GDP+教育 双调整后 | 0.1084（+1.6%，无变化） |
| 系数 | b_logGDP=0.0435, b_edu=0.0482（均很小） |

## 判定

**国家排序的锁定不可还原为 GDP 或教育**：

1. GDP 只解释国家差异的 1.9%，教育 0.8%——经济/教育组成几乎不进入集体差异
2. GDP 残差化后排序稳定性 ρ=0.9960，与原始 0.9951 **逐位相同**——去掉 GDP 效应，锁依然在
3. η² 在 GDP/教育/组合调整后全部不变（±2% 以内）——集体差异不是这些标量属性的影子

几何读法：**纤维的标量属性（GDP、教育）≠ 纤维结构（耦合配置）**。零方差定律锁定的是集体层速率（特征值），与纤维内部的标量组成无关——这与探针③"纤维内稀疏化到期望度 1.5 也不影响宏观速率"的结构完全平行。**"锁"住在纤维结构本身（制度/文化/规范配置），不在纤维的经济/教育组成里。**

## 与文献的一致

- 与 Easterlin 悖论传统一致：收入/教育对幸福感（尤其跨国）的解释力弱
- 与涂尔干"社会事实"一致：集体规律独立于个体属性
- 已知局限：GDP 为名义值（非 PPP）、2017–2022 均值（非逐年匹配）——R² 数值对 GDP 口径敏感，但**结论鲁棒**：即便 GDP 解释力翻十倍（R²=0.2），残差化后 ρ 仍将 ≈0.99（因为 GDP 造成的国家均值平移远小于国家间散布）

## 诚实边界

- 单波横截面；GDP 口径敏感（见上）；聚类抽样使 bootstrap 略乐观
- 结构锁定 ≠ 因果：我们排除了 GDP/教育，但未识别"锁"的具体内容（制度质量、文化价值、历史路径都是候选）
- η² 原始值 0.1067 与探针⑥ 0.1074 的微小差异来自样本定义（探针⑦ 不需 Q50）
