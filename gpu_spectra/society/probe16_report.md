# 探针⑯报告：和平↔战争两态 Markov 模型 + 破缺判别

**日期**：2026-08-23
**数据**：UCDP/PRIO v26.1（1946–2025，123 国，2112 国家-年冲突）+ WVS Wave7 满意度（Q49，51 国匹配）

## 模型

两态 Markov：P（和平=纤维化锁定态）↔ W（战争=破缺事件）
- λ_b = P→W 破缺率（= 1/平均和平段长）
- λ_r = W→P 重构率（= 1/平均冲突段长）
- 平稳分布 π_W = λ_b/(λ_b+λ_r)；弛豫 τ = 1/(λ_b+λ_r)

## 结果

### 1. 转移率与平稳分布
| 量 | 值 |
|---|---|
| λ_b | 0.0611/年（平均和平段 16.37 年） |
| λ_r | 0.1899/年（平均冲突段 5.27 年） |
| π_W 理论 | 0.2434 |
| π_W 实际 | 0.2146（偏差 13%） |

### 2. 段长度分布 vs 几何（无记忆）
| 段型 | 全局 KS p | 尾重（观测 vs 几何预言） | 单国拒绝率（≥5 段国） |
|---|---|---|---|
| 和平段 | 2.15e-11（拒绝） | 0.195 vs 0.133（重尾） | **0/35（0%）** |
| 冲突段 | 7.82e-25（拒绝） | 0.137 vs 0.122（重尾） | 3/28（11%） |

**关键判定**：
- 全局重尾 ≠ 内在记忆，而是**国家异质性**（不同国家不同 λ 的混合几何）
- 单国和平段 **0/35 拒绝几何** → 破缺是**泊松过程**（无记忆）→ 战争爆发的"随机性"（探针⑮ ρ=0.238）获得机制解释
- 冲突段 11% vs 名义 5% → **微弱自持信号**（冲突陷阱），与探针⑮ 烈度锁定 ρ=0.423 呼应

### 3. 自相关
- 理论 τ = 3.98 年；拟合 τ = 4.64 年（lag 1–10 log 线性）
- C(1)=0.477 vs 理论 0.778——观测衰减更快（异质性混合使短期去相关加速）

### 4. 破缺判别（λ_b × 满意度）
| 相关 | ρ | p |
|---|---|---|
| λ_b × 国内满意度 std | 0.192 | 0.176 |
| λ_b × 满意度均值 | −0.171 | 0.231 |

方向一致（国内离散度高→破缺率高；满意度高→破缺率低）但不显著——社会数据噪声 + 51 国样本。

## 几何论结论

1. **两态 Markov 一阶近似成立**：π_W 偏差 13%、τ 同量级、单国无记忆 ✓
2. **破缺是泊松过程**（单国）：战争爆发无记忆——"纤维化锁定态的随机破缺"，探针⑮"爆发不锁定"的机制根源
3. **异质性 = 纤维化完整度的国家差异**：全局重尾完全由 λ_b 因国而异产生——不同国家耦合强度不同
4. **冲突微弱自持**：重构非完全无记忆（3/28 国拒绝），与烈度锁定呼应——破缺态有粘性
5. **破缺判别方向一致不显著**：λ_b 与国内离散度的关联存在但弱

## 诚实边界
- 年度离散化：段长度以年计，亚年过程不可见
- UCDP 门槛：25 战死/年才计冲突
- 全局合并受异质性影响（已用单国检验控制）
- 冲突段样本 28 国 ≥5 段，3 国拒绝 = 小样本
- 满意度（2017–22）与冲突历史（1946–2025）时间错配
- 非平稳：λ_b/λ_r 可能随时间漂移（未检验时变参数）
