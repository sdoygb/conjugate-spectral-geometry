# 探针⑩报告：CEPII 地理/结构距离 × 国家满意度差异

日期：2026-08-23
数据：CEPII GeoDist（dist_cepii.xls，225 国成对）＋ WVS Wave 7 v6.0（Q49 生活满意度 1-10）
口径：与探针⑭（ASJP 语言距离）完全同款 Mantel 型检验——上三角成对、Spearman、2000 次标签置换零假设
码表：ROU→ROM、SRB→YUG、NIR→GBR（北爱属英国）；65 国全覆盖（CEPII 无缺失）
有效成对：2016 / 2080（distw 缺失 64 对剔除）

## 结果

### [1] Mantel：log(地理距离) × |Δ满意度|
- ρ = +0.0594，z = +2.6σ，p = 0.0105 —— **显著**

### [2] 地理距离三分位 → 平均 |Δ满意度|（严格单调）
- T1（近，≤5325km）：0.801
- T2（中）：0.900
- T3（远，>10347km）：0.938

### [5] 偏 Mantel：控制地理距离后，语言距离仍存活
- ρ = +0.0849（原始 0.105 → 残差 0.085，n=1891）——语言距离携带**独立于地理**的耦合信息

## 判定

1. **地理邻近也是显著结构耦合**：p=0.011、三分位严格单调（0.801→0.900→0.938），方向与语言一致（近→相似）。排除链上第二个存活的预测子。
2. **共同边界是最强二元耦合**：Δ=−0.257（p=0.005）——邻国满意度差异平均小 0.26 分；殖民链接 Δ=−0.226（p=0.046）同样强。共享边界/历史联系 = 高耦合纤维间连接。
3. **语言与地理互为独立通道**：控制地理后语言 ρ 仅从 0.105 降到 0.085——两个结构代理捕捉"成对耦合配置"的不同分量。这与"锁位于成对耦合配置层、不可还原为单一标量"的判定一致。
4. **对照结论**：单对相关强度语言（ρ=0.105）> 地理（ρ=0.059），但地理的显著性更高（p=0.011 vs 0.033）；二元结构链接中边界最强（Δ=−0.257）。**不存在"哪个是锁"的单一答案——两者都是耦合层的部分投影**。

## 诚实边界

- distw 缺失 64 对剔除（3%），方向无偏
- 偏 Mantel 用残差化近似（非双重置换），p 值未给出——解读为"语言在控制地理后仍有独立信号"
- ROM/YUG（罗马尼亚、塞尔维亚）不在探针⑭ ASJP 语言表内，偏 Mantel 有效对为 1891/2016，覆盖 94%
- 地理距离与满意度差异均存在空间自相关，Mantel 置换标签部分缓解，非完全消除
- 共同边界/殖民链接存在聚类（邻国互为邻居），p 值为保守参考
- 贸易流（BACI）未下载——"耦合配置"的第三种实现（经济交换）仍空缺
