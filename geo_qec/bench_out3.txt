## 实验设计

同一判定问题：验证 CSS(RM(r,m), RM(r,m)) 仿射完备码的最小距离 d = 2^(r+1)。

- 路径 A（暴力枚举基准）：枚举权重 1..d-1 的全部 flip 集做 syndrome 测试，
  确认 syndrome 全非零（d >= 2^(r+1)）。枚举数 Σ_{w<d} C(n,w) 随 n 指数增长。
  无任何理论捷径，只做检测。
- 路径 B（几何无枚举，定理 10.30.2.01 + RM 最小权重定理）：
  (1) 列互异 O(n) 判定 -> 权重 2 全检测；
  (2) RM 最小权重定理（C⊥ = RM(m-r-1,m) 最小权重 2^(r+1)）-> 权重 3..d-1 层无逻辑；
  (3) 证书构造：仿射 (r+1)-平坦指标向量 ∈ C⊥ \ C -> d <= 2^(r+1)。
  O(n^2) 多项式完成，含抽样佐证（权重 3..d-1 共 3000 抽样）。

## 暴力版正确性锚点（全实测）

[[32,20,4]] = (r=1, m=5) 暴力完全闭合：
- 权重 1..3 共 5,488 flip 集，syndrome=0 计 0 -> d >= 4
- 权重 4 共 35,960 flip 集，syndrome=0 计 1,240，
  与定理 10.30.2.04 的 2-平坦数闭式 ag_flat_count(5,2) = 1,240 精确吻合 -> d <= 4
- 完整判定 d = 4，暴力耗时 0.03s

[[64,20,8]] = (r=2, m=6) 暴力全量闭合：
- 权重 1..7 共 704,846,176 flip 集全枚举（逐层：64 / 2,016 / 41,664 / 635,376 /
  7,624,512 / 74,974,368 / 621,216,192），syndrome=0 计 0（每层均为 0）
- -> d >= 8，暴力总耗时 318.8s（5.3 分钟）
- 权重 7 层实测速率 2,183,785 flip/s（作为外推基准）

## 结论

1. 交叉点位于 n ≈ 64, d ≈ 8 附近：更小的码暴力更快（几何版固定开销 ~0.02s 占优反超），
   更大的码几何版以指数差距碾压。
2. [[1024,252,32]]（10.30 表格中最大码）暴力枚举需 2.4×10^45 年，
   几何证书验证 0.7 秒——加速比 ~10^53。
3. 加速的本质不是代码优化，而是"不该算的不算"：列互异 + RM 最小权重定理
   替代了指数规模的错误空间枚举。暴力版 7.05 亿次 syndrome 测试全部为 0，
   这是对几何下界定理最直接的数值背书（用独立路径确认）。
4. 外推假设：单 flip 检测速率恒定（同机同实现）。n 增大时单 flip 成本只增不减
   （列宽 rc 增大、组合生成更贵），故外推偏乐观——真实暴力耗时只会更长。

## 工程备注

暴力枚举首版用 list-of-tuples -> np.array 转换，速率仅 125K flip/s（纯 Python
转换瓶颈，经 macOS sample 诊断确认）。第二版改 array('Q') C 级流式缓冲 +
np.frombuffer 零拷贝，速率 218 万 flip/s（17 倍），使 [[64,20,8]] 权重 7
全量（6.21 亿）从预估 80 分钟降至 4.7 分钟。校验列宽 > 63 位的码
（(3,8) 起）用 object dtype 数组承载 Python 大整数。
