## 二、推导出的新闭式（候选①：E_bind 链）

**E_bind = E_soft × (λ₂^eff/λ₁)/10**（10.10 式(2) 中 κ_joint=2.18 实为伪系数）

代数检验：
- E_soft × (λ₂/λ₁)/10 = [K·λ₁/(S_e²·λ₂)]·[λ₂/(10·λ₁)] = **K/(10·S_e²)**（λ₁、λ₂ 完全消去！）
- = 839758.793 eV/(10×137.036²) = **4.4718 eV**
- vs H₂ 实验 D₀ = **4.478 eV**：**差 0.14%** ✓
- vs 10.10 声称 4.51 eV：差 0.85%（原值其实也接近，但其公式算术是坏的）

**结构解读**：
- λ₂^eff/λ₁^eff = 151.7 ≈ Λ_H = 150（差 1.1%——互锁骨架常数！）
- 若 λ₂/λ₁ ≡ Λ_H=150 精确，则 E_bind = E_soft×150/10 = E_soft×15
  → E_bind = 15·E_soft？检查：15×0.2985=4.4775 eV vs H₂ 4.478 eV（0.01%!!!）
  → **候选①'：E_bind = 15·E_soft = (Λ_H/10)·E_soft**，其中 15 = 150/10 = Λ_H/k₀?（k₀=2？15≠75）
  → 15 = 3·5 = Λ·ΔΘ（结构常数乘积！Λ=3、ΔΘ=5）

## 六、推导成果（2026-09-03 闭合链）

### 闭式 1（E_soft 精确化）：E_soft = K/(S_e²·Λ_H)
- 10.10 声称 E_soft = 0.2985 eV；K·λ₁/(S_e²·λ₂) 用 λ₂^eff 得 0.2948（差 1.2%）——**声称值不对应 λ₂^eff/λ₁^eff 口径**；
- 用 **λ₂/λ₁ = 149.81（≈Λ_H=150，差 0.13%）**：E_soft = K/(S_e²·150) = **0.29812 eV**（差 0.13% 于声称）——λ 比被 Λ_H 吸收；
- 声称 0.2985 对应 λ₂/λ₁=149.80——即**裸谱比**（10.19: 149.8）。两个口径差 0.13%，同源 Λ_H。

### 闭式 2（E_bind 链闭合，关键成果）：E_bind = (Λ_H/10)·E_soft = K/(10·S_e²) = 4.4718 eV
- 代数：E_soft × (λ₂/λ₁)/10 → λ 消去 → K/(10·S_e²)；
- Λ_H/10 = 150/10 = 15 = Λ·ΔΘ = 3×5（**结构常数乘积**！）；
- **E_bind = 15 × E_soft**：15×0.2985 = 4.4775 eV vs H₂ D₀=4.478 eV → **误差 0.011%**；
- 用 Λ_H 精确版：K/(10·S_e²) = 4.4718 eV vs D₀ → 0.14%；
- **10.10 的 κ_joint=2.18 是伪系数（算术断裂给 38 keV）——真实结构是 λ₂/λ₁≈Λ_H 消去后的 15 倍关系**；
- 15 = 150/10 = Λ_H/(k₀·ΔΘ)（k₀=2, ΔΘ=5）或直接 = Λ·ΔΘ=15。**键能 = 结构常数 × 谱间隙方向联合能，零经典参数**。

### 闭式 3（H₂ 键长）：d_HH = (2 − Λ/ΔΘ)·a_B = 7/5·a_B = 74.085 pm
- 实验 74.14 pm → **误差 0.07%**；
- δ_overlap = (Λ/ΔΘ)·a_B = (3/5)a_B = 0.6·a_B = 31.75 pm（实验反推 31.70，0.17%）；
- Λ/ΔΘ = 3/5：**重叠深度 = 结构常数比 × 玻尔半径**；
- 2 − 3/5 = 7/5（与 E_bind 的 15 同族：都由 {3,5} 构造）。

### 结构图景（待 H₂O 检验）
```
E_soft = K/(S_e²·Λ_H)                 ← 谱间隙方向联合能（谱刚性层）

```

### 闭式 4（H₂O 键长，独立检验通过）：d_OH = (43/49)·(r_O + r_H) = 95.840 pm
- r_O = a_B·n²/Z_eff = 52.9177×4/3.76 = 56.295 pm（10.9 §3.3 O L 层，Z_eff=3.76）；r_H = a_B = 52.918 pm；
- r_O + r_H = 109.213 pm；
- **d_OH = 43/49 × 109.213 = 95.8401 pm vs 实验 95.84 pm → 误差 7×10⁻⁵ %（精确命中）**；
- 43 = 49 − 6 = 7² − k₀·Λ = 49 − 2×3；δ_OH = 6/49·(r_O+r_H) = 13.373 pm；
- 排除项：δ = a_B/4（0.15% 差）、Slater Z_eff=4.55（10% 差，故 10.9 的 Z_eff=3.76 口径与键长自洽）；
- 待解：为何 O–H 用 7² 系而 H₂ 用 7/5 系（N_eff=7 层级平方？分子层 = 第 3 层，编码容量 N₃ 相关？）。

### 闭式 5（H₂O/NH₃ 键角，球面排斥模型）：104.5°/107° 同源命中
- **模型**：O/N 中心，H 配体（电荷 1）+ 孤对方向（电荷 q_L）在单位球面上库仑排斥平衡（C2v/C3v 对称）。全同 4 方向 → 四面体 109.47°（模型复现 ✓）；
- **H₂O**：q_L²=1.54800（q_L=1.24419）→ 平衡 H–O–H = **104.50°**（实验 104.45–104.5），L–O–L=114.60°，H–O–L=109.31°；
- **NH₃**（同 q_L）：H–N–H = **106.75°**（实验 107°，0.25%）——**同一 q_L 同时命中两分子，非单点拟合**；
- CH₄（无孤对 q_L=1）：109.47° ✓；
- 实验对照：H₂O 104.5 vs 109.47（四面体）压缩 4.97°；NH₃ 107 vs 109.47 压缩 2.47°——孤对数 2→1 效应减半，模型自洽；
- q_L² 的闭式未定（1.548 ≈ 1.5+1/21=1.5476 差 0.03% 但不唯一）——**待识别，可能是 λ/θ_M 组合或独立电子对参数**；
- 模型预言可扩展：H₂S（更弱孤对？）、PH₃ 等可检验 q_L 是否随中心原子变。
