## §2 数学内核（10.91，全部引库内已有定理，零新公理）

状态空间 = Clifford 外代数扇区（命题 2.1）；归一化态流形 = CP^{dim−1}，
FS 度量（命题 2.2）；E 是 Morse 函数（命题 2.3）；H 在行列式基下 Bruhat 局部（命题 2.4）。

**四个组件 = 一个几何递降的四面**（定理 8.1），唯一对象 = 梯度
r = grad_FS E = (H−E)|ψ⟩（引理 A）与其法 Hessian H_N = Q(H−E)Q：

| 组件 | 几何操作 | 旧线状态 | 本项目 |
|---|---|---|---|
| ① 变分 | 切梯度 r_in 归零（RR/子流形临界化） | eigh 已实现 | 复用 |
| ② 停机 | Newton 增益 \|E_corr\| < ε_chem（**不是** \|r_out\|） | 用错度量 → 假收敛 | **全新** |
| ③ 扩张 | Bruhat 球贪心覆盖（对齐 × 新颖性） | 已几何化 | 复用 |
| ④ 修正 | 法向 Newton 步 δ* = −H_N⁻¹ r_out；E_corr = −⟨r,H_N⁻¹r⟩ | **只做了对角 PT2 → 结构性地板** | **全新：球块精确求逆** |

**为什么旧线收敛差 100 倍**（10.88 §7.17.2 实测 H₂CO/cc-pVDZ）：
- 变分 5000 态×1 波包：E = −114.1298，**高 52 mHa**（1500 态档 107 mHa）
- +对角 EN-PT2 top-200k：**地板 ~10 mHa**（10.91 推论 6.2：H_N 强行对角化丢弃空间外耦合，
  top-N 增大只逼近地板；50k→200k 仅 0.0156→0.0100）
- 化学精度 1.59 mHa → 差一个数量级+，且**对角近似无法靠调参突破**——结构性问题。

**本项目解法**（10.91 §6.2 (6.3) + §9）：H_N 按 Bruhat 2-球分块，
球内**稠密精确求逆**（包含全部球内单/双激发耦合），球间用块 Jacobi 软解耦：

```
H_N ≈ ⊕_κ H_N^(κ)（球心距>4 的球间严格为零）
E_corr ≈ −Σ_κ ⟨r|_{B_κ}, (H_N^(κ))⁻¹ r⟩_{B_κ}          (6.3)
块 Jacobi：δ^{(t+1)} = D⁻¹(r − Oδ^{(t)})，ρ(D⁻¹O)<1 收敛  (9.1)
后验双停机：(i) |E_corr^(k)|<ε_chem ∧ (ii) |E_corr^(k)−E_corr^(k−1)|<ε_chem  (9.2)
```

**已验证基础**：LiH/6-31G（dim=3025）球块/精确二阶 = 0.0000 mHa，
块 Jacobi ρ=0.12–0.17，4 趟到 2×10⁻¹¹（10.91 §12）。**缺口 = 大系统实现**（§13.4 开放项）。

## §3 求解器架构（全新主循环，不复用 wci.py）

```
geo10-15/solver/
├── core.py        # 主循环：约束子流形 Newton 递降
├── blocks.py      # Bruhat 球块枚举 + 球内稠密 H_N + 块 Jacobi（matrix-free 版）
├── rank.py        # 组合数系统 RankTable（bitstring↔rank，O(n_occ·n)，无 O(2^n) 表）
├── apply.py       # H|v⟩ 薄封装：复用 geoqc.exterior.sparse_action_sz_vec（可 GPU）
├── diag.py        # 空间外对角按需（复用 sector_diagonal_at）
├── stop.py        # 后验双停机判据 (9.2)
└── verify.py      # 机器精度校验（对小系统对照稠密 FCI；符号/单调性断言）
```

**主循环**（伪码，对应定理 8.1 图）：

```
V = {HF 种子};  H_cols = {}
loop:
  ① ψ, E = Rayleigh–Ritz(V)                  # 复用 geoqc eigh（r_in=0）
  ② r_out = Q(H−E)ψ                           # matrix-free，增量残差（复用思路）
  ③ 停机? (9.2) 双判据 → 输出 E + 边界报告    # 全新
  ④ 球块 Newton:
       centres = top-nc 残差行列式
       B_κ = Bruhat 2-球(centre) \ V（不相交分配）
       E_corr += −⟨r, (H_N^(κ))⁻¹ r⟩           # 球内稠密求逆（~10³–10⁴ 维）
       块 Jacobi 扫块间耦合直到增量 < ε        # 大系统可选 1 趟
  ⑤ 扩张: 新波包中心 = 球覆盖 argmax          # 复用 _ball_cover_select 逻辑
     V ← V ∪ B(D,2);  goto ①
```

**与旧线 wci.py 的本质差异**：
1. ④ 每轮做**球块精确求逆**（不是对角 PT2）——直接攻击 10 mHa 地板；
2. ② 停机用 |E_corr|（Newton 增益）而非 ‖r_out‖——消除假收敛（10.91 §7）；
3. 变分空间扩张与二阶修正**交替**（每轮先修正再扩张，10.91 §12.5 正确路径）；
4. 内存按"球块 × n_centers"预算，不依赖 max_wp_size 全局截断。

## §4 关键模块设计

### 4.1 rank.py —— 组合数系统 RankTable（复用 examples/wci_h2o_ccpvtz_test.py）
- 已实现并验证（n_orb=38 时无 O(2^38) 查表，O(n_occ·n) 按需排名）
- 本项目直接搬入 solver/，补 unrank（rank→bitstring，az_of 仍 O(C(n,k)) 数组：
  C(38,8)=4.89e7 × 8B = 391 MB，两表 782 MB——16 GB 可行）

### 4.2 apply.py —— H|v⟩
- 复用 `exterior.sparse_action_sz_vec`（已验证 == 稀疏，GPU doubles 可用）
- 关键：t_s（自旋轨道二体 76⁴×16B=534 MB）保留或跳过均可；
  H₂CO 真实分子已验证 GPU occupancy-aware doubles 路径（10.88 §7.17.2，8.17 min/5000 态）

### 4.3 blocks.py —— 球块 Newton（全新核心）
- 球枚举：对中心 C，`supp(H|C⟩) = Bruhat 2-球`（apply_fn 一次调用，行度 ~82440/H₂CO 38 轨道）
- 球块 H_N^(κ)：build_H_matrix 局部稠密（复用），减去 E·I；球 ~10³–10⁴ 维稠密可逆
- 不相交分配：贪心 first-come（旧线 compute_block_pt2_correction 同思路，但**每轮主循环都做**，
  且块间 Jacobi 作为可选精化）
- **本机内存预算**：n_centers=20、球均 ~3000 态 → 最大块 3000²×8B ≈ 72 MB；
  20 块同时物化峰值 ~1.5 GB（可串行逐块、GC，压到 <500 MB）

### 4.4 stop.py —— 后验双停机 (9.2)
- |E_corr| 每轮免费得到（④ 的自然输出）；(ii) 比较相邻轮/相邻 Jacobi 扫描增量
- 双重满足才停——三阶余项与块间耦合的后验 Richardson 代理（10.91 §9.2）

### 4.5 verify.py —— 纪律
- 符号断言：E_corr ≤ 0（引理 D，正值 = bug）
- 单调性：E_k 单调不增（命题 4.2，上升 = bug）
- 夹逼：小系统对照精确 Schur 补 |E_2nd^exact| ≤ |E_block| ≤ |E_PT2^diag|
- 每个里程碑输出：能量、|V|、内存峰值、墙钟、与参考的误差

## §6 风险与开放项（诚实记录）

1. **球覆盖充分性**：r_out 有 ~1850 万点，top-nc 球能否携带足够残差权重？
   —— 10.88 波包数 ∝ log dim（≤10 波包），理论乐观；M2 先在 2.1e13 上实测覆盖率。
2. **球块规模**：H₂CO 每行度 8 万，球大小随中心变化大；需 max 球尺寸裁剪与误差记账。
3. **ρ(D⁻¹O) 不可廉价计算**：以扫描增量几何递减为数值证据（10.91 §13.2 开放项）。
4. **Morse–Bott 近简并**：H₂CO 基态单参考主导（非强多参考），风险低；多参考系统留待后续。
5. **严格三阶界未定**：用后验双判据 (9.2)，数值可证伪（10.91 §13.1）。
