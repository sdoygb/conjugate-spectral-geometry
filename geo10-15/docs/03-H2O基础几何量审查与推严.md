## 2. 审查发现：内部矛盾与开放推导点

### A. H₂ 推导链与表格不一致（关键裂缝，先查清）
10.10 §3.1 步骤：r_H = d_contact·a_B·π/2 = 52.9 pm（d_contact=2/π 由 Berry 匹配"锁定"）；两 H 接触 d_HH = 2×52.9 − 45.6 = **60.2 pm**。
但表 1 记 H₂ 间距 **73.8 pm**（实测 74.1 pm，表值正确）。反推若 73.8 正确则 δ_overlap = 32.0 pm ⟹ Φ_HH/2π ≈ 0.212，而非步骤中 0.302/45.6 pm。
→ **§3.1 步骤 2–3 的 Φ=0.302 与表 1 的 73.8 pm 矛盾**，须核对哪一处错（可能推导步骤是旧值）。H₂O 的 d_OH=96.0 沿用同链，可信度取决于此。

### A2（本轮新发现）：Φ 记号混乱是根源
10.10 的"匹配度 Φ_HH/(2π)=0.302"与 10.19/7.8 的**渗透矩阵 Φ=[[12.4415, 22.6281],[22.6281, 12.4415]]**（本征值 λ_Φ⁺=35.07, λ_Φ⁻=−10.19）**是同一个符号 Φ，但显然是两个不同对象**：
- 渗透矩阵 Φ 是 2×2 常数矩阵（10.19 §2.1，本征值 35.07/−10.19），数值 ~10–20；
- 10.10 的 Φ_AB = ∫_{Σ_AB} F_ξη 是 Berry 曲率在接触面上的积分（"匹配度"），数值 0.302/0.212；
- **两者差两个数量级，绝不可能同源**——10.10 用 Φ 记号指称一个从未定义过数值的积分，10.19 却说 Φ 矩阵"数值预留给后续定量计算（本文不直接使用）"。
→ **10.10 键长链的 Φ_HH=0.302 是一个占位符数值，出处悬空**；10.19 明言 Φ 矩阵数值未算。这是 (C) 级标注下"构造未完成"的实况。

### B. κ_joint（联合截面曲率）的几何来源未展开
E_bind = K·λ₁/S_e²·κ_joint 是 (T) 级公式，但 κ_joint 值（H₂ 用 2.18）"由定理自旋锁定联合变分"给值——**κ_joint 如何由编码轨道接触几何导出的推导链缺失**。

### B2（本轮新发现）：E_bind 数值链算术不闭合
独立验算（geo_calc 精确）：
- K·λ₁/S_e² = 839758.793 eV × 391.05/137.036² = 17487 eV；×κ_joint=2.18 → **38122 eV = 38.1 keV**，而非 10.10 声称的 **4.51 eV**；
- 若目标是 4.51 eV，需要 κ_joint = 4.51×18778.9/(839758.8×391.05) = **2.58×10⁻⁴**，与文中 κ_joint=2.18 差 8453 倍；
- 对照 E_soft = K·λ₁/(S_e²·λ₂) = 0.2948–0.2976 eV（用 λ₂^eff=59324.3 或裸 λ₂=58760.77），与 10.10 声称 0.2985 eV 差 0.3–1.3%——E_soft 链基本闭合（差 λ₂ 取值的口径）；
- E_bind/E_soft 声称比 = 4.51/0.2985 = 15.11，而 λ₂/λ₁ = 151.7——**恰好差 10 倍**。
→ E_bind 公式的量纲/系数链需要审计：38.1 keV vs 4.51 eV 差 ~8450 ≈ S_e·61.7？或 λ 比 151.7 的某种组合。可能 (a) κ_joint 定义含隐藏因子；(b) 公式漏/多了 S_e 或 λ 的幂次；(c) K 在此处不是质量量子而是别的标度。**这是键能链的算术硬伤，推导必须从这里修正**。

### C. Φ_OH（H₂O 键长用）数值来源未给
δ_overlap = χ_L·Φ_AB/2π，Φ_AB = ∫_Σ F_ξη。H₂ 的 Φ_HH/2π=0.302（或 0.212?，见 A）有值；**Φ_OH（H₂O 键长用）文中未给数值**——H₂O 键长 96.0 的 δ 来源不明。

### D. 孤对电子在 H₂O 键角中是否计入不明确
eq.(6) 用 Q̃_O=2.52（纯质量，16^⅓）得 104.21°（接近实测 104.5°，0.3%）。但 10.10 明言 NH₃ 需孤对 Q_lp 压缩角度、孤对几何定义为开放问题 2.4a。**H₂O 有 2 对孤对却不提修正而得 104.21°——是 Q̃ 已含孤对效应还是未含？**

### E. 键角 eq.(6) 的电荷来源
eq.(6) 用 Q̃_j/|r−r_j|² 的向量平衡——库仑型 1/r² 排斥的几何来源未在 10.10 内证明（标注为 (T) 球面平衡命题，但排斥律本身出处待查）。Q̃_O=2.52 仅来自质量比 16^⅓，为何排斥强度取质量立方根？(C) 级参考系问题见 10.10 原文。

## 3. 推严路径（建议顺序）

1. **先解裂缝 A**：核对 H₂ d_HH=60.2 vs 73.8 pm——决定整个接触间距链的正确形式；
2. **推严 κ_joint**：从编码轨道接触面（Berry 曲率 F_ξη、截面曲率）推导联合截面曲率 κ_joint（B 的落点）；
3. **确定 Φ_OH**：给出 H₂O 键长的 Berry 匹配度数值与来源（C）；
4. **澄清孤对**：H₂O 键角 104.21° 的孤对地位（D）；
5. 之后接化学性质：解离能（2×E_bind + 修正）、振动频率（键势曲率）、偶极、极化率。

## 4. 纪律
