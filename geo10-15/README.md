# geo10-15

**全新子项目：在本机上把 dim ≈ 10^15 的分子系统收敛到化学精度。**

> 目标（用户定义，2026-09-03）：dim = 10^15 左右，精度 = 化学精度（总能量误差 < 1.59 mHa）。
> 验收系统：H₂CO/cc-pVDZ（S_z=0 扇区 C(38,8)² = 2.392×10^15），参考 CCSD(T) = −114.1821464120 Ha。
> 本机：iMac20,1 · 16 GB RAM · 12 线程 · AMD RX 570 8 GB (OpenCL)。

## 为什么新开（旧线差距）

旧线（geocore/geoqc 的 WCI + 对角 PT2）能算到 dim=2.39e15，但收敛差化学精度 ~100 倍：
变分 5000 态高 52 mHa（1500 态 107 mHa）；对角 EN-PT2 有结构性地板 ~10 mHa（丢弃空间外耦合）。
详见 `docs/01-立项与差距根因.md`。

## 路线（用户确认）

- 收敛方法全新：按 10.91 约束子流形 Newton 递降完整化——球块精确求逆 (6.3) + 块 Jacobi 软解耦 (9.1) + 后验双停机 (9.2)，攻击对角 PT2 的 10 mHa 地板。
- 底层积木复用：外代数扇区、组合秩索引、matrix-free H·v、S_z 投影、GPU occupancy-aware doubles（geocore/geoqc）。
- 设计文档：`docs/02-求解器设计-约束子流形Newton.md`（待逐节确认）。
