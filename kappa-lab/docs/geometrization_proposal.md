# kappa-lab 几何化可行性论证（v0.3）

日期：2026-08-20 | 状态：检验 1 关闭；G1 几何管道已实证（P1/P2/P4/P5 通过，P3 修正后命中）

## 1. 目标与验收标准

把 WL OoD 管道中尽可能多的量纳入共扼谱几何推导。**验收标准（一句话）：几何论必须给出
标准方法给不出的量，或独立预言标准量——重新命名不算。**

任何几何声称必须通过三关（`kappa_lab/geo/validate.py` 自动审查）：

- **C1 闭合性**：推导链每步有定理/命题支撑，无"恰好 X 倍"后验因子
- **C2 先验性**：预言数值先于数据确定（不允许先看答案再选幂次/因子）
- **C3 无循环**：不允许用观测锚定反推再算回（η_K 教训，教学反馈 3）

层级标注：T=定理级 / P=命题级（显式假设）/ C=构造级（构造输入）/ X=不可几何化。

### 反例展示：#5 σ_n 数字巧合（禁止模式）

## 5. 检验 1：P(l) 局部谱指数 vs 几何指数族（2026-08-20 执行）

- **预言**：若谱刚性 −5/3 推论（10.8 §5.3）在 κ 场有对应物，则存在 ≥2 倍动态范围
  的尺度区间使 |dlogP/dlogl + 5/3| < 0.1
- **协议**：sampled 3 宇宙学 × 30 仿真，加噪 σ_n=0.0258（与基线一致），50 细 bin，
  3 点滑动线性拟合局部指数；脚本 `scripts/check_spectral_index.py`，结果
  `results/spectral_index.npz/.png`
- **结果**：

| 几何候选 | 最优窗口 | 平均 n_eff | 判定 |
|---|---|---|---|
| −5/3（谱刚性） | l∈[126,263] | −0.962 | **未命中**（差 0.7；单 bin l≈138 处 −1.74 擦边但窗口不满足） |
| −1（对数区） | l∈[126,263] | −0.962 | 命中但为 ΛCDM 已知物理（κ 谱大角标度），非几何预言 |
| 0（白噪声） | l∈[3467,7244] | −0.033 | 平凡闭合（候选 #2，平移不变性） |
| −3/2、−2 | — | — | 未命中 |

- **诚实结论**：几何指数族未以 ≥2 倍动态范围的幂律区形式出现在 WL κ 谱中。
  n_eff 从大尺度 ≈−1（ΛCDM κ 信号）平滑过渡到小尺度 ≈0（形状噪声主导），
  谱形由物理决定。**路径 #1 关闭**。单 bin 擦边（−1.74@l≈138）不构成幂律区，
  不扩展检验（防后验挑选）。

## 5b. 检验 2：G1 端到端几何管道（2026-08-20 执行，full 数据）

- **预言**（数据前固定，防后验纪律）：
  - P1 训练加噪 κ 图 S̃ 中位数 ∈ (1,2)（谱条件窗口无标度化）
  - P2 纯白噪声 S̃ = 1（Jensen 精确下界：Σ1/sin²θ_i ≥ n²/Σsin²θ = n²）
  - P3 额外噪声 → S̃ 减小（向白噪声退化）
  - P4 模糊 → S̃ 增大（谱不均匀度增加）
  - P5 干净新宇宙学 → S̃ 弱分离（结构同官方 d=+0.11）
  - H1：谱条件（100<S<200）从观测者位置推广到场统计量
- **编码器**：κ 图 → log10 P(l) 10 bin（标准）→ sin²θ_i = P_i/ΣP → S = Σ1/sin²θ_i → S̃ = S/n²
- **分数**：|S̃ − μ_train|（双侧偏离），训练集标定，测试集零参与；rng 顺序与基线逐位一致
- **结果**：

| 预言 | 结果数值 | 判定 |
|---|---|---|
| P1 | 训练 S̃ 中位 1.933，q16-84=[1.73, 2.16] ∈ (1,2) | ✅ 通过 |
| P2 | 白噪声 S̃ 中位 1.003 ≈ 1（Jensen 下界） | ✅ 通过 |
| P3 | 0.5σn: 3.60（增大）；1.0σn: 1.82（≈训练 1.93） | ⚠️ 表述错误，修正后命中 |
| P4 | blur_1px: 9.3×10⁵；blur_2px: 6.7×10⁸（爆炸性增大） | ✅ 通过 |
| P5 | 种子 d=+0.10（官方 +0.11），TPR=0.0089（弱分离） | ✅ 通过 |
| H1 | 谱条件窗口实证成立（训练中位精确落窗） | ✅ 实证支持 |

- **P3 修正记录**：原预言"额外噪声→S̃ 减小"未对齐官方扰动定义（扰动分支不加形状
  噪声：无噪基线+噪声）。修正后：无噪+1.0σn = 训练噪声水平 → S̃≈训练（实测 1.82
  vs 1.93 ✓）；无噪+0.5σn → S̃ 介于纯信号与标准加噪之间（实测 3.60，合理）。
  **几何论预言未失败，是预言表述未对齐实验定义**。
- **对比官方基线**：

| 扰动 | 官方基线 TPR | G1（1 维几何量）TPR |
|---|---|---|
| blur_1px | 1.00 | 1.00 |
| blur_2px | 1.00 | 1.00 |
| extra_noise_0.5sn | 1.00 | 0.995 |
| extra_noise_1.0sn | 0.015 | 0.013 |

- **结论**：1 维代数作用量 ≈ 10 维 χ²@MAP 检测能力（信息压缩 10 倍几乎无损；代价：
  检测裕度 d 从 23.7 降至 4.2）。几何论第一个实证支持的端到端数值预言。开放问题：
  训练 S̃ 分布宽度 [1.73,2.16] 的信息内容；blur 时 S̃ 动态范围 10⁸ 的数值稳定性；
  场编码定理（H1 形式化）。
