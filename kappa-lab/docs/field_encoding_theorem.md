## 1. 定义

- **n-bin 占比编码**：对功率谱 bin 值 P_i > 0（i = 1..n），x_i = P_i / Σ_j P_j，Σx_i = 1
- **对角作用量**：S_n(x) = Σ_i 1/x_i
- **无标度作用量**：S̃ = S_n / n²
- **3 扇区完整作用量**（主库 #362）：S₃(θ) = Σ_{i=1}^3 1/sin²θ_i + Σ_{i<j} 1/(sinθ_i sinθ_j)，
  θ_i ∈ (0, π/2)，Σθ_i = π/2

**注意形式差异**：G1 编码是 n 扇区对角形式（占比归一化 Σx=1）；主库 #362 是 3 扇区
完整形式（角度约束 Σθ=π/2 + 交叉项）。两者数值不可直接比较——这正是桥接难点。

## 2. 已证定理（提交主库）

### 定理 F1（对角作用量的白噪声下界）

对任意 x_i ≥ 0，Σx_i = 1，n ≥ 2：

$$\boxed{S_n(x) = \sum_i \frac{1}{x_i} \geq n^2}$$

等号当且仅当 x_i = 1/n 全体（完全均匀 = 白噪声）。

证明：f(x) = 1/x 在 (0, ∞) 严格凸（f'' = 2/x³ > 0）。由 Jensen 不等式：
Σ 1/x_i ≥ n·f(Σx_i/n) = n·(n/Σx_i) = n²。等号条件由凸性严格性：x_i 全等 → x_i = 1/n。∎
（等价形式：调和平均 ≤ 算术平均。）

推论 F1.1：S̃ ≥ 1 对任意占比编码成立；白噪声精确 S̃ = 1。

### 定理 F2（幂律谱作用量的严格单调性）

设 P_i = r^(−αi)（i = 0..n−1，r > 1，α ≥ 0，对数等距 bin），则：

(i) S̃(0) = 1（α=0 即白噪声，F1 等号情形）；
(ii) S̃(α) 在 [0, ∞) 上严格递增；
(iii) lim_{α→∞} S̃(α) = ∞（单 bin 占优极限）。

证明：占比 x_i = r^(−αi)/A(α)，A(α) = Σ_{j=0}^{n−1} r^(−αj) = (r^(nα)−1)/(r^α−1)。
S(α) = Σ_i 1/x_i = A(α)·A(−α)（展开后交叉求和）。
d/dα ln S = ln r · [g(nα) − g(α)]，其中 g(t) = t/(1−e^(−t·ln r))。
g 严格增：g'(t) = [1 − e^(−ct)(1+ct)]/(1−e^(−ct))² > 0（c = ln r > 0；
分子 h(t) = 1−e^(−ct)(1+ct) 满足 h(0)=0，h'(t) = c²te^(−ct) > 0 for t > 0）。
n > 1 且 α > 0 ⇒ g(nα) > g(α) ⇒ d/dα ln S > 0 ⇒ S 严格增。S(0) = A(0)² = n²。∎

### 推论 F2.1（窗口 ↔ 斜率映射）

对幂律谱，S̃ ∈ (1, 2) ⇔ α ∈ (0, α*)，α*(n, r) 由 A(α*)A(−α*) = 2n² 唯一确定。
数值（n=10, r = 100^(1/9) ≈ 1.668）：**α* ≈ 0.586**。

**适用范围（n=20 首版缺陷界定）**：编码器 l 动态范围必须 ≤ l_Nyquist = π/pixsize
（本数据 1424×176、2' 像素：l_Nyquist ≈ 5400）。n=20 首版用 [100, 10⁴] 时最高 bin
[7943, 10⁴] 超出采样能力 → Nmode=0 → P=0 → 占比钳位保护值 → 全图 S̃ 退化为同一
数值 2.5×10²⁷（技术缺陷，非物理结论）。修正为 [100, 5000] 后正常。

### 定理 F5（单调谱作用量的动态范围上界）★ v0.4 新增

对单调降占比 x₁ ≥ x₂ ≥ ... ≥ x_n > 0（Σx_i = 1，n ≥ 2），定义动态范围 R = x₁/x_n ≥ 1。则：

$$ S_n(x) = \sum_i \frac{1}{x_i} \leq \left(n-1+\frac{1}{R}\right)\left(R+n-1\right) $$

等号由**单尖峰谱** x = (R, 1, ..., 1)/(R+n−1) 达到（KKT/凸优化顶点）。

推论 F5.1（一般谱窗口的保守充分条件）：对任意单调谱，S̃ < 2 的充分条件是
R < R*(n)，其中 R* 由 (n−1+1/R*)(R*+n−1) = 2n² 唯一确定。数值（n=10）：**R* ≈ 13.03**。

证明：Σ1/x 在 x > 0 上严格凸（Hessian 对角 2δ_ij/x_i³ > 0）→ 最大化在凸约束集
（Σx=1，单调，x₁ ≤ Rx_n）的顶点。顶点分析：约束 x₁ ≤ Rx_n 必活跃（1/x 减函数，
增大 x₁ 提高目标）；其余质量由单调性收紧到 x₂ = ... = x_n（若 i ≥ 2 处 x_i > x_{i+1}，
转移质量到 x₁ 提高目标）→ 顶点 x = (Rx_n, x_n, ..., x_n)，Σx = 1 → x_n = 1/(R+n−1)。
S_max = 1/(Rx_n) + (n−1)/x_n = (n−1+1/R)(R+n−1)。S_max 严格增于 R（dS_max/dR
= (n−1) − (n−1)/R² > 0 当 R > 1）→ 推论成立。∎

对照 F2.1：幂律谱的窗口允许动态范围 R_pl = r^((n−1)β*) ≈ 14.88（n=10）> R* = 13.03
——幂律谱功率平滑分布（无尖峰），比最坏情形（单尖峰）允许更大动态范围。

### 定理 F4（噪声-窗口映射）★ v0.3 新增

设加噪幂律谱 P_i = A·l_i^(−β) + N（β ≥ 0，l_i = l₀·r^i，i = 0..n−1，r > 1），
无量纲噪声-信号比 ρ = N / (A·l₀^(−β))，归一化信号形 u_i = r^(−βi)（u₀ = 1）。
占比 x_i = P_i/ΣP_j，对角作用量 S(β, ρ) = Σ_i 1/x_i。则：

(i) **闭式**：S(β, ρ) = (Σ_i u_i + nρ) · Σ_i 1/(u_i + ρ)；

(ii) **噪声单调性**：对固定 β，S 关于 ρ 严格单调降：

$$ \frac{dS}{d\rho} = -\frac{1}{2}\sum_{i,j} \frac{(a_i - a_j)^2 (a_i + a_j)}{a_i^2 a_j^2} \leq 0, \quad a_i = u_i + \rho $$

等号当且仅当全部 a_i 相等（β = 0 或 ρ → ∞）；

(iii) **端点**：S(β, 0) = A(β)A(−β)（F2 的纯信号值），S(β, ∞) = n²（F1 下界）；

(iv) **窗口条件**：S̃ ∈ (1, 2) ⇔ **β ≤ β*（任意 ρ ≥ 0）** 或 **[β > β* 且 ρ > ρ_min(β)]**，
其中 β* 由 A(β*)A(−β*) = 2n² 定义（F2.1），ρ_min(β) 由 S(β, ρ_min) = 2n² 唯一确定；

(v) ρ_min(β) 在 (β*, ∞) 从 0 上升至峰值 ≈ 0.085（β ≈ 1.7），后缓降至渐近值
ρ_∞ ≈ 0.083（β → ∞；n=10 的解析极限 ρ_∞ = 2n² 的渐近解 ≈ 0.0826）。

证明：
(i) x_i = (u_i + ρ)/Σ_j(u_j + ρ)（整体因子 A·l₀^(−β) 消去），
S = Σ_i Σ_j (u_j + ρ)/(u_i + ρ) = (Σ_j(u_j + ρ))·(Σ_i 1/(u_i + ρ))。∎
(ii) a_i = u_i + ρ。dS/dρ = d/dρ[(Σa)(Σ1/a)] = Σ1/a − (Σa)(Σ1/a²)，
写成双和：dS/dρ = nΣ_i 1/a_i − Σ_i Σ_j a_j/a_i² = Σ_{i,j}(1/a_i − a_j/a_i²) = Σ_{i,j}(a_i − a_j)/a_i²。
对称化（i ↔ j 平均）：= (1/2)Σ_{i,j}[(a_i−a_j)/a_i² + (a_j−a_i)/a_j²]
= (1/2)Σ_{i,j}(a_i−a_j)(1/a_i² − 1/a_j²) = −(1/2)Σ_{i,j}(a_i−a_j)²(a_i+a_j)/(a_i²a_j²) ≤ 0。
每项 (a_i−a_j)² ≥ 0、a_i + a_j > 0、分母 > 0；等号当 a_i = a_j 全对。∎
(iii) S(β,0) = (Σu)(Σ1/u) = A(β)A(−β)（u_i = r^(−βi)，等比求和，即 F2 的 S(α)）；
ρ → ∞ 时 Σ1/(u+ρ) → n/ρ、Σu + nρ → nρ ⇒ S → n²。∎
(iv) 由 (ii)(iii)：S(β,ρ) 从 S(β,0) 连续单调降至 n²。若 S(β,0) ≤ 2n²（即 β ≤ β*），
则 S 恒 ∈ (n², 2n²)（开区间：ρ < ∞ 时严格大于 n²）→ 窗口对任意 ρ 成立。
若 S(β,0) > 2n²（β > β*），端点异号（S(β,0) − 2n² > 0，n² − 2n² < 0）+ 严格单调
⇒ 唯一 ρ_min(β) 使 S = 2n²；ρ > ρ_min 时 S ∈ (n², 2n²)。∎
(v) 数值解（n=10, r = 100^(1/9)）：ρ_min 从 β* 处 0 上升，β ≈ 1.7 处峰 ≈ 0.085，
β → ∞ 渐近 0.0826（由 S_∞(ρ) = (1+nρ)(1/(1+ρ) + (n−1)/ρ) = 2n² 解出）。∎

**F4 的物理表述（M4 形式化）**：谱条件窗口 (1,2) ⇔ 观测者的观测谱（信号+噪声）
必须满足：信号足够陡（β > 0，否则无信息）且噪声超过阈值（ρ > ρ_min(β)，否则
纯信号谱越界）。**可生存观测者 = 信号 + 阈上噪声**。纯信号（ρ=0，β>β*）越界；
纯噪声（β=0 或 ρ=∞）落在开区间边界 S̃=1——非严格可生存。
