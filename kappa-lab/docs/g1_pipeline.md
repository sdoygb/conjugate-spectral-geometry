## 管道定义

```
输入 κ 图（标准格式）
  → log10 P(l)，10 bin，l∈[100,10⁴]（标准统计量，与基线一致）
  → sin²θ_i = P_i / Σ_j P_j          （占比归一化，线性功率）
  → S = Σ_i 1/sin²θ_i                （代数作用量，10.8 §2 形式）
  → S̃ = S / n²                       （无标度化，n=10）
  → 分数 |S̃ − μ_train|（双侧偏离，训练集标定）
  → TPR@FPR（官方评估协议）
```

理论依据三层：
1. 编码器是几何论的：`S(σ)=Σ1/sin²θ_i` 是 10.8 §2 的代数作用量形式，非拼凑函数
2. 下界是数学定理：Jensen 不等式 → S̃ ≥ 1，等号当且仅当谱完全均匀（白噪声）
3. 窗口是几何论已有内容：谱条件 100<S<200 的比值结构 1:2，无标度化为 S̃ ∈ (1,2)

## 预言清单（数据前固定，防后验纪律）

- P1：训练加噪 κ 图 S̃ 中位数 ∈ (1,2)
- P2：纯白噪声 S̃ = 1（Jensen 精确下界）
- P3：额外噪声 → S̃ 减小（向白噪声退化）
- P4：模糊 → 谱更陡 → S̃ 增大
- P5：干净新宇宙学 → S̃ 弱分离（结构同官方 d=+0.11）
- H1：谱条件窗口从"观测者位置"推广到"场统计量"（定理推进点，本报告实证检验）

## P3 修正记录（诚实标注）

- 原预言："额外噪声 → S̃ 减小（向白噪声退化）"——隐含假设"从标准加噪图再加噪声"
- 实际扰动定义（官方 baseline_official.py）：扰动作用于**无噪图**（分支不加形状噪声）
- 修正后预言：
  - 无噪 + 1.0σ_n → 统计等价于训练分布（信号 + 1.0σ_n）→ S̃ ≈ 训练水平，不可检测
  - 无噪 + 0.5σ_n → S̃ 介于纯信号（更陡）与标准加噪之间
- 实测：1.0σ_n → S̃=1.823 vs 训练 1.933 ✓ 命中；0.5σ_n → S̃=3.602（> 训练，方向合理）✓
- 结论：**几何论本身未失败，是预言表述未对齐扰动定义**。修正后 P3 命中。

## 结论

1. **检测能力持平**：1 维代数作用量达到 10 维 χ²@MAP 的检测能力（3/4 扰动 TPR ≥ 0.995），信息压缩 10 倍几乎无损
2. **代价**：检测裕度减小（d：23.7→4.2），TPR 仍高但余量变薄
3. **种子敏感度数值一致**（+0.10 vs +0.11）：两个不同分数给出几乎相同弱分离——种子敏感度是"谱形对 Ωm/S₈ 不敏感"的内在性质，与分数选择无关
4. **H1 实证支持**：谱条件窗口（无标度化 (1,2)）在真实 WL κ 场统计量上成立——几何论"可生存观测者位置"窗口第一次在数据上验证

## 开放问题
