# 10.54 量子纠错解码错误模式的几何结构：拓扑分类的配对层显现

**编号**：10.54 | **日期**：260815 | **系列**：应用（量子纠错→程序验证接口） | **语言**：CN | **性质**：程序验证与几何解读

**摘要**：把共扼谱几何的 A0/A1 拓扑分类（A0 = 局部代数命题，Berry 相位 0；A1 = 整体拓扑命题，Berry 相位 2π）与量子纠错错误模式建立对应，并用标准工具（Stim 模拟器 [1] + PyMatching 匹配解码器 [2]）在 surface code 上做程序验证。核心结果：(1) 有效阈值 p_th ≈ 0.02–0.03（L=4 unrotated memory_z，四噪声通道，纯 depolarizing 阈值 ~0.10 被压低）；(2) 在码工作区（p=0.005，pL=1.45%），A1（逻辑错误）与 A0（可修正错误）的空间结构在**激发层**（syndrome 图案）只有弱区分（最强 cross 穿越率 1.72×），在**配对层**（MWPM 解码链投影）出现强区分——配对链总长度 total_dist 3.00×、配对边数 1.67×；随码距 L 增大，绝对拓扑信号线性存活：A1−A0 = L 精确成立（L=4/6/8 × 3 种子，§4.3），显式长链率随 L 增大至 51.2%；(3) 对照组（p=0.03，pL=38.7%）：全部特征塌缩（total_dist 1.00×、cross 1.01×）——**结构信息只在码工作区显现**。几何解读：拓扑信息不在初始数据层（激发），而在约束互扼的全局解层（配对）显现——"互扼锁定"思想的程序实证；逻辑错误的配对代价 = 恰好一个码距（A1−A0 = L），即非平凡同调类的几何成本。全部数值可复现（§6）。

## §1 引言与动机

量子纠错解码是容错量子计算的工程核心：稳定子测量给出 syndrome（激发图案），解码器（匹配解码 MWPM [2]）把激发配对成错误链并恢复逻辑态；解码失败（逻辑错误）是阈值之上唯一的失效模式。标准理论对"逻辑错误是什么"的回答是拓扑的：表面码 [3][4] 的逻辑错误 = 连接相对边界的错误链（非平凡拓扑），可修正错误 = 局域链（平凡拓扑）。

这一回答与共扼谱几何的 A0/A1 拓扑分类（主库约定：A0 = 局部代数命题，Berry 相位 0；A1 = 整体拓扑命题，Berry 相位 2π）在结构上同构。本文的目标是把这一对应做成可检验的定量形式，并用程序验证回答两个问题：

- **H1（激发层）**：A1 与 A0 的 syndrome 空间结构是否可区分？
- **H2（配对层）**：A1 与 A0 的解码链投影结构是否可区分？二者哪个更强？

框架的"互扼锁定"思想给出一个先验：拓扑本性显现在约束优化的全局解中（解码配对 = 最小总链长的互扼约束），因此 H2 应强于 H1。§4 实测支持这一先验（total_dist 3.00× vs cross 1.72×；标度律 A1−A0 = L，§4.3）。

与已有量子纠错系列的关系：10.27 重建量子纠错码的定义层（量子比特的 Clifford 根源、稳定子判据）；10.28/10.29 给出方向完备码系列的损失标度律（θ⁴）与可实验预言；10.43 给出拓扑量子计算的 Cl8 方案。本文不重建理论层，而是把标准工程工具（Stim/PyMatching）作为检验平台：**在 A0/A1 分类与解码错误模式之间建立定量的对应，并验证其可观察性**——检验对象是"错误模式的结构分类"，与 10.29 的"损失标度"互补。

## §2 理论框架：A0/A1 分类与错误模式的对应

### 2.1 几何论 A0/A1 分类

主库拓扑分类约定：
- **A0**：局部代数命题——Berry 相位 = 0，局域结构，可被局域操作完全描述（代数恒等式、群论计算、微积分命题）；
- **A1**：整体拓扑命题——Berry 相位 = 2π，整体结构（叶空间拓扑、Hopf 纤维化、Euler 类等），需要整体几何结构才能判定。

### 2.2 对应关系

| 几何论 | 量子纠错（surface code） |
|---|---|
| A0（局域，Berry 相位 0） | 可修正错误：局域错误链，配对链短（~2 单位），平凡拓扑 |
| A1（整体，Berry 相位 2π） | 逻辑错误：跨边界错误链（连接相对边界），非平凡拓扑 |
| 互扼锁定（约束互扼的全局解） | MWPM 解码：最小总链长的全局配对 |

### 2.3 可检验假设

- **H1（激发层）**：A1 样本的 syndrome 图案（激发集空间结构）与 A0 不同。特征：激发数 exc、空间直径 diam、最大连通簇 cluster、穿越率 cross（激发集是否同时接触码的相对边界）、最近激发对距离 min_pair。
- **H2（配对层）**：A1 样本的解码链投影（MWPM 配对边几何）与 A0 不同。特征：配对边数 n_edges、配对链总长度 total_dist、最长边 max_dist、长边率 long_rate、直度 strght、边界边数 bdry_edges。
- **框架先验（互扼锁定）**：H2 强于 H1——拓扑本性在约束互扼的全局解层显现，而非局部初始数据层。

## §3 方法：Stim/PyMatching 管道

### 3.1 电路

`stim.Circuit.generated("surface_code:unrotated_memory_z", distance=4, rounds=3)`，四噪声通道等强度 p：

- after_clifford_depolarization = p
- before_round_data_depolarization = p
- after_reset_flip_probability = p
- before_measure_flip_probability = p

规模：49 qubits，72 detectors。detector 坐标 (x, y, t) 由 `circuit.get_detector_coordinates()` 提取（x, y ∈ [0, 6]，t ∈ {0, 1, 2}，unrotated 码的稳定子网格 7×7）。

### 3.2 解码

1. 电路 → `detector_error_model`（decompose_errors=False）
2. `pymatching.Matching.from_detector_error_model` 建图
3. 采样：`circuit.compile_detector_sampler().sample(shots, separate_observables=True)`
4. 解码：`matching.decode_batch`（逻辑错误率）；`matching.decode_to_edges_array`（配对边，逐样本）

### 3.3 特征定义

激发层（每样本，按时间层分组，平面曼哈顿距离；surface code 有边界，无周期拓扑）：

| 特征 | 定义 |
|---|---|
| exc | 激发 detector 数 |
| min_pair | 同层内最近激发对距离（单比特错误恒产生相邻稳定子激发对 → 期望恒为 2） |
| diam | 同层内最大成对距离 |
| cluster | 同层连通簇最大尺寸（曼哈顿 ≤ 2 连通） |
| cross | 激发集是否同时接触码的相对边界（x 两端或 y 两端） |

配对层（MWPM 配对边；节点索引 ≥ num_detectors 为边界节点；detector-detector 边取曼哈顿距离，detector-boundary 边取 detector 到最近边界距离）：

| 特征 | 定义 |
|---|---|
| n_edges | 配对边数 |
| total_dist | 所有配对边空间距离之和 |
| max_dist | 最长配对边距离 |
| long_rate | max_dist ≥ 4 的指示 |
| strght | 最长内部边的直度 max(dx,dy)/(dx+dy) |
| bdry_edges | 边界边数 |

### 3.4 复现性

脚本 `toric/toric_decode.py`；环境 stim 1.15.0 + pymatching 2.4.0 + numpy；参数 `--L 4 --rounds 3 --noise p --shots N`。采样未固定随机种子——本文数值为单次运行（每组参数独立随机样本）；中位数级特征（total_dist、n_edges、exc、cross 等）在两轮独立运行间稳定复现，稀有特征（长边）样本依赖（见 §4.3 注记）。

## §4 结果

### 4.1 阈值扫描：有效阈值与"码工作区"

L=4, rounds=3，每点 20000 shots：

| p | pL（逻辑错误率） |
|---|---|
| 0.005 | 0.0145 |
| 0.01 | 0.070 |
| 0.02 | 0.240 |
| 0.03 | 0.384 |
| 0.05 | 0.481 |
| 0.07 | 0.505 |
| 0.10 | 0.501 |
| 0.15 | 0.501 |

有效阈值 p_th ≈ 0.02–0.03（四噪声通道将纯 depolarizing 阈值 ~0.10 压低至约 1/4）。p ≥ 0.05 后 pL 饱和于随机猜测 0.50——码完全失效。**结论 A（工作区）**：结构区分实验须在 p ≪ p_th 进行；p ≈ p_th 时激发密度淹没结构（§4.4 对照组验证）。

### 4.2 激发层（H1）：弱区分

p=0.005，shots=20000，pL=0.0145（A0=19711，A1=289）：

| 特征 | A0（可修正）med (q90) | A1（逻辑错误）med (q90) | A1/A0 |
|---|---|---|---|
| exc 激发数 | 5.0 (9.0) | 8.0 (13.0) | 1.60× |
| diam 空间直径 | 4.0 (8.0) | 6.0 (10.0) | 1.50× |
| cluster 最大簇 | 2.0 (4.0) | 3.0 (6.0) | 1.50× |
| cross 穿越率 | 22.3% | 38.4% | **1.72×** |
| min_pair 最近对 | 2.0 (4.0) | 2.0 (2.0) | 1.00×（无区分） |
| bdry 边界距离 | 0 (0) | 0 (0) | 无区分 |

方向全部一致（A1 更复杂、更大尺度、更常穿越），但区分度为统计性偏置（1.5–1.7×，中位数差异），非干净分离。min_pair 恒为 2——单比特错误恒产生相邻稳定子激发对，该量不携带拓扑信息（对照特征，验证特征提取正确性）。

### 4.3 配对层（H2）：强区分——拓扑信息在配对层显现

p=0.005，shots=20000（同一次运行）：

| 特征 | A0（可修正）med (q90) | A1（逻辑错误）med (q90) | A1/A0 |
|---|---|---|---|
| n_edges 配对边数 | 3.0 (5.0) | 5.0 (8.0) | 1.67× |
| total_dist 链总长 | 2.0 (6.0) | 6.0 (10.0) | **3.00×** |
| max_dist 最长边 | 2.0 (2.0) | 2.0 (2.0) | 1.00× |
| long_rate 长边率 | 0.0 (0.0) | 0.0 (0.0) | 稀有、样本依赖 |
| strght 直度 | 1.00 | 1.00 | 无区分 |
| bdry_edges 边界边 | 0 (0) | 0 (0) | 无区分 |

**结论 B**：配对层最强特征 total_dist = 3.00×（A1 的配对链总长是 A0 的 3 倍），n_edges = 1.67×。max_dist 中位与 90 分位均为 2.0——**A1 样本没有显著更长的单条边**，链长差异来自"更多配对边 × 每边略长"的累积，而非单条长链。

**标度律（L=4/6/8 × 种子 42/123/777）**：固定物理噪声 p=0.005（工作区内），随码距 L 增大，配对层的绝对拓扑信号线性存活：

| L | shots | pL | A0 total_dist | A1 total_dist | **A1−A0** | A1/A0 | A1 显式长链率（max_dist≥4） |
|---|---|---|---|---|---|---|---|
| 4 | 30k | 1.48% | 2.0 | 6.0 | **4.0 = L** | 3.00× | 12.9% |
| 6 | 300k | 0.49% | 8.0 | 14.0 | **6.0 = L** | 1.75× | 33.9% |
| 8 | 600k | 0.17% | 16.0 | 24.0 | **8.0 = L** | 1.50× | 51.2% |

**A1 − A0 = L 精确成立**（三种子中位数完全一致）——逻辑错误的配对链比可修正错误多出**恰好一个码距**：非平凡同调类（跨边界链）的几何代价，随码距线性增长。相对比值衰减（3.00×→1.50×）是背景稀释：局域错误背景随码面积 ∝ L² 增长，稀释了 ∝ L 的拓扑信号；绝对差值（A1−A0 = L）不受稀释，是稳健的标度不变量。

**注记（显式长链的频率标度）**：L=4 单次运行 20k shots 时 A1 样本仅 ~300，显式长链（max_dist ≥ 4）频率样本依赖（前轮观测 ~10%，本轮 90 分位未出现）。二期以 30k–600k shots × 3 种子给出确定性频率：**A1 显式长链率随码距增大 12.9% → 33.9% → 51.2%**（A0：5.2% → 16.9% → 32.6%），跨种子稳定（±1% 内）——显式跨码链不是稀有特征，而是大码距下逻辑错误的主要形态（§5 更新）。

### 4.4 对照组：阈值邻近区（p=0.03）特征塌缩

p=0.03，shots=20000，pL=0.3865（A0=12270，A1=7730）：

| 特征 | A0 med | A1 med | A1/A0（vs 工作区） |
|---|---|---|---|
| exc | 21.0 | 22.0 | 1.05×（1.60×） |
| diam | 10.0 | 10.0 | 1.00×（1.50×） |
| cluster | 7.0 | 8.0 | 1.14×（1.50×） |
| cross | 95.6% | 96.9% | 1.01×（1.72×） |
| n_edges | 13.0 | 13.0 | 1.00×（1.67×） |
| total_dist | 10.0 | 10.0 | **1.00×（3.00×）** |

**结论 A'（对照组）**：p=0.03（pL=38.7%，接近有效阈值）时，全部特征塌缩——total_dist 从 3.00× 降至 1.00×，cross 从 1.72× 降至 1.01×（A0 的 cross 已达 95.6%：激发密度太高，几乎所有样本都"碰巧"接触相对边界）。**结构区分只在码工作区（p ≪ p_th）存在**——与框架"谱条件窗口"（可生存观测者位置）同构：结构信息只在可生存区显现。

## §5 几何论解读

1. **互扼锁定的程序实证**。拓扑信息在配对层（约束优化的全局解，3.00×）比激发层（初始数据，1.72×）显现更强——支持"拓扑本性显现在约束互扼的全局解中，而非局部初始数据"。MWPM 的最小总链长配对是"良性互扼约束"的一个实例：原始 syndrome 经约束投影后，A1 的拓扑签名（总链长 3 倍）才显露。这与 §2.3 的框架先验一致。

2. **A1 的机制：从隐式配对选择到显式长链（随码距转变）**。L=4 时 max_dist 90 分位 = 2.0（无长单边）+ total_dist 3.00× → 大多数逻辑错误是**解码器在多条局域链间的全局配对选择错误**：激发图案局域平凡（A0 表象），但最小化配对路径在全局拓扑意义上绕了非平凡环。几何论表述：A1 的"Berry 相位 2π"是**配对路径的拓扑选择**——单看局部（激发）无法判定，必须看整体（配对）。随码距增大，机制连续转变：显式长链型（真跨码链）比例 12.9% → 51.2%（L=4→8）——大码距下逻辑错误的主要形态变为"看得见的跨码链"。两种机制统一于标度律 A1−A0 = L：无论是隐式选择还是显式长链，逻辑错误的配对代价都是恰好一个码距（§4.3）。

3. **谱条件窗口的类比**。结构区分在 p < p_th 显现、在 p ≈ p_th 塌缩（total_dist 1.00×）——与框架"可生存观测者位置窗口"（谱条件约束）同构：**结构信息只在可生存区显现，超出即被噪声淹没**。量子纠错的"码工作区"提供了一个可精确控制的窗口类比物（p 连续可调，塌缩可定量观测）。

## §6 可复现性与开放问题

### 6.1 复现

- 环境：stim 1.15.0、pymatching 2.4.0、numpy
- 脚本：`toric/toric_decode.py`（`--L 4 --rounds 3 --noise 0.005 --shots 20000` 主分析；`--noise 0.03` 对照组；`--scan` 阈值扫描）；`scripts/phase2_scaling.py`（二期标度律：L=4/6/8 × 种子 42/123/777，30k–600k shots/点）
- 诚实标注：一期采样未固定 seed（单次运行）；二期通过 `compile_detector_sampler(seed=...)` 固定种子，中位数级特征（total_dist、n_edges、A1−A0）跨种子完全一致，长链率跨种子稳定（±1% 内）；pL 统计误差 ~1/√shots（20000 shots ≈ 0.7%）

### 6.2 开放问题：几何特征能否构成检测量？

total_dist、n_edges、cross 构成一个**解码前逻辑错误预测器**的候选特征集：在 syndrome 数据上预测哪些样本将解码失败（实时系统可提前重试/降噪）。标准解码器不预测失败——若该预测器有效，即"几何论给出标准方法给不出的检测量"的一个实例。标度律 A1−A0 = L 给出预测器的稳健形式：绝对链长差（而非相对比值 3.00×，后者随 L 衰减）是跨码距不变量；显式长链率（max_dist ≥ 4）随 L 增大（12.9%→51.2%）成为大码距下高特异性的单样本指标。当前状态：特征存在方向性区分（统计偏置），预测性能（AUC/精度-召回）未评估——待后续。注意特征在阈值邻近区塌缩（§4.4），预测器仅在工作区有意义。

### 6.3 局限

- 单码族（unrotated surface code）、单噪声模型（四通道等强度）；标度律已在 L=4/6/8 × 3 种子验证，其他码型（rotated/color/toric）与其他噪声模型（circuit-level 完整）待验证
- 相对区分度随 L 衰减（3.00×→1.50×，背景 ∝L² 稀释）——**绝对差值 A1−A0 = L 是稳健量**，但单样本分类的 AUC 会随 L 下降（背景稀释），预测器设计需利用绝对链长差而非比值
- 隐式配对选择型的完整表征（哪类局域图案组合导致全局配对错误）未完成
