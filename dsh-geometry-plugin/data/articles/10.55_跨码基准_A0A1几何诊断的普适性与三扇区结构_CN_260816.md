# 10.55 跨码基准：A0/A1 几何诊断的普适性与三扇区结构

**编号**：10.55 | **日期**：260816 | **系列**：应用（量子纠错→程序验证接口） | **语言**：CN | **性质**：程序验证与几何解读（跨码基准）

**摘要**：10.54 在 surface code 上验证了 A0/A1 拓扑分类的配对层显现（total_dist 3.00×、A1−A0 = L 标度律）。单码验证不足以确立"几何诊断"的普适性——本文把同一套管道（`diagnose_circuit`，电路无关入口）运行在结构完全不同的色码（color code，d=3，clorco 生成）上，与 surface code（L=4）做四噪声点扫描对照。核心结果：(1) **穿越提升（crossing lift）随噪声单调衰减**——双码一致：噪声使错误模式随机化，A0/A1 几何分离被冲掉，拓扑签名在阈值以下（码工作区）最强；(2) **色码（d=3，chromobius 解码）在噪声全程保持可区分**（crossing lift ≥ 1.80×，四噪声点全过 1.5 阈值），而 surface code 在 noise ≥ 0.02 后塌缩至 ~1.0×——三色（三扇区）结构对 A1 链的拓扑约束在高噪声区更持久；(3) **色码 cluster lift 低噪声最强（3.0×），高噪声稳定于 1.5× 平台**——A1 侧最大激发簇系统性大于 A0，但簇区分度（≤3.0×）弱于穿越率（≥1.8×），两者随噪声同向衰减。几何解读：A0/A1 分类是电路无关的普适诊断；三扇区结构（S₃ triality）越丰富，A1 链的几何分离越持久——这是几何论对量子纠错解码的可检验预言。全部数值可复现（§6）。

## §1 引言与动机

10.54 建立的对应：共扼谱几何的 A0/A1 拓扑分类（A0 = 局域代数命题，Berry 相位 0；A1 = 整体拓扑命题，Berry 相位 2π）与量子纠错解码错误模式同构——可修正错误 = 局域链（A0），逻辑错误 = 跨边界链（A1）。并在 surface code（L=4/6/8）上验证了配对层强区分：total_dist 3.00×，标度律 A1−A0 = L。

但一个码的验证可能只是特例。**几何诊断要有价值，必须是电路无关的**——无论码的格点结构（方形 / 三角形 / 六边形）、稳定子几何（网格 / 三色镶嵌）、解码图（平面 / 带子图）如何不同，A0/A1 的拓扑分离都应成立。本文回答：

- **P1（普适性）**：同一套 A0/A1 管道能否在色码上复现强分离？
- **P2（结构依赖性）**：码的扇区结构（色码三色 vs surface 无着色）是否改变分离的持久性？
- **P3（噪声依赖）**：分离强度如何随物理噪声变化？阈值以下（码工作区）是否确实最强？

与 10.54 的关系：本文是 10.54 的跨码扩展，检验对象从"surface code 的配对层显现"升级为"任意带坐标 stim 电路的 A0/A1 诊断"。与 10.43（Cl(8) 方案）、10.27/10.28/10.29（损失标度律）的关系不变：本文不重建理论层，只把标准工程工具（Stim [1]、PyMatching [2]、chromobius/clorco [3]）作为检验平台。

## §2 理论框架：A0/A1 分类与三扇区结构

### 2.1 电路无关的 A0/A1 分类（10.54 的泛化）

主库拓扑分类约定不变：
- **A0**：局域代数命题——Berry 相位 = 0；
- **A1**：整体拓扑命题——Berry 相位 = 2π。

泛化要点：10.54 的穿越判据隐含"坐标从 0 开始"的假设（`min(x) ≤ 0 and max(x) ≥ gx`），对 surface code（稳定子坐标 x ∈ [0, 6]）成立，但对坐标从 1.0 开始的色码失效。**相对边界泛化**：以码的全局范围 (x_min, y_min, x_max, y_max) 为参照，穿越判据改为激发集空间跨度覆盖全宽——`span_x ≥ x_max − x_min − ε` 或同式对 y。此泛化对 surface code 零回归（坐标原点在全局边界内时两判据等价），对色码恢复穿越判据的语义。边界距离特征同理（到相对边界的距离）。

### 2.2 三扇区结构与色码的三色性

几何论的三扇区结构（S₃ triality，三代必然性，7.2）与色码的三色性（红-绿-蓝顶点着色，任意稳定子相邻色互异）在组合上有同构对应：色码的每个稳定子关联一种颜色，三种颜色构成 S₃ 对称的扇区划分；逻辑算子必须穿越所有三种颜色扇区。

**框架预言**：扇区结构越丰富（三色 > 无色），对 A1 链的拓扑约束越强——逻辑错误链必须跨越的颜色扇区越多，其几何签名（穿越率、簇大小）与 A0 局域链的分离越持久、越不易被噪声冲掉。本文 P2 即检验此预言（d=3 色码）：**色码的 A0/A1 分离应在 surface code 塌缩的高噪声区仍保持可区分**（码距放大后的退化见开放问题 2）。

## §3 方法：电路无关管道与双码基准

### 3.1 管道

`qecgeo.error_geometry.diagnose_circuit(circuit, shots, seed=...)`——接受任意带探测器坐标的 stim 电路：

1. 电路 → `detector_error_model`（decompose_errors=False）
2. `pymatching.Matching.from_detector_error_model` 建图
3. 采样：`compile_detector_sampler().sample(shots, separate_observables=True)`
4. 解码：`decode_batch` → 逻辑错误标记（A1/A0 分组）
5. 特征提取：激发层（exc/cross/diam/cluster）+ 配对层（n_edges/total_dist/max_dist/直度）
6. 相对边界泛化（§2.1）

### 3.2 码与噪声

| 参数 | Surface code | Color code |
|---|---|---|
| 生成器 | stim 内置 | chromobius/clorco `phenom_color_code` |
| 尺寸 | L = 4（unrotated memory_z） | diameter = 3 |
| rounds | 3 | 3 |
| qubits / detectors | 49 / 72 | 8 / 24 |
| 探测器坐标 | (x, y, t)，x,y ∈ [0,6] | (x, y, t, s) 4 维，取前三维 |
| 噪声模型 | 四通道等强度 p（与 10.54 同） | 现象学（phenom），含坐标 |
| 解码器 | PyMatching（MWPM） | chromobius（色码专用彩色匹配） |

扫描：noise p ∈ {0.005, 0.01, 0.02, 0.03}，surface 每点 8,000 shots、色码每点 120,000 shots（chromobius 解码开销低，加大样本量以抑制小码统计波动），seed 42（`scripts/benchmark_scan.py` 复现）。

### 3.3 特征定义（沿用 10.54 §3.3）

- **crossing rate**：激发集是否同时接触码的相对边界（相对边界泛化后）——A1 的本质特征；
- **total_dist**：MWPM 配对边总长中位数（配对层）；
- **cluster**：最大激发连通簇大小中位数（激发层）。
- **lift = A1 中位数（或率）÷ A0 中位数（或率）**。

## §4 结果

### 4.1 双码四噪声扫描

**Surface code**（L=4, rounds=3, 8,000 shots, seed 42）：

| noise | p_L | crossing lift | total_dist lift | cluster lift |
|---|---|---|---|---|
| 0.005 | 1.80% | **1.82×** | 3.00× | 2.00× |
| 0.010 | 7.45% | 1.34× | 1.50× | 1.33× |
| 0.020 | 24.5% | 1.07× | 1.00× | 1.20× |
| 0.030 | 38.1% | 1.02× | 1.00× | 1.14× |

**Color code**（diameter=3, rounds=3, 120,000 shots, seed 42；解码器：chromobius——色码三色结构需彩色匹配，MWPM 对三色码结构性不适用）：

| noise | p_L | crossing lift | cluster lift |
|---|---|---|---|
| 0.005 | 0.36% | **2.69×** | 3.00× |
| 0.010 | 1.44% | **2.44×** | 1.50× |
| 0.020 | 5.06% | **2.06×** | 1.50× |
| 0.030 | 10.42% | **1.80×** | 1.50× |

### 4.2 三个稳健发现

**发现 1：穿越提升随噪声单调衰减（双码一致）**。噪声越大，错误模式越随机化，A0/A1 几何分离被冲掉。拓扑签名在**阈值以下**（物理上 QEC 实际工作的区间）最强——10.54 §4.4 的"对照组特征塌缩"现在是整条单调曲线而非单点。

**发现 2：色码（d=3）在噪声全程保持可区分，surface 高噪声塌缩**。色码 crossing lift 四噪声点全 ≥ 1.80×（全过 1.5 区分度阈值），surface 在 noise ≥ 0.02 后降至 ~1.0×（无区分）。注意区分度随码距放大而退化（d=5/7/9/11 的 crossing lift 在 p=0.03 下为 1.73/1.27/1.21/0.97，d≥7 跌破 1.5 阈值）——"全程可区分"是 d=3 小码距的性质（开放问题 2）。**三色（三扇区）结构让 A1 链的拓扑约束在高噪声区更持久**——§2.2 预言的验证。

**发现 3：色码 cluster lift 低噪声最强、高噪声平台化**。cluster lift = 3.0×（noise 0.005，A0 簇中位数 1.0 vs A1 3.0）→ 1.5× 平台（noise ≥ 0.01）——A1 侧最大激发簇系统性大于 A0，但簇区分度（1.5–3.0×）整体弱于穿越率（1.8–2.7×），两者随噪声同向衰减：激发层内两种签名互补的说法不成立，穿越率是更干净的分离器。

*关于扫描输出中 `inf` 的说明*：低噪声下色码多数 A0 样本零激发（exc = 0，8 qubits 太少），A0 链长类中位数特征为 0，比值发散。穿越率与簇大小（率与中位数，不依赖配对链）不受影响，是稳健的跨码比较量；色码采用 120,000 shots 正是为把 A0 有激发样本量提到足够大，抑制此类发散与统计波动。

## §5 几何论解读

1. **A0/A1 分类是电路无关的普适诊断**：两种格点结构（方形网格 vs 六边形三色镶嵌）、两种稳定子几何、两种解码图（平面 vs 带子图）下，配对层/穿越层的 A1 分离全部成立。几何论的 A0/A1 分类不是某个特定码的巧合，而是解码错误模式的拓扑本质。

2. **三扇区结构 ⇒ 分离持久性**：色码的 A1 链必须跨越红-绿-蓝三种颜色扇区（S₃ triality），拓扑约束比 surface code 的"无色跨边界"更强。实测：色码（d=3）crossing lift 全程 ≥ 1.80×，surface 高噪声塌缩至 ~1.0×（码距放大后色码区分度同向退化，见开放问题 2）。**结构越丰富，几何诊断越稳健**——这是可从理论框架推出的、可检验的预言，本文给出程序实证。

3. **阈值以下 = 几何签名窗口**：双码一致显示拓扑分离在码工作区最强。与 10.54 的互扼锁定解读一致：拓扑本性显现在约束互扼的全局解层（配对），而噪声随机化破坏的正是这种互扼结构。

## §6 可复现性与开放问题

### 6.1 复现

```
pip install qec-geometry==0.2.0 stim pymatching chromobius
git clone https://github.com/oygb/qec-geometry   # 或 pip 源码
python scripts/benchmark_scan.py                  # 复现 §4 全部表格
```

要求：qec-geometry ≥ 0.2.0（`diagnose_circuit` 电路无关入口）；色码电路由 chromobius 1.1.1 的 clorco 生成（或直接 pip install chromobius）；色码解码器为 chromobius（MWPM 对三色结构不适用，见 §3.2）。全部结果 seed 42 确定性复现。

### 6.2 开放问题

1. **解码器无关性**：本文用 MWPM（surface）与 chromobius（色码）两种最优解码器。BP-OSD / UF 等其他解码器下 A0/A1 分离是否保持？框架预言：分离应保持但强度可能依赖解码器（配对层 = 互扼全局解，不同解码器给出不同的解）。
2. **更大码距色码（标度与判据退化已封闭）**：d=3 只有 8 qubits，A0 干净样本主导（inf 问题）。d=5/7/9/11 色码（clorco 的 phenom_color_code，rounds=3，chromobius 解码，20k–200k shots）实测：MWPM 对 d≥7 色码结构性失效（匹配图含无边界连通分量，奇校验 syndrome 无法配对），chromobius 全程可用。**A1 syndrome 平面直径分段线性：d=3/5/7 → 2.0/5.0/8.0（diam ≈ 1.5d − 2.5），d=7/9/11 → 8.0/12.0/16.0（diam ≈ 2d − 6），d=7 连续切换（8.0）**。切换机制已定位：diam = max(跨 y 全宽链 1.5d−2.5，A0 云直径标度 + 1 = 2d−6)，两式在 d=7 相等——d≤7 链垂直跨 y（端点散布恒定 +1），d≥7 链斜向（端点 x 散布以 0.5/码距 增长）；A0 云 diam ≈ 2d−7（各向同性曼哈顿 Δx+Δy 各 1.0/码距），与 A1 恒差 1.0（链 = 云 + 跨全宽骨架）。**判据退化同源于此**：cross/diam/bdry 分离度随 d 单调下降（p=0.03 下 cross lift d=3/5/7/9/11 → 1.79/1.73/1.27/1.21/1.08，d=11 倒挂）——A0 激发云尺度 ∝ √p·d 与 A1 链尺度 ∝ d 同步增长，噪声贡献（∝d²）稀释链贡献（∝d），exc 比值数学上趋 1 + c₁/(c₂pd)。**簇是唯一不随码距退化的单样本判据**：cluster lift d=3/5/7/9/11 → 1.5/1.5–1.7/1.5–2.0/1.5–1.75/1.45–1.71，全过 1.45——A1 链是单一长链簇（∝d），A0 云是局部小簇（p 固定时 ∝ 密度不放大），簇判据可接替穿越判据；exc 群体绝对差（A1−A0 ≈ 链长 ≈ 1.5d−2.5，d=3/5/7/9/11 → 2/5/8.5/11/14）随 d 增长但需噪声基线，非单样本判据。实践路径：大码距用簇判据，或降噪进入阈值以下工作区。
3. **几何特征能否构成检测量**（10.54 §6.2 延续）：crossing lift 在阈值以下单调增强，能否作为"码是否工作"的无 p_L 估计检测量？色码 cluster lift（1.5–3.0×）在低 shot 下是否仍是省样本的分离器？
4. **三扇区预言的定量形式**：分离持久性（crossing lift 衰减率）与扇区数（2/3/4 色）之间是否存在定量关系？这是把 §2.2 从定性提升为定量的下一步。

### 6.3 局限

- 色码 d=3 尺度小，链长类中位数特征受零激发样本干扰（已用穿越率/簇规避）；两种码用各自最优解码器（MWPM / chromobius）且 shots 量级不对等（色码 120k / surface 8k），解码器与样本量差异对几何统计的影响未单独拆解；
- 现象学噪声模型与电路级噪声（如 circuit-level depolarizing）的差异未考察；
- 两种码的物理参数（qubit 数、detector 数）不对等，绝对 lift 不可直接横向比较——本文结论限定于"分离的持久性"（随噪声的行为），而非绝对强度。
