**编号**：10.72　**日期**：2026-08-22　**系列**：离散随机家族（08-21/08-22 引入的连续决定论对偶层）

## §1 动机：量子单配性与几何权重约束

### 1.1 量子侧：CKW 不等式

Coffman–Kundu–Wootters（CKW，2000）证明了三方纯态的纠缠单配性：

$$E_{AB}^2 + E_{AC}^2 \le E_{A|BC}^2,$$

其中 E 是 concurrence 型纠缠度量。物理含义：**A 与 B 的纠缠平方加上 A 与 C 的纠缠平方，不超过 A 与 BC 整体的纠缠平方**——纠缠资源有限，A 不能同时与 B 和 C 最大纠缠；一方增强必然挤压另一方。这是量子信息论区别于经典关联的核心特征之一。

### 1.2 几何侧：三扇区权重归一化

主库 #257（定理 1.3.2.02，已验证 2026-08-05）：Cl(3) 扇区分解下编码权重满足

$$\sigma_M + \sigma_C + \sigma_I = 1, \qquad \sigma_i = c_i^2 \text{（投影强度的平方）}.$$

几何论同样存在一个"资源有限"约束：**三扇区编码权重总和恒为 1**。若某一扇区权重接近 1（如 T_ours 中 θ_I = 0.782），其余两扇区合计至多 0.218——这正是单配性的资源结构。本文证明这种结构自动产生 CKW 型不等式。

## §2 定义

以下用通用记号 (σ_1, σ_2, σ_3) 表示三扇区权重，满足 σ_i ≥ 0 且 σ_1 + σ_2 + σ_3 = 1（#257）。数值锚定使用 2.6 的 T_ours = (θ_I, θ_τ, θ_σ₂) = (0.782, 0.209, 0.009)（分量标签按 2.6；与 #257 的 (σ_M, σ_C, σ_I) 的精确对应关系以 2.6 原文为准，本文只用归一化与数值）。

**定义 10.72.2.01（扇区共享度）**。对 i ≠ j，定义扇区 i、j 的联合编码份额

$$c_{ij} = \sigma_i \sigma_j.$$

**定义 10.72.2.02（整体共享度）**。对给定 i，定义扇区 i 与其余两扇区整体的联合编码份额

$$c_{i|jk} = \sigma_i (1 - \sigma_i) = \sigma_i (\sigma_j + \sigma_k).$$

*注*：c_{i|jk} 是扇区 i 的权重乘以其补权重——与量子信息中"子系统与环境的互信息"同构的量纲结构（份额 × 补份额）。

## §3 几何单配性定理（纯代数，A0 类）

### 3.1 定理

**定理 10.72.3.01（几何 CKW 单配性不等式）**。设 (σ_1, σ_2, σ_3) ∈ Δ²（σ_i ≥ 0，Σσ_i = 1）。对任意 i，令 j、k 为其余两扇区，则

$$c_{ij}^2 + c_{ik}^2 \le c_{i|jk}^2.$$

*证明*。全部为纯代数：

$$c_{i|jk}^2 - (c_{ij}^2 + c_{ik}^2) = \sigma_i^2\left[(\sigma_j + \sigma_k)^2 - (\sigma_j^2 + \sigma_k^2)\right] = \sigma_i^2 \cdot 2\sigma_j\sigma_k \ge 0,$$

最后一步用 σ_jσ_k ≥ 0（权重非负，#257 的 Δ² 定义）。∎

**推论 10.72.3.02（亏量恒等式）**。定义单配性亏量 Δ_i = c_{i|jk}² − (c_ij² + c_ik²)，则

$$\Delta_i = 2\sigma_i^2 \sigma_j \sigma_k.$$

*证明*。上式展开即得。∎

**推论 10.72.3.03（等号条件 = 无共享）**。不等式取等 ⟺ σ_jσ_k = 0，即扇区 j、k 至少一个权重为零——两扇区之间无任何联合份额时，单配性饱和。

*注*：与量子 CKW 的类比——纯态（无环境共享）时 CKW 取等；几何版"无共享 ⟹ 取等"结构同构。

### 3.2 数值锚定（T_ours）

用 2.6 的 T_ours = (0.782, 0.209, 0.009)，取 i = 1（权重最大扇区，σ_1 = 0.782，j = 2, k = 3）：

| c_12 | σ_1σ_2 | 0.163438 |

不等式成立且亏量为正：最大扇区与另外两扇区的共享被整体共享严格约束，盈余 0.0023。

## §4 分支平均下的单配性（与 0.12 连接）

### 4.1 分支平均定理

**定理 10.72.4.01（分支平均单配性）**。设 σ ~ U_G（0.12 定义 0.12.2.02：S₃ 上均匀分支分布），则单配性亏量的分支平均

$$E_{\sigma \sim U_G}[\Delta] = \frac{2}{3}\,\sigma_1\sigma_2\sigma_3.$$

*证明*。亏量 Δ_i = 2σ_i²σ_jσ_k 是扇区标签的函数；S₃ 均匀平均使每个标签等权出现：

$$E_U[\Delta] = \frac{1}{3}\left(2\sigma_1^2\sigma_2\sigma_3 + 2\sigma_2^2\sigma_1\sigma_3 + 2\sigma_3^2\sigma_1\sigma_2\right) = \frac{2}{3}\sigma_1\sigma_2\sigma_3(\sigma_1 + \sigma_2 + \sigma_3) = \frac{2}{3}\sigma_1\sigma_2\sigma_3,$$

末步用 Σσ_i = 1（#257）。∎

*数值*：T_ours 处 E_U[Δ] = (2/3)(0.782 × 0.209 × 0.009) = **0.000980628**。

### 4.2 最大共享点

**推论 10.72.4.02（最大共享点 = 随机端）**。E_U[Δ] 在单纯形 Δ² 上的最大值

$$\max_{\Delta^2} E_U[\Delta] = \frac{2}{3} \cdot \frac{1}{27} = \frac{2}{81} \approx 0.0246914,$$

在 T* = (1/3, 1/3, 1/3) 处取得（AM-GM：σ_1σ_2σ_3 ≤ ((σ_1+σ_2+σ_3)/3)³ = 1/27，等号在等分点）。

*解读*：T* 正是 0.12 推论 0.12.6.01 的"随机端 = 对称恢复"点。**随机端是最大共享点**——三扇区等权，彼此联合份额最大（c_ij = 1/9 全部相等），单配性最弱。0.12 §6 说 T* 谱退化（秩 1，无结构方向）；此处给出互补视角：T* 也是"共享最大化"点。

### 4.3 随机端 vs 确定端的单配性谱系

| 配置 | Δ（亏量） | 单配性 | 0.12 相位 |
|---|---|---|---|
| T* = (1/3, 1/3, 1/3) | 2/81 = 0.0246914（最大） | 最弱（最大共享） | 随机端 |
| T_ours = (0.782, 0.209, 0.009) | 0.00230055 | 强（一扇区垄断） | 确定端 |
| (1, 0, 0) 极端 | 0 | 完全（零共享） | 确定端极限 |

**推论 10.72.4.03（单配性沿循环摆动）**。0.12 的交替循环 L = S ∘ Φ_σ 在"随机—确定"两相位间脉冲式交替时，单配性亏量在 2/81 与 (确定端值) 之间摆动：均匀化相位把配置推向 T*（共享最大化、单配性最弱），结构化相位沿 η 方向推进打破对称（垄断出现、单配性增强）。**"随机"的几何翻译之一是共享最大化**——随机端不是"无信息"，而是"信息均匀分布、无法独占"。

### 4.4 逐扇区亏量的精确上界

**定理 10.72.4.04（逐扇区亏量上界）**。对固定 i，Δ_i = 2σ_i²σ_jσ_k 在 Δ² 上的最大值为

$$\max_{\Delta^2} \Delta_i = \frac{1}{32},$$

在 (σ_i, σ_j, σ_k) = (1/2, 1/4, 1/4) 处取得。

*证明*。固定 σ_i，由 AM-GM：σ_jσ_k ≤ ((σ_j+σ_k)/2)² = (1−σ_i)²/4，故 Δ_i ≤ σ_i²(1−σ_i)²/2；对 σ_i ∈ [0,1] 求极大（导数 2σ_i(1−σ_i)(1−2σ_i) = 0，极值点 σ_i = 1/2），得 Δ_i ≤ (1/4)(1/4)/2 = 1/32。∎

*注*：逐扇区上界 1/32 ≈ 0.03125 大于分支平均上界 2/81 ≈ 0.0246914——"锁定某一扇区观测"比"随机选择分支"允许更强的单配性信号，两个上界对应两种观测策略。

## §5 与量子 CKW 的形式对应

| 量子 CKW | 几何共享约束（本文） |
|---|---|
| E_AB（concurrence） | c_AB = σ_Aσ_B（扇区共享度） |
| E_A\|BC（整体纠缠） | c_A\|BC = σ_A(1−σ_A)（整体共享度） |
| E_AB² + E_AC² ≤ E_A\|BC² | c_AB² + c_AC² ≤ c_A\|BC²（定理 10.72.3.01） |
| 等号 ⟺ B、C 无纠缠（纯态化） | 等号 ⟺ σ_Bσ_C = 0（推论 10.72.3.03） |
| 资源有限：纠缠不能三方共享 | 资源有限：Σσ_i = 1（#257） |

**形式同构的根源**：两者都来自"总量守恒 + 非负"的代数结构。量子侧是 concurrence 的平方可加性受限；几何侧是权重归一化 + 非负。CKW 不等式和几何不等式都是同一类"守恒量约束下的平方和不等式"——这是结构相似性，不是量子力学的几何还原（见 §6）。

## §6 诚实边界

1. **形式对应而非物理推导**：几何论没有希尔伯特空间三方张量结构，c_ij = σ_iσ_j 是编码权重乘积，不是纠缠熵或 concurrence。本文证明的是"几何论内部自动存在 CKW 型代数结构"，不是"几何论推导出量子纠缠"。物理语义不同，形式同构。
2. **混合态版本未做**：量子 CKW 的混合态严格形式（含"不等式可能不饱和"）与几何版 σ_jσ_k = 0 的纯化类比的衔接未几何化——与 10.71 §5 的 Englert 对偶混合态缺口平行。
3. **T_ours 标签对应未定**：本文用通用 (σ_1, σ_2, σ_3)；2.6 的 (θ_I, θ_τ, θ_σ₂) 与 #257 的 (σ_M, σ_C, σ_I) 的精确对应以 2.6 原文为准，未在本文件锁定。
4. **多体推广未做**：N 扇区（N > 3）的共享约束不等式族未构造。
