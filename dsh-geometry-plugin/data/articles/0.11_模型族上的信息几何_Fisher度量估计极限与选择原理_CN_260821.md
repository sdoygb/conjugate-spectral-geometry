## 摘要

0.9 引入模型族（随机格族 $\Lambda_q(A)$，$A\in\mathbb{Z}_q^{d\times d}$ 均匀采样），0.10 引入 KMS 态（谱三元组的统计面）。本文给模型族以**信息几何**：Fisher 度量（模型族上的 Riemann 度量）、Cramér-Rao 界（参数估计精度极限）、极大熵原理（族内选择机制）。主要结果：① 经典与量子信息几何的基本命题（纯数学，可提交主库 A0 类）；② **三位一体命题**：KMS 态（0.10）↔ 量子指数族（信息几何）↔ MaxEnt 解（选择原理）——统计面与信息几何在"约束下的唯一选择"处统一；③ 选择原理的框架定位：无约束 → 均匀（0.9 模型族），约束 → 指数族/KMS（0.10）——选择原理是输入层的机制化；④ 开放问题：σ* 观测者位置的可估计性语义、零方差定律的 Fisher 信息条件、自由 Fisher 信息在随机格谱上的应用、δ 模型多样性的统计结构。分层标注：信息几何基本命题为纯数学（可提交主库）；三位一体与选择原理为结构命题（中间层）；σ* 可估计性为开放问题（无声称）。

## 目录

## §1 从模型族到统计流形

### 1.1 模型族回顾

0.9 §3 引入离散轨的模型族：$\mathcal{F} = \{\Lambda_q(A) : A\in\mathbb{Z}_q^{d\times d}\}$，$A$ 均匀采样。0.9 §3.1 的立场：随机不是公理（δ 是确定性的自映射），随机性出现在模型族层的均匀采样。

本文问三个问题：

1. **距离**：模型族作为"统计流形"，其上有什么自然度量？（→ Fisher 度量）
2. **精度**：族内参数的估计有什么精度极限？（→ Cramér-Rao 界）
3. **选择**：为什么是均匀采样？约束下如何选择？（→ 极大熵原理）

### 1.2 统计流形

**定义 0.11.1.01（统计流形）**：设 $\{p(x;\theta) : \theta\in\Theta\}$ 是概率分布族（$\Theta\subset\mathbb{R}^k$ 参数空间），满足正则条件（支撑与 θ 无关、对数似然可微）。该族作为参数空间 Θ 上的微分流形，称为统计流形。

**注（与 0.9 的对接）**：0.9 的模型族 $\mathcal{F}$ 是有限集（$|Z_q^{d\times d}| = q^{d^2}$），均匀分布是其上的一个概率测度。统计流形框架的进入方式是**参数化**：子族（如结构格族、扰动族 $A\to A+\epsilon$）给出连续参数空间；观测者位置 σ*（1.5 §3.7）是框架内已有的一种"族内选择"。本文的统计流形适用于这些参数化子族，不要求全族连续。

### 1.3 三个问题的几何化

- 距离 → Fisher 度量（§2.1）
- 精度 → Cramér-Rao 界（§2.2）
- 选择 → 极大熵原理（§2.4）

## §2 经典信息几何（纯数学）

### 2.1 Fisher 度量

**定义 0.11.2.01（Fisher 度量）**：统计流形 $\{p(x;\theta)\}$ 上定义

$$g_{ij}(\theta) = \mathbb{E}_\theta\left[\partial_i \log p(x;\theta)\cdot \partial_j \log p(x;\theta)\right],$$

其中 $\partial_i = \partial/\partial\theta^i$。$g$ 是参数空间上的 Riemann 度量，称为 Fisher 度量。

**注（基无关性）**：Fisher 度量在参数重参数化下按张量变换——它是分布族的内禀几何，不依赖参数化选择。这与谱的基无关性（0.9 §5.1，谱定理自动）在结构上平行：**内禀量不依赖表示**。连续谱的基无关性由谱定理保证；统计流形的基无关性由 Fisher 度量的张量性保证。这是几何论"内禀性"主题在统计面的对应。

### 2.2 Cramér-Rao 界

**定理 0.11.2.02（Cramér-Rao 界）**：设 $\hat{\theta}$ 是 θ 的无偏估计（基于 n 个独立样本），则

$$\mathrm{Cov}(\hat{\theta}) \geq \frac{1}{n}\, g(\theta)^{-1},$$

其中 $g$ 是 Fisher 度量（矩阵形式），不等式按正定序理解。等号当且仅当估计量是充分统计量的函数（指数族中可达）。

**注（精度极限的内禀性）**：C-R 界只依赖 Fisher 度量——估计精度的极限是统计流形的几何性质，与具体估计算法无关。**几何决定精度极限**——这是信息几何与 CSG"结构决定内容"立场的一致点。

### 2.3 指数族

**定义 0.11.2.03（指数族）**：分布族

$$p(x;\theta) = \exp\left(\theta\cdot T(x) - \psi(\theta)\right) h(x),$$

其中 $T(x)$ 是充分统计量，$\psi(\theta)$ 是配分函数的对数（$\psi(\theta) = \log\int e^{\theta\cdot T(x)}h(x)\,dx$）。

**命题 0.11.2.04（指数族的 Fisher 度量）**：指数族的 Fisher 度量是 $\psi$ 的 Hessian：$g_{ij}(\theta) = \partial_i\partial_j\psi(\theta)$。

**注（对偶仿射几何）**：指数族在 Fisher 度量 + Amari α-连接（α = ±1 的对偶平坦结构）下是对偶平坦流形，满足广义勾股定理。本文只用 Fisher 度量的最基本性质；α-连接的完整展开（测地线、投影、迭代投影算法）留给后续文章。

### 2.4 极大熵原理与选择

**定理 0.11.2.05（MaxEnt → 指数族，Jaynes 1957）**：给定约束 $\mathbb{E}[T] = \mu$（充分统计量的期望固定），在满足约束的分布中使熵 $S[p] = -\int p\log p$ 最大的分布唯一，为指数族 $p(x;\theta^*) = \exp(\theta^*\cdot T(x) - \psi(\theta^*))h(x)$，其中 θ* 由约束方程 $\nabla\psi(\theta^*) = \mu$ 确定。

**注（选择的唯一性）**：MaxEnt 给出"约束下的唯一选择"——选择原理的经典形式。无约束（$\mu$ 自由）时，MaxEnt 解趋向均匀分布（在紧致/有限支撑上）。**均匀 = 无约束 MaxEnt 解**——这合理化 0.9 §3 的均匀采样：均匀不是"约定"，是无信息约束下的唯一选择。

## §3 量子信息几何（纯数学）

### 3.1 量子 Fisher 信息

**定义 0.11.3.01（对称对数导数与 QFI）**：设 $\rho(\theta)$ 是量子态族（密度矩阵）。对称对数导数（SLD）$L_\theta$ 由

$$\partial_\theta\rho = \frac{1}{2}(L_\theta\rho + \rho L_\theta)$$

定义。量子 Fisher 信息 $F_Q(\theta) = \mathrm{Tr}(\rho L_\theta^2)$。

**注（经典极限）**：当 $\rho(\theta) = \sum_x p(x;\theta)|x\rangle\langle x|$（经典混合态，基固定），$F_Q = g_{11}$（经典 Fisher 信息）——量子信息几何包含经典信息几何。

### 3.2 量子 Cramér-Rao 界

**定理 0.11.3.02（量子 Cramér-Rao 界，Braunstein-Caves 1994）**：任意测量方案（POVM）下的估计精度满足

$$\mathrm{Var}(\hat{\theta}) \geq \frac{1}{n\, F_Q(\theta)}.$$

存在最优测量（投影到 SLD 本征空间）使等号渐近可达。

**注（测量的代价）**：QCRB 是"所有测量方案"的下界——量子态包含的信息比任何经典测量能提取的都多（除非选择最优测量）。这与 0.9 §5.3 的"可读性分层"形成对照：连续谱信息直接可读（谱定理）、离散格信息读取路径锁死（计算）、量子态信息**需要最优测量才可读**（QCRB）——三种"可读性"的第三种形态。

### 3.3 Bures 度量

**定义 0.11.3.03（保真度与 Bures 度量）**：量子态 ρ, σ 的保真度 $F(\rho,\sigma) = \left(\mathrm{Tr}\sqrt{\sqrt{\rho}\,\sigma\sqrt{\rho}}\right)^2$。Bures 距离 $d_B(\rho,\sigma) = \sqrt{2(1-\sqrt{F(\rho,\sigma)})}$。

**命题 0.11.3.04（Bures 与 QFI）**：无穷小形式 $d_B^2(\rho_\theta, \rho_{\theta+d\theta}) = \frac{1}{4}F_Q(\theta)\,d\theta^2$——Bures 度量 = (1/4)·QFI。量子态空间的内禀度量与估计精度极限同源。

### 3.4 量子指数族

**定义 0.11.3.05（量子指数族）**：$\rho(\theta) = \exp(\theta\cdot T - \psi(\theta))$（$T$ 自伴算子，$\psi = \log\mathrm{Tr}\,e^{\theta\cdot T}$）。

**命题 0.11.3.06（Gibbs 态是量子指数族）**：$\rho = e^{-\beta H}/Z$ 是量子指数族（θ = −β，T = H）。

## §4 与 CSG 框架的对接

### 4.1 三位一体：KMS ↔ 指数族 ↔ MaxEnt（结构命题）

**命题 0.11.4.01（三位一体，结构命题）**：以下三者是同一对象的三个面：

1. **KMS 态**（0.10 §2.3）：$\omega(AB) = \omega(B\,\sigma_{i\beta}(A))$——平衡态的公理化；
2. **量子指数族**（定义 0.11.3.05）：$\rho = e^{-\beta H}/Z$——Gibbs 态；
3. **MaxEnt 解**（定理 0.11.2.05 的量子版）：约束 $\langle H\rangle$ 固定下 von Neumann 熵 $S = -\mathrm{Tr}(\rho\log\rho)$ 最大的态。

**论证**：Gibbs 态满足 KMS 条件（0.10 命题 0.10.2.05，纯数学）；Gibbs 态是量子指数族（命题 0.11.3.06，纯数学）；在能量期望约束下使 von Neumann 熵最大的态唯一为 Gibbs 态（Jaynes 1957 的量子版，纯数学）。三者通过 Gibbs 态同一。□

**注（框架意义）**：0.9 的立场"随机不是公理"、0.10 的"KMS 是平衡态"、本文的"MaxEnt 是选择原理"——三者统一为：**约束下的唯一选择**。选择原理是 CSG 输入层（观测者位置 σ*、模型族选择）的机制化：给定约束（能量、谱条件等），唯一的选择是 MaxEnt/KMS/指数族。这是结构命题（中间层）：数学部分（等价性）是标准结果，CSG 内的定位是本文的框架主张。

### 4.2 σ* 观测者位置的可估计性（开放）

σ* 是输入（1.5 §3.7：观测者位置，2 个独立自由度）。若 σ* 从实验数据估计，QCRB（定理 0.11.3.02）给出精度极限——但 CSG 中 σ* 是输入不是输出，可估计性的语义未定（σ* 不被实验"测量"，而是被理论"假定"）。**开放问题**：σ* 的可估计性是否有框架内意义。

### 4.3 谱统计量的 Fisher 信息（开放）

0.9 §4.3 的零方差定律（经验，N=20）：λ₁/GH = +1.0228 恒定。若零方差定律成立（确定性可观测），其 Fisher 信息发散（确定性 = 无穷精度）——但"零方差"是经验（N=20），理论化（集中不等式）未完成。另一方面：结构格 vs 随机格的区分（λ₁/GH = −1.7 vs +1.02，分离 3.7 个数量级，10.58 P3）是分类问题——分离间隔大 → 分类几乎确定——这是 0.9/10.58 实证的信息几何表述。**开放问题**：零方差定律的理论化条件与谱统计量的 Fisher 信息。

### 4.4 自由 Fisher 信息与随机格（桥）

**注（自由概率桥）**：Voiculescu 的自由熵 $\chi(X)$ 与自由 Fisher 信息 $\Phi(X)$ 是自由概率中的信息几何量（随机矩阵谱的内禀量）。0.9 的 Gram 谱（随机格 $\Lambda_q(A)$ 的谱统计）是随机矩阵的谱——自由 Fisher 信息是谱的"信息几何签名"。0.10 §5.2 预告的自由概率桥在此具体化：**随机 Clifford 代数（自由费米子）↔ 自由概率 ↔ 谱的信息几何**——工具可用（Voiculescu 框架，纯数学），CSG 内的应用（如随机格谱的自由熵作为"典型性"度量）开放。

## §5 选择原理

### 5.1 均匀 = 无约束 MaxEnt（结构命题）

**命题 0.11.5.01（均匀采样的合理化）**：0.9 §3 的模型族均匀采样是无约束 MaxEnt 的唯一解（定理 0.11.2.05 的有限集形式：有限集上的均匀分布是熵最大的分布）。

**注**：均匀不是约定而是选择原理的结果——0.9 §3.1"随机不是公理"获得正向论证：随机性（均匀采样）是"无信息约束下的唯一选择"。

### 5.2 约束下的选择 = 指数族/KMS（结构命题）

**命题 0.11.5.02（选择原理的统一表述，结构命题）**：CSG 中的选择原理：

- 无约束 → 均匀（0.9 模型族）；
- 约束（能量、谱条件等）→ 指数族/KMS（0.10 与本文）。

数学上这是 Jaynes MaxEnt 与量子统计力学的标准结果；CSG 内的定位：选择原理是输入层的机制化——不是新公理（δ 公理不变），而是"模型内选择"（0.2 的立场）的统计形式。

### 5.3 与 δ 公理的关系（开放）

**注（层次区分）**：0.1 的模型多样性（δ 公理在 ZFC 中的实例，逻辑层次）与 0.9 的模型族（概率分布，统计层次）是不同层次。δ 公理是确定性的（0.1 立场），概率出现在模型族层（0.9 立场）——不冲突。**开放问题**：δ 的模型多样性是否诱导统计结构（ZFC 实例集上的分布）？本文不主张——标注开放。

## §6 结论与开放问题

### 结论

1. 信息几何给 0.9 的模型族以三件内禀工具：度量（Fisher）、精度（C-R 界）、选择（MaxEnt）。
2. **三位一体**（KMS ↔ 指数族 ↔ MaxEnt）统一 0.10 统计面与本文信息几何——"约束下的唯一选择"是选择原理的核心。
3. 可读性的第三种形态：连续谱直接可读（谱定理）、离散格读取路径锁死（计算）、量子态需最优测量（QCRB）。
4. 均匀采样获得正向论证（无约束 MaxEnt）——0.9"随机不是公理"的立场深化。

3. 自由 Fisher 信息在随机格谱上的应用（§4.4）。
4. δ 模型多样性的统计结构（§5.3）。
5. 对偶仿射几何（Amari α-连接）在 CSG 的完整展开（本文仅用 Fisher 度量基本性质）。
