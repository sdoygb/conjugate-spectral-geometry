# 预言 2 严格化：时间纠缠几何相位的可检验形式

**编号**：10.50 | **日期**：260811 | **系列**：应用（时间纠缠→量子光学实验接口） | **语言**：CN | **性质**：严格化

**摘要**：10.18 预言 2（复数时间的实验信号）标注为"粗略估计，无严格推导"。本文完成其严格化：预言量修正为时间纠缠熵 $S_{\text{ent}}$（几何相位机制），去掉 $1/2\pi$ 系数的预言角色，给出完整的可检验函数形式 $\delta_\varphi(\Delta\eta,\Delta\xi) = \frac{1}{2}\log\left(1 + \frac{1}{\lambda_1(\Delta\eta)^2 + \lambda_2(\Delta\xi)^2}\right)$ 及其数值窗口。核心新结论：信号强度强烈依赖 $\Delta\eta$（光程差），HOM dip 中心（$\Delta\eta \to 0$）处信号达上限 $0.347$ rad，比 10.18 原文的 $10^{-3}$ 量级评估强约 350 倍。判别性论证：$\delta_\varphi$ 的 $\log(1+1/D)$ 形状与标准 HOM dip（高斯）及标准干涉相位（线性 $\omega\Delta t$）均不同，拟合完整曲线即为判别性检验。诚实标注：几何相位机制为模型级提案，$\Delta\eta \leftrightarrow \Delta L$ 映射为推断级（6.6 §8.2 的桥未建），$S_{\text{ent}}$ 公式保持"几何模型公式"地位。

## §1 动机：预言 2 推导链的审计结论

10.18 §7 预言 2 原文（260808 版，审计时版本；10.18 后续已更新为引用本文的表述）："若时间纠缠存在，则双光子干涉实验中的二阶关联函数应出现可测量的虚部贡献，表现为非零的余弦相位偏移。该偏移量由 $\tau_{\text{ent}}$ 决定，目前预估在 $10^{-3}$ 弧度量级【粗略估计，无严格推导】。该偏移处于当前实验精度边缘。"

逐环审计（引用链全部核实）发现四个问题：

1. **内部数值不一致**：预言值 $10^{-3}$ 与 $\tau_{\text{ent}} = S_{\text{ent}}/(2\pi) \approx 2.0\times10^{-4}$（10.18 定理 10.18.1.03）差 5 倍。$10^{-3}$ 实际是 $S_{\text{ent}} = 1.27\times10^{-3}$ 的量级——"偏移量由 $\tau_{\text{ent}}$ 决定"与数值自相矛盾。
2. **$1/2\pi$ 系数无出处**：10.18 §8 自认"模型系数"，未给任何理由。复数时间的标准推论 $\exp(-i\omega\tau_{\text{phys}}) = \exp(-i\omega\tau_{\text{real}})\cdot\exp(\omega\tau_{\text{ent}})$ 中，虚部给出增益/衰减（对比度修正），不是相位偏移——"余弦相位偏移"需要一个具体机制，而机制从未建立。
3. **实验映射链缺失**：从复数时间 $\tau_{\text{phys}}$ 到"二阶关联函数虚部"的桥未建立。且物理时间翻译 $t = \chi_T\sqrt{\lambda_1}\,\eta$ 在 6.6 §7.2 标注为"推断，非全部定理级"；$\chi_L/\chi_T \neq c$（差 98.6%，6.6 §8.2）——$\chi_T$ 不对应光子传播，$\Delta\eta \leftrightarrow$ 光程差的换算不确定。
4. **$\chi_T$ 引用链不完整**：10.18 只引"谱展开/Born法则（定理 1.3.4.01）"，实际 $\chi_T = 3.616\times10^{-17}$ s 由定理 1.3.4.01 与定理 10.17.0.06 联合确定（6.6 §7.1）。

本文修正 1–3 并补全 4。

## §2 核心修正：预言量 = 时间纠缠熵（几何相位机制）

**命题 10.50.2.01（几何相位机制）**：时间纠缠在双光子干涉项中引入附加几何相位

$$\delta_\varphi(\Delta\eta,\Delta\xi) = S_{\text{ent}}(\Delta\eta,\Delta\xi) = \frac{1}{2}\log\left(1 + \frac{1}{\lambda_1(\Delta\eta)^2 + \lambda_2(\Delta\xi)^2}\right),$$

其中 $\lambda_1 = 392.21\ \text{rad}^{-2}$、$\lambda_2 = 58760.77\ \text{rad}^{-2}$（Birkhoff 混合矩阵本征值：代数作用量 $S(\sigma)$ 在 $\sigma^*$ 处的 Hessian，1.5 §1.2；10.6 §3.1；10.18 定理 10.18.1.02）。

**依据**：
- ① 10.18 原文数值 $10^{-3}$ 本身就是 $S_{\text{ent}}$ 的量级（$\Delta\eta = 1.0$ 时 $1.27\times10^{-3}$）——修正使预言与原文数值一致；
- ② $S_{\text{ent}}$ 无量纲，直接作为相位（rad）最自然，无需 $\omega$、$\chi_T$ 参与量纲链；
- ③ $\tau_{\text{ent}} = S_{\text{ent}}/(2\pi)$（10.18 定理 10.18.1.03）降级为复数时间虚部的辅助概念，不进入预言量。

**修正说明**：$1/2\pi$ 系数退出预言。复数时间的虚部（若保留）给出的是干涉幅度的增益/衰减 $\exp(\pm\omega\tau_{\text{ent}})$，与相位偏移是**两个可区分的信号**——本文预言相位偏移（由 $S_{\text{ent}}$ 决定），对比度修正（由 $\tau_{\text{ent}}$ 决定）留作次级信号，二者可在同一实验中分别拟合（见 §5）。

**诚实标注**：几何相位机制（纠缠熵直接作干涉相位）是模型级提案——框架内无定理直接支撑"纠缠熵作为干涉相位积累"；$S_{\text{ent}}$ 公式本身保持 10.18 定理 10.18.1.02 的"几何模型公式"地位（$1$ 为模型正则化常数，$1/2$ 为模型系数），本文不改变其地位，仅修正其预言角色。

## §3 预言函数与数值窗口

**命题 10.50.3.01（数值窗口）**：取 $\Delta\xi = 1/\sqrt{\lambda_2} = 4.13\times10^{-3}$ rad（最小可分辨尺度，10.18 §4.2 数值例），预言相位偏移：

| $\Delta\eta$ (rad) | $\delta_\varphi$ (rad) | 备注 |
|---|---|---|
| 1.0 | $1.27\times10^{-3}$ | 10.18 原文量级 ✓ |
| 0.5 | $5.02\times10^{-3}$ | |
| 0.1 | $9.25\times10^{-2}$ | |
| 0.05 | $2.04\times10^{-1}$ | 时间纠缠显著阈值（$1/\sqrt{\lambda_1} \approx 0.05$，10.18 预言 1）|
| $\to 0$ | $\to \frac{1}{2}\log 2 = 0.347$ | 上限（HOM dip 中心）|

验证：$\Delta\eta = 0.1$ 时 $D = 392.21\times0.01 + 1 = 4.922$，$\delta_\varphi = \frac{1}{2}\log(1.2032) = 0.0925$；$\Delta\eta \to 0$ 时 $D \to \lambda_2\Delta\xi^2 = 1$（$\Delta\xi = 1/\sqrt{\lambda_2}$ 精确给出 $\lambda_2\Delta\xi^2 = 1$），$\delta_\varphi \to \frac{1}{2}\log 2 = 0.3466$。

**核心新结论**：$\delta_\varphi$ 随 $\Delta\eta$ 单调递减——**信号强度强烈依赖光程差选择**。10.18 原文"处于当前实验精度边缘"的评估基于 $\Delta\eta = 1.0$ 的数值例，过于悲观：HOM dip 中心（$\Delta\eta \to 0$）处信号达 $0.35$ rad 量级，比 $10^{-3}$ 强约 350 倍，远非精度边缘。

若改用有效值 $\lambda_1^{\text{eff}} = 391.05$、$\lambda_2^{\text{eff}} = 59324.3$（10.18 §2.2），数值偏差 $<1\%$，不影响结论。

## §4 实验映射（推断级，诚实标注）

**命题 10.50.4.01（映射假设）**：双光子干涉中两到达时刻的时间差 $\Delta t = \Delta L/c$（光程差），经翻译规则 $t = \chi_T\sqrt{\lambda_1^{\text{eff}}}\,\eta$（6.6 §7.2）给出

$$\Delta\eta = \frac{\Delta L}{c\,\chi_T\sqrt{\lambda_1^{\text{eff}}}}, \qquad \chi_T\sqrt{\lambda_1^{\text{eff}}} = 3.616\times10^{-17}\ \text{s} \times 19.776 = 7.15\times10^{-16}\ \text{s/rad}.$$

| $\Delta\eta$ | $\Delta L$ |
|---|---|
| 1.0 | 214 nm |
| 0.1 | 21.4 nm |
| 0.05 | 10.7 nm |

亚微米光程差在精密干涉仪中常规可达（压电驱动，nm 级控制），实验可行。

**诚实标注（推断级）**：此映射依赖 $\chi_T$ 作为双光子时间差的翻译标度。但 $\chi_L/\chi_T \neq c$（差 98.6%，6.6 §8.2），$\chi_T$ 不对应光子传播——$\Delta\eta \leftrightarrow \Delta L$ 的换算不确定（6.6 §8.2 的 $\Sigma \leftrightarrow \mathbb{R}^{3,1}$ 对偶映射未建设）。**即使映射不确定，预言的形式与上限不变**：$\delta_\varphi$ 作为 $\Delta\eta$ 的 $\log(1+1/D)$ 形状是确定的；实验可在多个 $\Delta L$ 处测 $\delta_\varphi$ 的相对变化检验形状，无需绝对标度。

## §5 判别性论证

**命题 10.50.5.01（判别性）**：标准量子光学不产生 $\delta_\varphi$ 信号：

1. 标准二阶关联函数 $g^{(2)}(\tau)$ 是实函数（强度关联）；复数贡献只出现在一阶场关联或相位敏感测量中；
2. 标准干涉相位 $\varphi = \omega\Delta t$ 随光程差**线性**变化，无 $\log(1+1/D)$ 非线性形状；
3. 标准 HOM dip 形状由波包决定（高斯/洛伦兹），无附加相位；
4. 复数时间的标准推论 $\exp(-i\omega\tau_{\text{phys}})$ 给出的是干涉幅度修正（对比度），非相位偏移——本文预言与标准推论的信号**正交可分**。

**命题 10.50.5.02（标准理论对照）**：标准量子光学对双光子干涉 + 时间纠缠已有完整理论（arXiv:2403.04432，Tian et al., JOSAB 41:2668, 2024）：输出态时间纠缠熵 $S_{\text{VN}}$ 由波包重叠积分 $P$、交叉积分 $J$ 与 BS 分束比 $t/r$ 完全决定（Schmidt 分解），散射矩阵无相位自由度。**标准理论没有 $\delta_\varphi$ 的存在空间**——若实验测得 $\delta_\varphi \neq 0$，则为超出标准量子光学的信号。判别性由此闭环：预言不是与某个标准公式竞争，而是与标准框架的完整性竞争。

**实验方案要点**：相位敏感双光子干涉（干涉仪输出端相位调制 + 符合计数），在多个光程差 $\Delta L$ 处测量相位偏移 $\delta_\varphi$，拟合 $\delta_\varphi(\Delta L) = \frac{1}{2}\log\left(1 + \frac{1}{A(\Delta L)^2 + 1}\right)$（$A = \lambda_1/(c\chi_T\sqrt{\lambda_1^{\text{eff}}})^2$，若映射成立）或直接拟合 $\log(1+1/D)$ 形状（映射不确定时）。**联合测量设计**：同一装置双测——符合率提取标准 $S_{\text{VN}}$（对照 2403.04432 的解析预言，兼作装置自检），条纹相位提取 $\delta_\varphi$（框架预言）；标准信号与框架信号正交可分（幅度 vs 相位）。同时独立拟合对比度修正（$\tau_{\text{ent}}$ 通道）——三个信号的形状与强度关系构成三维判别指纹。

## §6 修正后的预言表述

预言 2（修正版）：**双光子干涉实验中的二阶关联函数应出现非零相位偏移**

$$\delta_\varphi(\Delta\eta) = \frac{1}{2}\log\left(1 + \frac{1}{\lambda_1(\Delta\eta)^2 + 1}\right),$$

数值窗口 $[1.27\times10^{-3}, 0.347]$ rad（$\Delta\eta \in [1.0, 0]$），**HOM dip 中心处信号最强**；形状为 $\log(1+1/D)$（非线性、单调、有上限），与标准干涉相位（线性）和 HOM dip（高斯）均可区分。次级信号：干涉幅度修正 $\exp(\pm\omega\tau_{\text{ent}})$（$\tau_{\text{ent}} = S_{\text{ent}}/(2\pi)$，10.18 定理 10.18.1.03）。

## §7 边界与开放问题

1. **几何相位机制为模型级**：无框架定理直接支撑"纠缠熵作为干涉相位"——这是本文的最大开放环节。若 10.13（量子纠缠的几何解释）能提供支撑，机制可升级；否则保持模型级地位。
2. **$\Delta\eta \leftrightarrow \Delta L$ 映射为推断级**：依赖 6.6 §8.2 的桥未建。预言的形式与上限不受影响，绝对标度待桥建成后校准。
3. **$S_{\text{ent}}$ 公式地位不变**：$1$（正则化常数）、$1/2$（系数）仍为模型参数，不自封为几何论必然结论。
4. **测量方案细节未展开**：相位敏感双光子干涉的具体装置设计（光源、干涉仪拓扑、符合计数方案、噪声预算）为后续工作。
5. **判别性强度**：若实验在 HOM dip 中心观测到 $0.35$ rad 量级相位偏移且形状符合 $\log(1+1/D)$，将是时间纠缠（10.18）与框架时间几何的直接验证；若未观测到，则 $S_{\text{ent}}$ 作相位（或时间纠缠的量子光学映射）被排除——两种结局均有判别力。
6. **$S_{\text{VN}}$ 上限的 2 倍巧合（开放）**：标准理论完全重叠极限（50:50 BS）$S_{\text{VN}} = \log_2 2 = 1$ bit $= 0.693$ nat（2403.04432）；本文 $\delta_\varphi$ 上限 $= \frac{1}{2}\ln 2 = 0.347$ nat——恰为其半。两者定义不同（输出态纠缠 vs 输入时刻纠缠），2 倍关系是巧合还是深层对应待查。
