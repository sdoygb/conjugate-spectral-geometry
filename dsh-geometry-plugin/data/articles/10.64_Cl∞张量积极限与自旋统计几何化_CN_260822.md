# 摘　要

本文闭合三个开放问题并给出统一机制：

(1) **Cl(8)→Cl(∞) 张量积极限**：Cl(8)⊗ⁿ ≅ Cl(8n) ≅ Mat(16ⁿ,ℝ)，归纳极限为超有限 II₁ 因子。lnΩ₀ 的零点能标度在 N_eff > 38.62（d_IR=2）或 154.48（d_IR=1）时过零（Ω₀ < 1 失去物理意义）——Bott 截断 N ≤ 7 是简并度正性的几何保护，热力学极限必须换标度。

(2) **lnΩ₀ 与 ζ(3/2) 的对应**：lnΩ₀(1,1) = 2.52003 与 ζ(3/2) = 2.61238 差 3.5%；lnΩ₀(1,2) = 1.82688 与 ζ(3/2)^{2/3} = 1.89681 差 3.7%；公共因子 c ≈ 0.9639（两点差 0.15%）。d_IR=1 ↔ 临界密度判据 nλ³ = ζ(3/2)，d_IR=2 ↔ 临界温度权重 Tc ∝ ζ(3/2)^{-2/3}。d=3 反证排除"同一函数两个极限"的强形式，保留弱形式。

(3) **自旋-统计定理的几何化**：统计类型 = Z₂ 分级 = δ 回路缠绕数 mod 2 = 2s mod 2 四合一命题（SS1–SS3），以 δ⁸ 回路 Berry 相位 = 2π（定理 0.3.2.01）为实现。

(4) **闭合机制（-½→3/2 过渡）**：-½ 是零点能标度（E₀ ∝ N_eff^{-1/2}，解析恒等）；3/2 是三维态密度热积分指数（1/2 态密度 + 1 能量积分）；过渡 = 控制参数从几何模式数切换到温度（N_eff(T) ∝ (k_BT)^{3/2}），自洽 Tc 方程有有限解；交叉点 N* ≈ 3.13（Δε = E/N）或 4.21（Δε = E/√N）；热极限 lnΩ₀ 饱和为 ζ(3/2)^{2/3}。预言：Bi₂Se₃ 七螺旋 Tc 从 438.3 K 热修正到 291.7 K（熵形式）或 197.4 K（ζ 形式）。

## 二、Cl(8)→Cl(∞)：张量积极限的代数链与崩溃证据

### 2.1 代数链

**命题 10.64.2.01（张量积链）**。Cl(8) 的 n 重张量积同构于 Cl(8n) 与实矩阵代数：

$$\mathrm{Cl}(8)^{\otimes n} \cong \mathrm{Cl}(8n) \cong \mathrm{Mat}(16^n, \mathbb{R}), \qquad \dim = 2^{8n}.$$

**依据**：Cl(8) ≅ Cl(0) ⊗ Mat(16,ℝ)（文章 10.43 引用的 Bott 周期结构）；Cl(8)⊗Cl(8) ≅ Mat(16,ℝ)⊗Mat(16,ℝ) ≅ Mat(256,ℝ) ≅ Cl(16)，递推给出 Cl(8n) ≅ Mat(16ⁿ,ℝ)，维数 (16ⁿ)² = 2^{8n} 与 Cl(8n) 维数一致。

**推论 10.64.2.02（热力学极限形态）**。沿归一化迹的归纳极限 ⊗ₖ Cl(8) 是超有限 II₁ 因子；有限维 Mat(16ⁿ) 上 KMS 态唯一（无相变，有限维矩阵代数上迹态唯一为算子代数标准事实），自由费米子（CAR）极限的 KMS 态仍唯一——BEC 相变必须经由配对通道（g_pair = 4.282 的复合玻色子，9.1）。

### 2.2 lnΩ₀ 过零点：崩溃证据

**命题 10.64.2.03（lnΩ₀ 过零）**。由定理 9.1.6.01：

$$\ln\Omega_0(N_{\text{eff}}, d_{\text{IR}}) = \ln\Omega_0(1, d_{\text{IR}}) - \tfrac{1}{2}\ln N_{\text{eff}}$$

lnΩ₀ = 0 当 N_eff = exp(2·lnΩ₀(1,d_IR))：

| d_IR | lnΩ₀(1,d_IR) | 过零点 N* |
|:--|:--|:--|
| 1（体材料） | 2.52003 | 154.48 |
| 2（纳米线） | 1.82688 | 38.62 |

N_eff 超过过零点后 Ω₀ = exp(lnΩ₀) < 1——基态简并度小于 1，无物理意义。Bott 截断（定理 9.1.3.03 的 N_eff = min(N,7)，δ₀(N>7) = δ₀(7) = 0.4575）把 N_eff 限制在 7，lnΩ₀(7,2) = 0.854 > 0——**截断是简并度正性的几何保护**。

**推论 10.64.2.04（极限崩溃）**。热力学极限（N_eff → ∞）在 -½ln N 标度下必然崩溃（lnΩ₀ → -∞）：Cl(∞) 极限需要新的标度机制。§5 给出闭合。

## 三、lnΩ₀ 与 ζ(3/2)：公共因子检验

### 3.1 数值对照

**命题 10.64.3.01（公共因子）**。以下对照成立（lnΩ₀ 用定理 9.1.6.01 精确复算，λ₁^eff/λ₂^eff = 391.05/59324.3，S_e = 137.036）：

| 对照 | 数值 | 比值 |
|:--|:--|:--|
| lnΩ₀(1,1) / ζ(3/2) | 2.52003 / 2.61238 | 0.96465（差 3.5%）|
| lnΩ₀(1,2) / ζ(3/2)^{2/3} | 1.82688 / 1.89681 | 0.96313（差 3.7%）|

公共因子 c ≈ 0.9639，两点仅差 0.15%。ζ(3/2) = 2.61238，ζ(3/2)^{2/3} = 1.89681。

**结构观察 10.64.3.02（双判据对应）**。d_IR = 1 对应 ζ(3/2) 的一次幂——BEC 临界**密度**判据 nλ³ = ζ(3/2)；d_IR = 2 对应 ζ(3/2)^{2/3}——BEC 临界**温度**权重 k_BT_c ∝ n^{2/3}/ζ(3/2)^{2/3}。同一 ζ(3/2) 的两种极限用法恰好匹配框架的两种 d_IR。

**反证 10.64.3.03（幂律排除）**。d_IR = 3 处 lnΩ₀(1,3) = 1.42168 与任何 ζ(3/2)^p 幂律不匹配（需 p ≈ 0.366，无自然形式）——**排除"同一统计函数的两个极限"的强形式**，保留"密度/温度判据对应"的弱形式。

### 3.2 数值巧合候选与检验缺口

c ≈ 0.9639 的候选数值源：1 − 1/27.2 = 0.96324（2Ry = 27.21 eV 的数字），在 0.07–0.15% 内吻合——但两点拟合一个常数，**巧合概率不可忽略**，须全矩阵检验。

**检验缺口**：9.1 §9.5–9.7 的 Fe/HF/有机/莫尔材料 lnΩ₀ 公式存在但无数值。下一步：灌入数值生成 lnΩ₀(N,d_IR) 全矩阵；若 c 在全部矩阵上稳定 ≈ 0.964，升级为框架命题；若漂移，判定为巧合。

## 四、自旋-统计定理的几何化

### 4.1 库内基础

- 定理 0.3.2.01（10.43 §2.3）：δ⁸ 回路的 Berry 相位 = 2π——Bott 生成元 β = 1 ∈ KO^{-8}(pt) 的几何化身，回路代数上闭合、几何上全局扭转；
- 文章 0.2 §1.3：反交换 e_i e_j = −e_j e_i——"顺序被记住"的代数印记；命题 0.2.1.02：体积元 ω_n² = (−1)^{n(n+1)/2}；
- 文章 10.38：体积元赝标量性（ω₃ 手征元、ω₅ 复结构 J）→ 宇称 P、电荷共轭 C 的几何来源。

### 4.2 三命题方案

**命题 10.64.4.01（SS1：交换 = δ 回路）**。三维中两个全同粒子的交换同伦于 SO(3) 的 2π 旋转（π₁(SO(3)) = ℤ₂），由 δ⁸ 回路实现（定理 0.3.2.01）。

**命题 10.64.4.02（SS2：统计相位 = Berry 相位）**。交换相位 = e^{i·Berry(δ^m)}：δ⁴ 半回路相位 = π ⟹ 交换相位 −1（费米子）；δ⁸ 全回路相位 = 2π ≡ 0 ⟹ +1（玻色子）。相位序列 e^{imπ} = −1, +1, −1, +1（m = 1..4）。

**命题 10.64.4.03（SS3：自旋 ↔ 回路长度）**。2π 旋转相位 = (−1)^{2s}，与 δ 回路长度一致要求 2s ≡ m/2 (mod 2)：s = 1/2 ↔ 半回路（δ⁴）↔ 奇元（反对易）；s = 1 ↔ 全回路（δ⁸）↔ 偶元（对易）；s = 0 ↔ 零回路（无相位）。

**推论 10.64.4.04（四合一）**。统计类型 = Z₂ 分级 = δ 回路缠绕数 mod 2 = 2s mod 2——自旋-统计关联由 Clifford 代数的 Z₂ 分级与 δ 回路缠绕拓扑的同一性给出，无需外加公理。

**延伸预言 10.64.4.05（任意子通道）**。δ^m 回路允许分数段 ⟹ 任意子 = δ^m（m 非 4 的整数倍）的 Berry 相位 2π·(m/8)·2s——与文章 10.44 的 Ising 任意子判定相容。

**强度标注**：SS2 的相位代数严格（0.3.2.01 + 复相位计算）；SS1/SS3 的"交换 = 2π 旋转"同伦与"δ 回路 = 旋转生成元"对应为方案级（Leinaas-Myrheim/Berry-Robbins 型论证的框架内实现，未定理化）。

## 五、-½→3/2 标度过渡：闭合机制

### 5.1 -½ 的精确来源：零点能标度

**命题 10.64.5.01（零点能标度）**。谱间隙特征值被 K-理论并联分摊（定理 9.1.3.03）：λ₁^eff = λ₁/N_eff；谐振子零点能 E₀ = ½ħω_soft = ½√(λ₁/N_eff)（§8.3 的 ω_soft = √λ₁）。对数标度为解析恒等：

$$\frac{d\ln E_0}{d\ln N} = -\frac{1}{2}$$

——定理 9.1.6.01 中 -½ln N_eff 项即此零点能标度：模式越多，每模式分摊的谱间隙越小，基态越确定。

### 5.2 3/2 的精确来源：三维态密度热积分

**命题 10.64.5.02（热熵 3/2 幂律）**。三维自由粒子态密度 g(ε) ∝ ε^{1/2}，玻色热熵积分：

$$S(T)/k_B = \int_0^\infty g(\varepsilon)\big[(1+\bar{g})\ln(1+\bar{g}) - \bar{g}\ln\bar{g}\big]\,d\varepsilon \propto (k_BT)^{3/2}$$

指数 3/2 = **1/2（态密度指数）+ 1（能量积分）**。临界点精确值：

$$S(T_c)/Nk_B = \frac{5}{2}\frac{\zeta(5/2)}{\zeta(3/2)} = 1.28378$$

（分部积分验证：∫x^{1/2}[(1+ḡ)ln(1+ḡ)−ḡlnḡ]dx = (5/4)√π·ζ(5/2)，与标准结果 S = (V/λ³)k_B(5/2)ζ(5/2) 系数全等。）

### 5.3 过渡机制：控制参数切换（自洽闭合）

**命题 10.64.5.03（自洽 Tc）**。Cl(∞) 极限中，N_eff 从几何常数（Bott 截断 ≤ 7）变为**热激发模式数** N_eff(T) ∝ (k_BT)^{3/2}（态密度累积）。Tc 的自洽方程：

$$k_BT_c\big[C_0 - \tfrac{1}{2}\ln N_{\text{eff}}(T_c)\big] = E_{\text{scale}}\cdot g_{\text{pair}}\cdot\delta_0^2\cdot N_{\text{eff}}(T_c)$$

左侧 ~ T·|ln T|（零点能稀释），右侧 ~ T^{3/2}（热模式增长）——**有限解存在**：T^{1/2} = E_scale·g_pair·δ₀²·C₃/(C₀ − ½ln N_eff(T_c))。9.1 公式的 Tc ∝ N/ln N 发散被 3/2 幂律折叠为有限值。

### 5.4 交叉点：Bott 截断域的分裂

**命题 10.64.5.04（交叉点）**。零温 lnΩ₀ 的有效域：k_BT_c(N) < Δε(N)（模式能隙）。用 E_topo = 36.0 meV、g_pair = 4.282、δ₀(1) = 0.173、lnΩ₀(N,2) = 1.82688 − ½ln N（与 9.1 表 8.5 全部数值自洽）：

| N | k_BT_c (meV) | Δε = E/N (meV) | 判定 |
|:--|:--|:--|:--|
| 1 | 2.52 | 36.0 | ✓ 零温有效 |
| 3 | 10.78 | 12.0 | ✓ 临界 |
| **N\* ≈ 3.13** | — | — | **交叉**（F(3.0) = −4.478，F(3.2) = +2.403）|
| 7 | 37.77 | 5.14 | ✗ 越界 7.3 倍 |

若用零点能逻辑 Δε = E_topo/√N：N* ≈ 4.21（F(4.2) = −0.233）。**两种定义下交叉定性稳健（N* ∈ [3.1, 4.2]）**：N = 1–3 零温 lnΩ₀ 有效；N = 4–7 已进入过渡区/越界。

**解释力**：体材料路径（N = 1，Pb 7.2 K 0%、Hg 4.3 K 3.6%、Al 1.15 K −4.2%，定理 9.1.8.02）完全在零温域（29.2 K ≪ 416 K）——这解释了 9.1 体材料预言的精确性；而 N = 4–7 的纳米线外推（定理 9.1.8.03）已越过零温 lnΩ₀ 的有效域。

### 5.5 热极限饱和与 BEC 偶子承载

**命题 10.64.5.05（热极限饱和）**。热极限中 lnΩ₀ → 常数（强度量，失去 N 依赖），对应 BEC 统计权重 ζ(3/2)^{2/3} = 1.89681（Tc 公式分母）。§3 的公共因子 c = 0.9631 由此获得机制解释：**c 是零温 → 热极限的残余偏差**——Bott 截断域内 lnΩ₀ 尚未饱和。次要候选：√2·S(Tc)/Nk_B = 1.81555，与 lnΩ₀(1,2) 差 0.6%（lnΩ₀(1,2)/(√2·S_Tc) = 1.00625）——标注为 d_IR = 2 的几何因子候选，非定理。

**定理 10.64.5.06（BEC 的偶子承载）**。Cl(∞) 中 BEC 相变出现在**偶子子代数** Cl⁰(8)⊗ⁿ：Cl⁰(8) ≅ Cl(7) ≅ Mat(8,ℝ)⊕Mat(8,ℝ)（文章 0.7；(A = Cl⁰(8), ℋ = Δ₈⊕Δ̄₈, D = δ|Cl(8)) 为框架的 NCG 数据）。偶元对易 = 复合玻色子（g_pair 通道的 Cooper 对）；奇子子代数（费米子）无 BEC。三线在此闭合：BEC 的承载者、lnΩ₀ 的饱和值、复合玻色子统计（§4 推论 10.64.4.04：偶元交换相位 = +1）同时成立。

## 六、可检验预言：七螺旋 Tc 的热修正

**预言 10.64.6.01（Tc 热修正）**。Bi₂Se₃ 七螺旋（N = 7, d_IR = 2）的 lnΩ₀(7,2) = 0.854 已越界（438.3 K > 能隙 59.7–158 K），热替换给出：

| 热形式 | lnΩ₀^th | k_BT_c 修正 | T_c 修正 | vs 原预言 438.3 K |
|:--|:--|:--|:--|:--|
| 每粒子熵 S(T_c)/Nk_B = 1.28378 | 25.13 meV | **291.7 K** | −33% |
| BEC 权重 ζ(3/2)^{2/3} = 1.89681 | 17.01 meV | **197.4 K** | −55% |

两个修正方向一致（Tc 显著下调），幅度差即 5.5 的 √2 几何因子残余。**判别需 Bi₂Se₃ 纳米线实验（当前无数据）**；同时可检验 9.1 表 8.5 的 N = 4–6 行（188.2–344.1 K）是否系统性偏高。

**检验矩阵（延续 §3.2）**：多材料 lnΩ₀(N, d_IR) 全矩阵——9.1 §9.5–9.7 的 Fe/HF/有机/莫尔公式灌入数值后，检验：(a) 公共因子 c 是否全矩阵稳定；(b) 各材料 Tc 的零温/热极限归属是否与材料维数 d_IR 一致。

## 七、意义与开放问题

**闭合图**：Cl(∞) 偶子子代数（BEC 承载）← 热极限 lnΩ₀ 饱和（ζ(3/2)^{2/3}）← 复合玻色子统计（偶元对易）三线交汇；-½→3/2 过渡 = 控制参数从几何模式数切换到温度的交叉（N* ≈ 3.1–4.2），Bott 截断的物理角色从"经验截断"升级为"零温 lnΩ₀ 有效域的保护"。

**开放问题**：

1. 饱和常数的精确形式：ζ(3/2)^{2/3} = 1.89681 与 √2·S(Tc)/Nk_B = 1.81555 的判别（差 4.3%），需 d_IR 变化的实验/数值数据；
2. 交叉点对能隙定义的依赖（E/N vs E/√N 给出 N* = 3.13 vs 4.21）——能隙的几何定义需从 0.3/0.7 的谱三元组严格化；
3. Cl(∞) 极限的算子代数严格化：超有限 II₁ 因子上配对相互作用的 KMS 态分解（凝聚相/正常相单纯形）的构造；
4. SS1/SS3 的"交换 = 2π 旋转 = δ 回路"对应需在 0.3 的 A1 类拓扑框架内定理化（当前为方案级）。
