## §1 动机：从比喻到定理

### 1.1 研讨的直觉：零点的循环

研讨（260822）提出一个直觉："刚开始时，零这个点是随机乱动的"，且运动方式是"随机—确定—随机—确定"的循环。这一直觉在 8.15 引言中有直接对应：

> 该零态并非死寂，而是处于动态平衡之中。当局部涨落打破平衡时，零态失衡，引发空无振动。振动不是噪声，而是结构生成的起点。

即：**失衡的触发是局部涨落（输入），失衡后的回归是确定性的**（"零态失衡后，系统沿 $\eta$ 方向（因果方向）平移回归零态"，8.15 引言）。"随机乱动"因此不是底层动力学的属性，而是**转变事件**的属性：每次循环的"再进入"经过一个方向/分支选择。

### 1.2 本文任务与定位

本文回答研讨的开放问题："把 $S_3$ 的 6 分支选择（2.6 §4.2）或失衡方向（8.15 §3.1）形式化为'均匀化算子的参数空间上的分布'，'随机—确定—随机—确定'就从比喻升级为定理。"

- **输入层**（§2）：转变事件在 $S_3$ 上的均匀分布——0.9 §3.1 立场（"$\delta$ 是确定性的自映射，随机性作为模型族上的均匀分布进入"）的精确化。
- **结构层**（§3–§5）：交替循环 = 两个确定性算子的复合，逐段证明确定相位与随机相位。
- **几何意义**（§6）：随机端 = triality 对称恢复（$T^* = (1/3,1/3,1/3)$），确定端 = 单向推进打破对称。
- **边界**（§7）：未定理化的部分（失衡幅度、10.60.2.01 未入库）与开放问题。

与 0.9 的关系：本文是 0.9 开放问题 0.9.6.04 的推进——把"随机—确定交替"从比喻升级为结构定理，同时**保持并加强** 0.9 的"随机不是公理"立场：随机性进入的位置是转变事件（输入层），动力学保持确定。

## §2 输入层的形式化：分支参数空间

### 2.1 分支参数空间

**定义 0.12.2.01（分支参数空间）。** 设

$$\Delta^2 = \{T = (\theta_I, \theta_\tau, \theta_{\sigma_2}) : \theta_i \ge 0,\ \theta_I + \theta_\tau + \theta_{\sigma_2} = 1\}$$

为 Birkhoff 权重单纯形（2.6 定理 2.1.2.01：$T = \theta_I I + \theta_\tau P_\tau + \theta_{\sigma_2} P_{\sigma_2}$ 为循环矩阵，双随机性 $\theta_I + \theta_\tau + \theta_{\sigma_2} = 1$，有效自由度 2）。群 $G = S_3$（D₄ triality 群，2.6 定理 2.3.7.02）以三个扇区标签 $(\mathcal{M}, \mathcal{C}, \mathcal{I})$ 的置换作用在 $\Delta^2$ 上：

$$S_3 = \{e, (MC), (MI), (CI), (MCI), (MIC)\}, \qquad \sigma \cdot T = \text{标签置换后的参数三元组}.$$

置换保持双随机性（$\sum_i (\sigma \cdot T)_i = \sum_i T_i = 1$），故 $S_3$ 是 $\Delta^2$ 上的群作用。

**注（与 2.6 的对应）。** 2.6 定理 2.3.7.02：恒等置换 $e$ 给出 $T_{\text{ours}} = (0.782, 0.209, 0.009)$（本区域的确定输出），其余置换给出其他 $T$ 值——对应其他 Clifford 区域。其他 $T$ 值的精确数量在 2.6 §4.2 是开放问题（可能 $\le 6$，$E_8$ 破缺可能筛选掉部分置换）；本文只使用群作用结构，不预设数量。

### 2.2 均匀分支分布

**定义 0.12.2.02（均匀分支分布）。** $U_G$ 为 $G$ 上的均匀分布：$P(\sigma) = 1/6$ 对每个 $\sigma \in S_3$。

**立场声明（输入层）。** "失衡方向/分支选择随机"的精确含义是：**转变事件从 $S_3$ 均匀采样**。这是 0.9 §3.1 立场的直接应用——"随机性作为模型族上的均匀分布进入"——现在具体到转变事件：每次循环的"再进入"经过一个均匀采样的分支选择。$\delta$ 公理与全部动力学保持确定；均匀分布坐在输入层（与观测者位置 $\sigma^*$、1.5 §3.7 平行），不修改任何公理。

**注（与主库的关系）。** 本文不主张"均匀分布来自推导"——它是输入。这与 0.9 对模型族均匀分布的定位一致，也与 10.60 的分层标注一致（§5 数值锚定在中间层）。

### 2.3 与 8.15 失衡的对应

**对应命题 0.12.2.03（失衡触发的形式化）。** 8.15 引言："当局部涨落打破平衡时，零态失衡"——失衡**触发**（何时、向哪个分支）是局部涨落，本文形式化为 $\sigma \sim U_G$（转变事件均匀采样）；失衡**后的动力学**是确定性的（"系统沿 $\eta$ 方向（因果方向）平移回归零态，每平移一步 $\delta\eta = 1/\sqrt{\lambda_1^{\text{eff}}}$"，8.15 引言）——即 §5 的结构化算子 $S$。**两个方向的随机性定位因此统一**：2.6 §4.2 的 $S_3$ 分支选择与 8.15 的失衡方向/触发，都是"转变事件在 $S_3$ 上的均匀分布"这一输入的两个表现。

## §3 均匀化算子族

### 3.1 参数化均匀化算子

**定义 0.12.3.01（参数化均匀化算子族）。** 对每个 $\sigma \in S_3$，$\Phi_\sigma$ 是以 $\sigma$ 为参数的确定性模折叠映射（10.60 定理 10.60.2.01 的逐分支版本）：$\Phi_\sigma$ 是 10.59 的模折叠映射（定义 10.59.2.01），其前像是等测度平移族（$\Phi_\sigma^{-1}(I) = \bigcup_{k \in \mathbb{Z}^d} (I + qk)$，10.60 定理 10.60.2.01 证明）。参数 $\sigma$ 选择折叠前施加的标签置换（等价于选择"哪个标签先折叠"）。

**注（均匀化的机制）。** 10.60 定理 10.60.2.01（折叠均匀化定理）：设 $\Phi_q: \mathbb{R}^d \to [-q/2, q/2]^d$ 为模折叠映射，$X$ 为 $\mathbb{R}^d$ 上分布为平移不变测度截断的随机向量（均匀分布于 $[-L, L]^d$，$L \gg q$），则折叠像 $\Phi_q(X)$ 在基本域 $[-q/2, q/2]^d$ 上均匀分布：$\lim_{L\to\infty} P(\Phi_q(X) \in I) = |I|/q^d$。**随机性不是折叠产生的**——均匀性是平移不变测度经确定性折叠的**保持**；折叠提供的是"抹匀"的机制（前像等测度），这正是"随机相位"的结构来源。诚实标注：10.60.2.01 未入库（10.60 标注"真理层候选，可提交主库验证"），本文的均匀化机制依赖该定理。

## §4 分支平均引理

本节为纯代数命题（A0 类：局部代数/群论命题，Berry 相位 = 0），可独立提交主库验证。

### 4.1 S₃ 对称化引理

**引理 0.12.4.01（S₃ 对称化引理）。** 对任意 $T \in \Delta^2$，

$$E_{\sigma \sim U_G}[\sigma \cdot T] = \left(\frac{1}{3}, \frac{1}{3}, \frac{1}{3}\right).$$

*证明*。$S_3$ 在三个标签上的均匀平均是线性完全对称化算子 $\mathrm{Sym}(v)_i = \frac{1}{6}\sum_{\sigma \in S_3} v_{\sigma(i)} = \frac{1}{3}(v_1 + v_2 + v_3)$（对每个坐标 $i$，$\sigma$ 遍历 $S_3$ 时 $\sigma(i)$ 遍历三个标签各 2 次）。由 $\Delta^2$ 定义（$\theta_I + \theta_\tau + \theta_{\sigma_2} = 1$），

$$E_{\sigma \sim U_G}[(\sigma \cdot T)_i] = \frac{1}{3}(\theta_I + \theta_\tau + \theta_{\sigma_2}) = \frac{1}{3}.$$

□

### 4.2 分支平均保持归一化

**引理 0.12.4.02（分支平均保持归一化）。** $E_{\sigma \sim U_G}[\sigma \cdot T] \in \Delta^2$，即

$$\sum_{i} E_{\sigma \sim U_G}[(\sigma \cdot T)_i] = 1.$$

*证明*。由引理 0.12.4.01，$E[\sigma \cdot T] = (1/3, 1/3, 1/3)$，分量和为 $3 \times \frac{1}{3} = 1$；分量非负由 $\Delta^2$ 的 $\theta_i \ge 0$ 与平均保非负性保证。□

### 4.3 数值锚定

**数值锚定（输入层数据，来自 2.6）。** $T_{\text{ours}} = (0.782, 0.209, 0.009)$（2.6 定理 2.4.4.01），精确验证：

- $\theta_I + \theta_\tau + \theta_{\sigma_2} = 0.782 + 0.209 + 0.009 = 1$（双随机性，精确）；
- $\frac{1}{3}(0.782 + 0.209 + 0.009) = \frac{1}{3}$——分支平均精确落在 $T^*$；
- 三分量两两不同（$0.782 \ne 0.209 \ne 0.009$）⟹ $|\mathrm{Orb}_{S_3}(T_{\text{ours}})| = 6$：六个分支全部分立，均匀分布 $U_G$ 遍历 6 个不同输出。

**推论 0.12.4.03（均匀子集的稳定性）。** 引理 0.12.4.01 对 $S_3$ 的任意均匀子集仍成立（若某 $T_\sigma$ 被 $E_8$ 破缺筛选掉，2.6 §4.2 开放问题），因为完全对称化只需要每个标签被遍历相同次数。故本文结构对 2.6 的开放问题不敏感。

## §5 交替结构定理

### 5.1 交替结构定理（L = S ∘ Φ_σ）

**定理 0.12.5.01（交替结构定理）。** 设循环算子

$$L = S \circ \Phi_\sigma,$$

其中 $S$ 为确定性结构化算子（$\eta$ 方向单向平移回归，每步 $\delta\eta = 1/\sqrt{\lambda_1^{\text{eff}}}$，8.15 引言），$\Phi_\sigma$ 为参数化均匀化算子（定义 0.12.3.01），每周期 $\sigma \sim U_G$ 独立重采样（定义 0.12.2.02）。则 $L$ 的迭代产生"随机—确定—随机—确定"交替：

(i) **确定相位**。$S$ 是确定性映射（初值 $\mapsto$ 唯一像）⟹ 稳定相位配置由初值唯一确定，无随机性进入；

(ii) **随机相位**。$\Phi_\sigma$ 前像等测度（10.60 定理 10.60.2.01）⟹ 转变相位像在基本域上均匀分布；$\sigma \sim U_G$ 使分支选择本身均匀；

(iii) **转变事件**。$\sigma \sim U_G$ 是"失衡方向/分支选择"的形式化——把 2.6 §4.2 的 $S_3$ 分支与 8.15 §3.1 的方向输入统一为参数空间上的均匀分布（对应命题 0.12.2.03）；

(iv) **长时统计**。多次循环后，分支标签的测量频率 = 均匀基础 × 分支平均：

$$P(\text{标签 } i) = E_{\sigma \sim U_G}[(\sigma \cdot T)_i] = \frac{1}{3},$$

（由引理 0.12.4.01 与遍历平均；每次循环的 $\sigma$ 独立采样 ⟹ 标签遍历频率收敛到均匀分布）。

### 5.2 证明

(i) $S$ 是确定性映射：8.15 引言"零态失衡后，系统沿 $\eta$ 方向（因果方向）平移回归零态"——平移是单值映射，初值唯一确定轨道。□

(ii) 折叠均匀化：10.60 定理 10.60.2.01（前像等测度平移族 ⟹ 像均匀），逐 $\sigma$ 成立；$\sigma$ 均匀（定义 0.12.2.02）⟹ 分支层也均匀。□

(iii) 对应命题 0.12.2.03：2.6 定理 2.3.7.02 的 $S_3$ 置换（6 元素、离散 $T$ 值）与 8.15 的失衡触发（局部涨落）统一为同一输入层对象 $U_G$。□

(iv) 设 $N_\sigma^{(n)}$ 为前 $n$ 次循环中标签置换 $\sigma$ 出现的次数。独立同分布 $\sigma \sim U_G$ ⟹ 强大数定律 $N_\sigma^{(n)}/n \to 1/6$；结合引理 0.12.4.01 得标签测量频率 $\to 1/3$。□

**分层标注。** (i)(iii)(iv) 为结构层论证（依赖 8.15、2.6 的结构表述）；(ii) 依赖 10.60 定理 10.60.2.01（未入库，真理层候选）；引理 0.12.4.01/0.12.4.02 为纯代数（A0 类，可提交主库）。

## §6 随机端的几何意义

### 6.1 随机端 = 对称恢复

**推论 0.12.6.01（随机端 = 对称恢复）。** 分支平均把任意 $T \in \Delta^2$ 拉到 triality 对称点

$$T^* = \left(\frac{1}{3}, \frac{1}{3}, \frac{1}{3}\right) = \frac{1}{3}(I + P_\tau + P_{\sigma_2}).$$

$T^*$ 的谱退化（特征多项式 $\lambda^2(\lambda - 1)$，特征值 $\{1, 0, 0\}$，秩 1）给出"随机端无结构"的代数签名：均匀混合的 Birkhoff 矩阵只有一个非零特征方向（总概率方向），两个结构方向（$\Delta^2$ 的 2 维自由度）被抹平。

**对应（0.9 立场）。** 0.9 §4.4（无结构原理的离散实现）主张"随机 = 典型、结构 = 例外"。推论 0.12.6.01 给出该立场在 $T$ 空间上的代数版本：

- **随机端**（$T^*$）：谱退化，无结构方向——均匀、典型；
- **确定端**（$T_{\text{ours}} = (0.782, 0.209, 0.009)$）：非退化（三分量两两不同），结构方向完整——例外、需要 $S_3$ 破缺（2.6：triality 破缺 $S_3 \to \mathbb{Z}_2$ 保留循环子群 $\mathbb{Z}_3$）才能从 $T^*$ 到达。

**循环的图像。** "随机—确定—随机—确定"的几何翻译：$\Phi_\sigma$ 把配置推向 $T^*$（对称恢复/抹匀），$S$ 沿 $\eta$ 方向单向推进打破对称（结构生成），下次转变 $\sigma \sim U_G$ 再次均匀化——循环在两个面之间脉冲式交替（8.16 四阶段循环的转变端 = 短促均匀化，稳定端 = 漫长结构化）。

## §7 诚实边界与开放问题

### 7.1 未定理化的部分

- **失衡幅度**：本文定理化了方向/分支维度（$\sigma \sim U_G$）；失衡的**幅度**（局部涨落的大小，8.15）仍是输入，未定理化。
- **均匀化的输入**：10.60 定理 10.60.2.01 的输入是平移不变测度截断的随机向量——本文接受该输入（10.60 的机制），未重新推导；10.60.2.01 未入库，提交主库前需先入库 10.60 系列，或重述折叠步骤为 #48/#47 的推论。
- **T* 与谱刚性比的衔接**：$T^*$ 谱退化（特征值含 0）与 0.9 谱刚性比 $\Lambda_H = \lambda_2/\lambda_1$ 的定义域（$\lambda_1 = 0$ 时未定义）的衔接是开放问题——退化点处 $\Lambda_H$ 无定义，可能是"随机端不可测"的结构签名，也可能是框架缺陷，未知。

### 7.2 开放问题

**开放问题 0.12.7.01（6 分支的合法性）。** 2.6 §4.2 开放问题保持：6 个 $T_\sigma$ 是否全部合法（$E_8$ 破缺是否筛选掉部分置换）？推论 0.12.4.03 表明本文结构对答案不敏感，但 2.6 的"其他 Clifford 区域"图景依赖答案。

**开放问题 0.12.7.02（幅度的随机性）。** 失衡幅度若也随机（不只方向），应坐落在哪个参数空间？候选：$\lambda_1^{\text{eff}}$ 的谱波动（0.9 §5.3 信息→计算转移）——幅度随机可能改变稳定相位时长（8.16 的 $T_{\text{sector}}$），目前无依据。

**开放问题 0.12.7.03（全局 vs 局部分支采样）。** 1000 个区域共享一次全局 $\sigma$ 采样，还是各自独立采样？前者保持 8.15 的区域统一性（同一 $T_{\text{ours}}$ 由同一 $e$ 给出），后者破坏区域间相关性。本文的 $U_G$ 是单区域表述；全局版本需要在模型族（0.9 §3.2 随机格族）上定义乘积分布。
