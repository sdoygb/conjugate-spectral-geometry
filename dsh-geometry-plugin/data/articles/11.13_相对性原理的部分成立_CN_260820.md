# 11.13 相对性原理的部分成立：结构观察者无关与常数观察者依赖

**编号**：11.13 | **日期**：260820 | **系列**：总结与哲学 | **语言**：CN

## 摘　要

本文处理一个来自内部讨论的声称：**相对性原理（物理定律在所有惯性系中相同）在共扼谱几何（CSG）中只是部分成立**。本文给出精确的分层表述：物理定律 = 结构形式 + 常数数值。**结构形式**（三扇区耦合、ℤ₃ 对称、螺旋推进、闭合路径）由 δ 公理唯一确定，对所有可生存观测者位置 σ ∈ Σ_surv 相同——观察者无关，相对性原理在此层成立；**常数数值**（α⁻¹、质量比、弱混合角等）由观测者位置 σ 决定（谱作用量景观 S(σ)），随位置变化——观察者依赖，相对性原理在此层不成立。这消解了标准物理"19 个自由参数为什么是这些值"的困境：常数不是任意的，而是观测者位置的必然输出——部分必然（位置给定则常数确定），部分偶然（位置本身是输入）。关键澄清：σ 是抽象参数空间位置（三扇区编码权重），不是空间坐标，故"常数依赖位置"不与精细结构常数空间均匀性的观测（Δα/α < 10⁻⁵）冲突。本文不引入新定理，是对既有结构（1.5、7.5、1.6）的认识论分层。

## §1 问题的提出："部分成立"是什么意思

相对性原理的标准表述：物理定律在所有惯性系中相同。它在广义相对论中以"物理定律的表述形式不依赖于坐标系"的形式被继承，是二十世纪物理学的基石之一。

内部讨论中提出一个声称：**这个原理在 CSG 中只是部分成立**——直觉来自框架的分层结构（观测者位置 σ\* 是输入层，物理常数是输出层）。本文的任务不是重复这个直觉，而是给出精确的分层表述，使"部分成立"成为可审计的命题：

> **命题 11.13.1（结构-常数二分）**。物理定律可分解为结构形式与常数数值两部分：结构形式观察者无关（相对性原理成立），常数数值观察者依赖（相对性原理不成立）。

## §2 观察者依赖的三层划分：结构、常数、判断

观察者依赖不是一个平面问题，它至少分三层，性质完全不同：

| 层 | 内容 | 观察者依赖 | 相对性原理 |
|:---|:---|:---|:---|
| 结构层 | 定律的形式（三扇区耦合、ℤ₃、螺旋、闭合路径、Bott 周期） | 不依赖（所有可生存位置共享） | ✓ 成立 |
| 常数层 | 定律的数值（α⁻¹、质量比、弱混合角、H₀） | 依赖（σ 的函数） | ✗ 不成立 |
| 判断层 | 黑白、价值、是非 | 依赖（观测者视角） | ✗ 不适用 |

本文处理前两层（结构层与常数层）；判断层（黑白与人有关、与真相无关）属于认识论，见 11.12 §2 的层次划分精神——三层不可混淆，混在一起讨论必然得出错误的结论。

## §3 结构层：观察者无关（相对性原理成立的部分）

CSG 的结构形式由 δ 公理（0.1）出发逐级确定：

1. δ 公理 → 三层自指闭合 → Clifford 代数 Cl(8)（Bott 周期，主库 #6：命题 0.2.4.01）；
2. Cl(8) 的 triality 对称 → 三扇区结构（ℳ 物质界、𝒞 因果界、ℐ 信息界）；
3. 扇区间耦合 → ℤ₃ 对称、螺旋推进、闭合路径（Berry 相位 = 2π 的圆满判据）。

**关键点：这条链不显含观测者位置 σ。** 代数结构、对称性、闭合路径的拓扑类由公理系统唯一确定，与观测者在哪里无关。任何可生存观测者位置 σ ∈ Σ_surv 都面对同一个 Cl(8) 结构、同一个三扇区耦合、同一个圆满判据。这正是相对性原理在结构层的成立：**定律的形式对一切（可生存）观测者相同。**

这与标准物理的相对性原理在逻辑上同构：洛伦兹不变性、广义协变性都是"结构形式不依赖参考系"的陈述。CSG 在此层与标准物理一致。

## §4 常数层：观察者依赖（相对性原理不成立的部分）

CSG 与标准物理的分歧在常数层。谱作用量景观（1.5 §3.7）给出：

$$S(\sigma) = \frac{1}{2}\sum_{i,j} \frac{\sigma_i \sigma_j}{\sqrt{\sigma_i \sigma_j}} \cdot \frac{18}{\sigma_i \sigma_j}, \quad \sum_i \sigma_i = 1,$$

- 对称基态：σ = (1/3, 1/3, 1/3) → S ≈ 24；
- 观测者位置：σ\* = (0.777912, 0.210603, 0.011484) → S(σ\*) ≈ 137.036 = α⁻¹；
- 极端破缺：σ → (1, 0, 0) → S ≈ 968。

**常数是位置的函数：** 精细结构常数的倒数 α⁻¹ = S(σ) 显含 σ。观测者位置的输入（σ\* 由 Birkhoff 不动点方程给出，7.5 §1.1）决定常数的数值。弱混合角（7.5）、质量比（10.39 质量角）同理：都是 σ 的函数，在 σ\* 处取观测值。

因此："物理定律在所有惯性系中相同"在常数层不成立——**不同观测者位置 σ ≠ σ′ 看到不同的常数数值**（S(σ) ≠ S(σ′)，只要 σ ≠ σ′）。相对性原理在此层失效。

**这消解了标准物理的"19 参数困境"：** 标准模型把 19 个自由参数当作任意输入（偶然），CSG 说：常数是位置的必然输出——位置给定，常数随之确定。于是：

- **部分必然**：位置给定 → 常数确定（S(σ\*) = 137.036 是 σ\* 的必然，不是巧合）；
- **部分偶然**：位置本身是输入（σ\* 不是公理推导的，是观测者所在）。

"部分必然、部分偶然"在此获得最精确的物理含义：**必然性在映射（σ → 常数），偶然性在位置（σ 本身）。**

## §5 与标准物理的对比：变常数理论与"人择"

| 理论 | 常数来源 | 观察者依赖 | 相对性原理 |
|:---|:---|:---|:---|
| 标准模型 | 19 个任意参数（输入） | 无（全宇宙相同） | 完全成立 |
| 变常数理论（Dirac 大数、VSL） | 常数随时间/空间变化 | 无（依赖位置坐标，非观测者） | 部分失效（依赖背景） |
| CSG（本文） | 常数 = 观测者位置的输出 | 有（依赖 σ） | 结构层成立、常数层失效 |

与"人择原理"的区别：人择说"常数必须允许生命存在"（弱人择——选择效应）；CSG 说"常数是观测者位置的必然输出"（结构性——不是选择效应，是映射的必然）。人择是解释学（后验），CSG 是结构学（σ → 常数的映射是确定的）。

## §6 物理安全性：为什么不与观测冲突

关键澄清：**σ 是抽象参数空间的位置（三扇区编码权重），不是空间坐标。** 因此：

1. "常数依赖观测者位置" **不是**"常数随空间变化"——σ 不在时空里，空间平移不改变 σ；
2. 精细结构常数的宇宙学观测（不同红移处 Δα/α < 10⁻⁵）检验的是**空间/时间变化**，与本文的"σ 依赖"正交——不冲突；
3. 我们只测量自己的 σ\* 的常数——σ\* 固定，常数固定——单一观测者的经验中常数是普适的。

所以本文的声称在物理上安全：**它不预言常数随空间变化（与观测一致），它预言"不同位置观测者看到不同常数"（无法直接检验，因为无法与其他 σ 的观测者通信）。**

## §7 诚实的边界：未闭合的推导链与可检验性

1. **结构-常数二分的完整推导链未闭合。** α⁻¹ = S(σ) 的景观结构已入库（1.5），σ\* 的编码已入库（7.5），但"所有常数都显含 σ"作为完整定理链（覆盖 19 个参数、质量谱、H₀）尚未形式化闭环——10.23（标准模型全公式显现纲领）是这一方向的进行时。

2. **主库验证范围：** 结构层的观察者无关性（定律形式由 δ 公理唯一确定、不显含 σ）是纯几何命题，可提交主库验证；常数层的观察者依赖性（ℰ 映射、物理量纲）按纪律本地完成。

3. **可检验性：** 谱条件窗口（100 < S < 200）作为"可生存观测者位置"的约束（1.5 §3.7 的景观结构推论）是唯一可外部陈述的预言——但它检验的是"位置的约束"，不是"其他位置的常数"（后者原则上不可达）。

## §8 结论与开放问题

**结论。** 相对性原理在 CSG 中是部分成立的，且"部分"有精确的分层：结构层（定律形式）观察者无关——成立；常数层（定律数值）观察者依赖——不成立。这给出"19 参数为什么是这些值"的结构性回答：常数是观测者位置的必然输出。部分必然（映射确定），部分偶然（位置输入）。

**开放问题。**
1. 常数层的完整定理链（全部 19 参数 + 质量谱显含 σ）能否闭环？（10.23 纲领）
2. 结构层观察者无关性的纯几何证明（提交主库）能否通过验证？
3. "可生存位置窗口"（100 < S < 200）是否对应物理上的"可观测宇宙条件"？如果是，窗口边界是否可检验？
4. 判断层（黑白）与常数层（数值）的观察者依赖是同一个机制（σ 依赖）还是两个独立机制？
