## §1 动机与缺口定位

3.12 §8（量子测量理论）宣称封闭"量子测量公设"：§8.1 定义 zonal 投影算子族 {P̂_k}，§8.2（#46）给出单次测量 m_k = sgn(Re P̂_kΨ)，§8.3（#47 基础）给出 Born 法则的遍历闭合，§8.4（#48）给出塌缩=截面投影。**这是投影测量（projective measurement）的封闭，不是测量理论的完整封闭**：

1. **完全性缺口**：3.12 §8.1 的投影族满足近似正交（命题 3.12.8.01：P̂_jP̂_k† ≈ δ_jkO(Δξ²)），但**未验证完全性** Σ_k P̂_k†P̂_k = I。本文 §3 证明它实际等于 (N₁/16)Π_{H₁}——只覆盖第一调和子空间 H₁，且差一个系数。
2. **POVM 缺失**：广义测量（正算子值测度，E_i ≥ 0，ΣE_i = I，不要求幂等）在 3.12 §8 中不存在。
3. **Zeno 缺失**：测量与演化的交替结构（测量—演化—测量—…）在 3.12 中未处理——§4 有演化（扩散/薛定谔半群），§8 有测量，但没有两者组合的定理。
4. **弱测量缺失**：部分信息提取、不塌缩的测量在框架内无对应（10.60 §7 开放问题 4 已指出的"截面加粗"方向）。

本文封闭缺口 2 与 3；缺口 4 以"探测器盲区"的形式部分封闭（E_rest 即"读不到的弱信息"），完整的弱测量动力学保持开放。

## §2 预备

### 2.1 zonal 投影族（3.12 §8.1 定义 33）

在扇区参数空间 S³ 上，{â_k}_{k=1}^{N₁}（N₁ = 6000）为近似均匀分布的像素方向集。第一 zonal 调和函数 Z_k(ξ) = â_k·x̂(ξ)，投影泛函

$$\hat{P}_k: L^2(S^3,\mathbb{C}) \to \mathbb{C},\qquad \hat{P}_k\Psi = \langle Z_k|\Psi\rangle = \int_{S^3}(\hat{a}_k\cdot\hat{x})\,\Psi(\xi)\,\mathrm{d}\mu(\xi).$$

基本计算（3.12 §8.1）：∫_{S³}(â_j·x̂)(â_k·x̂)dμ = (1/4)â_j·â_k。特别地 ⟨Z_k|Z_k⟩ = 1/4。

### 2.2 演化与作用量子（3.12 §4 + 10.67）

几何演化：i∂_τΨ = Ĥ_geomΨ（3.12 命题 3.12.4.01），Ĥ_geom = −(1/2λ₁^eff)∂_η² + V(η)（3.12 §4.2）。几何作用量子（10.67 定理 10.67.3.01）：

$$\hbar_{\text{geom}} = \frac{1}{2\lambda_1^{\text{eff}}} = \frac{1}{782.1} \approx 0.0012786\ \text{rad}^2,\qquad 2\hbar_{\text{geom}} = \frac{1}{\lambda_1^{\text{eff}}} = \frac{20000}{7821} \approx 0.002557\ \text{rad}^2,$$

λ₁^eff = 391.05 rad⁻²（3.12 §4.3 锚定）。

### 2.3 测量与折叠（#46、#48、10.60、0.12）

单次测量 #46：m_k = sgn(Re P̂_kΨ)；塌缩 #48：Ψ_after = P̂_kΨ（截面投影，维度骤降→信息丢失→随机）；折叠均匀化（10.60 定理 10.60.2.01）：确定性商映射产生均匀测度；交替循环（0.12 定理 0.12.5.01）：L = S∘Φ_σ，σ ~ U_G 每周期重采样。

## §3 几何 POVM 构造

### 3.1 完全性缺口

**命题 10.70.2.01（投影族的完全性）**。设 {â_k}_{k=1}^{N₁} 为 S³ 上近似均匀的像素方向（N₁ = 6000），Z_k = â_k·x̂ 为第一 zonal 调和函数。则

$$\sum_{k=1}^{N_1} |Z_k\rangle\langle Z_k| = \frac{N_1}{16}\,\Pi_{H_1} + O\left(\frac{N_1}{\sqrt{N_1}}\right),$$

其中 Π_{H₁} 为第一调和子空间 H₁（S³ 坐标函数，dim H₁ = 4）上的恒等投影，O(N₁/√N₁) 为像素采样的蒙特卡洛误差。

*证明*。(1) 离散核：对任意 f = v·x̂ ∈ H₁（v ∈ ℝ⁴），

$$\left(\sum_k |Z_k\rangle\langle Z_k| f\right)(\hat{x}) = \sum_k (\hat{a}_k\cdot\hat{x})\int_{S^3}(\hat{a}_k\cdot\hat{x}')\,v\cdot\hat{x}'\,\mathrm{d}\mu(\hat{x}') = \sum_k (\hat{a}_k\cdot\hat{x})\left(\frac{1}{4}\hat{a}_k\cdot v\right) = \frac{1}{4}\,x̂^{\top}\!\left(\sum_k \hat{a}_k\hat{a}_k^{\top}\right)v.$$

(2) 均匀采样：E[ââᵀ] = I₄/4（S³ 均匀分布单位向量），故 Σ_k â_kâ_kᵀ = (N₁/4)I₄ + O(√N₁)（中心极限，误差 O(√N₁) 每分量）。(3) 代入：Σ_k|Z_k⟩⟨Z_k|f = (N₁/16)(x̂·v) = (N₁/16)f 在 H₁ 上；f ⊥ H₁ 时每项 ∫(â_k·x̂')f(x̂')dμ = 0（zonal 调和正交于高阶调和），像为零。∎

**推论 10.70.2.02（不完全性的几何意义）**。3.12 §8.1 的投影族只覆盖 H₁ 且差系数 N₁/16——**像素测量天然是第一调和截面上的读数**。高阶调和（精细结构）在像素测量下不可分辨：这正是 10.59 折叠信息丢失（σ·R > q/2 时方向信息丢失）的测量版本——高阶信息"折叠进盲区"。

### 3.2 POVM 构造

**定理 10.70.2.03（几何 POVM 构造）**。定义

$$E_k = \frac{16}{N_1}|Z_k\rangle\langle Z_k| = \frac{1}{375}|Z_k\rangle\langle Z_k|,\qquad E_{\text{rest}} = I - \Pi_{H_1}.$$

则：

(i) **正半定性**：E_k ≥ 0（秩一正半定 × 正系数），E_rest ≥ 0（正交补投影）；

(ii) **完全性**：Σ_k E_k + E_rest = I（精确），Σ_k E_k = Π_{H₁}（像素近似，命题 10.70.2.01，误差 O(1/√N₁)）——{E_k, E_rest} 是 S³ 上的合法 POVM；

(iii) **概率**：p_k = ⟨Ψ|E_k|Ψ⟩ = (16/N₁)|⟨Z_k|Ψ⟩|²，p_rest = ⟨Ψ|E_rest|Ψ⟩ = 1 − ‖Π_{H₁}Ψ‖²；Σ_k p_k + p_rest = 1（精确，对任意归一化 Ψ ∈ L²(S³)）；

(iv) **H₁ 限制下的投影测量还原**：若 Ψ ∈ H₁（方向编码态），p_rest = 0，p_k = (4/N₁)⟨Ψ|P_k|Ψ⟩，P_k = 4|Z_k⟩⟨Z_k| 为幂等投影（⟨Z_k|Z_k⟩ = 1/4 ⟹ P_k² = P_k）——还原为 3.12 §8 的投影测量语境。

*证明*。(i)(ii) 直接。(iii) 完全性 (ii) 取期望。(iv) P_k² = 16⟨Z_k|Z_k⟩|Z_k⟩⟨Z_k| = 16·(1/4)|Z_k⟩⟨Z_k| = P_k。∎

**注（POVM 优于投影测量的关键）**。POVM 元素不要求幂等、不要求正交——因此不需要 3.12 §8.1 的近似正交性（命题 3.12.8.01 的 O(Δξ²) 误差）。这使 POVM 构造对像素分布的不均匀性鲁棒：只要 Σ_k â_kâ_kᵀ ≈ (N₁/4)I₄（均匀性的一阶矩条件），构造即成立。

**数值自洽**：Tr(Σ_k E_k) = Σ_k (16/N₁)⟨Z_k|Z_k⟩ = N₁·(16/N₁)·(1/4) = 4 = dim H₁ = Tr(Π_{H₁}) ✓。

### 3.3 弱测量的第一形式

**推论 10.70.2.04（盲区概率 = 弱信息量）**。p_rest = 1 − ‖Π_{H₁}Ψ‖² 是"读不到的信息"的概率测度——与 10.59 混叠等价类（折叠抹除方向信息）同一逻辑：**POVM 的盲区就是折叠的像外残差**。弱测量的完整动力学（部分投影、不塌缩）需要"加粗截面"的多值量化（10.60 §7 开放问题 4），本文只给出盲区概率，不给出弱测量算子的完整族——开放。

## §4 几何 Zeno 冻结

### 4.1 冻结定理

**定理 10.70.3.01（几何 Zeno 冻结）**。设 |Ψ₀⟩ ∈ H₁，测量为幂等截面投影 P_k = 4|Z_k⟩⟨Z_k|（§3.2 (iv)），两次测量间演化 U(δτ) = exp(−iδτ Ĥ_geom/ħ_geom)（3.12 命题 3.12.4.01 + 10.67），n 次测量，总时间 t = nδτ 固定。若测量间隔满足 **Zeno 条件**

$$\delta\tau \ll 2\hbar_{\text{geom}} = \frac{1}{\lambda_1^{\text{eff}}} = \frac{20000}{7821} \approx 0.002557,$$

则：

(i) **冻结**：跃迁出 P_k 像空间的概率

$$P_{\text{esc}} \approx \frac{n\,\delta\tau^2\,(\Delta\hat{H}_{\text{geom}})^2}{\hbar_{\text{geom}}^2} \xrightarrow{\delta\tau \to 0} 0;$$

(ii) **相位累积**：留在像空间的分量获得确定性相位 e^{−it⟨Ĥ_geom⟩_k/ħ_geom}，概率不转移；

(iii) **几何解读**：高频截面投影（#48）锁住方向 â_k——每次测量都把 Ψ 拉回截面（维度骤降，信息丢失），若两次测量间隔小于扩散特征时间 1/λ₁^eff，信息没有时间逃逸出截面——**冻结是"截面投影频率超过信息逃逸速率"**。

*证明*。(1) 展开 U(δτ) = I − iδτĤ/ħ − δτ²Ĥ²/2ħ² + O(δτ³)，得

$$P_k U(\delta\tau) P_k = P_k\left(1 - \frac{i\delta\tau\langle\hat{H}\rangle_k}{\hbar} - \frac{\delta\tau^2(\Delta\hat{H})_k^2}{2\hbar^2}\right) + O(\delta\tau^3),$$

其中 ⟨Ĥ⟩_k = ⟨Z_k|Ĥ|Z_k⟩，⟨Z_k|Z_k⟩ = 1/4 归一化后取期望，(ΔĤ)_k² = ⟨Ĥ²⟩_k − ⟨Ĥ⟩_k²。(2) n 次迭代，n → ∞，δτ → 0，nδτ = t：

$$(P_k U(\delta\tau) P_k)^n = P_k\left(1 - \frac{i\delta\tau\langle\hat{H}\rangle_k}{\hbar} - \frac{\delta\tau^2(\Delta\hat{H})_k^2}{2\hbar^2}\right)^n + O(n\delta\tau^3) \xrightarrow{\ } P_k\,e^{-it\langle\hat{H}\rangle_k/\hbar}.$$

(3) 跃迁概率：P_esc = 1 − |⟨Ψ₀|(P_kU(δτ)P_k)ⁿ|Ψ₀⟩|² ≈ nδτ²(ΔĤ)²/ħ²（(1−ε)ⁿ ≈ 1−nε 展开）。(4) 代入 ħ = ħ_geom = 1/(2λ₁^eff)。∎

**分层标注**：定理 10.70.3.01 的证明是标准 Misra–Sudarshan 论证（纯算子代数，A0 类）；"Zeno 条件 δτ ≪ 2ħ_geom"的数值（20000/7821 ≈ 0.002557）依赖 λ₁^eff = 391.05 rad⁻²（3.12 §4.3，中间层锚定）；(iii) 的物理解读是框架推论。

### 4.2 与不确定性原理的连接

**推论 10.70.3.02（Zeno 条件 = 不确定性下界）**。Zeno 条件 δτ ≪ 2ħ_geom 与几何不确定性原理（10.67 定理 10.67.3.01：σ_η·σ_p ≥ ħ_geom/2）由同一常数控制：2ħ_geom = 4·(ħ_geom/2)。**冻结的时间尺度与位置-动量不确定度的乘积下界是同一个几何量的不同表现**——谱间隙 λ₁^eff 同时设定"确定性的最小尺度"（10.67）与"冻结所需的最大测量间隔"（本文）。谱间隙越大 ⟹ ħ_geom 越小 ⟹ 不确定性越小且冻结越容易——**谱刚性是确定性的来源**（与 0.9"谱刚性=结构"同向）。

## §5 微观-宏观统一：Zeno ↔ 交替循环

**推论 10.70.4.01（冻结-释放机制的两个极限）**。0.12 的循环算子 L = S∘Φ_σ（定理 0.12.5.01）与本文的 Zeno 结构是同一机制的两个极限：

| | 微观 Zeno（本文 §4） | 宏观交替循环（0.12） |
|:--|:--|:--|
| 测量/折叠算子 | P_k（固定方向，幂等投影） | Φ_σ（σ ~ U_G 每周期重采样） |
| 方向采样 | 固定（同一 â_k 重复） | 均匀重采样（U_G，0.12 定义 0.12.2.02） |
| 长期行为 | 冻结在 â_k（概率不转移） | 标签频率 → 1/3（0.12 引理 0.12.4.01） |
| 时间尺度 | δτ ≪ 2ħ_geom（Zeno 条件） | 周期 ≫ τ_dec（8.16 四阶段） |
| 几何解读 | 截面投影频率 > 信息逃逸速率 | 均匀化频率 > 结构化速率 |

**统一表述**：方向不重采样 ⟹ Zeno 冻结（信息锁在单截面）；方向均匀重采样 ⟹ 交替循环（信息在 6 分支间均匀分配）。**重采样分布决定宏观统计，测量频率决定微观冻结**——0.12 的 σ ~ U_G 与本文的 δτ 是两个独立控制旋钮，分别控制"锁在哪里"与"锁得多紧"。

## §7 诚实边界与开放问题

### 7.1 诚实边界

1. **完全性的统计输入**：命题 10.70.2.01 的 O(1/√N₁) 误差依赖像素均匀分布（一阶矩条件 Σ_k â_kâ_kᵀ ≈ (N₁/4)I₄）——这是统计近似（中间层），不是纯几何定理；误差的精确常数未计算（仅量级）。
2. **Zeno 的 ΔĤ_geom 未锚定**：定理 10.70.3.01 的 P_esc 含 (ΔĤ_geom)²，本文未用谱间隙给出其具体数值（ΔĤ_geom ~ λ₁^eff 量级是估计，非定理）——P_esc 的精确数值是开放问题。
3. **弱测量不完整**：推论 10.70.2.04 只给出盲区概率 p_rest，未给出弱测量算子的完整族（"加粗截面"多值量化，10.60 §7 开放问题 4）。
4. **主库提交性**：定理 10.70.3.01（Zeno 冻结）是纯算子代数（A0 类），可提交主库；定理 10.70.2.03 的 (i)(iii)(iv) 是代数，(ii) 依赖统计近似。注意 2026-08-22 主库去重存在误判记录（A0/0/1 组合撞 3.1.6.07），提交需注意。

### 7.2 开放问题

**开放问题 10.70.5.01（Zeno 条件的实验检验）**。δτ ≪ 2ħ_geom ≈ 0.002557 是"几何时间"（rad² 单位）——映射到物理时间的量纲桥（10.13 参数表：ħ = 6.582×10⁻¹⁶ eV·s）未在本文处理；Zeno 冻结的物理可观测时间尺度依赖该映射，未闭合。

**开放问题 10.70.5.02（反 Zeno 效应）**。非理想测量（E_k 非幂等，含盲区泄漏）在高频极限下可能加速演化（反 Zeno 效应）——本文的 E_rest 泄漏项 δτ·(盲区耦合) 是否产生反 Zeno，未分析。

**开放问题 10.70.5.03（H₁ 限制的合理性）**。物理态是否真的限制在第一调和子空间 H₁（方向编码态），还是高阶调和在物理上可及？若可及，POVM 需在更高调和层构造（zonal 调和推广到 k 阶球谐）——本文的 (16/N₁) 系数与 N₁ 的标度会改变。这是"像素测量能读到多少精细结构"的结构性问题，与 10.59 的混叠分辨率 σ·R > q/2 同族。
