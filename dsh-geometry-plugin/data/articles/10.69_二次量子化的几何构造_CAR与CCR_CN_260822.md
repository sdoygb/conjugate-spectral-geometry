## 二、费米子 CAR 的几何构造

### 2.1 复数化与正号生成元

**引理 10.69.2.01（符号转正）**。设 {e_i} 是实 Clifford 代数 Cl(n) 的生成元，满足 e_i² = −1，e_i e_j + e_j e_i = 0（0.2 定义 0.2.1.01 的约定）。在复数化 Cl(n)⊗ℂ 中定义 γ_i = i·e_i（i 为虚数单位）。则

$$\gamma_i^2 = +1, \qquad \gamma_i \gamma_j + \gamma_j \gamma_i = 0 \quad (i \neq j).$$

**证明**。γ_i² = (i·e_i)² = i²·e_i² = (−1)(−1) = +1；反交换性在乘以纯量 i 下保持。∎

> **注（约定合法性）**。0.2 §1.1 注记已声明"e_i² = +1 在标准 Clifford 代数定义中同等合法"。本文不改变 0.2 的约定，而是通过复数化把负号约定转正——复数化是框架内已有操作（3.12 §6.4 的复结构 J 即来自 Cl(7) 的复数化，引理 0.2.2.03）。

### 2.2 产生/湮灭算符

**定义 10.69.2.01（费米子产生/湮灭算符）**。在 Cl(2n)⊗ℂ 中，对 k = 1, …, n：

$$a_k = \tfrac{1}{2}(\gamma_{2k-1} + i\gamma_{2k}), \qquad a_k^\dagger = \tfrac{1}{2}(\gamma_{2k-1} - i\gamma_{2k}).$$

**定理 10.69.2.01（CAR 验证）**。上述算符满足正则反对易关系：

$$\{a_j, a_k^\dagger\} = \delta_{jk}, \qquad \{a_j, a_k\} = 0, \qquad \{a_j^\dagger, a_k^\dagger\} = 0.$$

**验证**（符号计算，工具确认）。取 γ₁ = σ_x、γ₂ = σ_y（Pauli 矩阵，满足 γ² = I、反交换）。则 a = (σ_x + iσ_y)/2 = [[0,1],[0,0]]，a† = [[0,0],[1,0]]：

- {a, a†} = aa† + a†a = I（单位阵）✓
- {a, a} = 2a² = 0 ✓
- 粒子数算符 N = a†a = [[0,0],[0,1]]，N² = N（幂等）✓

k ≠ j 情形由不同下标生成元的反交换性直接为零。∎

**命题 10.69.2.02（粒子数算符）**。N_k = a_k†a_k 是幂等投影（N_k² = N_k），本征值 ∈ {0, 1}——费米子的占据数二值性从 Clifford 代数自动涌现，无需额外公设。

**推论 10.69.2.03（与自旋-统计连接）**。a_k 是 γ_{2k-1}, γ_{2k} 的奇数元组合（一个 γ 因子），承载反对易——与 10.64 命题 10.64.4.03（SS3）"s = 1/2 ↔ 半回路 ↔ 奇元（反对易）"精确对应：**费米子 = CAR = Clifford 奇元**。

## 三、玻色子 CCR 的几何构造

### 3.1 辛结构与 Kähler 极化

**引理 10.69.3.01（辛结构的库内来源）**。3.12 §6.4 命题 3.12.6.02 已构造：编码轨道在 ℳ 扇区的投影 ≅ S² 是 Kähler 流形，配备辛形式 ω = dξ∧dη 与复结构 J（J² = −1，来自 Cl(7) 复结构，引理 0.2.2.03）；Kähler 极化给出投影算子 P_± = (1∓iJ)/2，将复化切丛分解为全纯/反全纯子丛 T_ℂS² = T^{1,0} ⊕ T^{0,1}。

### 3.2 产生/湮灭算符

**定义 10.69.3.01（玻色子产生/湮灭算符）**。在 Kähler 极化下，全纯截面空间（如 O(1) 的全局全纯截面 ≅ ℂ²，3.12 §6.4）构成玻色子单粒子态空间 H_hol。定义 a（湮灭）、a†（产生）为满足正则对易关系的一对算符。

**定理 10.69.3.01（CCR 验证）**。

$$[a, a^\dagger] = 1.$$

**验证**（微分实现，工具确认）。取 a = d/dx、a† = x（L²(ℝ) 上，Schwartz 空间内）：[d/dx, x]·f = (x·f)′ − x·f′ = f——对任意函数 f 成立，故 [d/dx, x] = 1。∎

**推论 10.69.3.02（与自旋-统计连接）**。玻色子算符是偶元（零个或两个 γ 因子），承载对易——与 10.64 命题 10.64.4.03（SS3）"s = 1 ↔ 全回路 ↔ 偶元（对易）"精确对应：**玻色子 = CCR = Clifford 偶元**。

> **注（玻色子构造的几何意义）**。玻色子不直接来自 Clifford 生成元本身，而是来自辛结构（J, ω）——Kähler 极化 P_± 把 S² 的切空间分解为产生/湮灭方向。这是 10.64 SS3"玻色子 = 零回路/偶元"的代数实现：偶元构成 Cl(n) 的偶子代数 Cl⁰(n) ≅ Cl(n−1)（Bott 周期结构），其上的辛结构来自复结构 J。

## 四、Fock 空间与统计类型的统一

**定理 10.69.4.01（Fock 构造）**。由 3.12 §9.4 命题 3.12.9.03（对称/反对称张量子空间），定义费米子与玻色子的 Fock 空间：

$$\Gamma_a(\mathcal{H}) = \bigoplus_{N=0}^{\infty} \bigwedge^N \mathcal{H} \quad (\text{费米子}), \qquad \Gamma_s(\mathcal{H}) = \bigoplus_{N=0}^{\infty} \bigvee^N \mathcal{H} \quad (\text{玻色子}),$$

其中 ℋ = L²(S³, ℂ)（3.12 §9.4），∧^N 为反对称张量积，∨^N 为对称张量积。产生/湮灭算符在 Fock 空间上的标准作用（a_k† 增加一个占据、a_k 减少一个占据）与 §2/§3 的代数一致。

**命题 10.69.4.02（统计类型 = 代数类型，三线合一）**。以下三种刻画指向同一分类：

| 层面 | 费米子 | 玻色子 | 出处 |
|:--|:--|:--|:--|
| 拓扑（构型空间） | 符号表示（反对称波函数） | 平凡表示（对称波函数） | 3.12 定理 3.12.9.01 |
| 几何（自旋-统计） | 奇元（反对易），δ 半回路 | 偶元（对易），δ 全回路 | 10.64 命题 10.64.4.01–4.04 |
| 代数（本文） | CAR {a,a†} = 1 | CCR [a,a†] = 1 | 定理 10.69.2.01 / 3.01 |

**命题 10.69.4.03（CAR 极限 KMS 态的实体化）**。10.64 推论 10.64.2.02 引用的"自由费米子（CAR）极限的 KMS 态"由此获得代数实体：CAR 代数（§2 构造）配 0.10 定义 0.10.1.01 的 GNS 构造与 0.10 §2.2 的 KMS 条件，给出自由费米子平衡态的标准框架——有限维 Cl⁰(8) ≅ Mat(8,ℝ)⊕Mat(8,ℝ) 上迹态唯一（无相变），与 10.64 推论一致。

1. **审核缺口封闭**：审核报告"二次量子化 ❌ 缺失"的判定现在改为"✅ 已覆盖（构造层）"。Fock 空间、CAR/CCR、粒子数算符全部有库内几何来源，无新公理。
2. **10.64 引子实体化**："自由费米子（CAR）极限"从空引用变为有构造支撑的代数对象。
3. **三线合一的完成**：拓扑（3.12 §9.2）、几何（10.64 SS）、代数（本文）三条独立路线收敛到同一玻色/费米二分——这是框架内罕见的"三重独立验证"结构，每一条路线的假设不同，结论一致。
4. **通往场论的入口**：3.12 §6.5 已预告 Dirac 算子 Not D = −iγ^μ∂_μ 与 Cl(3,1) 提升；二次量子化完成后，场算符 ψ(x) = Σ_k (u_k a_k + v_k b_k†) 的构造成为自然下一步。

## 六、边界与开放问题

**边界（诚实标注）**：
1. γ_i = i·e_i 是复数化操作（Cl(n)⊗ℂ）——"复数化从何而来"依赖 3.12 §6.4 的 Cl(7) 复结构（中间层），CAR/CCR 验证本身是纯代数（A0 类）。
2. Fock 构造在独立粒子极限内（3.12 §9.4 注记：粒子间距 ≫ Δξ_pixel 时成立；近距失效，需 N 体构型空间分析）。
3. 玻色子构造未显式验证多重占据谱（n = 0,1,2,… 的阶梯），仅验证了 [a,a†] = 1 的代数核心。

**开放问题**：
- **场算符与 Cl(3,1)**：3.12 §6.5 预告的 Dirac 提升 + 本文的 CAR/CCR → 场算符构造（O1）。
- **相互作用**：3.12 §11 的费曼图微扰展开（框架级）如何与 Fock 空间上的相互作用项连接（O2）。
- **重整化**：3.12 §11.4 标注"方向明确（开放）"——二次量子化后此缺口保持（O3）。
- **玻色子 Fock 阶梯的显式谱**：从 Kähler 极化构造出发显式写出玻色子占据数本征态（O4）。
