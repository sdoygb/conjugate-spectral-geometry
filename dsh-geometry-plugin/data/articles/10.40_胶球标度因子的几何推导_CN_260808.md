# 10.40 胶球标度因子的几何推导

## 摘要

本文推导胶球质量公式中的标度因子。10.24 已推导夸克扇区标度 $\kappa_c = (k_0\Delta\Theta)^3 = 10^3$（命题 10.24.4.01，色空间体积提升），$\kappa_c K = 839.759$ MeV 为色态标度。10.39 的胶球质量公式 $m_g = \kappa_g K\sin^3\sigma_\mathcal{M}^{(g)}$ 经单位修正后取最简形式：

$$m_g = \kappa_c K \cdot \sqrt{D},$$

其中 $K\sin^3(30°) = 1/8 \cdot K$ 与胶球因子中的 $8$（伴随维数）**精确抵消**——10.37 定理 X1.2 的等权构型 $\sigma_\mathcal{M}^{(g)} = 30°$ 给出 $\sin^3(30°) = 1/\dim(\mathrm{adj})$，这是构型与表示维数的耦合。$D$ 为色闭合通道的有效维度：

$$D_- = 8 \quad (0^{-+}, 2^{++}), \qquad D_+ = \frac{\sigma_\mathcal{M}^*}{\sigma_\mathcal{C}^*} = 3.694 \quad (0^{++}).$$

数值预言：$m_{0^{-+}} = m_{2^{++}} = 2.375$ GeV（X(2370) 偏差 0.2%）、$m_{0^{++}} = 1.614$ GeV（f₀(1500)/f₀(1710) 之间）。弦圈交叉检验给出 $R\cdot\Lambda_{\text{QCD}} = \sqrt{\Lambda/(k_0\Delta\Theta)} = \sqrt{0.3}$（锚定常数 $0.3 = \cos\theta_I^{\text{sat}}$），与质量算符路径差 0.03%。$D$ 的两个取值有候选解释但未定论，列为开放问题。

**状态**：探索稿，未提交主库。$\kappa_c$ 部分为定理级（10.24 已推导）；$D$ 的取值是实验导出的候选构造（选择偏差风险已标注）。含零个推测性假设——所有数值均来自已入库参数。

## §1 问题：κ 的推导现状与 10.39 的单位修正

质量算符（7.16 §2.1，圆满再现定理命题）：$m = \kappa K \sin^3\sigma_\mathcal{M}$，$K = 839.758793$ keV 为普适质量量子。三个扇区的标度因子：

| 扇区 | κ | 状态 | 来源 |
|:---|:---|:---|:---|
| 轻子 | 1 | 定理级 | $m_e = K\sin^3\sigma_\mathcal{M}^{(e)} = 511$ keV |
| 夸克 | $\kappa_c = (k_0\Delta\Theta)^3 = 10^3$ | 已推导（构造性分解） | 命题 10.24.4.01 |
| 胶球 | $\kappa_g = \kappa_c \cdot f$ | $f$ 待推导（本文） | 10.39 |

10.39 初版将 $K\sin^3(30°) = 104.97$ keV 误作 0.10497 GeV，导致 $f = 8^{3/2}$ 直接乘出"2.375 GeV"（实际为 2.375 MeV，差 $10^3$）。修正后 $\kappa_g = \kappa_c f$，数值预言不变（2.375/1.614 GeV），但结构澄清为：**胶球标度 = 色态标度 × 胶球因子**。

## §2 κ_c 的推导机制回顾

命题 10.24.4.01（色空间体积提升）的三步论证：

1. **色空间三维**：夸克色空间 = SU(3) 基础表示 $\mathbb{C}^3$（定理 7.14.3.01，色单态 $(T, \varepsilon)$ 缩并；#285 规范群 Clifford 根源；#288 排除 $SU(N\geq4)$）。
2. **每维编码容量**：$k_0\Delta\Theta = 2\times5 = 10$——终端二元性 $k_0=2$ 与复结构 $\Delta\Theta=5$ 之积。与互锁骨架 $\Lambda_H = k_0\Lambda(\Delta\Theta/1°)^2 = 150$（7.11 §3.2）同源：$\Lambda_H$ 含 $k_0(\Delta\Theta)^2$ 因子，色方向含 $k_0\Delta\Theta$——同一互锁结构在色空间的投影。
3. **三维体积**：$\kappa_c = (k_0\Delta\Theta)^3 = 10^3$。

**地位标注（10.24 原文）**：步骤 1 有定理支撑；步骤 2、3 是"基于互锁常数一致性的构造性分解"，唯一性未证明（$1000 = (k_0\Delta\Theta)^3$ 是唯一"纯 $\{2,3,5\}$ 复合且次数最低"的分解）。严格验证依赖 10.26 的 $\alpha_s$ 闭合（$\eta_{\text{QCD}}$ 与 $\kappa_c$ 的独立性检验，已由定理 10.26.7.01 完成比值级闭合）。

$\kappa_c K = 839.759$ MeV——**色态标度**：单个色荷（色单态约束下）的质量标度，是强子质量谱的基准。

## §3 胶球因子的最简形式：m_g = κ_cK·√D

### §3.1 sin³(30°) 与伴随维数的抵消

10.37 定理 X1.2：胶球单态构型驻留三扇区等权叠加 $\theta_0 = (30°,30°,30°)$，即 $\sigma_\mathcal{M}^{(g)} = 30°$。质量算符给出

$$K\sin^3(30°) = K \cdot \frac{1}{8} = \frac{K}{\dim(\mathrm{adj})}.$$

**命题 10.40.3.01（构型-维数抵消）** 胶球的质量权重因子 $\sin^3(30°)$ 精确等于伴随表示维数的倒数 $1/8$，与胶球因子中的 $8$ 因子抵消，质量公式化为

$$m_g = \kappa_c K \cdot \sqrt{D},$$

其中 $D$ 是色闭合通道的有效维度（取值见 §3.2）。**依据**：$\sin(30°) = 1/2$ 是等权构型的几何事实（#295 定理 7.14.3.01(iii)：$\theta_0$ 是 $S(\sigma)$ 的唯一全局极小，$S_{\min} = 24$）；$\dim(\mathrm{adj}) = 8$ 是 SU(3) 的表示论事实（#285）。

### §3.2 D 的两个取值

| 胶球 | $J^{PC}$ | $D$ | $\sqrt{D}$ | $m_g = \kappa_c K\sqrt{D}$ | 实验候选 | 偏差 |
|:---|:---:|:---:|:---:|:---:|:---|:---:|
| 标量 | $0^{++}$ | $\sigma_{\mathcal{M}0}/\sigma_{\mathcal{C}0} = 3.6938$ | 1.9219 | **1.614 GeV** | f₀(1500)/f₀(1710)（混合） | 7%/6% |
| 赝标量 | $0^{-+}$ | 8 | 2.8284 | **2.375 GeV** | X(2370) 2.37 GeV | **0.2%** |
| 张量 | $2^{++}$ | 8 | 2.8284 | **2.375 GeV** | f₂(2340) 2.34 GeV | 1.5% |

其中 $\sigma_0 = (\sigma_{\mathcal{M}0}, \sigma_{\mathcal{C}0}, \sigma_{\mathcal{I}0}) = (0.777912, 0.210603, 0.011484)$ 是零阶编码权重（1.5 §3.7，观测者位置；Cramer 法则见 2.1 §3.4；编码累积拉伸 $\chi = (8,9,1)$）；物理编码权重 $\sigma^* = (0.777428, 0.211091, 0.011481)$ 含 Bott 周期回声修正（偏差 $6.9\times10^{-5}$），用于 $S(\sigma^*) = 137.036$（1.5 §3.7）。$D$ 因子采用 $\sigma_0$；若用 $\sigma^*$，$D_+ = 3.683$、$m_{0^{++}} = 1.612$ GeV（差 0.14%，不影响结论）。

分裂比（与 10.39 一致）：

$$\frac{m_{0^{-+}}}{m_{0^{++}}} = \sqrt{\frac{8\,\sigma_{\mathcal{C}0}}{\sigma_{\mathcal{M}0}}} = 1.4717.$$

### §3.3 D 的候选解释（均未定论）

1. **缩并张量的通道结构**：$0^{-+}$ 的算符 $O = \mathrm{Tr}(G\tilde{G})$ 含体积元缩并（ε，全反对称）——ε 缩并在色空间卷进全部 8 个胶子方向（$\sum_{a=1}^{8}G^a\tilde{G}^a$，无权重衰减）→ $D = 8$。$0^{++}$ 的算符 $O = \mathrm{Tr}(G^2)$ 是度规缩并（δ，对角）——有效参与度由零阶编码权重的质量/色比 $\sigma_{\mathcal{M}0}/\sigma_{\mathcal{C}0}$ 调节（观测者看到的"标量胶球"通道）→ $D = \sigma_{\mathcal{M}0}/\sigma_{\mathcal{C}0}$。
2. **拓扑密度 vs 能量密度**：$\mathrm{Tr}(G\tilde{G})$ 是拓扑荷密度（$Q \in \mathbb{Z}$，通道数 = 伴随维数 8）；$\mathrm{Tr}(G^2)$ 是能量密度（无拓扑量子数，通道数由观测者位置决定）。
3. **反对称组合的全通道性**：$\varepsilon$ 张量（全反对称）在 $\mathrm{su}(3)$ 上的缩并无对角权重衰减；$\delta$ 张量（对称）的对角缩并保留观测者位置的权重比。

三种解释都指向同一个数值结构，但无法从现有数据区分——**列为开放歧义**。

## §4 弦圈交叉检验：R·Λ_QCD = √(Λ/(k₀ΔΘ))

7.9 §3.1：弦张力 $\sigma_{\text{string}} = H_{CC}\Lambda_{\text{QCD}}^2 \approx 3.45\times(0.2)^2 = 0.138$ GeV²。胶球若按弦圈 $m = 2\pi\sigma_{\text{string}}R$ 理解：

$$R = \frac{2.375}{2\pi\times0.138} = 2.74\ \text{GeV}^{-1} \approx 0.54\ \text{fm},$$

与格点 QCD 的胶球半径（~0.5 fm）量级一致。

**观察 10.40.4.01（半径的无量纲化）** 弦圈半径的无量纲积恰好是锚定常数的平方根：

$$R\cdot\Lambda_{\text{QCD}} = \sqrt{\frac{\Lambda}{k_0\Delta\Theta}} = \sqrt{\frac{3}{10}} = 0.54772,$$

其中 $0.3 = \Lambda/(k_0\Delta\Theta) = \cos\theta_I^{\text{sat}}$ 是 10.24 锚定定理 10.24.2.01 的锚定常数（$\theta_I^{\text{sat}} = \arccos(0.3) = 72.5424°$）。等价形式：

$$m_g = 2\pi H_{CC}\Lambda_{\text{QCD}}\sqrt{\frac{\Lambda}{k_0\Delta\Theta}} = 2\pi\times3.45\times0.2\times0.54772 = 2.3745\ \text{GeV},$$

与 $\kappa_c K\sqrt{8} = 2.3752$ GeV 偏差 0.03%。

**地位标注**：该恒等依赖 7.9 的弦张力参数化（$H_{CC} = 3.45$、$\Lambda_{\text{QCD}} = 0.2$ GeV），而 $\sigma_{\text{string}} = 0.138$ GeV² 与格点值（~0.18 GeV²）差 23%——恒等可能是参数自洽而非独立结构。若弦张力采用格点值 0.18 GeV²，$m_g = 2\pi\times0.18\times2.74 = 3.10$ GeV，与质量算符路径不符。**两条路径的一致性目前只在 7.9 参数化下成立，列为开放问题。**

## §5 与 γ = 8.57 的联系（方向性）

10.26 定理 10.26.7.01：$\eta_{\text{QCD}}$ 比值结构闭合，$\gamma = 8.57$。10.26 §7.1 已回写闭式（10.42 命题 10.42.2.01）：$\gamma = k_0^2\Lambda\Delta\Theta/(\Delta\Theta+k_0) = 60/7 = 8.5714$（0.03%），分解 $\gamma = \dim(\mathrm{adj}) + k_0^2/(\Delta\Theta+k_0) = 8 + 4/7$。

胶球因子 $f_- = 8^{3/2}$、$D_- = 8$ 与 $\gamma$ 的主项 8 共享"8"——Cl(7) 旋量维数、SU(3) 伴随维数、$\chi_{\mathcal{M}} = 8$（编码累积拉伸，2.1 §3.2）、$D_- = 8$ 可能是同一互锁结构（$k_0^3$）的多个投影。$\gamma$ 含修正项 $4/7$（$= k_0^2/(\Delta\Theta+k_0)$）而 $D_-$ 不含——不对称的几何含义开放。

## §6 判别性预言与诚实边界

### 6.1 判别性预言

1. **$0^{-+}$ 与 $2^{++}$ 严格简并**（$D_- = 8$ 共享）：$m_{2^{++}} = m_{0^{-+}} = 2.375$ GeV。量化检验（10.39 §5 已立）：当前 $|\Delta m| = 24 \pm 56$ MeV（0.43σ）；若未来 $|\Delta m| > 100$ MeV，$D_- = 8$ 被排除。
2. **$0^{++}$ 与观测者位置的绑定**：$m_{0^{++}} = \kappa_c K\sqrt{\sigma_{\mathcal{M}0}/\sigma_{\mathcal{C}0}}$——标量胶球质量与零阶编码权重的质量/色比直接绑定（1.614 GeV）。若未来从 f₀ 混合态分离的纯胶球质量显著偏离 1.6 GeV，$D_+$ 需修正。
3. **弦圈恒等的判别**：$R\cdot\Lambda_{\text{QCD}} = \sqrt{\Lambda/(k_0\Delta\Theta)}$——若弦张力独立测定收敛于 0.138 GeV²（7.9 值而非格点 0.18），恒等成立；若收敛于 0.18，弦圈路径与质量算符路径的分歧成为实质问题。

### 6.2 诚实边界

1. **$D$ 的取值是实验导出的候选**：$D_- = 8$、$D_+ = \sigma_{\mathcal{M}0}/\sigma_{\mathcal{C}0}$ 由 X(2370)/f₂(2340)/f₀ 的质量反推，存在选择偏差风险。支撑点：$D_- = 8$ 恰好是伴随维数（表示论独立量），$D_+$ 恰好是零阶编码权重的质量/色比（框架独立量，Cramer 法则导出）——两个取值都"落在框架已知量上"，而非任意拟合参数。
2. **sin³ 抵消依赖 θ₀ 构型**：$\sin^3(30°) = 1/8$ 依赖 10.37 定理 X1.2 的等权构型。若未来发现胶球构型偏离 θ₀（例如混合效应），抵消结构需修正。
3. **0⁺⁺ 的混合复杂性**：f₀(1500)/f₀(1710) 是胶球与 qq̄ 的混合态，纯胶球质量有歧义——$D_+$ 的 7%/6% 偏差不可作为强证据。
4. **弦圈恒等的参数依赖**（§4 标注）：只在 7.9 参数化下成立。
5. **编码权重两体系**：7.9 §2.3 经验公式（观测者位置因子）与 7.16 质量算符（粒子 σ_M）的关系未完全厘清（10.39 §6 已列）。
6. **开放问题清单**：
   - $D$ 取值的唯一性证明（三个候选解释无法区分）；
   - 弦圈恒等的独立验证（弦张力精确值）；
   - $\gamma = 8.57$ 与 $D_- = 8$ 的互锁关系；
   - 胶球半径的实验测定（~0.54 fm 预言，格点可检验）。
