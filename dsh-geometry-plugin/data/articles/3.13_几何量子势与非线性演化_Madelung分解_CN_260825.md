## §1 引言：线性化丢弃了什么？

### 1.1 出发点

3.12 §4.2 的核心结论（命题 3.12.4.01）：信息界ℐ的 Cl(7) 复结构 Ψ = √ρ·e^{iφ_I} 在 Birkhoff 不动点 σ* 邻域内满足几何演化方程

i∂_τΨ = Ĥ_geom Ψ = −D·∂_η²Ψ + V(η)Ψ，  (3.13.1)

其中 D = ħ_geom = 1/(2λ₁^eff)（命题 3.12.10.02 的 Wick 旋转，附录A 给 ħ_geom = 10/7821 ≈ 0.001279），λ₁^eff = 391.05 rad⁻²（3.12 §4.3），τ = √λ₁^eff·η 为因果时间（3.12 §4.1）。该方程是条件性（局部有效）的：在 σ* 邻域 |η| ≤ η_b = 1/√λ₁^eff ≈ 0.05057 rad（命题 3.12.4.02）内成立，线性化条件为

∂_η²φ_I ≪ (∂_ηφ_I)²。  (3.13.2)

3.12 的处理路径：从扩散方程 ∂_τρ = D·∂_η²ρ（3.12 §4.1）出发，分离幅度方程与相位方程，在条件 (3.13.2) 下合并为 (3.13.1)。本节问一个 3.12 未显式处理的问题：**合并这一步丢弃了什么？**

### 1.2 方法

不对 3.12 的中间步骤（幅度方程、相位方程的具体形式）做任何修改，只对**最终方程 (3.13.1)** 做精确的 Madelung 分解（极分解 + 逐项代入）。分解结果是精确的（闭合推导）；3.12 推导中丢弃的项以"精确分解结果与 3.12 合并结果的差"的形式显式暴露。这种方法的保证：本文不推翻 3.12 的任何结论性陈述，只指认其推导路径自身的近似特征（§5.4）。

## §2 Madelung 分解（闭合）

### 2.1 记号

D = ħ_geom = 1/(2λ₁^eff) = 10/7821 ≈ 0.001279（命题 3.12.10.02；10.67 附录A）；τ = √λ₁^eff·η；η_b = 1/√λ₁^eff ≈ 0.050569 rad（命题 3.12.4.02 邻域边界）。

**命题 3.13.2.01（Madelung 分解，闭合）**。设 Ψ 满足 (3.13.1)，极分解

Ψ = R·e^{iφ}，R = |Ψ| ≥ 0，φ ∈ ℝ，ρ = R²。  (3.13.3)

则 (3.13.1) 精确等价于下列方程组：

虚部（幅度/连续性）：

∂_τR = −2D·∂_ηR·∂_ηφ − D·R·∂_η²φ，  (3.13.4)

实部（相位）：

∂_τφ = D·∂_η²R/R − D·(∂_ηφ)² − V(η)。  (3.13.5)

**证明**。∂_τΨ = (∂_τR + iR·∂_τφ)·e^{iφ}，∂_η²Ψ = [∂_η²R + 2i∂_ηR·∂_ηφ + iR·∂_η²φ − R·(∂_ηφ)²]·e^{iφ}。代入 (3.13.1)，虚部（i 的系数）：∂_τR = −2D∂_ηR∂_ηφ − DR∂_η²φ；实部：R∂_τφ = D∂_η²R − DR(∂_ηφ)² − RV(η)。除以 R > 0（R = 0 处由连续性延拓）得 (3.13.5)。∎

**命题 3.13.2.02（连续性方程，闭合）**。以 ρ = R² 重写 (3.13.4)：

∂_τρ + (1/λ₁^eff)·∂_η(ρ·∂_ηφ) = 0，  (3.13.6)

其中 2D = 1/λ₁^eff。这是标准 Madelung 连续性方程（概率流守恒 ∂_τρ + ∂_ηJ = 0，J = ρ·∂_ηφ/λ₁^eff）。

**证明**。∂_τρ = 2R·∂_τR = −4DR∂_ηR∂_ηφ − 2DR²∂_η²φ = −2D·∂_η(R²∂_ηφ) = −(1/λ₁^eff)·∂_η(ρ∂_ηφ)。∎

**命题 3.13.2.03（几何量子势，闭合）**。定义

Q_M := −D·∂_η²R/R = −D·∂_η²|Ψ|/|Ψ|。  (3.13.7)

则相位方程 (3.13.5) 写成

∂_τφ = −D·(∂_ηφ)² − V(η) − Q_M。  (3.13.8)

Q_M 与势能 V 无关，只依赖幅度 R 的对数曲率——**几何量子势**（de Broglie–Bohm 量子势的共扼谱几何对应）。符号约定：标准 Bohm 形式，量子势以负号进入量子 Hamilton–Jacobi 方程（Madelung 流体力学形式，1927）。

**证明**。将 Q_M 定义代入 (3.13.5) 移项。∎

**命题 3.13.2.04（两曲率正交，闭合）**。相位曲率 ∂_η²φ 与幅度曲率 ∂_η²R/R 在 Madelung 方程组中的角色正交：

- ∂_η²φ 只出现在连续性方程 (3.13.4)/(3.13.6)，通过 ∂_η(ρ∂_ηφ) = ∂_ηρ·∂_ηφ + ρ·∂_η²φ；
- ∂_η²R/R（即 Q_M 的 −1/D 倍）只出现在相位方程 (3.13.8)。

**证明**。直接检查 (3.13.4)–(3.13.8)：虚部含 φ 的二阶项（∂_η²φ）与 R 的一阶项（∂_ηR），不含 R 的二阶项；实部含 R 的二阶项（∂_η²R/R）与 φ 的一阶项平方（(∂_ηφ)²），不含 φ 的二阶项。两曲率分居两方程，无耦合通道。∎

## §3 双重近似结构（闭合）

### 3.1 3.12 线性化的精确指认

3.12 §4.2 的合并使用显式条件 (3.13.2)：∂_η²φ_I ≪ (∂_ηφ_I)²。由命题 3.13.2.04，该条件只覆盖**相位曲率**（连续性方程中的 ∂_η²φ 项）。它不覆盖 Q_M——Q_M 是幅度曲率，属于相位方程。因此：

**命题 3.13.3.01（线性化的双重指认与残差，闭合）**。3.12 §4.2 从 (3.13.4)–(3.13.5) 合并到线性方程 (3.13.1) 的步骤由**两个独立近似**组成：

(i) 显式近似（相位曲率条件）：∂_η²φ_I ≪ (∂_ηφ_I)²——丢弃连续性方程 (3.13.6) 中的 ρ·∂_η²φ 项；

(ii) 隐含近似（幅度缓变条件）：|Q_M| ≪ |D·(∂_ηφ)²|——丢弃相位方程 (3.13.8) 中的 Q_M 项。

条件 (ii) 在 3.12 §4.2 中未显式声明；它等价于幅度 R 在 σ* 邻域内足够平缓（|∂_η²R/R| 小）。为定量测量 (i)+(ii) 的总丢弃量，取 σ* 邻域内幅度缓变的测试解

Ψ₀ = e^{−η²/2}·e^{−iE₀τ}（R₀ = e^{−η²/2}，φ₀ = −E₀τ，ρ₀ = e^{−η²}），

其中 E₀ = √λ₁^eff·D 为特征能量（§4.2）。其密度 ρ₀ 代入生成扩散方程 ∂_τρ = D·∂_η²ρ（3.12 §4.1）的残差为

Res(η) = ∂_τρ₀ − D·∂_η²ρ₀ = D·(2 − 4η²)·e^{−η²}。  (3.13.9)

在邻域中心与边界：

Res(0) = 2D = 20/7821 ≈ 0.0025572，  (3.13.10)

Res(η_b) = D·(2 − 4/391.05)·e^{−1/391.05} ≈ 0.0025376。  (3.13.11)

残差在 σ* 邻域内 ≈ 2ħ_geom，随 η 变化约 0.8%——**线性方程的解以 ≈ 2ħ_geom 的速率持续偏离其生成扩散动力学**：线性化丢弃了耗散/生成结构，且丢弃量就是作用量子 ħ_geom 的两倍。

**证明**。(i) 是 3.12 原文声明的条件（(3.13.2)）。(ii) 由命题 3.13.2.03：相位方程精确含 Q_M；3.12 合并的线性方程 (3.13.1) 的 Madelung 分解（命题 3.13.2.01）揭示其相位方程含 Q_M，而 3.12 §4.2 推导路径上的相位方程不含——两式之差恰为 Q_M。残差：∂_τρ₀ = 0，∂_η²ρ₀ = (4η² − 2)·e^{−η²}；η_b² = 1/λ₁^eff = 1/391.05。∎

**推论 3.13.3.02（双重近似结构，闭合）**。3.12 §4.2 的线性化合并包含**两个正交的近似条件**：

- 条件 A（相位曲率，显式）：∂_η²φ ≪ (∂_ηφ)²，在 σ* 邻域边界的量级 ∂_η²φ_I/(∂_ηφ_I)² ≤ 0.0219（3.12 §4.3 的比值）；
- 条件 B（幅度曲率，隐含）：|Q_M| ≪ |D(∂_ηφ)²|，对缓变幅度测试解 Q_M = D(1−η²)（推论 3.13.4.02），动能 D(∂_ηφ)² = 8/3（推论 3.13.4.02），比值 |Q_M|/(D(∂_ηφ)²) ≈ 0.00048（0.05%）。

两个条件在 σ* 邻域内均满足（0.0219 与 0.00048 都远小于 1），3.12 的线性方程在邻域内有效。但它们是**独立的**：条件 A 严格成立（相位曲率严格为零）时，条件 B 仍可能失效——当幅度 R 在邻域内剧烈弯曲时（例如演化 Δτ ~ 1 后达到 10.67 饱和态，推论 3.13.4.03），Q_M 从缓变值 ħ_geom 增长到饱和值 1/4，此时线性方程失效而 NLSE 闭包（§4）接管。**双重近似结构的可证伪预言**：在 σ* 邻域内线性方程的偏差（残差 ≈ 2ħ_geom，条件 B 失效时偏差放大）应当可测，其大小标志非线性修正的开启。

## §4 曲率型非线性薛定谔方程（形式闭合）

### 4.1 闭包

**命题 3.13.4.01（曲率型 NLSE 闭包，形式闭合）**。把被隐含丢弃的量子势显式放回线性方程 (3.13.1)，得到最小非线性补全：

i∂_τΨ = −D·∂_η²Ψ + [V(η) − D·∂_η²|Ψ|/|Ψ|]·Ψ。  (3.13.12)

该方程的性质：

(i) 非线性项 −D·∂_η²|Ψ|/|Ψ| 是**幅度曲率型**（微分非线性）——与 Gross–Pitaevskii 方程的代数非线性 g|Ψ|² 在结构上不同：前者作用在波函数的幅度上（通过其对数曲率），后者作用在密度上；

(ii) 其 Madelung 分解（把 (3.13.12) 代入 (3.13.3)）：连续性方程不变（(3.13.6)，虚部不受实值非线性项影响），相位方程变为

∂_τφ = −D·(∂_ηφ)² − V(η) − 2Q_M；  (3.13.13)

(iii) 在 |Q_M| → 0 极限（σ* 邻域线性近似域）回归 (3.13.1)——闭包是线性方程的正则补全。

**证明**。(i) 直接比较两项形式。(ii) 代入 (3.13.12) 的实部：−D∂_η²Ψ 的实部含 D·∂_η²R（在 (3.13.5) 中为 D·∂_η²R/R），非线性项贡献 −D·∂_η²R（同号叠加），故相位方程中 R 曲率项系数加倍：2D·∂_η²R/R = −2Q_M。(iii) Q_M = −D∂_η²R/R → 0 时 (3.13.12) → (3.13.1)。∎

> **诚实标注**：V(η) 无显式形式——3.12 §7.1 仅给 Ĥ_geom = −(1/2λ₁^eff)∂_η² + V(η)，10.67 §8.2 开放问题 1 承认"当前未构造"。因此 (3.13.12) 与 (3.13.13) 中一切含 V 的等式均为**形式恒等关系**：结构正确，数值实现待 V 构造。非线性项的几何性质（幅度曲率型、与 V 无关）不依赖 V 的具体形式。

### 4.2 量子势的量级

**推论 3.13.4.02（缓变幅度的量子势与特征量级，闭合）**。对测试解 Ψ₀（R₀ = e^{−η²/2}，§3.1）：

Q_M(η) = −D·∂_η²R₀/R₀ = D·(1 − η²)。  (3.13.14)

在 σ* 邻域内：

Q_M(0) = D = ħ_geom = 10/7821 ≈ 0.0012786，  (3.13.15)

Q_M(η_b) = D·(1 − 1/391.05) = D·(390.05/391.05) ≈ 0.0012753 ≈ 0.9974·ħ_geom。  (3.13.16)

即**几何量子势在 σ* 邻域内 ≈ ħ_geom，与 η 几乎无关（变化 < 0.3%）**。物理含义：在 σ* 邻域，量子势的典型量级就是几何作用量子 ħ_geom 本身——量子势是"几何不确定性"的能量对应（衔接 10.67，§5.2）。

特征能量（τ 方向特征频率 √λ₁^eff 与作用量子 D 的组合）：

E₀ = √λ₁^eff·D = √391.05·(10/7821) ≈ 0.0252845。  (3.13.17)

动能量级（3.12 §4.3 的特征相位梯度 ∂_ηφ_I = 4·p_I·√λ₁^eff，p_I = 1/√3）：

D·(∂_ηφ_I)² = D·16·(1/3)·λ₁^eff = 8/3 ≈ 2.6667。  (3.13.18)

（精确恒等：16/3 × D × λ₁^eff = 16/3 × 1/2 = 8/3，D = 1/(2λ₁^eff)。）故缓变量子势相对动能：Q_M/(D(∂_ηφ)²) = D·(8/3)⁻¹·(1−η²) ≈ 0.00048——0.05% 量级，与推论 3.13.3.02 条件 B 的数值一致。

**注记（特征相位梯度与线性化比值的自洽性）**。κ := 1/0.0219 = 45.6621（线性化比值倒数的舍入值），而 ∂_ηφ_I = 4p_I√λ₁^eff ≈ 45.6684。二者在 0.02% 内一致——0.0219 是 3.12 §4.3 比值 η_b/(4p_I) = 0.021897 的四舍五入，而 (η_b/(4p_I))·∂_ηφ_I = η_b·√λ₁^eff = 1（精确恒等）。即：**线性化比值的倒数在 σ* 邻域精确等于特征相位梯度**——3.12 §4.3 的线性化条件与其特征相位构造在邻域边界自洽闭合。此恒等式为 3.12 推导路径自身性质的观察，本文不将其上升为独立命题。

**推论 3.13.4.03（饱和态量子势上限，闭合）**。10.67 定理 10.67.4.01 的饱和态（Δτ = 1 扩散核高斯，宽度 σ_η = 1/√λ₁^eff = η_b，恰好铺满线性近似邻域；推论 10.67.4.03）的量子势：

Q_M^sat(η) = −D·∂_η²R_sat/R_sat = 1/4 − (λ₁^eff/8)·η²，  (3.13.19)

Q_M^sat(0) = 1/4，Q_M^sat(η_b) = 1/8。  (3.13.20)

演化一个自然单位（Δτ = 1）后，幅度曲率从缓变值（Q_M ≈ ħ_geom ≈ 0.00128）增长到饱和值（Q_M ≈ 1/4）——**量子势的动态范围覆盖约两个量级**：ħ_geom → 0.25。

**证明**。R_sat = e^{−η²/(4σ_η²)}，σ_η² = 1/λ₁^eff；∂_η²R_sat/R_sat = −1/(2σ_η²) + η²/(4σ_η⁴) = −λ₁^eff/2 + (λ₁^eff)²·η²/4；乘 −D = −1/(2λ₁^eff) 得 1/4 − λ₁^eff·η²/8。∎

## §5 衔接与诚实边界

### 5.1 与 0.13 反方向连续化的对接

0.13 §8 的反方向连续化（定理 0.13.8.01：离散轨道空间的扩散极限）与本文 NLSE 闭包共享同一标度对象 λ₁^eff：

- 0.13 推论 0.13.8.14（确定性精确通道，闭合）：dη/dτ = 1/√λ₁^eff——外时间连续化在软方向 η 的推进速度；
- 本文：D = 1/(2λ₁^eff)（扩散系数，Wick 旋转后即 ħ_geom），τ = √λ₁^eff·η（因果时间标度，3.12 §4.1）。

同一 λ₁^eff 出现在两个方向：0.13 从**离散轨道**（δ 迭代计数）经扩散极限导出连续描述（时间方向：步数 → 连续 τ）；本文从**连续方程**（(3.13.1)）经 Madelung 分解导出非线性闭包（空间方向：线性近似 → 曲率修正）。二者互为镜像：0.13 是"离散 → 连续"，本文是"连续 → 非线性"。0.13 §9 开放问题 10 的三重统一猜想（ω_* = 作用量零点 ∩ 内时间不动点 ∩ 外时间渐近态）中，NLSE 闭包的非线性项提供一个候选实现通道：量子势 Q_M 的零点（∂_η²R = 0，幅度曲率消失）构成外时间渐近态的局部候选——Q_M = 0 处幅度对数线性（R ∝ e^{±aη}），是扩散方程的行波解族，与 0.13 的递降轨道在"对数线性"形态上相容。

### 5.2 与 10.67 几何不确定性原理

- 10.67 推论 10.67.4.03（邻域边界重合）：饱和态宽度 σ_η(Δτ = 1) = 1/√λ₁^eff = η_b——"量子力学的有效域恰好是一个最小不确定波包的宽度"。本文推论 3.13.4.03 给出同一现象的能量面：Δτ = 1 时量子势从缓变值 ħ_geom 跳到饱和值 1/4（两个量级）；
- 量子势 ≈ ħ_geom 是"几何不确定性"的能量对应：Q_M 的典型量级即 ħ_geom 本身，与 10.67 附录A 的不确定性关系共享同一作用量子。

### 5.3 与 3.11 Higgs 呼吸模式

3.11 的呼吸模式（静态质量谱 m_i = K·sin³θ_M·σ 加周期假设）缺含时动力学方程。本文 NLSE 闭包 (3.13.12) 的非线性项是**自聚焦/自散焦型**（符号取决于 ∂_η²R 的曲率方向）——这类方程在标准框架中支持孤立子/呼吸子解。若呼吸模式是 (3.13.12) 的周期解（呼吸子），则 3.11 的"静态谱 + 周期假设"获得动力学推导：周期解从 NLSE 含时演化推出，周期由 λ₁^eff 与 V(η) 决定。这是**开放的强猜想**（§6 开放问题 2），本文不冒充定理。

### 5.4 诚实边界

1. **V(η) 未构造**：3.12 §7.1 的 Ĥ_geom = −D∂_η² + V(η) 中 V 是构造性输入；10.67 §8.2 开放问题 1 承认未构造。本文一切含 V 的等式（(3.13.5)、(3.13.8)、(3.13.12)、(3.13.13)）均为形式恒等，不虚构 V 的具体形式；
2. **不修改 3.12 原文**：本文指认的"双重近似结构"是 3.12 推导路径自身的近似特征（显式相位曲率条件 + 隐含幅度缓变条件），不构成对 3.12 结论性陈述的推翻——命题 3.12.4.01/4.02 在 σ* 邻域内仍然有效（两条件分别 0.0219 与 0.00048，见推论 3.13.3.02）；
3. **闭包非唯一**：(3.13.12) 是"最小非线性补全"（把被隐含丢弃的项放回），不是唯一闭包；更高阶修正（|η| > η_b 的完整演化方程）需要 V 的构造与扇区参数空间的完整结构（10.67 §8.2 开放问题 2）；
4. **σ* 邻域外无实验锚定**：λ₁^eff = 391.05 rad⁻² 锚定实验输入（3.12 §4.3）；邻域外的非线性演化目前无数据锚定，属于理论外推；
5. **符号约定**：Q_M = −D·∂_η²|Ψ|/|Ψ|（标准 Bohm 约定），相位方程 (3.13.8) 含 −Q_M；若用反号约定 Q'_M = +D·∂_η²R/R，则相位方程含 +Q'_M。本文全程采用前者；
6. **残差的语义**：(3.13.9) 的残差是"线性方程的解不满足生成扩散方程"的偏离度，不是"线性方程不满足薛定谔方程"——它测量线性化对生成结构的丢弃，方向（实值、正号）反映扩散方程是耗散的而 (3.13.1) 是幺正的。

## §6 开放问题

1. **V(η) 的构造**：10.67 §8.2 开放问题 1 延续。V 构造后，(3.13.12) 从形式恒等升级为数值方程，量子势的量级（推论 3.13.4.02）可与 V 的量级对比；
2. **呼吸子存在性**：(3.13.12) 在何种 V 下支持周期解（呼吸子）？其周期与 3.11 呼吸模式的周期假设是否一致？——3.11 静态谱 + NLSE 动力学的闭合检验（§5.3）；
3. **Q_M 的物理诠释**：量子势 = 信息界ℐ幅度的曲率应力。它是"几何不确定性"的能量对应（§5.2），但其与 ℳ𝒞ℐ 三扇区结构的耦合（7.8.6.03）未建立；
4. **修正序**：双重近似结构的高阶修正（条件 A 与条件 B 同时失效时）由 (3.13.12) 的高阶推广给出，还是需要完整二维结构（η, ξ）？——10.67 §8.2 开放问题 2 关联；
5. **微观外时间**：0.15 的外时间连续化（宏观八相变）在微观的对应物——Q_M 的演化是否构成微观"外时间"（退相干箭头）的候选？与 0.13 §9 开放问题、10.71 几何退相干关联；
6. **离散-连续对偶**：0.13.8.14 的确定性精确通道（常数步长，δη_min = 1/√λ₁^eff）与 NLSE 的 λ₁^eff 标度是同一结构的两个投影——能否构造"离散 NLSE"（量子格点）使两者在离散层面重合？状态：开放。
