# qec-geometry

**量子纠错码的几何诊断工具包**

零依赖 Python 工具：按拓扑对解码错误模式分类（A0：局域/平凡拓扑；A1：跨边界非平凡链），
并用闭式公式预测容错阈值。

```
qecgeo  ──  Pauli 代数 ── 稳定子框架 ── 码库 ── 错误几何 ── 阈值闭式 ── 任意子判定
```

---

## 功能

### 1. 错误模式几何：A0/A1 分类（surface code）

MWPM 解码后，每个采样错误模式按拓扑分类：

| 类 | 含义 | 拓扑 |
|---|---|---|
| **A0** | 可修正的局域错误链 | 平凡（Berry 相位 0） |
| **A1** | 逻辑错误，跨码边界的非平凡链 | 非平凡（Berry 相位 2π） |

MWPM **配对层**将两类强烈分离：

| 特征 | A0 中位数 | A1 中位数 | A1/A0 |
|---|---|---|---|
| `total_dist`（配对边长总和） | 2.00 | 6.00 | **3.00×** |
| `n_edges` | 3.00 | 5.00 | 1.67× |
| `cluster`（最大激发簇） | 2.00 | 4.00 | 2.00× |
| 穿越率 | 22% | 47% | 2.1× |

A1/A0 分离**在阈值以下显现**（p ≈ 0.005 < surface code 阈值 ≈ 0.011）：
低噪声时逻辑错误链在配对层携带可测量的拓扑签名；高噪声时错误模式失去结构、
区分度消失（10.54 发现的物理行为）。

#### 二期：码距标度律 A1−A0 = L（L = 4/6/8 × 3 种子）

固定物理噪声 p = 0.005，随码距 L 增大，**绝对拓扑信号线性存活**：

| L | p_L | A0 链总长 | A1 链总长 | **A1−A0** | A1/A0 | A1 显式长链率 |
|---|---|---|---|---|---|---|
| 4 | 1.48% | 2.0 | 6.0 | **4.0 = L** | 3.00× | 12.9% |
| 6 | 0.49% | 8.0 | 14.0 | **6.0 = L** | 1.75× | 33.9% |
| 8 | 0.17% | 16.0 | 24.0 | **8.0 = L** | 1.50× | 51.2% |

- **标度律：A1 − A0 = L**——逻辑错误配对链多出**恰好一个码距**，非平凡同调类
  （Berry 相位 2π）的几何代价随码距线性增长；相对比值衰减（3.00×→1.50×）
  是局域错误背景 ∝ L²（错误数 ∝ 码面积）稀释的结果。
- **显式长链更常见**：A1 中含配对边 ≥ 4 的比例 12.9% → 51.2%
  （回答 10.54 §6.3 开放问题）。
- **种子可复现**：每个 L 的多种子中位数特征完全一致（L=4/6 三种子，L=8 两种子）。

### 2. 容错阈值：闭式

单轮最优纠错 + 去极化噪声下，逻辑错误率满足二次律

```
p_L(p) ≈ A·p²,    A = η·C(n,2),    p_th = 1/A
```

η = 权重 2 错误被误恢复为逻辑算符的比例（全枚举精确计算）。验证值：

| 码 | η | A | p_th |
|---|---|---|---|
| [[5,1,3]] 五比特 | 1.000 | 10.00 | 10.00% |
| [[7,1,3]] Steane | 0.3333 | 7.00 | 14.29% |
| [[15,7,3]] RM(1,4) CSS | 0.3333 | 35.00 | 2.86% |

Monte Carlo 在低 p 下确认 p_L ≈ A·p²（p=0.01 时 ratio ≈ 0.87，[7,1,3]）。

### 3. 任意子类型判定

δ = Cl(8) Majorana 8-循环置换以零净相位闭合（δ⁸ ≡ 0 mod 2π，与 Berry 相位 2π 一致）——
**Ising（Majorana）型**任意子签名，非 Fibonacci 型。

r = analyze_eta(steane_code())

## 验证

- **阈值闭式**：对 [[5,1,3]]、[[7,1,3]]、[[15,7,3]] 全枚举全部权重 2 错误；
  Monte Carlo 验证二次律；拼接压缩 p_{L+1} = A·p_L² 对 p0 = 0.001/0.01/0.05 演示。
- **错误几何**：20,000 样本 @ p = 0.005（L=4 surface code），318 个逻辑错误分析；
  total_dist 3.00× 分离跨运行稳定。
- **二期标度律**：L = 4/6/8 × 种子 42/123/777 @ p = 0.005（30k–600k shots/点）；
  **A1−A0 = L 精确成立**（4.0/6.0/8.0）；显式长链率 12.9% → 51.2%；
  中位数特征跨种子完全一致（`scripts/phase2_scaling.py` 复现）。
- 所有数值结果存于 `data/`（JSON），可由上述脚本复现。

## 诚实的局限

- A0/A1 几何分离是**阈值以下现象**：噪声高于阈值时错误模式失去结构、区分度
  消失。它是*解码错误拓扑*的诊断量，不是解码器本身。
- 阈值闭式是**单轮、无记忆、最优解码模型**——不捕捉电路级噪声相关性和多轮
  传播。真实电路阈值通常更低。
- [[5,1,3]] 的 η = 1（所有权重 2 错误都被误恢复）：其 p_th = 10% 是该模型下的
  上界估计，不是实际电路阈值。
- surface code 几何在 L = 4/6/8 表征（单一码族）；穿越率统计随 shots 有
百分之几的波动（1.2–2.1× 区间）。相对分离度（A1/A0）随 L 衰减（背景稀释）；
**绝对标度律（A1−A0 = L）是稳健的可观测量**。
